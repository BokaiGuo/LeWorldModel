## Source-level findings

`hierarchical.py:319` constructs `StandardScaler` for every cached non-pixel column, reads `dataset.get_col_data(col)`, removes rows with NaNs and fits the column. At `:503–509` the statistics dataset is the configured evaluation dataset and its process is constructed; `:533` the same process is passed to the policy. The policy's `_prepare_info` uses `process[k].transform`, and `get_action` applies `process["action"].inverse_transform` to the selected action before returning it. No action clipping or tanh is present in that inverse call. This proves the source dependency, **not the actual historical dataset, fitted values or process bytes**. The separately saved mirror model config's `BatchNorm1d` belongs to neural projection modules, not this action scaler.

`_plan_high` solves for returned macro actions, executes `rollout_high`, and selects `pred[:,0,0,:]` as `_z_subgoal`; `_plan_low` consumes that target. `rollout_high(z_init, latent_actions)` accepts no target-time argument. The five-step high replan interval is a target-hold/replanning schedule, not proof that FIRST is a physical cp5 or cp50 state. The checkpoint configuration has 5 `random_sorted` waypoints, min stride 1, max span 15 and frameskip 5; source sampling uses random total span and random gap allocation. These are variable training intervals, not a deterministic FIRST endpoint. Native single-last-frame low input and zero action history also differ from the existing history3 adapted tracker. Staged-policy duration logic is a separate policy and cannot be attributed to FIRST receding policy.

The native D50 matrix means **dataset final goal offset 50**, with `eval_budget=100`; it does not establish FIRST's timestamp. D25 and D75 exist too, so it is incorrect to say Hi only supports H50 or to import SAGE timing rules. Current known2 E1 goals are not automatically certified dataset-offset50 goals. Existing FIRST integration and pairing/parity/tracker evidence is preserved and not rerun; its saved target delivery does not authenticate a raw inverse or a matched E1 learned arm.
