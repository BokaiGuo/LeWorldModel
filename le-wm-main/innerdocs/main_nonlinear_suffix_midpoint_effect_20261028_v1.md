# 固定动作真实中点干预：预先固定的分析口径

本模块是 MAIN 独立 saved-array 算术，不加载模型、不读物理 outcome 选参数。
生产分析必须先由实际上游 strict 认证四条 full10 动作、task/goal、真正 cp5
三帧及动作 history、两个预测和相同实际 cp10 编码，再接入这些纯函数。
目前尚未接生产 acquisition ABI，不把 unit fixtures 或本协议当真实结果。

主要指标是预测终态相对同一个实际终态编码的 MSE，次要指标是预测 goal Q
相对实际 goal Q 的绝对误差。两者可能反向，均保留。恒等式为
`delta_error = 2 mean((p-a)*(q-p)) + mean((q-p)^2)`，完整带符号存储；
不拟合共同偏移，不删除交叉项，不用事后阈值筛根或选择指标。

固定四条件 / 两 known 根，不计算独立成功率、显著性或新鲜泛化。
原动作和物理结果不变，因此不存在本次干预的控制收益；不把新条件预测
与未匹配条件的旧候选比较为“排序修复”。后续真实观察后重新编译是
独立算法版本与另一项干预，需要重新获得实际物理和终态 RGB 证据。
