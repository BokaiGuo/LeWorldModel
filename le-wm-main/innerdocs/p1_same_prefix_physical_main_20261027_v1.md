# Same-prefix fixed physical interventions

MAIN-owned prospective measurement, on the same two already-used calibration roots.
Not an independent sample or a replacement for P1 eligibility, non-greedy selection,
matched strong baselines, physical success, or generalization.

Three roles are fixed before any new execution: raw zero prefix; lowest saved
step5 original-Q cost among all16 original bank prefixes (stable bank index tie);
and original two-stage winner prefix. Roles are not deduplicated even if equal.
Role selection reads saved model predictions, not real successors. Every prefix
is replayed from the original seeded reset/placement recipe, not hidden state restore.
At each saved checkpoint record both bodies' position, velocity, unwrapped angle,
angular velocity, force, torque and sleep flag; assert their exact step5 equality
across probes, in addition to state7/RGB. This does not serialize or certify exact
contact solver warm-start caches or the complete hidden simulator state.

Suffix census is zero plus both signs of every one of ten time-major logit
coordinates at fixed absolute radii .25/.5. NumPy float32 tanh maps to primitive
commands; all are within the original suffix packet ball. No fitted action,
optimizer, Q, neural computation or outcome-based selection is introduced.

2 roots ×3 roles ×41 probes =246 branches; nominally492 resets,2460 public steps,
2706 explicit renders,738 PNGs at step0/5/10. Preserve guard checks at all steps,
native termination, failures and full planned denominator; no replacement trials.
Source bindings and original task/goal are reconstructed from the sealed physical
prepare. 64MiB complete-output allowance plus200MiB disk reserve; no deletion.
Reset/substep physics is implied by source, not independently instrumented.

Compare each probe endpoint to that role's zero-suffix endpoint. Assert exact
same actual prefix state and RGB at step5 across probes. Report raw state7 changes
with wrapped angular displacement, own and common position-direction response
(common goal residual uses zero-role actual step5), native distance change, and
wrapped object angle error change. Position direction includes agent and object,
matching the four native position coordinates; velocity is retained in state7
but not silently included in a geometric direction. Do not call mixed-unit rank,
goal approach, or a finite response census a global controllability certificate.
Common versus own residuals prevent mere prefix goal proximity from automatically
counting as expanded future response. No posthoc controller or best probe dispatch.

Plan/tests and real execution are different evidence classes. Until an exclusive
prepare and actual run report exist, no physical response numbers are claimed.
CLI from inner root uses `prepare --output ...`, `verify --prepared ... --prepare-sha ...`,
then MAIN `run ... --authorize-physics`. No model inference is performed on CPU.
