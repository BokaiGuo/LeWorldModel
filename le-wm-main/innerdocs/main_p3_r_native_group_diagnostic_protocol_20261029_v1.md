# MAIN：原生 R 九项组接通诊断，非旧 equal-cap 实验

在任何本诊断模型输出产生前固定。静态代码证明旧 parent.default_caps 的 replay_calls=2，只覆盖最终 whole/segmented；冻结 R kernel.minimum 则要求18。原 tree 在旧上限下整组拒绝是正确的协议覆盖边界，不是模型/理论负结果。旧协议/source/结果均保留，不改阈值、模型、normalizer或资格规则。

此新诊断只验证原生 R 候选组能真实执行并保存其全部资格/能力数值，绝不替代 R-aware 全树、P1机制、等预算、物理收益或独立确认。固定原两个known root，顺序root0 H1、root0 H3、root1 H1、root1 H3，四槽全保留；每槽独立原始task/root_context，无反馈选根/改bank/重试，模型与identity192目标不变。仅主机CUDA，禁止CPU神经fallback。

每槽先付该parent所需H的真实raw-zero signal（不计算无关的另一H）；从其原生J按已冻结spectral8协议生成八条动作，独立zero；完整执行九项edge、各自postcontext H1 J、固定bounded_ridge和仅诊断H1 suffix，全部eligible保留。不能把kernel诊断winner说成原beam选择或发布动作，不按结果跳过任何候选。无完整组则partial，仍保存attempted/completed与全部固定槽，不退款、不自动重试。不新增encoder/physics/训练。

资源预先静态编译：每槽cap = 此H原始signal准确原生资源向量（含唯一signal_compile wrapper） + spectral.bank_cost() + kernel.minimum(H)的完整27轴投影；未知/缺轴须实现前报告，不能填零冒实测。另预留所选eligible诊断动作的whole/segmented校验可选项不在本版执行：本版不发布计划，所以最终replay0，不产生core_plan/physical_release。完整18次edge/suffix replay均计费；所有调用/数组/J/VJP/source/normalizer/precision/模型前后均逐项保存。H1/H3预算按各自形状不同如实报告，不宣称equal resources/FLOPs。

四槽各最多512MiB，整作业2GiB含256MiB失败收尾reserve，disk floor200MiB，整作业wall1800s（含验证/加载/哈希/四槽运行），allocated3GiB/reserved4GiB。写前核完整额度；排他目录、完整artifact census/hashchain、pre-run source/input封存、全量saved消费，不依赖RAM分类标签证明CUDA。不得改原源码以容纳新schema；新增独占runner或冻结orchestrator的新明确诊断入口。若原始树版本尚未冻结，先冻结已有层再实现此诊断，避免交接窗口变动。
