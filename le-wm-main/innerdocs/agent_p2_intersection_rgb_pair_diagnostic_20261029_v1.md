# Intersection same-time RGB/native diagnostic

Saved-only, fixed six plans and 24 positions; the requested pair denominator is two known roots × three public checkpoints (5/10/15) × three ordered arm pairs, 18. Each pair is right minus left: negative means smaller Q or error for right. Exact sign comparisons retain zero ties; missing actual or native values are null, never substituted. Counts are recomputed from the receipts rather than asserted. cp0 is included as observed root latent, not forecast and not native step response; it is not in the 18 pairs.

Explicit pinned MAIN RGB strict receipt, RGB report and physical strict receipt are read and SHA checked. Each RGB row is joined against the full original physical plan and same-step native snapshot/response, raw action prefix, task, root, goal and output report. Original saved 192-dimensional float32 arrays are independently loaded, decompressed with bounds, and checked against compressed and raw-array hashes. Q, model-versus-real MSE and the cross-term decomposition use independent Python float64 `math.fsum`, not producer arithmetic. Native seven-axis squared residual, agent/block XY, raw-angle, goal-relative agent velocity, native success, original angle threshold and wrapped diagnostic are separate. The native original returned reward and independent numerical residual are both reported; neither modifies the original metric. No model latent distance is added to native distance.

This inherits MAIN's completed strict receipts without rerunning their full consumer, and establishes no trusted external preregistration, new root, causality, P1/P2 admission, or benefit. No execution, encoder, optimizer or physics. No post-hoc slot, root, threshold or checkpoint selection.
