# Wall-budget panel physical replay contract

Fixed while the model batch was underway and before inspecting its new outcomes:
all 12 point/root/arm combinations,
including identical winners, receive a fresh physical environment once.
Before replay independently reconsume every delivered model journal, bind
its hash, selected root/task, actual costs and exact raw float32 action bits.
Proceed only if all six model slots completed under their fixed delivery
deadline and passed saved consumption; no rerun, no outcome-based omissions.
The existing guard validates reset, warmup, goal, RGB and action acknowledgments.
Native stops retain the returned prefix and censored remainder; other failures
are kept, never silently accepted. Each point has the same established
physical caps, no neural inference, and requires strict saved consumption.

This separate physical contract does not alter the model-only or older
physical protocols. It is an exploration on two known roots following prior
results: no independence, global isolation, total-cost equality or scientific
gate admission is asserted.
