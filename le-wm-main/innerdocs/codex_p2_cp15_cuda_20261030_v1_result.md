Each slot attempted and returned 39 packet, action_encoder, predict, predictor
and pred_proj calls; 2 Jacobian and 2 SVD requests. The axes are nested and
cannot be summed into FLOPs; a Jacobian requests 192 mathematical VJP rows,
not measured engine backward counts. Search wall spans synchronization and
durable events. Shared CUDA preflight/model load took 4.258 s and whole driver
wall 10.939 s; the lock wait was 3.928 microseconds. Original task acquisition,
encoding, OS cache, energy and actual internal backward costs are separately
inherited or unknown. This does not establish equal total compute.

The cooperative lock was held during initialization, all model operations,
source verification and synchronous computation, but the driver releases it
before the Python process exits and before explicit CUDA context teardown.
That is a lifecycle gap relative to the stronger hold-through-cleanup contract;
the recorded run must not certify exclusive cleanup. It is not corrected
retroactively. Non-cooperating processes are never excluded by this lock.
