## Strata and direction

Eight branches retained even when blocked/partial. Pair by root identity, not
array position. Initial contexts must match exactly. Full same-H2/H3 summaries
are separate. Full mixed-H2/H3 per-root differences remain explicitly
duration-confounded descriptive entries, with no pooled same-H summary. Partial
equal-step observed endpoint differences are separate and omit predicted costs
(predictions are at the originally selected full horizon). Stale encodings fail;
missing encoding remains null, never imputed. Strict nonzero sign reversal,
exact tie and unavailable are distinct. Each predicted Q is compared with its
own actual Q, object pose and original official state distance. Q disagreement
is not proof of cause, representation failure or repair benefit.

## Costs and execution

Verify actual encoder/projector attempt/completion journals and 8-cap receipts;
inherit original planner/metric/replay resources without erasing shared costs.
Physical selected steps capped90; root collection/reset/warmup separate unknown
cost, never zero. Audit invokes bound physical validation once (48 saved-array
CPU SVDs), no fresh AD/predict/encoder. Goal/Q multiplications, image reads and
validation cost are not a claim of total-compute matching. Prepare separately
validates once; run's auditor source checks add no SVD beyond compute validation.

`--prepare --output NEW_PREPARED` freezes source/test/doc and actual physical-run
path. `--run --prepared NEW_PREPARED --prepare-sha256 REVIEWED_SHA
--report-sha256 ACTUAL_PHYSICAL_REPORT_SHA --output NEW_REPORT` consumes only
already-written data and creates a new arithmetic report. No waiting loop or
automatic neural/physics dispatch. Source/run hashes recorded in output. Tests
are synthetic arithmetic/metadata and real saved-evidence validation, not new
experimental execution.
