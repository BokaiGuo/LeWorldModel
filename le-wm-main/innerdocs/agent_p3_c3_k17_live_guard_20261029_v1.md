# K17 live-root / action guard seam (fixture only)

This NEW module is not a physical runner, release or time/budget certificate.
It offers instance-local functions for a future independently reviewed adapter;
it neither creates an environment nor imports torch. K17 six identities are
fixed and it does not choose root, mode, horizon or candidate by outcome.
Actual K17 known root is warm10, not actual-cp5. Nothing is inferred from model
success, and same budget is not equal FLOPs or a scientific conclusion.

The caller MUST first authenticate the complete immutable task, saved K17
plan, native physical prepare/receipt and original whole/segmented paid
replay source/bytes. This seam is not a source reader: `reference.task_sha256`
is a digest of the supplied full task, not an external authority. The caller
must bind root, task ID, normalizer and replay token to the pinned K17 handoff
and its verified original source. The old H3 physical prepare
`results/agent_p3_h3_witness_physical_20261029_v1_prepare_MAIN01.json` SHA
`0e31243a683a7383066ea3b495840610a4b1f2df811fcae318764d3b5acbac4e`
contains the two actual `warm_traces`; old source `agent_allmode_physical...`
`check_warm_frame` establishes 17 reference positions and off fallback. The
live adapter must supply genuine freshly observed 33 off/on/off captures,
all ten actual completed public warm controls, reset/placement receipts,
native root7/goal7, bound goal invariant and the plan-step0 off capture.
`reset_identity` and goal references must themselves be reconstructed from
authenticated artifacts, not self-asserted. This seam cannot certify constructor,
reset, installed environment, collision cache, event completeness, PNG files,
or actual capture implementation by accepting caller-provided dictionaries.

`history_guard` checks ordered 33 frames, source 17 positions plus 8 off
fallbacks, nonmutating capture, state/snapshot and PNG hashes, original root
and goal hash, all warm10 raw f32 actual returns and no early termination,
plus exact single-normalization of the two model-history tokens. The eight
historical unpaired on frames stay unknown, never invented. Live goal invariant
and original plan0 off frame must match the authenticated saved reference;
the full latest frame is rechecked immediately before the first intent.

`action_guard(raw5, mean, std, saved_replay_tokens)` checks literal f32 [5,2]
raw domain, once-normalization and exact bytes of an *actual saved paid replay*
token; absence or mismatch blocks. It also records inverse->raw bit equality,
including signed zero, without substituting the inverse: if inverse differs,
the literal original raw can still be used only when original saved replay
token is bitexact. A different normalized token requires a new paid replay,
not relabeling the old witness. An adapter must extract and verify the actual
replay input through the original native-call/capsule closure; this is not yet
implemented here, and no new replay is run.

`GuardedDispatch.arm` saves accepted/rejected guard to caller journal before
`first`; `first` rechecks current native goal/frame and original raw first
action, saves commit intent before invoking supplied callback and saves return
or failure. `DurableFixtureJournal` is a real exclusive fsynced test journal,
NOT the bounded native production store; its API has no output/time/floor
proof or trusted event source. It does not independently prove fsync hardware
durability or authenticate the environment. Integration must use a reviewed
bounded durable store, real native observer/meter, all remaining actions,
failure persistence, source pre/post and full saved consumer. Full wall/space
budget and commit length require separate MAIN approval; source changes are
not authorized by this fixture.
