## Endpoint arithmetic and strata

Original RGB history/goal identities and float32 normalized warmup between-state
tokens must match source references and saved predictor action history exactly.
Pair reset/context/state/goal identities must be identical. Final state must be
the last observed state (initial state for zero-step refusal); evaluator errors,
returned-but-unrendered steps and no-observation failures remain explicit.
Freshness is independently recomputed, never inferred just from returned steps.

Original official labels are recomputed from saved seven-state and goal using
the installed-compatible pure label function, including agent contribution,
full seven-state distance, position/angle errors and exact success thresholds.
Object pose is separately recomputed as object XY norm plus20 times circular
angle distance. Neither is replaced by latent Q. Saved labels must agree; full
paths require all labels. Source actual-encoding vector is scored with original
Q/goal0; predicted vector is scored separately with the same Q/goal0. Both saved
costs are verified. A valid fresh partial encoding remains a partial Q, not full.
No encoding yields null actual Q; no imputation or latent/state substitution.

Full same-horizon pairs are full_H2_pair or full_H3_pair, with separate
descriptive delta summaries and explicit root IDs. Delta is dynamic minus
uniform, lower better except success. Full mixed-H2/H3, partial_same_steps and
partial_or_unmatched are retained with per-arm metrics but excluded from all
full same-horizon delta/reversal summaries. No pooled H2+H3 effect estimate.
Failed/reset-blocked arms cannot be removed to keep apparent n=4.

For each eligible root, report strict opposite nonzero signs between predicted
Q delta and actual Q, pose or official-state-distance delta. Exact zero in
either is tie_in_either, not a reversal; missing actual Q is unavailable.
No sign tolerance is tuned to outcomes. Counts and deltas are descriptive of
these four already-used roots, not independent-cohort efficacy or inference.

## Costs and execution

Auditor calls neural/physical functions zero times. It reads PNGs and saved
arrays and revalidates frozen exporter (eight saved-array SVDs per
load_and_compute); these CPU checks are explicit overhead, not zero compute.
Prepare also validates consumer (eight saved-array SVDs). Original planner
predict/Jacobian/VJP/SVD costs and physical visual encodings are inherited once
by byte-bound source report, not repeated, zeroed or added as standalone sums.
The output includes recomputed actual planner predict/action-encoder/context
counts, compilation/Jacobian/SVD/VJP counts and consumer visual-forward counts;
historical cache acquisition remains inherited unknown, engine backward API
counts remain unmeasured. Shared work is counted once, not per-arm attribution.
No total-FLOP/equal-runtime claim, uncertainty test, p value or causal claim.
