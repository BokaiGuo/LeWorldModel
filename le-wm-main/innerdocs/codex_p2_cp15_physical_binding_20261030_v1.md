The new model output is joined to the original real task, root, goal, literal
prefix, complete native/RGB prefix reference and full observed feedback context.
For each fixed base, both joint and suffix actions are the exact saved CUDA
float32 bytes, not a reconstructed tanh or a prior planner witness. A reusable
dispatch gate permits suffix work only after an exact 106-event warm/prefix
comparison and a durable guard receipt. A stop or mismatched prefix fails closed.

This file provides a real-input prepare and dispatch gate, not a complete
physical runner or saved physical consumer. In particular it does not yet
implement bounded native construction, per-operation physical attempt/return
accounting, native-stop/censor publication or independent frame/ACK/goal saved
validation for the new schema. It must not trigger physical execution. Existing
physical consumers validate different planner witnesses and cannot certify this
new one merely by copying fields. Prior inherited acquisition and model costs,
and all new execution costs, must remain separate. P1/P2 gates unchanged.
