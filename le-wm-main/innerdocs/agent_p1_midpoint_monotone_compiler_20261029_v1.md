# P1 actual-context midpoint-monotone compiler core

This is a new model-only intervention, not a correction certified by physical
outcomes. The existing observed-recompile compiler evaluates nine projected
logit iterates and picks minimum identity192 Q. Here all eight non-incumbent
iterates additionally receive a real forward at the logit midpoint to the
incumbent, in the exact same actual-cp5 context. A candidate is eligible only
when `Q(candidate) < Q(midpoint) < Q(incumbent)`; choose the eligible minimum
`(Q, iteration)`, otherwise abstain. There is no physical-outcome input, gate
change, fitting, or claim that model monotonicity implies physical improvement.

All nine original candidates and eight midpoint calls remain visible; the
midpoint is evaluated through the original chart, not an ambient raw probe.
Its logit lies in the convex ball containing both validated endpoints; the
original incumbent's boundary/cast witness is preserved, not silently projected.
The original result is retained for same-action/context comparisons. Across
four slots the inherited full compiler costs 72 predict/32 reverse including
four winner replays; this method adds 32 predict, zero reverse, encoder or
physics. A failed callback raises after recording intent; it cannot yield a
selected plan. The hosting runner must retain all four slots including failure.

This is an executable callback-based method core only. It is **not production
ready**: a separate reviewed runner must reconstruct all original authorities,
enforce atomic per-slot resource limits, persist partial failures and native IO,
bind model/class/precision, replay/validate outputs, and implement complete
prepare/run/saved consume. No CUDA, physics or complete producer strict is run
by this module. It cannot itself release a physical plan or satisfy P1.
