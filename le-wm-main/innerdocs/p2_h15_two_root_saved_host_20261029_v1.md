# P2 H15 双根保存式 HOST 接缝

本接口仅实现启动前拒绝的持久化：验证外部 SHA 锚定的真实双根来源清单，独占创建目录，fsync 哈希链日志和报告。独立消费要求外部报告 SHA 与清单 SHA，重建来源清单、事件顺序、固定分母及报告。两根都是 not_started，计划额度不是实测额度；没有派发 native backend、GPU 或物理。

独立消费可以发现保存数据、顺序、任务标识及来源文件不一致，不能仅凭日志证明进程没有执行未记录的调用，也不能证明运行时模型、精度、调用预算、物理结果或源码完整闭合。历史源码清单未全部重新哈希；清单的 state-dict 哈希是历史预期而非本轮模型测量。文件系统写入失败或崩溃时，最终报告可能不存在；无报告不能消费为成功。

尚缺：真实 task 到 native ABI 的不同 root/model 哈希命名空间可验证桥接；双根 start/seal/fail 与单槽 native 审计实际接线及失败持久化；对实际调用进行不可退款资源计量及完整源码/模型/精度闭合；宿主资源限制、物理适配和独立实物证据。当前接口不允许通过传入参数启用 HOST 派发，也不承诺恢复或重试。
