# E3 continuous dispatch core

One env reference is used for each 5-step physical packet, current boundary RGB
encoder callback and subsequent node callback. Returned action bits, byte hash
identity of the captured frame, original action normalization and observed latent
history are checked before the next node. Short native stop returns without
encoding or planning later. Failed attempts record the actual exception, retain
not-reached roster and re-raise. Tests use fake callbacks, never NN/physics.

This is not a production launcher or saved strict. Its callbacks are not a source
authority; caller still must implement native setup/authenticated producer inputs,
original image/encoder complete IO, actual CUDA loader/hooks, model/source guards,
durable writer, independent numerical/native/encoder replay, close and terminal
publication. It cannot be used as evidence of an actual feedback experiment.
