# CP15 spectral physical lifecycle

Fixed four jobs, joint then sequential suffix per job, on original known roots.
Original native reset, goal, warmup and complete 106-event cp15 feedback
reference precede any suffix action. Both arms use saved CUDA action bits;
no model is loaded by the physical stage. Each job retains the original
physical resource caps and counts attempted and completed operations separately.
All output and failures are exclusive; native early stops are never padded.

The saved-only consumer runs separately and uses the lifecycle module's copied
validator. It is independent of the producing process and reconstructs saved
inputs and journal, but shares validation implementation with the producer:
it is not an independently authored implementation. Partial or failed output
is not equivalent to successful full saved verification.

Known roots and inherited CUDA/task acquisition costs preclude independent
confirmation and equal-total-compute claims. The original CUDA cooperative
lock was released before process exit and explicit CUDA context cleanup.
Sequential spectral suffix freezing is not complete program composition.
No scientific gate is changed.
