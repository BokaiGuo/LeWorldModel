# P2 H3 已知根物理配对与零动作控制

## 范围和结果

四个已知根各有 joint、suffix 两条此前验收的 CUDA chart 重算动作轨迹；本次另固定并执行每根一条 15 步零动作物理控制。三臂均为 15 步完成，12/12 原生任务成功标志为 false。这里的姿态指标是自定义的 `xy_distance + 20 * angle_distance`，角度单位为弧度，越小越好；它不是原生成功指标。

四根中模型 Q 均偏向 joint，而物理自定义 pose 均偏向 suffix；位置和角度分别只有 3/4 偏向 suffix。这是不同指标上的描述性排序反转，不是机制证明。零动作的 pose 小于 joint 4/4、小于 suffix 3/4；第 3 根 suffix 小于零动作。不能把该复合指标当作原生成功或推断普遍有效。

## 固定控制与实际接线

零动作控制在看到原八槽结果之后、其自身物理执行之前固定，不是预注册。每根固定 15 个 `[0, 0]`，沿用原根、目标、历史、渲染和真实 PushT factory；保存绑定、逐次尝试/返回的耐久预算日志、轨迹和失败记录。保存消费者重读四槽及原八槽，配对分析核验每根的初始状态、目标、历史和 RGB 身份一致，以及每臂均完成 15 步。原轨迹保存分析重建各步命令并提供第 5、10、15 步姿态。此次实际无早停；入口对终止后不得继续执行的情况有检查。

零动作实际记录 root collection 0 次 step、32 次 reset，warmup 60 次 step、4 次 reset，selected 60 次 step，所有调用均返回。未运行新神经计算或 GPU。控制臂无 planner 搜索成本；不能与 planner 两臂视作总资源相等，也不能从物理步数相同推断计算公平。

两条 planner 动作是此前 CUDA chart 重算的新动作，不能称为原始规划动作逐位复现：原产物没有保存原始 raw 位。固定零动作是对照解释的改进，不是已证明的策略性能改进。已知根、结果后选择控制、复合指标及计算差异均限制推断；未证明机制、独立复现或 P2 科学门通过。后续需要在新任务根上事先固定策略和控制、记录完整动作原始位与模型/物理资源，并开展独立评估。
