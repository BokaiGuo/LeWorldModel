## 先审查现有 kernel，再直接复用

现有 `experiments/spectral_reachability/d2p_sampling_baselines.py::mppi` 是纯 NumPy
kernel。它评估 initial，再每轮评估 N 个扰动及 updated nominal，输出全部已评估
动作中的 best-ever，稳定 first tie。其 `softmax_weights` 对 cost 最小值平移再
算 exp(−cost/temperature)，固定对角 Gaussian、clip box、按实际 clipped proposals
加权更新 nominal。新模块原样调用此 kernel，不重写/monkeypatch 旧优化器。

它缺少 proposal-density importance correction 和自动 control-energy/cross term，
clip 也不满足精确路径积分解释。因此明确命名 **MPPI-inspired shooting**，不是
标准/官方 MPPI，不声称文献复现；负结果不能排除 faithful MPPI。原 kernel 在
Reacher sampling calibration 已被同样标为 heuristic，不能换名字消除这条边界。

## 严格预算单位与固定设置（任何新结果之前封存）

原 sealed full20 是 **40 个完整 H2 候选 = 80 次 planning predict samples**，
不是80个完整候选。H2 是两个5×2包，总共20个独立 raw 分量、10个物理 primitive。
本版固定 `iterations=3, samples=12, temperature=1.0, noise_scale=0.5`、zero initial，
根0–3种子 `20261027/20261028/20261029/20261030`，不通过新结果选择这些值。

计数：`1 + 3*(12+1) = 40` 完整候选，每个两次 batch1 prediction，合计80 planning；
winner 分段重放2次，再独立完整重放2次，合计4 replay，单根84，四根预期336。
初始和三个 updated nominals 全在40内，没有遗漏额外 mean evaluation。
如果字面要求80个完整候选，则必须160 planning+4 replay，严格不匹配原80+4。
prepare 记录此冲突及 `literal_80_complete_candidates_supported=false`；CUDA CLI
必须由主线程 review 后明确 `--acknowledge-40-h2`，否则分配/创建 started 前拒绝。
这不是把80个候选悄悄降为40，而是显式保留预算单位冲突供主线程选择。

与原 CEM/random 相同 raw float32 [-1,1]^20、time-major `[2,5,2]→[10,2]`、相同
root 完整context / normalization / goal0 / Q metric。kernel 自身参数为 float64，
cost callback 明确评估转换后的 float32 raw actions，receipt 报告此量化；selected
命令逐值核对，不输出未经评估的最后 nominal。参数更新不拟合神经模型/readout。

## 真实 CUDA 路径的复用（本交付不执行）

直接复用 sealed full20 的 `RootAnchoredCudaReplay`、`_Ledger`、`raw_actions`、
`actual_entries` / `entries_match`、`metric_for` 与原 `PredictionBudget`。

predict/action_encoder 入口计数、84 sample硬上限、processed context tokens=252。
每个优化器batch在callback内串行 batch1 运行，不能把12候选batch当1次预测。
每根单一新增arm，不重跑 CEM/random；保留原对照的全部 source/input bindings。

失败时 kernel 原 batch-attempt receipt 与真实 packet-dispatch 账本分别保留，
不把尚未dispatch的batch余项写成已运行；不补齐、不退款、不隐瞒失败、不输出
可部署 winner。不完整搜索或replay不能生成消费动作见证。journal 每候选flush，
root结果独占写入；fatal环境/加载错误可能仅保留started，不自动重试。
所有神经调用仅显式主机CUDA，CPU adapter拒绝；不含物理执行器或下载入口。
