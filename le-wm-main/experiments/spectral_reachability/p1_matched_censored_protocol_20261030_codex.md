# Fixed matched suffix exploration after MAIN02

This is a new exploratory protocol selected after observing MAIN02. It is not
independent confirmation, a P1 admission, or a change to any earlier protocol.
The fixed input is the existing 16-anchor, 21-probe matched-scale preparation;
all 336 scheduled branches remain in the denominator and retain their order.
Each branch reconstructs the original warmup, prefix and 51-frame anchor trace.

The original RGB/canvas guard is unchanged. A probe-phase guard rejection may
be recorded as `censored_out_of_domain` only when the same returned public
transition, requested and actual float32 action, first guard image, branch,
step, state and immutable render snapshot are bound; the state contains a
finite coordinate outside the closed [0,512] canvas. The original image remains
on disk and its blue-pixel visibility is recorded, never synthesized. In-bounds
invisibility alone, malformed images, inconsistent state, other exceptions,
resource faults, hook cleanup failures, or source drift fail the run closed.
The censored step is not an accepted observation or an endpoint, including
when it is step 5; no further actions are dispatched on that branch.
Native early stop is separate and never padded. All later branches still run
after a valid censor. No retries or replacement are allowed.

Preparation pins all old input bindings and the complete bytes of the new
runner, saved consumer and this protocol. Source hashes bind those files,
not every dynamic/native dependency or a trusted host. Physical execution
requires explicit authorization and independently fixed prepare SHA; saved
consumption additionally requires independently fixed final report SHA.
