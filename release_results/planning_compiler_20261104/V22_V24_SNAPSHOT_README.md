# v22–v24 development evidence snapshot

This snapshot preserves the recent v22 PointMaze live-feedback/physical
response records, the v22 two-mode prospective E0 mechanism panel, v23
shared-CEM E0 panel and post-hoc diagnostics, and v24 E0 panel and seed-use
audit. The corresponding protocols and bounded conclusions are in `docs/`.
These are development results, not evidence that PC2–PC5 passed.

`saved_records/` contains copies of selected files from the local ignored
`le-wm-main/results/` directory. Original filenames and contents are
preserved, including manifests with original absolute paths. The copies are
not a relocation-aware, self-contained replay package: existing verification
scripts may require the original directory layout, matching dependency
hashes, checkpoints, datasets, runtime, and hardware. Additional older
artifacts and source-independence certification are not included merely by
this snapshot. No result or manifest has been rewritten to claim otherwise.
