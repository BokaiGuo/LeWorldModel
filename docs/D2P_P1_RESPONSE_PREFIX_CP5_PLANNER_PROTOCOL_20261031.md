# 结构化前缀真实 cp5 后缀规划：探索协议

输入是已完成保存态验收的固定 16 行；完整保留其顺序与删失。
对有真实 cp5 的行，从该 RGB、真实前缀动作、原任务目标和原模型
历史构建 planner-only 输入。对 cp5 前越界的行记录不可规划，不补值。
仅按执行状态及实际 cp5 可用性决定能否运行，不按成功、距离或任何
后续 outcome 筛选。模拟器状态和物理任务指标不得进入规划输入。

对每个可规划行采用已有四起点、每起点 20 次 Adam、两包共十步的
同一优化器及确定性初始化；同一 slot/arm 的两前缀共享初始化。
仅主机 CUDA，冻结模型，保存模型前后哈希和分类调用次数。这个
协议是看过第一次越界后的探索性续版，不是独立确认；调用记账
应区分推理、反向与编码，并将前缀生成成本单列，不能声称等预算
优势。规划后的动作还必须真实执行；预测分数不是物理结果。
