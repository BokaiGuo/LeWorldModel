# JEPA PushT v7 接线：单根模型内开发协议

**范围及信息权限。** 使用此前已暴露的 JEPA PushT validation episode 1；历史 RGB、agent 位置和速度取帧 0/5/10，两段已执行动作取 `[0:10]`。将同一轨迹帧 25 固定为图像目标；该帧在规划时作为目标图像输入，不是用于调候选的未来观测。目标图像因来自已暴露轨迹，不能声明任务独立或新泛化。规划器不得读取真实 `[10:25]` 动作、未来状态、物理后果或成功标签。没有环境执行，此处的 agent 位置和速度是离线数据真值，因此不是 RGB-only 或真实反馈。

**动作及模型。** 一次决策、15 个原始标准化前动作，限制为每轴 `[-1,1]`，再用 JEPA PushT 数据集的公开 `ACTION_MEAN/STD` 标准化并以时间顺序打包 5×2。参考 loader 将离线原始动作除以 100；此处规划坐标为除以 100 后的单位。该盒约束是开发合同，不认证所有环境动作的物理可行性。观测历史使用显式历史保持 rollout；后续本体 latent 由预测器生成。编码器和 predictor 使用已有原生封存及精确 checkpoint，保持模型冻结、TF32 关闭和共享 GPU 锁。

**方法与基线。** 目标及当前视觉 patch latent 定义第一条单位方向，第二条为固定 seed 1 的正交随机方向；只从图像计算二维 chart。候选评分使用完整视觉 patch 到目标的 MSE，不能与其他模型的 latent MSE 直接比较。分别运行不改核心的 v7 response（nominals 与 Reacher 相同）和零初始、四结点多代 smooth CEM；两臂各限 1920 prediction-token，token 按实际轨迹数乘 packet 数计数，生成、重评分和弃权均计入。CEM 包含零链 incumbent，其余预算用于 v6 同一 CEM 实现。此初步 CEM 不是充分调优的强基线或独立确认。

**输出与限制。** 固定根、随机种子和预算；保存每次请求动作、完整评分、二维 chart、预测调用计数、精修与最终选择、来源哈希。记录目标编码、初始历史编码及 wall time；SVD、内存和总成本未全面认证。不得因结果修改根、目标、指标、预算或挑选候选后重跑。结束后独立比较可记录模型内两臂最终分数，但不把模型内分数、已知目标可达性或特权本体输入当作物理成功、PC3/PC4/PC5 通过。失败及停止原样记录。
