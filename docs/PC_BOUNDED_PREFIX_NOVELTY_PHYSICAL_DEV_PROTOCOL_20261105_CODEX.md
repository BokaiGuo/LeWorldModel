# 有界新增候选的物理反事实：开发协议

使用 `PC_BOUNDED_PREFIX_FULL_POOL_NOVELTY_DEV_PROTOCOL_20261105_CODEX.md`
运行中首次规划的完整评分日志，不更改规划器选择。对每个任务，
在首次规划后续九轮中，选择相对其同轮共同池最低模型代价
差值最小的合法独有条件化候选（即模型看起来最有优势的一条），
与该同轮共同池的最低分链配对；没有独有候选的任务保留为空，
不从分母中删除。此选择是事后审计，不是规划器选链。

先重放每个任务首次规划实际返回的链，要求实际动作、完整物理
状态相对 trace 的最大误差分别 <=1e-6、<=1e-4；50 个任务
全部通过后，才从相同物理初态和目标分别执行候选与同池对照，
最多 25 步，记录首次成功、完整计划与实际执行动作域。任何
越界或执行错误明确记录，禁止事后裁剪。报告全体 50 个任务、
有候选任务、各链成功和配对方向；同时报告模型分差与真实结果。

这只判断模型声称有优势的独有候选是否具有物理后果，未检验
该候选是否会被最终均值利用、共同精修是否获益或额外调用的
完整资源优势；该已曝光面板亦不能用于确认 PC2/PC3。
