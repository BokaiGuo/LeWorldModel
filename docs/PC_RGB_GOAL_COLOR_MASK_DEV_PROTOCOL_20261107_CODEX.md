# 目标图推杆颜色遮盖：固定候选开发协议

在已暴露的 16 根 PushT 几何接触开发面板上，比较原始目标图与只由目标 RGB 构造的固定颜色遮盖目标；不使用物理状态构造评分输入。固定三个动作、模型预测后继、真实后继编码与评价端物理代价，不重新生成或精修候选。

遮盖规则事先固定：对 uint8 RGB 图中 `B > 170, B - R > 45, B - G > 25, R < 150` 的像素用左上角像素颜色替代；通道差用有符号整数计算。检测不到像素则报错，不依据结果更改阈值。记录掩码像素数、边界范围、目标输入及哈希。规则利用环境的渲染颜色，可能漏掉抗锯齿或误遮挡目标物体，不宣称通用分割。该结果只对本面板有效，不回流标准任务定义。

冻结模型编码两种目标；分别以原先封存的预测和真实后继计算平方特征距离，事后读取真实物理评价代价，按条件及根统计选择变化和物理遗憾。验证原目标编码复现已有结果，记录模型、输入、实现和协议指纹；不得读取反事实目标或从物理指标选择参数。真实后继评分只是评价端上限诊断，不能用于部署。

这是复用已暴露任务的探索性排错，不设追认通过门槛；平均遗憾、逐根改善／变差／不变、掩码可能改变的物体区域均须报告。若没有一致开发信号，不扩大此规则；即使改善，也不能代替未见任务上的完整搜索、真实闭环、成本及 PC1–PC5 证据。
