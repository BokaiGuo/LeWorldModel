# PointMaze 归档精度对物理重放的影响

针对原 25 步审计唯一超出 `1e-4` 的已曝光 root 1891，不改变原
结果或阈值。从同一归档提取原始精度状态和 25 个动作，按照二乘二
对照分别使用原始状态／float32 状态、原始动作／float32 动作，再
经相同 XML、时钟和 legacy MuJoCo 重放；float32 值在传入模拟器
前可转回 float64，但不能恢复精度。

逐条件记录每步相对归档状态的最大差和 1e-4 通过情况，检查初态与
每步时钟，不使用模型或后果选择。此对照只能定位精度在该根上的
影响，不证明全部归档、渲染、输入或动作协议等价。
