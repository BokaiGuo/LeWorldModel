# RGB 缓存规划路径与反馈重放协议

固定已曝光的 TwoRoom episode 9000–9039 及此前 CEM16 baseline 实际反馈轨迹。逐任务恢复同一初态、目标、每次真实派发与旧尾；对每个观察时刻，用相同 seed 和相同 CEM16 预算独立运行无缓存和缓存两条完整规划路径。候选生成、elite 更新、时序评分、最终选择、执行频率、停止规则不变。

两条路径必须比较每轮所有分数（`rtol=1e-5, atol=1e-3`）、elite 索引、最终选择及动作，并将无缓存结果与历史记录核验；所有实际派发的动作及物理轨迹与历史记录逐步核验。记录最低候选的竞争间隔，若出现不同选择则保留为失败而非事后调阈值。缓存对象跨观测保留，记录每次编码调用数，以测试真实输入变化时缓存失效。模型参数与来源哈希前后核验。

每次同步计时覆盖整个 CEM 规划函数，包括采样、所有查询、缓存首次建立及原输入权限/收据检查；交错先后顺序以减小顺序偏差。分别记录环境步耗时，但不把本次逐决策的配对重放当作两次独立闭环控制或完整任务总成本。物理状态只用于评价端重置与轨迹验证；规划器仅接收 RGB、目标和空单帧历史。结果仅为已曝光开发任务的工程等价性证据，不能证明方法收益或 PC gate。
