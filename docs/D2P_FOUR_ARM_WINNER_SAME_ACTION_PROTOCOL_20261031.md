# 四臂赢家预算：同动作预测与真实 RGB 对照

对已封存的 16 个节点，各用该节点实际执行的五步动作、原始 RGB
历史及部署 normalizer，重新预测一个 packet；将预测与对应时刻
实际 RGB 经同一冻结 encoder 重新编码的 latent 比较。保存完整向量、
误差、目标距离及恒等式交叉项，不使用模拟器状态选动作。

这是事后已知根诊断，同轨迹同动作同时间，不是四臂共同动作干预，
也不是独立样本、P1 通过或等预算证明。记录实际主机 CUDA 和模型
前后 hash；源报告、执行动作、观测、历史和封存源码必须匹配。
若任何绑定不成立，停止，不以失败代替模型或理论负结果。
