# TwoRoom RGB 固定候选保留：开发结果

按事前协议，使用此前暴露的 10 个标准任务；仅以 RGB、目标图和合法动作对共享候选评分。四臂均在计划封存后实际执行各自选中的 25 步链。

| 保留规则 | 曾成功 |
| --- | ---: |
| 父链分数 | 6/10 |
| 普通 lookahead | 6/10 |
| 后果向量多样性 | 6/10 |
| 行内动作身份打乱 | 6/10 |

描述臂与 lookahead 的配对独胜、独负均为 **0**，未达到预定“至少多成功 2 根”的开发出口。9/10 根两臂最终动作链相同；唯一不同的一根两臂均成功，末距分别为 2.2030 和 1.5073。前 10 根中有两根保持动作本身也成功，所有任务均保留分母。该结果停止扩大本次具体保留规则，不否定其他方法或所有程序结构。

每臂的反事实部署评分为 **440 条完整链**；为离线配对，本次实际评分每根 **656 条**，包括所有 8 个前缀的精修。模型阶段实际约 4.52 秒，不包括模型加载、物理执行和系统总成本；不是质量—成本曲线。四臂共享的 incumbent 包含 300 条 CEM 链、4 条全局链和 64 条共同尾部组合；没有单独运行等 440 评分预算的强全链 CEM，因此不能声称胜过或追平强基线。

独立审计重算保留决策、incumbent、固定前缀和最终候选来源；用 GPU 复评 40 条实际选中链，最大模型分数差 `3.06e-5`；重放 1,000 个物理步，距离最大差 0、终止标记一致。审计沿用相同模型与环境，并未重算全部 6,560 次模型评分。相关输入权限、选择规则和行动后果测试 **20 项通过**。审计最初错误地将实际评分数写为 652，已按 `300+4+64+8×36=656` 修正；原始计划记录与每臂 440 预算未改动。

数据用于开发和 normalizer，独立性未知；本次是首次开放环选择，不是整任务反馈。没有证明描述预测未查询尾部或 PC2 的实际链机制，也没有对强基线建立质量—成本优势。PC0–PC5 均不改判。
