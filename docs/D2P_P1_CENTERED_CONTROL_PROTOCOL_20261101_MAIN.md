# 居中开发任务四臂规划（结果前固定）

使用唯一已合格的平移root，不新增或替换根。完整运行
structured、native、random、immediate_progress四臂；失败槽保留。
采用既有H4→H1动态剩余时域、六次归一化梯度更新、首包保护、
后缀交换和旧计划尾部重评分。新任务使用原goal co-metric，
不是上一轮失败的几何Q。每5步真实RGB反馈、完整计划封存和计费保持不变。

不得向动作生成传入脚本见证、模拟器状态、未来帧或物理结果。
转移任务适配必须替换reset、真实历史图像、latent、root/task身份；
normalizer和实际动作历史不变且需核对。目标绑定不得修改物理状态。

所有四臂先完成和保存检查，再做综合分析，不能只报告成功臂。
原生成功停机与画布删失须保留真实步数，不补值比较20步终态。
报告即时物体/推杆/角度/jointXY变化、原生成功、终态和分类成本；
共同上限不宣称实际等成本，不声称已有强基线优势。

这是已知根开发和可见性隔离实验，不构成独立确认。
即使规划成功，仍需同一模型选定前缀的共同后缀机制干预、
各自后缀优化对照、冻结方法后的独立根和公平强基线，不能直接打开P1。
