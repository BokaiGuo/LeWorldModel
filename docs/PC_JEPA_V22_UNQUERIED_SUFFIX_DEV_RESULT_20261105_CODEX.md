# v22 共同未查询后缀：单根开发诊断

按[协议](PC_JEPA_V22_UNQUERIED_SUFFIX_DEV_PROTOCOL_20261105_CODEX.md)，四个五步前缀分别接同一组零尾、7 条构造后缀与 8 条验证后缀。总计 64 条完整链均完成物理回放和模型评分。对 v22 两臂首轮记录的 991 条去重完整链进行精确动作比较：仅全零基准曾被查询；60 条非零后缀完整链均未精确出现。

**物理覆盖不足：64 条的物体终态全部相同，且成功 0/64。** 每个前缀的验证后缀之间，物体位置误差和角度误差均全部并列，无法检验物体任务排序。预测与真实编码评分之间的排序一致，只说明本根这组动作的编码评分具有一定一致性；可能反映 agent 或外观变化，不能认证物体控制机会、未查询物理后果或行动后果描述的样本外预测能力。此实验对每条验证动作直接查询模型，亦不是用构造描述预测未查询动作质量的检验。

检查阶段发现全零基准曾被原规划查询，因而在新物理/模型调用前将零尾明确列为可重用基准；非零动作重叠仍拒绝。训练、normalizer 和任务来源独立性未知。一次预测调用计 64 条轨迹、192 prediction tokens；物理回放、编码与审计另计，不能代表规划总成本。

独立 CPU 审计重建动作库、核对已查询重叠与输入绑定、重算排序和误差，并以相同物理后端重放 64 条，末帧和末态精确一致；没有独立重算神经模型。动作生成与共享后缀单元测试 `1 passed`。证据见[模型及物理报告](../le-wm-main/results/pc_jepa_v22_unqueried_suffix_dev_20261105_codex/report.json)、[原始物理记录](../le-wm-main/results/pc_jepa_v22_unqueried_suffix_dev_20261105_codex/physical.json)与[审计回执](../le-wm-main/results/pc_jepa_v22_unqueried_suffix_dev_20261105_codex/audit.json)。

结果约束的是这一固定随机后缀库：它没有覆盖接触造成的物体后果，不能因此否定冻结模型或全部描述方法。下一步应事前规定能够覆盖不同接触/位姿的合法动作来源，同时确保物理状态仅供评估、保留未接触和失败样本。此结果不改变 PC0–PC5。
