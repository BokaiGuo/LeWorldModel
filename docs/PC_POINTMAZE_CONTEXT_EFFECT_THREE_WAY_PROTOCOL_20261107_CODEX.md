# PointMaze 多步候选：预测、真实编码与物理后果

复用前一实验已经封存的八根、每根八条动作，以及其两种窗口的
目标分数；不重新生成或按真实后果选择候选。先从原输入和动作
复算两窗口的最终预测视觉／proprio token 及目标编码，对原封存
分数要求最大差不超过 `1e-5`，封存后才访问物理轨迹。

从之前物理轨迹的精确初始和末态使用相同 XML、camera 0、目标隐藏
规则重渲染；记录实际图像与原规划输入的差异、渲染前后状态是否
改变。该重渲染不等于当时物理执行期间的原始视频：如存在视觉
差异，必须报告且不能声称图像级严格等价。

只在预测封存后使用同一冻结编码器编码真实末态图像及实际 proprio，
并按同一多模态目标计算真实编码代价。对固定同一动作，按任务
汇总模型／真实编码的预测 MSE、预测代价对真实编码代价、真实编码
代价对物理末距和预测代价对物理末距的成对排序，及各自选链的
物理遗憾；同时保留初始已命中的两根。真实后继编码是不可部署的
评价端 oracle，不用于重新选择。

先逐根再汇总；只有八个已曝光 state-assisted 任务，不能将候选对
视为独立任务。真实目标采用允许该轨道使用的目标 proprio。
诊断不宣称新描述或闭环收益，也不改 gate。
