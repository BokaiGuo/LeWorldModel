# 已知根混合前缀的真实 cp5 后缀规划

对修复后混合方法在两个已封存已知根事前选出的首五步前缀，
使用实际执行后的 cp5 RGB，固定采用历史对照所用的四个相同初始化、
每初始化 20 步 Adam、学习率 0.05、十步时域及相同动作边界。
初始化以 logical_pair 为索引，与同根 zero／greedy 对照一致。
基于冻结模型的后验分数选一个后缀；不使用物理真值或后缀物理结果选动作。
所有来源、图像、动作及 checkpoint 绑定须校验，模型调用只在主机 CUDA 运行。

仅规划不代表物理成功；必须随后实际重放每个前缀和选出的后缀，
保留原生早停与删失，并与各自 cp5 同优化预算对照配对。
此阶段不包含混合前缀生成的资源，因此不宣称端到端等预算优势；
两个已知根也不是独立确认，不改变 P1 gate。
