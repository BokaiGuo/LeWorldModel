# PushT 三方动作排序：事后分解结果

**指标边界补充：**这里的“物理”排序仅指物块位置／角度诊断代价，不是本地环境原生成功或奖励。原生成功还依赖推杆与物块的联合位置，奖励还依赖速度；对同一面板的逐状态核验见[原生指标审计](PC_PUSHT_NATIVE_SUCCESS_METRIC_AUDIT_POSTHOC_RESULT_20261107_CODEX.md)。

对已运行并独立重放的 16 个新几何开发根，按照[事后诊断协议](PC_PUSHT_EFFECT_TRIPLE_ALIGNMENT_POSTHOC_PROTOCOL_20261107_CODEX.md)比较同一动作对的模型预测目标分数、真实后继图像编码目标分数与物理 pose cost。没有重新执行环境、训练模型或把真实后继用于动作选择。

每根两种背景、左右两侧、三个无序动作对，合计 192 个相关配对；其中 64 个物理代价并列，剩余 128 个物理排序非并列。后者按预定数值容差分解：

| 相对于真实物理排序 | 配对数 |
| --- | ---: |
| 预测与真实编码均正确 | 84 |
| 真实编码正确、预测错误 | 12 |
| 预测正确、真实编码错误 | 0 |
| 预测与真实编码均错误 | 32 |
| 评分数值并列、无法判断 | 0 |

这些配对不是独立任务：每根都有 8 个物理非并列配对，白/灰背景复用同一物理过程，且多个根具有相似几何。12 个“真实编码正确、预测错误”配对分布在 5/16 根；32 个“二者均错误”配对分布在 11/16 根。所有物理非并列配对均为一个动作发生接触、另一个不接触；没有两个动作均接触的对照，因此不能推广到接触模式内部的方向辨识。

这表明此面板**同时存在**预测—真实编码排序反转和真实编码—物理排序反转，无法靠单纯改善其中一者就预先保证整套评分正确。二者共同错误也不能直接归因于某个 encoder 层：目标图包括推杆像素，视觉编码、目标定义、动作时钟及预测等因素仍可能共同作用；本分析不建立因果归因。

原始逐对差值、容差、按根和动作分层见[机器可读记录](../le-wm-main/results/pc_pusht_effect_triple_alignment_20261107_codex.json)，实现见[分析代码](../le-wm-main/experiments/pc_pusht_effect_triple_alignment_20261107_codex.py)。并列、四格分类与非有限值测试 **3 项通过**。这些结果是事后开发诊断，不证明独立任务泛化、描述增量、真实闭环或任何 gate 通过。
