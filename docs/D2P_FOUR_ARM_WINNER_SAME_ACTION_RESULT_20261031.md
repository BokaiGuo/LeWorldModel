# 四臂赢家预算：同动作单包预测与真实 RGB

已完成 16 个节点：使用每个节点实际执行的五步动作和其原始历史，
以冻结模型主机 CUDA 预测，再编码同一时刻的真实 RGB。封存报告、
完整事件链、动作、历史、目标、RGB、各节点合同及权重身份在运行
前后重新核验；没有执行新物理动作。

16 个节点预测 latent 与实际 RGB latent 的 MSE 范围
0.01365–0.12416，均值 0.03496。这不是 16 个独立任务：数据只有
一个已知根，四条轨迹各自连续共享状态。误差大小本身也不能单独
归因模型能力或代码故障。

初始节点四臂的 latent 历史、目标和归一化参数相同。它们按
目标 latent MSE 从小到大排序：

| 初始动作所属臂 | 模型预测 MSE | 真实 RGB MSE |
| --- | ---: | ---: |
| immediate-progress | 0.76458 | 0.60650 |
| native-style | 0.89276 | 0.70172 |
| random | 0.90365 | 0.93759 |
| structured | 1.04370 | 1.09415 |

这四个已执行动作的六个配对在这个时间点没有 latent 排序反转；
其中 native 与 random 的预测分数只差约 0.01090。此结论仅适用于
这四个事后观察的动作、同一初始上下文和五步结果；不能推断所有
候选排序正确，也不能把它们的 latent 排序当作物理成功排序。
五步之后各臂状态和上下文不同，不对其跨臂分数做同状态排序。
