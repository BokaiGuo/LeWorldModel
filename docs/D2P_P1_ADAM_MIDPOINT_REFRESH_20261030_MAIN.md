# P1 Adam 同动作真实中点刷新

沿用已封存的 Adam 物理轨迹和开放模型预测，使用十步动作中前五步
执行后的真实 RGB 更新历史，再预测同一轨迹的后五步；将两个预测
与同一真实十步 RGB 编码比较。19 条未删失轨迹全部进入分析，5 条
原生停止轨迹保留原删失合同、不补终点。没有新增物理干预或重规划。

输入审计核对每步真实执行动作字节与保存的完整 Adam 动作、中点
图像哈希和物理状态、终点哈希、同一 checkpoint。主机 CUDA 上冻结
模型前后散列一致，实际终点编码与上一轮结果一致。保存向量的误差
独立复算、动作篡改拒绝、既有终点测试共 3 项通过。

19 条记录的开放预测对真实终点 latent MSE 均值为 **0.25706**，
真实中点刷新后为 **0.09357**；14 条下降。按 logical pair 比较
selected 与 greedy 各自预测目标 MSE 的排序，开放预测与真实编码
排序反向 1/8，刷新后反向 4/8；这些前缀与后缀各自不同且共享两个
已知根，不能解释为独立样本的总体错误率。说明均方误差下降并不
自动保证跨候选目标排序改善。

开放路径预测两包，刷新路径只预测后一包且额外使用真实 RGB，
因此这同时改变了预测时域与状态信息；不能单独归因于观测刷新，
也不能证明同预算在线重规划或真实控制收益。原生成功轨迹的删失
意味着本结果不能用于估计完整面板成功率，更不构成 P1 通过。
