# JEPA 原生 PushT 静态目标因子：修订协议

上一协议因保存的 float32 目标状态重绘图像与原目标图不完全一致，按规则在模型编码前停止；失败记录保留。原因尚未确定，不能简单归因于精度。

本次新协议沿用原协议的两个臂、四个边界、四种干预、逐像素门槛及其全部解释边界。唯一变更是以原闭环的固定 seed、原始目标 reset 输入、同一后端配置重新 reset 目标环境，并要求重建的目标 RGB 和 float32 评价状态均与原始保存逐元素一致；从目标环境读取双精度 body 位置与角度用于图像替换。若 reset 或任一基图、两者替换图不匹配，停止且保留失败。此步骤不重新运行规划或更换目标。
