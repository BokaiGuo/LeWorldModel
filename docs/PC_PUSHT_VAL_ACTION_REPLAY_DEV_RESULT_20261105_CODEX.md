## 中间帧重置的具体问题

直接从记录的第 10 帧重置时，agent 位置在执行动作之前已分别偏移约 **0.745**、**2.111** 像素。现有环境 `_set_state` 设置了 agent 速度后，又执行一次 `space.step(0.01)`；该额外步骤会使运动中的 agent 在观察前移动。

进一步按[配对协议](PC_PUSHT_RESET_STEP_PAIRED_DEV_PROTOCOL_20261105_CODEX.md)，对两序列 `t=10..24` 的 30 个状态做标准重置和评价专用 agent 位置/速度恢复，并执行同一动作：

| 指标 | 标准重置：平均 / 最大 | agent 状态恢复：平均 / 最大 |
|---|---:|---:|
| 重置后 agent 位置误差（px） | 0.7770 / 2.1105 | 0 / 0 |
| 一步后 agent 位置误差（px） | 0.7770 / 2.1105 | 0.0000056 / 0.0000153 |
| 一步后物体位置误差（px） | 0.2231 / 0.6654 | 0.0158 / 0.0474 |
| 一步后角度误差（rad） | 0.002229 / 0.005042 | 0.000160 / 0.000462 |

逐对数据见[配对记录](../le-wm-main/results/pc_pusht_reset_step_paired_dev_20261105_codex.json)。**这支持额外重置步造成已观察的 agent 偏移，并影响此面板的一步比较。** 不能据此断言历史规划负结果均由这个问题造成，也不能把仅修正 agent 的干预称为完整状态重放：记录没有物体线速度、角速度或接触缓存。

两项实验均使用物理状态作为评价端信息，没有训练或调用视觉模型，没有修改原环境或正式规划器。下一步应设计合法初始观测与连续 warmup 的视觉实验；若要修复通用状态准备，需要单独定义接口与兼容性测试，不能静默改写旧实验。checkpoint、normalizer、开发集的来源独立性仍未知，PC0–PC5 不因此改变。
