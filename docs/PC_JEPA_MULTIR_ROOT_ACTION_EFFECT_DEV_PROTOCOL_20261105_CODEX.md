# PushT 多根非特权动作后果开发诊断协议

目的：在不使用物理见证来生成动作的条件下，分开测量模型预测后继与真实后继编码的差异、真实编码目标评分与物理指标的关系。本实验不是描述对未查询动作的预测性实验，也不是规划性能比较。

预定四个 root seed `2026110511`–`2026110514` 和四个目标 reset seed `2026110515`–`2026110518`，按相同顺序配对；每根固定十步原有 warmup，观测历史取第 0、5、10 帧。目标图来自另一 reset，不借助物理见证构造；未证明目标在 15 步可解。四根共享 64 条随机动作：生成器 seed `2026110590`，每条 15×2，在 `[-1,1]` 均匀采样，三个 5 步 packet 每段保持不变；第 0 条预定为零动作。动作生成不读取图像、模型输出或物理状态。

每条动作从同一 root 和 warmup 独立重置执行；逐元素核验历史图、proprio 和状态，保存原生末帧、末态、动作和目标。实际碰撞/物体姿态覆盖由结果报告；不足即不可识别，不能事后选样。异常、提前终止或不一致使该根失败并保留记录，不将其排除后报告成功。

对每根在隔离 worker 中先固定全部 64 条模型预测，再编码真实末帧。分别报告逐根模型预测与真实编码 MSE、持久基线、模型评分与真实编码评分排序、两种评分与物体位置/角度指标的排序、物体姿态变化数。对角度偏差使用原环境 2π 周期；并列对单独计数，样本与动作对不作为独立任务。模型实际查询了全部动作，禁止称未查询动作验证。

模型输入只有合法图像、目标图、proprio、历史动作、正常化参数及随机动作；真实状态只用于评估。封存协议、代码、动作、normalizer 源、环境、模型元数据和输入输出哈希；诊断编码/预测调用不等同正式规划的全系统成本。新 seed 不证明开发外、normalizer 拟合外或 checkpoint 训练外，相关来源保持 unknown；不改变任何 PC0–PC5 判定。
