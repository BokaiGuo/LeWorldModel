# PointMaze 单帧起始、context 1 与 2 的动作选择对照

本地旧开发 loader 明确硬编码 `ctxt_window=1`；所用仓库 PointMaze
评估配置 `mz_L2_cem_sourcerandstate_H6_nas6_ctxt2_r224_alpha0.1_ep96_decode`
声明 `ctxt_window=2` 和 `num_frames=1`。本协议检验不同的是自回归
上下文窗口，而不是额外提供真实历史帧。使用同一冻结权重和同一
单帧视觉、完整 proprio、目标、动作及预处理；在 1884–1886 已
曝光任务上比较窗口 1 与 2。

每根固定 3 父链、4 探针尾部、2 评价尾部，四个既有保留规则各保留
两个前缀，每臂 19 次完整链评分。实际单次预测为五个动作包、对应
25 环境步，不冒称官方六包 CEM。记录全部父链与探针成本、各臂
保留及最终动作；当保留不同，尾部候选也不同，不逐索引比较尾部分数。
对同一第一父链另外逐模型时刻比较预测视觉和 proprio token。
事前检查第一包的差异应在 1e-5 内；不满足时报告实现异常而非
强行继续认定归因。两个窗口分别记录实际权限、模型指纹和输入。

该实验是状态辅助、已曝光候选的实现影响核验；不改变既有结果，
不判断哪一窗口物理预测更准，也不是官方完整复现或 RGB-only 结果。
后续正式 state-assisted 版本应明确绑定配置及窗口，不把旧 context 1
研究结果重标为 context 2。
