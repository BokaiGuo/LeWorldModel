# V4 Reacher 三轮真实 RGB 反馈开发协议

固定未改动 v4 编译器、已暴露 Reacher 根 `20263160`、目标偏移 `(0.65,-0.65)`、已核验冻结 checkpoint、原统计、三帧历史和与 v3 相同的真实热身。基于自身每轮真实 RGB 历史分别规划剩余 `15/10/5` 步，执行所选链首五步，固定总时长 15 步；每次预测预算 1920 个五步 token。每轮从观察根和目标构造 seed `2027111800+step` 的二维 chart，响应使用投影坐标，全链评分使用完整 latent MSE，qpos 仅执行后用于评价。

记录完整动作和预测轨迹、模型评分、carry 及在新观测下的重评分、弃权、计量、上下文、先封存后执行的动作和物理终距。执行器复用既有 v3 RGB 路径，但在单个独立进程内配置其方法、路径、依赖与单臂；此桥接不是线程安全的公共 API，不改变历史模块或计划。已运行的 v3 response 和 smooth CEM 仅列为同根历史参考，后者热启动不充分，不能称充分调优或公平强基线。

原始结果排他写入；运行后独立核对上下文、动作、计数、评分与 carry，再分别重算模型预测和同后端物理重放。单根开发结果既不是 PC4 通过，也不是 PC2、PC3 或泛化确认；固定动作重放与模型重算本身不能认证模型—物理响应一致。二维 chart 的任务相关性、训练和 normalizer 来源及完整成本仍待证明。
