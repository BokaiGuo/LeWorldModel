# State-assisted 后果描述：固定局部支持验证

本实验只属于 official_state_assisted。依赖已封存双轨 smoke、PointMaze 原生相机物理面板及其审计；不替代 RGB-only PC1。

固定四个已暴露 episode 1880–1883，起点帧0、目标帧5、两种原生相机。保持目标视角与当前视角匹配。仅用起点 proprio；目标编码仅图像。候选为五个相同原始环境动作，沿 x 方向，时长0.25秒。不把 raw zero 当静止；所有后果相对等时长 raw zero。

构造支持：raw x=0、±0.003；中心差分另一尺度±0.001只检查数值一致性。通过自动微分计算 raw x 对视觉终帧 MSE 代价的导数，检查其与两尺度差分；不称作完整高维 Jacobian 验证。
在观察结果前固定未查询幅度 B：±0.03、±0.1。预测规则：父代价常数、构造探针最小值常数、AD线性、由±0.003估计曲率的二阶 Taylor；保留完整符号与幅度，不拟合30维欠定线性回归。B标签只用于评价，不选起点或调步长。

主开发统计：按四个任务根汇总，每根先平均两个视角。报告模型未查询代价 MAE、B内模型评分选择遗憾、近零导数绝对误差。
数值检查预定标准：每条件至少一个差分尺度满足 abs(AD-FD) ≤ 1e-3 + 0.05*abs(AD)，全部条件才标数值检查通过；不追溯改变阈值。
局部预测出口：二阶规则相对两个常数基线的根级 MAE均下降，并在至少3/4根同时成立，才继续讨论该支持下的信息使用；这是开发准入，不是PC1通用标准或独立统计确认。

物理对齐仅限已有±0.1/zero链：比较模型代价、真实终帧图像编码代价、到目标位置的真实欧氏距离。目标 state 仅评价端用于距离；不送入目标编码或选择器。报告相对zero的效应和物理选择遗憾，不能跨单位比较MAE。不把新增幅度模型结果冒充新物理重放。

记录每个候选原始动作、预测代价、支持身份和输入收据；保存冻结权重前后指纹。所有前向、反向、编码次数和同步GPU阶段墙钟记录为开发测量，不构成效率主张。数值异常先查代码/模型支持，可信性或物理方向不成立不接入端到端搜索。
