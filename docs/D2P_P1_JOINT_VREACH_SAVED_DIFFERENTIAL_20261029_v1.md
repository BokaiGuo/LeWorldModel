# P1 joint Vreach 保存差分诊断

诊断固定继承 MAIN01 已保存且 SHA 锚定的完整 saved-consume receipt；本程序不重新执行原 1.4 GB native journal 全量审计，不声称硬件证明。它核对报告、receipt、prepare 字节哈希与八臂 roster，再对报告内 160 条候选进行独立数值检查。所有结果均为事后描述或线性反事实，不改门槛、不构成新模型预测、物理结果或新根证据。

## 结论与边界

- `bounded_ridge` 的 SVD 解与独立 Gram 特征分解/乘子二分解逐项比较：最大参数差 `7.30e-14`、最大 KKT 驻点残差 `1.13e-12`；160/160 处于半径 `sqrt(5)*0.75` 约束边界，最大半径误差 `6.66e-16`。在这批有限条件输入上未发现求解器符号或约束计算错误；这不是对所有输入的数学证明。
- J 是该候选 prefix 之后、zero raw suffix 下 `d latent / d raw`。原生实现内部执行 `(raw-mean)/std`，原审计核对相同 parent context 和实际 native IO；本诊断另外重建 prefix、zero suffix、执行 suffix 对 action-history 的一次归一化。这里没有重新调用模型，也不能以本次诊断独立证明 J 的 finite difference 或捕获原链之外的隐藏调用。
- J 对 raw 的零点导数也等于对 logits 的零点导数，但 ridge 将线性解 `x` 直接代入 `Jx` 评分，执行的 float32 后缀则是 `tanh(x)`。这是有限幅度线性化与执行动作的单位/语义差异，不自动是实现 bug。L2 差为 `0.2194–0.4304`；将实际动作代入同一 J，同时保留原 logits 惩罚，线性分数较原分数高 `0.00499–0.03278`。这是固定线性模型差分，不是重新评估非线性终点；另存了按 raw 范数惩罚的反事实，不能等同原门。
- baseline 是各臂 winner-prefix 的条件最优线性分数，不是原 winner 全动作的终点分数。每臂的 baseline 候选自身因严格 `<` 必然不通过，故 160 中有 8 个结构性相等；其余 152 个均严格高于各自 baseline，最小差 `0.0145268`。在每臂对 baseline 和候选一致使用 `J*tanh(x)` 线性代入后，仍无候选低于本臂 baseline；该反事实不重定义科学门。
- 固定 baseline 残差、只替换候选 J 后有 9/160 个组合分数更低；固定 baseline J、只替换候选残差后有 4/160 个组合更低。这些是 J/残差交叉组合的代数敏感性，不是同一实际条件上下文下的可执行路径，也不说明因果。原终点比较有 14/160 为真，但全部不能满足 reach 合取。

因此不能把全零结果归因为理论必然性；也没有证据据此修改求解器或门槛。需要明确的问题是：该研究希望比较零点局部、logit 球约束的代理能力，还是实际 `tanh` 动作下的非线性可达能力。后者需要另外预先指定的比较协议及新的模型验证，不能从本 saved-only 差分中推导。
