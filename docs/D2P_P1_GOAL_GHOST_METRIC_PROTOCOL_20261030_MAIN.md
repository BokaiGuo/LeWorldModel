# P1 目标图附加标记评分：探索合同

这是一项看过既有结果后的模型内诊断，不是 P1 确认实验，也不是
十步物理机制干预或等预算性能比较。原平移推杆图像的尝试因遮挡或
非白背景被守卫拒绝；该失败保留，不放宽其守卫。

使用原固定 8 组、每组 4 个候选动作，全部原样重放。对每个目标
RGB，以蓝色推杆像素及抗锯齿区域为模板，固定在四个方向平移 8
像素，但仅在原图纯白像素上附加标记；原有推杆、物体和其他非白
像素逐位保留。方向若越界或新增像素少于 8 则拒绝整次实验。
以相反方向编码差张成二维子空间，采用固定权重 16，比较原评分
和加权评分的选择。模型、动作和目标的来源与重放基准须通过原有
检查，CUDA 和模型冻结须验证，输出不得覆盖。

附加标记不是物理推杆平移，不可称为推杆切向导数；可能引入额外
图像伪影。所有结果仅为已知根上的事后合成扰动分析，不证明真实
能力变化、独立泛化、P1 通过或公平优势。

## HOST01 结果

运行在原封存输入核验后、CUDA 模型加载之前被
`insufficient new white pixels for marker` 拒绝：至少一个固定方向
新增白底标记像素不足 8。没有输出目录、没有神经推理或评分结果。
这属于合成图像构造前置失败，不是 P1 科学负结果；不能事后降低
像素阈值、删除该方向或选择有利任务来冒充完整固定面板。
