# P1 中点信赖域：真实物理结果

固定 24 条真实物理执行全部完成并通过封存消费。与原开放、
无信赖域真实中点两种参照逐条核对，24/24 条的前五步动作字节、
物理状态、快照及终止标志一致；信赖域执行的所有返回动作还
逐步匹配封存的计划动作。信赖域规划在主机 CUDA 上完成，冻结
模型前后哈希一致；不使用模拟器真值选择动作。

| 前缀角色 | 原开放 | 无信赖域真实中点 | 信赖域真实中点 |
| --- | ---: | ---: | ---: |
| selected | 0/8 | 0/8 | 0/8 |
| zero | 5/8 | 1/8 | 2/8 |
| greedy | 0/8 | 0/8 | 0/8 |

两条信赖域成功都是 root 0 的 zero 前缀，分别是 index 1 和 7；
它们原开放均成功，无信赖域只在 index 7 成功。原开放另外三条
成功在信赖域下未成功，其中 index 19 和 22 是重复的相同优化
记录。故此结果既不是五个独立失效，也不能估计独立泛化收益。
信赖域相较无信赖域增加一条成功记录，但未恢复原开放的全部
成功，也未使 selected 成功；不能宣布该修改解决 P1。

与原开放比较有 19 对双方完成固定十步，与无信赖域比较有
22 对；原生早停的固定时域终点和配对差保持 null。相对无信赖域
的 22 对完整记录中，信赖域减无信赖域的描述性均值分别为：
物体位置误差 +2.7804、角度误差 -0.04223、推杆位置误差
-2.8193、native joint XY 误差 -0.3335。这里不同物理量不应
混合成统一好坏判定；样本共享两根且删失非随机，均值不是
独立统计推断。

此实验在观察之前结果后设定半径 0.5。它隔离的是该固定算法
中的有无信赖域，不能证明动作漂移是全部失败的根因，也不能
将该半径当作独立确定的最优参数。信赖域投影增加计算，尚未
认证全流程等成本。共同后缀物理干预仍在运行；核心非即时
进展、真实可规划能力改变、独立根和强基线联合证据仍缺。
