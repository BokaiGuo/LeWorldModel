# P1 同时间动作包偏移诊断

固定使用 24 前缀 × 4 候选及其真实五步 RGB 编码；对每条轨迹
使用相同真实 cp5 历史，仅改变待预测的五动作 token：

1. 正常：第 1–5 步实际动作；
2. 前移：前缀末动作 + 第 1–4 步动作；
3. 后移：第 2–6 步动作。

逐一比较预测 latent 与实际第 5 步 RGB latent 的 MSE，并记录
原始动作字节与此前结果的正常预测误差绑定；全部 96 条保留。
偏移 token 并非该时间段的真实动作：后移甚至读取未来第六步，
只能离线诊断，不能用于正式 selector、动作派发或 gate。

按角色和已知根/逻辑槽分栏报告描述结果，重复轨迹不当独立样本。
比较涉及同一个模型与观测，并非证明训练数据行的时间语义。
偏移更准不自动证明代码错，正常更准也不能证明其他时间错位
不存在。模型保持冻结，主机 CUDA，FP32、MATH attention。
