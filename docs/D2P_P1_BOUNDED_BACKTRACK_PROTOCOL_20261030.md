# P1 固定候选双包有界回溯探索

事前规定：沿用已封存的 8 臂 × 20 个候选、两个动作包、原目标及初始 suffix 参数。每个候选进行 8 轮，每轮在当前点计算一次原终态 MSE 的动作梯度，加上原 logits 正则的解析梯度；用原投影器分别评估步长 1、1/2、1/4、1/8 四个候选，选择第一个严格降低原正则评分者；全部不降低则保留当前点。四次试探一律实际执行并计费，不提前退出。最后再评估一次当前点；确定性 tie 按试探顺序，不改 P1 gate。

固定完整模型预算：160 × (8 × (1+4) + 1) × 2 = 13,120 次 predictor 和 action encoder；160 × 8 = 1,280 次 reverse。记录全部目标值、动作、后继、梯度和选中项，验证相同初始第一包的封存重放、冻结模型散列、来源、计数和非增性。后续必须逐候选保存复算；不能把多出的模型调用当作与旧固定步长等计算的比较。

本设计受已观察的固定步长轨迹启发，是已知根的模型内探索，不是独立确认或物理证据。比较每臂完整候选的评分 argmin 是否上坡和原固定步长结果的差异；未获得真实能力改变与闭环收益之前，所有 P1 准入标志保持 false。
