# v3 选中尾部附近的事前机制开发协议

## 假设与范围

先前网格的预定零名义响应交集为零；事后诊断显示：部分非即时链的
选中尾部附近可能有响应差异，而大尺度差分也可能跨阻挡分支。
本协议在看到下列新网格任何结果前固定，检验同一个冻结 v3 是否
事前选中这样的程序。它不撤销旧负结果，不改变原 PC2 合同。

24 根任务按笛卡尔积固定：起点 `[-0.5,y,theta]`，目标 `[0.5,gy]`，
`y=(-.35,-.05,.25,.50)`，`theta=(-1.,-.05,1.)`，
`gy=(-.25,.25)`。与两个已引用 24 根面板核对完整任务参数不重合；
不声称全仓历史排重、独立来源或确认。三臂 response、matched_random、
smooth_cem 使用 v3 在每根一次开放环规划 15 步，各 1920 token 上限；
动作选择、随机规则和所有其他方法配置不变。事前固定结果无论正负
均不得增根、重跑或调参。

## 先封存规划，再做同链干预

沿用前一网格协议的 selected、zero、same-bank greedy、random bridge、
ordinary lookahead 前缀，六个共同后缀，以及每前缀同一 120 次完整链
评价的 CEM。保留每个前缀绝对终距、相对零尾变化、自行重规划动作
与终距。另保留零名义响应，作为历史对照。

新的预先指定名义是 v3 选中链后 10 步：首五步逐坐标裁剪至
`[-.9,.9]`，末五步维持选中链实际动作。对所有前缀使用完全同一
名义；只扰动首五步的十个坐标，以 `.01`、`.05` 中心差分评价完整
15 步终点，并记录中心及各正负扰动的完整阻挡序列。这个名义由
方法事前选中的动作确定，不使用真值或干预结果，但它并不必然等于
未裁剪实际尾部，必须报告裁剪距离。

预定严格开发见证要求同一 selected 链满足：

1. 非零前缀的目标距离不小于初距减 `1e-10`；
2. 共同的实际选中尾部相对各自零尾的变化，及各自同预算重规划
   终距，均严格优于 zero 和 greedy 各 `1e-10`；
3. `.01` 和 `.05` 两个尺度，selected 对 zero 和 greedy 的完整
   终点响应矩阵 Frobenius 差均大于 `1e-6`；
4. 对 selected、zero、greedy，在每个尺度中心及全部 20 个扰动的
   整条阻挡布尔序列完全相同（允许不同前缀之间的序列不同）。

还报告是否满足对四个对照的更严格交集、所有子条件、绝对距离、
差分矩阵、阻挡序列、动作裁剪量及诊断成本；不能由单项阳性合成
见证。差分稳定分支不等于真实环境、其他尺度或因果中介证明。
规划、逐批重算审计、干预及确定性重建各自封存。没有预定见证
即保留负结果并停止此网格；出现见证也只能称开发线索，不自动
通过 PC2 或推及 RGB。
