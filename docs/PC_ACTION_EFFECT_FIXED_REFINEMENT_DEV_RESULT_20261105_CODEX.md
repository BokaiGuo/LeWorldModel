# 保留完整链固定精修机会：开发结果

按[协议](PC_ACTION_EFFECT_FIXED_REFINEMENT_DEV_PROTOCOL_20261105_CODEX.md)，在原 ranked 开发面板上对四臂各执行新的共同优化机会：每臂两个共享全局起点加本臂两条末层保留链，每起点 157 次评分。64/64 次运行完成。

| 方向 | 比较指标 | min 平均终距 | effect 平均终距 | effect 更好 / 更差 / 持平的 root |
| --- | --- | ---: | ---: | ---: |
| random | 四起点最佳 | 0.330019 | 0.330087 | 0 / 3 / 13 |
| random | 两个保留起点最佳 | 0.501543 | 0.501422 | 3 / 3 / 10 |
| spectral | 四起点最佳 | 0.329736 | 0.329765 | 0 / 1 / 15 |
| spectral | 两个保留起点最佳 | 0.501192 | 0.501165 | 2 / 1 / 13 |

四个方法臂的四起点最佳均为 **5/16** 成功；两条保留起点各自精修后的最佳均为 **0/16**。这五个成功在各臂均由共享全局起点检出。不能据保留起点 0/16 断言它们不可行：这里只使用一个预定种子和有限 CEM 预算。

本实验给出比不同来源均值更有识别力的固定机会比较，但仍不能将候选生成、保留与前缀质量分离为各自因果效应。共享全局起点在本固定机会下提供了成功保底，不代表所有预算或任务都如此；这也不是完整方法的等总成本结果。

## 账本与审计

- 64 臂 × 1884 = **120576 prediction tokens**，是独立追加的诊断成本，不计入旧端到端的 2880-token 规划成绩。
- 所有来源计划哈希与此前来源审计记录一致；每臂共享的两个全局起点动作和评分一致，保留起点来自对应末层。
- [独立审计器](../le-wm-main/experiments/audit_pc_action_effect_fixed_refinement_dev_20261105_codex.py)通过 64 条日志的动作、预测、预算与优化器重放；它使用同一工作区的动力学与优化器，不是独立复现。
- 当前证据是已暴露同族任务的开发诊断；没有全系统成本、RGB 真实执行、独立来源或同链机制证据。原 PC0–PC5 不改判。
