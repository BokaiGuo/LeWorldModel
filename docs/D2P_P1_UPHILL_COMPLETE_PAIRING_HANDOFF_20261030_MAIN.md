# 新重选前缀完整面板配对入口

`experiments/spectral_reachability/p1_uphill_complete_pairing_20261030.py`
供新重选前缀的完整 H10 面板封存后使用。入口先调用原有全量
consumer 验证全部 24 分片与 1008 物理分支，再把共同后缀结果与
真实 cp5 RGB 刷新后的零初始化、暖初始化规划结果按根、任务、
条件、前缀动作和像素哈希配对。24 个前缀观测只保存一次，
336 组共同后缀分别引用对应前缀；不得将重复臂或共同后缀当作
独立规划样本。

每个共同后缀分别记录三种前缀的状态、返回步数、绝对终点、
相对自身零后缀的变化、相对 zero 前缀的终点差与响应差。
缺失终点不填补。前缀物体、角度、推杆和原生成功分栏保留；
规划成本 receipt 原样保留，不能将上界声称为已认证实际成本。
暖初始化来自 selected 联合动作，且当前样本是已知根、事后
开发结果，不能用于独立确认或直接宣称公平强基线优势。

使用实际完整 `run_report.json` 的 SHA，从 `le-wm-main` 执行：

```bash
.venv/bin/python -B -m experiments.spectral_reachability.p1_uphill_complete_pairing_20261030 \
  --directory /home/gbk/code/LeWorldModel/le-wm-main/results/p1_uphill_h10_20261030_run_RUN01 \
  --report-sha256 ACTUAL_REPORT_SHA256 \
  --output /home/gbk/code/LeWorldModel/le-wm-main/results/p1_uphill_complete_pairing_20261030_RUN01.json
```

仅在完整面板出现 `recorded_not_consumed` 后运行。四项测试以
真实冻结的准备及规划资产配合模拟面板验证配对、缺失值、终点差
与相对零后缀响应差的区别、身份篡改拒绝；不构成新增物理实验
或 P1 通过。入口尚未对完整真实面板运行。

配对入口还会对零初始化与暖初始化两份记录分别复算前缀相对
初始状态的五项数值变化，并拒绝非有限或不一致的保存差值；
篡改两份记录的测试均被拒绝。这个检查保护即时变化表格，
不证明历史结果存在错误，也不替代完整物理面板的验收。

## 2026-10-31：各自规划差值字段

策略（真实中点、信赖域和多起点）进一步按同一逻辑任务、
