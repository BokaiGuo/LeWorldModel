# P1 cp10 固定动作：主机 CUDA 精度敏感性

按照 `D2P_P1_CP10_PRECISION_PROTOCOL_20261031.md`，复用两个已知根
的四条已执行动作和同 cp10 真实 RGB，上机比较 FP32 与 BF16 autocast；
真实标签统一由 FP32 encoder 产生。两次 FP32 编码的真实终点和
四条 FP32 预测均复现此前封存向量；模型参数及 buffer 哈希不变。

数值为反馈动作减开放动作的目标 MSE；负数表示偏好反馈：

| 根 | FP32 预测 | BF16 预测 | 真实 RGB |
|---|---:|---:|---:|
| 0 | -0.102794 | -0.103171 | -0.459371 |
| 1 | -0.092720 | -0.092436 | +0.053656 |

BF16 没有改变本次四条固定动作的排序，也没有消除根 1 的排序
反转。根 1 开放／反馈预测相对真实编码的 MSE，FP32 分别为
0.086750／0.237470，BF16 为 0.086883／0.237362。
这只排除在所测两种精度设置下通过切换推理精度修复该实例；
当前训练配置的 BF16 设置不证明此 checkpoint 的历史训练精度。
不得把 BF16 差异用于事后选动作或更改正式规划器。

共执行 12 次 encoder、8 次 action encoder 和 8 次 predictor，
没有训练、新物理执行或动作优化。独立保存态复算了完整向量、
目标误差、真实误差及动作哈希，篡改向量和动作哈希均被测试拒绝；
本次相关测试 4 项通过。两个根均用于开发，不是独立确认，P1
仍未通过，也不能排除未测的历史归一化、数据来源或接口问题。
