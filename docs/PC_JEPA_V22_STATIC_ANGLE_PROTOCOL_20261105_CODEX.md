# v22 单因素角度静态诊断：开发协议

固定已暴露接触库索引 8、9、24、25、40、41、56、57，在每个完整重放的物理末态保留 agent 与物体位置，只将物体角度设置为目标角加 `[-0.8,-0.4,-0.2,-0.1,0,0.1,0.2,0.4]` 弧度，共 64 张图。目标与反事实统一关闭碰撞点 overlay；原生渲染必须先和保存末帧逐像素相同，恢复原角后再次相同。目标须由原见证完整重放并匹配保存图与状态。

用冻结 encoder 对这 64 图及同绘制模式目标计算目标 MSE；每个末态分别报告各角度分数及其与绝对角偏差的非并列对排序。角度仅在小于 π 的范围内变化，使用与既有物理指标相同的 2π 周期。保留每个末态、所有并列与失败，禁止按结果选择索引、角度或物理条件。评估遮挡和接触缓存影响：记录原生与去碰撞点的像素差；此操作不是控制缓存的真实动态反事实。

该诊断只隔离静态画面中可修改角度的敏感性，不能证明真实动作可达性、动态预测、encoder 因果失效、规划能力或统计泛化。八个末态出自一个已暴露任务且高度相关，含评估特权见证，不能作为独立样本或正式规划输入；旧 gate 保持不变。模型输入只含渲染图与目标图，不传物理状态。保存协议、源结果、动作、环境与模型元数据哈希以及错误；神经评分和物理渲染成本分开记录，不作全成本结论。
