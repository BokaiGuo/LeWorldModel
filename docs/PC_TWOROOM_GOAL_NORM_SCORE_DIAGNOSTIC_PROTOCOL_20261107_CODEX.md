# TwoRoom 目标编码范数：固定候选开发诊断协议

已有 10 个曝光任务、每任务 64 条封存预测，观察到模型与真实编码
排序较一致但与最终物理距离关系较弱。本试验检查一个具体假设：
未归一化 latent 的范数变化是否影响目标匹配。比较原始平方距离
与单位范数后的余弦距离；后者不训练、不使用真实后继或物理标签，
只使用预测向量与可合法获得的目标 RGB 编码。若任一向量范数小于
1e-12 则拒绝该候选集，不静默加常数改变定义。

先仅打开模型预测与目标编码文件，封存每根两个选中索引和全部分数；
再读取已有物理重放结果，按任务汇总曾成功、成对独胜独负、末距及
每根预测向量范数范围。比较候选、动作、时域与已有物理结果相同，
不将真实编码后继作为在线输入或更改训练模型。原评分须能从封存
预测及目标编码在 1e-3 内重建，否则停止。

开发出口预定为：余弦选择相对原评分至少两任务独胜、无独负，且
10 任务平均末距不增加。未达到则不将该评分接入端到端搜索；达到
也仅允许在新的开发面板继续验证，不能证明统计显著、闭环收益或
PC gate 通过。数据已曝光，若历史结果曾间接影响方案则仍属探索性。
