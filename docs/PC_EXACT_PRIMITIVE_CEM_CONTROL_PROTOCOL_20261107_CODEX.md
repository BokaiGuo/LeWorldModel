# 精确墙障动作原语 CEM 对照：事前开发协议

目的：检查已暴露的单中间点程序 12/24 开发结果是否仍领先一个能够使用相同起点、朝向、目标和运动学先验的低维优化对照。不视此对照为已充分调优的最强基线。

固定先前 24 个开发根、每根 15 步、384 条完整链评分和终点欧氏距离选择。新对照的四维参数描述相对目标方向的两个绝对航向，以及两段直行距离；依次执行原地转向、直行、原地转向、直行，截断或补零至 15 步。两航向均在目标方向左右 90 度，距离各为起终距离的 0 至 2 倍。轨迹只在生成完整动作后由动力学评分；禁止使用墙坐标、真实成功标签、未来真值或解析见证来生成候选。该对照与单中间点程序均使用精确状态，不是纯视觉。

每根独立随机流先均匀采样 128 个参数；以其中代价最低的 16 个初始化对角高斯 CEM，之后固定 4 轮、每轮 64 个，取前 16 个更新，标准差下限 0.08，边界裁剪至 [-1,1]。最终从全部 384 个已评分样本选最低终距，平局取首个。动作、参数、代价、逐步阻挡、计算时间及随机种子均保存。与封存的单中间点程序结果逐根比较；记录完整模型评分和动作构造墙钟，但不同运行的时间不作为完整成本声明。

事前决策：若此对照至少 9/24 成功且比单中间点少不超过 3 根，旧结果不能再表述为相对这一更强对照有明确成功率优势；否则只说明该固定对照未消除旧开发差距，不能宣称已超越充分调优强基线。成功定义为终点距离严格小于 0.05，报告成对独胜和平均终距、完整分母及失败。独立重放全部候选并核查输入、动作边界、每轮 CEM 更新、计数与选择；使用同一动力学后端不构成独立物理引擎认证。结果不改变 PC0–PC5，也不证明描述增量。
