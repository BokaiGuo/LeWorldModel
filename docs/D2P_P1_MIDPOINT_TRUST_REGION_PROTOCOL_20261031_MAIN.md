# P1 真实中点后缀信赖域：探索性协议

在已观察开放和中点反馈结果之后，使用与此前相同的全部 24 条
固定记录及真实 cp5、中点 RGB。维持原有 20 次 Adam、学习率、
目标 latent MSE、动作盒约束和 baseline 回退规则；在每次更新后
将第二包投影到相对于原始第二包 L2 半径 0.5 的球内，再检查原
动作范围。该半径为事后开发试探，不是预先确认的最优值。此实验
仅检查约束改动能否减少大幅后缀漂移，不用结果筛选记录。

用冻结模型在主机 CUDA 完成规划、封存，再对完整 24 条执行真实
物理轨迹。与原开放和无信赖域真实中点臂逐条对齐前五步，原生
早停保留删失；报告位置、角度、推杆和成功，不将任务真值输入
规划器。记录编码、预测、backward 和耗时。此比较使用已知根且
结果影响了方法设计；不证明独立泛化、等预算胜出或 P1 通过。
