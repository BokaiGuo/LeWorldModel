# V4 局部可达价值与坐标变换：后验诊断协议

使用已暴露 24 根 v4 E0 计划中所有 216 个后继响应矩阵，固定 `A=[[2,0.4],[0,0.5]]` 和 `B=diag(linspace(0.5,2,10))`。对 `r=goal-position`、`G` 和阻尼 0.1：

1. 重算原单位度量岭值及最优动作，核验与源记录一致。
2. 令 `r'=Ar, G'=AGB⁻¹`，同时使用因子 `q'=A⁻¹, ri'=B`；其目标和动作度量分别为 `q'ᵀq'` 和 `(ri'ri'ᵀ)⁻¹`。比较原值、奇异值和 `delta'=B delta`，并用直接线性方程而非 SVD 求解交叉核验。
3. 在变换后错误地再次使用单位度量，记录各候选岭值、每根最低值候选和差异。此步骤改变了目标和动作代价，不是假装相同任务坐标表示。

依赖封存，输出排他；记录全部矩阵的误差及逐根赢家。仅检验无约束局部线性岭问题；实际 v4 还涉及单位坐标下的模态选择、有限差分、动作盒和完整链选择，此代数检查不能认证物理机制、谱增量或完整 planner 的坐标不变性。分析针对已暴露数据且为事后诊断。
