# 固定 cp10 动作排序：normalizer 敏感性

固定两个已知根、每根开放与反馈两条已物理执行动作，比较现用部署
normalizer 与本地 PushT 归档的动作均值和样本标准差。相同真实 cp10
RGB、相同冻结模型及相同原始动作下，三包动作 token 均按对应的
同一组参数计算；部署路径的预测向量复现此前固定动作诊断。

数值是「反馈动作预测目标 MSE − 开放动作预测目标 MSE」，
负数表示模型更偏好反馈：

| 根 | 部署 normalizer | 归档统计 normalizer | 真实 RGB 排序 |
|---|---:|---:|---|
| 0 | -0.102794 | -0.106023 | 偏好反馈 |
| 1 | -0.092720 | -0.095446 | 偏好开放 |

因此两个具体备选参数下根 1 的真实排序反转均存在；不能将这两个
动作的反转简单归因于这两套统计之间的差异。根 1 反馈动作的
预测与真实 latent MSE 分别为 0.237470 和 0.243545；两套参数都
没有消除这条固定动作的明显偏差。

归档仅是有限的对照，不等于 checkpoint 实际训练统计；未测的
normalizer、图像域、历史或模型实现问题仍不能排除。这不是训练来源
认证、不支持修改部署参数，也不是独立根实验或 P1 通过证据。
完整预测向量及三包 token 的独立保存态算术检查通过；
故障注入覆盖历史两包与候选包各一处 token 损坏。
