# 固定候选库的预筛与有向机会覆盖：开发合同

使用已暴露 ranked 开发面板的 `random_min`、`spectral_min` 两个已封存候选库：16 根、depth 0 和 1，共 64 个根×方向×层。固定候选、即时分数、任务与动作；不修改原规划结果，也不运行末层后继探针。每层对 float32 完全相同前缀去重，按即时分数稳定排序。

四臂采用 2×2 比较：预筛 A 取前四个；预筛 B 取前三个加一个从其余不同前缀中由固定种子均匀抽取的探索前缀。保留规则 M 保护即时最优前缀，再保留探针绝对终距最低的其他候选；规则 D 同样保护即时最优，再选择对 greedy 探针绝对终距带来最大平均正向改进 `mean(max(cost_greedy[j]-cost_candidate[j],0))` 的其他候选，稳定并列按候选索引。该规则是待检验设计，不宣称真实机会或必然改善。

每个入选前缀共享九条尾部：零尾及 seed `2051200010+tail_length` 生成的八条固定高斯尾（标准差 0.35，裁剪到 ±0.5），全层相同。两条被保留前缀各以自己的最佳探针尾为初始，使用四结点 CEM、120 个完整链样本，按 `(root, direction, depth, slot)` 固定随机流，跨臂对应槽位共享。全部 36 个探针和 240 个 CEM 样本均以完整 15 步链计费，最终返回所有已评分完整链中最低代价者；即使某个 probe 前缀后来未保留，其已评分链仍可成为 incumbent。

主要开发指标：每层实际返回完整链终距及 `<0.05` 成功；分别测预筛变化（同保留规则）和保留规则变化（同预筛）；以每根对方向、层取均值汇总配对差，同时保留逐层与失败分母、实际选择、候选路径、探针和 CEM 调用。每臂每层固定 276 条完整链，即 828 prediction tokens；源候选生成、该诊断以及端到端成本分开，不将回溯比较当成新规划成绩。

本实验只覆盖来自旧方法的暴露候选池和有限尾部优化，且不同预筛间引入的新候选不同；不能判定未采样候选不可用、不能识别生成器贡献、不能建立公平总成本或 PC2/PC3 优势。若候选不足四个或无独立探索候选，必须记录失败而非事后改变规则。仅使用合法模型预测，禁止向规划器注入物理见证。
