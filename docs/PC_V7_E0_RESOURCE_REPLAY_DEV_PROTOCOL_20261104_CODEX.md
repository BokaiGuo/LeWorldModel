# v7 E0 资源重放：已暴露面板开发协议

在读取本次计时结果前固定：重跑已封存 v7 18 根首次决策以及已封存的
三重启 smooth/action CEM。使用原任务、精确动力学、动作、随机种子、
优化器与 1920 prediction-token 策略；每批请求、实际 float32 动作、
位置和评分均须与各自封存轨迹一致，最终完整链和分数须一致。
排除计时字段，不将重跑当作新的独立实验。

对每个完整规划调用以单调时钟计量，包括有限差分、分解、筛选、
采样、预测、选择及配对弃权。另在实际调用点分别记录预测次数、
样本、token 与耗时，以及 v7 response、SVD、retention 和 CEM 调用
的次数和累计包容时间；响应时间包含预测与 SVD、CEM 时间包含预测，
这些时间不可相加。CEM 基线的三次优化也记录同口径时间与实际预测。
NumPy SVD 包裹计时，核对实际次数与 v7 原结构记录；差异即失败。
编码、图像反馈和反向传播在本精确动力学实验中没有发生，不以零宣称
视觉方法总成本；模型加载、进程启动和事后重算不计入规划时间。

以根顺序循环三臂执行次序，减少固定顺序偏置；计时为单进程 CPU、
受调度和插桩影响的开发测量，报告每根和中位数，不视为严格硬件基准。
保留所有依赖哈希，输出排他创建，并核对两套原始审计。结果不得用作
来源独立、强基线充分性、PC3 优势或任何 GPU 质量—成本曲线证明。
