# PushT 动作提案尺度与覆盖：开发协议

目的：在已暴露的验证序列 9、11 上比较不依赖参考后缀的三种固定动作提案，判断动作幅度和时间结构改变时，真实候选覆盖及出界如何变化。不是规划、评分、因果机制或独立确认。

每根从数据初态及 agent 速度开始，连续执行记录动作 0–9；目标为同一初态继续执行记录动作 10–24 的物理末态。每个候选重新从初态执行相同 warmup；参考动作仅用于目标，不进入候选生成。两根共享每臂 64 条 15×2 float32 动作，三个五步常值 packet，均不使用物理状态筛选：

- wide：各 packet 坐标独立均匀 `[-1,1]`；
- correlated：首 packet 独立正态标准差 0.2；后续为 `0.7*前值+0.3*独立正态(0,0.2)`，逐坐标裁剪到 `[-1,1]`；
- mixed：前 32 条来自 correlated，后 32 条来自 wide，使用同样的已生成索引。

种子 `2026110519`；三臂同一物理动作语义，环境相对输入乘 100。声明空间与实际相对接口不一致仍未修复；不宣称接口合法性认证。候选不使用目标参考动作；不进行事后剔除、补抽或重新选根。三臂包含不同分布，尺度与时间相关性共同变化，无法归因到单一因素。

物理主描述量为各臂各根固定 64 条的成功数、最小联合位置误差、物体位移及 agent/物体中心末态是否在 `[40,472]²` 之外；成功需联合位置误差 `<20` 且周期角误差 `<π/9`。额外报告任一步中心越界，以及物体相对 warmup 末态位移。记录逐条动作、末态、目标、输入哈希与失败状态；同一后端重放不能替代独立物理实现。动作相关、两根且已暴露；不报告统计显著性，不以最优候选冒充实际选中结果。未测模型调用、时钟成本或最终规划收益。保留所有失败，PC0–PC5 不改判。
