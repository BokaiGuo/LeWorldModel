该协议以精确状态保留手工前缀，不能称为从冻结 RGB 动力学自动生成完整程序。33 次前缀筛选按旧执行方式计入预算，响应矩阵额外计入 40 次全链评估；SVD、岭解及墙钟单列，不声称等总算力。联合精修可改变前缀，所有即时条件均基于精修后实际选中链。没有修改旧结果、旧停止规则或 gate。
