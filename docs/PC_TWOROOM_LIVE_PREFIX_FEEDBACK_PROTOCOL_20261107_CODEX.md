# TwoRoom RGB 现场固定候选反馈执行

旧反馈诊断实际观测了前缀后 RGB，但使用已有物理轨迹评价所选尾部。
本次在相同 40 个已曝光根、各自选中与逆序两种前缀上，持续运行真实
TwoRoom 环境：执行 10 步合法前缀，从现场 RGB 和目标图像对 CEM 与
既有 B 两个尾部评分，按最小模型代价选出一条，再在同一环境立即执行
15 步。必须记录现场前缀图像、模型评分、选择、25 步动作及完整距离与
终止轨迹。规划器仅接收 RGB、目标 RGB 和候选动作；物理状态仅用于
评价端 reset 与最终指标。

输入动作和模型来自已封存实验，原轨迹、反馈诊断评分与真值结果不进入
动作选择。先完成整个新执行并封存，再对照历史固定候选反馈和物理
重放，报告 80 次选择、逐步轨迹差异、两种前缀的成功数。额外反馈成本
为每条执行 2 次模型链评分、6 个模型 packet；与开放环不等总成本。
历史候选和任务已曝光，本实验不作独立或正式收益确认，也不修改 gate。
