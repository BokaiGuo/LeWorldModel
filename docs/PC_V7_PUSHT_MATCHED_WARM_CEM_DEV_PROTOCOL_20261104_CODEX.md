# v7 PushT 热启动 CEM：单根真实 RGB 开发对照

使用已经暴露的 v7 PushT episode 0、相同原冻结 checkpoint、公开动作统计、目标、共同初始 15 步暖身、官方后端、RGB guard 和关闭 TF32 的相同数值设置；另运行一条独立的 smooth CEM 臂，不覆盖 v7。固定终点三轮分别规划剩余 15/10/5 步，每轮执行 5 步。CEM 每轮使用自己的真实 RGB 和历史，后两轮使用本臂自身 carry，不读取 v7 计划或真实后果。各轮预算均为 1920 prediction-token；在后两轮共同评分 zero 与 carry，分别以两者为基底平分剩余预算并保留最优完整链。首轮沿用现有零起点 CEM。记录动作、预测、每轮分数、预算、事件与结果；guard 拒绝或终止原样记录。

基于已封存 v7 执行记录，事前规定对比两个臂的初始 RGB、动作历史和目标，及各自物体位置误差、角误差、官方成功与模型分数；不同反馈状态的模型评分不可直接比较。使用同一后端对全部执行动作、物理状态和帧逐步重放，并用同一 checkpoint 显式展开重算每批预测、选择和计数；额外记录 v7 与 CEM 的起始上下文绑定。失败分支保留，不伪装完成或续接已派发实验。

这是一根已经暴露的开发比较，并非充分调参的强基线、独立确认或 PC3/PC4 通过；prediction-token 相等不表示总成本相同，训练与 normalizer 来源的未知不因本次重放而消失。封存依赖、协议、原 v7 manifest 与审计；所有新产物排他写入。
