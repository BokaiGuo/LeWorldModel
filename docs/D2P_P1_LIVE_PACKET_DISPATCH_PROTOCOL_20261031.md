# P1 在线第二包真实派发：已知根开发合同

对固定的 24 个已知根/条件/前缀槽，使用与先前分段反馈相同的
第一包。执行五步后读取现场 RGB，使用相同四起点、每起点 10 次
Adam、相同冻结模型和目标现场规划第二包。执行器第五步之前不
读取或保存任何封存第二包；第六至十步只派发现场产生的字节，
无需与离线动作相等。离线结果仅可在运行后用于诊断对照，不可用于
选择或派发。真实物理状态仅用于来源检查、成功和报告。

保留提前成功/越界删失，不补值；规划失败停止后续动作。保存现场
动作字节、分数、调用、观测哈希、CUDA 设备、模型参数/buffer
哈希和完整物理事件。历史选择得到的前缀与第一包不重新计费：
本实验是已知根在线接线和物理开发验证，不是独立确认、完整
端到端预算、强基线性能或 P1 准入；模型不训练。
