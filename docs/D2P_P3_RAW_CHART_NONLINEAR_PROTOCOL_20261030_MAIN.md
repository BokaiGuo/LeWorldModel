# P3 raw 图表修正：固定失败面板的非线性重放

本开发实验在观察旧失败与保存态线性分析后制定，并非独立确认。
固定原 decision journal SHA-256 为
`ff67c50f2f76b2d0bc3efcc774e60e42c8a55c564f6beaa4e9d706aa74e61da2`，
固定四个决策 index 49891、118022、172473、245163。每个决策的
H1/H3 均包含 zero 和全部八个候选，共 72 行；不按结果删选。

对每一行，在同一保存的 postcontext、目标及 normalizer 下，先用
冻结模型在主机 CUDA 重放旧实际 raw 后缀。旧终点 latent 与保存
轨迹、旧目标代价必须与保存值一致，否则整体拒绝结果。再用保存
Jacobian、目标及 nominal，通过 raw 图表有界 ridge 求解新动作，
从同一 postcontext 做非线性模型 rollout。保存两者的动作、模型
末 latent、目标代价、求解信息及调用计数，并核对模型与输入文件
前后哈希；不更新模型，也不使用 CPU 神经推理。

仅描述逐行新旧 rollout 差异及对应面板中的排序；不更改旧 gate、
不按新旧胜负挑选物理候选。根与策略重复，72 行不是独立样本。
这是模型内探索，不认证原训练 normalizer 来源、独立 ABI、真实
物理表现或等预算，也不能宣称 P1/P3 通过；后续生产应用需要
另行固定合同、记入求解及模型调用开销，并独立物理验证。
