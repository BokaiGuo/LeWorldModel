# 发现过程归因：固定机会与全额计费开发比较

使用上一同链面板的 16 个已暴露 E0 任务与原 seed `2032500000+root`；不是新确认任务，不重判旧机制面板。科学问题：共享全局起点和精修相同条件下，谱方向候选及可达价值保留是否增加有效发现；全部生成与优化按固定 token 上限计费后是否有净收益。

预定四臂、一次规划/根、2880 prediction-token 上限：`spectral` 为先前 ridge 候选和保留规则；`random_direction` 将各选定谱方向换为独立随机方向，模式数量、名义点、幅度、候选数、保留、谱计算和其余调用不变；`diverse` 只将可达价值保留换为状态多样性，仍计算相同可达探针；`global_cem` 使用相同全球动作库、评分和同一多起点 CEM，省出的响应预算交给该基线。各臂用同一全局库、动作界、任务评分、随机种子及最终弃权规则。随机方向按每片段无穷范数匹配裁剪前幅度；裁剪后的幅度和动作分布可能不同，须报告这不是严格分布匹配。随机臂仍使用响应矩阵确定模态数并计算后继岭值，不能称为“完全无响应”。`diverse` 仍支付后继探针，不可用来估计删除响应计算的成本。

固定机会诊断在全部端到端计划封存后执行：前两起点为共同全局库中分数最好的两个不同动作，另外两个起点对三条递归臂取其最终保留束，对 global_cem 取全局库接下来的两个不同动作。四起点统一 628 次完整链评分、同一 CEM 及随机种子；前两起点身份、评分及随机流逐根跨臂相同。固定机会中的递归候选选取仍有不同生成成本和信息，须单列生成与诊断资源，不与全额计费结果混合；仅证明有限机会下的表现，不能判不可行。所有起点和后续样本计费，保留已评分 incumbent。若候选不足或失败则记录失败，不补选特权链。

报告各臂任务成功数（终距 `<0.05`）、连续终距、成对差、全额实际预测 token、精修样本、wall time；固定机会还报告四个起点身份、精修前后分数、获胜来源及共享起点逐步优化是否相同。16 根为配对单位，不视为独立来源或有功效的 PC3；不能以一条正向样本下结论。记录实际动作、预测、失败、哈希并做同环境替代几何与确定性重放审计。

该协议固定特征而不是事后筛选结果；不更改已停止面板、已选链和旧机制结论。若完整总成本和真实视觉数据尚缺，不宣称 PC2、PC3 或谱独立增量通过。
