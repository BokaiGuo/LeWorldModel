# TwoRoom 终止即停反馈：纯视觉决策接口复核

上一补充实验虽然实际 80 次均未触发初态成功判断，却用 reset 返回的
物理距离判定是否立即停机；这条依赖不属于 RGB-only 决策权限，不能
把它作为纯视觉执行合同认证。本次不覆写旧工件。

对同一已曝光面板重新执行相同前缀和两个尾部。规划决策函数只接收
现场 RGB、目标 RGB、合法候选动作及冻结模型接口，不接收环境、物理
状态或成功标签。环境执行端使用标准 Gym terminated/truncated 信号
停机；reset 信息不参与决策。该协议不在 t=0 推断物理成功；实际行动后
按环境返回值记录成功。因旧面板初态成功均为零，本次只对这批任务
比较选择、现场图像、每一步动作及状态轨迹；其他初态需要单独定义
有权限的目标判定，不能从这里推断。

旧运行、输入、模型和 normalizer 哈希必须一致。额外计两次链评分、
六个模型 packet；初始规划成本未测。本实验验证权限路径和现场轨迹，
不构成新方法、独立样本、等总成本收益或 gate 通过证据。
