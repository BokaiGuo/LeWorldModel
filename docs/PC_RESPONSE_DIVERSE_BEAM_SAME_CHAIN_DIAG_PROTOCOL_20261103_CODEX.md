# 多方向版本最终链：事后同链机制诊断

在多方向版本 24 个已暴露根的结果和停止决定后制定，仅诊断已封存的最终
`response_diverse` 链，不选择新链或重开规划。对每根固定五类五步前缀：
最终链 selected、全零、该方法首次五候选中的即时 greedy、先前封存
480-token floor-CEM 控制臂 `random_bridge` 和 `lookahead` 各自最终链的
前五步。后两者来自同一个精确动力学任务但不是新方法同一次搜索所得；
其后验使用必须单列，不能称为事前同版本对照。

每个前缀后执行同一六个十步后缀：零、恒定 `(.5,0)`、`(-.5,0)`、
`(.5,.5)`、`(.5,-.5)`、以及新方法最终链的后十步。以原精确动力学记录
绝对末距及相对各自零后缀的变化。再对五个前缀各自以原 floor-CEM
（下限 0.05）、同根相同种子 `2026121800 + root`、120 完整链评分
独立重规划，记录每条动作和评分。

沿用旧开发筛查的非即时条件：selected 五步终距不小于起始终距减 `1e-10`。
对每个控制分别统计 selected 最终链后缀的相对变化是否更优、各自重规划
的绝对终距是否更优；同时报告 selected 超过 zero 和 greedy 的两项条件
及与非即时条件的同链交集，并另外报告同时超过全部四类控制的交集。
严格优势须大于 `1e-10`，不通过改变阈值规避平局。

所有响应、重规划与最终结果逐条重算，来源、上下文及动作绑定哈希。
有限后缀族和后验对照只是开发归因，不宣告 PC2；不扩大根、预算或种子，
不把历史控制结果拼装成独立正式方法或 PC3。
