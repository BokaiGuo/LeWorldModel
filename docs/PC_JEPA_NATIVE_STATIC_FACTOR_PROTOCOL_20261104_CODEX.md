# JEPA 原生 PushT 静态目标因子：后验诊断协议

本协议在读取已有轨迹后制定，仅用于诊断目标视觉编码，不是事前确认实验，也不修改规划器。固定使用已暴露 seed 2026102701 的 response、CEM 两臂在物理帧 10、15、20、25 的全部边界；两臂帧 10 重复，不视为独立样本。

每一边界固定四种图像：原始位置、仅 agent 换成目标位置、仅物体换成目标位置与角度、两者均换成目标。目标位置从评价专用目标状态读取，只用于此离线特权诊断。使用闭环相同的原生渲染器、配置及固定背景；通过直接设置图形位置并重建空间索引来避免 reset 隐含的物理步。使用保存的完整公共状态中的双精度位置与角度重建基图。逐像素比较每个基图与原有 RGB，任一不一致停止模型阶段并保留失败记录；同时独立重建目标图并逐像素核对。反事实可能产生交叠或不可达状态，不执行物理模拟。

在独立 GPU 进程以原冻结 JEPA encoder 和相同图像变换编码所有图像，记录特征数组、MSE、哈希与依赖；使用同一批形状逐一编码，报告 agent、object 主效应及二者交互，不挑选有利边界。独立 CPU 审计图像绑定和分数算术。严格使用原模型 UUID 与共享锁；模型加载或哈希不一致则停止。

此设计只检验特定已暴露轨迹上的静态图像敏感性，不能解释全部动态失败、证明目标可解、证明因果物理控制或确定跨根泛化；原模型训练及 normalizer 来源仍未知。不得以此更新 PC0–PC5 通过状态。
