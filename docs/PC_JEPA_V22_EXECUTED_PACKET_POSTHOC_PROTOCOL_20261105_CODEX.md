# v22 已执行 packet 的后验预测诊断

固定对象：已暴露 v22 单根、response 和 CEM 两臂各三轮全部六个已派发五步 packet。只读取原已封存决策、合法上下文和真实后继；不重新规划、不派发动作、不重开旧实验。目标由评估见证构造，物理真值和后继图像仅用于本后验诊断。

复用既有 v7 packet 诊断的冻结 JEPA、历史保持 rollout 和指标，切换数据源前验证原 saved-data audit、chronology audit、物理重放、六份相同模型元数据，以及每个实际命令与封存决策的动作和哈希。记录所有输入及诊断依赖的哈希，运行后再次核对。保留六例和完整 patch 数组。

报告每例预测对真实后继的 latent MSE、持久基线 MSE、预测与真实目标评分变化、物体位置/角度及 agent 物理误差变化；同时重算选中完整链终态评分。编码批形状可能导致微小差异，完整链评分差异不直接归因于错误。各项分别衡量模型预测与视觉目标评分，不能仅凭相关性确定错误原因。根和轨迹之间非独立，预测目标不是物理成功指标。

若运行失败保留失败记录；不修改旧结果。此事后诊断并不检验未执行动作、反事实排序、PC2 机制或规划优势，也不证明 RGB-only（输入包括本体信息）或独立泛化；PC0–PC5 不改判。
