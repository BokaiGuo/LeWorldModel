# 固定前缀可解性与尾部优化缺口：诊断协议

运行前冻结。本实验是 24 个已暴露 wall 任务的特权诊断，不是部署方法，
不重新运行已封存描述策略，不修改其停止判断。

逐任务读取上一轮固定的八条候选前缀和名义尾部；对每个前缀沿用相同
种子和优化器，从 36 次评分扩展到 384 次，须逐动作和逐成本重现前
36 次。另取该任务首个 15 步内的几何可行见证，核验合法边界、全部
阻挡事件、终点成功；固定见证首五步，以全零尾部为合法起点，使用独立
随机流及同一优化器执行 384 次评分。见证尾部只用于合法性及可解性
审计，绝不用于初始化优化或候选选择。

同时记录：每根原候选的 36 和 384 次最好终距、成功数、各自前缀实际
位置；可行见证初段、见证尾部与新优化的结果；所有动作与成本。比较
任务级成功覆盖，不把每个前缀当独立任务。

解释规则：原池 384 次仍失败、见证前缀优化成功，支持在该优化预算内
原池前缀覆盖不足；见证链确实成功但其前缀的零起点 CEM 仍失败，
说明候选尾部优化也未能恢复该已知可行链。都只能作为有限预算诊断，
不能证明不可达、不能归因所有失败，更不能冒充规划器性能。
