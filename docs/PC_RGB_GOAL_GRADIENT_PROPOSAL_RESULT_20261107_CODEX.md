# RGB 目标梯度候选：开发结果

按[协议](PC_RGB_GOAL_GRADIENT_PROPOSAL_PROTOCOL_20261107_CODEX.md)，
对先前四个已曝光 TwoRoom 任务的共同名义链，比较普通目标梯度、最大
表示奇异方向和固定随机方向。三臂各以相同冻结模型评分五条候选并选
最低分，然后评价端执行梯度臂的五条链；谱与随机使用已封存物理记录。

| episode | 初态已成功 | 梯度选中成功／池内成功 | 梯度末距 | 谱末距 | 随机末距 |
| --- | --- | --- | ---: | ---: | ---: |
| 9000 | 是 | 是／5 | 8.32 | 13.32 | 9.25 |
| 9013 | 否 | 否／0 | 88.27 | 84.93 | 86.20 |
| 9022 | 否 | 否／0 | 57.46 | 69.46 | 61.10 |
| 9032 | 否 | 否／0 | 80.41 | 80.41 | 77.95 |

池内数字是五条链中的成功数量，不是独立任务数。排除初态成功的任务，
梯度臂为 **0/3**，其候选池也未发现成功链。梯度臂选中模型分数在四
任务中三次同时低于两条对照、一次与谱相同且高于随机；物理末距并不按
该排序稳定变化。该具体构造未建立真实成功
增量，不应直接扩展为确认实验。

四个方向导数均通过预定中心差分判据，最大绝对差约 **0.0462**。
同步计时的梯度前向和反向约 0.025–0.276 秒（首例含冷启动），不包含
两个额外数值核验前向和候选评分；旧谱方案另需 50 次 JVP 和 SVD，
随机臂不需反向。候选数相同不等于完整计算成本相同。

独立存档审计重建了四任务的候选、选择、物理成功标签、差分判据及与
谱臂共同父链的物理轨迹；候选生成定向测试 **5 项通过**。该审计未独立
重跑模型。运行前后冻结模型指纹一致。

**权限限制：**虽然真实后果没有用于候选计算或选择，当前开发运行器为
核对来源而在模型选链前读取了旧物理记录的计划哈希；该文件还包含真实
评价标签。因此本运行的进程级数据隔离不满足正式 Planner/Evaluation
分离要求，不能作为正式 RGB-only 权限认证。后续正式实现须先生成不含
标签的输入清单，并把真实性检查放在隔离的评价端。此限制不应被描述为
“标签参与选链”，也不能当作已经通过权限测试。
