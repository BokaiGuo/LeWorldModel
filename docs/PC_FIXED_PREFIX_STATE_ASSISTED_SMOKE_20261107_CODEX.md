# 共享固定前缀搜索：PointMaze state-assisted 冒烟

新增与模型输入无关的固定前缀搜索核，并通过四种保留规则的单元测试
对齐上一版 RGB 编译器的选择；另加入使用当前及目标 RGB 与完整 proprio
的 JEPA 适配器。后者只接受已审核的 `official_state_assisted` 边界，
目标 proprio 编码单独留存输入收据，不得晋级为 RGB-only 证据。

使用本地 PointMaze JEPA checkpoint、官方配置的 L2 加权目标及已有
目标状态数据，在 GPU 上完成 1 个已曝光任务的工程冒烟：3 条父链、
6 条前缀—探针组合、2 条保留前缀—尾部组合，共 11 次候选评分及
1 次目标编码；最终选择了尾部组合。冻结模型权重前后哈希一致。
该演示没有执行环境、基线对照或机制干预，不能解释为规划成功。

搜索逻辑和权限测试共 5 项通过。测试中发现，后果向量距离接近零时，
评分从 float32 转为 float64 可能改变多样性选择；共享核保留评分器
返回的精度以对齐已有实现，但没有证明该规则对近并列扰动稳定。
这是现有向量保留配置的实现敏感性，不能据此改判过去结果。

逐调用输入收据、动作和来源哈希见
`le-wm-main/results/pc_fixed_prefix_state_smoke_20261107_codex.json`。
本地 JEPA 兼容路径尚未认证与官方完整 rollout 等价；PC0–PC5 不变。
