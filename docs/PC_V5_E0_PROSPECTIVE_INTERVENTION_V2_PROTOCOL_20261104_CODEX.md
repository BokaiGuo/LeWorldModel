# V5 新网格干预 v2：仅修复诊断索引比较

首版干预在第 0 根、任何干预产物写出之前停止：复用的局部响应记录包含 `candidate_index`，把固定随机桥插入库后 selected 的索引由 9 变为 10。已单独复算第 0 根，移除该索引字段后其余 selected 响应记录完全一致。原计划、原首版干预 manifest 与失败事实保留，不覆盖。

本版只在单进程局部诊断适配器中把两次 selected 响应记录的 `candidate_index` 规范化为 `-1`，以便比对物理和数值内容；不改变任何 selected 动作、任务、随机种子、控制条件、预算、响应或事前阈值。其它候选索引保留。调用原首版已封存算法，新输出与依赖另行封存，并以同一方式独立重算。新适配器在规划完成后才创建，故尽管条件和阈值事先规定，不能声称其代码在规划前冻结或把本次作为严格预注册确认；整体仍为开发性机制实验。
