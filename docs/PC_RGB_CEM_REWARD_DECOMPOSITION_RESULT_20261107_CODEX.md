# RGB CEM 选择：环境奖励语义及物理分量

对上一轮四对链的末帧快照进行事后分解。核对当前本地 PushT 环境源码：状态为推杆位置、物块位置、物块角度和推杆速度；奖励是该七维状态与目标七维状态的欧氏距离的负数。成功条件使用推杆和物块的**联合位置距离**以及包裹角度差，奖励本身则使用原始状态向量角度差。这是本地实现的具体语义，不应概括成仅物块距离或严格物块位姿成功。

| 根 | 推杆位置误差：旧／最低分 | 物块位置误差：旧／最低分 | 推杆速度误差：旧／最低分 | 物块姿态诊断代价：旧／最低分 |
| --- | ---: | ---: | ---: | ---: |
| 0 | 275.95 / 258.50 | 21.19 / 30.52 | 23.91 / 174.98 | 1.723 / 3.243 |
| 1 | 356.97 / 390.75 | 20.00 / 20.00 | 85.76 / 269.65 | 1.562 / 1.562 |
| 8 | 325.79 / 276.60 | 20.00 / 21.14 | 55.86 / 97.80 | 1.562 / 1.723 |
| 9 | 351.93 / 347.83 | 20.00 / 20.00 | 35.19 / 54.56 | 1.562 / 1.562 |

物块姿态诊断代价是原接触面板定义的归一化位置／包裹角度平方和，**不是**环境奖励或成功规则。根 0 的最低分链物块姿态更差；根 1 两链物块姿态相同，奖励反向主要伴随推杆位置和速度变差。根 8 的最低分链奖励更高，但物块姿态诊断更差；根 9 物块姿态相同。因而之前的“编码分数与奖励反向”仍成立，但不能将两根都解释为物块位姿评分反向。

从每个封存末帧快照独立重建环境状态，8/8 条链的奖励与终止标志均与原执行记录精确一致；源码及原始输入哈希绑定在结果文件。合成测试覆盖速度计入奖励及角度奖励／成功规则的区别，相关测试 3 项通过。隐藏状态仅用于评价，不输入 RGB 规划器。样本为事后选出的 4 根开发任务，不构成闭环收益或 gate 通过。
