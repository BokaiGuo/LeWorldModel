# PointMaze state-assisted 已选链：物理重放

对已封存的 root 1884、camera 0 选中链，从相同的完整初始状态在本地
legacy MuJoCo 后端执行 25 个动作；同时从同一初态执行 25 步零动作。
每个环境步包含 5 个、各 0.01 秒的物理步，重放记录了全部 26 个状态
及时间。动作来自此前封存的模型选择；真实状态和成功标签不反向用于
选链。模型输入包含当前和目标的完整 proprio，因此属于 state-assisted。

| 链 | 初始位置距离 | 25 步内最小距离 | 末步距离 | 首次进入 0.5 半径 |
| --- | ---: | ---: | ---: | ---: |
| 选中链 | 0.6154 | 0.0830 | 0.5336 | 第 3 步 |
| 零动作 | 0.6154 | 0.1979 | 0.5659 | 第 3 步 |

两条链都在第 3 步进入成功半径，早于固定前缀结束；因此本次不能用作
尾部利用或重配置机制证据。两条链末步均位于半径外；若任务采用停止
在首次成功，不能把继续执行到第 25 步解释为实际部署过程。

零动作前 5 步与此前同初态、同 legacy 后端的保存轨迹最大状态差为 0；
逐步时钟和阈值已复算。这不是独立物理引擎认证，也不是官方完整
rollout 等价认证。零动作不与 11 次模型候选评分的规划器构成公平
计算对照；此单根结果不证明方法收益或 RGB-only 闭环。

原始轨迹与审计分别见
`le-wm-main/results/pc_fixed_prefix_state_physical_20261107_codex.json` 和
`le-wm-main/results/pc_fixed_prefix_state_physical_audit_20261107_codex.json`。
PC0–PC5 状态不变。
