# CEM16 方差实验的候选和 GPU 分数复核

重放已封存 40 任务的两臂反馈轨迹。每次决策按原种子、记录分布与相同截断重建 15 个采样链，再加由前次派发计划还原的旧尾链；从重放历史后的 RGB 逐批以原始批量大小 1、5、5、5 重新计算时序最小目标代价。比较已记录的 15 个采样分数、被选链分数、最小分数索引，以及实际派发动作和物理距离。因此前未保存单独的旧尾分数，只能验证其本次重算值与已保存的选中分数（如选中旧尾）及完整重算选择，不能声称旧尾历史分数逐项吻合。

严格检查输入、原结果、原运行器、模型和 normalizer 指纹；对浮点分数采用 1e-3 绝对容差并记录最大差异，对动作和轨迹使用 1e-6、1e-5。只记录差异，不因发现不一致而覆盖原结果。环境真值只用于重置、重放与核验，不输入规划器。GPU、编码器、模拟器与原实验相同；复算不是独立实现或跨平台认证，也不产生新的性能或 gate 证据。
