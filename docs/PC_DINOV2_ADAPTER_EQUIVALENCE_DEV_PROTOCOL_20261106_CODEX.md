# DINOv2 离线适配器的同权重局部数值核查

使用本机 HuggingFace 缓存的 ViT-S/14 权重，将权重逐项转换到
本地保存的 DINOv2 源码模型，严格检查官方模型 `state_dict` 键、
维度全部覆盖，并额外检查转换映射覆盖全部 HF 张量。两个模型
eval、同一 GPU、同一数据图像输入，分别比较 CLS 与 patch token，
覆盖 224×224、518×518 的同一数据帧缩放。记录最大绝对误差、
均方误差、相对向量误差和哈希；不混入各自预处理差异。

此核查使用同一份 HF 权重转置映射，**不证明它与原始官方权重文件
字节一致**；本地所谓官方源码的文件夹名也不证明其权威提交。
结果仅说明此权重和有限图像上两种实现的数值差异，不能证明 JEPA
世界模型 rollout、动作历史、预处理或整个评测等价。
