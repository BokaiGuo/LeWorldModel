# PushT 随机可达目标：非特权候选评分开发合同

## 问题与范围

预定动作生成可复现的物理可达目标，检查冻结模型对不包含目标参考动作的固定随机候选库的排序。目标生成不依赖模型评分或事后物理状态筛选；物理轨迹及参考动作只供评价，不传入预测器。目标 RGB 属于合法目标输入。该目标分布与独立 reset 目标不同，本实验是开发诊断，不是原任务分布性能、预算内 oracle、正式规划或独立确认。

## 固定配置

- 四个 root seed 为 `2026110601` 至 `2026110604`；与之前的四根不同，但开发外、normalizer 拟合外、checkpoint 训练外均为 unknown。
- 采用原四根诊断的十步固定 warmup 和三帧历史、物理后端、动作域、模型、normalizer 和 15 步／5 步 packet。
- 随机生成器 `2026110610` 生成 65 条三个 packet 各自常值、每坐标均匀 `[-1,1]` 的完整链；前 64 条是候选，第 65 条只用于参考目标。拒绝重复完整动作；不使用物理或评分筛选目标和候选。
- 每条从同一 reset 与 warmup 独立执行，核验相同历史；第 65 条最终 RGB 与状态分别是目标图和仅供评估的目标状态。参考动作不放入模型查询或正式规划输入。预测器对前 64 条一次性固定预测，再读取真实末帧进行编码。
- 记录预测评分最佳、真实编码评分最佳、64 条成功数、两种评分的成功排名、逐根实际距离及预测误差；成功条件使用 agent/物体联合位置 `<20` 与周期角度 `<π/9`。所有失败计入分母；报告参考动作通过回放的事实与真实状态变化，避免把静止目标当作接触任务。
- 每根 64 条均直接送入模型；不得声称对未查询动作预测。目标可能与其他候选末态相近或相同，构成可达性见证不等于需要接触、也不保证候选库中存在成功动作。若库内无成功则成功排序为不可识别；不得事后筛除该根。

## 记录与验收

物理运行及神经预测分别保存逐项输入、物理状态、图像、结果与哈希，检查预测在读取标签前完成；异常保留并报告。参考链的离线执行是评估见证，不进入 planner 或计入规划成绩。检查对应依赖的封存绑定与神经 worker 回执；若无法运行或审计，不声称实验完成。

比较是每根的候选排序与标签，不能将候选动作或动作对当作独立任务。仅当真实评分与预测评分在物理上意义明确的不同候选中分别表现良好，才支持进一步开展正式评分研究；不能从本实验推断 PC0–PC5 通过。
