# 可达价值保留与共同后缀机会的事后交叉分析

使用已审计的 v25 beam resource curve 1920-token narrow 记录，以及同一面板的 response/random fixed opportunity 已审计结果。只用 response 库，每根核对源首层候选动作与固定机会库逐项完全相同，并核对各结果来源与审计；源层保留规则、探针值和固定 49 样本后缀得分均不可更改。失败根保留分母。

问题：在同一候选库和已产生的单一共同求解机会下，响应保留相对状态多样性或 greedy 是否保留了更低终距的候选；探针值对已探测候选的后缀得分排序是否有一致性。逐根记录被新增/替换的索引、其后缀得分、各策略最优得分以及探针对的同向、反向和并列数。较低为更好；允许并列。也记录基线 lookahead 和随机保留，但不将它们称作成本匹配端到端方法。

此为利用已观察任务及结果的事后诊断，不对因果性、已剪枝候选可行性、统计确认或 PC2/PC3 作结论。每候选仅有 49 次后缀评分，已知可行前缀在此机会下可全部漏检；动作采样及裁剪并未充分匹配，响应的生成和探针开销未在该诊断中扣除。排序不支持将响应值称为真实可达性判定器。
