# 目标图推杆颜色遮盖：开发结果

按 `PC_RGB_GOAL_COLOR_MASK_DEV_PROTOCOL_20261107_CODEX.md`，仅使用目标 RGB 的固定蓝色阈值生成遮盖，复用此前 16 根、左右两侧、三个动作的封存候选。评分完成后才加载评价端物理代价；真实后继编码评分仍只是评价端诊断。所有任务均已暴露，不是独立确认。

| 评分后继 | 32 条条件中选择变化 | 原图平均物理遗憾 | 遮盖目标平均物理遗憾 | 根级改善／变差／不变 |
| --- | ---: | ---: | ---: | ---: |
| 模型预测 | 3 | 0.242684 | 0.188145 | 2／1／13 |
| 真实后继编码 | 2 | 0.220419 | 0.188145 | 1／1／14 |

16 根各两侧并非 32 个独立任务。物理遗憾相对同条件三动作中的最低物块姿态代价，不是实际任务成功率。该固定阈值在所有目标图均遮盖 128 像素，包围框为 `(28,28)–(41,41)`；它不能保证覆盖完整抗锯齿边缘，也不保证在其他外观、遮挡或位置条件下只遮盖推杆。编码遮盖后的图像也可能超出 checkpoint 训练分布。

原图各候选分数与此前封存的目标反事实实验完全一致（最大差异 0），所有原图动作选择一致。遮盖函数的无符号差值、输入不可变和检测失败行为及已有权限测试共 20 项通过。这些检查不证明分割语义或真实闭环性能。

**决策：当前颜色遮盖仅产生少量选择变化，根级改善不稳定，按开发协议停止扩大此规则。** 它没有提供足够依据将其接入 Planning Compiler，也不能否定其他合法 RGB 目标表示。PC0–PC5 不改判。
