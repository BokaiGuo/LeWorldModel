解释为独立成功率。此表仅使用各候选的 `predicted_midpoint_goal_mse`
评分，**不使用**真实中点 `actual_midpoint_goal_mse` 或刷新评分

这些候选是在相同十步目标下优化出来的，五步选择不是从零运行
