2,345 个环境动作均合法。两个新增 seed 的任务总完整链评分：

仅同单次规划评分预算，不等于完整成本严格相等。求解器墙钟亦
含实现及记录开销。

的复现，不是未调优 CEM 上的正式优效，不证明响应描述贡献。
