# 原生 CEM 评分链选择：开发性配对协议

2026-11-05，运行前记录。目标是检查原生评测路径的适配器和
“已评分最优链”选择，不是响应方法或独立确认。

沿用本地 PushT 原生评价、checkpoint、seed 42、50 抽样行、
300 样本×10 轮、30 elite；各臂使用相同配置及资源，仅替换
solver 类并切换 `return_best`：

1. 关闭：保留原生 CEM 最后一轮分布均值；
2. 开启：从本次求解所有已评分候选中选择代价最小链。

每次反馈后独立重置 incumbent，不复用旧评分。开启臂不对最后均值
额外评分；因此不能说它在“包括均值”的完整候选集合中最优。候选
评分次数相同，但选择开销和实际反馈路径可不同；墙钟必须如实记录，
不能把模型调用等量当作完整成本等量。

验收先检查关闭臂与同配置历史原生输出一致，再报告两个实际闭环
结果的逐任务差异。历史任务与方法已暴露，不能做确认性结论。
执行失败保留错误，不以其作为理论否定；不改变既有文件或旧 gate。
