# TwoRoom RGB 闭环剩余时域评分开发协议

此前共享核心闭环在每个重规划时都以完整 25 步预测末帧评分，但任务总上限为 25 环境步，因此在第 5、10、15、20 步观察后的评分时间分别超出任务截止 5、10、15、20 步。重规划时使用固定长远时域可以是有意的 MPC 设计，本实验只检验其对该固定截止任务的影响，不预设为代码 bug。

在同一批已曝光 root 10–49 上，对父链、普通 lookahead、向量和打乱四臂，保留前一实验的候选生成、种子、13 条评分、旧尾补零、最终选择、每 5 步重观测和成功／截断规则。唯一改变是按 `remaining = 25 - 已执行环境步`，只将候选前 `remaining / 5` 个动作包送入模型评分。所有臂一致使用剩余时域；模型步骤计算量和数值成本另行报告。记录输入收据、完整评分、动作及逐步结果，并与旧固定 25 步目标进行同任务事后配对比较。

此改动改变优化目标，不追溯更改旧研究结果，也不是用评价端物理状态选动作。结果仅用于已曝光任务上的开发决策，不能直接提升 PC gate 或宣称 RGB 模型、响应描述已有优势。
