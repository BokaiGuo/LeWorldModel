# 固定 cp5 八候选物理干预

使用根 0 混合反馈实验 structured 第 5 步节点封存的八个候选，
以已执行 DLS 首五步为共同前缀。赢家使用实际接受的 refinement；
其他候选使用各自优化后的动作。每个候选执行第一、二个五步包，
另分别执行第一包加五步零动作、十步零动作，共 24 分支。固定
顺序并保留所有停止、越界及未观测数据，不按结果筛选。

模型对候选评分使用三个五步包，而本实验只执行前两包；同时
赢家额外优化，其他候选没有。因此物理指标不等同于评分目标，
不可直接判断评分正确与否。该事后固定诊断没有神经推理，不构成
独立确认、预算公平或 P1 通过，不将物理结果反哺规划器。
