# PushT 显式前缀：已评分候选保留开发协议

固定已曝光 seed 85 的 50 任务、solver seed 42、RGB 冻结模型、动作
边界、30 条初始链、两固定前缀、3×100 尾部样本、2 个最终均值及
每次规划 632 条链评分。与历史显式前缀 lookahead 唯一区别是最终
选择：V2 从全部已评分的 632 条链中取模型代价最低者，原版只从
两个最终均值中选。分布更新、随机流、时钟和任务成功判据不变；
最终样本已经评分，不增加模型查询。初始 30 条中的完整链也进入
选择，因此其前缀未必是两条被保留前缀；必须记录来源，不能把它
误称为固定前缀优化产物。

单元测试须核对逐轮候选与原版、评分次数及选中链的真实评分；
两版在闭环选择分歧后观测不同，后续候选不再声称配对相同。
报告 50 任务配对成功、总规划次数和链评分，并与同面板调优
CEM 105×6/300×10 同时列示。初始状态、动作边界、source 和随机种子
需核验。模型分数改善并不保证物理收益；该开发比较不证明 descriptor
增量、严格机制、独立任务或 gate 通过。
