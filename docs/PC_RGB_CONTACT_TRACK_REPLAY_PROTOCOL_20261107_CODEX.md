# RGB-only 接触面板接口重放协议

复用 `pc_geometric_contact_equivalence_dev_20261106_codex` 的全部 16 根、两侧、两背景、三动作；不按结果筛选。该面板已暴露，接口重放不是独立确认。

分三进程：prepare 从旧记录仅提取当前 RGB、目标 RGB、五步原始动作及候选身份，封存为不含物理后继及标签的输入；score 使用冻结 PushT LeWM、原数据动作 normalizer 和 `primary_rgb` 权限封装对全部候选评分；audit 在 score 封存后读取旧模型记录，比较候选分数及每条件选中动作。各动作原始字节和初始／目标图像必须与旧记录一致。历史动作为空，保留旧实验使用的显式空历史占位；不声称已验证真实多帧历史或完整 MPC。

判定接口重放：全部 192 个候选完成，模型权重指纹相同，每个分数按绝对 `1e-4`、相对 `1e-5` 通过数值容差，每个条件三动作的最终选择相同。近并列也不豁免，若选择不同须报告而非自动判等。不能将其他模型、候选或物理真值转入 planner。三个阶段与文件隔离是数据流设计，不是操作系统沙箱。

本实验仅验证 RGB 权限入口与旧受控预测的等价性，不证明行动后果预测正确、描述超过 ordinary lookahead、真实闭环收益或任何 gate 通过。
