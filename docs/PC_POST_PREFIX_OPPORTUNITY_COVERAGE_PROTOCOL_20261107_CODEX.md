# 前缀后机会分数：固定池物理覆盖审计

沿用 119 个已曝光决策和三个预先生成的前缀；严格前缀后分数取共同 A 探针在前缀边界之后所有模型时刻的最低预测分数。该分数不读取 B 物理标签。每个方法保留两个前缀并评价该前缀下两条已有 B 尾链：对照原末帧机会、全时域最低机会、严格前缀后最低机会。三者共享候选和物理评价，不产生新模型查询或环境交互。

分两类报告固定 B 池存在曾成功链及前缀尚未成功而后续成功链，并按任务汇总是否至少有一个决策覆盖后者；明确共同历史条件来自已有臂，不是所提规则的真实闭环。再按全时域对严格前缀后分数逐根配对差异，报告完整分母。固定池和标签已经曝光，此项是事后诊断，不设追认的通过标准，也不能用物理标签部署选链。
