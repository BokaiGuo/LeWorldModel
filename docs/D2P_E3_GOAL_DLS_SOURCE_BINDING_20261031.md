# 目标 DLS 实验的初始化器来源绑定修正

已封存的目标 DLS 开发实验在整体 preparation 的来源表中包含
`e3_cp10_goal_dls_20261031.py` 的 SHA，但每个节点合同的
`arms.structured.initializer_sha256` 仍由继承的 extra32 代码设为
`p1_four_arm_extra32_budget_20261031.py` 的 SHA。实际 structured
初始化器已由 DLS wrapper 替换，因此这一字段没有标识实际方法。

这是来源合同字段错误，不等于动作、数值或真实轨迹错误；已封存
实验的实际候选可从 Jacobian 与目标复算。旧合同不能证明该字段
单独绑定了 DLS 源码，也不能以新合同覆盖旧证据。

本次只修正节点合同 structured 初始化器的 SHA，指向实际 DLS
wrapper；其余臂、动作生成、后缀优化、反馈和原生停止不变。
根 0 单独执行一次主机 CUDA / 物理重放并与前一 DLS 运行逐臂
比较，检查是否有动作和结果变化；属于工程重验，不是新的独立
实验或等预算科学结论。若重放不同，应保留结果并调查，不强行
视为等价。新合同必须进入账本摘要并接受已保存候选检查。
