# PushT 冻结第九层：新几何开发面板结果

**后续指标核验：**下表的物理遗憾是物块姿态诊断指标，不是本地环境奖励或成功率；后者也依赖推杆位置。192 个候选末态的原生成功数为 0，逐项比较见[原生指标审计](PC_PUSHT_NATIVE_SUCCESS_METRIC_AUDIT_POSTHOC_RESULT_20261107_CODEX.md)。

## 结论

上一面板上事后选出的 block 9，在事先固定的新几何面板中**没有复现相对正式视觉输出的平均遗憾优势**。这限制的是“block 9 的真实后继目标距离在此类几何面板上稳定更好”这一具体假设，不证明冻结模型不存在其他可利用信息，也不证明理论失败。

按[实验前固定的协议](PC_OSFAL_PUSHT_HELDOUT_GEOMETRY_PROTOCOL_20261107_CODEX.md)，使用新的 16 个位置—角度组合，每根两侧、两种背景、三个动作，冻结同一个 RGB LeWM checkpoint。16/16 根通过原有物理合同；独立进程重放 192 条轨迹，初末 RGB 和动作后快照均通过原审计中的一致性断言。白背景有 32/96 条轨迹记录到接触，零动作 0/32。背景是外观变化，不是相机变换。

| 事前固定的比较 | 平均物理遗憾 | 并列最优条件 |
| --- | ---: | ---: |
| block 9，真实后继编码 | 0.1453 | 45/64 |
| 正式视觉输出，真实后继编码 | 0.0879 | 46/64 |
| 冻结模型预测后继评分 | 0.1665 | 本表未统计 |

遗憾是所选动作的物块位置及角度组合代价相对本条件三个动作最小值之差；每根四条件平均后计算总体平均。按根比较 block 9 与正式真实编码：**3 根更好、3 根更差、10 根持平**。其中不同位置使用相同角度与相同目标相对变换，不能将几何根简单当作互相独立、同分布的正式任务。预测评分与真实编码评分差异仍是有价值的诊断，但该表不能单独确定预测误差或目标代价哪个是主要原因。

正式编码代价与先前模型阶段的保存值最大绝对差 `0.000124`，满足预定 `atol=0.001, rtol=1e-4`；权重指纹与旧面板相同。逐层脚本复用的控制台提示“previously exposed roots”指原脚本的通用文字，不描述本次实际根；本次具体位置与角度记录于协议和 JSON，且与旧面板不重复。
