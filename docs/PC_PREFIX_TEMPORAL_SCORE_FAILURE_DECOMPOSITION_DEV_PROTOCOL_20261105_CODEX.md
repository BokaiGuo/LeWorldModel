# 固定精修链的时序评分失败分解：开发诊断

复用已有 47 对有界候选、冻结模型和物理重放；不新增候选、不训练模型，
也不以真实状态或成功标签选取部署动作。对每条完整执行 25 环境步，
记录初态和每 5 步的物理状态、实际成功标志、原生图像管线编码代价、
首次成功时刻及既有模型终点评分。每条检查首次成功与历史物理重放
一致、动作无越界、目标图与参考脚本一致、参数指纹未变化。

主诊断是区分“25 步内曾成功”和第 25 步成功，以及各时刻真实编码
代价与成功事件的关系。时刻 0、5、10、15、20、25 不能解析未采样
时刻的图像评分；模型预测仍只有终点评分，本实验不能定位预测轨迹
误差、不能估计完整候选覆盖、不能作为规划器策略或 PC gate 证据。
这是已暴露、有选择的开发候选对，不是独立样本。
