# 已知根 structured 额外优化探索合同

使用既有 cp10 目标与根 0、1，分别独立进程执行四臂真实 RGB
反馈。唯一改动是 structured 获胜候选也获得 16 轮、每轮两次的
额外优化；native 和 random 原有额外优化不变，immediate-progress
不变。保留模型评分接受规则、反馈时刻、原生停止和执行保护。

结果按根与臂报告动作、成功、实际资源和删失；structured 的
Jacobian、筛选和新增计算全部计费。此方案是在观察旧结果后提出，
不是事前注册的独立确认，调用数量也不构成统一等预算。此实验不
替代新重选前缀的共同后缀干预、各前缀独立规划或 P1 机制门。
冻结世界模型，不训练额外模块；神经计算仅限主机 CUDA。
