# 条件化规划器实际选中链：首次计划干预开发协议

2026-11-05，在 seed 42 首轮比较之后、此干预运行前固定。对相同
固定 reset 的 50 任务，再次运行条件化规划器并记录首次真实选中均值
链与实际每步物理 trace。不得先按结果筛选链。先通过同任务同动作
的物理回放 parity，再在评估端进行如下 2×2 干预：

| 前 10 个环境动作 | 后 15 个环境动作 |
|---|---|
| 选中前缀 | 选中尾部 |
| 选中前缀 | 物理零动作 |
| 物理零动作 | 选中尾部 |
| 物理零动作 | 物理零动作 |

记录每条链所有动作域违规、每步状态、首次成功、开始／10 步／
25 步物块位置误差；只在全部 50 条选中链的已执行部分动作和物理
状态 parity 通过后才运行干预。公开 object position 仅在评估使用。
对 50 个任务逐一报告，不把 25 步成功当 50 步重规划成绩。
干预回放在首次成功后继续执行到第 25 步，以便记录同一固定时钟
的状态；成功指标为 25 步内曾成功，与末态成功分开。

探索性机制候选需同时满足：10 步物块位置误差改善不超过 1e-3
环境坐标单位、完整链在 25 步内成功、同一尾部搭配零前缀失败、
保留前缀但用零尾失败、四条执行命令均在声明动作域内。
该筛查只是开发环境里的有限干预，不证明必要性、发现贡献、因果
普适性或 PC2 通过，也不证明最终均值来自条件化组件。

补充基线归因：观察到条件化臂的初筛结果后，对已经记录并通过
物理 parity 的原生均值臂，按完全相同的 50 任务和四种干预规则
计算同一初筛指标；记录哪些任务仅条件化、仅基线或两者均满足。
这是结果暴露后的开发性对照，不能当预注册的独立确认。
