# P1 配对结果解释与公平比较合同

本文件固定后续分析的解释规则，不修改已封存的实验合同、准入门槛、
动作或历史结果。既有面板是开发数据，不能因本文件变成事前注册的
独立确认。

## 分开回答机制与规划能力

对同一根、条件、目标，分别执行 selected、zero、greedy 前缀：

1. 对各前缀执行同一固定后缀族，逐后缀报告绝对终态与相对各自
   零后缀的变化。它识别前缀对这些动作后果的影响；即使 selected
   更好，也不能单独证明其可规划能力更强。
2. 各前缀分别使用同一优化器、事前固定的相同资源约束独立规划
   后缀，比较真实执行结果。不得把某一前缀优化得到的后缀当成
   另一前缀的最佳可规划能力。
3. 性能比较中所有方法享有相同反馈时机；结构计算、候选筛选、
   优化与编码均计入各自完整账本。比较原生强基线时须保留其
   合法的搜索机会，不只比较共同优化器的几种初始化。

## 前缀即时变化和停止

初始状态、前缀结束状态和后缀终态分别报告物体位置误差、物体
角度误差、推杆位置误差、联合位置误差及原生成功。物体不动不能
证明整个任务没有进展；推杆重定位也不能事后排除在任务进展之外。
应在新确认实验开始前指定非贪心判定的指标、参考状态与容差，
不事后更换。联合位置误差不是完整的原生成功判据。

逐条记录停止原因、实际停止步和是否观察到原生成功；按原合同
保留固定时域端点的删失，不插补终点。实际已观察到的停止状态
可另列，但不能与固定时域未删失终点混排。拒绝和失败保留分母。

## 资源比较

事前定义每个资源轴的统一上限和测量口径，至少分别记编码、
世界模型预测、反向传播、结构计算、筛选、规划耗时和反馈次数；
标明批大小、设备与计量覆盖范围。不同类型调用不得未经事先
约定直接相加。基线可以使用 D2P 用于结构计算所占的预算；无需
通过空转或无用调用凑齐实际消耗。报告实际使用量和多个预先固定
预算水平下的收益，完整账本缺失时不宣称等预算优势。

身份绑定、停止与剩余资源缺口以该表及其引用产物为准。

[十步结果](D2P_P1_H10_INITIAL_RESULTS_MAIN_20261030.md) 仅来自
两个已知根，存在动作和任务重复；prepare 未绑定实际续跑入口。
独立 Adam 后缀有同样局部优化设置，但没有认证包含前缀结构计算、
筛选及反馈的公平总预算。因此现有证据尚不能认定 P1 通过或
公平强基线胜出。新根必须区分未用于方法开发与 checkpoint 训练外
两种来源认证；来源未知时明确标记，不按结果挑根。
