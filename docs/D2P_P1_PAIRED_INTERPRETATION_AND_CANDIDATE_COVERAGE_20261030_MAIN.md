# P1 配对判读与候选覆盖：2026-10-30

本记录固定分析边界，不修改正在运行的 H10 协议或历史结果。

## 配对表要求

按根、条件、前缀和后缀身份配对，分别呈现初始和前缀后的物体
位置误差、物体角度误差、推杆位置误差，以及包括推杆位置的原生
联合距离与原生成功状态。各指标分别给出前缀变化；物体不动不能
被解释为整个任务没有进展。原生成功按实际实现计算，并单列
停止时间和原因；在指定终点之前停止的轨迹，其固定时域终点为空，
最后观测另列，不补值。

共同后缀报告各前缀的绝对终态，以及相对于该前缀自身零后缀的
变化。只有根、目标、条件和后缀字节一致时，才作跨前缀比较；
没有匹配控制的后缀保留为空。此干预衡量给定动作的后果差异，
不等于前缀的可规划能力。

独立后缀规划结果应另列，明确每个前缀的优化器、初始化、真实
反馈、资源约束、实际编码/预测/反向调用、时间及停止状态。
现有独立 Adam 结果尚未认证完整总预算，不能标记为公平优势；
缺失的配对一律标记未测，不从共同后缀推断。正式性能比较须在
实验前固定统一资源约束，让基线可使用结构计算所占资源，报告
实际消耗和预算曲线；不同调用类型不能未经约定加总，也无需
浪费计算来凑齐调用数。

## 联合分析器准备

新增 `le-wm-main/experiments/spectral_reachability/p1_diverse_h10_adam_join_20261030_main.py`：
在 H10 完整保存态通过消费并产出配对表后，将三条新 selected
的独立 Adam 物理结果与既有 zero/greedy 独立 Adam 接入。它检查
根、任务、前缀动作、cp5 状态与像素、后缀哈希以及旧控制
准备文件身份，并保留共同后缀和独立规划两类数据。每种角色的
独立终点分别与自身零后缀和 zero 前缀的独立终点比较；若任一
端按既定合同被删失，差值为空，最后观测另列。

篡改根本身份所需的前缀、checkpoint、后缀或控制身份都会拒绝
联合；相关联合与共同后缀分析器共 7 项测试通过。测试包含已有
真实身份数据与构造的共同后缀表，不是完整物理结果验收。最终
联合表必须等当前 126 条实验结束、报告封存与独立消费后生成。
历史控制的实际续跑入口未绑定、总预算未认证的限制仍然保留。
