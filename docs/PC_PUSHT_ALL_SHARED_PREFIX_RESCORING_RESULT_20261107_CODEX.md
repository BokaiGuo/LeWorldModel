# PushT 共同前缀全池重评分：开发结果

## 设置

在已暴露的四个 PushT 开发任务上，复用首轮全部已评分候选及先前物理回放。每个任务筛选与原规划器选中链前两个动作包完全一致的所有不同动作链，并使用该链真实回放第 10 个环境步的 RGB 编码，在冻结 LeWM 下重新预测剩余三个动作包的末帧目标代价，选择代价最低链。

候选身份只取决于动作字节和共同前缀；选择完成并保存后才读取物理成功标签。评分输入来自此前对选中链的评估端重放；非实际在线执行。核验原物理记录哈希，复核每个候选的动作哈希、去重、共同前缀、原选择和 argmin。原预测模型权重前后指纹一致。

## 边界

该开发诊断使用事后确定的四任务及候选池，不是独立验证；真实第 10 步观测来自重放，而原闭环实际执行了更长前缀。结果不能证明短周期反馈的整体性能，也不能归因于行动后果描述。曾成功与第 25 步成功分开报告，任务 2 唯一曾成功链在末帧已失败。

该特定“保留全体共同前缀候选、以真实中途观测重评分并直接取末帧代价最小”的反事实选择没有修复这三个失败。任务 1、2 存在同前缀曾成功链但仍未选中，任务 3 不存在同前缀曾成功链；这仅约束当前候选池与评分规则，不排除其他合法反馈方法。没有新实验足以改判 PC0–PC5。

原始评分和冻结选择见 `le-wm-main/results/pc_pusht_all_shared_prefix_rescore_20261107_codex.json` 与同名 `.npz`；事后物理核验见同名前缀 `.evaluation.json`。验证测试：对应新评估测试及已有池捕获、编码对齐测试共 5 项通过。
