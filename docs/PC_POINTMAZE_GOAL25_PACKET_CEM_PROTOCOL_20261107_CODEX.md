# 第 25 帧目标：分段动作参数化 CEM 开发对照

前一开发 CEM 独立采样 25×2 个动作，而固定前缀库每 5 环境步保持动作不变。为隔离该参数化差异，在相同八根、目标、checkpoint、当前与目标完整 proprio、模型时钟及末帧评分下，增加 5×2 维 CEM；每个参数复制 5 步，动作裁剪至 `[-1,1]`。

固定每根随机种子 `7102500 + root`、初始均值 0、标准差 0.5、每轮 16、4 elite、第一个候选为当前均值。运行 10 轮并保留所有 160 条候选、分数及分布：48 预算选取前三轮已评分最佳，160 预算选取全部已评分最佳。两预算共享前 48 次评分，记录同步用时和 batch 数；160 不与 48 称等预算，也不能通过事后选预算宣称优势。

预测和选链封存后，从同一原始 float64 初态实际重放 48、160 选链及上一实验 25×2 CEM 选链；旧臂物理轨迹必须与先前记录一致。指标为最终物理位置距离与 `<0.5` 成功，保留初态已成功任务并分层；与上一报告的固定前缀臂、零动作和归档见证并列。CEM 每个预算只有一个种子和一个超参配置，没有完成强基线调优；分段动作幅度支持与固定程序库仍不完全相同，候选集亦不同。

该评估是已曝光同源目标上的 state-assisted 开放环开发诊断，不是因果隔离全部算法因素、独立确认、闭环收益或 RGB-only 证据。
