# 固定候选后缀预算：后验诊断

36 个固定候选的精确动力学后缀搜索，36 次与 108 次评分的平均最佳终距分别为 `0.67347` 和 `0.59583`；36/36 个候选在 108 次时改善。每候选 108 次的前 36 次分数，均重现封存计划中对应的 36 次分数。单独重跑还核对了 36 次与 108 次运行的前 36 条动作完全相同，且 36 次运行的最佳动作链与原封存最佳链一致。

**协议核验缺口：** 原始计划只封存了每次评分和最佳动作链，未封存全部 36 条采样动作。因此无法逐条验证“原始运行全部采样动作”与重跑相同；事前诊断协议的这一项不能完全验证。分数、种子、优化器代码 hash、重跑动作序列和最佳链一致支持确定性重现，但不能替代缺失的原始逐动作记录。诊断输出保留，结论仅作受此限制的后验工程线索。

这说明在当前候选、同种子和固定前缀条件下，增加后缀搜索次数有帮助；它**不证明**完整方法在等总预算下将超过 greedy，也不能为 PC2 的非即时机制或 PC3 的独立性能提供通过证据。诊断运行的 36 与 108 次不是原方法额外可用预算。未来需要在正式计量入口封存逐批动作或逐批动作 hash，以实现完整的同动作绑定核验。
