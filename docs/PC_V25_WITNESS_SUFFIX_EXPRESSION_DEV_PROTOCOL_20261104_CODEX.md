# 已知可行前缀：等预算尾部优化表达对照

对既有八根 E0 幅度面板，每根使用两条已验证成功见证的前五步；丢弃对应见证尾部。见证只用于事后诊断，不进入正式规划器。每个前缀、每臂固定两次重启，每次总计 121 个 15 步完整链样本（含起点），预测 token 每前缀每臂 726。

三臂固定如下：

1. `step_zero`：现有逐步动作 CEM，从零尾部初始化；
2. `step_random`：相同逐步动作 CEM，但用预定均匀随机尾部初始化，每次重启一条；随机种子和初始化费用计入；
3. `knot_zero`：现有四结点线性插值 CEM，从零尾部初始化，先评价一次起点再评价 120 个样本。

每臂优化器以 12 为批大小、4 个精英、初始尺度 0.35 和尺度下限 0.07。两次重启的种子由根和重启索引确定，与前一见证前缀诊断一致。比较共同预算下的逐前缀和逐根成功、终距和实际花费；这是针对表达与初始化的开发比较，不是证明任何优化器充分或全局最优，也不是完整方法资源比较。

逐批写入预测前动作、费用、输出与失败；每个根×臂完整保存结果。审计验证精确样本数、原始前缀、全链最优值，重放优化提案，并用另一同环境几何实现重算。任何失败保留在分母，停止实验不可追加或替换任务。来源和独立性未知；不作 PC2、PC3 或理论有效性的结论。
