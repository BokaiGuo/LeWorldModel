# root3 固定动作误差分解协议

开发性诊断：从上一轮封存 root3 的谱方法和无谱方法 root 计划中，分别取模型事前选择的完整 15 步动作，不重选动作或更改评分。相同真实热身重放后执行整链，保存 RGB，并使用同一因果 RGB 状态估计和冻结模型编码评价真实终帧。另在官方物理后端回放同动作，比较模型预测终分、真实 RGB 编码终分和真实物理终距。

分别报告此前两臂 root 阶段实际预测 token、谱 SVD 和候选后缀样本分配。固定动作验证模型预测与真实效果，不能因两臂搜索样本量不同而将差异直接归因预算挤占；若要识别预算因果作用，需要独立的补预算干预。此结果不进入新协议的选择规则。
