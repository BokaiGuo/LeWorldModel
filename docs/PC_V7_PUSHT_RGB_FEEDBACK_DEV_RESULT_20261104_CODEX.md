# v7 PushT：单根真实 RGB 反馈与失败诊断

按[协议](PC_V7_PUSHT_RGB_FEEDBACK_DEV_PROTOCOL_20261104_CODEX.md)，v7 在已暴露 episode 0 的 15 步暖身后完成三轮真实 RGB 反馈，各执行 5 步。guard 未弃权，官方成功为否。

| 指标 | 暖身后 | 执行 15 步后 |
|---|---:|---:|
| 物体位置误差 | 101.373 | 110.968 |
| 物体角度误差（弧度） | 2.1623 | 2.3008 |
| 官方状态距离 | 242.135 | 538.478 |

三轮的最终 float32 完整链与该根先前 v5 逐元素相同；v7 不能将此作为新根或独立复现。[同后端审计](../le-wm-main/results/pc_v7_pusht_rgb_feedback_dev_20261104_codex_audit.json)逐条重放 15 条暖身及 15 条决策命令，核对每步状态、RGB、终止标记和上下文，并以显式 packet 展开重算 **305 批、3642 条预测**；最大位置和评分差均为零。各轮分别使用 1920、1919、1920 prediction-token，包括 v7 配对弃权比较。guard 记录的是可见性检查而非完整可观测性证明。

对三次[已执行 packet 的后验诊断](../le-wm-main/results/pc_v7_pusht_rgb_feedback_dev_20261104_codex_executed_packet_diag.json)，模型预测对应的下一帧 latent MSE 均低于持久基线；但首段实际目标 latent MSE 降低约 `0.182` 时物体位置误差增加 `6.985`、角度误差增加 `0.102` 弧度，末段模型预测目标 MSE 降低 `0.766`、实际仅降低 `0.142`，物体位置和角度均未变化。该证据提示评分与物理姿态指标错位及模型误差均可能参与失败，不足以唯一归因或认定模型接口 bug。

这只是单根开发结果，不能证明 PC1、PC2、PC3、PC4 或 PC5 通过；未完成强基线、独立数据来源、完整成本或接触机制确认。控制台沿用旧版“两臂”文案，实际 manifest 只有 v7 response 一臂。
