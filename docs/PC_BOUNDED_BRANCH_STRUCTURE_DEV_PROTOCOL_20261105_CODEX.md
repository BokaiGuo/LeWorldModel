# 有界双分支 CEM 结构对照：开发协议

这是不使用响应、无行动后果描述的结构对照，不是 Planning
Compiler 或响应方法。目标仅为检查在相同动作域与逐次规划模型
评分预算下，保留两组完整链分布是否比单一分布更有利。

固定 task seed 42、reset seed 771001 和 solver seed
42/1042/2042，沿用 50 任务 PushT 及有界 CEM 的模型、动作
normalizer、评分与执行合同。每次规划固定 3000 条模型评分：
第一轮从共同初始分布评分 300 条，取代价最好的 30 条，按与
最优样本及最远精英的距离分为两组；若某组少于两个，则按精英
代价排序交错平分。分别根据两个组初始化两条完整链分布。
后续 8 轮每个分支各评分 150 条，分别取各自最优 15 条更新；
最后一轮每支评分 149 条并更新，再对两个分支均值各评分一次，
总计 300+8×300+298+2=3000。返回两个已评分均值中代价较小者。
所有候选在评分前投影到同一有界物理动作域；每分支内前缀和尾部
保持同一完整链，分支之间不混合均值。

对照为有界单分布 CEM 300×10、返回未额外评分的最终均值。
末尾选择规则不同，因此性能差异不能单独归因于分支结构；
两均值评分已经计入 3000，而对照没有均值选择开销。记录每次
计划调用数、投影次数、每任务实际执行动作和真实成功。
无响应分支若无收益也不否定其他生成方式；若有收益亦不能证明
响应的独立贡献。已暴露开发集非确认，实际总墙钟时间仅供诊断。
