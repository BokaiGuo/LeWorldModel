# 固定终点反馈实际执行尾部：事后机制诊断协议

目的：原同链诊断使用首次规划的后十步；反馈执行可能替换该尾部。以已封存
V1 固定终点反馈的三个实际派发段拼成 15 步链，检查其实际后十步在原五类
控制前缀后的作用。不重新选择动作、重跑规划、调参或增加任务。

每根固定先前同链诊断的 selected、zero、same-bank greedy、random bridge、
lookahead 前缀。前者必须等于反馈首个派发段；后两者是历史事后控制。对
每个前缀分别拼接零后缀及该根实际执行的后十步，按原 float32 转换和精确
动力学重算终距，记录绝对终距与相对零后缀的变化。复用先前同一个前缀、
同预算优化器的已封存自行重规划结果，不重新采样：前缀、任务、优化器及
随机种子均未改变。逐根验证反馈三个派发段、最终物理距离、源哈希与原
同链诊断绑定。比较采用原协议的 `1e-10` 严格阈值，报告非即时、相对变化
和自行规划优于 zero/greedy 的同根交集及四控制交集。

实际尾部是在后续观测后选出的，既不是首决策事前选定后缀，也不是在其他
前缀下闭环产生的行为。反事实重放只用于事后归因，不能作为 PC2 的事前
同链见证、PC3 或 RGB 证据。原反馈和同链结果已暴露，不能用于独立确认。
