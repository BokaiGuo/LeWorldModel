# PushT 原生初始化隐藏状态：开发审计

按 `PC_PUSHT_RESET_HIDDEN_STATE_AUDIT_PROTOCOL_20261105_CODEX.md`
对 seed 42 的 50 条任务重复初始化，每条在两次初始化后执行相同
25 个零动作。全部 100 对环境完成，无异常：

| 初始化方式 | 初始完整状态不一致 | 公开状态轨迹不一致 |
|---|---:|---:|
| 原生路径 `reset(seed=None)` 两次 | 18/50 | 18/50 |
| 同一任务两次使用相同显式 reset seed | 0/50 | 0/50 |

阈值 `1e-10`；无 seed 的最大初始坐标差为 33.19，包含物块速度；
25 步中公开状态最大差为 1.195。重复环境初始化使用不同的无 seed
随机重置；显式种子正对照只说明该实现和当前动作下可重复。

本地 HDF5 没有 `seed` 字段，`World._evaluate_dataset` 以
`init_state.get("seed")` 重置环境，随后 `_set_state` 虽重设可见
位置、角度和 agent 速度，但不显式清零物块速度、角速度，还推进
一次物理。这为此前方法臂配对比较引入可能的隐藏状态混杂，也为
相同 seed 的成功数变化提供具体待查原因；**本实验没有证明该混杂
造成某个具体成功差异**。后续需固定每任务环境 reset seed 并重新
记录完整状态和轨迹；此受控设置须与原始协议单独命名，不静默替换
历史结果，也不能仅凭此审计声称原论文的官方实现有同样行为。
