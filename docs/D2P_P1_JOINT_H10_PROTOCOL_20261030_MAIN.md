# 联合优化前缀：固定十步共同后缀干预

在已观察开放链结果后，对全部八个根/条件/臂槽固定 selected、
zero 和原 mixedmode 已认证 stage-greedy 三种前缀；不筛选根或动作。
selected 取新联合优化的真实五步执行及完整 warmup/前缀图像轨迹；
zero 和 greedy 取先前 H10 已认证的同任务锚点。每槽三者施加完全
相同的 42 个十步后缀：零动作、20 个坐标正负 tanh(0.25) 探针、
以及该槽新 selected 的十步后缀。最后一条是事后开发探针，不是
独立确认。总计 24 锚点、1008 分支。

每次重建真实环境，实际前缀状态和 51 帧必须精确匹配自身封存轨迹
才能执行后缀；保留早停和域外删失，不补终点。逐槽保存审计和
资源账本。各分支不调用神经模型；没有 CPU 神经降级。由于状态
缓存未序列化，同轨迹重放不构成对隐含物理解算器缓存的完全保证。

报告物体位置、角度、推杆、原生联合成功以及绝对终态和相对各自
零后缀的变化。共同后缀差只表示该动作后果的差异，不能证明各自
后缀规划能力；需要另行执行同优化器统一预算的独立后缀规划。
已知根、重复轨迹、事后开发及训练来源未认证均须保留，不开放 P1。
