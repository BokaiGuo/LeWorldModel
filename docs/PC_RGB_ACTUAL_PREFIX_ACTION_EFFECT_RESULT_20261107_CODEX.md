# 真实已执行前缀后的共同动作后果

## 范围

对上轮 40 个已曝光任务中具有完整五步实际前缀的全部 35 个，重放 effect 实际前缀、lookahead 前缀、零前缀、随机前缀，并分别执行同一五步探针库：零动作、四个 ±0.6 轴向动作；当原链有第 6–10 步时，该片段作为同任务的第六探针。运行了 **820 条物理探针**，并在 RTX 5060 Ti 上预测及编码相应后继。

物理效果是零探针终点距离减去指定探针终点距离；模型和真实编码效果分别是对应的目标 latent 平方距离之差。两种量单位不同，只比较符号。零动作是合法参照，不保证物理静止；所有探针执行完整五步，即使中途成功，属于诊断性轨迹。前缀重放逐步核对上轮记录；预测和真实编码向量与相应代价通过重算。

## 结果

四个轴向探针在 35 个任务中有 140 个比较；将任一侧在预定容差内的平局排除：

| 前缀 | 模型效果与物理效果同号 / 非平局 | 真实编码效果与物理效果同号 / 非平局 | 模型效果与真实编码效果同号 / 非平局 |
| --- | ---: | ---: | ---: |
| effect 实际 | 74/134 | 74/134 | 118/134 |
| lookahead | 71/133 | 70/133 | 116/133 |
| 零动作 | 77/137 | 73/137 | 113/137 |
| 随机动作 | 73/133 | 75/133 | 109/133 |

平局数分别是各列分母与 140 的差；同一任务的四个方向不是独立任务。这里的真实编码是**事后评估端**观察，不能用于部署时规划。模型与真实编码的方向较常一致，但两者与终点物理距离效果的一致性较弱；这提示在本动作支持和当前 goal cost 下，应同时考虑表示/目标评分失配，不能只归因于多步预测误差。它也不能证明所有物理任务指标或所有动作方向均如此。

排除 2 个 effect 前缀内已成功的任务后，**13/33** 个任务在 effect 与零前缀之后，四个轴向探针中至少有一对的物理目标距离排序发生严格反转。实际位置差异及目标几何本身也能产生这种反转，因此它不是独立的控制机会改变证明。

在这 33 个任务中，30 个保留了原实际链第 6–10 步作为共同探针；其中 **1/30** 个任务满足：该后缀相对零动作在 effect 后为正效果，而在零前缀后为非正效果。这只评价实际后缀的前五步，不等同完整链或等预算尾部重优化的效果，也不能追溯地作为 PC2 判定阈值。

本次未测 greedy 前缀、未建立描述帮助发现链的独立贡献，且任务来源独立性未知；不能据此通过任何 gate。相关测试 **17 项通过**。
