# RGB 共同池逐时刻预测—真实编码—物理对齐诊断

使用已封存的 119 个匹配决策池、每池 6 条动作链，不根据后果筛选。重放原历史并逐条执行动作；每 5 环境步记录真实 RGB 的冻结模型编码、真实距离和物理成功，直至计划时域末尾。为对齐预测轨迹，成功后仍在未包装的诊断环境继续执行；首次成功前的轨迹必须与原停止式重放一致。成功后动作与状态只用于时序对齐，不是部署轨迹。

同一 RGB 初态和目标、同一原始动作链进行模型 rollout，保留预测和真实编码向量、目标编码、各步距离及成功位。对每池比较预测最小时序代价的选择、真实编码最小时序代价的事后选择与物理成功；将原成功判据“任意环境步曾成功”与每五步采样时的成功分别报告。真实编码最优是不可部署的评估端诊断，不作为规划结果。

记录全池和排除初态成功，按任务汇总，不能将相同任务的多个决策当作独立任务。分析是对已曝光开发池的事后诊断，不认证独立效果、不视为理论证明。模型分数与真实编码不一致不自动证明模型本体错误，还可能来自时钟、历史、渲染或预处理。
