# 行动后果保留：新随机流后缀求解结果

按[运行前协议](PC_ACTION_OPPORTUNITY_FRESH_CEM_DEV_PROTOCOL_20261104_CODEX.md)，对已有三种两槽保留规则所选候选的并集，使用不同于旧诊断的随机种子重新执行四结点、零尾初始化的有限 CEM。每个 root×depth×来源组内的候选共享同一初始随机流；这并不意味着不同候选的自适应优化轨迹完全相同。

| 候选来源 | 绝对探针最小 | 相对改善最大 | 后果互补 | 后果互补较绝对探针更好 / 更差 / 持平的 root |
| --- | ---: | ---: | ---: | ---: |
| random_direction | 0.50294 | 0.50356 | 0.50348 | 5 / 10 / 1 |
| spectral | 0.50116 | 0.49421 | 0.50200 | 1 / 10 / 5 |

终距先对每 root 的 depth 0/1 等权取平均，再对 16 个 root 等权平均；越低越好。三策略在两来源的 32 个 root×depth 组中均为 0/32 有限预算成功检出。`effect_complement` 相对 `absolute_probe_min` 的平均 root 终距分别高 0.00055、0.00083，未表现出稳定改善。

本次求解了 **234 个去重候选**，每个候选 11 次预测调用、363 prediction tokens；诊断合计 **84942 tokens**，没有计入原规划成绩。验证了本次候选质量源与选择审计记录的源哈希一致，并检查零尾重评分；实际动作、预测和每个候选优化轨迹保存在结果目录。

## 解释边界

- 新随机流与旧候选后缀求解流不重叠，但候选、任务和保留规则仍来自旧开发面板，不是来源独立确认。
- 这是固定候选池的共同有限优化机会，**不是**端到端规划、等总成本比较或生成器贡献估计；跨来源分数差不能解释为谱方法因果效应。
- 只对三种规则选中候选并集重算，没有重算整个候选池；没有检出成功不能证明这些前缀不可行。对四结点 CEM 的已知漏检限制仍然成立。
- 后果互补策略只按向量距离选槽，没有任务收益约束；本次否定的只是该具体开发配置在此面板的稳定增量，不否定全部行动后果方法。
- 独立审计脚本已在同一工作区检查全部 234 个候选的日志哈希、成本、初始随机种子及来源前缀，重新调用当前精确动力学核对每次预测，并以原优化器重放所有动作、得分、最终链和优化代；另外核对 192 个保留组的选择绑定和 root 汇总。该审计仍依赖当前动力学和原优化器，未封存所有依赖，也未独立重建跨 root 的汇总表；不是完整复现包或真实物理证据。

原 PC0–PC5 判定不变；下一步应转向事前指定的任务相关机会评价与等总成本端到端消融，并行完成独立来源和视觉预测/评分诊断。
