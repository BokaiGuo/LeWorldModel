# v22 选中链评分批形状重算协议

对已暴露 v22 单根两臂三轮全部六条封存选中链，复用 v7 已有精度诊断：从原预测记录中找到动作和评分均完全匹配的首次出现，并按原 `CHUNK=4` 恢复其原始子批。分别交叉执行原路径的三帧上下文/单帧目标编码和后验路径的五帧合批编码，以及原子批和单链预测。冻结相同历史、动作归一化、权重和 GPU 算子；记录四组评分及原分数差、每个实际子批大小、编码差异。

重算前核对 v22 后验诊断、CPU 算术审计、完整源绑定与模型元数据；重算后核对源哈希。禁止重新规划或执行物理。报告所有六例，包括失败；不能用偶然小的误差作为跨设备容差、排序可靠性或物理真实性认证，也不能据此改写原面板和 gate。
