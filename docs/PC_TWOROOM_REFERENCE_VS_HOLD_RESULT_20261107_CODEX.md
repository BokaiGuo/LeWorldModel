# TwoRoom 参考动作与保持动作：预测—真实对齐

按事前协议，在已暴露的标准 seed-42 面板上，先封存 50 对合法的 25 步候选及冻结 RGB 模型预测，再实际重放 100 条链、2,500 步，最后编码真实末帧。参考动作仅作为评价端见证，未作为部署搜索的候选生成方法。

| 比较 | 参考链优于保持链 |
| --- | ---: |
| 模型预测目标代价 | 50/50 |
| 真实末帧编码目标代价 | 50/50 |
| 真实末端物理距离 | 50/50 |
| 曾触发成功 | 50/50，保持链 4/50 |
| 最后一步成功 | 50/50，保持链 4/50 |

三类代价的两候选排序在 50 根上均一致，无排序平局。保持链成功的 4 行为 79449、85128、510811、773558；其中保持链没有动作，不能将这 4 对计作“参考动作使原先失败状态转为成功”的独胜。其余 46 对参考链成功、保持链不成功，模型评分均偏好参考链。

预测末帧与真实末帧的表示均方误差，按 100 个后继及表示维度平均约 **0.1280**；排序一致不意味着状态预测精确。此前 10 步固定方向矩阵在部分根上的物理排序较差，本试验只能说明大幅不同的参考／保持候选在此面板容易区分，不能推出附近候选、动作顺序或接触情形也可靠。

审计根据封存表示重算模型和真实编码代价，最大差分别为 `3.06e-5`、`6.11e-5`；参考链逐步距离与先前封存重放最大差 `5.17e-6`，终止标记一致。这是同一环境实现的交叉重放及数值检查，不是独立物理引擎认证。RGB 输入权限、行动后果及图像对齐相关测试 **20 项通过**。

限制：数据及参考动作已用于开发，训练成员和 normalizer 独立性未知；数据生成环境与本地默认几何尚未完全认证。任务按行抽样，不自动构成独立 episode。该诊断不比较普通 lookahead、描述保留或真实闭环性能，亦不证明 PC1–PC5 通过。
