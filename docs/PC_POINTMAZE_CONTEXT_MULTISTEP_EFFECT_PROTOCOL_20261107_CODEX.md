# PointMaze 多步动作排序：窗口 1/2 受控对照

使用 1884–1891 八个已曝光任务、camera 0 和同一固定动作库：
`numpy.default_rng(27155000)` 在 `[-0.4,0.4]` 生成 8 条、每条 5 个
二维分段动作，每段重复 5 个环境步；第 0 条为 25 步零动作。零动作
只称为零动作，不假定物体静止。每根使用同一动作库，且不依据真实
成功挑选。模型及目标使用完整 proprio，属于 state-assisted。

每臂 8 条模型查询，先封存窗口 1/2 的完整候选、逐候选最终目标
代价、最低分选择和哈希；逐条相同输入、五个动作包和本地配置的
alpha=0.1。窗口 2 绑定实际配置，窗口 1 是旧实现对照。无目标的
真实后继、真实物理距离或候选结果进入预测阶段。

之后从归档 float64 原初态、同一固定动作和时钟重放 25 步，使用
当前任务的合法目标 proprio 在评价端计算各步位置距离。按任务
报告预测代价与物理末距的非并列成对排序一致率、所选链的末距
相对固定池最优的遗憾、曾进入 0.5 半径；记录初始已经命中的根，
同时报告全部八根与初始未命中根，但不移除原分母。物理真实末距
仅为诊断指标，不是部署评分或完整官方 episode 成功。

事先判定：仅当窗口 2 的任务平均排序一致率高于窗口 1 且平均
末距遗憾低于窗口 1，才把该面板视作支持继续检验窗口修正的动作
排序价值；否则不以本面板声称它改善动作后果。阈值不是 PC1
通过标准，结果也不证明独立任务、闭环或原响应方法有效。
