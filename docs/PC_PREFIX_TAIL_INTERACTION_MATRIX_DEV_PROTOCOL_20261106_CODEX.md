# 前缀—共同尾部配合矩阵开发协议

本协议在执行及查看新增矩阵之前确定。使用已暴露任务 15、25、35
的第二次规划上下文，分别取之前记录的前 4 条合法完整链的前 2 个
action packet；以既有 A 库种子 12001+任务编号生成 8 条共同随机
尾部，取前 4 条形成 4×4 矩阵。尾部动作经过相同归一化边界裁剪。
三个任务共 48 条 25 环境动作链。不按成功或预测分数筛选行列。

所有单元同时记录模型终点代价、实际末帧编码目标代价和曾成功与否。
物理环境从同一 reset 及数据状态恢复，逐步回放该任务原第二轮之前
的 25 步，并逐步核验已存 before/after 状态；候选动作不交给正式
规划器。末帧与目标使用相同冻结编码器及既有像素处理；额外记录
回放初始帧与捕获上下文输入的差异，不能静默当作完全等价。

连续代价矩阵计算双中心残差 `M - row_mean - column_mean + grand_mean`
及其 RMS；该残差衡量相对加性行列模型的非加性项，不自动证明搜索
收益。逐一比较所有 2×2 的差中差方向在预测与真实编码代价中是否
一致；零差和数值容差内情况分开记录。还应列出成功矩阵、每行尾部
排名与模型两次重复评分的最大差。4×4 小矩阵及 3 个已暴露任务
仅用于判定是否值得进一步建更大预定面板，不能声称统计显著性、
样本外泛化或 gate 通过。物理成功、接触分支、时域及编码评分可能
不一致；不根据事后结果调整任务、尾部或阈值。
