# P1 重选与原联合 winner 的物理探索协议

固定 8 臂 × 2 条完整 15 步动作，均来自已完成主机 CUDA 双路径
重放和保存态验收的同一动作 roster。执行器的历史兼容角色名称
`incumbent` 在本实验中特指原联合终态 winner，`model_selected`
特指模型内非即时 latent 改善重选 winner；两者不是先前回溯
incumbent 的语义。按固定顺序全部执行，重复动作也保留。

重用原物理执行器的任务根、图像、预热动作和 normalizer 绑定；
每行重置独立环境、完整记录物理轨迹及 RGB、五步与终态指标、
原生成功和停止状态；提前停止后的终点保持缺失。执行后独立
保存态消费，比较同根、同条件的物体位置、角度、推杆和原生
联合判据。模拟器状态只用于记录评估，不参与模型选择。

这是已知根上的开发探索，重选策略在观察旧结果后确定；两种
动作同时改变前缀和后缀，没有真实反馈重规划，不能将性能差
归因于前缀改变控制能力，也不是等预算强基线或独立确认。
该实验不调用神经模型，不训练，也不开放 P1。共同后缀干预和
同一预算下各自后缀规划仍须单独开展。
