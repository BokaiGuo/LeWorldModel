# v22 特权接触覆盖：共同后缀诊断结果

按[协议](PC_JEPA_V22_PRIVILEGED_CONTACT_SUFFIX_PROTOCOL_20261105_CODEX.md)，四个固定前缀共享 16 条后缀；其中见证前缀与部分后缀来自物理状态生成的已暴露见证，**仅限评估**。64 条均完成物理回放和冻结模型评分，无结果回流规划器。

| 五步前缀 | 全部 16 条的精确物体姿态数 | 验证组：预测 vs 真实编码排序一致 / 非并列对 | 验证组：预测 vs 角度误差一致 / 非并列对 | 相对零尾改善平均绝对误差 |
| --- | ---: | ---: | ---: | ---: |
| 零动作 | 2 | 27 / 28 | 7 / 7（21 对并列） | 0.01076 |
| response 首 packet | 1 | 22 / 28 | 无非并列对 | 0.02046 |
| CEM 首 packet | 12 | 17 / 28 | 14 / 28 | 0.19152 |
| 特权见证首 packet | 14 | 21 / 28 | 8 / 28 | 0.35468 |

固定动作设计在后两个前缀上覆盖了多个物体姿态，比上一随机后缀库有更直接的接触诊断价值。特权见证前缀的 16 条中有 6 条达到物理成功，其余前三组均无成功；不能将这些成功归因于自动规划器。

在这组验证动作中，CEM 与见证前缀下的预测—真实编码排序和相对零尾误差均比前两个前缀弱；见证前缀下模型评分与角度误差的 8/28 一致也提示潜在失配。**这些对都来自一个已暴露任务、共同见证扰动及相互相关的动作，不能作为独立样本或证明普遍模型缺陷。** 动作结果中的 agent 变化也可能影响目标评分。每条验证动作都直接接受模型查询，因此这不是从构造描述预测未查询动作质量的验证。

与原两臂首轮的 991 条去重查询精确比较，只有全零基准重合；见证及其变体此前已作为评估数据暴露，不能称为来源独立。模型预测计 192 prediction tokens，编码、物理和审计成本另计，不是规划总成本。

独立 CPU 统计审计重建全部动作、核验输入和重叠、重算报告，并在同一物理后端重放全部 64 条，末帧和末态精确一致；没有独立重跑神经模型或换物理实现。见[报告](../le-wm-main/results/pc_jepa_v22_privileged_contact_suffix_20261105_codex/report.json)、[物理记录](../le-wm-main/results/pc_jepa_v22_privileged_contact_suffix_20261105_codex/physical.json)和[审计回执](../le-wm-main/results/pc_jepa_v22_privileged_contact_suffix_20261105_codex/audit.json)。动作构造单元测试 `1 passed`。

本结果不改变 PC0–PC5；下一步须分别排查该接触段的预测后继与真实编码、真实编码评分与物理角度的失配，并在非特权、来源合格的新任务上检验，而不是把见证变体带入正式规划。
