# P1 现场 RGB 最佳迭代：离线/在线等价开发验证

对既有固定 24 行、冻结 checkpoint 和已封存原始首包，执行真实
前缀与首包，确认未停止后，从现场物理 journal 认证该首包及末帧；
立即用现场 RGB、实际动作历史和固定原后缀初值，按信赖系数 0.1、
20 步 Adam、最佳迭代规则重新规划第二包并直接执行。前缀、首包
和目标沿用现有输入；不将物理状态、奖励或未来物理 outcome
作为规划输入。零填充的第二个计划包仅用于满足现有两包接口，
绝不执行该填充包。

24 行不按 outcome 筛选；前缀或首包终止时禁止第二阶段，保留
停止信息。CUDA 采用合作锁和冻结模型检查。每阶段保存来源、
输入图像与动作摘要、所选动作和显式模型调用数；物理 journal
保留执行和 render 顺序。比较旧的离线中点规划和回放时须独立
核验实际中点、动作与状态，不把两次重放当独立任务。源闭包、
FLOPs 和完整动态硬件调用仍未知；本实验不能证明等预算。

已知根、历史初值和此前 outcome 已见，本实验只验证现场反馈
与离线前缀链的接线及真实结果，不构成 P1 通过或方法独立泛化。
