# TwoRoom 行动敏感目标度量：固定池开发结果

在已暴露的 10 个任务、每根同一份 656 条合法候选上，按预先冻结的 rank-8 规则，对共同尾部预测后继建立行动敏感子空间。三个评分臂的候选和冻结 RGB 模型预测相同；决策封存后，各执行各自选中链。

| 最终评分 | 曾成功 |
| --- | ---: |
| 完整 latent 目标距离 | 6/10 |
| 行动敏感子空间距离 | 7/10 |
| 固定随机子空间距离 | 6/10 |

行动敏感臂相对完整距离**独胜 1 根、独负 0 根**，未达到事前至少独胜 2 根的开发出口；按协议停止扩大这个具体 rank-8 构造。唯一独胜是此前已知存在成功候选且被原始评分丢失的任务 82490，因此该结果尤其不能当作未见任务确认。该臂另在几个双方均失败的任务上得到较小末距，但不能替代成功率，也不能从中追溯修改出口。

10 根的行动变化矩阵均达到 rank 条件；行动敏感臂与完整距离臂在 6 根选中不同候选。每根复算 656 条预测，原始模型成本与原封存分数最大差 `6.41e-4`，在预定 `1e-3` 内；本次预测及三种评分的同步计时约 3.12 秒，不包括模型加载、原候选搜索和真实执行。三臂共享所有前缀的精修结果，**不是**原始单臂 440 评分预算，也不构成完整质量—成本曲线。

独立审计从保存的预测表示重建奇异子空间、随机投影、全部分数及候选身份，并重放 30 条实际选中链：分数重算和物理距离最大差均为 0。审计使用同一模型预测及环境，不能认证模型真实动力学。行动子空间、候选构造和 RGB 权限相关测试 **20 项通过**。

这里的候选此前由原目标评分生成且任务已暴露；未测试不同任务、在线重规划、与调优 CEM 的等完整成本比较，也未验证该子空间对未查询动作的真实后果预测。观察到的 7/10 不证明 Planning Compiler、行动描述或任何 PC gate 通过。
