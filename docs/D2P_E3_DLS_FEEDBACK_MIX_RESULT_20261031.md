按 `D2P_E3_DLS_FEEDBACK_MIX_PROTOCOL_20261031.md`，两根各执行
四臂主机 CUDA 推理和真实物理反馈。第 0 步 structured 保持 DLS；
第 5、10、15 步各将四个 DLS 候选与四个固定种子随机候选交给
原后缀优化和模型评分。未将交叉实验成功动作或物理状态输入规划器。

两个根的四臂实际动作均与对应原 DLS 实验逐项相同，首包也完全
一致。structured 均在 20 步未原生成功：根 0 物体位置误差
12.7668，根 1 为 13.8914。其他臂结果保持原样；不是新的独立
成功率样本。

保存的三次反馈节点中，根 0 选择混合库下标 `2,3,3`，根 1 选择
`3,3,3`；下标 0–3 是保留的 DLS 候选，4–7 是随机候选。每个
节点实际初始化均从保存的 Jacobian、目标和固定种子逐项复算，
且实际执行动作绑定到选中候选。因此随机候选确已进入优化和
模型评分，但此设置下均未被选中；不能据此断言它们真实物理
执行必然失败，也不能把结果归因于接线未生效。

这次只测试一种固定候选库、两个已知根和当前 latent 终态评分；
不证明随机搜索无效，也不证明评分是唯一瓶颈。8 个候选和模型
调用数量保持不变不代表完整等成本；未证明 P1、独立泛化或强
基线优势。保存态检查分别验证 15、16 个节点及各 4 个 structured
初始化，未独立复演完整物理事件链。相关单元测试 6 项通过。
