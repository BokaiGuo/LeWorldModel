# RGB 时序近并列选择：开发协议

观察到同一前缀导致不同尾部的时序最小值相同或极近，而 float 计算差异会改变所选尾部。本实验对已曝光 TwoRoom episode 9000–9039 的 effect 臂比较原规则与新规则；各规则分别运行原始和缓存模型，每臂独立执行、重观测、处理旧尾。固定相同模型、种子、候选生成、保留器、16 条评分预算和 25 步上限。

新规则仅在最终已评分链中：时序最低分加绝对容差 1e-3 内视为近并列，从中选末帧分数最低者；末帧分数加同一容差内再取原始候选顺序首项。1e-3 沿用此前 GPU 评分重放预定容差，不是统计误差界；它可能将真正不同的代价合并。只剩一个模型时刻时沿用原 fallback。不得使用物理真值选择候选。记录全部计划、实际派发、距离、成功、候选计数及每次选中的时序与末帧分数。

预定开发出口：新规则的缓存／原始完整动作及来源一致的任务数严格高于原规则，且新规则非缓存臂相对原规则成功独负不超过独胜。未达到则停止此固定规则；即使达到也只是已曝光任务的开发信号，不代表独立确认或 PC gate 通过。缓存精确等价、响应增量和完整成本优势均不能从该实验自动推出。目标图预处理与模型加载不计入任务计时。
