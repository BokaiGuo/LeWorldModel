# P3 raw 坐标修正：H1 同根物理配对探索合同

针对已观察过的四个 P3 失败决策，固定其 H1 面板全部 zero 与
八个候选，不根据模型分数或物理结果筛选。每个候选将日志原
五步前缀分别与原五步后缀、已封存的 raw 坐标修正五步后缀拼接，
从同一原始物理根、目标和 warmup 重放。共 4×9×2=72 条，
分为 12 批、每批 6 条；原生提前停止立即记录，不补终点。

本合同是对已知根、已观察失败面板的开发探索，不是事前独立
确认。模型后继是想象状态，物理执行重新执行相同前缀后自然得到
真实状态，不将想象 latent 当成物理状态。分别记录根、任务、
前缀和后缀动作字节、动作 ACK、逐步状态、终止与原生成功。
预测的两种后缀来自相同模型预测上下文，但真实物理环境对
此前缀可能与模型预测不同，因此物理结果不能单独区分模型误差
与坐标修正的效应。

每批均使用六槽既有物理执行器和其资源上限；独立环境构造，
输出互不覆盖，逐批失败即停止并保留 partial，不自动重试。
四个决策来自两个共享根，策略可能重复，72 条不能当成独立样本；
比较相同前缀的新旧后缀，早停不能补值。H3 前缀为 15 步，需要
独立的 20 步执行合同，不能截断为 H1。无神经前向或模型训练，
不宣称 P1/P3 通过、等预算或独立泛化。
