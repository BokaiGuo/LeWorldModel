# P1 固定四起点 Adam 预算轨迹：开发合同

目的：在 24 个已知前缀各自的真实 cp5 RGB 上，保留同一四起点
Adam 优化的第 5、10、20 次更新后的全部动作和模型分数，供后续
逐预算真实物理执行和方法开发。输入采用既有 uphill cp5 bundle；
统一冻结模型、随机起点、动作尺度、学习率及每个逻辑任务的种子，
在每个预算点按模型分数及起点索引选动作。物理状态和已有真实
outcome 不进入选择器，不能按成功重新选择候选或预算。

此运行是在观察旧结果后设计，属于已知根探索，不是预注册确认。
每个起点只运行一条 20 步轨迹，在第 5、10、20 步分别评分并保存；
这不同于三个独立运行。中间评分产生额外推理成本，须在本次总
账中列出；其间壁钟不能作为三个独立预算的实际耗时。后续性能
实验需分别物理执行全部固定预算点、分列停止和删失，并对各臂
计入前缀生成与反馈成本。不同调用种类不直接相加。

本实验仅主机 CUDA 模型规划，不更新任何模型或训练模块；未进行
物理执行前不声称成功率、机制、预算优势或 P1 通过。
