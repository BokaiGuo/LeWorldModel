# P1 推杆方向的目标残差分解

使用前轮真实重建目标场景，以推杆 x/y 方向 ±20 原生坐标的四个
反事实渲染之编码中心差构造二维 latent 子空间；四个根／渲染条件的
目标基线和完整偏移图像哈希均与已封存面板匹配。二维方向均通过
非零秩检查。模型及编码在主机 CUDA，模型参数和 buffer 不变。

将该子空间与既有四起点二十步规划的固定 22 个完整十步终帧及
同动作模型预测进行配对，分别计算相对目标的总残差和投影残差；
两个提前成功停止槽没有十步终帧，保留停止步数而不补值。真实
残差投影占总能量的描述性均值为 0.421，预测为 0.275。关键根
0/on 的 selected 两槽，真实投影比例为 0.790/0.773，预测比例为
0.586/0.377；对应真实推杆误差为 78.92/83.25。

这不支持“此批真实编码残差完全没有推杆相关响应”的简单解释，
但有限差方向可能同时包含遮挡、渲染和物体相关变化，投影比例不
是推杆误差估计器；也不能仅凭占比断定某种评分权重应当加大。
预测与真实的残差及其占比依赖总误差，不能解释为预测错误的单独
因果归因。两个根、重复前缀和相互依赖轨迹不构成独立样本。

反事实图像使用模拟器状态，只作为事后诊断，**不作为 RGB 规划器
输入或可部署评分**。没有选择、优化或执行新动作，不提供 P1
机制或公平基线证据。
