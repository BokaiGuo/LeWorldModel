# PushT 任务 1 位置与角度静态因子诊断协议

对已暴露任务的原选失败链和唯一末帧成功链，交叉其推杆位置、物块二维位置和物块角度，形成全部 8 个零速度静态状态。使用原目标图、同一冻结编码器和原末帧 latent 距离；评价端记录目标状态和物理成功规则，任何物理状态或后继图均不提供给规划器。

逐格记录请求与观察状态，位置角度最大误差超过 1e-4 的格子无效；物块位置与角度同源的四格须与前一实验对应图逐像素一致，代价绝对差不超过 1e-5，否则不将其视为有效重现。记录模型及输入文件指纹。比较固定另外两因素时的物块位置效应和角度效应，以及固定物块状态时推杆位置效应，保留完整八格和无效格。

该实验使用事后选择的单任务及评价端合成静态状态，组合可能不可达、碰撞或遮挡；不能据此认定因果机制在自然轨迹成立、判定模型动力学、调参或宣称规划收益。不得改变任何 gate 状态。
