# 行动后果保留：新随机流后缀求解开发协议

制定于本次新随机流求解前。性质为对既有开发候选和已定义保留规则的追加诊断，不是预注册确认，不运行完整规划器。

- 候选与槽位：读取 `pc_action_opportunity_retention_absolute_probe_audit_20261104_codex.json`，覆盖两个来源臂、16 roots、depth 0/1、三种既有两槽策略，逐组运行三种策略选中候选的并集。策略由既有 A 探针确定，不使用新 C 探针或新求解结果选择候选；所有槽和全部 root 保留。
- 求解器：与旧候选质量诊断相同的四结点 CEM、零尾初始化、1 次初始评分与 120 次后续评分。每组内所有候选使用同一新随机流 `default_rng(2045000000 + root * 100 + depth)`，跨臂同 root/depth 使用同一初始随机流；该范围与旧种子 `2032800000 + root * 1000 + depth * 100 + index` 不重叠。自适应 CEM 后续动作可因分数不同而不同。
- 固定预算和候选机会，记录每个候选真实输入动作、模型调用、最终分数、完整动作链、分项 token 和前缀哈希。检查前缀、索引和旧即时分数；候选失败不得静默剔除。
- 按 root 和来源臂，对两个 depth 中每个策略保留槽的最佳新求解分数等权求均值；对 16 个 root 等权报告，主要对照为 `effect_complement − absolute_probe_min`。完整记录每组及每候选数据，报告 `<0.05` 的有限预算检出数，但未检出不等于不可行。
- 本次只评价固定候选池上受限共同优化机会，不能证明端到端规划收益、生成器因果贡献、物理控制、独立任务泛化或 PC2/PC3。诊断调用成本不混入旧规划预算；全成本方法比较另行实施。
