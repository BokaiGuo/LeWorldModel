# JEPA 历史保持 rollout：开发接口协议

目的：提供独立适配器，显式传入观测历史之间的实际动作 packet，使每个预测步的状态槽与从该状态出发的动作槽对齐。此开发分支不更改原 JEPA 包装器、v7 核心或既有结果。

训练配置 `frameskip=5`、`action_skip=1`，轨迹切片对相对时间 `t=0,5,10,15` 的帧使用相邻五个动作拼接成 packet。训练代码对预测使用 `shift=1` 的目标。对于 `0,5,10` 三帧上下文和下一动作，适配器首步送入动作 `[0:5, 5:10, 10:15]`；后续一步滑动到 `[5:10, 10:15, 15:20]`。全部 packet 必须已按原模型合法预处理，禁止将物理未来状态作为输入。

先使用可追踪的合成模型验证首步和三步全部动作／状态槽、batch、因果性及原地修改防护；测试仅认证接口，不是科学证据。然后在已暴露 episode 1、原生冻结权重及其三帧真实历史上，比较原包装器 `unroll` 和新适配器：同真实未来 packet、模型、上下文、预测器和逐步预测本体状态；分别在一、两和三 packet 的预测末端比较输出。未来 RGB 只作逐时刻事后参考，不用于筛选或优化。首步新适配器需重现上轮真实历史的原生预测；原包装器需重现零填充原生预测。记录四个调用中的计数和独立分数，失败保留；此比较不证明真实控制、RGB-only、训练来源独立性或 PC gate 通过。
