# 固定预算内部响应替代：开发协议

2026-11-05，运行前协议。目的：在原生末轮均值选择不变的前提下，
检查有限差分方向是否能替换一部分随机采样；不是程序组合或 PC2 机制。

每次 CEM 迭代维持每环境 300 条完整链评分，首轮保持原生采样。
其余迭代分别使用 288 条原生随机候选（含当前均值）、8 条围绕
当前均值的四个正负探针、4 条依探针结果生成并单独评分的候选；
总和为 300。所有 300 条共同参加相同 top-30 更新，最终返回分布均值。
响应臂依据正负代价差确定每条方向的符号；匹配随机臂采用与代价
无关的固定方向符号。四个候选分别为相邻有符号方向之和并归一化，
不是重复评分单个正负探针；另有原生 300×10 CEM 对照。三个臂均仅使用
模型合法输入及预测，均不访问物理真值。探针、候选全部计费。

候选方向按完整动作链单位范数，幅度 0.25（模型归一化动作空间）。
方向是启发式，不声称谱或梯度精确。使用独立随机生成器产生方向，
避免探针本身消耗原生采样的随机流；探针和组合仍改变候选池和分布。
开发 smoke 先测试每轮计数、零响应、非有限值、批处理和原生模式
等价；随后在 seed 42 开发 50 任务比较。seed 42 已有公开历史结果，
不称独立确认；此前统计的额外均值评分不算本实验的必要规划调用。
记录物理成功、调用、墙钟，不能仅以相同完整链数声称完整系统同成本。
如果共同评分选择消融或反事实重放尚未完成，明确作为并行开发，
不提前声称该方案解决了评分失配。

扩展约定：seed 42 结果已知后，为检查开发随机流敏感性，固定在
seed 43、44 分别运行原生、响应和随机三臂，不按结果排除任务。
这仍是开发集，历史原生同 seed 结果也已知，并不等同独立确认。
执行期间并行启动了 CPU 物理初始化审计，扩展臂的墙钟时间受资源
竞争影响，不用于耗时比较；各臂模型评分计数仍须独立校验。
