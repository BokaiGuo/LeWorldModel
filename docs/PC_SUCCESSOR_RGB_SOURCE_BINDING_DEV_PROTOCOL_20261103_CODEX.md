# Successor RGB prospective source binding protocol

This is a source-binding development version of the existing successor RGB
policy; it does not change the algorithm, authorize independent confirmation,
or reopen any stopped mechanism protocol. Before model setup or a decision,
create an exclusive receipt binding the files used for the policy, response
generator, optimizer, inference/unroll, feedback runner, renderer bridge,
configuration, checkpoint, normalizer inputs and target data. Hash these again
after the execution and fail closed on any difference. Bind every decision,
execution receipt and RGB archive into a separate exclusive completion
receipt. Keep the original per-decision dependency fields unchanged and
retain both receipts, including the absence of a completion receipt on
failure. The declared file list is an explicit engineering scope, not a claim
to have captured every package, dynamic library, hardware or training source.

The resulting run remains a repeated, exposed four-root development panel;
it cannot be used as independent confirmation or as a new performance claim.
Running this version is not required to validate the source-binding mechanism.
