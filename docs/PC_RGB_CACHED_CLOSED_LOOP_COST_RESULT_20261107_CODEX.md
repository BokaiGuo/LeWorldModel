# RGB 单帧编码缓存：完整反馈配对开发结果

按照[协议](PC_RGB_CACHED_CLOSED_LOOP_COST_PROTOCOL_20261107_CODEX.md)，对已曝光的 40 个 TwoRoom 任务，分别独立执行 effect 与 CEM16 的原始和缓存反馈过程。两版本共享冻结 checkpoint、输入权限、动作生成和种子；任务顺序交错缓存版本。

| 规划器 | 原始／缓存成功 | 完整计划和选择均一致的任务 | 原始／缓存任务时间总和 | 原始／缓存同步规划时间总和 |
| --- | ---: | ---: | ---: | ---: |
| effect | 32/40、32/40 | 34/40 | 5.110 / 4.242 秒 | 3.404 / 2.534 秒 |
| CEM16 | 31/40、31/40 | 40/40 | 5.628 / 4.627 秒 | 3.951 / 2.948 秒 |

两版本对 effect 的 650 个实际派发步、CEM16 的 572 个实际派发步，动作逐值一致，物理距离和终止标记均在预定容差内。两个方法的配对成功独胜／独负均为 0／0。每个任务各版本独立执行；这些是同任务配对结果，不是独立确认。任务计时从 reset 前到停止后，不包括模型加载、数据打开、预先准备目标图张量及保存结果；规划计时同步 GPU。这是单次同机交错测量，不能宣称统计显著的成本优势。

## Effect 计划分歧

effect 的 6/40 个任务出现完整计划或来源不同，故缓存**尚不能认证为 effect 全计划等价**。对所有六个任务的首个分歧，在相同真实 RGB、旧尾和种子下进行[事后重算](PC_RGB_CACHE_EFFECT_DIVERGENCE_PROTOCOL_20261107_CODEX.md)：

- 六次保留前缀均一致，首个分歧的实际前五步均一致；其中三次未执行尾部不同，另三次完整动作相同但候选来源不同。
- 原始选择的最低和次低时序分数间隔分别为 0、0、约 1.53e-5、0、0、约 3.81e-6；对应评分数组两路径最大绝对差不超过约 9.16e-5。这与极近并列下的数值排序变化一致，但不证明其余输入或不同硬件上仍会保持相同派发。
- 三个不同尾部都进入之后的合法旧尾处理；本面板后续实际动作仍相同，不能据此推广到其他任务。尤其当中途观测或执行间隔变化时，尾部不同可能重要。

不能把本结果称为“缓存对 effect 全部等价”，也不能直接调整并列容差并将其作为既有结果。缓存对所有基线同样开放，测得的时间差不是行动后果描述的独立贡献。历史数据、模型和代码哈希已绑定，测试 5 项通过；环境仍有 Gymnasium 观测类型警告。PC0–PC5 不改判。
