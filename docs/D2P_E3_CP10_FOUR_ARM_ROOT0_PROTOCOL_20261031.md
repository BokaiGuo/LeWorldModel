状态作为目标，使用 `e3_cp10_target_cuda_20261031_RUN01.json`
中的冻结 CUDA 目标编码，不根据后续各臂结果调整目标。
原根、历史、目标像素和物理评价状态均须绑定，物理状态只供
环境成功判定和评估，不输入 RGB 规划器。

执行 structured、native-style、random、immediate-progress，使用
真实 RGB 按其既定时刻重规划；原生成功、截断和画布保护均保持。
如有失败，保留未启动槽和部分结果，不重试或补终点。

成本尚未认证为等总算力，native-style 不是官方强基线。目标
历史见证在第十步成功不保证其他规划臂必然跨越反馈节点。
