# P1 新响应前缀与历史控制：中点反馈配对

将已验收的新前缀现场中点重规划，与历史 zero／greedy 的真实
中点 CUDA 规划及物理重放配对。关联依据是共同根、目标、任务、
条件、动作臂与 33 帧 warmup 状态／快照／图像；各自 cp5 后缀
规划还核验同一冻结模型、Adam 配置与起点字节。中点后缀更新
均为以原第二包初始化的单起点 Adam、20 步、学习率 0.05，
共同计数每条额外 2 encoder、22 predictor、22 action encoder、
20 backward。代码路径计数不是独立硬件计量。

固定 16 槽中 13 条能关联，1、3、5 槽保留删失。其中 5 条是
`model_selected`（响应多样性列表第二候选，不是认证部署赢家）。
这 5 条、对应 zero 和对应 greedy 均无原生成功。物体终点位置
误差在 5/5 条相对 zero 较高，在 4/5 条相对 greedy 较高；
角度、推杆和原生联合位置另行记录，不可仅用位置替代成功。
其余 8 条 incumbent 与 greedy 的终点位置差在此批均为零；
这不是八个独立发现。所有行共享两个已知根。

该结果不支持把这批新候选称为更强的独立后缀规划，但也不能
单凭它判断共同后缀机制：后者面板仍在运行。控制组是已验收的
离线中点规划加物理回放，新候选是现场 CUDA 规划；现场动作与
封存离线动作逐字节一致。总前缀生成成本、端到端预算和独立根
均未认证，不能称公平强基线胜负或 P1 通过。提前原生停止的
固定十步终点和差值保持空值，最后有效状态单独保留。
