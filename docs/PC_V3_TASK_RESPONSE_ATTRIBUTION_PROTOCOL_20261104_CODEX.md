# v3 尾部局部任务响应：封存数据事后诊断

对既有尾部局部干预的全部 24 根及五种前缀，在 `.01/.05` 两种
尺度上使用已保存的同一选中尾部名义动作和中心扰动终点，不修改
计划、不重新筛选根。令目标距离为 `d(x)=||x-goal||`，非零距离时
计算位置中心差分矩阵 `J`、自身名义终点距离梯度
`g=Jᵀ(x-goal)/d`，并计算直接对距离做中心差分的梯度 `g_fd`；
同时报告绝对差和两个向量的范数。距离接近零（`<=1e-10`）时
将梯度置为未定义，不能用不稳定余弦代替。

对每根使用 selected 的负距离梯度单位方向作为共同动作探针，
计算五种前缀各自 `g` 在该方向上的有符号投影、和 selected 的
梯度差范数；另报告所有扰动是否保持原有阻挡分支。该探针是
事后从 selected 构造的局部线性方向，不是实际尾部动作，也不
等同可执行约束下的收益或因果中介。保留绝对距离、原始向量和
数值误差；不定义或重写 PC2 通过阈值。

引用既有事前规划、审计和干预重建哈希；输出独立排他创建。
由于 24 根和见证已暴露，这是事后归因而非新的事前确认，也
不能代替共同尾部、同预算重规划和普通分阶段搜索消融。
