# v3 Reacher 冻结预测重算审计协议

本审计在读取重算结果之前固定：对已封存的两臂、三次决策和所有
trace 批次，重建 RGB 上下文、目标 latent、随机正交 chart，并使用
原 `_terminal_batch` 路径重新编码和预测。逐批比较二维投影和完整
latent 目标 MSE；不修改原结果，不按结果选择批次。

参考路径接收 tanh 之前的参数。先按原适配器将已记录的 float32
原始动作变为归一化 packet，再对边界映射求反函数；只有浮点
舍入造成的不超过 2e-6 的区间偏差允许投影回边界。重建动作与
原归一化动作的最大绝对差须不超过 2e-6。±1 对应无穷参数；
不通过缩小动作来消除边界。其他非有限输入或模型输出均失败。

chart、target、投影绝对误差阈值 2e-5，MSE 阈值 2e-6。
汇报实际最大误差和批次数；任何差错即失败，不放宽阈值。读取并
校验 live manifest 依赖、封存账本及冻结模型参数哈希；输出独立
排他创建。共享模型、预处理和 GPU，不是独立模型或数据复现，
也不能认证模型代理目标的物理有效性。
