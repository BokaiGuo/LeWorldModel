# PushT 冻结第九层：新几何开发面板协议

上一轮在已曝光的 16 根事后观察到 block 9 的真实后继排序优于正式输出。这里先固定 block 9，不再按本面板结果重新选择层。取笛卡尔积：物块中心 `(240,240),(260,240),(240,260),(260,260)`，角度 `pi/8,3pi/8,5pi/8,7pi/8`，共 16 根。旧面板位置和角度分别是 220/280 及 0、pi/4、pi/2、3pi/4；本面板两者均不重复。它们是人为生成的几何开发状态，不代表训练外、来源合格的正式独立任务。

沿用已封存几何实验的接触就绪构造、两种背景、三组五步动作、目标位移/转角、物理检查、pose cost、冻结 RGB 模型及动作 normalizer。先完整采集、记录所有物理合法性与真实轨迹，后进行模型分析；若存在无效根，不删除或替换，先停止自动汇总并报告。不得以模型结果选择根。

主要描述性对比是按根对两个背景及左右两侧的物理遗憾取均值，再比较预定 block 9 的真实后继目标代价选择与正式视觉编码和冻结模型预测选择。报告每根差异、胜/负/平、两种背景、有效根和并列分母。`1e-9` 为并列容差；同时报告物理代价单位和背景不是相机。无独立样本功效或 Gate 通过阈值，不事后修改层或条件。真实后继只用于离线评估，不是 planner 可用输入；该对比不能直接证明可部署收益。

与原面板使用相同模型参数指纹；每阶段独立输出，已有文件拒绝覆盖。绑定本协议、runner、历史物理实现、checkpoint、图像与物理轨迹哈希；任何模型或数据不一致中止。完成此测试后仍需独立检验合法预测路径、真正视角变化和未查询动作，不得直接将真实后继表现接入规划器。
