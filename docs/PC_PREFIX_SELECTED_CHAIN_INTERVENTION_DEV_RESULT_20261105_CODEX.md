# 条件化方法实际选中链的首次计划干预

按 `PC_PREFIX_SELECTED_CHAIN_INTERVENTION_DEV_PROTOCOL_20261105_CODEX.md`
重跑固定 reset 的条件化臂，记录实际选中链及真实动作／完整物理
状态。50/50 任务、1193 个实际执行步的重放 parity 通过，动作和
物理状态最大绝对差均为 0；50 条首次完整链没有声明动作域越界。
之后在同一任务、同一 reset seed 上运行四种预定物理干预。

| 25 步内曾成功 | 条件化选中链 / 50 | 原生均值链 / 50 |
|---|---:|---:|
| 原前缀＋原尾部 | 36 | 36 |
| 原前缀＋零尾部 | 0 | 0 |
| 零前缀＋原尾部 | 0 | 0 |
| 零前缀＋零尾部 | 0 | 0 |

两臂各有 **14/50** 条满足预定的探索性初筛：前 10 步物块目标
位置误差没有改善超过 1e-3、完整链成功、删去前缀或尾部后均不
成功、四条命令链合法。13 个任务两臂均满足、各有 1 个任务仅
一臂满足。原生对照是在看到条件化初筛结果后补做的开发性分析。

条件化臂这 14 条中，11 条前 10 步物块位移不超过 1 个环境坐标
单位，agent 前 10 步位移中位数约 55.77。它们值得进一步检查
接触、可见性和同一后缀的控制条件；但不能仅凭“agent 移动且
删前缀失败”断言发生了所需的接触重配置。删除动作会改变时间、
位置和后续碰撞，未隔离具体因果变量。

事后描述性分析：对这 14 条，比较“同一尾部在原前缀之后的物块
位置误差改善”减去“在零前缀之后的改善”，条件化臂中位数约
37.63、范围 −1.08 至 81.87；原生 14 条中位数约 36.79、范围
−4.33 至 82.54。该量使用成功后继续执行到第 25 步的状态，且
只在已经筛出的链上统计，不能当独立检验或认定差别来自接触。

这些结果不证明条件化组件发现了更多机制链：原生同样找到 14 条；
也未证明这些链在最终重规划后仍保留该机制、作用机会的样本外
预测性、强全链搜索无法发现，或能提供等资源性能优势。更不能
将此开放环干预等同于 50 步闭环成功。PC2–PC5 不改判。
