# 行动后果同探针端到端开发比较协议

本协议在运行前写入，属于已暴露 E0 任务的开发实验，不是独立确认或 PC3。目标是检查固定候选诊断中的结果能否在实际递归选择、完整链优化和弃权后兑现。

## 方法与对照

沿用同一递归核心、全局候选库、两槽 beam、即时 greedy 保护、候选预筛、优化器、incumbent 与最终弃权。在有剩余尾部时，预筛候选使用共同随机 A 后缀库：零尾加八条固定种子正态有限动作，`default_rng(20411000 + 100 * tail_length)`，尺度 0.35、裁剪到 `[-0.5, 0.5]`；每条完整动作序列正常计费。最后一层剩余长度为零，不生成后续探针。

四个递归臂形成 2×2 开发对照：

| 候选方向 | 探针最低绝对代价保留 | 任务约束下的后果互补保留 |
| --- | --- | --- |
| 随机方向 | random_min | random_effect |
| 谱方向 | spectral_min | spectral_effect |

每层都保护即时 greedy 槽。`min` 从已探针、非 greedy 候选选绝对总代价最小者；`effect` 只在探针最小代价不超过该层已测最小值 0.05 的已测非 greedy 候选中，选择相对已测 greedy 的标准化后果向量距离最大者；greedy 未测时，以已测最小代价者作为参考。如果合格集合为空或不足以比较，回退到相同 `min` 规则，记录回退。这个阈值是开发假设，不是物理可行性证书，后果差异也不等于收益。

全部递归臂共享同一探针成本，但不同保留导致后续候选不同。global CEM 按现有对照实现运行，并可使用不必支付递归探针的预算。其后应补充合适强基线和真实完整成本，不能以 token 计数替代墙钟/GPU/内存。

## 面板和报告

使用现有 `pc_retention_equal_slot_cost_dev` 的 16 个任务作为事前指定开发面板，不宣称新任务或来源独立。各方法限制 2880 prediction tokens，统一真实调用 journal、初始全局库、评分、动作域、反馈设置和合法输入。每 root、方法报告实际返回完整链得分、成功（终距 `<0.05`）、完整调用 tokens、墙钟和失败；失败不从分母删除。主要开发比较为同方向下 effect 相对 min 的 root 配对结果；同时报告 global CEM。预算、样本量与效应未满足独立确认合同，不得声明 PC2/PC3 通过。

保留所有根及分支记录。token 是受控预算代理，不是完整系统成本。后续必须独立审计选中动作和预测、完整资源、来源及真实 RGB 执行。
