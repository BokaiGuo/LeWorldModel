# V5 Reacher 已保存 RGB 上下文接线诊断

在已暴露的 v3 Reacher 首轮真实 RGB 上下文复用 v4 已有模型加载、动作归一化和预测器，以 `v5.decide("response", "response", ...)` 原样调用固定 v5 核心；通过仅适配函数签名的单进程包装器运行，使用 15 步、1920 token、同一冻结 checkpoint 与二维 chart。完整缓存预测、原始及 float32 动作、选择、精修和成本，封存包装器、v5、v4 响应、优化器及输入哈希。使用已有协作 GPU 锁，不物理派发。

随后复用独立参考 rollout 审计全部预测批、选中链、最终弃权和 token 计数。此为同模型、单个已暴露上下文的接线开发诊断；模型分数不是物理收益，不构成 RGB 闭环、PC1/PC4 或独立复现，环境依赖闭包和数据来源仍未完全认证。
