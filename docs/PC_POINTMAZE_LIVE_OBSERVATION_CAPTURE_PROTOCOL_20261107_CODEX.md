# PointMaze 现场反馈观测封存：开发协议

在已曝光的八个根上重新运行既有 state-assisted 反馈算法，使用完全相同的
初始计划、随机流、候选评分、动作时钟与物理环境。原结果和原运行器不得修改。
包装器在每次实际环境返回时复制 RGB 和 proprio，记录前四次重规划实际使用的
观测，以及最后一次动作后的观测。逐帧哈希包含形状和 dtype；另封存无损数组。

运行器先检查输出不存在，再执行既有逻辑；现场观测另存，独立审计逐根逐轮
检查现场 proprio、图像哈希、候选评分、选择和已派发动作。对比历史反馈记录：
评分最大绝对差、选中索引、真实末距均逐项报告，不以近似一致证明历史原始帧
与本次逐像素一致。模型加载、输入权限、时钟和冻结校验沿用原运行器。

这是已曝光任务的工程复现，不是新方法比较、独立验证或整任务等成本实验。
PointMaze 使用 RGB 和完整 proprio，只能标记 state-assisted，不能提升
RGB-only 轨道或任何 PC gate。若模型结果不一致，保留差异，不能改写历史数据。
