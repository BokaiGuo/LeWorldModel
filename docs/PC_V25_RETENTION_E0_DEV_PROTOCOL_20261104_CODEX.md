# v25 comparable reachability and retention E0 development protocol

Before execution fix eight exact-Wall tasks with starts `(-0.5, ±0.23,
±1.17)` and goals `(0.5, ±0.12)`, rejecting exact overlap with enumerated
prior panels. Broader provenance remains unknown. Each of five arms receives
the same 1920-token cap and the same unprivileged global proposal bank.

The four v25 arms differ only in the declared retention rule: local
reachable-value winner, immediate greedy, feature diversity, or seeded
random retention. All four compute and pay for the same type of successor
probes, but their subsequent banks can differ after the first decision.
The fifth arm is shared-bank full-action CEM and does not pay for response
probes. Each response probe uses packet-constant orthonormal action
coordinates, not the full per-step Jacobian. Probe at least two candidates
including a non-greedy candidate, or skip the selection probe; no single
value is represented as a comparison.

For every layer save the same-bank counterfactual retention sets, response
winner, added and displaced indices, and all complete-chain outcomes.
Record each prediction attempt and its cost before dispatch, then returned
arrays or failure; preserve failure denominators and do not retry a partial
journal. Verify common bank, recorded actions and outputs, tokens, and
alternative same-environment geometry. Report terminal distances, success
under the existing 0.05 threshold, probe counts and the number of layers
where response changes selection relative to diversity. Stop after the
declared eight roots; do not tune on this panel.

This is a development ablation, not a fixed-bank equal-suffix study or PC2
mechanism confirmation. Changed retention does not itself prove useful
reconfiguration; either positive or negative results remain bounded.
