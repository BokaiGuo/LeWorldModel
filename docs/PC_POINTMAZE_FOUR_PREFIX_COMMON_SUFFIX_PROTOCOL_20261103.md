# Four-prefix common-suffix physical intervention

For every exposed root 1888–1895, fix four saved five-step prefixes:
model-greedy, zero, random-CEM and spectral-CEM. Apply each of five shared
five-step suffixes: zero action, and the separately optimized saved tail
from each of the four prefixes. Execute all 160 combinations, including
duplicates, from the same archived reset; no new model inference or
outcome-based choice. Save physical cp5, cp10, actions and terminal RGB.

Verify each terminal position against both position and legacy backends.
Require exact reproduction of all 72 combinations of the preceding
three-prefix/three-suffix panel (actions, terminal RGB and full terminal
state) and the 16 newly added greedy/zero own-prefix own-tail chains (RGB
and full terminal state). For each cell report initial, cp5 and cp10
physical goal distance and change relative to the same prefix's zero
suffix. Compare same-suffix effects across prefixes without treating
positions, shared trajectories or suffixes as independent samples.

The model-greedy prefix is not a physical oracle. A prefix may already
improve position relative to another prefix and zero action may still
move due to momentum; report these confounders. This is a retrospective
development intervention, not independent testing, same-budget method
comparison, proof of reconfiguration capability, or P1 admission.
