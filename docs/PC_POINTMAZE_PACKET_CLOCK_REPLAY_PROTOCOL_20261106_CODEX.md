# PointMaze 动作与时钟合同重放诊断

对已暴露轨迹 1884–1891，分别从记录初态用记录动作 0–14 做真实物理重放，逐环境步对比数据集的状态 1–15。每个环境步执行 5 个 MuJoCo 子步、按上游规则裁剪动作和速度，比较每一步的位置、速度及计时；检查 0–4、5–9、10–14 的规范化拼包和解包。状态绝对误差不超过 1e-4 作为本次初始严格对齐标准；失败应保留误差，不得推断唯一原因或修改训练数据。

同时比较本地 normalizer 与源码硬编码 PointMaze 统计，比较模型装载使用的确定性图像预处理与配置中的预处理（相同 RGB 输入，禁用随机翻转；固定 RNG，报告最大差异及配置）。图像变换不等价不自动意味着旧实验的性能已被修复。

不改变任何规划器，不将数据集未来状态用于在线选择；这是预先限定的工程诊断，不是闭环性能、RGB-only、独立任务或 gate 证据。若发现确定的接口 bug，另行修补并在独立输出复跑；如果时钟合同一致，报告模型预测失配仍未解决。
