# P1 配对分析与公平比较合同

本文件固定后续分析的解释边界，不改写已封存实验合同，也不凭已有结果
设定非贪心阈值、预算值或统计显著性门槛。后续独立确认必须在观察其
结果前另行冻结具体指标、容差、资源上限、样本量和失败处理。

## 三个不同问题

1. **共同后缀干预**：同根、同条件的 selected、zero、greedy 前缀后，
   执行同一动作后缀。比较绝对终态和相对于各自零后缀的变化，判断
   前缀是否改变了该后缀的效果；这不能单独证明可规划能力更强。
2. **独立后缀规划**：各前缀分别以相同优化器、预定统一资源约束
   和相同反馈机会规划自己的后缀。比较真实终态及原生成功，而不是
   把针对某一前缀事后发现的成功后缀当成所有方法的初始化。
3. **完整方法性能**：统计前缀生成、筛选、后缀规划、反馈和执行
   的全部费用，与公平强基线比较；不同阶段的局部相同预算不能替代
   完整方法的总预算对照。

## 即时变化和配对表

每条前缀分别报告物体位置误差、物体角度误差、推杆位置误差、
原生联合指标和原生成功；报告前缀前后的绝对值和差值。物体静止
不等于整个任务没有进展，推杆重新定位本身也可能带来进展。确认
实验必须事先指定“没有即时改善”的具体指标、参照和容差，不得
根据结果替换；描述性分项不自动产生通过判定。

配对键至少包括根和任务身份、条件、前缀角色、实际动作与后缀身份；
重复动作和共享根的行应显式标记，不能计作独立任务。每行保留：

- 前缀即时变化及前后原生成功；
- 每个共同后缀的绝对终态及相对该前缀零后缀的变化；
- 各前缀自行优化后缀的绝对终态、相对前缀及对照的变化；
- 实际执行步数、原生停止、越界、拒绝和删失状态；
- 各方法实际资源分轴和预定预算，并标记未知来源与未认证费用。

第十步发生的真实成功可另报观察值；不得回填旧合同中已封存的
空终点。提前停止或无图像时不得构造未观察终点。

## 预算

预先统一资源约束和反馈机会，使基线可以使用结构生成占用的预算。
不要求方法消耗完整额度或人为凑齐调用数。编码、预测、反向、
Jacobian/SVD、候选筛选、实际耗时和物理交互分别报告，不能将不同
调用类型未经事前规定换算直接相加；报告各预算点与实际消耗。
若成本无法完整核验，标记未认证，不得称等预算。

## 已有结果如何使用

现有 [24 前缀连接表](../le-wm-main/results/codex_p1_guard_mechanism_join_20261030_main_RUN01.json)
包含即时变化、42 个共同后缀、独立规划与反馈结果，以及身份和
停止信息；它是两个已知根上的描述性探索，存在重复和未认证总费用。
共同后缀第十步成功的原始逐步观测与封存空终点应分开阅读，见
[十步结果](D2P_P1_H10_INITIAL_RESULTS_MAIN_20261030.md)。

已知根 0/on 的 selected 前缀物体位置和角度不变，但推杆误差变化，
不能据此断言整体任务没有即时进展。该实例的共同原后缀曾成功，
但后缀已知 outcome；其作用是定位搜索问题，不是事前选择的性能证明。
独立规划结果和反馈结果仍不构成 P1 通过，且尚无独立确认或完整
等预算认证。
