# 响应方向与匹配随机方向：固定尾部机会的事后诊断

对已停止的 16 根束宽开发面板，读取 1,920 token 窄束 v25 的已封存首层候选，不重跑原规划。每个响应候选保留其 nominal、候选索引及动作扰动 L2 范数；以根和候选索引生成独立高斯方向，归一化至相同 L2 范数，再按动作域截断。零扰动 nominal 保持不变。记录截断后实际 L2 范数和候选动作；不宣称坐标分布、逐坐标幅度、组合结构或实际范数完全相同。

两个库候选数量和候选索引逐一对应。每根生成一组共同的 8 条均匀随机尾部（额外含零尾）和一条共同随机优化起点，分开使用独立随机流。先对两库全部前缀评分、评价共同尾部，封存两个两槽保留规则：按即时评分 top-2；即时第一加普通 lookahead 的非重复最佳候选。随后每个前缀用相同随机起点、相同 CEM 种子及 49 条完整链样本优化。报告每库的 all-bank 最佳（特权诊断上界，不是可部署选择）、greedy 和 lookahead 对应最佳值、成功与库内保留损失。所有候选均来自规划输入或随机生成，不注入几何见证。

逐批持久化动作、评分与预测 token；按阶段报告首层响应差分在原始已封存日志中的 token 和 SVD 次数、新增候选评分、lookahead 与统一优化的 token。原运行全局候选和其他层成本另列，不得把本诊断预算当完整方法成本。原任务已经暴露，实验仅为事后生成覆盖／保留诊断，不是正式方法、PC2 或 PC3；失败记入 16 根分母，不换根或调整阈值。逐批确定性重放、校验原响应候选、另一同环境几何与评分及固定预算；结果不构成独立复现。
