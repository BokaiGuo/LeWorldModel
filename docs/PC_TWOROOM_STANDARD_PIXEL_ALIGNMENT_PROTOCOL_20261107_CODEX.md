# TwoRoom 标准参考面板：图像与环境状态对齐检查

对已封存的 seed-42 参考 50 行，使用数据集的 `pixels[t]`、`pixels[t+25]` 以及 `proprio[t]`、`proprio[t+25]`。环境 reset 后按本地评测配置设置数据初态和目标，分别比较数据图像与环境渲染的当前图像、目标图像。逐根记录像素绝对误差、非零差像素数、最大差、图像指纹和红色通道加权中心；未发现红色证据或红色中心不可解释时不声称定位成功。

50 根全部保留。环境 geometry 取默认 reset 的实际值并记录，目标图像使用环境生成的 `_target_img`；同时记录数据集中 `proprio` 与 `pos_agent` 的差异。结果是已暴露开发面板上的观测合同诊断，不改变官方式评测，不使用状态辅助规划、不进行算法比较；像素差异本身不证明物理状态错误、模型错误或控制失败的因果来源。两种图像都没有充足红色证据时中心不适用，不能把它记为匹配。
