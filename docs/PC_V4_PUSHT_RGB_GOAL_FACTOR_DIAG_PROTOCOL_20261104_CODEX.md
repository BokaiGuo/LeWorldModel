# PushT RGB 目标距离：已执行边界的受控图像因子诊断

针对已暴露 episode 0 的两条已完成轨迹，固定两臂各四个已保存边界（共八条记录，共同起点仍分别记录）。使用物理状态仅在独立诊断环境中生成四个静态图像：原边界、仅推杆位置替换为固定诊断目标的推杆位置、仅物体位置和角度替换为固定目标物体姿态、两者同时替换。速度原样保留，不执行动作、不做规划，也不把物理状态或反事实图像作为方法输入。

每个组合通过官方环境的 reset 和 renderer 生成；逐项核对重置状态与所需七维状态、固定目标及图像尺寸；原边界图必须逐像素匹配原实验保存的最新 RGB。若上述合同不成立，记录失败，不将分支结果用于判断。保存每张图像哈希及状态，不把同时替换解释为可达控制轨迹；被替换后的物体和推杆可能相互遮挡或发生几何重叠，图像因素存在交互。

固定冻结 checkpoint 的同一 encoder、相同预处理及原目标图像，输出四图到目标 latent 的逐维 MSE，计算原→推杆替换、原→物体替换及二者差分交互，不把这些差异解释为像素独立归因。校验原图目标 MSE 与先前实际编码诊断的相同边界一致（绝对误差 2e-6），并验证完整模型参数和 buffer 不变。

该实验仅检验声明的全 latent MSE 在这些具体静态图像上的敏感性，并非模拟真实动作或规划结果，也不能说明目标替换可被合法短动作实现、模型预测是否准确、数据独立或 PC gate 通过。不得依据这八条事后记录调整原目标或宣布替代评分更优。
