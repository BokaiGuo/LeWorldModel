# TwoRoom 原链保留搜索：RGB 反馈开发冒烟协议

实现在线、定长剩余时域、原链保留的搜索，并在已曝光根 10–13 上做端到端开发检查；该面板不是独立确认。每次规划用当前 RGB、目标 RGB、合法旧动作尾部和冻结 LeWM；真实状态只用于评价端重置和记录。各臂相同动作域、5 步执行间隔、25 步任务上限、观测与终止权限。

每次规划共同生成 300 条块动作 CEM 链（3×100、10 elite）及 300 条块随机链，旧尾合法时参与 CEM 初始候选；完整来源中最低模型代价链必须进入最终竞争。剩余时域大于 5 时，按预定规则从两池分别选取四个不同前缀，计算共同 A 库 64 个后续链并按 lookahead 或中心化后果向量保留两个前缀，再计算各自 B 库 16 个链。最终选择全部 600 个原候选、64 个 A 和已查询 16 个 B 中模型最低者。对照为 600 条相同基础候选加 80 条独立随机块链，同样保留最优，共 680 条评分；lookahead 与 vector 也各为 680。最后只剩 5 步时所有臂均使用同样的 600+80 原链搜索。成本以候选数、模型包步、批次、同步规划时钟及真实步数分别记录；等候选数不等于等墙钟。

先在受控 scorer 上验证 incumbent、预算、确定性、动作界及旧尾；再用 GPU 在固定根上真实重规划。所有臂各自在自己的真实后继重新观测、重新规划，不共享另一臂的物理状态或真实后果。记录完整派发动作、决策及反馈。冻结权重指纹前后一致。报告逐根曾成功和成本；仅 4 个已曝光开发根，不作显著性、优势或 gate 通过声明。若本版本无增量，不扩大同一配置来争取阳性。
