# RGB 搜索区域后继表示 JVP/VJP 开发核验

运行前冻结。复用 `PC_RGB_SEARCH_REGION_MULTIHORIZON_DERIVATIVE_PROTOCOL_20261107_CODEX.md` 的 4 个已暴露任务、截断内点动作、5/15/25 环境步、每时域两个单位物理动作方向及数据集 RGB 输入；不是原始边界动作或真实反馈观测。使用完全相同的冻结 checkpoint 和动作归一化器。

对同一候选的预测末时刻完整表示，计算动作坐标 JVP，并以 0.001、0.002、0.01 的中心差分逐元素比较；记录向量 L2 误差、JVP 和差分范数。每尺度的开发数值判据为 `L2误差 <= 0.01 + 0.02*||JVP||₂`。另以固定种子的单位随机表示向量计算 VJP，检查 `u·Jv = v·Jᵀu`，开发判据为绝对差不超过 `1e-4 + 1e-4*|u·Jv|`。阈值只用于本次诊断，不是正式 PC1 标准，也不追溯修改历史实验。

检测失败和求导不支持都须保留，不改权重或把物理真值输入模型。记录输入、原动作记录、runner、协议、模型及 normalizer 指纹，结果排他创建。本实验仅验证模型内部导数计算，不证明物理预测可靠、谱方向有效或任何 gate。

首次实际运行在第一个样本的 JVP 报错：默认 `aten::_scaled_dot_product_efficient_attention_backward` 不支持所需二阶求导，未生成结果。运行前修订：在局部作用域强制 PyTorch math SDPA 执行 JVP、VJP 和差分，同时对每条名义动作记录默认后端与 math 后端的表示及目标分数差；表示最大元素绝对差须不超过 1e-4、分数绝对差须不超过 1e-3，否则拒绝把后端视作近似一致。该修订发生在任何完整样本结果产生前；后端前向相近仍不证明其他设备或所有候选等价。
