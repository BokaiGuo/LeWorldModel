# 已封存固定前缀 CEM 轨迹重建协议

这是对已观察结果的后验工程审计，不执行新规划、改动旧协议或扩展样本。
输入是固定前缀诊断封存的 144 次搜索及其审计。对每次搜索，以原根随机种子、
初始均值零和标准差三分之一，逐批重建 12 个裁剪动作，验证其与记录动作相同；
以记录分数稳定排序前 4 个精英，重建下一批均值与标准差（下限 `1e-5`）。
若任何批次、前缀、评分封存哈希或源依赖不匹配，审计失败。

记录第 1、8、16、32 批采样前的标准差中位数、最小值及小于 0.01 的坐标比例，
和每批精英分数、incumbent。对特权解析前缀，额外记录可行原后缀相对对应
采样分布的坐标标准化距离的中位数和最大值。这些仅为边界诊断，不把某个
后验发现归因于唯一原因，也不将标准化距离等同于成功概率；裁剪会影响分布。
聚合时以根为单位，五步、十步见证单独报告。完整轨迹及重建摘要绑定输入与
代码哈希；不覆盖已有文件。
