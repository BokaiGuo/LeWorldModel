# P1 多起点后缀：同时间真实 RGB 误差诊断

对已完成验收的 24 条多起点后缀轨迹，使用封存的停止状态固定
纳入所有 `probe_completed` 且走满十步的轨迹；原生早停及删失
保留为缺失，不取最后帧假装十步终点。读取对应十步 RGB 并校验
物理报告、图像和像素哈希、规划动作与根/前缀绑定，再用同一
冻结模型在主机 CUDA 编码真实观测，计算实际编码到目标的 MSE。
同时保留原模型十步预测分数、物理位置角度与成功指标。

同一逻辑臂的 selected 和 zero 只有双方均有十步终点时才能
比较预测与真实编码排序；对早停臂只报告成功和停止时间，不
制造同时间排序。此诊断在物理结果后制定，是已知根探索，不是
独立确认、能力干预或 P1 gate；真实 RGB 不参与原规划选择。
