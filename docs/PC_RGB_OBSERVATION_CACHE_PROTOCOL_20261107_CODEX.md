# RGB 规划内观测编码缓存：等价性及成本开发协议

既有在线搜索每次规划有 25 次模型评分调用，同一调用序列的当前图、目标图及动作历史不变；原 RGB 边界每次复制输入后调用上游 `get_cost`，导致每次重编码这些图像。本实验只在一次规划内复用首次由上游生成的当前与目标 embedding，不跨规划、环境、历史或 checkpoint 复用；每次核验全部输入的形状、dtype 和内容指纹，任何变化 fail closed。缓存只在冻结、eval、inference 模式有效，不缓存动作预测、不修改动作、权重或评分函数。

在已保存的四根、三臂全部 57 次决策上重建真实 RGB 及历史，使用相同种子分别运行原始和缓存边界；对每个候选比较分数（atol 1e-4、rtol 1e-5）、最终动作、保留、真实执行轨迹；同时用编码器钩子计数，分别同步计时包括缓存构造与检查的整次规划。若候选排序或动作不同，标为不等价，不宣称效率收益；微小数值变化即使未翻转也如实记录。结果为已曝光开发轨迹及同模型重放，不是独立控制或 PC gate 确认。实际时间仅针对本机同期测量，不泛化到其他硬件或任务。
