# PointMaze 单动作包执行合同诊断结果

本次在 GPU 上重放了已曝光的四根、两个视角、四个固定动作，
共 32 个条件。模型使用完整 proprio，属于 state-assisted 轨道。

- 数据集的 2000 条轨迹计算出的动作与 proprio 均值、标准差，
  与本地 JEPA 仓库 `DATA_STATS["pointmaze"]` 完全一致。
- 每个动作包的手工归一化与模型 `Preprocessor.normalize_actions`
  一致；传入的原始 proprio 经编码器内的归一化路径处理。
- 权限包装器输出、同一模型 `encode + unroll`、单步
  `forward_pred` 一致；32 条预测与先前封存预测最大绝对差为 0。
- 单帧上下文及单动作包调用中，输出第 0 项等于输入编码，第 1 项
  等于底层单步预测。动作包到五个环境步的物理对应关系依赖此前独立的
  物理时钟回放，不能由本次张量比较单独证明。
- 平均逐元素均方误差：预测对真实后继编码为 0.45454，当前上下文
  编码对真实后继编码为 0.12624。这说明固定面板上直接沿用当前编码
  在此指标更接近后继；不自动说明它能更好选动作或改善闭环。

测试为 `3 passed`，其中包括重新计算封存面板中模型与真实编码
选同一动作仅 1/8 的现象。该症状测试不等于已发现代码错误。
模型权重在本次运行前后指纹一致。
