# TwoRoom RGB 实际派发链的前缀干预

## 范围与合同

对已曝光 40 个 TwoRoom 任务，固定 effect 臂真实闭环的整段派发动作；该链由多次反馈重规划拼接，不声称是首次规划时就完整选中的程序。对其中有至少 5 步派发动作的任务，替换首 5 步，比较原 effect 前缀、同初态 lookahead 首次计划前缀、零动作和固定种子随机常值前缀。

5 个任务原链短于 5 步（其中 3 个初态已成功，另 2 个在 3、4 步成功），均保留记录，不制造额外动作或进入五步干预分母。其余 35 个任务均非初态成功；原链的 35 次物理重放与记录的距离和成功标记一致。

共同尾部使用 effect 实际派发链的第 6 步起相同动作；因而是对**实际派发链**的固定尾部干预。等预算重优化则是在各前缀后的真实 RGB 上，用同一冻结模型、同一 seed、无旧尾的 CEM16 重选 20 步尾部；这产生新链，不能冒充原链机制。共运行 140 次规划、2,240 条模型候选评分、8,960 个模型 packet 步。前缀已成功的情况仍做诊断规划，但不当作后续机会收益。

## 结果

| 前缀 | 前缀内曾成功 | 共同实际尾部曾成功 | 等预算重优化后曾成功 |
| --- | ---: | ---: | ---: |
| effect 实际 | 2/35 | 27/35 | 20/35 |
| lookahead | 2/35 | 26/35 | 20/35 |
| 零动作 | 0/35 | 11/35 | 18/35 |
| 随机动作 | 1/35 | 10/35 | 14/35 |

共同尾部下，effect 相对 lookahead 独胜/独负为 1/0，相对零动作为 16/0。等预算重优化后，effect 相对 lookahead 为 0/0，相对零动作为 7/5。effect 与 lookahead 的前缀在 **33/35** 个任务完全相同，故这组对照对区分两种策略的机制能力很弱。

排除 effect 前缀内已成功的 2 个任务，剩余 33 个任务中，共同尾部成功分别为 effect 25、lookahead 24、零动作 11、随机动作 10；重优化成功分别为 18、18、16、13。以第 5 步目标距离衡量，effect 前缀有 15/35 次不比零动作更接近目标；这不是完整的非即时进展证明。

## 证据边界

固定实际尾部依赖原前缀，不能单独证明重配置：不同前缀可能只是把执行者带到不同位置，导致同一尾部不再适用。等预算尾部重优化缩小了与零动作的差距，但各臂物理后继不同，结果不证明它们具备相同机会。尚未对这些同链案例测量真实动作后果向量、被动运动和 greedy 控制；也没有独立任务及描述发现贡献。故本次不能通过 PC2 或说明 effect 优于普通 lookahead。

这是已曝光任务上的开发分析，不进行显著性或非劣效声明。规划器只接收当前/目标 RGB、合法动作上下文与冻结模型，物理状态仅用于评估 reset 和指标；该实验不改变 PC0–PC5 状态。相关单元测试 **14 项通过**。
