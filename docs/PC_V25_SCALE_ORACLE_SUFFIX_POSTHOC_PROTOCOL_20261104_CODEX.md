# v25 幅度面板：固定特权后缀诊断协议

输入是已审计封存的两臂 8 根开发计划和事后几何见证。对每臂首层自动生成的每个候选前缀，分别拼接该根两条成功见证的最后 10 步，使用原来的 exact-Wall 动力学和 `<0.05` 终距标准评价。相同两条后缀用于该根所有候选，评估按批持久记录，含失败及费用；不优化后缀，不将特权后缀注入编译器。

固定候选库内分别报告全部候选及原搜索中 greedy、diverse、response、random 保留集合的最佳完整链和成功情况；记录 response 相对 diverse 的增删候选。只比较每臂自身生成库；不同臂的首层库可以不同。重算每个动作序列并用另一同环境几何实现核对，且确认原选择与见证源哈希。

该事后实验只测有限特权后缀族对前缀的条件有效性：无成功不证明没有可行后缀；有成功也不能证明共同优化器能够发现该后缀或正式方法发现了程序。它不是等总成本方法比较，也不是 PC2 或 PC3 通过证据。
