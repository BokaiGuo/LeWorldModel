# 精确墙障：预测轨迹驱动的程序阶段修正

## 动机

上一轮的后继条件组合按自由空间计算的段时长判断中间点是否完成；即使该时间点的预测位置被墙阻挡，也会进入目标段。该行为违背“已到达中间点才进入下一段”的阶段语义，但旧试验确实声明了这一规则，其负结果和停止决定保持不变。

## 预定比较

沿用上一轮 24 个已暴露任务、每根 192 条完全相同的五步前缀、模型、动作域及预算。新规则仅改变阶段判断：若名义中间点段在五步内结束，查看已查询五步预测轨迹中该结束时刻的位置，只有与中间点距离不超过 `1e-9` 才进入目标段；否则仍以中间点为先生成剩余尾部。名义时长超过五步也继续中间点；中间点距离阈值仅处理此 exact-dynamics 路径的浮点数误差，不适用于视觉 latent 状态。检查已有预测轨迹不新增动力学查询。每条完整链从初态重新评分并实际选择最低末距候选。

与上一轮阶段判断臂比较，均按每根 `192×5 + 192×15 = 3840` 动力学步计费；再次报告先前 256 条原 waypoint 基线，仅作为相同动力学步数的参照。不得用物理成功标签、墙坐标、真实后验轨迹或未查询未来信息选择动作。输出所有链、模型代价、阶段判断和动作来源；仅以最终选中链计成功。

在结果生成前固定开发出口：修正臂相对旧阶段臂成功独胜至少 3 根且独负最多 1 根，同时不低于 256 条原 waypoint 基线的成功数。否则停止该阶段修正规则的开发扩展；即便达标也仅允许后续设计不依赖精确状态且完整计费的开发实验，不通过任何 PC gate。报告动作与评分变化以及旧臂名义完成却预测未到达的候选频数，不把多个候选视为独立任务。
