# 固定前缀 CEM 采样坍缩及方差下限干预

## 重建与干预

对既有 24 根、144 条固定前缀搜索的 4,608 个批次，按
[重建协议](PC_RGB_SUCCESSOR_EXACT_CEM_TRACE_RECONSTRUCTION_PROTOCOL_20261103_CODEX.md)
重新生成随机动作、稳定排序精英并重建分布；所有记录动作与随机流逐项一致。
已知可行前 5 步分支的坐标标准差中位数（先在各根取坐标中位数，再跨根取中位数）
在第 1／8／16／32 批采样前分别为 `0.33333 / 0.01821 / 0.000914 / 0.00001`。
第 16 批前，平均 96.7% 坐标的标准差小于 0.01。该观察表明搜索分布快速收缩，
不单独证明收缩是失败的唯一原因。

随后按[事前干预协议](PC_RGB_SUCCESSOR_EXACT_CEM_VARIANCE_FLOOR_DIAG_PROTOCOL_20261103_CODEX.md)
仅将标准差下限由 `1e-5` 改为 `0.05`；前缀、每根随机种子、样本数、
动作域和其他更新规则保持一致。旧臂复用已封存结果；新臂进行了 144 次
搜索、55,296 次完整链评分，并逐条重新执行随机流与精确动力学。
这是暴露根上的单一工程诊断，不是正式方法性能比较。

## 结果

每项按 24 根报告，成功阈值 `<0.05`；192 与 384 为同次搜索的嵌套截面。
下表是 384 次时的结果：

| 固定前缀 | 原下限：平均终距 / 成功 | 新下限：平均终距 / 成功 |
|---|---:|---:|
| zero/zero | 0.62860 / 0 | 0.51346 / 0 |
| zero/svd_0 | 0.54696 / 0 | 0.50487 / 0 |
| svd_0/zero | 0.54696 / 0 | 0.50487 / 0 |
| svd_0/svd_0 | 0.54740 / 0 | 0.50735 / 0 |
| 特权见证前 5 步 | 0.54758 / 0 | 0.27711 / 8 |
| 特权见证前 10 步 | 0.02734 / 21 | 0.00122 / 24 |

192 次时见证前 5 步两臂都是 0/24，前 10 步分别为 21/24 和 23/24；
四条自动前缀均为 0/24。384 次时，四条自动前缀按每根事后取最佳的平均
终距由 0.53375 降到 0.50168，成功数仍是 0/24。该事后最佳并非方法选中链，
每根消耗四次前缀搜索，不能当作规划成绩。

在已知可行的五步前缀上，保持更大的搜索尺度使 8 根找到成功后缀，说明原
方差策略确实限制了这一具体配置下可发现的解；它不是动作时钟或评价错误的
证明，也不意味着下限 0.05 是最优配置。四条自动前缀仍未成功，候选覆盖、
有限预算和其他搜索限制不能排除。见证利用特权几何且固定前缀长度不同，
绝不能拼成 PC2 自动发现或 PC3 优势证据。
