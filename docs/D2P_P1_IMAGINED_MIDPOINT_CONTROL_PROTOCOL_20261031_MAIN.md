# P1 中点信息的匹配优化对照

在观察真实中点反馈物理结果后，对全部相同 24 条固定轨迹
建立事后开发对照：原 cp5 RGB、第一动作包、第二包初值、Adam
20 步、学习率、动作约束、原包回退和真实物理执行均与真实
中点反馈相同；仅将第二次规划的中点 latent 改为从 cp5 及第一
动作包由冻结模型预测得到的 latent，不使用真实中点编码作为
规划输入。固定物理名单和动作不按结果筛选。

两臂各自的中点生成计算不同：真实臂编码真实 RGB，想象臂增加
一次 action encoder 和 predictor；各自分类记账，不宣称等 FLOPs
或全流程等预算。须验证与原物理轨迹前五步完全相同，按原生
停止状态比较物理结果；无十步终点时保持缺失。这个单因素
对照定位在该固定算法和已知根下中点来源的影响，不证明理论、
独立泛化或 P1 通过，也不证明无其他代码/协议误差。
