# 行动后果参考动作的物理语义合同

行动后果向量可相对任何合法、等时长的参考动作定义；参考为零动作
不自动说明状态保持。新接口默认只声明 relative-action reference。
若要称为 position hold，诊断端必须提供同一 root、同一动作与时钟的
完整逐步位置轨迹，且所有时刻相对初态的欧氏位移不超过预定容差。
此见证只覆盖记录的状态、位置维度和动作时域，不证明速度、姿态、
接触或其他状态保持，也不自动推广到附近状态。

复核既有 PointMaze 原生模拟数据中的八个状态、零动作 5 步，
位置容差固定为 `1e-6` 物理位置单位。数据和动作定义绑定既有
报告、审计和原始文件哈希；先用完整轨迹判定，再独立记录初始速度
与最大位置漂移。本实验是已曝光数据上的合同修复与检查，
不重做模型预测，不改变已有结果或任何 gate。
