# dev305 两包候选：预测、真实 RGB 目标度量与物理任务分解

对先前固定的三个前缀、17×17 两包候选，按封存动作和 seed 重新执行
全部 867 条物理轨迹，逐步检查动作、状态、奖励和终止标志，并采集每条
真实终态 RGB。全部重放成功。冻结模型在主机 CUDA 对 867 张终态图和
目标图逐张编码，共 868 次 encoder/projector 调用；模型参数哈希不变。
真实后继仅作事后 oracle 评价，不进入部署选择器。

对同一候选库分别选择模型预测 latent 目标距离最小、真实后继编码目标
距离最小，以及真实原生奖励最大的动作：

| 前缀 | 模型选择：原生奖励 / 物体位置误差 | 真实 RGB latent oracle：奖励 / 物体位置误差 | 物理奖励 oracle：奖励 / 物体位置误差 |
| --- | --- | --- | --- |
| candidate_02 | -525.699 / 152.285 | -484.386 / 270.567 | -286.844 / 249.814 |
| candidate_00 | -527.686 / 150.584 | -569.384 / 265.077 | -286.305 / 249.814 |
| zero | -632.038 / 221.150 | -569.391 / 259.549 | -281.671 / 249.814 |

该表修正了只按原生奖励理解上一轮结果的风险：**模型选中的动作虽然
奖励更低，但三个实例的物体位置误差均小于物理奖励 oracle**。这不等于
原生任务成功或 P1 通过；推杆状态和速度也属于原生评价，且模型动作发生
的物体运动不证明其由重配置能力变化所致。

对 8,670 个已封存物理转移独立复算，环境原生奖励等于七维状态与目标的
负 L2 距离，包含推杆、物体、角度和速度；成功条件使用推杆与物体的四维
位置差以及角度阈值，不使用速度。复算的原生成功数为零，最大奖励误差
不超过 1e-9。不能事后以物体位置替换原先实验的正式成功指标。
