# dev305 真实反馈点的 RGB 几何候选覆盖

在已知开发根的三个实际反馈点上，从当前 RGB 提取推杆到物体最近可见
边界的方向，事先固定向该方向、反方向和零动作三种五步动作包。
几何方向及动作选择不读取模拟器状态；状态仅用于复位后逐步精确重放
和执行后评价。当前 RGB 均通过既有可见性检查。该单包几何探针没有使用
世界模型或谱结构，不是 D2P、强规划基线或独立确认。

九条分支各执行满五步、无原生成功。真实物体位置变化、终态目标误差及
既定可见性检查如下（距离为环境状态单位，角度为弧度）：

朝物体分支在该面板中改变物体姿态，但都破坏后续 RGB 可见性，且没有
完成原生任务；仅凭物体位移不能宣称任务成功或重配置机制。零动作

归因于新动作。该执行器未记录接触点，不能把位移当成已验证接触事件。
三组反馈点来自同一开发根，不能视为三个独立任务。
