# P1 RGB 推杆修正与模型动作混合：开发合同

已知根的探索性消融：在同一固定 24 行、同一前五步和中点 RGB 上，
对视觉分割有效且推杆距离超过原阈值的行，执行
`0.5 * 模型后缀 + 0.5 * 五步同向 RGB 修正`，逐元素以 float32 计算。
两项动作均在 [-1, 1]，凸组合不需要裁剪；其余有效行使用模型
后缀，视觉失败仍拒绝，原生停止后不得继续。比例固定，不调参挑行。

目的只是测试能否兼顾先前五脉冲的推杆接近和模型动作对物体的控制；
该 RGB 启发式不是动力学编译程序，也不是安全保证。规划器不得读取
物理真值；真实状态仅用于执行评价。结果与已保存模型、五脉冲在
相同身份／中点下逐行比较，物体位置、角度、推杆、原生成功和停止
分别列报。此开发设计制定时已看过旧结果，不能声称独立确认、
公平总预算、P1 机制或强基线胜出。拒绝和原生停止保留分母。

## 主机 CUDA 与物理执行结果

24 行均记录且通过保存态消费：21 行执行混合动作并完成，3 行因
视觉分割失败拒绝；原生成功 0 条。两个对照均逐行核验共同前五步
动作、状态、快照及中点 RGB，24/24 匹配；21 行均有可比较端点。
下面是混合版减对照版的误差均值，负值表示更低：

| 指标 | 对原模型包 | 对五脉冲 |
| --- | ---: | ---: |
| 物体位置 | +6.1514 | -3.9027 |
| 物体角度 | +0.09525 | -0.06874 |
| 推杆位置 | -6.9955 | +1.3827 |
| 原生联合位置 | -2.7274 | -0.0427 |

相对原模型包，19/21 行推杆误差降低，但物体位置仅 4/21 降低、
角度 0/21 降低。相对五脉冲，13/21 的物体位置、17/21 的角度
降低；五脉冲原有的两个成功记录在混合版均消失，它们是同一
重复轨迹而非两个独立实例。此结果不支持该混合规则作为当前
面板的成功修复，也不应把局部指标改善解释成 P1 成功。
