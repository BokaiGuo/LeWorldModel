# TwoRoom 共同尾部与后果向量保留结果

按[协议](PC_TWOROOM_COMMON_TAIL_RETENTION_PROTOCOL_20261107_CODEX.md)，
40 个已曝光任务分别使用 13 个 RGB 前缀、5 条 A 尾部（含零动作参考）
及 4 条未参与保留的 B 尾部。GPU 离线评分完整矩阵后，保留器只读取
A 评分，各臂只从保留前缀的 B 评分中选链；随后物理重放全部
40×13×9 = **4680 条链**、每条 25 步。

| 保留策略 | 实际选中链曾成功 | 被保留的 B 库可成功前缀 |
| --- | ---: | ---: |
| 普通 lookahead | 40/40 | 80/80 |
| 后果向量多样性 | 40/40 | 78/80 |
| 任务内向量身份打乱 | 40/40 | 75/80 |

普通 lookahead 与描述臂的保留集合在 35/40 个任务不同，最终选中
完整链在 6/40 个任务不同，但没有形成成功率增量。三臂选中链在
前 10 步均未曾成功；这排除了“选中链已在此前成功”的简单解释，
**不证明重配置机制**，因为尚无共同尾部替换、同预算重优化等
反事实干预。B 库有成功前缀的任务为 40/40，且 lookahead 两个
槽位均为可成功前缀，存在明显保留天花板。

因此，这个固定描述构造在此候选池中**没有显示超过普通 lookahead
的独立实际收益**；不应扩大该固定配置进入确认。任务内打乱并非
跨 root 打乱，不能代替所有描述负对照。四条 B 尾部未用于 A 留存
决策，但离线全矩阵已实际查询 B；不是未查询动作预测或独立泛化证据。

每个任务实际离线评分 117 条完整链、585 个模型 packet，物理重放
117 条链。根据固定候选重算，各臂若只评分 A 与保留的 B，概念上
需 73 条链、365 个 packet；本次**没有实际执行这个精简查询流程**，
不能宣称其延迟或数值决策等价。GPU 分批为 32 条；同结构各臂共享
同一实际全矩阵评分，不是完整计算成本曲线。

动作界限、共同尾部逐元素相同、保留不访问 B、最终选择不访问未
保留前缀的测试等 **9 项通过**；初始渲染逐链与公开 RGB 一致。
重放仍与先前使用相同模拟器，存在 Gym 观测类型与动作转换警告，
没有进程级权限隔离。此结果不证明 PC2、正式闭环、独立收益或
泛化；PC0–PC5 不改判。
