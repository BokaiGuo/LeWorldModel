# Reacher v3 接口预检 v2：参考动作参数修正

保留第一次宿主机预检失败：缓存适配器接收的是已归一化的实际动作，
而既有 `_terminal_batch` 接收的是经 `tanh` 映射前的无界参数。
把前者直接传给后者，会对动作再次做非线性压缩；这是一项已定位的
**预检参考接线错误**，不是已证明的 v3 编译器或世界模型错误。

本版本其余任务、根、动作、模型、输出、容差和 GPU 规则均继承
[v1 预检协议](PC_RESPONSE_TEMPORAL_V3_REACHER_ADAPTER_PREFLIGHT_PROTOCOL_20261104_CODEX.md)；
对严格位于物理动作域内部的固定探针，在调用 `_terminal_batch` 前
将相同归一化动作应用边界仿射逆和 `atanh`，令其内部 `tanh` 后动作
与缓存适配器一致。显式检查逆映射结果；端点探针不通过该逆映射，
禁止静默裁剪或放宽预定容差。输出新路径，先前失败和部分产物不改。
预检不运行或宣称闭环。
