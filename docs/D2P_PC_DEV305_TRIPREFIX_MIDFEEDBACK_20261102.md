# dev305 三前缀真实 RGB 中间反馈重规划

在已封存的共同初始状态上，分别取模型选中的 `candidate_02`、`candidate_00`
anchor 和 zero 前缀；各自先执行之前由相同 CEM 选择的尾部首包五步，再从
各自真实 RGB、真实动作历史和目标 RGB 出发重新规划。每臂使用相同种子、
相同两包终点评分及 CEM 预算，每臂 10 次 predictor 调用、3,200 个预测
样本；执行各自新计划的首包五步。重规划共使用 10 次 RGB 编码，模型权重
哈希前后相同。选择输入不含环境状态；状态仅用于物理重放校验和评价。

这是已知开发根上的事后设计，不是新根或确认实验。三种前缀最初生成成本、
结构计算和完整 wall time 未被认证为等预算；`candidate_00` 也不是认证
greedy。因此不能用它证明完整方法优势。全部执行完成、不提前终止，且
各臂从重规划时刻到终点物体位置与角度均未变化。

| 前缀 | 原 CEM 旧尾终态奖励 | 实际反馈重规划终态奖励 |
| --- | ---: | ---: |
| candidate_02 | -421.999 | -419.487 |
| candidate_00 | -428.507 | -417.759 |
| zero | -414.622 | -415.213 |

奖励是原生环境混合指标，不等同物体任务进展。反馈后 selected 优于
anchor，但仍低于 zero；同一中间状态下替换旧尾的奖励对不同分支有升有降。
这不能说明反馈规划优于无反馈，也不能说明谱前缀改变了有用物体控制能力。
不要以该结果重新解释此前的共同后缀干预或将其计为独立 P1 确认。
