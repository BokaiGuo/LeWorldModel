# TwoRoom 当前像素差：固定候选诊断协议

在已暴露行 82490，沿用此前固定的 12 条曾成功候选和两条失败候选，固定动作、数据目标图、冻结模型和 normalizer。比较数据当前图与评价端从同一数据状态重渲染的当前图；后者不进入原规划。不同初始渲染不是像素对齐以外的隐藏物理状态等价证明。

两种当前图分别完整预测所有同样的合法候选，记录当前图像差、预测后继表征差、目标分数、14 条候选全体两两偏序变化及 parent 对 12 条成功链的排序。使用绝对分差不超过 `1e-4` 的结果标为数值近并列，另报告严格符号变化，不能隐藏靠近零的翻转；对数据当前图复核原封存预测和分数。动作、目标、模型和数据指纹均需核对；模型冻结与重渲染初态来源明确记录。

若 parent 对成功链排序变化，检查对应实际分差、实现来源和数值边界；若全部不变，不能将该极小当前图差异作为该固定候选组排序错误的解释。两种结果均不证明任务总体成因、物理泛化或性能增量，不改变任何 gate；不能用评价端标签重新选动作。
