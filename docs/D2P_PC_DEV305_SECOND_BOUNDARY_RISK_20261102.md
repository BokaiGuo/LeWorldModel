# Dev305：第二个反馈边界的执行前风险投影

## 方法与范围

在已有第二边界模型候选上，沿用上一轮固定的局部 RGB 扰动、岭系数和 8 像素门限：用当前真实 RGB 的编码切线估计各五步预测终点的物体与推杆框；只在预测可见的候选中按原 latent 终态代价选最小者，无候选则拒绝。所有神经计算使用冻结 checkpoint 和主机 CUDA。投影忽略旋转对框的改变、遮挡、形变与非线性，属于未校准的终态启发式，不是安全保证。

这是同一个已知开发根的事后重评分：之前已经执行了全部候选，**没有新增物理执行**。新的投影不读取物理状态或真实 outcome，但由于开发者已看过这批结果，也不能称独立前瞻验证。目标图仍不满足原 guard。
