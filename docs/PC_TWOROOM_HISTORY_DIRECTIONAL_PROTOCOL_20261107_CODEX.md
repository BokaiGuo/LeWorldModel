# TwoRoom 真实历史对固定方向后果预测的开发诊断

## 假设与范围

原方向实验使用一个当前图像，模型训练配置则包含历史上下文。本实验检验：对同一合法候选和同一冻结 checkpoint，增加真实的、时间对齐的历史 RGB 与已执行动作，是否改善预测后继与真实后继的匹配。它不是声称原单帧协议有 bug；不是反馈控制或新规划器。

复用已暴露方向面板的 10 根，25 步 24 条候选不变。每根历史帧为数据行 `row-10,row-5,row`，历史动作分别是 `[row-10,row-5)` 和 `[row-5,row)`，检查同 episode、逐步时钟连续、动作有限且合法，最后一帧等于封存当前帧。目标、动作 normalizer、模型、预处理与原实验一致；通过现有时间契约拼接两包历史，预测全部候选。原实验中 ±0.02、±0.2 共 16 条候选已有逐链物理末帧编码；封存新增预测后才能进行后置比较。此面板和真实结果此前已暴露，因此不声称盲法或独立验证。

## 比较与开发出口

逐根记录单帧与三帧的 16 条候选表示均方误差、预测评分和八个正负对的物理距离排序一致数，平局单独报告。原单帧预测与新预测均比对同一真实末帧表示；按照根平均，不将候选当独立任务。报告配对改善、退化和平局及历史实际额外开销；历史来自数据集参考轨迹，只是本离线诊断的合法历史，不能暗示规划器执行了参考轨迹。

为决定是否值得设计后续反馈对照，事前规定：三帧在至少 7/10 根表示 MSE 严格更低，且 10 根平均 MSE 至多为单帧的 90%，同时物理方向排序总一致数不低于单帧。任一不满足则停止将此具体历史配置当作预测修复，不改变历史接口的合法性。此开发出口不是 gate 阈值，也不证明真实闭环。

允许使用既有封存物理数据进行评价，不允许物理状态、未来图像或成功标签进入预测。任务与数据来源独立性未知，结果不改变 PC0–PC5。
