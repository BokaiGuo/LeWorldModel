# RGB 梯度候选的预测—编码—物理分解协议

对已封存的四个 TwoRoom 开发任务、每任务五条梯度候选，评价端从相同
物理初态重放完整 25 步并保存最终 RGB；真实轨迹须与已封存物理记录
逐项一致，否则停止。成功标志仍按曾成功记录，最终距离是第 25 步距离；
两者不能互相替代。真实帧仅供评价，不能回流规划器。

冻结 checkpoint 与正常图像变换下，对同一动作、同一目标及最终时刻
保存三类量：模型预测末态表示及目标平方距离、真实末帧编码表示及同一
目标平方距离、真实物理目标距离。重新预测得分须在 `atol=1e-3,
rtol=1e-5` 内复现封存计划；模型参数与时钟不变。逐任务比较五候选
所有 10 对的三组排序，并记录并列；统计任务层面不把对数作为独立
样本。报告预测选中、真实编码事后最优和物理事后最优各自真实末距，
后两者均为不可部署 oracle。

计划不筛任务，包括初态已成功者；四任务、二十链均已曝光，开环且
没有成功/失败的充分区分。该结果仅用于诊断这一候选池内的预测与
评分失配，不能直接归咎特定代码、声称模型理论无效、证实新描述或
修改 PC0–PC5。评价输入严格在模型计划封存之后读取。
