# 共核 RGB 实际派发链：共同尾部干预结果

按事前协议，对先前反馈运行的 3 条实际派发链全部进行干预，保留
失败任务。替换前 5 步后，所有臂使用原来实际派发的相同尾部；
成功或截断即停止。greedy 与 lookahead 分别使用冻结模型对 32 个
共享前缀评分，合计额外 **192 条完整链评分**。

| 前缀条件 | 曾成功 | 前缀内已成功 |
| --- | ---: | ---: |
| 原实际前缀 | 2/3 | 0/3 |
| 零动作 | 3/3 | 0/3 |
| 固定随机动作 | 1/3 | 0/3 |
| 模型 greedy | 3/3 | 3/3 |
| 模型 lookahead | 3/3 | 1/3 |

原链成功的 root 10、11 在去掉原前缀后仍成功；原链失败的 root 12
在零前缀下成功。故该小样本**不支持原实际前缀对共同尾部成功不可
替代**。greedy 的成功都发生在尾部执行前，不能计作尾部利用机会。
这也不能否定其他前缀或任务中的重配置机制。

lookahead 在评分时使用了事后固定的实际尾部，是受控机制对照而非
可部署规划器；模型评分与物理成功不同。实验未做各前缀等预算尾部
重优化，也未证明行动后果描述帮助发现链，不能据此通过 PC2。

原始实际链重放逐步一致；独立审计核对了 3 根全部候选、种子、分数
选择、共同尾部、终止与失败分母。审计使用相同模拟器与封存分数，
没有再次 GPU 重算。候选边界及随机流测试 2 项通过。原始计划、物理
结果和审计见 `le-wm-main/results/pc_shared_rgb_executed_chain_intervention_20261107_codex_*`。
该研究按 `experiment-design` 的分阶段与消融约束先固定了比较及停止
规则；参考文件在本机缺失，未使用该参考文件。PC0–PC5 未改判。
