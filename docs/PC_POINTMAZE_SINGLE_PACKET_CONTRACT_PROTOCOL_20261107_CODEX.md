# PointMaze 单动作包执行合同诊断

本诊断使用已曝光的四根、两个视角及四个固定动作；属于
`official_state_assisted` 开发轨道，不是 RGB-only 或独立确认。
动作与输入来自已封存面板，真实后继只用于误差评价，不参与动作选择。
诊断在同一进程打开后继数据，不宣称进程级的预测／评价隔离。

逐条件比较权限包装器、`encode + unroll` 和单步底层 `forward_pred`；
检查上下文是输出第零项、预测是第一项、张量形状及冻结结果重放。
对原始五步动作比较本地数据集统计、预处理器及模型仓库声明统计；
真实轨迹动作时钟仍以此前物理回放审计为证据，不以张量比较替代。
数值使用 `atol=1e-5, rtol=1e-5`，并报告最大绝对差。
输出应包括条件级预测与真实编码误差、上下文与真实编码误差。
误差高低只是诊断，不把其当作修复或时钟语义的证明。
