# P1 前后缀联合优化：已知根主机 CUDA 结果

针对原生成器只用阶段梯度更新前缀、后续回溯固定前缀的限制，
按照 `D2P_P1_JOINT_PREFIX_SUFFIX_PROTOCOL_20261030_MAIN.md` 对
全部 8 臂 × 20 个固定候选进行三包动作联合优化。冻结模型前后
哈希一致；predictor 与 action encoder hook 各记录 2,400 次，
640 次反向是代码路径计数，不是独立反向 hook。

保存态检查结果：

- 160/160 初始前缀动作、模型前缀预测和终态预测与原候选及
  回溯结果精确匹配，支持该批初始化没有接错动作或历史。
- 160/160 候选的最佳迭代前缀发生数值变化，终态 latent MSE
  低于各自初始值；152/160 的全部相邻迭代分数单调下降，其余
  8 条存在非单调步骤，因此必须保留每条最佳迭代而非假设单调。
- 八臂选出候选索引依次为 `4, 4, 0, 0, 10, 10, 15, 15`，
  各臂选择的都是第 4 次更新。其模型得分不能等同于真实物理
  进展或控制能力；重复根、条件和动作必须继续单独标识。
