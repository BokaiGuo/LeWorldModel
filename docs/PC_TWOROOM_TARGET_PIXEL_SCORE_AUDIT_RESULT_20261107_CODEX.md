# TwoRoom 目标像素差与失败链选择：诊断结果

按[事前协议](PC_TWOROOM_TARGET_PIXEL_SCORE_AUDIT_PROTOCOL_20261107_CODEX.md)，对已暴露行 82490 的 12 条物理成功链与 parent、lookahead 两条失败链，比较数据目标图和由评价端重渲染的目标图。预测使用冻结 RGB 模型、同一候选动作和相同预处理；重渲染目标图没有参与原规划。

- 两张目标图有 4 个通道值不同，最大差为 1/255；当前图有 3 个通道值不同，最大差同为 1/255。
- 两个目标编码的最大分量差为 0.001364；两次模型预测后继逐位相同。本次重算的预测后继与原保存结果也逐位相同。
- 目标图替换造成的候选分数最大变化：预测代价约 0.0646，真实末帧编码代价约 0.0668。各 14 条链的 91 个两两顺序没有变化。
- 对两张目标图，预测代价及真实末帧编码代价都将 parent 失败链排在全部 12 条成功链之前。原数据图下，真实末帧编码的分差至少约 13.29。

因此，**本次受控的目标图微小像素差没有解释这个候选组的排序错误**。该结论不排除编码目标函数、其他预处理、模型预测或其他任务上的问题；当前图像虽也有微小差异，本实验没有替换当前图并重新预测，不应将目标图结论扩展到它。模型实际 `get_cost` 与末帧编码平方距离手算在 `1e-4` 容差内一致，原分数与真实编码分数复算在 `1e-3` 内一致；这排除了本案例中这些有限的算术与目标图替换解释，并未证明训练／评估的全部合同正确。

动作 normalizer 已按相同 scaler 反归一化再归一化，并检查误差小于 `1e-6`；相关权限及比较函数测试 **18 项通过**。候选来自事后筛选的单个开发任务，评价端物理标签和重渲染目标未被用于部署动作选择；它不支持方法改进、RGB 闭环收益或任何 gate 改判。
