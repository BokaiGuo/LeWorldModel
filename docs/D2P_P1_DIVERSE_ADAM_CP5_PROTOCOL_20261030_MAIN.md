# 新多样性前缀的独立 CUDA 后缀规划

在两个已知根上，对三个固定新前缀分别使用其真实 cp5 RGB、原始
动作历史、冻结目标表示与归一化参数。复用旧对照的每逻辑槽相同
随机种子、四个原始动作起点、每个起点 20 次 Adam 更新及最终
预测目标 MSE 选优；每个前缀各自规划，不能沿用另一个前缀的后缀。
世界模型、编码器不训练，任务规划不读取物理状态或目标真值。

这只是已知根开发探索；不能按此三槽估计独立成功率。各槽分别
记录编码、预测、动作编码、反向次数、规划耗时与最终动作字节，
旧模型代码调用口径可与旧局部实验对照，但无独立完整账本或
包含前缀生成的统一总预算。CUDA 规划完成后仍须逐条绑定原生
reset、前缀和完整执行记录进行真实验证。不能根据模型分数单独
认定能力优势，更不能据此打开 P1。
