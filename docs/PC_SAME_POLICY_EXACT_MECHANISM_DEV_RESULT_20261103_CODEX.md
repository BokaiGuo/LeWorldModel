# 同一策略的精确动力学机制开发结果

按 `PC_SAME_POLICY_EXACT_MECHANISM_DEV_PROTOCOL_20261103_CODEX.md` 运行：使用 RGB 开发实验的同一个 `decide` 函数，把预测接口换为精确 unicycle；12 个按几何规则固定的开发方向、15 步时域。各臂先独立选择并封存完整链，随后仅对 SVD 臂最终选择的同一条链进行干预。代码、协议及依赖 hash 和原始数据位于 `le-wm-main/results/pc_same_policy_exact_mechanism_dev_20261103_codex_*`。

## 事前选中链的机制干预

| 预定条件 | 满足任务数 |
| --- | ---: |
| 五步前缀无即时进展 | 0/12 |
| 实际选中后缀的相对响应严格优于 zero 和同库 greedy | 8/12 |
| 各前缀同 120 次评分重规划后严格优于两者 | 11/12 |
| 三者在同一链同时成立 | **0/12** |

12 条选中前缀的即时终距变化均为负，即均向目标即时进展；因此即使有后续响应变化，也不能报告非即时机制见证。各前缀使用相同预设后缀族，额外独立报告各自 120 次完整链评分的迭代 CEM；干预费用不混入选择成本。结果是受声明预算、动作尺度、12 个方向和该具体策略限制的开发负结果，不能证明所有动作程序或其他任务均不存在该机制。

## 开发规划比较

| 方法 | 平均终距 | 相对 SVD 的配对结果（SVD 胜／平／负） |
| --- | ---: | ---: |
| SVD 响应＋联合精修 | 0.33890 | — |
| 等价岭响应＋联合精修 | 0.33890 | 0／12／0 |
| 同名义无响应＋联合精修 | 0.43294 | 12／0／0 |
| 同名义随机扰动＋联合精修 | 0.40769 | 10／0／2 |
| 同库即时 greedy＋联合精修 | 0.26841 | 2／0／10 |
| 完整时域 CEM | 0.55263 | 12／0／0 |
| 同库固定前缀 lookahead（共享 SVD 缓存） | 0.53923 | — |

每臂每任务恰好使用 480 个五步预测 token；SVD 额外支付每任务两次 SVD，岭支付两次线性求解，不能把 token 相同视为全部计算等价。SVD 与岭各任务最终动作最大差为 `1.11e-15`，不支持 SVD 分解独立收益。全部 12 个 SVD、岭、nominal、随机及 greedy 的最终结果均为联合精修链；因此机制检查针对精修后的真实最终前缀。lookahead 值来自 SVD 分支三条固定前缀后缀搜索的共享缓存，不是独立等成本运行。

SVD 的平均终距优于本次具体 CEM 配置，却弱于具体同库 greedy 配置；这些结果不能替代充分调优的强基线、质量—成本曲线或独立确认。精确模型可见真实状态，而视觉运行使用 RGB 接口，两者不能拼成同一实证性能结论；该策略尚无跨后继响应程序组合。

预算分解为下一版提供了具体诊断：SVD 分支给三个前缀各 36 次后缀评分，greedy 给选中的一个前缀 108 次；两者均余 37 次联合精修。12 个任务中有 11 个，SVD 完整链搜索选出的精修起点前缀与 greedy 的即时选择相同。精修前 SVD 最佳链平均终距 0.53923、greedy 为 0.44918；精修后分别为 0.33890、0.26841。该观察与后缀预算分散造成差距相容，但尚不是固定候选、随机数和后缀预算受控的因果证明，也不能将选择差距直接归因于分解。

校验：批量动力学对照原逐步 unicycle 计算；封存依赖哈希及最终链、各控制前缀、实际后缀重算和 120 次后缀评分均已测试。相关测试共 24 项通过。此结果不改变 PC2、PC3 或历史 P1 状态。
