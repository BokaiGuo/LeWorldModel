# 统一开发入口：冻结 RGB 模型重放结果

## 范围和结果

依照[事前协议](PC_UNIFIED_RGB_FROZEN_MODEL_REPLAY_PROTOCOL_20261103_CODEX.md)，
对四个已暴露根的三次已封存决策，重新加载冻结 checkpoint、normalizer，
使用保存的 RGB、动作历史、时钟及目标图像运行真实模型。物理环境没有推进，
也没有把重新编译的动作派发到原轨迹。

| 检查 | 结果 |
| --- | --- |
| 固定请求重放 | 820/820 批在 `2e-5` 绝对容差内；记录的位置和评分最大误差均为 0 |
| 新入口重新编译 | 12/12 完整选中链及评分在预设容差内；最大动作、评分误差均为 0 |
| 弃权、批数 | 12/12 匹配；这 12 次原决策均未弃权，因此不验证真实弃权分支 |
| 新旧逐批比较 | 820 批形状匹配；模型动作、位置和评分的最大差均为 0 |
| 审计 | 35 个列出的文件哈希一致；重算选择、逐批差异、上下文绑定和计数 |

每次第一、第二、第三轮分别使用 478、480、480 个预测 token；
重新编译共 820 次预测调用、3708 条样本、5752 个 token。
固定请求重放另用 820 次调用和 5752 个 token，属于诊断开销，
不能并入或替代原方法的性能预算。另记录 37 次编码；完整诊断墙钟时间
108.46 秒（含模型加载等），不是方法的独立规划延迟。
运行环境为 Python 3.12.3、NumPy 2.4.6、PyTorch 2.12.0+cu130、
CUDA 13.0、RTX 5060 Ti。

固定请求阶段仅保存逐批误差和标记，没有保存此次重算的原始预测；
因此独立审计能核对索引、原请求、容差及计数，**不能独立重算这些误差**。
重新编译阶段保存了新预测轨迹，故上述逐批比较可独立重算。哈希只覆盖
列出的文件，不证明全部传递依赖、数据集来源或训练独立性。

这验证了指定已暴露上下文、目标投影和冻结模型下的开发入口回放一致性；
并非新 RGB 闭环、PC0–PC5 通过、自动程序发现或规划优势。
历史 RGB runner 尚未接入该入口；后续仍需同一方法的实际反馈执行、
事前同链机制干预、全成本强基线及独立来源认证。
