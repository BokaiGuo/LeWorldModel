# P1 真实中点在线求解一致性探索

使用离线中点回放的固定 13 槽和三条既有删失，不按结果再筛选。
每条重放到真实中点时，在继续派发动作前，将刚获得的 RGB 与
已认证 cp5 和实际前五步动作构造模型历史，在同一冻结模型的
主机 CUDA 上按相同 Adam 合同优化后五步。结果与封存离线动作
逐字节比较；不一致立即中止，不用历史动作替代现场结果。
一致时派发相同动作，并将实时求解事件、分数、设备、模型哈希
与分类调用计数封存。物理动作和图像仍需保存消费者核验。

封存离线动作只是事先固定的确定性一致性断言，不是额外候选；
这是已知根上的在线工程 parity，且只覆盖之前可到达中点的轨迹，
不能称独立确认、完整公平预算或 P1 机制胜出。模型不后训练，
模拟器真值只用于回放审计，不进入规划目标。
