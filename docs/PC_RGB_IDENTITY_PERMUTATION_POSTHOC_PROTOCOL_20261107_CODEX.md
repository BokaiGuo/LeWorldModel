# RGB 首轮后果身份置换：事后诊断协议

本分析使用已经曝光的 TwoRoom 40 个首轮共同候选和已物理重放的尾部。
协议在本分析计算前记录，但并非原实验的事前注册，不改变此前闭环
实验的停止结论或任何 gate。

每个任务的三个前缀均有两个模型探针后果。保持各行数值集合、各前缀
原始 probe-min 和首个保留项不变，穷举每行是否交换两个后果的
2³=8 种组合。按照原 retention 的距离和稳定平局规则保留第二项。
与原未交换选择、普通 lookahead 以及原实验记录逐任务核对。

物理评价只在决策之后使用：沿用已封存标签，初态或前缀已成功不计
有用前缀；两个独立生成尾部任一个之后成功才计有用。记录每个任务
各置换保留的有用数量、与真实身份相比的好／同／差次数及所选前缀
变化。按任务汇总，置换不是独立任务；也不把用真实标签选择最佳置换
称为可部署策略。B 尾部只对 A 描述构造保持隔离，部分曾被原规划器
查询，不能称为原规划器全局未查询。

数据、代码均记录 SHA-256，输出排他创建；核对原链、前缀成功和
归档结果的一致性。该分析不计算未查询动作预测、不提供物理增益
确认、不证明动作身份有因果贡献，也不重启已终止的描述配置。
