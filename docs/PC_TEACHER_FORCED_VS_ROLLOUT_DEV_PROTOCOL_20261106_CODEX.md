# 固定链的重观测预测开发诊断协议

复用第二次规划开发面板中已存的动作、同次自回归预测与物理重放。
范围固定为任务 15、25、35，lookahead/effect 两臂各自的模型最优、
实际选中均值以及存在时的模型评分最优成功链。成功链根据物理标签
事后选取，不能作独立抽样或部署选择证据；重复的动作记录保留标签，
汇总需去重。

逐条先精确重放已派发的 25 步，核对每步状态；再依次执行完整
候选链，在每 5 步渲染并经冻结编码器编码。对每个 packet，将模型
输入历史长度限制为至多 3：使用截至当前时刻真实重编码表示和
对应已执行／当前 packet 动作，预测下一表示，记为 teacher-forced
单步预测；同样时刻比较原规划时保存的自回归预测。两个预测均
与同一下一真实编码按平方距离比较，报告每个时刻及每条独特链。
重观测只用于评价端诊断，不进入开环规划，不计算为控制收益。

核查时间 0 表示与重放编码一致、第一步 teacher-forced 与原始
自回归预测一致、动作 scaler 往返、目标编码及首次成功时刻；
否则报错并排查，不把错误归因模型。比较关注误差大小及哪些步
更小，不预设单步必然改善，也不将较小 latent 误差等同任务成功
或公平闭环收益。候选来自已暴露结果，统计仅为事后开发描述。
