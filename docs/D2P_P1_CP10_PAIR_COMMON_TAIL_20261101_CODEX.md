# Known-root cp10-goal structured/CEM common-tail intervention

This is a fixed-action developmental mechanism intervention on the already observed root0 and its previously observed cp10 goal. It is not independent confirmation, a complete planner comparison, or P1 admission. The old reports' physical outcomes are known; no claim of blind prospective source selection is possible.

Before starting this new run, freeze exactly four ordered 15-step programs: the actual first five structured or CEM actions, crossed with either the two-packet structured plan sealed at structured boundary 5, or exactly ten zero actions. Suffix actions are taken directly from the full plan sealed before its original step 6, not selected by any outcome of this intervention. The four schedules, input report and code SHA closure are written to `prepared.json` before physical branches. Prefix/cp0 identities and the actual original sealed boundary are checked against the existing report/journal/ledger, and task goal is rebound through the existing cp10 source. The original selected full plan may already have influenced historical outcomes; that limits interpretation, not the fixed choice for this run.

Each branch resets and warms up through the existing actual PushT executor, checks its real root and historical prefix cp5 state, exported two-body snapshot and RGB, and saves newly collected per-step observations and accounting. New dynamics receipts are **new replays**, not backfilled historical measurements. Native stops and out-of-canvas censoring are retained at the true step; no missing endpoint is padded. All work, including rendering, is under the existing cooperative GPU lock. No neural inference is executed. A failure interrupts remaining branches and is reported as partial, not a scientific negative. Costs count the diagnostic interventions rather than assert equal complete controller costs.

Primary descriptive output is the actual same-tail versus zero-tail outcome for each prefix, including every native stop and absent step-15 endpoint; compare the two within-prefix differences only where both endpoints are actually observed. Same common tail is an effect-modification probe, not independently optimized capacity and not proof of a non-greedy mechanism. No gate, root roster, original evaluator, or prior files are changed.
