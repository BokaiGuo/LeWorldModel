# TwoRoom 共享核心 RGB 反馈保留规则开发协议

在已曝光 root 10–49 上，固定冻结 LeWM、标准 TwoRoom 图像目标、25 环境步上限、每次最多执行 5 步及成功／截断停止规则。采用既有共享固定前缀核心，逐次从实时 RGB 和目标图构建同权限动作候选；合法动作历史为空，未执行旧尾补零作为下次评分父链。每次使用同一确定性随机种子构造 3 个完整父链、2 个共同探针、2 条共同尾部，保留 2 个前缀，计 13 条完整链评分；父链、探针和授权尾部中所有已评分链都参与最终竞争。

同样条件分别运行父链排序、普通 lookahead、向量多样性、动作身份打乱四臂。所有臂每根相同初态、目标及随机流，之后由各自真实执行与实时观测产生不同状态；重规划数及整任务查询可不同。记录每轮输入图像收据、完整评分、前缀身份、选择、实际动作、终止状态、同步规划时间及任务局部墙钟。报告四臂逐根曾成功、终止时物理距离、查询数、对 lookahead 的成对独胜／独负。不可把早停后的物理距离作为固定 25 步末距，不能把成功数或查询数当作全系统成本。

该实验是小规模、已曝光开发比较，候选生成预算低于先前经过调优的强 CEM；即便描述臂胜出，也必须再与同权限充分调优强基线、完整成本及独立任务比较。向量是探针行中心化特征，并非已经认证的 hold 对照描述。物理状态只用于环境初始化和评价，不能进入 RGB 规划器，不跨轨提升 Gate。
