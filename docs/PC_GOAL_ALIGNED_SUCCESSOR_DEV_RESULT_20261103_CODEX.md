# 目标条件化多方向后继搜索：开发结果

旧多方向响应实现接收 `target` 但只用其维度检查，提案方向没有使用
目标残差。本次按[预先协议](PC_GOAL_ALIGNED_SUCCESSOR_DEV_PROTOCOL_20261103_CODEX.md)
实现目标对齐方向，在同一有效响应子空间内生成候选；与原奇异方向、
匹配结构的随机方向和完整时域 CEM 在 24 个已暴露 Wall 根配对比较。
候选、响应、后继留存、共同优化、全动作精修及弃权均属于本次新版本。

| 臂 | 平均终距 | 成功 `<0.05` | goal 逐根终距更低 |
|---|---:|---:|---:|
| goal | 0.51471 | 0/24 | — |
| svd | 0.51887 | 0/24 | 14/24 |
| random | 0.52573 | 0/24 | 15/24 |
| full-CEM | 0.52104 | 0/24 | 8/24 |

三个结构化臂每根消耗 478–480 token、3 次 SVD；full-CEM 每根 480
token、无 SVD。random 臂为匹配结构而支付响应提取和分解成本，不能
用它证明最有效随机方法在相同总计算下落后。goal、svd、random、
full-CEM 的本机串行平均墙钟时间分别约 0.0377、0.0311、0.0353、
0.0061 秒，token 相近不代表总成本相同。每个首响应秩均为二；goal
的 48 个后继响应按原阈值分别有 36 个秩二、6 个秩一、6 个秩零，
没有对无响应方向凭空生成候选。

按[机制诊断协议](PC_GOAL_ALIGNED_SUCCESSOR_MECHANISM_DIAG_PROTOCOL_20261103_CODEX.md)
对 goal 最终链进行同尾部、各前缀 120 条重规划及后继响应干预；
**24 条最终选中链中非即时前缀为 0/24**，故 zero/greedy 机制交集和
四控制交集均为零。该结果不能作为 PC2 自动机制见证；平均终距的小幅
差异也不能证明 PC3 强规划优势。相同根是已暴露开发数据，历史
lookahead 和已选尾部有事后限制，120 条重规划不是上界。

在固定任务和预算下，目标旋转并未找到预设所需非即时程序。按协议
停止此单配置，不在这批根上追加调参；该有限负结果不证明目标条件化、
响应程序或理论一般无效。新版本还未完成 RGB 反馈或独立模型复现，
不能将旧方法的视觉结果拼接给它。PC2、PC3 和后续 gate 仍未通过。

目标方向、零秩与一秩退化的两个代码测试通过；96 次计划的全部预测
与最终全局已评分最优逐批重算，24 组机制干预确定性重放一致。测试
与重放不等于独立科学确认。
