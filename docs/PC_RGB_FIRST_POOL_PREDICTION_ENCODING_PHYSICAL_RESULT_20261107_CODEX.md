# RGB 首轮候选：预测、真实编码与物理后果对齐

按[诊断协议](PC_RGB_FIRST_POOL_PREDICTION_ENCODING_PHYSICAL_PROTOCOL_20261107_CODEX.md)，对 40 个已曝光 TwoRoom 任务的首轮 360 条固定前缀—探针链，重新执行相同初态和动作，记录 25 步真实末帧；冻结 RGB 模型在 GPU 上重算相同动作，保存预测后继、真实后继的冻结编码和目标编码。

对同一前缀的两个非零探针，比较相对于零参考的末帧后果符号：

| 比较 | 一致的候选后果 | 每任务 6 项中多数一致／持平／多数不一致 |
| --- | ---: | ---: |
| 模型预测分数 vs 真实末帧编码分数 | 192/240 | 34／4／2 |
| 真实末帧编码分数 vs 物理末距 | 141/240 | 21／10／9 |
| 模型预测分数 vs 物理末距 | 139/240 | 22／7／11 |

按协议两侧任一平局均单独排除；本次没有平局。240 项共享任务与前缀，不是 240 个独立任务。模型预测与真实编码的 360 个末帧特征平均均方误差为 **0.1278**，对应目标分数的平均绝对差为 **26.11**；这些量是模型表示尺度，不能直接与物理距离比较。

在该候选分布上，模型预测与真实编码、真实编码与物理距离**两层都存在不一致**。因此不能仅凭此结果断言某一层是唯一瓶颈，也不能把目标编码分数当作可靠的物理成功标签。结果仅覆盖已查询的三个探针和一个 25 步末帧，不证明未查询动作、全时域或其他任务的表现。

物理重放的 9,000 步距离和成功标志与先前记录一致；GPU 重算的模型代价与封存分数最大差为 **0**。独立算术审计从保存的预测／真实特征重算代价与符号，最大代价误差约 **6.11×10⁻⁵**；审计仍使用同一模型和物理后端。相关测试 **4 项通过**。真实后继只用于评价，并未输入规划器；PC0–PC5 不改判。
