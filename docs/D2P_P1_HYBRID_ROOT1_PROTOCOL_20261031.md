# P1 混合谱候选：已知根 1 开发合同

沿用已知根 1、冻结 checkpoint、目标、真实 RGB 反馈时刻和共同后缀优化器，
只运行 structured 臂；这不是独立确认，也不改变任何阶段准入条件。
固定 H3 完整 Jacobian 与阻尼 `0.01 * sigma_max²`，候选池按次序为：
旧谱库半径一的四个候选、零、阻尼方向的 +0.5、+1、-0.5、-1、裁剪阻尼解、
旧谱库第二半径的四个候选。按 float32 最大绝对差 `<=1e-7` 去重，顺序取八个；
不足八个或谱退化则拒绝运行。不得按物理结果选择候选。

每个候选执行原共同优化器的两步优化，模型终点评分，真实派发五步后刷新 RGB。
保留原生成功和画布保护，报告逐类调用及耗时；Python 调用数不是完整 FLOPs。
开发根上的性能变化不能证明 P1 的非即时进展、能力变化或独立公平收益。
