# 多起点预算版本的最终链机制诊断

两个预算、24 个暴露根的计划已封存，物理机制结果前固定此事后诊断；
不重跑或挑选方法计划。对 480 和 1920 两个预算点，逐根取精修及弃权后
实际选中完整链，以其前五步和同库 greedy、zero、既有历史 random
bridge/lookahead 前缀执行此前固定的同一套 6 个共同后缀（含该实际
选中链尾部）和各前缀 120 条同优化器 CEM 搜索。后两类来自历史记录，
不是本方法同时事前执行的控制；共同 selected 尾部亦为事后选定。
对五类前缀重算相同有限差分后继响应矩阵。

沿用既有诊断对非即时、相对各自零后缀的变化和各自重规划严格比较
的定义，逐预算逐根保存所有动作、得分及响应；根跨预算重复，不作为
独立样本。报告 selected/zero/greedy 两控制交集以及四控制交集，
报告绝对终距和实际开销。120 条链并非充分搜索或强上界；如果有线索，
不能将不同预算版本、事后尾部或其他根拼接成首次事前完整链的证据。
这一开发诊断不判 PC2、PC3 通过。结果与代码、协议及全部来源哈希
绑定，文件排他创建。
