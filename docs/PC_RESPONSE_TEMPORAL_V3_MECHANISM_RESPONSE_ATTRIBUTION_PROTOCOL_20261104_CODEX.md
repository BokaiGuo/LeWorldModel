# v3 机制负结果：局部响应归因诊断

这是看到事前网格机制结果后的开发诊断，不能改变原合同或升级为
事前见证。对原结果中全部六个非即时前缀，以及每根对应 zero 和
same-bank greedy，检查精确动力学后继位置／角度是否相同，并在
相同后缀名义动作下重新计算五步后继响应。名义动作固定为全零及
最终选中链后缀的首五步（逐坐标裁剪至 `[-0.9,0.9]`），中心差分
尺度固定为 0.01、0.05、0.1；每个扰动后再接五步零动作。

逐根保存三种前缀的物理后继状态、各尺度响应矩阵及 selected 对
zero／greedy 的 Frobenius 距离。检查零名义、0.05 的结果能否复现
原事前干预；不能复现时停止报告。此诊断只分辨局部响应是否在
其他尺度或选中尾部附近改变，不能证明因果利用、不能为事后修改
的阈值提供 PC2 资格，也不追加规划或改变旧结果。
