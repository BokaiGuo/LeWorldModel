# 未查询前缀—尾部组合开发实验协议

执行前冻结。面板为已捕获首轮上下文 task 0、5、10、20、30、40、
45：来自先前两个固定开发捕获，七个 episode 不同，但均已暴露，
数据与 normalizer 训练独立性未知。每任务取捕获首批前四条链的前
两个 packet；不以真实结果筛选。每任务用独立种子 73000+task 和
83000+task 分别生成 A、B 各 4 条独立合法三 packet 尾部。模型打分
及物理重放包含每任务全部 32 个组合，实际实验费用需计全部评测；
但计算任何预测时只能使用该划分许可的模型分数。

两个问题分别报告：

1. **未查询配对**：A 的 4×4 中固定 `(row+column)%4 == 0` 的 4
   个单元留出，其余 12 个模型分数用于拟合；每行每列均恰有一个
   留出单元。评价留出单元的代价及物理结果。
2. **新尾部**：使用完整 A 的 16 个模型分数构造预测，对全部
   B 的 16 个新尾部单元进行评价。B 不参与拟合、保留或优化。

对照为前缀原链代价、该行 A 最低分、最小二乘行列加性模型
（新尾部的列效应为零）、逐行岭线性动作—代价模型（固定岭系数 1、
动作向量 30 维，按可见 A 样本中心化），以及逐行固定种子
93000+task 打乱“可见 A 动作—分数配对”后相同线性模型。
各臂对许可的留出单元预测代价，稳定排序选出一条链；预测时不得
使用真实状态、物理成功或 B 目标得分。保留所有任务及所有单元，
单独报告被选链前缀已经成功（<=10 步）与尾部才成功（>10 步）。
每任务报告模型代价预测 MSE 与选择链的真实结果；任务而非单元
为比较单位。真实终点编码目标代价另报，不以其替代物理成功。

预定开发继续标准：两个划分各自在线性描述的逐任务模型 MSE 上，
至少 5/7 任务同时严格优于父链、probe-min、加性和身份打乱；
且新尾部所选链的尾部后成功任务数比每一对照至少多 1 个、至少
涉及 2 个不同任务。若不满足，停止升级**该线性描述**；允许单独
报告模型预测与真实编码/物理的失配，不能根据观察结果改阈值。
这个规则是开发筛选，不是 gate 阈值或统计显著性。

若通过才另立固定生成器、合法起点、无 B 最佳作弊的公平优化与
真实执行协议。A 的计算及原父链成本必须计费；本实验诊断成本、
物理标签不作为规划器免费信息，不能将所选链覆盖计为闭环成功率。
