# PC1：RGB 多方向实际候选的模型与物理响应诊断

本诊断事前固定；使用四个已暴露 PointMaze 根的多方向 RGB 闭环封存
决策，在 0/5/10 步共 12 个真实观测历史上，检查每次五步名义动作和
实际生成的整个首段候选库（包括 zero 和实际保留的谱方向正负候选）。
不重启规划、不改变候选、不用物理结果选择动作；结果是开发分析。

逐个候选从封存 trace 找到事前模型五步投影、任务评分和 float32 原始
动作，验证与首候选库及名义中心绑定；读取当时 `0.05` 中心差分得到的
`2×10` Jacobian 和名义输出。计算 `J·(candidate−nominal)`，对比同一
模型的实际非线性投影位移。另从相同重置、热身、实际执行历史出发，
在已核验原生后端分别物理执行名义及每个候选的原始五步动作，要求
分支前逐步状态和时钟与已封存物理重放逐位一致。物理只用于事后评价。
模型输入的 float32 舍入与物理派发原始数值的差异须保留，不宣称逐位
相同。

报告模型线性预测与模型实际位移的绝对向量误差及参照非零时的相对
误差、方向余弦；再比较模型实际位移与物理相对名义位移。接近零的
向量（范数 `≤1e-8`）不计算相对误差或余弦，保留绝对误差。单独
报告每个候选对名义动作的模型任务评分差与物理目标距离差的同号、
反号及平局；两者量纲不同，仅比较排序。模型/物理位移比较消去固定
坐标平移，不消去坐标轴、尺度或状态估计错误，因此不将误差自动认定
为某一种原因。分别报告 zero 与谱候选，12 个决策并非独立根。

预检发现最后五步的 zero 动作会在不同批次重复评分，得分最大差约
`2.09e-7`，位置最大差约 `6.75e-7`。按封存 trace 时间顺序采用首次
出现的候选评分，核对其与候选库评分一致，并报告重复差值；不能声称
模型对相同动作逐位确定。

该试验只覆盖实际五步首段候选、所用模型和暴露根；不认证多步后继、
大范围动作、训练独立性，也不据此判 PC1–PC5 通过或声称实现 bug。
不可覆盖，绑定决策、执行、物理重放、后端和协议哈希；记录每个
模型候选、线性预测、物理轨迹与差异，使用全部候选，不事后择根。
