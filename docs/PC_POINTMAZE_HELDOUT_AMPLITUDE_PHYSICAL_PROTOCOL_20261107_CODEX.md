# PointMaze 未查询幅度真实后果：state-assisted 开发核验

复用 `pc_state_effect_local_dev_20261106_codex` 已封存的四个已曝光任务、两视角、冻结官方 proprio 路径和四个幅度 `[-0.1,-0.03,0.03,0.1]` 的模型代价，以及父链常数、probe-min、AD 线性和二阶 Taylor 预测；原模型曾计算四个幅度，因此这里的“未查询”是指它们未参与先前 ±0.003 描述构造，而不是新盲模型任务。先保存全部规则对四动作的选择、来源哈希，再启动评价端物理重放。

使用既有 PointMaze MuJoCo XML 与官方动作裁剪、五个环境步、每步五个物理子步，针对同样起始状态执行四个常动作，并重放零动作；目标使用同一条已存轨迹的第 5 帧状态。目标及真实后继仅用于评价。逐根核查 zero 与 ±0.1 的六个状态时刻均与先前相机实验一致，否则中止。比较直接模型、父代价、probe-min、AD 线性和二阶外推的真实目标位置遗憾及动作对排序；两视角先按任务平均，四个任务为统计单位。物理目标距离不是完整成功规则。

本实验用于确定此前模型内近似是否对应物理控制；不调整此前二阶描述的停止规则，不以已曝光的开发根宣称泛化、闭环、RGB-only 或 PC1 通过。结果按原样报告，不事后新增准入门槛。
