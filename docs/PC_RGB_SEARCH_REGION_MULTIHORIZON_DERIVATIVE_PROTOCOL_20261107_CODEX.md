# RGB 搜索区域多时域动作导数开发核验

冻结于运行前。本实验使用已暴露的 TwoRoom 开发任务 9000、9013、9022、9032，取原 CEM16 首次决策所选物理动作，逐坐标裁至 [-0.7, 0.7] 得到内点名义链；该链不再等同原执行链。分别截取 5、15、25 个环境步，5 步打包为一个模型动作。输入是封存数据集首帧和目标 RGB，而非重置后渲染帧；不证明两者一致。输入无 proprio、空动作历史，冻结原 RGB 模型与归一化器。

每任务、时域按种子 `27125000 + episode*10 + steps` 产生两个独立 Rademacher 单位方向。对物理动作坐标做自动微分，包含动作标准化的链式法则；在同模型、同候选批大小 1 下，以 0.001、0.002、0.01 中心差分核对。正负扰动逐坐标必须合法，不进行二次裁剪。

逐条记录名义分数、导数、正负分数、差分及误差；数值开发判据为 `绝对误差 <= 0.1 + 0.01*|自动微分值|`，每尺度分别报告，该阈值不是 PC1 通用标准，不改变以往实验结论。近零导数不以相对误差单独判定。记录输入、模型、normalizer、代码和协议指纹，输出采用排他创建。实验仅验证标量目标方向导数，不认证完整表示 Jacobian、物理相关性、闭环收益或任何 gate。
