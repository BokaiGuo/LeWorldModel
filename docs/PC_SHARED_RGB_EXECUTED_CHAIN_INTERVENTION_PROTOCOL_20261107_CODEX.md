# 共核 RGB 实际派发链：共同尾部干预

对已曝光的 3 个反馈任务全部保留，不按成功筛选。将该版本实际派发
的动作拼成链，冻结前 5 步和此后实际派发的尾部；链长为各任务实际
结束时长。前缀、尾部及其效果均来自该同一版本，而非事后优化新链。

从合法当前 RGB 和目标 RGB 出发，每根固定生成 32 个五步恒定候选
前缀：实际前缀（不要求恒定）、零动作、固定种子的 30 条随机前缀。
比较原前缀、零前缀、首个随机前缀、greedy 选出的前缀及 ordinary
lookahead 选出的前缀。greedy 用前缀加 20 步零动作按模型评分选择；
lookahead 用前缀加已封存实际尾部，再补零至 25 步按模型评分选择。
两种选择分别计 32 条评分；它们共享候选，不使用物理结果选动作。
lookahead 能看到事后固定的实际尾部，仅是机制干预对照，不是可部署
闭环基线。每条候选合法并完整封存原始动作、评分与选择。

计划封存后，对每个干预在同一物理初态下依次执行被替换前缀和同一
实际尾部；每臂在成功、截断或链结束时停止。逐步记录动作、物理
距离、停止及成功；核验原链与原运行完全一致，报告前缀结束前是否
成功、前缀即时距离和尾部后成功。不同臂只有前缀不同、链长上限
相同。没有尾部重新优化的本轮不构成完整 PC2，也不证明后果描述
帮助发现；3 个已曝光任务不能推断总体机制，保留失败分母。
