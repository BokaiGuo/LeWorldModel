# PushT 已评分成功／失败链视觉误差：特权事后诊断

序列 11 的 v22 和 CEM 已评分完整链中分别发现 2、10 条物理成功链，但最终选中链失败。本诊断区分冻结模型预测误差与真实后继编码评分误差；不重新规划、不改变最终选链。

## 选样及权限

每臂从其封存普查的去重库中，先按原预测评分升序取出全部成功链；再按原预测评分升序取失败链补足至 64 条，顺序为成功链在前、失败链在后。如果成功链数超过 64 则停止，不能事后调整规则。选样依赖物理成功标签，属于**特权评价集**；候选库、标签及结果不能作为正式规划输入、规划发现率或独立泛化证据。保持两臂分别分析；候选链不是独立任务。

从第 0 帧连续执行共同 warmup 和选中的每条链，确认终态与封存物理普查完全一致，保存真实末帧。复用原合法模型上下文、目标和冻结模型 worker：对全部候选先预测，随后才读取真实后继图片并编码；记录 input、worker、checkpoint 回执哈希及成本。对每条链保存原预测评分、重算预测评分、真实后继编码评分和物理标签；首先核对重算预测与原评分误差。

报告每臂：

- 原规划首选和物理成功链的原／重算预测评分与真实编码评分；
- 64 条中预测评分、真实编码评分各自首选是否成功、首个成功的排名；
- 成功—失败评分成对排序数、预测与真实编码评分同序数和逐候选预测 latent 对真实 latent 的均方误差；
- 全部成功数、失败数、源物理普查覆盖，图像和候选绑定及额外评估开销。

若预测和编码评分都偏好失败链，可观察到真实编码的目标评分与此物理判据在该选样上不一致；不能仅凭它证明评分在所有状态失效。若两者分歧，则只在该数据和输入范围内定位预测／编码评分问题。保持全部失败及边界情况，不能依观察结果改变样本；两目标已暴露，来源独立性未知，PC0–PC5 不改变。
