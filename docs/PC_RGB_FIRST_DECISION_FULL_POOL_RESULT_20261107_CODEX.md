# RGB 首次决策：完整已评分池失败分解

按[事后协议](PC_RGB_FIRST_DECISION_FULL_POOL_PROTOCOL_20261107_CODEX.md)，
在 40 个已曝光 TwoRoom 任务上重放了缺失的 **120 条父链、3000 步**，
并与已有 600 条前缀—尾部物理重放合并。每臂只使用首轮自己实际
评分的 3 条父链、9 条探针链、4 条 B 尾部链；评价端物理真值没有
参与原规划决策。排除 2 个初态已成功任务后：

| 首轮规则 | 16 次评分中存在曾成功链 | 实际选中链开放环曾成功 | 存在成功链但选中失败 |
| --- | ---: | ---: | ---: |
| 普通 lookahead | 26/38 | 16/38 | 10/38 |
| 中心化向量 | 26/38 | 17/38 | 9/38 |
| zero-relative 向量 | 26/38 | 17/38 | 9/38 |
| 身份打乱 | 26/38 | 16/38 | 10/38 |

四臂各自池中第 25 步成功的 oracle 都为 20/38；原选中链分别为
13、14、14、13/38。曾成功与末步成功分别统计，并非相同目标。
每臂没有成功链的 12 根也保留在分母；这仅限制该臂首轮已评分池，
不能判定完整闭环搜索不可解。

这一分解表明：在这些已评分候选和该模型末帧分数下，**选择损失是
值得继续研究的具体问题**，但物理 oracle 不可部署，不能据此把某种
新选择规则认定为修复。原规划器只派发前五步并重新规划，表中的
25 步开放环反事实不等于闭环成功，也不能据此判定组件优劣。

## 核验与范围

每个原始选择重新由 16 次已记录评分和原稳定选择器重建；动作哈希、
派发动作和已执行步的距离与原闭环日志一致。独立检查 120 条父链
的前十步与此前同前缀物理重放一致，逐步验证全部 3000 步成功谓词，
并复算 160 个臂级汇总；相关测试 **4 项通过**。Gymnasium reset
观测类型和动作转换警告仍存在。同环境重复不等于独立物理后端认证。
