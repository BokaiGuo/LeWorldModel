# TwoRoom 同前缀尾部排序：事后开发诊断

此分析使用已曝光的十个开发任务及既有封存的 8 前缀 × 8 共同尾部；
不是预注册实验、独立确认、可部署策略或 PC1 通过判定。

在物理步 15、20、25，对每个前缀内所有无序尾部对，比较模型目标代价、
真实后继经冻结编码器的目标代价、物理目标距离的排序。严格差值为零时
分别记平局，不进入对应一致率分母；不混合三种量的数值尺度。先按任务
汇总配对，再以有效任务等权报告。另报告前十步未曾成功的前缀子集。
各时间点评估距离排序；成功排序使用完整 25 步内曾成功，针对前缀未
成功的前缀这等价于尾部内曾成功。成功和失败不同的尾部对才有成功
排序分母；无有效对的任务以 null 表示而不是零。

验收输入的哈希绑定、共同前缀与共同尾部动作、物理轨迹前十步和成功
标记。真实物理状态及真实后继编码只用于评价，不提供给规划器。结果
是诊断性后验观察，不改变历史停止规则或 gate；不能仅凭标量排序判定
世界模型动力学存在实现错误。
