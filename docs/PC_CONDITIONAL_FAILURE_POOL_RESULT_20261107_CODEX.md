# 条件尾部 CEM：失败任务完整池复盘

按[事后诊断协议](PC_CONDITIONAL_FAILURE_POOL_PROTOCOL_20261107_CODEX.md)，对两臂实际选链至少一臂失败的全部任务 root 38、39，逐条重放每臂两条 incumbent 与 192 条尾部候选，共 **776 条链、19,400 环境步**。每臂已选链的物理逐步结果与原记录一致；候选动作、模型分数和选择均取自既有封存，不用真实结果进行选择。

| root／臂 | 池内曾成功链 | 池内末步成功链 | 选中链曾成功 | 最低模型代价成功链的排名 |
| --- | ---: | ---: | --- | ---: |
| 38／末帧更新 | 1/194 | 1/194 | 是 | 1 |
| 38／时序更新 | 7/194 | 5/194 | 否 | 2 |
| 39／末帧更新 | 2/194 | 2/194 | 否 | 62 |
| 39／时序更新 | 15/194 | 15/194 | 否 | 14 |

这三个失败臂的各自候选池中均存在可执行成功链，因此仅在这三个具体情况下，可以明确排除“该臂这 194 条已评分链全部不可解”作为唯一解释。模型末帧分数将失败选中链排在全部成功链之前：例如 root 38 时序臂的选中失败链代价为 `72.953`，最佳成功链为 `131.885`；root 39 末帧臂分别为 `14.132` 与 `169.970`。

这不是证明搜索覆盖已充分：池不含之前 600 条初始搜索中的全部候选，也没有检测其他未查询动作；每臂池由不同自适应搜索生成，成功链数量不同不代表可公平比较生成效率。对这些链的真实后果不能在部署时免费获得。结论支持优先分析同池的预测、真实编码和任务评分失配，而非直接增加候选数量或宣称改选第 2 名就能泛化。

相关失败覆盖、评分排名、平局和原 CEM 测试共 **6 项通过**。重放使用同一模拟器实现，并出现已知 Gym reset 观测类型和动作转换警告；不是独立环境认证。该分析按既有失败事后选根，不能作为独立性能、闭环增量或 PC0–PC5 通过证据。
