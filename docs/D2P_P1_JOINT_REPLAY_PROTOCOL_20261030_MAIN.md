# 联合优化动作 CUDA 重放合同

对已封存联合优化的八臂，每臂固定两条 15 步动作：原候选 0 的
incumbent 与该臂按模型分数及候选索引选出的联合优化 winner。
不根据物理结果筛选。重放是已知根开发检查，原候选生成成本、
不同动作域和独立根问题仍未解决。

固定动作字节、任务和归一化，冻结 checkpoint；主机 CUDA 使用相同
禁用 TF32、数学注意力模式。分别执行整体与逐包两条模型路径，
保存每包 latent、逐包上下文和标准化动作；比较两条路径及已封存
联合优化的首包和终包预测，incumbent 比较其原始预测。记录模型
哈希、设备和实际 predictor/action encoder hook。异常、设备或绑定
不匹配停止，不使用 CPU 推理，不授权物理执行。重放通过只是动作与
模型接口证据；后续仍需单独审核来源、实际物理执行和共同后缀、
独立后缀公平比较，不开放 P1 gate。
