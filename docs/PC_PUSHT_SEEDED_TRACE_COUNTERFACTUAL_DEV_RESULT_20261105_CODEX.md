# 固定 reset 的首次动作链物理反事实

依 `PC_PUSHT_SEEDED_TRACE_PARITY_DEV_PROTOCOL_20261105_CODEX.md`，
记录受控均值选择臂的每步动作与物理状态。带 trace 的完整闭环
47/50，逐任务成功标记与无 trace 均值臂一致。对 50 个首次计划，
重放与实际执行的 1199 步动作和完整物理状态逐项一致；最大绝对差
均为 0，50/50 通过预定容差。提前成功的环境不会执行完 25 步。

在全部 50 对轨迹通过上述 parity 后，使用同一物理初始化、各自的
首次计划，独立评价最多 25 步、无重规划的候选真实后果：

| 首次计划选择 | 25 步内成功 / 50 |
|---|---:|
| 原生均值 | 36 |
| 已评分样本最优 | 35 |
| 二者共同模型评分选低 | 36 |

均值与样本最优配对中，7 例仅均值成功、6 例仅样本成功；三臂
不是三套独立任务。第 22 号任务的样本链有 1 条实际执行动作
越过声明动作域且该链成功，环境没有裁剪该动作。其余两类候选
全链没有越界。在排除该任务的 **49 个共同合法候选对**上，均值、
样本、共同评分的成功分别为 **36、34、35**。不静默裁剪，也不将
越界成功计为严格合法成功。

该结果说明首次固定候选池中模型最低分选择并非必然对应更好的
物理结果；差异小、仅一个已暴露开发面板，不构成总体统计结论。
首次 25 步开放环成功不等于 50 步带反馈闭环成功。物理真值仅在
评估端使用；此结果不证明响应组合价值、不改变 PC gate。
