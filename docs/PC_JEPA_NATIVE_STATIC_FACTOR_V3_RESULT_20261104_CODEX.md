# JEPA 原生 PushT 静态图像因子诊断

## 渲染问题

[回调与绘制原语追踪](../le-wm-main/results/pc_jepa_native_render_primitive_probe_20261104_codex.json)发现几何复制后的环境额外画了一条红色线；[标志对照](../le-wm-main/results/pc_jepa_native_contact_overlay_probe_20261104_codex.json)显示关闭 Pymunk 默认碰撞点调试绘制后，两环境目标图的 242 个通道差异消失，原目标图本身不变。该控制定位了前两次静态重建失败的具体来源：复制几何未复制或清除原 reset 的碰撞缓存。不能据此认为实际轨迹的原生 RGB 都不含碰撞调试图形，也没有改动正式环境或规划器。

按[新协议](PC_JEPA_NATIVE_STATIC_FACTOR_V3_PROTOCOL_20261104_CODEX.md)，每个边界从原 seed 分别完整重放。两个臂的 10、15、20、25 帧及此前所有帧的 RGB、状态和本体均与原始记录逐元素一致；几何恢复后原图也精确一致。分别保存原生绘制和去碰撞点绘制的 66 张图像，后者只用于离线敏感性诊断，不是实际观测。

## 冻结 encoder 的目标 MSE

下表为去碰撞点版本，四列依次为原始几何、仅替换 agent、仅替换物体位置和姿态、两者都替换；目标图采用相同去碰撞点绘制。两臂 10 帧来自同一个共同起点，不能视为两个独立样本。

| 臂 | 帧 | 原始 | agent | 物体 | 两者 |
|---|---:|---:|---:|---:|---:|
| response | 10 | 1.19527 | 1.08693 | 0.24014 | 0 |
| response | 15 | 1.15838 | 1.08693 | 0.17658 | 0 |
| response | 20 | 1.17017 | 1.01269 | 0.21005 | 0 |
| response | 25 | 1.04709 | 1.01286 | 0.03701 | 0 |
| CEM | 10 | 1.19527 | 1.08693 | 0.24014 | 0 |
| CEM | 15 | 1.19226 | 1.08693 | 0.18076 | 0 |
| CEM | 20 | 1.34513 | 1.11074 | 0.23458 | 0 |
| CEM | 25 | 1.11095 | 1.09517 | 0.03621 | 0 |

这组静态特权替换中，物体替换导致的 MSE 降幅在全部八行都大于 agent 替换，故不能依据这一诊断将此前目标 MSE 下降笼统归因于 encoder 忽略物体。替换同时改变位置和姿态，且图像不是物理可达反事实；不能据此认定动态预测或控制目标正确。

## 碰撞绘制敏感性及边界

两臂第 20 帧，原始真实图与去碰撞图各仅差 6 个通道，但在移动几何后，保留旧碰撞缓存的叠加会改变反事实图像。两者均替换时，原生绘制对目标的 MSE 分别为 response `0.21984`、CEM `0.27072`，去碰撞点版本均为零。其他受测帧对应的两种模式没有像素差异。默认模式的这些反事实携带旧碰撞缓存，不应解释成新的真实接触；两种绘制模式的完整分数及交互项保留在[结果](../le-wm-main/results/pc_jepa_native_static_factor_v3_20261104_codex/scores.json)。

[独立 CPU 审计](../le-wm-main/results/pc_jepa_native_static_factor_v3_20261104_codex/audit.json)核对全部 16 行分数、66 张图与特征绑定、基图、目标图和算术，误差为零；它没有独立重跑 encoder 或物理。原模型训练和 normalizer 来源仍未知。结果不能证明目标在 15 步可解、解释全部模型—物理失配，亦不构成 PC0–PC5 通过或统计优势。
