# P1 新重选前缀：两项交付与剩余条件

本记录汇总已有开发实验，不改变封存合同，不构成新的实验预注册。
新重选前缀与旧 joint-selected、后续 hybrid 前缀是不同实验对象，
不得相互替代。

## 共同十步后缀

新重选前缀的 selected、zero、greedy 已完成 24 anchor、1008 条预定
共同后缀分支及保存态验收：1004 条完成十步、4 条原生提前停止。
其中两条在第九步停止，没有第十步观测；两条在第十步停止，具有
真实第十步观测。不得补全提前停止的轨迹。结果和 1008 行配对表见
`D2P_P1_UPHILL_H10_COMPLETE_RESULT_20261031_MAIN.md` 与
`../le-wm-main/results/p1_uphill_observed_pairing_table_20261031_RUN01.csv`。
表逐项保留前缀的物体位置、角度、推杆及联合 XY 变化，后缀终点、
相对同前缀零后缀变化、规划终点和停止状态。

特定成功反馈后缀的交叉执行中，selected 和 zero 前缀下均原生成功，
zero 的物体终点误差更低。因此该成功实例不能证明 selected 的独有
能力导致成功。共同后缀只检验固定动作效果，不证明各自重新规划
后存在优势。详见 `D2P_P1_PACKET_FEEDBACK_CROSSOVER_RESULT_20261031.md`。

## 真实 RGB 后各自规划

已有实验从各自真实 cp5 RGB 规划十步后缀并物理执行。共同四起点
Adam 的 selected、zero、greedy 分别原生成功 0/8、5/8、0/8；逻辑槽
共享两个已知根和重复轨迹，不能解释为独立成功率。另一个 packet
objective 的三类前缀各 0/8；不得混合不同合同。前缀生成与结构
计算未纳入认证的统一端到端预算，所以这些不是公平强基线结论。
来源和完整性见 `D2P_P1_RESELECTED_INTERVENTION_RECHECK_20261031_CODEX.md`
及 `D2P_P1_PACKET_OBJECTIVE_RESULT_20261031.md`。

## 指标与下一阶段

根 0 selected 前缀物体位置和角度未变，但推杆目标误差及联合 XY
误差下降；不能据物体静止断言整个任务无即时进展。历史合同未预先
单独固定完整任务的非即时进展指标，不能事后补定以声称 P1 通过。
下一项新实验须在观察结果前固定指标、候选与对照、资源约束、根的
生成和排重、样本数及停止与删失处理，并保留原生成功、位置、角度、
推杆与实际各类计算成本。物理状态仅用于评价，不进入 RGB 规划器。

近期 hybrid 实验另发现一个同真实 cp10 输入、同时间动作预测排序
反转；两个现有 normalizer 对照均未消除该实例，但 checkpoint 实际
训练统计尚无 authority，不能因此排除所有接口问题。详见
`D2P_P1_CP10_PAIRED_PREDICTION_RESULT_20261031.md` 和
`D2P_P1_CP10_NORMALIZER_RANK_RESULT_20261031.md`。

当前 P1 不通过；未建立独立任务上的机制合取、端到端预算公平或
训练外来源。已有失败不能直接解释为理论不成立，也不能假设必有
尚未发现的代码错误。
