# 已选前缀的共同后缀干预（探索性）

在coherent四臂结果之后固定，不作为独立确认。前缀集合是四臂各自
事前封存并真实执行的首五步，加上zero五步，共五种；不是按成功筛选。
共同后缀固定为structured臂已执行的第6至20步（15步），另加15步zero，
共10条分支，全部执行和报告。后缀原来自反馈控制，现在固定后做因果干预，
不能称为所有前缀各自最优后缀。

从同一真实reset和warmup重放，用实际任务goal绑定；动作float32逐步检查，
原生停止与越界保留，不补值。记录0/5/10/15/20状态与RGB。
比较绝对终态与各前缀的zero后缀终态，分列物体位置、角度、推杆和jointXY。
immediate_progress是原四臂短视筛选臂，不能冒充严格一阶段greedy最优解。

该实验只能回答相同动作后果是否被前缀改变，不能证明可规划能力更强。
后续仍需相同预算各自后缀优化、独立根和公平强对照。
真实分支结果不得反馈给正式选择器；P1保持未通过。
