# State-assisted 后果描述：GPU 开发结果

协议：`PC_STATE_EFFECT_LOCAL_DEV_PROTOCOL_20261106_CODEX.md`。本轮属于 `official_state_assisted`，不支持 RGB-only gate 晋级。

## 实际完成

固定4个已暴露 PointMaze episode，起点帧0、目标帧5、两视角，共8个条件。当前 proprio 为官方路径的 x,y,vx,vy；目标只编码图像，真实后继与位置距离只用于评价。

新增可复用 `pc_action_effect_descriptor.py`：保留完整动作字节指纹、动作序列、时长与有符号后果向量；拒绝时长不等、越界、重名和非有限评分。它是有限探针库描述工具，不是新学习模型或完整规划器。

CUDA 实跑：80次封装预测、8次反向求导、32次额外图像编码，阶段同步墙钟2.054秒。时间包含阶段内特征收集及收据开销，不含模型加载和最终封存，不能用作完整系统效率主张。冻结参数前后指纹相同。

## 数值与未查询幅度

构造幅度±0.003，另以±0.001检查差分；未查询幅度固定为±0.03、±0.1。全部8个条件至少一个差分尺度满足预定 AD/FD 容差。

这是五个原始 x 动作共同变化方向上的**标量代价导数**核验，不是完整 Jacobian/JVP/SVD 认证，也不是接触动力学可微性的认证。

| 未查询代价预测规则 | 任务级平均 MAE |
|---|---:|
| 父链代价常数 | 0.00386091 |
| 构造 probe-min 常数 | 0.00390107 |
| AD 线性 | 0.00294259 |
| 二阶 Taylor | 0.00607923 |

二阶规则在3/4个任务均胜两常数，但总体 MAE 更差，因此**预定开发出口不满足**。主要失效为 episode1882 原始视角：二阶 MAE=0.0376948，父代价=0.00473719；同条件两个差分尺度误差分别0.00280094、0.0134602，提示局部近似对尺度敏感。不能只报告3/4胜率。

AD 线性平均误差较小是开发观察，不是事前注册的独立胜出或净规划收益。不能看完结果后将二阶规则门槛改为“任何规则平均更好即可”。

## 真实后果对齐

仅对已有 zero、+0.1、-0.1 物理链评价，到目标位置的欧氏距离为物理指标，不是标准成功判据。

| 选择规则 | 平均物理遗憾 | 并列感知最优条件数 / 8 |
|---|---:|---:|
| 模型预测评分 | 0.0337933 | 1 |
| 真实终帧图像编码评分 | 0.0190249 | 3 |
| 固定零动作 | 0.0254745 | 4 |

相机平移改变模型最终选择：3/4任务；改变真实编码选择：1/4任务。已有物理审计确认两相机轨迹一致。该结果说明视觉路径/评分存在视角敏感性；不能仅凭它区分编码器、预测器或目标表示的全部责任，也不能推出所有视角/任务失效。

## 独立重算

`pc_state_effect_local_audit_20261106_codex.py` 从保存的预测表示和真实编码重算32个未查询代价、24个真实编码代价，核对物理距离、选择遗憾、输入和代码哈希。重算结果与运行日志一致。

物理后果来自先前完整重放产物，本轮没有重跑物理仿真；±0.03只做模型内预测评价，没有对应新增物理轨迹。所有统计以4个任务为单位，双视角不是8个独立样本。

## 研究决策

不将该二阶局部外推配置升级为 Bridge Retention 的部署描述，不扩大同配置 seed。已证实动作梯度通路没有被全局 no_grad 关闭；仍未证明行动后果在当前支持上能可靠选择物理更好动作。

完整有限动作向量可用于后续**独立声明的**固定候选保留实验，但不能把本轮三动作直接评分当成超越 ordinary lookahead 的增量。原方案的可执行前缀、真实后继和组合利用仍需验证；本轮未实现或宣称其通过。

主协议 RGB-only 不放宽。PC0–PC5 均不改判，完整研究目标仍未完成。
