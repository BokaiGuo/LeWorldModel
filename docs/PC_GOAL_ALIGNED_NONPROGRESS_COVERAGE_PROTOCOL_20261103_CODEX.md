# 目标条件化搜索的非即时覆盖：封存轨迹归因协议

此前目标条件化版本 24 条最终链均不满足非即时进展；这是获知结果后的
探索性归因，不重新运行规划，不修改已经停止的单配置或作独立确认。
对该版本封存的 goal、svd、random 三个结构臂，各 24 根，复用先前
多方向覆盖归因的分析函数：依照原精确动力学和 float32 执行动作，
重算第一候选库、最终保留的十步组合和全部已评分十五步链的前五步
距离；非即时定义为 `prefix_distance >= initial_distance - 1e-10`，
同时要求前缀非零。将最终链与已评分完整链逐位匹配并核对最优。

报告每臂第一库、保留库、已评分链和最终选择中满足条件的根数，
每根已评分非即时链的最佳终距及未覆盖根，不把未选中链称为 PC2
见证；完整链包含精修生成的动作，因而可能没有来自保留库。
同时报告每臂完整链评价数量及证据哈希。若源哈希或动作、分数
核验失败立即停止。输出排他创建，统计为开发数据上的描述而非
新调参、独立样本或强基线确认。
