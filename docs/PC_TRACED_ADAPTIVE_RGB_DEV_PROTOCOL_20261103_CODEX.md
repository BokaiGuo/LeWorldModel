# 逐批封存的自适应分配 RGB 开发协议

在运行结果前固定。本实验将 `PC_TRACED_SUFFIX_ALLOCATION_E0_DEV_PROTOCOL_20261103_CODEX.md` 的自适应策略接回既有固定终点真实 RGB 执行器；复用四个已暴露 PointMaze 根和冻结模型，仅作开发接线比较。反馈时刻、目标、动作域、相机、归一化、固定终点、15／10／5 步规划、每次决策 480 五步预测 token、旧计划尾部重评分及选择均沿用 `PC_MULTI_NOMINAL_RGB_DEV_PROTOCOL_20261103_CODEX.md`。

四臂分别为原 SVD 同库均匀分配、同库自适应分配、原同库 greedy、全动作 CEM。均匀、greedy、CEM 调用旧冻结 `decide`；自适应保留相同多名义 SVD 候选、候选即时评分、后缀／联合精修总预算比例、评分、随机数、旧尾部规则。15／10 步时先每候选各 12 个完整链样本，此后每次把不超过 12 个样本分配给当前完整链模型分数最低的候选，保留各候选 CEM 均值、方差、随机流和最佳链；最终按完整链选中并以余下预算共同联合精修。5 步时无后缀，行为与均匀臂相同。保持精修前最佳链和最终与旧尾部的比较；真实选中链不得继承其他前缀的机制资格。

在每次实际模型预测入口封存每批原始动作、模型预测位置、评分、样本数与 token；候选、各候选分配、模型编码、结构计算、计划和执行的账本与 hash 分别存档。每臂同一 token 政策，结构成本单独报告；这是单预算接线开发而非完整质量—成本曲线或全计算公平认证。执行完后在同一 MuJoCo 后端对封存动作重放，并核对决策、尾部、RGB 哈希与动作绑定；不声称逐像素重放。

本实验不含跨后继响应程序组合或共同后缀机制干预；四根已暴露，checkpoint 和 normalizer 来源仍未闭合。不论结果如何不修改 PC2、PC3 或历史 P1，不能把此面板当独立确认或重开旧 PointMaze 非即时机制协议。
