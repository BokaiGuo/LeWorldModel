# State-assisted 局部误差原因诊断

这是对已暴露任务和失败条件的事后工程诊断，不是新方法确认，也不更改上一轮的预定停止规则。

对同一4个任务、两个相机、同一冻结 checkpoint、预处理和原始动作，首先验证 FP32 的零动作和±0.003 代价可重现上一轮记录。将相同的 FP32 编码视觉与 proprio 特征固定，再仅把冻结预测器权重和输入转为 FP64；不重新编码、不训练、不把 FP64 变成部署版本。

比较 raw x 方向的代价、中心差分、二阶差分和直接动作梯度，尺度固定为 0.0001、0.0003、0.001、0.003、0.01、0.03、0.1。额外在 x=±0.001 处计算梯度以观察局部变化。所有 raw 动作仍是相同的五步常数控制。记录真实调用数及代价，不引入新物理标签。

区分三类结论：FP32 与 FP64 在相同尺度的二阶差分差异是精度敏感性；FP64 不同尺度之间的差异是可复现的尺度依赖（仍可能包含其他实现因素）；FP64 也不能自动证明真实环境动力学光滑或外推可信。报告全体8条件和已知 episode1882/camera0，其他条件不是独立确认。

输出追加独立文件，验证权重浮点类型恢复后逐字节指纹一致，禁止覆盖旧结果。无新选择准入阈值，不根据本次诊断追溯改判原实验。
