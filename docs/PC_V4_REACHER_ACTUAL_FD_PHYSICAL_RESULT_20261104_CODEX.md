# V4 Reacher 实际有限差分探针：模型与物理响应

按[协议](PC_V4_REACHER_ACTUAL_FD_PHYSICAL_PROTOCOL_20261104_CODEX.md)，对 v4 第三次决策实际使用的两个名义动作及各自 20 个 `±0.05` 坐标探针，分别从相同重建状态在 MuJoCo 执行五步；模型输出和实际末帧编码都投影到原二维 chart。这是已暴露单根、一个时刻和一个扰动尺度。

| 名义动作 | 模型矩阵范数 | 实际末帧差分矩阵范数 | 矩阵绝对误差 | 相对实际范数误差 | 矩阵余弦 |
| --- | ---: | ---: | ---: | ---: | ---: |
| `(0.25, 0)` | 5.660 | 5.954 | 1.540 | 0.259 | 0.966 |
| `(0.25, 0.5)` | 9.897 | 9.932 | 1.168 | 0.118 | 0.993 |

矩阵整体相似度掩盖了方向差异。对模型矩阵的两条右奇异方向，用两侧**已测坐标差分矩阵的线性组合**评价：第一名义动作的第二方向，模型响应范数为 0.106、实际编码差分组合为 1.403，方向余弦为 -0.274；第二名义动作相应数值为 0.809、1.190、0.691。这不是在奇异方向上直接执行扰动，不能替代实际谱方向的有限尺度验证。

模型与实际目标 MSE 对十组 `+/-` 探针排序：第一名义动作有 9/10 组相反，第二名义动作为 0/10；模型目标 MSE 与物理关节终距分别为 10/10 和 0/10 组相反。第一名义动作的正负目标 MSE 差绝对值，模型为 `0.00128–0.00847`，实际编码为 `0.000845–0.00381`；这些是有限单状态对照，不是独立样本统计。

原模型矩阵已从实际 trace 重建；42 条动作全部由相同热身和前两包重建初态，两个名义动作末帧与此前封存帧一致。[数值审计](../le-wm-main/results/pc_v4_reacher_actual_fd_physical_20261104_codex_audit.json)重算矩阵、每列和正负排序；[复编码审计](../le-wm-main/results/pc_v4_reacher_actual_fd_physical_20261104_codex_reencode.json)对 42 张保存末帧使用同一 checkpoint 再编码，最大差异为零。它不是独立 checkpoint；物理动作来自同一模拟器，物理末帧差分受图像量化影响。

结果表明局部模型—实际响应及任务排序依赖名义动作和方向，不能以整体矩阵余弦认证全部方向。没有据此定位代码 bug，也不能由这一根推翻理论或宣告 PC1 通过；仍缺直接谱方向扰动、多尺度、AD/FD、其他时刻与根的认证。
