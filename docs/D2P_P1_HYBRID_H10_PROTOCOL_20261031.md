# 修复后混合前缀：共同 H10 物理干预

固定两个已知根、各自模型事前选出的第一个五步前缀，以及既有
H10 面板对应 root/goal/condition 的 42 个共同后缀（含零后缀）。
参考历史面板中同一根、同一任务、同一 42 后缀的 zero 与 greedy
前缀；不按 outcome 选择后缀或添加样本。两个根不是独立确认。

每个后缀从原 root 和 warmup 重放：逐帧比较原 CUDA 反馈运行保存的
11 帧 warmup、6 帧计划阶段 RGB 像素、状态和动力学快照；检查前缀
原始动作、模型赢家以及 cp5。任何不符即停，禁止派发后缀。
保存固定末态与相对同前缀零后缀的变化；原生早停和越界删失不补值。
此共同动作干预只测指定后缀的物理响应，不能单独证明自行规划能力
或者 P1 成立；推杆、物体位置、角度、联合状态和成功须分开。
