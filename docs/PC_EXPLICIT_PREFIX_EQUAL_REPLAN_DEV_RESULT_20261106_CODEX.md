# 选中首计划前缀：等预算尾部重优化开发诊断

按[事前协议](PC_EXPLICIT_PREFIX_EQUAL_REPLAN_DEV_PROTOCOL_20261106_CODEX.md)
在十个任务的原先选中首计划上，分别固定选中、置零、随机三种
前缀，对同一原尾部进行每臂 3×40 次完整链模型评分优化，再执行
各臂模型评分最优链。每任务含初始评分共 363 条；十任务 3,630 条。
跨臂共享噪声，物理标签不进入模型或选择。每个实际原链的初始
模型评分均复算并与来源审计相符；物理初态与实际 trace 相符，
重优化后的动作均合法。

| 固定前缀 | 重优化后链成功数 |
| --- | ---: |
| 实际选中前缀 | 6/10 |
| 置零前缀 | 5/10 |
| 随机合法前缀 | 2/10 |

一项任务上选中前缀的重优化链成功而两个对照失败；但该任务的
**原先实际首计划并未成功**，所以这是一条新的事后反事实链，
不是正式规划器实际选中并执行的成功链，不能直接登记为 PC2
机制见证。另有任务置零前缀重优化成功而选中前缀失败。

本实验保留失败分母，补上了此前缺失的等模型评分机会对照，但
只用一组固定噪声和候选，未证明接触机制、后续控制机会的变化、
跨任务统计显著性或相同最终闭环收益。可见状态和动作合法性检查
不替代来源认证或隐藏状态完整性。
