# P1 全候选选择：已知根 CUDA 重放合同

目标是验证事后开发的全 20 候选最小正则模型分数规则能否通过
现有部署重放接线；不是独立确认，不开放物理准入或 P1 门。规则
不排除 zero 或 incumbent，也不强制产生非贪心动作。候选和优化
结果使用已保存的八臂完整候选库；全部候选的原有搜索成本不能
省略，也不能称为四候选成本。

固定八臂 × 两行：每臂索引 0 incumbent 和全候选选择。重复动作
仍执行并标注，不作为独立样本。逐行在主机 CUDA 对三段五步
动作比较连续 rollout 与分段 rollout，检查源前缀、源端点和
前缀动作历史，并保存逐段 latent、上下文及动作 token；模型
哈希前后保持一致，不能训练或降级为 CPU。失败须保留原记录，
不得转译为理论负结果。完整重放验收之后才能另行考虑物理合同；
本合同本身不授权物理或发布。模型内成本改善不是物理机制或
公平闭环优势。
