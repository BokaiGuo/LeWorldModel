# RGB 表示导数伴随误差固定样本重放

事后选取多时域检查中唯一未通过伴随阈值的任务 9000、25 步、方向 0；这是有选择的排错样本，不是新任务。复用同一封存动作、方向、随机投影和冻结模型，在 math SDPA 下连续重算 10 次 JVP 与 VJP，并使用相同三种扰动步长记录投影后中心差分。逐次记录 `u·Jv`、`v·Jᵀu` 和差分，保留重放序列，不改变原试验阈值或结果。

比较重复数值是否波动以及两种求导与有限差分的差异，不能凭单个尺度判定谁是真值；默认后端二阶反向不支持的事实独立保留。输入只包含 RGB，物理状态不用于选择；样本已曝光、筛选，不能作为完整 PC1 证据。源与模型哈希核验，结果排他创建。
