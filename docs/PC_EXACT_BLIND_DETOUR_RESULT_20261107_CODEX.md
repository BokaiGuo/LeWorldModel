# Exact-wall 盲脱困对照：开发结果

按[运行前协议](PC_EXACT_BLIND_DETOUR_PROTOCOL_20261107_CODEX.md)，
比较 24 个已曝光任务、每任务 384 个候选和 15 个动作步。盲臂在第
5 个动作后无条件设置侧向目标；受阻臂使用既有预测受阻触发。两者
各计每任务 5760 动力学步；旧的无脱困臂是同伺服事后消融。

| 指标 | 无脱困 | 固定时刻盲脱困 | 受阻触发 |
| --- | ---: | ---: | ---: |
| 终距 < 0.05 | 12/24 | 14/24 | 16/24 |
| 平均终距 | 0.26349 | 0.20014 | 0.14945 |

受阻臂相对盲臂独胜 2（root 10、13）、独负 0，**未达到事前规定的
至少 3 独胜且至多 1 独负的开发出口**。不能据此宣布受阻信息贡献
成立；也不能把这个固定时刻盲策略视为全部非响应策略的上界。
先前对无脱困的 4 个独胜仍是已曝光任务上的开发观察。

盲臂 9216 条链均检查动作边界、与无脱困臂前五个动作一致及逐链
重放一致，验证重放另计 138240 动力学步；相关测试 7 项通过。
盲触发不读取碰撞标志；改变动力学函数返回的碰撞标志不改变动作，
但控制器仍依赖模型预测位置构造并跟踪侧向目标。两个对照均使用
精确状态与同一底层动力学，等模型步不等于等墙钟。盲臂仅触发
一次，受阻臂可多次触发，不能将对照解释为触发次数完全匹配。

结果不构成 RGB-only、真实闭环、Action-Effect Descriptor 或独立任务
证据，不改变 PC0–PC5 状态。
