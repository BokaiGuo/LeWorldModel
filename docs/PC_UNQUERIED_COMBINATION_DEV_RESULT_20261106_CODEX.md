## 初态绑定与实现检查

首轮发现原 runner 使用的数据集图像与 reset 后重渲染图像在归一化
像素空间不同，最大绝对差各任务为 2.19–3.12。另做完整同面板
重放：七个任务捕获上下文与对应数据集图像逐值一致，物理重放
初始快照与原 runner 对应首步快照逐值一致。两轮模型分数与全部
成功标签一致。但“初始数据帧与真实重渲染不同”依然限制模型预测
与物理后果的解释；初态快照也不证明所有隐藏状态或物理轨迹一致。

扩充核验首次尝试误将底层 `_get_obs()` 的数组当字典读取而失败，
已修复并重新运行；原结果保留。两项测试通过，包含留出单元数据
改变不影响预测和成功时刻分层。初次沙箱运行因 CUDA 不可用失败，
批准后使用 GPU 完成。

## 决策与边界

**按预先冻结的开发规则，不将该线性描述接入端到端搜索。**
其结果不支持描述满足未查询预测条件；物理候选池全失败且存在
首帧图像差异，不能据此下结论说物理信息一定无用或模型理论失败。
更不能把评价端 B 最优作为免费合法起点。

因此第二项“合法起点搜索利用”的**正式增量比较尚未实施**；
第一项未过规定出口，直接扩大该配置会违背本轮决策规则。模型与
真实物理后果对齐、不同构造的可行性、独立来源、PC2–PC5 仍需
在有依据的新候选上完成；本实验不改变 gate。
