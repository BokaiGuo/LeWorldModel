# P1 固定动作的 action normalizer 敏感性

现有全量本地 PushT 归档的动作统计为均值 `[-0.00781256, 0.00686069]`、
样本标准差 `[0.20846749, 0.20674867]`，与已有公开约定的
`[-0.0087, 0.0068]`、`[0.2019, 0.2002]` 不同；标准差约高 3.3%。
归档不等于 checkpoint 原训练数据或其实际 normalizer，不能据此把
任何一套值认证为正确。统计 receipt 哈希
`c816c535e08a946a6f7464c659b23e98022b0375359bf5a7add4edd6e018cdda`。

对之前固定的 19 条无删失 Adam 动作，在主机 CUDA 使用同一真实 cp5、
同一模型、同一真实终帧编码分别比较原结果与归档统计替代值。
替代路径先按原均值和标准差还原两包已存历史动作，再用替代值
重编码历史与两包实际动作，避免只改变未来动作的归一化而错配
历史。5 条原生停止轨迹仍不纳入固定十步误差；没有新物理执行。

当前 normalizer 的预测对真实终帧 latent MSE 均值为 **0.257056**，
替代值为 **0.257405**；19 条中 10 条下降、9 条上升，单条误差变化
的最大绝对值为 **0.01937**。这批已知根上不支持将替代统计作为
一项一致的预测修复，但不排除正确训练期 normalizer 是其他值，
也不排除对新的优化或其他任务产生更大影响。未更改正式规划器。

冻结模型前后哈希一致，保存向量与真实编码的误差算术及固定动作
身份测试通过；测试不独立重新运行神经预测。结果来源于两个已知
根、重复轨迹和事后对照，不能推断训练来源或 P1 通过。
