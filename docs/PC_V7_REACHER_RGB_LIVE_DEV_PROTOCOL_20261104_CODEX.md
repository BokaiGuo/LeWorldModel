# v7 Reacher 真实 RGB 反馈：已暴露单根开发协议

以 v5 已暴露的 Reacher 根 `20263160`、相同原冻结 checkpoint、原动作统计、相同目标图像、真实同后端 warmup 与实际观测为输入，另运行 v7 response 一臂，不覆盖 v5。三次规划分别为固定终点剩余 15/10/5 步，每轮仅执行前 5 步；动作历史和 carry 只来自该臂自身执行，保留三次完整预测调用、配对弃权评分、所派发动作、执行前后 RGB 和物理评价边界。采用与 v7 Cube 诊断相同的 `matmul.allow_tf32=False` 与 `cudnn.allow_tf32=False`，并在预测重放时保持一致。两条二维 nominal 与 v5 相同。

各轮总预测预算 1920 packet-token，v7 为最后同批两条链评分预留相应 token；编码、SVD、同步墙钟和后续审计另列，token 不能冒充总算力。依赖捕获应包括 v7、其实际调用的 v6 核心、反馈与局部几何、预算分配及适配器；实验启动前和完成后检验。记录已暴露根的真实关节目标距离及模型 latent MSE，不修改成功阈值，不在观察结果后增根或调参。

运行后独立审计：全部动作请求的 float32 转换、时钟、派发与下一轮因果历史、每次评分及预算、carry、同批弃权规则；再用既有参考模型回放全部预测批次，以及同后端重放派发动作与四个物理边界。任何参考复算均共享模型和后端，不能称独立复现。已有 v5、双起点 CEM 仅是暴露根上的历史背景；本次不声称配对强基线或 PC4 成功率改善，也不将 E0 v7 结果拼成已完成 gate。
