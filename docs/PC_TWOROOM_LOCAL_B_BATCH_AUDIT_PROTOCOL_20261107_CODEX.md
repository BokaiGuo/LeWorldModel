# 局部尾部对照：统一批次重评分审计

对已封存的 40 个已曝光任务，逐任务重建并按固定顺序拼接两条共同 incumbent、64 条 A、普通 lookahead 实际查询的 16 条均匀 B 和新生成的 16 条局部 B，共 98 条。使用原模型、normalizer、输入图像和 32 条批次重新评分；依照 incumbent、A、各自 B 的顺序做稳定最小分选择。各臂比较相同重算的共同候选，不使用真实后果或历史物理标签。

验证候选身份、已有成本字段、模型指纹与原始输入绑定；输出每条成本偏差、最大偏差、选链是否改变及前两名分差。若重算选链改变，不将旧物理轨迹直接视为重算结果的物理收益。此为事后数值与实现审计，不是新方法或独立确认，也不能改变 gate。
