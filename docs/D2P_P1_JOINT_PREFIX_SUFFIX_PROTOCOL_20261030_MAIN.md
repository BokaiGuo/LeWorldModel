# P1 全动作联合优化：已知根探索合同

既有候选生成器使用即时 latent 阶段距离的上升梯度生成前缀，
回溯阶段只优化后缀；它没有根据完整后缀损失直接更新前缀。
本实验在已观察既有结果之后提出，使用全部固定 8 臂 × 20 候选，
不按真实结果挑根或候选。

每个候选以已封存五步前缀和对应回溯十步后缀为初始动作，在
相同原始动作范围 `[-1, 1]` 内，用冻结模型、三包 rollout 和
终态 latent 均方误差，对 15 步全部动作同时做固定四步投影梯度
下降，学习率 0.05；记录每次更新前和最后一次完整模型评分，
保留每个候选中评分最低的迭代（平分优先较早迭代）。各臂在
20 个候选中按同一终态分数、原索引稳定选择，不强制非贪心或
排除 zero。只优化动作，不训练模型。

这是用于验证联合优化能否改变候选和模型预测的开发实验；
梯度、模型调用和结构化候选的完整生成成本必须另计，不能把
模型分数下降、前缀变化或阶段上坡称为真实能力变化、等预算
优势或 P1 成立。动作边界与原 logits 球约束并不相同，不能将
本次结果当作原方法同域对照。任何物理执行须先另行绑定来源、
动作、观测、重置和完整预定名单，并逐项报告真实物理指标。
失败和全部候选必须保留；任何 GPU 或输入合同错误停止，不降级 CPU。
