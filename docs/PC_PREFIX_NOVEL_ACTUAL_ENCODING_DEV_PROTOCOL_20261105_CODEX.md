# 独有／共同池精修链：真实末帧编码诊断协议

复用 `PC_PREFIX_NOVEL_SAME_REFINEMENT_DEV_PROTOCOL_20261105_CODEX.md`
中同机会精修产生的 47 对完整链，依已有 50/50 首链物理重放
parity 准入；无独有链的 3 个任务保留无候选记录。
从相同物理初始化、相同目标重放各条链满 25 步，执行到第 25
步的真实 RGB 与数据集中同轨迹第 25 步目标 RGB 使用原生
LeWM 的 ImageNet 预处理和冻结 encoder/projector 编码，采用
和 `LeWM.criterion` 相同的 embedding 平方误差和作为实际末帧
目标代价。原记录模型预测代价为同一候选的完整链代价。
真实环境渲染须先经与 World `AddPixelsWrapper` 完全相同的 PIL
双线性缩放到 224×224，再进行上述模型预处理；直接使用
张量预处理缩放原始帧的先行结果保留但不用于解读。

记录预测及实际编码代价、25 步内首次物理成功、动作合法性。
为使终点评分对应模型 25 步预测，即使此前已成功也继续执行至
25 步；首次成功指标保持独立的“任意时刻成功”，不是最终步成功。
与前一物理反事实的首次成功逐条比较，若有不一致则拒绝解读。
不得将真实图像编码或物理标签反馈到求解器。

预定只报告 47 对内的预测排序与真实末帧编码排序一致／相反／
并列，以及两种排序在恰好一条链物理成功的任务中选中成功链的
数量和分母。编码分数只测已选开发链，不能证明模型整体视觉
能力，也不等于响应预测、闭环性能或独立确认。
