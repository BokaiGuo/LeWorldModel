# P1：同真实中点的两种已执行动作

主机 CUDA 对 24 个固定配对分别重放两条已真实执行的第二阶段动作。
两个动作都从**同一个真实 RGB 中点编码、同一个已执行动作历史**
出发，用冻结模型预测一个五步包，并与该动作实际执行后的真实
RGB 编码比较；物理数据来自此前各自轨迹。两侧前五步动作、状态、
完整快照及中点 RGB 一致。阶段二动作报告绑定执行 journal，后五步
实际动作逐字节核对。该批没有重新选择或执行动作。

按严格数值正负比较（没有预设近零容差），24 对中模型目标 latent
距离与真实 RGB latent 距离的动作排序有 4 对反向；真实 RGB latent
距离与原生联合位置误差排序有 2 对反向。两个计数不是独立的错误
来源归因，也不是统计结论：面板只包含两个已知根，部分轨迹重复。
预测目标误差和真实编码目标误差的差异可能很小，不应视为显著排名。

实际单包预测向量与真实终帧向量 MSE 平均分别为 `0.03414`（原
想象中点动作）和 `0.02973`（原真实中点动作）；这两个均值不
能相互证明哪种策略更好。原真实中点组第 0、3 行是一个具体的
评价失配：其真实编码目标距离较差，但原生联合位置误差较低；
这两行来源相近，不能当独立证据。仍不能用 latent 距离替代物体、
角度、推杆和原生成功分项。

实际调用为 96 次 encoder、96 次 projector、48 次 action encoder、
48 次 predict，均为显式代码路径计数，非独立 hook 认证；模型
参数和 buffer 前后 hash 相同。同一模型实现重放不构成独立 ABI
验证或训练数据／normalizer 来源证明。该结果不能打开 P1 gate。
