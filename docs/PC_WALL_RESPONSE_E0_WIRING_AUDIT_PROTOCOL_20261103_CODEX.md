# Wall 响应 E0 固定动作与导数接线事后审计

本协议在 E0 负结果后制定，只做诊断不更改旧选择、结果或方法成绩。绑定旧 E0 的协议、源码及其全部依赖哈希，绑定既有特权覆盖诊断。对每个根挑覆盖诊断记录中首个成功解析动作见证，只用于固定动作注入检查，不传给规划器或优化器、不声称方法发现该解。

1. 将该完整动作以四参数模板反解并重新 decode，逐元素核对动作，再用 E0 的同一批量真实 rollout 和目标评分评价，与原始见证比较；与全部五臂已选链的终距在同一评分器排序。检查注入后最小终距选择器能否保留见证；这只说明评价/选择函数能否识别已存在解。
2. 对每个根、预算和 goal/singular/ridge 臂保存的四个名义动作，重算每列中央差分，验证 0.01 结果与封存矩阵一致；另测 0.001 和 0.05，报告矩阵差异、奇异值、名义碰撞次数和动作边界。小响应、非光滑处的相对误差不稳定，另报绝对误差。
3. 按封存数据比较名义点、响应生成后候选、实际最终选中链的终距，检查模型评分、候选选择与实际 replay；零、NaN、约束/时钟错误应明确列出，不将无异常解释为方法必然失败。不得按诊断结果修改阈值、候选或旧结果。

诊断使用已公开的八个开发任务、精确状态和解析见证，不构成独立确认或 RGB-only 方法。所有输出另存、哈希绑定，记录真实额外 rollout 调用；不触碰旧 gate。
