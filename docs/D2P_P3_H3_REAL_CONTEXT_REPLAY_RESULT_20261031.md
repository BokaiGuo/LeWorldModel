52 次 predict，不包含旧实验的计算开销。

按 26 条去重轨迹计算，开放想象的终点 latent MSE 平均为
**0.49763**，真实上下文重放为 **0.05423**，26/26 下降。开放与
刷新均预测相同的后五步；但前三个上下文状态全部改变，因此只
能说明本批输入上下文差异与误差下降相关，不能把它归因于单一

编码排序一致 8 组、反向 5 组；真实上下文预测与真实编码排序

## 动作历史时间索引复核

追加独立测试，对 52 条完整轨迹逐行以实际第 6–15 步 float32
动作和对应任务 normalizer 构造两个历史 token，再与原决策日志
的 postcontext action_history 比较；52/52 字节一致。结合模型
接口中三个状态与两个历史 token 加一个待预测 token 的顺序，
本次未发现这两段动作的时间索引或归一化错位。该核查不认证
normalizer 的训练来源，也不证明 RGB 渲染分布或全部模型接口
无误。相关历史与分析测试共 3 项通过。
