# PointMaze 动作相关误差的事后分解

使用同渲染四根、两个视角、四个动作的既有已曝光封存结果。
本分析属于 state-assisted 开发诊断，不是独立或纯视觉证据。
逐条件将预测和真实后继分别沿动作轴减均值，检查动作相关变化；
按平方误差恒等式分解原始误差为共同偏移平方和中心化误差。
比较中心化模型变化与预测所有动作后果相同的零变化基线，
同时报告中心化预测与真实变化的余弦、各根结果及物理排序。

额外计算用四个真实后继均值校正的事后 oracle：这是使用未来真实
观测的不可部署上界，不作为可用校正方法或训练成果。候选和规则均
已曝光；不事后挑选任务，不将动作对和视角当独立任务，也不宣称
事先注册的确认性检验。数据与输入哈希绑定，输出排他创建。
