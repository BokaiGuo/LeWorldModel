# PushT 真实成功候选池的冻结逐层评分：事后诊断

## 结果

在已曝光的两个 RGB PushT 开发任务中，每任务重放并评估共享前缀池的全部 301 条链。任务 0 有 13 条、任务 1 有 1 条第 25 步环境原生成功链。用冻结编码器处理真实末帧和目标图，按各层 CLS 欧氏平方距离排序：

| --- | ---: | ---: | --- |
| block 1 | 24 | 269 | 否 / 否 |
| block 2 | 67 | 186 | 否 / 否 |
| block 3 | 19 | 54 | 否 / 否 |
| block 4 | 11 | 32 | 否 / 否 |
| block 5 | 14 | 137 | 否 / 否 |
| block 6 | 8 | 128 | 否 / 否 |
| block 7 | 3 | 130 | 否 / 否 |

| block 9 | 6 | 186 | 否 / 否 |

| block 11 | 1 | 129 | 是 / 否 |
| block 12 | 1 | 170 | 是 / 否 |
| 正式视觉输出 | 1 | 195 | 是 / 否 |

这里的 block 12 是未经过最终 layernorm 和 projector 的 CLS，不等于正式输出。逐层变化表明不同冻结表示对这两个固定池的真实末帧目标距离排序不同；任务 1 上第 4 层的排名优于正式输出，但仍未选中成功链。不能据此断言第 4 层具有可推广的接触信息、已定位表示瓶颈，或证明任何层能够改进预测与搜索。

例如，任务 0 中第 9 层有 2,913/3,744 个成功—失败对将成功链排在前面，正式输出为 3,666/3,744；任务 1 的第 4 层为 269/300，正式输出为 106/300。**这些对共享同一批链，不是独立样本**，任务 1 也只有一条成功链。所有层、所有候选的代价和成对统计均保存在原始 JSON 中。

## 一致性与范围

根据[事后开发协议](PC_OSFAL_PUSHT_SUCCESS_POOL_POSTHOC_PROTOCOL_20261107_CODEX.md)，共重放 602 条链、15,050 个环境步。每条链核验动作哈希、初始快照、每五步物理状态、首次成功及末帧成功；目标图的正式编码与既有目标编码一致。正式输出末帧代价对之前实验重算的最大绝对差分别为 `3.05e-5`、`6.10e-5`，满足协议容差；模型指纹在运行前后一致。结果与统计测试连同之前时序选择测试共 **5 项通过**。

首次在沙箱内启动时 CUDA 不可用，未产生结果；授权访问本机 GPU 后完成两个任务。真实末帧和成功标签仅供离线评价，不能供正式规划器选链；原数据是已曝光开发任务，不是独立确认。共享前缀使这些候选覆盖范围受限；排除两个无末帧成功样本的任务仅用于此成功排名诊断，不意味着它们可从正式性能分母删除。物理初始化快照匹配不等于隐藏状态已经得到完整认证。

此实验未建立中间层的预测器输出、未查询动作的预测质量、真实相机变化下的对应关系或描述驱动搜索增量；不能把真实后继分数直接接入部署规划。没有修改 PC0–PC5 的判断。
