# v4 保留策略同成本消融协议

针对 v4 开发负结果，固定同一 24 个已暴露 Wall 根、同一 v4
生成器、目标排序、所有逐候选后继响应探针、后缀 CEM 和联合
精修；仅将保留规则替换为 v3 的“即时最佳＋位置最远”。
两臂同用 1920 预测 token；消融臂仍实际计算和计入全部后继
响应，不享有节省探针成本的优势。所有顺序、种子和其余代码相同。

事前报告首层候选和后继响应是否一致、保留前缀交集、各阶段样本、
终距均值与 `<0.05` 数目；逐批重算预测和最终选择。两臂都通过
相同冻结方法预算，不证明局部价值或响应多样性的独立因果贡献：
它们在此一并被替换，且有限搜索、同根开发和完整计算成本仍有限。
这个新消融不更改 v4 或 v3 的封存结果，不是 PC2/PC3 确认。
