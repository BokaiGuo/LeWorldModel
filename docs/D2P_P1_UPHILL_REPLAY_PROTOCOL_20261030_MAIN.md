# P1 重选动作的主机 CUDA 接口重放协议

在已知根探索性重选结果之后，固定 8 臂，每臂两个动作：原联合
终态 winner 和模型内非即时 latent 改善 winner。全部 16 条都重放，
即使两个动作相同也保留，绝不按照物理结果挑选。所用后缀与前缀
来自同一记录；这一步不能区分单独前缀的因果作用。

复用原 CUDA 双路径重放及独立保存态消费者，对两个动作分别核验
模型检查点、归一化、动作 token、逐包历史、前缀和终态预测；
上下文与输出数组全部保存。设备必须是主机 CUDA，模型冻结，不
可 CPU 降级。选择动作和原始记录、重选脚本、协议和源文件均绑定
哈希；任何身份或比较错误即失败，不发放物理执行许可。

若重放全通过，还需新建物理合同并重新认证实际来源、初始状态、
执行、停止和观测；此协议本身不执行物理实验、不认证公平总预算、
不证明重配置能力或 P1，也不构成独立确认。
