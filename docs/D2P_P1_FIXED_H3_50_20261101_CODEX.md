# Fixed-H3 40-to-50 exploratory continuation

This new development contract uses the project's PushT `eval_budget: 50`.
It is not an independent P1 admission or a matched-budget comparison. The
fixed six-prefix denominator and prior 40-step outcomes are retained. Random
was censored at step 31 and is not reset, retried, or continued.

For each previously completed40 branch, the physical environment starts at
the original centered reset, replays the exact forty returned actions, and
checks every saved 0/5/.../40 state and RGB against the verified prior run.
Only after exact cp40 identity may the controller encode the current actual
RGB and run coherent structured H3 at actual boundary 40, logical boundary 5.
It then physically executes the selected first packet, observes/encodes actual
cp45, runs the identical H3 node at actual boundary 45, and physically executes
its first packet. Stop/censor events end the branch without fabricating cp50.

At each boundary the immediately preceding actual three-packet selected plan
is bound to the true physical episode/boundary and actual returned first
packet. H3 scoring receives `[actual_issued, previous_tail_1, previous_tail_2,
zero_packet]`: a clearly marked hold-extended carry, not the original plan.
The model context uses the last two actual previously encoded latents plus the
new actual encoding and the last ten returned actions. Neither later physical
truth nor old future observations select actions.

The six-row denominator is fixed. Five surviving branches have at most ten new
nodes and ten new RGB encodes in total, with independent measured durable
ledgers, expected H3 costs, and physical replay/continuation steps reported
separately. Old charges are historical, not new charges. Per-branch valid
native stops and censoring are terminal observations; failures remain visible.
There is no endpoint neural diagnostic and no change to the P1 gate.
