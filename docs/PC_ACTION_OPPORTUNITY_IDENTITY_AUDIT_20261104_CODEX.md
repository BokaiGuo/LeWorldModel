# 行动后果探针身份：root 留出开发审计

日期：2026-11-04。性质：对既有随机探针 v2 的后验分析，不是预注册实验、真实物理验证或规划性能确认。原始数据和旧审计未覆盖。

## 问题和方法

上一版“固定反转全部特征列”的对照同时反转训练与测试中的列，对岭回归只是坐标重命名，不检验身份作用。本审计比较同一组 A 探针对两种 B 后缀目标的预测：

1. `scalar`：最大相对改善；
2. `ordered`：按固定探针次序排列的完整改善向量；
3. `sorted`：逐候选按数值排序的完整改善向量，保留数值集合但去掉探针身份；
4. `shuffled`：逐候选以固定种子独立打乱向量，只运行一个随机种子。

每种特征均加入相同的即时分数、零尾代价和剩余时域；以一个 root 为测试，其余 root 的候选拟合岭回归。预测目标分别是 B 探针的最大相对改善及最小绝对代价；B 不作为 A 特征或候选保留输入。每个 root 内先计算候选均值，再对 16 个 root 等权平均。按 root、来源臂、depth 的候选级统计也记录在结果 JSON 中；候选与重复前缀不是独立任务。

## 结果

| B 目标 | scalar 平均 root MAE | ordered | sorted | shuffled |
| --- | ---: | ---: | ---: | ---: |
| 最大相对改善 | 0.05730 | 0.04791 | 0.05203 | 0.05687 |
| 最小绝对代价 | 0.05730 | 0.04791 | 0.05203 | 0.05687 |

相对改善目标下，`ordered` 比 `sorted` 低的 root 为 14/16，高的为 2/16；平均 root MAE 差为 −0.00413。绝对代价目标具有相同的 14/16 方向。两个目标由同一零尾代价相减得到，且模型控制项已包含零尾代价，所以这不是两项独立的验证。

## 可支持与不可支持的结论

这是一项开发性线索：在当前固定探针和线性模型下，按探针身份排列的向量对有限 B 探针质量的预测优于将向量排序的比较。它比同时反转训练和测试列更有区分力，但仍不能单独证明语义动作身份的因果作用：

- 排序改变特征分布，也改变线性模型能表达的函数；`shuffled` 只用了一个随机种子；
- B 探针虽未进入 A 特征，却是本开发面板的历史结果，不是来源独立任务或新鲜确认集；
- 候选可能重复，且各 root 用其他 root 的候选拟合，只作 root 留出诊断，不是正式规划器内的免训练评分；
- 对有限 B 探针的预测，不是独立重规划最优性、物理真实后果、最终链机制或完整成本收益；
- 探针生成代码及动力学依赖尚未作为完整复现包封存。

后续应先冻结身份对照和数据划分，验证多个预定的逐候选置换及其他身份无关模型、独立后缀和独立重规划随机流；再决定是否进入同探针、等槽位、全成本的规划比较。不能根据当前结果改变原 PC0–PC5。
