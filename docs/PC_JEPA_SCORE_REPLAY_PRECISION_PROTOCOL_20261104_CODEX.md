# JEPA 完整链重算差异：批形状归因诊断

六例已执行 packet 的后验完整链单样本重算与原规划保存分数相差约 10⁻⁶；先区分数值批形状效应和动作/接口错位，不能先称 bug。固定全部六个已选链，不挑样本；不规划、不执行物理、不更改原产物。

对每例从保存的候选批次中找到与最终 float32 链和原评分都一致的第一次出现，按原评估器的 `CHUNK=4` 截出其所在实际模型子批。交叉比较：

1. 编码器分别处理历史三帧与目标一帧（原路径），或者一次处理历史、目标、已执行后的真实帧共五帧（后验诊断路径）。
2. predictor 使用原实际候选子批，或者只使用同一选中链。

四种组合使用相同冻结模型、动作、归一化、历史、SDPA 和 GPU；记录完整链评分、与保存原分数的绝对差、编码特征差和实际批大小。目标后果帧只参与编码器数值批形状诊断，不作为目标或动作输入；此为后验分析。结果仅说明本次设备及算子上的数值差异，不能保证其他批次、平台或任务的容差，也不认证模型物理真实性。
