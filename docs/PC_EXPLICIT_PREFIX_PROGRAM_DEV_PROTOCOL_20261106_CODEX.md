# 显式固定前缀程序：初步开发对照

在同一冻结 PushT 模型、同一动作域、相同 25 步预测／执行间隔、
50 步上限、10 个任务和种子下比较三臂。每规划恰好计费 632 条
完整链评分，不将 packet 数当作独立模型调用。

1. 全链有界 CEM：210 样本 × 3 轮，加两次均值评分；返回均值。
2. 固定前缀、均匀分配：先生成并评分 30 条全局完整链，按预定
   下标选前两个前缀；每个前缀固定两个 packet，独立优化三个 packet
   尾部，各 100 样本 × 3 轮，最后评分两个完整链均值并选低分。
3. 固定前缀、普通 lookahead：初始 30 条及后续分支结构、预算均
   相同，但根据对应完整链模型评分选择两个前缀。

初始 30 条保留全局随机探索，并在每臂也评分；没有响应方向、
真实后果标签、行动后果描述或额外训练。lookahead 是普通完整链
末端评分，不应称为描述；均匀分配消融所付的初始评分是为匹配
信息和调用而承担。分支期间不改变前缀；未做联合精修。全链 CEM
两次末尾评分实际为重复均值，只是预算配平，不称为强基线调优。
按每次规划总评分数相等，并报告整个任务的重规划次数和成本；
执行分叉后随机流与状态可能不同，因此并非固定候选机会实验。

这是小型事后开发面板，不作独立确认或 PC2–PC5 通过依据。若结构
臂有优势，必须继续同机会、任务分离及强基线比较；若无优势，
只能限制此具体前缀生成与分配，不否定其他程序搜索。结果不用于
选择确认任务；真实轨迹只用于执行和评价。
