# 前缀配额开发实验：动作身份与全池上界核验

事后重建已封存的 24 根和五臂选择，不改变任何动作或历史结论。检查
每根前缀、B 尾部及每臂八条完整 B 链的逐元素精确身份，包括 B 与已评分
名义/A 完整链重合。精确相等不代表近似相同的动作也已去重。

从历史源代码、任务、偏移重建池并先复核已保存的共同池和选中 B 评分，
再于评价端额外计算全 512 条 B 组合。报告共同 incumbent 未成功而全池
有成功链的任务数、全池能改进 incumbent 的任务数、各臂捕获数及相对全池
最优的遗憾。核对预算仍为每臂 80 条逻辑模型评分；额外全池费用不记
作原部署调用。保存逐根结果、完整 B 成本及源文件指纹。

这仅用于决定负结果的可区分性，不改变事前停止标准，也不把后验 oracle
反馈给规划器。该任务使用精确状态、相同动力学预测和评价，并非独立物理、
视觉、真实反馈或 PC gate 证据。
