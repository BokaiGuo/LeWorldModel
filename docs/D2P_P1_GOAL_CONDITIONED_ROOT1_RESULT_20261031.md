# P1 目标条件化谱初始化：已知根 1 结果

按 `D2P_P1_GOAL_CONDITIONED_ROOT1_PROTOCOL_20261031.md`，将原四臂
开发路径中的 structured 初始化从“前两个右奇异方向”改为使用
目标残差的阻尼最小二乘动作候选；共同优化器、原始动作约束、
模型及反馈时刻不变。实现中的 SVD 解与直接阻尼线性方程数值
一致，目标改变能够改变候选；两项数值测试通过。这是不同的
候选生成算法，不是对历史代码错误的证明。

主机 CUDA 与真实物理执行完成 20 步，未原生成功。相同已知根的
旧 structured 与本次结果分别为：

| 方案 | 原生成功 | 物体位置误差 | 物体角度误差 |
| --- | --- | ---: | ---: |
| 旧谱方向初始化 | false | 56.3030 | 0.10359 |
| 目标条件化阻尼初始化 | false | 147.7689 | 0.58752 |

两次边界 0 的真实 RGB 像素、编码 latent 和十步动作历史哈希／值
一致；独立的编码收据路径不同，后续轨迹则随所选动作不同而分叉。
首节点模型最终候选最小 latent MSE 分别为 0.30141 和 1.17096，
所以本次物理表现变差不需要先假设“模型预测更好却物理更差”；
这只是该固定输入和所测候选库下的描述，不能推广到其他根。

本次首节点候选 3 和 7 具有相同最终分数，原因是本次阻尼解已
处于动作盒内，使其与单位比例的归一化方向相同；因此 8 个槽中
至少两槽重复，实际候选多样性不足。这是当前候选设计的限制，
不是模型理论的反证，也不应将重复槽算作额外搜索。后续可在新
合同中固定混合目标解与原谱方向，保留旧结果并重新评估。

4 个节点的实际动作、选中分数、预测模块 hook 和 Python autograd
API 次数通过保存态检查；每节点 75 次预测和 208 次 grad。消费器
不独立复演完整物理事件链，Python API 计数亦非完整 FLOPs。开发
任务已被重复观察；没有独立根、公平强基线、真实重配置能力或 P1
合取证据。本次更差结果不能用来判定整套理论无效。
