# 新 C 后缀开发验证结果

按[运行前协议](PC_ACTION_OPPORTUNITY_C_PROBE_DEV_PROTOCOL_20261104_CODEX.md)，使用旧 A 构造特征、其他 root 的旧 B 数据拟合固定岭回归，并对留出 root 的新 C 后缀进行预测；C 未用于候选选择、描述构造或拟合。

| 特征 | 16-root 等权平均 MAE |
| --- | ---: |
| A 最大相对改善标量 | 0.05401 |
| A 有序完整向量 | 0.05547 |
| A 按值排序向量 | 0.06110 |

有序向量与排序向量的平均 root MAE 差为 −0.00563，16/16 roots 上有序向量误差较低；但**标量总体上优于有序向量**。因此，本次结果不支持“完整描述比同探针最大改善更有预测力”的一般主张。排序改变线性特征分布和函数类，也不能单独把有序与排序差异归因于动作身份。

覆盖原面板全部 **16 roots、3 arms、2476 候选**，新预测耗费 **66852 prediction tokens**。候选和重复前缀不算独立任务。候选源与描述键和即时分数匹配、零尾重算一致，并对每个前缀保存 float32 哈希；实际动作与预测在调用日志中。全部质量源、旧描述和协议哈希记录在结果 JSON，依赖代码并未全部封存，因此不是完整独立复现包。

绝对终距目标可由已知零尾减去相对改善得到；使用相同零尾转换预测与真值时，绝对代价 MAE 数值与相对改善 MAE 相同，不能当作第二项独立证据。

这是同一开发候选及模型上的新后缀检验，**不是新任务、来源独立确认、独立重规划、真实物理可信性或端到端规划收益**。后续应首先比较多个预定新后缀库及独立重规划随机流，并验证标量在等探针预算、全成本条件下能否改善最终选中链；不能因有序向量优于排序就跳过更强的标量对照或宣称 PC1–PC3 通过。
