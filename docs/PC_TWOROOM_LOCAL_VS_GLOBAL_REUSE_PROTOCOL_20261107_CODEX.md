# TwoRoom local versus global tail: retrospective matched-budget comparison

This is an exposed-development, retrospective analysis, not a preregistered
confirmation. Roots 10–49, both candidate banks and all physical outcomes have
already been inspected. It asks whether the existing data justify a new
nonlocal-generation experiment, not whether a descriptor improves planning.

For each root use the same two lookahead-retained prefixes, the same common
incumbent, and 16 complete-chain model evaluations: either the 16 previously
queried local perturbations or the 16 corresponding B-bank tails. Select the
lowest model cost only if strictly below the incumbent cost; ties retain the
incumbent. Reuse the sealed physical trajectories for the actually selected
chain. Physical outcomes may not determine the selection.

Report paired ever-success and final-step success, selected-bank identity,
the number of roots containing a successful candidate, and paired wins/losses.
Each arm is charged 16 candidate scores plus one incumbent rescore, in
addition to the common upstream search; offline batch reuse does not make
scores free. The B bank and source parent choices predate this analysis, and
the result cannot establish a new algorithm, full wall-clock equivalence,
independent generalization, or a PC gate. Continue nonlocal generation only
if it improves actual selected-chain ever-success by at least two roots and
loses at most one relative to local, and separately report final-step results.
