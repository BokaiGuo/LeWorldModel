# TwoRoom CEM 与动作梯度后续优化：开发结果

按[事前协议](PC_TWOROOM_CEM_VS_GRADIENT_CONTINUATION_PROTOCOL_20261107_CODEX.md)，在 10 个已暴露 TwoRoom 任务上，两臂共享原始 300 条已评分候选和 incumbent，再分别继续评分 20 条 CEM 候选或执行 20 次动作梯度评分与反向传播。评分使用实际冻结 RGB checkpoint 和严格单帧接口；封存后分别物理重放选中链。

| 指标 | CEM continuation | 梯度 continuation |
| --- | ---: | ---: |
| 25 步内曾成功 | 7/10 | 6/10 |
| 配对独胜 | 1 | 0 |
| 平均选中模型代价 | 152.57 | 145.85 |
| 每根延伸阶段平均同步时间 | 约 0.0097 秒 | 约 0.375 秒 |
| 每根额外前向候选／反向 | 20 / 0 | 20 / 20 |

梯度臂在 6 根模型分数较低、1 根较高，但没有多成功，未达到事前至少多成功 2 根且 CEM 独胜不超过 1 根的出口；停止扩大该固定梯度配置。CEM 唯一独胜的行是 **82490**：梯度臂在该根把已存在的成功 incumbent 替换成模型评分更低的失败链，与此前对该根“分数降低未兑现物理收益”的诊断一致。这不意味着模型评分在其他任务上都不可靠。

每臂评分机会同为 320 条完整链，但梯度额外反向，CEM 的 20 条为一次批量调用；表中时间仅为本机扩展阶段、包含同步，不含前 300 次共同评分、模型加载、环境执行及反馈，不是完整系统成本曲线。数据和任务已暴露，每根只有一个随机流；该对照不是充分调优的梯度基线，也不能支持独立泛化结论。

独立审计按保存记录重建 CEM 随机候选、全部 200 次梯度和动作更新，复算选择、边界和计数，重放 20 条选中链的 500 个物理步。模型分数、梯度最大范数、更新动作和物理距离的最大重放误差均为 **0**；它复用同一 checkpoint 与物理后端，不是独立实现或独立科学复现。原 300 条 CEM 成本重算与历史记录最大差 `1.23e-4`，在预定容差内。相关测试 **30 项通过**。

该实验不包含行动后果描述或程序保留，不能代表 Planning Compiler 增量；也不是 RGB 闭环。PC0–PC5 均不改判。原始计划、物理记录和审计分别为 `le-wm-main/results/pc_tworoom_cem_gradient_continuation_{plan,physical,audit}_20261107_codex.json`。
