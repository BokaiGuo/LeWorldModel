# Fixed-action velocity-source × scoring inventory

This pre-analysis contract is an availability audit, not a new physical or
neural experiment. Its only permitted execution reads the four SHA-bound
artifacts below and writes a new inventory receipt. It does not open or
rank physical outcomes, select actions, execute physics, or call a model.

The intended later diagnostic fixes all 384 previously exposed two-packet
plans in the eight cp5 velocity banks, preserving every candidate and its
actual cp5 RGB and action history. For each exact same cp5 RGB, tail and
goal, it crosses velocity source {zero, cp4-to-cp5 RGB finite difference,
legacy simulator cp5 qvel} with score {predicted visual goal distance,
predicted proprio goal distance}. The privileged qvel is an evaluator-only
diagnostic and must never enter a planner. The RGB estimate is a quantized
0.05 s average and qvel is instantaneous; their alignment is not certified.
Root, method, candidate index, action bytes, cp5 image, goal, mask, scoring
coordinates, checkpoint and normalizer must be bound before any comparison.
All candidate-specific cp5 images were obtained using oracle physical
replay, so no resulting selection is a deployable closed-loop policy.

The existing velocity report stores visual scores for all three inputs, not
proprio predictions or proprio scores for those inputs. The separate saved
proprio score report must not be joined unless root, phase, candidate actions,
context and goal match exactly. Missing cells remain missing; a different
physical/RGB metric is not a substitute for a model proprio score.
