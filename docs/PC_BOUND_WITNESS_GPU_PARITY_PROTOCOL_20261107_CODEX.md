# 绑定动作见证：GPU 接口等价检查协议

使用已暴露 PointMaze state-assisted 本地兼容模型和旧后果描述实验的首根、首相机输入，重放零动作及 ±0.003 原始 x 动作（每个动作重复五环境步）。不使用物理后继。新旧见证分别经过同一官方 proprio 路径、同一动作标准化和同一视觉目标 MSE；检查逐项代价与原已封存结果在 `atol=1e-6, rtol=1e-5` 内一致，并核验模型前后参数指纹。两个描述各计三次模型预测，轨道标记为 state-assisted。

这只是候选身份绑定与接口等价检查，不验证 checkpoint 官方等价、后果信息真实性或搜索收益，也不提升 RGB-only Gate。历史动作见证使用元组；发现旧类允许调用方提供可变列表，不代表历史候选发生漂移。
