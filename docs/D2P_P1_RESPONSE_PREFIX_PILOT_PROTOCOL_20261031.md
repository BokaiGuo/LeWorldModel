# 结构化前缀真实 cp5 采集：探索协议

目标是为真实 RGB 反馈规划建立输入，不评价 P1。使用已封存的八个
slot/arm，每臂按原动力学多样性列表固定取第 0 和第 1 项；共 16 行。
第 0 项是即时最优种子，第 1 项是预先生成的响应多样候选，不称后者
为算法选择赢家。无需查看物理结果选择或替换行。

物理执行每个五步前缀后执行十步全零动作，记录完整轨迹与 cp5 RGB；
原生成功或其他原生停止保持删失，不补帧。末十步只是采集轨迹，不是
各自规划后缀或共同能力实验。使用现有任务、动作归一化、来源绑定、
fresh environment、逐步记录和保存态验收；仅两条历史根，不是独立确认。

下一阶段应从真实 cp5、真实历史和同一目标，以固定相同优化器及预算
产生并执行各自后缀；必须另行封存与记账。动作前缀生成及筛选成本
也须计入全链成本。不能用真实物理 outcome 选候选，不能用模拟器
状态给规划器评分，不能因本批 outcome 修改历史 gate 或宣称 P1 通过。
