# 分段预算反馈动作：共同后缀机制干预

在观察分段反馈结果后，固定全部 8 个逻辑槽、三种前缀以及同槽
selected、zero、greedy 各自产生的完整十步反馈动作，另加十步
零动作。所有 8×3×4=96 条分支均真实执行，不以成功或分数
筛选。不同前缀接收同一动作时，该动作是离线迁移，不是目标
前缀上的在线反馈重规划。

绑定原根、目标、条件、前缀、来源动作字节、RGB 反馈来源和保存
报告；保留成功停止与越界删失。第十步观测存在时才计算固定
时域终点，相对自身零后缀分开报告。前缀的物体位置、角度、
推杆和联合指标分开，不能事后排除推杆即时进展。

使用已知根和已观察的动作，本实验提供机制线索，不是独立
确认或公平强基线，不能据此打开 P1。模型不参与物理干预，
不额外训练或修改既有 gate。
