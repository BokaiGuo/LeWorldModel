# PushT 首轮完整候选池失败分解

在已使用的 seed-85 四任务面板上，记录器保存第一轮四个任务各 632
次完整链评分及模型预测；与上次 action-only 运行比较，选择记录、
实际派发和物理轨迹均一致。按动作字节去重后，每任务 630 条；共
物理重放 **2,520 条不同链、63,000 步**，每次初始物理快照均匹配
闭环记录，选中链的前 25 步与实际派发轨迹核对一致。

| 任务 | 25步内曾成功 / 630 | 第25步成功 / 630 | 实际首轮选链曾成功 | 成功链最佳模型排名 |
| --- | ---: | ---: | --- | ---: |
| 0 | 81 | 27 | 是 | 1 |
| 1 | 13 | 3 | 否 | 23 |
| 2 | 1 | 0 | 否 | 23 |
| 3 | 1 | 0 | 否 | 224 |

排名在每任务去重链中按记录的模型代价从低到高排列。任务 1–3
最终闭环均失败，但其首轮候选池中并非完全没有“曾成功”链；模型选中
链的代价分别为 31.723、9.983、24.168，而池内曾成功链最低代价
分别为 79.039、14.157、58.967。这里的成功标签来自事后物理重放，
没有输入规划器。任务 2、3 唯一的成功链在第 25 步均已不成功，
不能将“曾成功”等同稳定终态成功；同样也不能据此推断更早停止一定
可被合法部署。

该观察指向：这三个首轮池中，单纯取最低模型代价未选到曾成功链；
它不证明真实编码评分失配或动力学误差哪一个是原因，也不证明池外
不存在更好链。所选链在首轮完整开放环上的结果，不能替代整段
重新规划后的闭环结果。四任务规模和来源均不足以支持独立统计结论。

20 个预测批次的末时刻表示重算代价最大绝对差不超过 `6.11e-5`；
这验证了已保存表示与评分的一致性，而非模型预测与真实后继的一致性。
环境仍有动作转换和 fork 警告；物理重放与原实验共用环境实现，初态
快照匹配不证明所有隐藏状态等价。未做 checkpoint 前后哈希认证。
PC0–PC5 均不改判。
