# P3 H3 raw 修正：完整二十步物理配对合同

对已观察的四个 P3 失败决策，固定 H3 面板全部 zero 和八个
候选，共 36 个前缀。各前缀分别接原五步后缀与已封存的 raw
修正五步后缀，形成 72 条二十步动作；每对前十五步必须逐字节
相同。不得按预测值、物理结果或候选成功挑选。

每条使用对应的原物理根、目标和十步 warmup 重放，不能将想象
latent 当作环境状态。执行前验证来源、动作范围、根和任务身份；
实际执行需记录原生动作 ACK、状态、真实 RGB、停止及资源计数。
原生提前停止和画布守卫失败不得填补二十步终点。新旧对照的
实际第十五步状态、快照及画面须单独核对；不因前缀动作相同就
假定重放物理状态相同。结果分开报告位置、角度和原生成功。

数据来自两个已知根、四个已观察失败决策，逻辑策略可能重复。
这里检验的是固定候选上的坐标修正及真实执行，不能称独立、
等预算、调度优势或 P3 通过。执行阶段必须使用专门的二十步
物理合同和保存态消费者；既有十步执行器不得通过截断使用。
本阶段只准备动作清单，不启动物理环境，不运行或训练神经模型。
