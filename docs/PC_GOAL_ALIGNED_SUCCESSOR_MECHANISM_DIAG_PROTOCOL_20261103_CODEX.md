# 目标条件化后继编译器：最终链机制开发诊断

在所选链及规划成绩已封存后、干预结果产生前固定。对 24 个暴露 Wall
根的 goal 臂，复用此前的最终链干预：selected、zero、same-bank greedy、
同次实验 random 臂的实际选中前缀、以及已封存历史 lookahead 前缀，
各自测试统一的五个预设常值尾部与 goal 实际选中尾部，记录绝对终距和
相对自身零后缀变化；再以相同 120 条、同随机数的 floor-CEM 进行
各自重规划。计算各前缀后继有限差分响应矩阵，报告与 selected 的差。

非即时条件及 zero/greedy、四控制的严格交集沿用既有开发诊断，不
修改历史标准。random 为同次匹配结构的实际选中前缀，lookahead
为历史封存的另一配置，不是本方法同预算新实验；selected 尾部在
干预开始前已知但为事后选择，不能伪装为独立预先指定尾部。随机与
lookahead 由各自完整链选择得到，不冒称同库 greedy。

每根保留动作、计算过程与哈希，固定所有根、对照和预算，不在结果后
挑链或加预算。此为暴露任务的后验开发干预；响应差不自动证明可利用
机制，120 条后缀不构成强搜索上界，不能从本实验判 PC2 或 PC3 通过。
输出排他创建，绑定新计划、新审计、历史控制和脚本。
