# V4 Reacher 末包：预测 latent 与实际 RGB 编码

对已暴露单根的五个反事实动作重新执行模拟器，保存末帧并用相同冻结 checkpoint 编码；预测和目标使用同一第 10 步上下文。候选和原结果此前已知，本项是[事后诊断](PC_V4_REACHER_FINAL_PACKET_LATENT_GAP_V2_PROTOCOL_20261104_CODEX.md)，不是独立确认。

| 动作 | 预测目标 MSE | 实际末帧目标 MSE | 预测—实际 latent MSE | 物理关节终距 |
| --- | ---: | ---: | ---: | ---: |
| selected | 0.745872 | 0.769165 | 0.024046 | 0.491198 |
| carry | 0.766592 | 0.769565 | 0.029703 | 0.483812 |
| zero | 0.886359 | 0.901279 | 0.007466 | 0.351960 |
| nominal0 | 0.870459 | 0.877046 | 0.008271 | 0.275857 |
| nominal1 | 0.918847 | 0.871711 | 0.031405 | 0.600100 |

五动作十个配对中，预测目标 MSE 与实际末帧目标 MSE 的排序有 **2/10** 反转；预测 MSE 与关节终距为 **5/10**，实际末帧 MSE 与关节终距为 **7/10**。例如实际末帧 MSE 偏好 selected 而不是 nominal0，物理关节距离则相反。因此，即使直接编码真实末帧，此处 latent 目标 MSE 也未保持关节距离排序；但预测和实际编码之间同样存在差异，不能把全部偏差唯一归因于评分指标或模型。

以 zero 为共同参考，四个非零动作的预测与实际 latent 位移向量余弦为 0.991–0.993，但范数和绝对差异并不为零；高余弦不等于目标代价排序正确，也不认证局部导数或物理控制。zero 自身的差向量为零，不计算余弦。

[参考路径审计](../le-wm-main/results/pc_v4_reacher_final_packet_latent_gap_v2_20261104_codex_audit.json)重新编码五张保存的 RGB 末帧，并从同一冻结模型的参考 rollout 重算预测：观测编码和目标最大误差为零，预测 latent 最大绝对误差 `5.96e-7`，逆动作映射误差 `1.20e-7`。该审计不是独立 checkpoint；物理模拟仍为同一后端。原始 RGB 和 latent 数组在对应 `_arrays.npz`，与结果及 manifest 哈希绑定。

首次 v1 运行因 MuJoCo 渲染图像的负步长视图不能直接转换为 PyTorch 张量而失败，只留下 manifest；v2 对预处理输入做连续复制后完成。此修复仅属于诊断路径，没有改变原 v4 规划或之前的实验。目标图像、表示几何、物理任务指标、其他根及实际响应仍需检查，本结果不证明 PC1 或 PC4 通过。
