# 等预算尾部实验：GPU 分数重算协议

对已封存的三个开发 root、五种前缀和各臂三批候选，重新从实际
重置后渲染的 RGB 和同一目标图构造输入，按原批大小 16 重新调用
冻结模型。逐元素比较全部 720 个分数，并检查每臂的全局最小分数
候选是否改变。报告最大绝对误差及 1e-5 容差超出数；该阈值只用于
本次数值核验，不代表理论误差上界。遇到近并列选择改变必须单独
报告，不能单凭最大误差判断行为等价。

封存协议、runner、来源计划与候选池的哈希，核对模型和 normalizer
指纹及重算前后权重哈希；输出新文件，不修改原结果。此为相同
checkpoint、模型实现和环境下的可重复性核查，不是独立模型验证、
物理真实性检验或性能确认。不得用物理后果重新选择候选。
