# Exploratory common-suffix protocol

Before this intervention executes, fix both development roots in the sealed
spectral physical report. For every root execute each of its selected, zero
and same-bank-greedy five-step prefixes, followed by every member of the
four-element ten-step suffix family: all-zero, and the three suffixes already
executed by the selected, zero and greedy arms. This includes all available
optimized tails rather than selecting one from physical outcomes; nevertheless
they have already been exposed to outcomes and this is exploratory only.

Use the exact stored raw actions. Restore the same complete simulator root
snapshot for every branch; bind the RGB goal and root to their source hashes;
reproduce each original prefix qpos distance to absolute tolerance 1e-8.
Record qpos, qvel, evaluator qpos goal distance, reward, and termination at
each step. Do not fabricate values after termination. Comparisons will report
terminal distances and each suffix's change relative to the zero suffix under
the same prefix, separately. Common suffixes cannot establish an independently
optimized controllability advantage, and simulator state must not feed the
RGB-only planner.

This is a two-root development mechanism diagnostic, not preregistered
confirmation, a statistical test, or an admission gate. If a prefix or tail is
found to have a binding failure, the run fails closed and the issue is fixed in
a new output; it is not interpreted as a scientific negative.
