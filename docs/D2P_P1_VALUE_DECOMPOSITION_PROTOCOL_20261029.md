# P1 同候选的预测与任务评价分解：探索协议

QWM 的摘要启发我们分开未来预测和任务价值评价；这里不复现 QWM，不引入或训练 critic、policy 或 adapter。冻结世界模型不变。该协议用于定位 P1 失败层次，不修改原 gate，不以 latent 距离代替物理成功。

## 固定比较对象

对预先固定的每个根及其完整前缀候选集，记录候选身份、前缀原始动作字节、后缀及时间边界、目标和上下文身份；同候选的各列只有上述身份一致时才能合并。对每个前缀，用预定相同预算与初始化规则规划后缀，保留全部候选与早停/失败，不基于真实结果挑动作或挑根。不同方案须记录实际预测、反向、Jacobian/VJP、规划耗时和硬件；同 cap 并不等于同实际计算量。

同一候选并列记录：首段模型阶段代价及其相对固定 greedy 的差值；后缀模型终态代价及完整动作；同一后继状态、目标和动作尺度下重算的 Jacobian 与 bounded-ridge Vreach；按预定规则真实执行该前缀和对应后缀得到的物理轨迹、原生成功及各物理误差。没有真实执行或没有严格身份绑定的列填写缺失并说明原因，不能用另一轨迹或另一时刻代替。

分析应分别报告 selector 是否选中非贪心候选、模型与真实后果的排序是否一致、真实编码与预注册物理指标是否一致。每个判断保留比较方向、平局、缺失、候选分母和根数；共享根与轨迹的候选不是独立样本。模型后缀改善不是物理收益，事后分析不是独立确认。任何新评分须在不看独立确认结果前冻结，保持原 P1 合取和强基线比较。

## 既有证据与缺口

固定 prefix 的 576 候选已有主机 CUDA 后缀模型结果，但没有对应的新真实动作执行；不可与其他动作库的物理数据假定为同一候选。此前 40 分支、80 动作对已有部分真实 RGB 与物理分解，但动作对只涉及两个已知根，且需要逐项认证后才能加入新的条件 Vreach/后缀列。当前 joint-Vreach 四槽新来源已重建，其四槽八臂宿主和真实物理链尚未完成。因而目前不存在可据此声称四列全齐或 P1 通过的证据。

下一执行步骤是完成 joint-Vreach 宿主与 saved consumer，记录全候选实际资源；仅在动作、目标、根、后缀和时间边界逐位绑定后执行预定物理评价，之后再用不按结果选择的独立根确认。论文数值只有在独立核验协议匹配时才可对比；QWM 的具体完整方法仍需查阅全文。

新增离线 `p1_value_binding_bridge_20261029.py`，对四种 receipt 检验候选、目标、上下文、时间与两段动作字节一致性，主线程复跑 11 项 fixture 通过。它不认证 receipt 来源，不填补现有缺失列，也不证明真实候选四列已接通；producer 仍须从原严格消费链导出数据。

随后新增 `p1_value_source_export_20261029.py` 接入既有 fixed40 保存重建与 joint 原 winner authority。主线程联合回归 16 项通过，并对 fixed40 实际来源重新重建：40 个候选中后缀预测 40、原物理返回 40、终态实际编码 39，即时评分和条件 Vreach 均为 0 个已认证值。joint authority 的 4 个 winner 是另一条来源，未运行新 joint arm，不能按槽号与 fixed40 拼接；completed-arm 导出接口仍仅有 fixture，非真实结果。缺失不是零收益，也不改变 P1 gate。
