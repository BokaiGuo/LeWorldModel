# TwoRoom 预定跨墙任务：开发基线协议

标准性能集保持不变。本机制开发集事前固定 40 个任务（seed `1888800+i`），交替设置起点在左／右室；左侧横坐标从 `[75,91]`、右侧从 `[133,149]` 均匀采样，起点与目标纵坐标各从 `[70,100]` 独立采样。每根的起点与目标位于墙两侧；任务取样不依据模型、成功或物理轨迹。环境使用本地标准 TwoRoom 默认墙与门。任务构造依赖物理坐标，仅用于评价侧；正式规划器只接收当前／目标 RGB、合法旧尾和时钟。

评价侧为每个任务生成最多 25 步的确定性参考动作：先对齐本侧门口 `(96,49)` 或 `(128,49)`，再穿到对侧门口，最后向目标移动；每轴动作由位移除以环境速度并裁剪到 `[-1,1]`。记录完整动作、真实距离、首次成功及失败，不筛掉参考未成功任务。该几何控制器使用特权状态与环境几何，只证明或未证明任务可解，不能用于 RGB 规划。

在任务及参考见证封存后，冻结 RGB LeWM，使用同一 25 步时钟、五步反馈、合法旧尾和全局 normalizer，分别运行 CEM16、CEM300；每个预算使用相同逐任务种子、相同合法输入。记录各次计划、评分数量、完整动作及真实反馈。分别报告所有任务和参考成功任务，后者只能作为事后可解性诊断分层，不用于选择或筛选主结果。初态成功也保留。

这是预定机制集开发，不是官方 benchmark、独立确认或 PC gate 通过证据；已停止的响应配置不在本轮扩样。种子与坐标新建不证明 checkpoint 未见过近邻或原训练数据，normalizer 与 checkpoint 的训练绑定仍未知；此任务分布的难度和参考可解性不能预先假定。
