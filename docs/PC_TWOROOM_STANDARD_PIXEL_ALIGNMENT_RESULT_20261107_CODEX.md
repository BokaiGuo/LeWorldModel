# TwoRoom 标准参考面板图像对齐结果

按预先记录的协议，对已暴露的 seed-42 标准参考面板全部 50 个数据行，使用其初始位置和第 25 步位置设置本地默认 TwoRoom 环境，分别比较数据集图像与环境重新渲染的当前图和目标图。

| 检查 | 当前图 | 目标图 |
| --- | ---: | ---: |
| 逐位相同 | 2/50 | 1/50 |
| 每图最多不同像素 | 11 | 9 |
| 单通道最大绝对差 | 1/255 | 1/255 |
| 平均每图不同像素 | 4.3 | 3.8 |
| 全图通道平均绝对差 | 0.0000286 | 0.0000252 |

两时刻的数据 `proprio` 和 `pos_agent` 在 50 个任务上最大差为 0。所有图像均有可计算的红色通道加权中心，其逐图坐标和输入图像摘要保存在结果中。

这些结果表明：对当前本地环境的默认几何，此面板的数据图像与基于数据位置的重渲染非常接近；未发现大范围初始或目标图像错位。逐位差异的原因未查明，不因此宣称数值完全等价。该检查单独 reset 并执行 setter，不能替代完整 `World.evaluate` 的逐步观测、历史及动作对齐，也不能证明模型预测、任务评分或其他 checkpoint 正确。未使用物理状态辅助规划，未修改基线或 Gate。

像素比较单元测试及已有边框、参考任务选择测试共 **5 项通过**。逐任务指标、文件身份和边界见 `le-wm-main/results/pc_tworoom_standard_pixel_alignment_20261107_codex.json`；实验方案见 `PC_TWOROOM_STANDARD_PIXEL_ALIGNMENT_PROTOCOL_20261107_CODEX.md`。
