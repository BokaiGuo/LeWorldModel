# 第二已知根：四臂赢家追加预算

复用第二已知 PushT 根的既有原始来源、物理环境和真实 RGB
反馈框架，执行 structured、native-style、random、
immediate-progress 四臂。每臂按各自真实状态在 0/5/10/15
反馈时刻使用根 0 的赢家追加预算规划器；native 和 random
在模型选中的赢家上追加相同固定优化规则。四臂各自执行最多
20 个动作，保留提前成功、截断和错误。

所有推理在主机 CUDA 上进行，冻结模型；逐节点保留 action
encoder/predictor hook、反向账本、同步时间、实际动作、候选
和模型哈希。绑定根 1 的历史及模拟器快照，不混用根 0 图像。
提前失败保留，不重新挑选根或按结果选择方法。

这是查看过两根结果后的已知任务探索；native-style 不是认证的
官方强基线，逐轴上限不代表总 FLOPs 或全流程公平；不评价
独立泛化、P1 机制或阶段通过。根 1 与此前根 1 的旧预算合同
不同，不是相同动作重复执行。
