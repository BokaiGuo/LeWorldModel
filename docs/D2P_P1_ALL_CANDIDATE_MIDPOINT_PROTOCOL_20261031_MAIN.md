# 全候选同时间中点与刷新诊断

已知全部 96 条物理轨迹的结果后，对四个起点全部记录做事后
诊断；不得根据成功、分数、角色或根筛选。使用固定真实前缀
cp5 和原动作，编码真实后缀第 5 步 RGB，计算模型五步预测与
真实编码误差、各自目标距离、以及原十步开放评分与采用真实
中点刷新后的十步预测评分。中点真实观测用于离线诊断，不是
原选择器可在前缀时预见的输入；不生成新的动作。

逐条核验完整物理报告、分片哈希、前缀/目标、原动作字节、
中点状态、图像文件和像素哈希。全部 96 条均到达第 5 步；
如发现不成立应失败，不插值。对提前停止的轨迹不构造十步
真实终态。各条成功和终止仅事后读取，不参与模型评分。

该实验使用同一冻结模型和归一化器在主机 CUDA 编码和预测。
结果用于分解模型漂移及任务评分，不能作为在线反馈控制收益、
独立确认或 P1 通过。不同轨迹共享根和动作，不能作为独立样本。
