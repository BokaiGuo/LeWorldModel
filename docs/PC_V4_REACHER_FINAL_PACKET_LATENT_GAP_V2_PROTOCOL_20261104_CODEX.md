# V4 末包预测与实际 RGB latent：v2 修复协议

遵循 [v1 协议](PC_V4_REACHER_FINAL_PACKET_LATENT_GAP_PROTOCOL_20261104_CODEX.md) 的候选、模型、时钟和指标。v1 在编码 MuJoCo 重放末帧时因负步长 NumPy 视图无法转换为 PyTorch 张量而中止，未产出结果；保留 v1 manifest，不改写原始运行。
