# v7 Reacher 同设置热启动 CEM：单根开发对照

针对已完成 v7 真实反馈的已暴露 Reacher 根，使用同一原冻结模型、目标、动作统计、共同 warmup、真实后端、固定 15/10/5 剩余时域、每轮 5 步执行及每轮 1920 packet-token，另运行既有双起点 smooth CEM。采用与 v7 相同的 TF32 关闭设置和同一 chart 生成规则；第二、三轮使用该 CEM 臂自己的实际观测与旧尾，不读取 v7 的候选、动作或物理结果。保留所有调用、动作、分数、旧尾和实际观测。

每轮首起点 zero；有旧尾时在当前上下文共同评分 zero 与 carry，余量近等分给从两个基底各自初始化的 CEM。无旧尾首轮沿用既有实现。以完整链历史最小模型评分选择，记录模型候选可能因批次数值误差有细微差异；这不是 v7 的弃权语义，不能把两个选择器的标签直接等同。对记录、动作历史及预算进行独立审计，并使用同一冻结模型的参考路径重算所有预测、同一物理后端重放四个边界。

比较两臂共同初始 RGB/目标/热身和关节距离，但各臂后续真实反馈各自演化；只报告该单根配对开发结果。该 CEM 未充分调优，也不代表 AP-CEM、梯度或强搜索上界；同 token 不等于全计算成本相同，训练来源独立性未知，不作 PC3/PC4 通过声明。
