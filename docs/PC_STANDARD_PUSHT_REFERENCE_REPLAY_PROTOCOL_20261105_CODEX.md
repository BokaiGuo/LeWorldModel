# 标准 PushT 面板参考动作重放：开发协议

对象为已有原生 seed 42、50 行面板，不依照重放表现删选或替换。每个根取 HDF5 `state[row:row+26]` 和 `action[row:row+25]`：固定假设 action[t] 令 state[t] 转至 state[t+1]。用本地 `swm/PushT-v1` 的相对动作和原生 reset，将动作原值按顺序执行 25 次，不裁剪、不额外缩放；实际记录超出动作空间或非有限值，若非有限则该根失败。

逐步保存动作、参考／实际状态、误差、成功／终止与异常。为诊断终态，首次成功后仍继续通过 base environment 完整执行；额外记录首次成功时间，不能称为原生早停 rollout。计数采用所有 50 根为分母，异常根不替换。优先报告末态和任意时刻的本地成功、最大偏差以及首步误差。每个根重新构造环境，避免跨根的物理隐状态污染。

参考动作仅用于评估，不传入规划器。归档状态不包含完整物理隐状态，reset 及物理库可能引入偏差；重放失败只能证明当前重置／动作约定下未复现，不能直接判任务不可解。数据完整哈希和作者权威版本尚未认证；本实验是开发诊断，不是独立确认。
