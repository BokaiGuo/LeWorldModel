# TwoRoom 时序目标一致的前缀保留：固定池开发检验

已封存时序规划器用末帧模型代价保留前缀，再用预测时域最小代价选择完整链；这两项评分规则不同。本次仅检验把普通 lookahead 前缀保留改成与最终选择一致的时序代价，是否更有可能保留成功尾链。不是声称时序保留必然优越，也不改变原任务的成功规则。

使用此前 40 个已曝光或独立性未知任务的 119 个共同历史决策池。每池三个前缀、相同三个描述探针（含零参考）和两个 B 尾部；原决策已保存各探针逐时序最低预测代价，物理评估已记录所有六条 B 链。两臂保留 2 个前缀：原 lookahead 按每行三个末帧探针代价的最小值排序；新臂按每行三个探针的时序最低代价排序，平局按前缀原序稳定处理。原保留结果须与封存记录一致，时序代价及末帧均须与两臂历史记录一致。两臂得到相同查询与相同 B 尾部机会，物理标签仅事后计算覆盖，不进入选择。不得把第三个原先未查询前缀的 B 结果当作免费部署查询；此处是反事实机会对照。

主要覆盖指标为：从决策初态出发、前缀执行中没有成功且 B 尾段发生成功的链，是否由保留的两个前缀覆盖。按 episode 汇总至少一个共同决策池具有覆盖，完整 40 任务和排除决策初态成功的子集均报告；同时报告按决策的曾成功覆盖。决策之间相关，不能作为独立样本。所有数据在本协议前已曝光，本项为事后固定池开发诊断，非独立确认、实际选中链或闭环控制。

事先固定本次开发出口：排除初态成功的 episode 中，新方法相对旧方法至少 3 个 episode 独有覆盖，且旧方法相对新方法独有覆盖不超过 1 个，覆盖总数不得下降。未达标则停止扩大这个时序保留规则；达标也仅支持开展公平完整搜索比较，不证明行动后果描述增量或 gate 通过。评分选择只读取封存模型代价；物理轨迹在选择固定后才用作评估。
