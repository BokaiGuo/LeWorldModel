# Fixed-tail RGB reobservation after selected prefix

This is a post-outcome development diagnostic on the same 40 exposed roots,
using both original and reversed prefixes from the sealed equal-CEM plan.
For each fixed prefix compare its CEM-selected tail and the previous
descriptor-selected B tail. Both are already available action witnesses;
they were not chosen afresh based on physical outcomes in this diagnostic.
All outcomes from the prior experiment are nevertheless exposed, so this is
not a blinded or independent evaluation.

From each matched reset, execute exactly the ten prefix actions and record
the actually rendered RGB. With only this RGB, the goal RGB and the two
remaining 15-step actions, use the same frozen model to predict endpoint costs
over three five-step packets. The input history follows the existing
single-frame model contract. Ties choose the CEM tail. Record both costs,
chosen index, prefix actions/trace, input image fingerprint, two full model
queries per arm, and frozen fingerprints. Seal all 80 choices before opening
the previous physical results.

Then compare the selected tail with the previously recorded physical
outcomes for each pair. Verify source/root/action bindings and all ten prefix
distance and success/truncation records against prior physical traces.
Report all pair outcomes and separately the already exposed CEM-fail/B-success
pairs; two arms sharing a root are not independent tasks. The B witness is
a previously model-selected tail, not a new post-observation search.
This is a fixed-pool counterfactual obtained by reusing outcomes, not a new
continuous closed-loop evaluation, an equal-cost performance claim or PC4.
