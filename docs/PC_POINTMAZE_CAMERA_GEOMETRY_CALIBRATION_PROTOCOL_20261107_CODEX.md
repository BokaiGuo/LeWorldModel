# PointMaze 归档与重渲染的相机几何检查

已在八个曝光任务的初态发现图像约 14 像素的垂直位移。为核查是否可由相机平移解释，在相同原始 float64 物理初态、相同 XML、相同 legacy 渲染器下，固定 azimuth=90、elevation=-90、默认 distance 和 z lookat；预先设定 x lookat 为 2.5、2.75、3.0、3.25、3.5，y lookat 为 2.0、2.25、2.5、2.75、3.0，完整 25 个相机。

仅使用曝光任务 1884–1887 的初始归档帧平均绝对像素误差选择相机，以相同选择在曝光任务 1888–1891 初始帧评估；不使用动作结果、目标、物理成功或未来帧。所有 25 个相机、八根误差和原图保存，保留当前相机 `(3, 2.5)` 作为对照，记录默认相机参数、图像哈希、状态和源码哈希。

此为开发集的后验几何校准，后四根仅用于同面板迁移检查，不是独立确认。像素更近不证明相机真实性、目标处理、模型泛化或预测质量；也不能把得到的设置标记为官方协议。若出现可复核改善，须在单独预定实验中比较相同动作的预测与真实后继，并在正式轨道明确声明渲染协议。
