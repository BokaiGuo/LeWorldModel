# JEPA PushT 历史动作填充：单根结果

按[固定协议](PC_JEPA_PUSHT_HISTORY_PACKET_DIAG_PROTOCOL_20261104_CODEX.md)，在已暴露 episode 1 上运行冻结 JEPA-WM 原生模型；[原始结果](../le-wm-main/results/pc_jepa_pusht_history_packet_diag_20261104_codex.json)的 SHA-256 是 `4dfc32ea23215d9bda11fde94d68885b8d2aa8b8b6e5504dca22335651a20c9b`。RGB、agent 位置与速度和末动作相同，仅替换两个历史动作槽，分别进行四次预测。

| 历史 packet | 真实末 packet 的目标 patch MSE | 归一化零末 packet 的目标 patch MSE | 零末动作减真实末动作 |
|---|---:|---:|---:|
| 真实 | 0.06643459 | 0.32966194 | 0.26322735 |
| 归一化零 | 0.05608358 | 0.32226359 | 0.26618001 |

在固定真实末动作下，两种历史的预测 patch RMSE 为 **0.05913549**、最大绝对差 **0.88043106**；固定零末动作时分别为 **0.06968878**、**0.52181518**。两种历史下目标误差都偏好真实末动作，未观察到该二选一排序反转。归一化零代表训练动作均值，不是原始动作零。

真实历史和真实末动作的 MSE 与旧[原生响应封存](../le-wm-main/results/p5_jepa_native_action_response_20261027_v8/manifest_frozen.json)记录 `0.0664345920799759` 一致；编码特征哈希也匹配。上述四个预测是连续四次单样本调用，不是一个四样本联合批次。目标帧只用于诊断评分，没有用于规划、选择或训练。

首次尝试在模型加载前因历史来源归档位于已清理的 `/tmp` 而失败。之后重新获取封存所列官方提交源码归档，SHA-256 与原值 `c27dcdaf50e9fb5bbdf2bb529da357716372e19c6afab17d5350f3f0094aed4b` 一致，恢复至原临时路径；原验证器随后通过并完成运行。此恢复不等于永久可复现，干净环境仍需要归档与其他完整依赖。

**结论边界：** 首步历史填零与输入真实历史在此上下文并非数值等价，因此跨模型适配不能忽略历史动作语义。单根结果不能说明哪个是训练一致的规划接口，也不能以较低单步 MSE 推断物理控制更好，更不构成 PC0–PC5 通过。本实验需要真实 agent 位置和速度，不能标记为 RGB-only。后续应核验原训练时动作与帧的时间绑定、包装器的完整多步行为，再按信息权限单列开展 v7 同任务接口实验。
