# 多方向 RGB 最终链零前缀比较：物理诊断协议

在读取本次干预输出前固定分析。输入为已封存的四个暴露 PointMaze 根、
多方向臂三次决策、真实执行动作和已有原生重放；不重新运行规划器或
改变选择。对每次决策，仅取已记录的 `precomparison` 完整链以及由它
将前五个原始动作置零得到的 `comparison_chain`。模型分数和弃权决定
直接读取对应封存记录，不重新优化，不使用物理结果选择。

每个分支均从相同初始状态、共同热身与该决策前实际执行的全部动作开始，
使用已审计的原生 MuJoCo 后端重放剩余完整链至固定终点。对同一对分支
比较模型原始分数差（零前缀减原链）与物理终距差（同方向）；零差记为
平局，不随意设定数值容差制造一致性。对比重放中决策前轨迹与已封存
原生重放的状态和时钟，要求逐位一致。另报告每条实际选中前缀的五步
终距相对起始终距的变化；不将其视为重配置机制或首次事前完整链见证。

报告全部 12 对数据、模型排序与物理排序的同号/反号/平局、弃权次数、
物理距离和决策前轨迹验证。模型评分是潜在投影，物理距离是目标几何
指标，二者排序不一致可能来自模型、状态估计或目标投影，不能单凭该
诊断归因为代码 bug。它属于后验反事实接口诊断，不是独立确认、正式
性能、共同后缀机制实验或 PC2–PC5 通过证据。输入与输出绑定哈希，
输出排他创建，不覆盖既有产物。
