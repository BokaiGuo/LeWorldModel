这些链来自已暴露、有开发选择的候选对，并非独立任务或完整搜索池。

因此，在这个小面板上，“曾成功却在终点丢失”确实发生，但仅有两条；
不能用它单独解释整体退化。六对不一致样本不足以证明评分可靠，也不能
排除其他任务或完整候选池中的评分选择失配。采样只包含 0、5、10、
15、20、25 步；最小采样代价不是全时域最小值，时刻 0 的环境成功
状态未判定。

每条首次成功时刻与既有物理重放一致；动作均在域内；末帧编码代价
与既有原生像素管线结果一致（`rtol=1e-4, atol=1e-5`）；模型参数
指纹与前次相同。首次试跑发现环境初始观测为数组而步进观测为字典，
已修复，失败发生在输出写入之前。相关汇总与原生编码测试 2 项通过。

本实验没有记录模型逐时刻预测状态或整个已评分候选池，因此不能区分
预测动力学误差与目标评分失配，也不能完整分解覆盖、更新及闭环损失。
不得将真实状态、真实成功或真实编码分数反馈到规划器；不改变 PC0–PC5。
