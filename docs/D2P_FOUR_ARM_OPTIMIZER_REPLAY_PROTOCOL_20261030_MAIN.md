# 四臂共同优化器：固定候选优化前后模型重放

事后探索：使用既有四臂已封存的全部 16 个控制节点、每节点 8 个
初始及 8 个优化后 H3 候选，重建各节点实际 RGB 历史与动作归一化，
在同一冻结 checkpoint、主机 CUDA 上重新评价三包终态 latent MSE。
对优化后 8 个分数逐项复核原封存分数；若不一致则整次失败。保留
所有初始、优化后的分数及变化，不筛选节点，不做物理实验。

本实验检验优化步骤是否按模型目标改善及其量级；不能据此推断
真实收益、P1 通过、独立泛化或计算预算公平。硬件和实际外层预测
调用数、输入报告哈希、模型权重哈希与脚本哈希均需保存；禁止 CPU
神经推理，不覆盖旧结果。

## HOST01 结果

主机 CUDA 重放完成，记录 768 次 action encoder 和 768 次 predictor
模块调用；权重哈希前后一致。16 个节点各 8 个优化后分数与原保存
分数逐项相等（本次最大绝对差为零）。128 个候选的优化后减优化前
模型目标均为负，范围为 -0.346468 至 -0.000819，平均 -0.045654。
这排除了本批候选“优化后模型目标整体变差”这一解释，但不能证明
每一步单调、梯度数学完全正确或物理效果改善。
