# E3 根 1 cp10 目标：四臂真实反馈探索

固定根 1 历史 endpoints 轨迹第十步的真实 RGB 和同时间原生
状态作为目标，使用 `e3_cp10_target_cuda_20261031_RUN01.json`
中的冻结 CUDA 目标编码，不根据各臂结果调整目标。原根、历史、
目标像素和物理评价状态均须绑定，物理状态只供环境成功判定及
评估，不输入 RGB 规划器。

沿用根 1 cp5 四臂执行器、原初始化与分类资源账本，按固定顺序
执行 structured、native-style、random、immediate-progress，按原
时刻用真实 RGB 重规划。保留原生成功、截断和画布保护；如失败，
保留未启动槽及部分结果，不补终点或重试失败臂。

该根和目标是历史开发数据，不是独立样本；四臂成本未认证等价，
native-style 不是官方强基线。历史见证在第 4 步达到该目标，故
实验不保证每臂都跨越重规划节点。不得宣称 E3、P1、P3 或跨任务
泛化通过。
