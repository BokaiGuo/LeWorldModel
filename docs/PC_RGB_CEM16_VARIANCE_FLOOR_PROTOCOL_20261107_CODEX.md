# TwoRoom 低预算 CEM 方差下限开发对照

已有 40 个开发 episode 的 CEM16 每轮 5 条候选、2 个 elite、3 轮，最后一轮有效动作坐标的标准差有 252/908 小于 0.05；这是从已曝光记录计算的描述统计，不是独立证据。检验固定方差下限能否缓解过早收缩：在相同 checkpoint、RGB 输入、任务、执行上限、时序评分、初始标准差、种子、每次规划 16 次链评分和反馈规则下，仅将每轮 elite 更新后的坐标标准差下限由 1e-5 改为 0.2（归一化动作单位）。该值为开发假设，不将其事后调整。

每任务分别运行原规则及下限规则，使用相同种子，重新观测并重评分旧尾；分布一旦改变实际轨迹和后续观察可以不同。原规则每次选择与先前记录的派发动作及实际轨迹核对，不一致即停止且不写结果。模型参数保持冻结，物理真值只用于环境初始化、成功评价和实验记录，不进入规划器。计入模型候选链、packet 数、同步规划时间及任务墙钟；不包含模型加载或结果持久化。三个初态成功任务保留并另报其余 37 任务。

按任务报告成功数、配对独胜/独负、总查询和墙钟；这是强基线优化，不是 descriptor 或 PC gate 证据。开发出口事先固定：排除初态成功任务后，下限版本相对原版本独胜至少 3 根、独负不超过 1 根且平均每任务总评分链数不增加 10% 以上；同时保留所有任务和完整成本。未达标则停止扩大此具体配置，不否定其他优化策略。结果是否阳性均不改变历史结果。
