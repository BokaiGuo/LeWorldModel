# 任务得分预筛的行动后果端到端开发协议

制定于本次运行之前。上一面板的距离多样性预筛使合格候选至多一个，互补臂从未改变保留选择。本开发假设是：以即时任务分数顺序预筛、去除动作完全相同的前缀，可以在相同探针数量与预算下提供更多接近任务目标的候选，从而使已有的 0.05 绝对代价窗口更有机会比较至少两个候选。**这也可能剪掉即时稍差但有延迟收益的前缀**；不能预设它改善规划。

## 冻结配置

- 新开发任务：`start=[-0.5,y,theta]`，`y ∈ {-0.2,0.2}`，`theta ∈ {-0.95,0.95}`，`goal=[0.5,gy]`，`gy ∈ {-0.1,-0.03,0.03,0.1}`，共 16 个；运行前检查不与此前三个已记录面板逐项完全相同。它们仍是同族参数变化，**不是独立任务来源**。
- 每层按即时任务分数稳定排序，依次取前四个 float32 动作数组完全不同的前缀；不足四个取全部。两种保留臂共享生成、预筛、探针、即时 greedy 保护和两槽宽度。
- 保留上一实验的相同有限尾部探针、原 0.05 质量窗口、min 和互补规则、最后完整链评分及全局候选库。随机/谱方向 × min/互补四臂加 global CEM，逐任务共享相同模型、评分和 2880 prediction-token 上限；分项输出所有失败，不能从分母排除。
- 主要开发诊断为每方向 root 配对最终终距、成功及每层 min/effect 是否真的选择不同的前缀；记录窗口合格的非 greedy 候选数、候选实际动作是否重复。若未触发，明确报告不识别；若触发，也不能据此声称发现贡献或 PC3 通过。
- 每个模型调用逐条记账并保存动作；token 不是完整系统成本。应在同环境重算实际选中链与预测并核对日志。该面板不认证任务来源、真实物理表现、同链机制或独立统计；全成本与 RGB 确认仍需另行完成。
