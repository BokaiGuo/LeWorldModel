# 固定反馈计划：预测与真实结果同动作分解

使用已封存的全部 16 个前缀槽及其真实 cp5 规划和物理执行，不改变
动作、不重新选赢家。仅对十步后缀完整执行且保存验收通过的行，
比较真实 cp5 条件下的开放十步模型预测、真实中点 RGB 刷新条件下
的相同后五步预测，以及真实终点 RGB 的编码。固定检查 cp5、动作
字节、五步与十步真实帧、目标、物理状态和 CUDA 计划分数；原生
提前停止和越界不补终点。逐行保存 latent 与目标距离、真实任务指标，
按根/条件/臂对两个前缀配对；此时共同预算仅指后缀优化调用，不
包含前缀构造成本，不声称完整公平。

本分析在已有结果后提出，只做故障定位而非确认实验。中点刷新同时
改变观测和预测时域，不能单独归因；来自两个历史根和共享动作，
不把每个动作或配对当作独立任务。不得使用物理结果修改选择器、
gate 或规划器输入；不进行新物理或模型训练，神经运算只在主机 CUDA。
