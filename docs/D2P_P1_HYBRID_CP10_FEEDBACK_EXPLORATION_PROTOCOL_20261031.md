# 固定前十步后实时中点重规划：已知根开发协议

固定两个混合前缀、其 cp5 Adam 后缀的首五步及已封存物理 cp10 RGB。
不根据诊断结果选择根或动作。将 cp10 实际 RGB 编码替换模型预测
历史的末帧；更早两帧及动作历史按原合同顺序保持。
对于每根，取对应原四起点的第二动作片段作为确定初始化，
各做 20 次 Adam、学习率 0.05、动作范围 [-1, 1]，选预测目标
latent MSE 最小的第二片段，平局按索引。只使用 RGB、动作历史及冻结模型，
不得用物理状态、真实任务指标或真实后续结果选动作。

随后从相同根重放原五步混合前缀及原后缀第一段，逐帧验证
cp5 来源和 cp10 实际 RGB／状态／动力学快照，然后执行新第二段，
记录全部物理状态、原生终止、删失、调用和耗时。
固定原完整十步后缀为开放对照，两臂前十步逐帧相同才允许配对；
不得用提前成功轨迹填补终点。

该试验在两个已知根、观察既有结果后提出，使用额外编码与优化预算，
不能声称端到端公平或独立确认；P1 门不改变。不更新任何模型。
