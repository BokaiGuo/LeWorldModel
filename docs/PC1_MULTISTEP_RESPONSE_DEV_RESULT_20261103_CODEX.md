# PC1 多步响应开发诊断结果

按事前协议，在四个复用开发根上，以同一真实热身历史、冻结 RGB 模型和 MuJoCo 2.1.2.14 后端，分别比较 5/10 步、x/y 两个原始动作方向。模型预测先封存，再进行 64 条正负物理重放；各分支热身末状态一致。

| 时域 | 扰动幅度 | AD 与模型 FD 相对误差：中位数 / 最大值 | 模型 FD 与物理 FD 方向余弦：中位数 / 最小值 | 模型相对物理 FD 幅向量误差：中位数 / 最大值 |
|---|---:|---:|---:|---:|
| 5 | 0.005 | 0.00102 / 0.00347 | 0.99734 / 0.94091 | 0.26706 / 0.56857 |
| 5 | 0.05 | 0.05631 / 0.12286 | 0.99619 / 0.95473 | 0.22433 / 0.39488 |
| 10 | 0.005 | 0.00579 / 0.01314 | 0.99710 / 0.98514 | 0.17095 / 0.39007 |
| 10 | 0.05 | 0.18781 / 0.44393 | 0.99979 / 0.99667 | 0.09965 / 0.32520 |

每行是 8 个根—方向配对，两个时域和幅度不是独立样本。误差以对应参照向量的范数归一化。小尺度的 AD/FD 结果支持所测方向的局部梯度与动作接线一致；尺度 0.05 尤其在 10 步时不能把零点局部导数视作同尺度有限扰动的精确替代。模型与物理方向在这两个固定轴上接近，但物理幅值误差仍明显；该比较不能证明任意方向、碰撞区域、任务评分或动作排序可靠，也不能判定误差来源。

结果仅为开发诊断，不构成 PC1 整体通过，更不构成 PC2 非即时机制、PC3 公平优势或独立确认。训练和 normalizer 来源仍按既有边界标注未知；这批根已参与开发。未改历史 gate、未重开已停止的 PointMaze 机制协议。

产物：`le-wm-main/results/pc1_multistep_response_dev_20261103_codex_model.json` 和 `..._physical.json`；后者绑定前者哈希并保留全部逐步物理状态。模型统计为 12 次编码、72 次预测函数调用和 16 次反向调用，不是完整方法成本认证。
