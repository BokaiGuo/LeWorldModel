# 发现过程归因：固定机会与全额计费结果

按照[预定开发协议](PC_DISCOVERY_ATTRIBUTION_DEV_PROTOCOL_20261104_CODEX.md)，在此前 16 个已暴露 E0 任务、相同随机种子上，完成四臂共 64 次全额计费规划和 64 次固定机会精修。旧面板未更改；spectral 臂 16 条最终动作及分数与上一轮 ridge 全部一致。

全额计费（每臂最多 2880 prediction-token）：

| 规划臂 | 终距 `<0.05` | 平均终距 | 平均 prediction-token |
|---|---:|---:|---:|
| 谱方向、响应保留 | 5/16 | 0.30946 | 2879.25 |
| 随机方向、响应保留 | 4/16 | 0.32767 | 2879.75 |
| 谱方向、多样性保留 | 5/16 | 0.32423 | 2879.25 |
| 全局库＋CEM | 5/16 | 0.32607 | 2880 |

以 `1e-10` 作为数值相等容差，谱方向臂相对随机方向为 7 根更好、3 根更差、6 根相同；相对全局 CEM 为 6 更好、5 更差、5 相同。只替换保留规则得到 1 更好、0 更差、15 相同。样本小且开发任务已暴露，不应据这些差异宣称独立优势。不同 token 计数和 SVD、随机方向、墙钟及内存消耗并非完全相同。

固定机会：所有臂共享前两个全局起点、其随机流和各起点 157 次完整链评分；后两个起点分别取保留束或全局库，四个起点合计 628 次评分。各臂均为 4/16 成功；谱方向、多样性、随机方向、全局 CEM 的平均终距依次为 **0.27934、0.29407、0.32760、0.32776**。谱方向相对全局 CEM 为 6 更好、1 更差、9 相同。该比较仅匹配优化机会，不扣除生成不同起点的全部开销；固定机会执行额外支出 1884 token/臂/根，不能与全额计费结果合并为成本优势。

前一机制面板的两条基础见证 root 8、11，在固定机会下**四臂均由相同第一全局起点精修出完全相同的最终动作**：分别为 0.02038、0.06807。去掉响应生成及组合的全局 CEM 因而在该固定起点、随机流和预算条件下足以找到同一两条链。全额计费下 root 8 纯全局 CEM 也产生完全相同动作；root 11 纯全局 CEM 产生不同链且终距 0.04457。此反事实否定“这两次发现必须使用响应生成/保留”的强解释，但不否定其他任务或预算下响应的价值。

谱与随机方向仅在裁剪前按无穷范数幅度对齐，裁剪后的实际幅度、相关结构不同；随机臂仍计算谱和后继响应。多样性臂也仍支付后继探针。因此分别只能研究这里的方向替换和保留准则，不能声称完整无响应消融或推算移除响应的成本。固定结果使用的最终束来自各自完整运行，生成过程的成本与信息不一致，不构成独立确认。

全部计划与固定机会调用经预测账本、同环境另一几何、提案及结果确定性重放审计；`fixed_audit_v2.json` 额外逐批核对四臂共享前两个起点的 26 批优化动作完全一致。相同实现重放不是独立复现。结果与原始动作保存在 `le-wm-main/results/pc_discovery_attribution_dev_20261104_codex/`。

复现须另设输出目录并重新封存依赖：在 `le-wm-main` 依次运行 `.venv/bin/python -m experiments.pc_discovery_attribution_dev run`、`audit_plans`、`fixed`，然后运行 `.venv/bin/python -m experiments.pc_discovery_attribution_fixed_audit`。当前固定路径拒绝覆盖。

该开发实验使两条基础机制见证的发现来源更明确，但尚未证明响应引导有可重复的独立作用，更未形成来源独立、强基线、完整资源或同版本真实视觉控制优势；PC2、PC3 不宣告通过。
