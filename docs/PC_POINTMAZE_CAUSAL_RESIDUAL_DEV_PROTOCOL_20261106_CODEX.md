# PointMaze 已观测预测残差修正：开发协议

假设：一步 latent 预测误差中存在跨相邻决策近似共享的部分，可用上一次真实观测与该次事前预测的差来修正当前候选预测。本方法不训练模型。若预测偏差随动作、时间或接触快速变化，该假设可以失败。

固定八个已暴露轨迹 1884–1891。上一观测为轨迹帧 0，当前观测为对应帧 5，合法已执行动作是数据中 0–4；目标是同轨迹帧 10。当前三候选为五步 zero、+0.1、-0.1，执行时间与既有实验一致。使用同一物理后端与两个固定实际渲染相机 `(3,3)`、`(3.5,3)`；分别渲染上一、当前与目标初态，验证当前状态与上一动作真实重放一致。物理轨迹和目标物理状态只用于数据制备及后置评价，不向选择进程提供。

定义 `r = E(o_current) - Φ(E(o_previous), actions_previous)`；两个模型调用在同一观测权限下计算、均计费。当前候选比较 `raw = Φ(E(o_current), Q)` 与 `corrected = raw + r`，目标分数都为相同冻结编码器目标特征的均方误差；不调整残差系数，不拟合。`persistence` 对所有候选使用同一当前编码，并以预定动作顺序处理平分，仅为信息量基线。残差候选只允许使用历史观测，不能使用任何候选真实后继。

物理重放制备、规划选择、真实编码和物理后评估分别为独立进程。输入文件不包含未来物理标签；目标 RGB 允许输入。所有模型候选预测与校正选择在读取后继文件前封存，生成的有限候选预测特征供后置计分；Python 进程隔离不等于 OS 权限沙箱。若动作越界、发生数据缺失、初态无法绑定、模型或源码哈希改变则拒绝，不替换或过滤失败。

主指标按任务汇总两个相机的平均候选后继编码 MSE 与所选动作相对三动作池最优真实位置距离的 regret；逐视角和完整分母也报告。预定开发出口：八个任务全部有效、修正的任务平均 latent MSE 严格低于 raw；修正的任务平均物理 regret 不高于 raw，且至少 5/8 任务的平均 regret 不高于 raw、至少 1/8 严格低于。固定探索样本非独立、已暴露；即使达到出口，也不能认定闭环收益、描述增量、RGB-only 或任何 gate 通过。失败则停止该固定单位系数单残差构造，不事后调节系数。
