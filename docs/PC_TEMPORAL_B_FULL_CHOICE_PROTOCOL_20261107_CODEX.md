# 全候选池时序选链：已曝光开发对照

在已曝光 roots 20–49，固定使用已评分的 A 64 条、B 64 条及旧搜索的两个 incumbent，每臂拥有完全相同的 130 条合法动作、冻结 RGB 模型输出与时域。旧搜索产生前缀及 incumbent 的 600 条评分也计入共同逻辑成本；本比较不声称与完整强 CEM 等总预算。

只改变最终评分：endpoint 使用第 25 步，all-time 使用第 5/10/15/20/25 步最小代价，post-prefix 使用第 15/20/25 步最小代价。所有臂对完全相同的动作前缀按同一时钟进行数值一致性处理，最大允许差 `0.005`；最终平分按动作字节确定。评估前封存每臂动作、来源、代价与哈希，再用真实环境从同一初态实际重放 25 步。环境状态与真实标签仅用于重放评价；不得用于选择。

预定开发出口：all-time 相对 endpoint 在曾成功任务上至少 2 独胜、至多 1 独败，且终点成功数不比 endpoint 少超过 1；同时报告 post-prefix、实际末距、成功时间及完整分母。若不满足，停止此具体全池评分版本。即使满足，也只是同池选链开发结果，不是向量描述增量、闭环收益、独立确认或 gate 通过。

本协议在 B 物理排序已曝光之后制定，B 部分候选也有历史查询；不是预先封存的独立验证，须明确保留此选择偏差边界。原始规划器应执行多少步、成功后是否停止需另行闭环验证。
