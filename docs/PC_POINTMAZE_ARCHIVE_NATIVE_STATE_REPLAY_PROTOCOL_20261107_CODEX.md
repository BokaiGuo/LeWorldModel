# 归档八根：原精度物理初态重放

由 root 1891 的预定精度二乘二对照发现，将物理初态从归档 float64
转换为 float32 会导致 25 步末状态误差超过原 `1e-4` 阈值。本协议
对原八根全部使用归档 float64 物理初态，并执行先前预测时封存的
float32 动作；逐根逐步与归档状态、时钟比较，原通过阈值不变。

记录所有根，包括失败；不得用该重放覆盖旧的 float32 初态失败。
模型输入的 proprio 仍为 float32，这是预测接口原有输入；必须报告
它与 float64 物理初态并非逐位相同。后验精度诊断不证明整套
归档或渲染实现等价，也不证明控制收益。
