# 固定终点反馈 CEM 热启动 E0 开发对照协议

在运行前固定：使用已封存 v3 E0 面板的 24 个暴露 Wall 任务、相同
初始状态和 `15/10/5` 固定终点，在精确动力学中增加独立的
carry-aware smooth CEM 臂。第零次决策与原 smooth CEM 相同；后两次
各自先评价零链和本臂上一轮未执行尾部，在同一 1920 预测 token
上限内以较优者为 CEM 基点并保留 incumbent。每臂执行自己实际
选中的前五步并观测真实后继，不借用 response 轨迹或未来动作。

原 response 和 smooth CEM 的封存结果只作配对开发参照，不重跑或
更改。固定报告每臂最终距离均值、中位数、`<0.05` 数目，以及
新臂相对两个旧臂逐根胜/平/负；各臂自身轨迹可能不同，不是
控制中间状态的因果干预。预算仅保证预测 token 上限，额外记录
调用、样本及耗时，不声称完整资源等价。

新规划前封存协议、运行器、实际规划依赖、既有面板和其审计；
逐批保存 float32 动作和动力学结果，运行后检查依赖。另行重算
所有预测、选择、token、carry 和执行；排他输出，不覆盖历史。
结果是暴露开发根上的基线排查，不是充分调参、独立确认或 PC3
通过；如果源依赖漂移或审计失败，不使用结果作比较。
