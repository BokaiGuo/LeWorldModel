# 精确动力学动作身份保留：开发结果

## 决策

按[事前协议](PC_EXACT_ACTION_IDENTITY_RETENTION_DEV_PROTOCOL_20261106_CODEX.md)，
完整向量多样性保留**未达到预定开发准入标准，停止该具体构造**。
不是逐前缀岭线性描述的重跑，也不是对所有行动后果方法的否定。

| 保留规则 | 平均最终终距，越低越好 | 成功（终距 <0.05） |
| --- | ---: | ---: |
| 名义完整链 | 0.51296 | 0/24 |
| 即时距离 | 0.51430 | 0/24 |
| 共同尾部 ordinary lookahead | 0.52720 | 0/24 |
| 动作身份向量多样性 | 0.54651 | 0/24 |
| 动作身份打乱 | 0.54647 | 0/24 |

向量保留相比 lookahead 平均终距**增加** 0.01931，仅 5/24 根
严格更好；相比打乱对照平均增加约 0.000036。尽管 21/24 根的
保留集合与 lookahead 不同，差异没有转化为正向开发增量。所有臂
共享候选和 A 探针，并从各名义尾部开始以相同预算精修，选中的链
均已评分；每臂按协议计入 788 个五步 token，未包括评价端 B 和
未选前缀后验精修。

## 未查询尾部与覆盖边界

独立 B 尾部的每任务 MSE 再跨 24 根平均：名义链 0.28651、行均值
0.11435、加性 0.11934、向量近邻描述 0.12998；向量描述只有
4/24 根优于行均值。这是针对所声明的最近邻预测器和 B 分布的负
结果，不能代表其他描述或其他尾部分布。

重要限制：即使对所有八个前缀事后都给予 36 次合法精修、再由评价
端取最好链，仍为 **0/24 成功**，平均终距 0.51039。这是不可部署的
覆盖上限诊断，不是算法成绩；它也说明本面板的成功率完全无区分力，
不能用它证明组件无法发现任何成功链。预定停止判断同时基于连续
终距和身份打乱对照，而非仅凭 0/24。

这些是已暴露 exact-wall 开发根，精确模型就是物理动力学，没有视觉
预测误差，也不能用来证明冻结 LeWM 的后果可信性、真实 RGB 闭环
或独立泛化。未运行端到端强 CEM 对比；不能宣称完整成本优势。

## 工程核验

新实现记录 120 条名义 CEM 样本、4 条全局候选、共同 A/B 尾部、
8 个前缀各 36 条精修动作及各臂选择。独立审计重算全部代价、随机
流、前缀固定、合法边界、选择和评分，确认部署选择不使用 B 或
未选前缀的结果；两项单元测试通过。后验全池诊断与部署成本分开。
