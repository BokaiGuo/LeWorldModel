# CP5 fixed-bank real successor decomposition

On the four previously exposed roots and all four sealed CP5 prefix branches,
execute every one of the eight sealed five-step tail packets from the same
initial state and prefix, for 128 action-chain slots. Preserve duplicates
and report them as dependent slots, not independent episodes. Capture real
native RGB at steps 5 and 10; require every step-5 hash to match the source
branch and every original selected step-10 hash to match its source. Encode
each real step-10 RGB with the same frozen model on host CUDA using fixed raw
zero proprio. Independently replay the same actions with the established
position evaluator, and require each original selected endpoint to match the
source. Position labels and real successors are evaluation-only.

Per fixed prefix report all eight single-frame and history model scores from
sealed reports, the real-successor latent goal costs, position-only goal
distances, and the selected indices of both planners, real-successor latent
oracle and physical candidate oracle. Report candidate-oracle gaps and the
two types of exact-sign ranking reversals. Exact ties have zero sign; no
minimum margin was preregistered. These oracles use privileged outcomes and
are not deployable planners. No outcomes are used to select or modify methods.

Save actual RGB and pooled latent vectors, scores, endpoint arrays and source
hashes. Record duplicate sequences and preserve their multiplicity. This is an
exploratory development panel, not an independent test, success-rate benchmark,
perfect-dynamics MPC, equal-total-resource comparison or P1 demonstration.
Model training membership and normalization provenance are unknown; the
normalizer includes the full archive, the camera was selected on an exposed
root, and the checkpoint expects proprio while the diagnostic uses raw zero.
