# Five-response random bridge ablation

On the same observed 64 angular goals, compare the original five fixed
turn-only prefixes against five independently uniform turns in the identical
bounded turn interval. Each candidate uses the same analytical successor
velocity projection, two exact transitions and one terminal objective; seed
the random generator as `91200 + root_index`, with no outcome-based
resampling. Report all root outcomes and separate counts. This is an
exploratory matched-computation ablation of the hand-designed angle grid,
not independent confirmation or a learned world-model test.
