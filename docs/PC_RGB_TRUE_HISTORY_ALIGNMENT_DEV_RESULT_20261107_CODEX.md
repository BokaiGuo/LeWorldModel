# RGB PushT 真实历史对齐：开发结果

## 范围与协议边界

按 `PC_RGB_TRUE_HISTORY_ALIGNMENT_PROTOCOL_20261107_CODEX.md`，在已暴露的四个开发根 0、1、8、9、左右两侧执行固定的三个五步动作包，采集 0、5、10、15 步图像及完整物理轨迹。四个根是统计单位，八条轨迹不是八个独立任务；这不是正式确认或闭环性能比较。

原始评分实现有一项协议偏离：它读取了包含物理状态的 trace JSON 以核对哈希。代码计算没有引用其中的物理状态，也没有打开未来图像文件，但不能称原始评分进程未读取真实状态。原始记录保留，不覆盖。

新增独立评分进程只读取公开 manifest、0/5/10 步 RGB、动作、目标及模型和归一化数据；manifest 准备进程单独从原轨迹提取哈希，不导出物理状态。该复验是在原结果已知后执行的实施审计，不是新的盲法确认；代码路径未采用后验标签选择输入或模型。两次封存的 40 个预测数组最大绝对差为 **0**。这也不等价于所有模型接口都已通过权限封装认证。

## 对齐和预测结果

- 独立物理重放 8 条轨迹、120 步：所有状态快照最大差为 **0**；每 5 步图像逐像素相同，终止标志一致。
- 独立 GPU 手工 predictor 核验：三帧真实历史和历史动作置零预测与封存结果最大差为 **0**；8/8 轨迹中改变历史动作影响预测表示。这只验证本面板和具体计算路径。
- 四根等权平均真实后继 latent MSE：真实历史 **0.02258**，归一化坐标历史动作置零 **0.03647**，单帧 **0.02087**，当前帧 persistence **0.03752**。真实历史在 3/4 根优于单帧，但第 9 根较差，平均 MSE 未改善。
- 平均目标编码代价绝对误差：真实历史 **5.446**，置零 **6.322**，单帧 **6.932**，persistence **27.427**。这里没有事前设定显著性或科学通过阈值，不能据此声称真实历史稳定改善控制。

置零是标准化动作坐标置零，不等同物理零动作。实验比较固定动作的预测，没有用真实后继选动作；没有测试选中链的物理后果、相机偏移下的选择遗憾或实际闭环，因此不能判定最初 state-assisted 视角排序问题已修复，也不能把这组 RGB 结果提升为 PC0–PC5 通过证据。
