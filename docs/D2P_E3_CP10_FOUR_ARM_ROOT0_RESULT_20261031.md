# E3 根 0 cp10 目标：四臂真实反馈开发结果

固定历史 endpoints 轨迹第十步真实 RGB 和对应原生状态为目标；
目标在控制开始时不成功，历史动作见证第一次成功在第十步。
两根目标已在主机 CUDA 编码；本实验使用根 0，按预定顺序四臂
执行冻结模型与真实 RGB 反馈，未训练额外模块。

| 臂 | 控制步数 | 原生结果 | 最后物体位置误差 | 最后物体角度误差 |
|---|---:|---|---:|---:|
| structured | 20 | 未成功 | 13.129 | 0.02964 |
| native-style | 20 | 未成功 | 56.314 | 0.23943 |
| random | 13 | 成功后停止 | 10.378 | 0.00903 |
| immediate-progress | 20 | 第 20 步成功停止 | 10.032 | 0.00096 |

四臂均经过至少一个真实反馈节点；原生停止后不补步。成功还依赖
推杆和原生条件，不能用物体误差单独替代。本结果不能证明随机或
其他方法的总体优势：只涉及一个已知根、已观察目标，四臂成本未
认证等价，native-style 也不是官方实现。

保存检查核对目标像素、目标 latent、原生目标和最终状态、到达的
15 个节点的模型调用及 Python autograd API 账本、候选选择和实际
动作绑定；未独立复演整个物理事件链，调用计数不是 FLOPs 或完整
成本。目标绑定和错误根拒绝测试 2 项通过。E3 与 P1/P3 科学门
保持关闭。
