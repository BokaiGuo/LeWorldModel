# TwoRoom RGB 行动后果：固定动作矩阵结果

按事前协议，四个固定开发 seed 各使用五个前缀和五个共同尾部；冻结 RGB TwoRoom 模型先对 100 条合法十步链评分并封存预测，然后才重放物理链和编码真实末帧。运行时评分使用当前 RGB、目标 RGB 和合法动作，没有输入物理位置。

后果定义为同一前缀下“保持尾部的末端代价减指定动作尾部的末端代价”。下表是每根 20 个非保持后果的符号一致数量；平局单独记录，四根是统计单位，20 个动作配对不是独立任务。

| seed | 预测 vs 真实编码 | 预测 vs 真实距离 | 真实编码 vs 真实距离 | 任一侧平局 |
| --- | ---: | ---: | ---: | ---: |
| 2717100 | 17/20 | 15/20 | 16/20 | 0 |
| 2717101 | 19/20 | 11/20 | 12/20 | 0 |
| 2717102 | 19/20 | 12/20 | 11/20 | 0 |
| 2717103 | 12/20 | 7/20 | 11/20 | 5 |

每前缀五条尾部的 50 个两两排序中，预测与真实距离一致数分别为 **36、26、23、17**；最后一根有 6 对涉及平局。相应预测—真实编码表示均方误差分别为 **0.0744、0.0655、0.0693、0.1336**。真实距离是评价端位置到目标的欧氏距离，不输入规划；各比较的尺度不同，不能把数值大小直接当成同一误差量纲。

100 条十步链在任意时刻均未触发环境成功。因此当前结果没有成功／失败动作的区分能力，也没有比较描述与普通 lookahead 的下游保留效果。它说明在该有限动作支持和开发面板上，预测与真实编码有一定同向性，但与物理距离的关系因根而异；不足以认证 PC1，更不能证明 PC2 或 RGB 闭环收益。

**后续发现的 reset 例外：**seed 2717103 的原生初态超出 step 使用的边框范围，第一步即使零动作也发生 4.20 像素位移。原行及其分母仍保留，但不能将它当作合格静止初态；受控修正与重放见 `PC_TWOROOM_RESET_BOUNDARY_DEVELOPMENT_RESULT_20261107_CODEX.md`。

独立审计重置并重放全部 **100 条链、1,000 个物理步**，逐步距离最大差为 **0**、成功标志一致，真实末帧逐像素一致；从封存预测和真实表示重算目标代价及后果排序。审计使用同一环境与模型实现，不是跨实现认证。相关权限及动作矩阵测试 **18 项通过**。两阶段评分和评价使用不同进程，进程隔离不是安全沙箱。来源、训练外与 normalizer 独立性仍未知，PC0–PC5 不改判。
