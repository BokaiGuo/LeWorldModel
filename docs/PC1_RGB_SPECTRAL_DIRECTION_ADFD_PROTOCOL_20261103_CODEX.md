# PC1 RGB 谱方向 AD/FD 开发诊断协议

冻结于运行前。使用已有多方向 RGB 方法首轮的四个暴露 PointMaze 根，
每根首响应及两个保留父分支的后继响应，各取封存的两个右奇异方向，
共 24 个方向。使用原始 RGB 历史、动作历史、模型、normalizer、
投影与封存名义动作；后继固定实际父动作，只扰动后五步。

对单位方向，比较模型自动微分得到的方向导数与中心有限差分；
单位方向 epsilon 固定为 0.005、0.05 和 `0.5 / max(abs(direction))`。
最后尺度对应候选生成幅度；仅在双侧合法动作域内测量，否则明确跳过，
不裁剪。输出中心、方向、AD、正负预测、差分、绝对误差、相对误差、
余弦和原封存有限差分 Jacobian 乘方向。参考范数低于 `1e-6` 时不报告
相对误差及余弦；任何非有限值或输入绑定不一致即失败。

逐个绑定协议、代码、模型 checkpoint、参数、normalizer、源决策和
RGB 历史的哈希；计量编码、前向及反向调用，使用协作 GPU 锁，结果
排他创建。复算保存的数值和与源数据绑定；这不是独立根或模型复现。
大尺度差异可能反映非线性而非导数错误；物理一致性单独见已有实验。
不据此宣称 PC1 整体或 PC2–PC5 通过，不改变任何历史 gate。
