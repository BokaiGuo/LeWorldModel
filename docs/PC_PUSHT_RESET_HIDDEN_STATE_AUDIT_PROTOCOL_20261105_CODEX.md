# PushT 初始化隐藏状态审计

2026-11-05，运行前。针对当前本地数据集没有 `seed` 列、原生
`World._evaluate_dataset` 调用 `reset(seed=init_state.get("seed"))`
然后调用 `_set_state` 和 `_set_goal_state` 的实现，检查同一任务的
两次初始化是否得到相同的完整物理状态，以及相同动作是否重放一致。

固定 seed 42 的既有 50 行任务；对每行分别以原生路径构造两个环境：
先 `reset(seed=None)`，再覆盖起始 state 与目标；记录 agent、物块
位置、速度、角速度及公开观测，随后各执行同一序列的 25 个零动作，
逐步比较公开状态。零动作仅为测试输入，不是参考轨迹或规划器成果。
再做每行两个相同显式 reset seed 的正对照。保留全部失败及完整分母。
随机重置造成的不一致只能作为潜在配对混杂，不能单独解释任何已观测
成功差异；此审计不改原生协议或追溯改判结果。
