# P1：结构化候选与共同后缀优化器

探索性方法假设：模型动力学产生的不同任务响应前缀可以减少共同优化器的
无效搜索，收益需要覆盖 Jacobian、筛选和试算成本。不是现有结果，也不
替换真实能力机制实验或 P1 合同。

已实现独立纯数值候选选择核心
`le-wm-main/experiments/spectral_reachability/p1_task_response_diversity_20261030_main.py`。
对于共同目标方向 r、统一任务加权与统一动作坐标下每个预测后继的 Jacobian
J_i，特征为 `J_i.T @ r`。先按事前的模型即时分数选最佳候选，随后每次
选与已选特征集合最远的候选，平局按原候选索引；完整特征、分数、选择和
距离均返回。零响应和重复响应按固定分母保留，不声称它们是能力提升。
此规则只比较模型内对同一方向的响应，不能从一般 latent 变化幅度推断真实
控制能力。输入类型、维度、有限值和非零共同方向检查及确定性测试已完成；
尚未接到真实模型、预算账本或物理执行。

四臂实验应分别保留原生强规划器、固定数量随机前缀、即时进展前缀和
结构化前缀。后三臂使用同一有界后缀优化器及真实反馈次数；原生强规划器
保留原生搜索语义，单列初始化注入实验，不能将更改初始化后的变体称为
官方原方法。所有臂从总账扣除实际前缀生成、Jacobian、筛选、后缀试算、
优化、观察编码与反向成本；预算轴和预算曲线须在观察 outcome 前固定。
不同调用种类不自动等价，须分别记录并明确匹配或不匹配。

已有本地 GRASP 有界变体并非官方全协议复现；论文中的模型内成功率不能
直接作为本地物理成功率。已完成的五步能力探针、正在进行的同后缀干预、
