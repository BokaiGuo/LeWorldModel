# Shadow 闭环随机方向计算匹配开发合同

事前冻结；此实现轮不运行物理实验。沿用 `PC_POINTMAZE_SHADOW_SPECTRAL_CLOSED_LOOP_DEV_PROTOCOL_20261103_CODEX.md` 的两个已暴露根、各自独立 reset、12 步前缀、逐帧 v4 哈希检查、每臂自身连续 RGB 反馈、5 次重规划、动作域、时钟、模型与持久失败合同。此协议不涉及已有四条物理轨迹的重评估或回放。

对照为 spectral 方向与随机方向两臂；两臂使用相同根和每轮 CEM 噪声种子，但独立 bridge 和 RGB，故后续动作、图像允许分叉。每决策均按旧谱方法实际计算 1 次响应前向、2 次反向向量与 1 次 SVD；随机臂丢弃所得方向，按以下独立随机种子生成标准正态 10 维方向，按最大绝对值归一，应用同一 `(+.25,-.25,+.5,-.5)` 原始动作幅度并转换为训练归一化坐标。四个候选均经同一 CEM 正常评分。随机种子为 CEM 噪声 float32 CPU 连续字节与固定域标签的 SHA-256 前 8 字节小端整数，取低 63 位；该随机源不依赖 RGB、状态、梯度、谱方向或得分。谱方向规范和 CEM 均不改变。随机抽样及转换是额外操作，两个方向对照**匹配结构调用数与 CEM 样本数，不保证总 FLOPs、时间、内存或能耗相等**。

每臂每根 5 决策：每决策 50 次候选评分、4 批，1 响应前向、2 反向向量、1 SVD；两臂合计 20 决策，1000 样本、80 批，20/40/20 结构调用；目标各臂各一次编码（两臂合计两次），每臂两根共 12 次反馈编码，合计 24 次；4 reset、68 动作命令。额外记录随机方向种子、向量、生成时间、被丢弃的谱方向、结构数组和完整评估轨迹。失败 attempt 未 returned 的动作状态不确定，禁止自动重试。

开发实现复用固定 SHA-256 `e0bc75a72f49af42e3b0d67d523d6d67b45a9df413e9ea33bec43eae533c2990` 的上一版执行器：单进程、单线程、依次运行谱臂和随机臂；随机方向仅在该进程内通过临时可恢复替换谱候选函数实现，异常也恢复。输出必须是全新目录，子目录显式标记 `spectral` 和 `random`; 基础执行器内部将两者都标为 spectral，因此顶层带持久映射，禁止根据内部标签误判。禁用隐式重试，保留失败事件和全部部分结果。真实运行须显式选项与另行授权，遵守原 CUDA 协作锁；不得声称独立确认、真实效果或等总计算。
