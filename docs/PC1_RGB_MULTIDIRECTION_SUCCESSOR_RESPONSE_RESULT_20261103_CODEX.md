# PC1：RGB 多方向后继候选的十步响应诊断

按照[事前协议](PC1_RGB_MULTIDIRECTION_SUCCESSOR_RESPONSE_PROTOCOL_20261103_CODEX.md)，
对四个暴露 PointMaze 根首轮的两个保留父候选，分别物理重放后继名义
动作及全部后继候选，共 8 个父分支、48 条物理路径、40 个候选。
每条路径的热身及父动作轨迹与此前首候选审计逐位一致。

| 候选 | 比较 | 绝对向量误差中位数 / 最大 | 相对误差中位数 / 最大 | 方向余弦中位数 / 最小 |
|---|---|---:|---:|---:|
| 32 个谱候选 | 模型线性近似 vs 模型实际位移 | 0.06508 / 0.25276 | 0.28537 / 3.97649 | 0.99308 / 0.94219 |
| 32 个谱候选 | 模型实际位移 vs 物理位移 | 0.03050 / 0.10667 | 0.12678 / 5.17008 | 0.99726 / 0.22217 |
| 8 个 zero | 模型线性近似 vs 模型实际位移 | 0.03934 / 0.13835 | 0.40454 / 1.86919 | 0.99307 / 0.36997 |
| 8 个 zero | 模型实际位移 vs 物理位移 | 0.03779 / 0.05489 | 0.36844 / 14.47717 | 0.99544 / 0.36342 |

比较的是同一父动作之后，后继候选相对名义后继产生的位移；相对误差
分母是实际参照位移。较大的相对误差需要结合绝对量：zero 最差项的
物理参照范数约 0.00231、绝对误差约 0.03349；谱候选最差项物理参照
范数约 0.00585、绝对误差约 0.03025。它们高于预设 `1e-8` 阈值，
仍然计入，但不宜单独视为大绝对位移失配。候选及父分支仅来自四个根。

每个父分支内，模型评分最佳的后继同时是该五候选库中物理终距最佳者
（8/8），因此物理最佳也全部在当时的“最佳加最远”保留集合内。
但这不能证明其他未生成动作被覆盖，也不证明完整 15 步链最佳。逐
候选相对名义动作的模型评分差与物理距离差为 37/40 同向、3/40 反向：

| 根 / 父候选 | 后继 | 模型评分差 | 物理距离差 |
|---|---|---:|---:|
| 0 / 第一方向正号 | zero | −0.00741 | +0.01472 |
| 1 / 第一方向负号 | 第一方向正号 | −0.00011 | +0.02571 |
| 3 / 第一方向负号 | 第一方向负号 | +0.02222 | −0.00762 |

模型评分和物理距离只比较正负排序，不假定同尺度。实际动作与模型
float32 输入的最大舍入差为 `2.99e-8`。48 条物理路径已独立重跑并
逐轨迹匹配，8 个后继 Jacobian 从封存差分预测重建的最大误差为零；
这是确定性复算，不是独立模型或泛化证据。

该结果局限于首轮后继候选；没有验证 15 步完整链、其他模型和独立根，
不能判 PC1 整体通过，也不替代 PC2 非即时机制或 PC3 强基线比较。
存在响应及评分偏差不单独证明代码 bug，也不应直接归咎于理论。
