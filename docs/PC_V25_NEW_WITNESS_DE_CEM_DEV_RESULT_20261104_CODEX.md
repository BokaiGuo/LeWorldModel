# 新开发任务：特权前缀尾部求解对照结果

按 [预定协议](PC_V25_NEW_WITNESS_DE_CEM_DEV_PROTOCOL_20261104_CODEX.md)，8/8 根各得到两条几何见证，CEM 和差分进化的 16 根×臂均完成。每根每臂消耗 1,452 prediction-token，共涵盖两条前缀各两次 121 样本重启；每前缀两臂共享初始随机尾部。

| 求解器 | 成功前缀 | 至少一个前缀成功的根 | 16 前缀平均终距 |
| --- | ---: | ---: | ---: |
| 随机初始化 CEM | 3/16 | 3/8 | 0.3180 |
| 差分进化 | 1/16 | 1/8 | 0.2758 |

差分进化相对 CEM 在逐前缀终距上 12 优、0 平、4 劣；均值改善并未转化为更多 `<0.05` 成功。逐根记录的含账本墙钟合计分别约 0.66 秒和 0.72 秒；这不是完整总成本或可靠硬件基准。

每次模型请求的动作和费用已保存；审计通过两种求解器逐批提案重放、同环境另一几何实现的终点核算和样本预算检查。另以保存的逐批记录核对每次重启的返回动作确实是该次已评分最优链，并检查前缀及聚合，结果保存在 `incumbent_audit.json`。两条前缀来自特权几何见证，见证尾部未用于初始化；这些结果不能用于正式规划器，也不能算 PC2 机制或 PC3 等总成本优势。样本小且前缀同根相关，任务的广义来源独立性未知；重算不是独立复现。该结果没有定位此前失败的代码 bug，也不证明响应或理论失败。

运行：在 `le-wm-main` 使用 `.venv/bin/python -m experiments.pc_v25_new_witness_de_cem_dev_20261104_codex run`，随后以相同命令将 `run` 改为 `audit`；脚本拒绝覆盖已有输出。原始数据在 `le-wm-main/results/pc_v25_new_witness_de_cem_dev_20261104_codex/`。
