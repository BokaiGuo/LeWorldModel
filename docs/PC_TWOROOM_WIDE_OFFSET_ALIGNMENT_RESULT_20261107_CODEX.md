# TwoRoom 宽门偏移：预测、真实编码和物理对齐

按[协议](PC_TWOROOM_WIDE_OFFSET_ALIGNMENT_PROTOCOL_20261107_CODEX.md)，
在已曝光的 40 个任务上，以固定 13 个偏移生成 520 条 RGB 动作链。
GPU 模型预测、选择和表示先封存，再在评价端重置物理环境并重放每条
链 25 步；同一冻结编码器编码真实第 5、10、15、20、25 步图像。
真实后继和物理状态没有用于模型选链。

| 指标 | 结果 |
| --- | ---: |
| 候选 25 步内曾成功 | 399/520 |
| 模型选择的链成功 | 40/40 任务 |
| 固定零偏移链成功 | 40/40 任务 |
| 含成功和失败候选的任务 | 40/40 |
| 模型评分的任务平均成功/失败对排序率 | 0.9280 |
| 真实后继编码评分的同一排序率 | 0.9588 |

排序先在每任务内计算，平分计半，再对 40 个任务等权平均。13 个
偏移依次为 `0,-3,+3,-6,+6,-9,+9,-12,+12,-15,+15,-18,+18`，
各偏移的成功任务数依次为
`40,40,40,40,40,33,40,29,40,17,40,0,0`。

**事后简单对照：**只按偏移绝对值从小到大排序，在同一评估口径下
任务平均成功/失败对排序率为 **0.9698**，高于模型的 0.9280。
这是看过结果后加入的诊断，并非事前冻结比较；它说明在此手工几何
候选池中，不能将高排序率归因于模型独有的行动后果信息。固定零偏移
已经全部成功，也未观察到模型选链相对该规则的实际成功增量。

预测表示与真实编码逐元素 MSE，按五个 packet 分别为
`0.0867, 0.0857, 0.1434, 0.2573, 0.3123`；这不是物理距离误差。
预测表示重算代价与封存评分一致；所有链的重置渲染与输入图像
逐像素一致，模型参数前后指纹一致。候选生成和阶段推进测试共
**6 项通过**。仍有 Gym 观测类型与动作转换警告；重放使用相同
模拟器，未做进程级权限隔离。

这些是已曝光任务上的开放环候选池诊断，不是未查询动作泛化、
Action-Effect Descriptor 独立增量、端到端效率或 RGB 反馈闭环收益。
不能根据上述结果改变 PC0–PC5 判定。
