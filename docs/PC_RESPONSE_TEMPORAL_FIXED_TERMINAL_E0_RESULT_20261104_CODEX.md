# 时间相关响应程序：固定终点精确反馈开发结果

依照[事前协议](PC_RESPONSE_TEMPORAL_FIXED_TERMINAL_E0_PROTOCOL_20261104_CODEX.md)，
四臂在 24 个已暴露 Wall 任务上分别执行各自的 15 步真实精确动力学
轨迹；第 0、5、10 步分别规划剩余 15、10、5 步。首轮调用上一轮
封存算法，后两轮使用本次新增的固定终点反馈实现，因而这是一个
新复合反馈版本，并非将原开放环结果直接改名为闭环。

| 臂 | 平均实际终距 | 实际终距 `<0.05` | 响应臂逐根终距更低 |
| --- | ---: | ---: | ---: |
| 响应 + 时间相关搜索 | 0.39634 | 5/24 | — |
| 匹配随机方向 | 0.45867 | 2/24 | 11/24 |
| 全链平滑 CEM | 0.45872 | 2/24 | 12/24 |
| 全动作 CEM | 0.50010 | 0/24 | 15/24 |

响应臂根 0 的首轮开放环选中链评分为 0.03158，反馈重规划后的
实际终距为 0.00076；它们是不同动作链，不能相互替代。响应臂原
三个开放环成功根 0、6、23 在本次闭环均低于 0.05；第 2 轮在
1/24 根触发置零弃权。每个决策上限为 1920 token，各轮实际计量
与全部逐批预测保存在原始记录，不能把 token 等同总成本。

独立审计逐批重算了 288 次决策的 float32 输入、精确预测、评分、
预算、选中链、carry 及实际派发；96 次首轮与先前封存开放环选择
完全一致。新旧相关接口测试共 10 项通过。该审计未验证训练或数据
来源独立性，且对照只用一套配置，故本表不是 PC3 强基线确认。

上轮机制见证针对首轮选中的开放环尾部；本次闭环后两段重新规划，
因此不能把那份机制资格直接赋予实际执行的三段组合链。需要另行
审计该实际链；这一开发面板也不能证明真实 RGB 或 PC4。
