# 固定前缀等预算多起点反馈诊断

## 假设

单零均值 CEM 在已知有可行尾部的根 13 上未找到尾部。检验同总样本预算
下，多个分散起点是否改变搜索覆盖；不推断失败仅由初始化造成。
复用既有 24 个暴露任务和五类封存前缀，仅优化各自后缀；不重新打开已
停止的首次全链搜索，也不使用历史反馈的动作作为初始化。

## 事前固定

每个决策使用四个 CEM 起点：一个全零均值，另外三个为独立均匀
`[-0.6, 0.6]` 的逐时刻二维动作均值，标准差均为 1/3。每根、每个
决策生成一次起点和四个独立采样种子；对五类前缀完全相同。分布更新与
既有 floor-CEM 一致：每批最多 12，首样本为当前均值，保留全程最低分，
前四精英更新，标准差下限 0.05。

十步阶段四个起点各 60 条（合计 240 条、480 个五步 token）；执行最佳
十步计划的前五步。五步阶段先重评未执行 carry 一次，再以四个起点分别
运行 120、120、120、119 条（合计 479 条），加 carry 共 480 token；
低分严格替换 carry，平分保留 carry。总计每前缀每根 960 token。
起点生成器种子为 `2027030100 + 10*root + stage`，四个采样生成器种子
为 `2027040100 + 100*root + 10*stage + restart`，stage 为 0 或 1。
实际执行与 float32 评分规则同单起点协议。

保存起点、每批请求动作与分数、种子、状态、carry、最终动作及成本；
逐批重放评分、分段和整链执行，并重新构造起点、采样及精英更新。报告
五类前缀质量、成功率和 selected 的逐根比较，配对比较单起点固定配置；
同时报告非即时根，但不以结果增加种子或更改预算。

这是一项已暴露任务上的新优化器开发对照，不是充分优化上界、PC2 事前
同链证据、PC3 确认或 RGB 闭环。多起点与单起点每个阶段 token 相同，
但随机流、批次及计算开销不同，须单列；不把独立搜索的候选免费拼入旧臂。
