# RGB 闭环进程隔离开发重放协议

固定 TwoRoom 已曝光 episode 9000、9013、9022、9032，重放已有 temporal `effect` 与 `cem16` 两臂。父进程从数据集设置物理初态并执行模型选择的动作；规划子进程在私有挂载及 PID 命名空间运行，只接收当前 RGB、目标 RGB、剩余时钟、合法旧尾、任务标识及迭代号，使用公开的固定动作 normalizer 与冻结 RGB checkpoint。每五个环境步重新观察；保持历史种子、候选构造、选择、停止规则和 25 步上限。

对每个决策比较历史选中来源或索引、完整动作、派发动作、查询数及物理距离和终止标记；动作绝对误差上限 1e-6，距离上限 1e-5。逐条保留比较结果，记录模型及输入摘要；不一致应停止，不覆盖历史文件。

该实验只检查已曝光开发任务的输入权限及行为复现，不证明新的规划收益、独立泛化或任何 Gate 通过。命名空间无网络隔离，且设备、系统库和实验源码可见；路径探针不能证明恶意代码或所有侧信道不可访问。子进程不能接收物理状态、成功标签、真实距离或历史评价结果。
