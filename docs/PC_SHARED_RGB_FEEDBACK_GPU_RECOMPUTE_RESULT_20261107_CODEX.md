# RGB 反馈账本：GPU 复核结果

按事前协议，从 3 个已曝光任务的相同初态重放实际动作，每轮以实际
重渲染 RGB、目标图和封存随机流重建候选，用同一冻结 LeWM 在 GPU
重新计算全部 12 轮、132 条候选分数。

- 父链、共同探针及获准尾部的分数最大绝对差为 **0**。
- 12/12 轮保留前缀、最终候选身份和动作一致；物理距离及成功／截断
  标记一致，模型权重前后指纹相同。
- 复核规划部分同步计时合计约 **0.511 秒**；这是复核运行的局部
  计时，额外花费的 132 次候选评分不是原运行的部署成本，也不是完整
  系统时间。

重算和原运行共用模型、数值实现、环境及已曝光任务，因此这是工程
重复性证据，不是独立模型、独立任务或跨实现认证；没有公平基线、
机制干预或全成本收益证据。已有 Gymnasium reset 类型与动作转换
警告仍在。PC0–PC5 状态不变。
