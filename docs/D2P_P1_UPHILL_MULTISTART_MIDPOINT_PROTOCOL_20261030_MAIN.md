# P1 多起点固定动作：五步反馈误差诊断

固定上一轮全部 19 条走满十步的轨迹，不按排序或结果选槽；五条
原生早停不补十步结果。对相同真实 cp5 RGB、相同两个动作包和
相同冻结模型，重新执行开放两包 rollout，并核对十步目标分数
与原规划选出的分数；保存五步预测与真实五步 RGB 编码误差、
开放十步预测与真实十步 RGB 编码误差。再在中点使用真实 RGB
替代预测 latent，保持动作历史与第二包动作不变，比较相同十步
目标上的预测误差和目标排序。所有图像、物理状态和动作必须按
保存报告及哈希逐项绑定，神经推理只用主机 CUDA。

这是对已知根事后固定动作的诊断：真实中点是离线测量，刷新
预测并未重规划或重新执行，不能算真实反馈控制收益；冻结模型、
训练 normalizer 来源、独立 ABI 与全流程预算仍需单独认证。
