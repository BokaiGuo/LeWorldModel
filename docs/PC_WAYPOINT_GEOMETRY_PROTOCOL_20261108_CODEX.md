# 池外覆盖：二维 waypoint 生成与编译审计

2026-11-08，执行前协议。旧交叉描述/来源保持配置已停止，不改其阈值或结果。本实验检验生成支持，不声称描述贡献。

## 假设

旧生成器的`waypoint=(start+goal)/2 + lateral*[-dy,dx]`只覆盖起终点连线的垂直平分线。它可能排除15步内合法绕障路径。先验证转向/平移编译正确，再在同128查询预算内增加纵向自由度，而非增加seed或候选数。

新参数为`waypoint=midpoint + lateral*[-dy,dx] + longitudinal*[dx,dy]`。lateral仍均匀[-2,2]；longitudinal均匀[-1,1]。生成器只能使用该exact-state协议允许的初态、目标坐标和动作界限，不读取墙位置/高度、后继或成功标签。

## 固定实验

- 同24个已曝光任务×2生成流，仍用`2831000+100*root+repeat`产生128个lateral；独立`seed+70000`产生128个longitudinal。每臂128次完整15步评分，终距<0.05。
- `line_1d`：longitudinal全部0，须与旧编译器128条动作逐字节一致，并复现已封存同seed waypoint基线。
- `plane_2d`：全部采用二维参数，不按可解性筛选。
- `lineage_mixture`：前16条保留相同1D名义链，后112条使用对应二维参数；全部实际查询并保留已评分incumbent。它是本次主开发候选，纯二维是辅助生成消融。
- 不扩大时域；超过15步的名义程序仍显式截断并记录`required_steps`，不免费获得更长执行。没有新增精修器、响应探针、筛选规则或模型训练。

所有臂先封存实际选择，再评价。主出口：mixture相对line_1d净增至少4/48次成功且平均终距降低，报告24任务单位bootstrap（10000次、seed2839000）。若通过，仅支持采用更强exact生成基线；**不准入Full Planning Compiler，不证明RGB-only、PC2描述发现或PC3独立收益**。不通过则封存本生成配置，不调范围或换seed。

## 失败分解与验证

1. 所有1D参数零纵向时与旧动作完全一致；同成本旧基线复现。
2. 不含墙的解析unicycle积分：所需步骤不超过15的程序应抵达指定目标（atol1e-10）；若不满足，先判编译/时钟风险，不作性能解释。
3. 在执行的15步内记录真实碰撞、无墙终距、动作截断，失败按“碰撞且截断/仅碰撞/仅截断/其他”分类；类别可重算，不把尚未执行的完整几何路径当真实轨迹。
4. 评价端另用明确标注特权的waypoint `(0,+1.05)`、`(0,-1.05)` 构造可解性见证，每任务各2条。它们使用墙知识，只检验任务是否在15步内可解，不进入部署臂。
5. 选中链独立标量重放；动作、时间、全查询及预算原始记录绑定。编译正确、生成改善、描述增量三者分开。

复用既有精确动力学和原子产物工具，源码/协议/后端哈希冻结、逐根恢复。输出完整逐候选动作、代价、碰撞、轨迹、统计、图与结果。没有GPU或完整视觉闭环成本主张。
