本批是两个已知根上的事后开发实验，不是独立确认。先前完整 20
候选均已计算，不能将其费用冒充四候选预算。固定八臂，每臂记录
incumbent 和多样性选择各一条，共 16 条；重复根、条件或动作不
构成独立实例。不按物理结果删选。

重放器从已封存的多样性筛选和回溯结果重建每条 15 步动作，核对
候选索引、任务身份和 float32 动作字节，在冻结 checkpoint 上
使用主机 CUDA 逐条比较连续和逐包预测，并保存两条路径的完整
末端数组、每包动作 token 和更新历史。模型没有训练。
