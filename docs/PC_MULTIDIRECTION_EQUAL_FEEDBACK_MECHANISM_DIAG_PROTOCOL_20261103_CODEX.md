# 多方向最终前缀的等资源反馈规划诊断

事后机制诊断中根 20 在 120 样本单次后缀 CEM 下相对 zero 和 greedy
出现有限见证，但历史对照优于 selected，且该优化器曾遗漏已知好尾部。
检查该结论在先前已固定的另一反馈规划配置下是否敏感；不重新运行或
调节已停止的多方向首次编译器，也不从已暴露面板中挑选根。

固定先前 24 根及每根 selected、zero、同库 greedy、历史 random bridge、
lookahead 的五步前缀。对每个前缀执行共同的既有零初始化 floor-CEM：
在十步剩余时域使用 240 样本（480 个五步 token），执行前五步；重评分
carry 一次并用 479 个五步样本继续规划，总计第二次 480 token。种子
分别为 `2027010100 + root` 和 `2027011100 + root`，对五前缀共同；
动作约束、最终比较及计费完整复用既有固定前缀优化器。每前缀共 960
token，额外于原编译和先前干预，不允许使用历史好尾部初始化。

记录所有动作与分数，逐批重放，验证来源、相同反馈机会、token、所选链
和整链执行。报告 24 根每类最终距离、逐根比较、非即时根，以及根 20
对五控制的对照；沿用此前 `1e-10` 阈值并固定早先共同尾部结果，不
根据结果修改配置或追加种子。该反馈条件比先前单次 120 样本 CEM 增加
了后继观测和预算，测试稳健性而非等预算优劣；仍不是充分优化上界。
选中链是在反馈后拼接，不能替换原事前固定完整链或作为独立 PC2/PC3。
