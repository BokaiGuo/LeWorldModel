# 固定候选后缀预算诊断

本协议在观察 `PC_SAME_POLICY_EXACT_MECHANISM_DEV_RESULT_20261103_CODEX.md` 后制定，属于已暴露任务上的后验工程诊断，不是事前机制实验、独立性能确认或完整方法比较。

对已封存的 12 个任务、SVD 臂的全部三个固定候选前缀，使用同一精确动力学和相同 CEM 随机种子，分别执行 36 和 108 次完整链评分。36 次的动作／分数序列应逐项重现原封存的同候选搜索，并且是 108 次运行的前 36 次；否则停止报告。对每个候选报告独立后缀最佳完整链分数、差异、前缀名称；不重新选取原方法执行链。评分次数分别为每候选 36、108；诊断运行重复计算不计为原方法成本。结果存在则拒绝覆盖，绑定源计划、代码和协议 hash。

此诊断只回答同一固定前缀获得更多后缀机会是否改善本例，不能直接断言所有方法的总预算分配因果，也不能宣称 greedy 与响应方法公平或 PC gate 通过。
