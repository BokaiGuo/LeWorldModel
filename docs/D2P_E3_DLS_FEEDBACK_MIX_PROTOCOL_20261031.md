# DLS 前缀后混合初始化的在线反馈开发实验

使用既有两根和 cp10 目标。第 0 步 structured 保持目标 DLS 八
候选及额外 32 次优化不变；第 5、10、15 步真实 RGB 反馈后，
structured 保留 DLS 候选下标 3、5、6、7，并加入四个固定种子
独立高斯随机候选（标准差 0.4，裁剪至动作域）。种子为
`20261031 + boundary`，与物理结果无关。仍为八候选、原三包
预测评分、同样的优化和 winner refinement；其余三臂不变。

不使用交叉实验的轨迹或状态作为规划输入，不训练模型；神经
计算仅限主机 CUDA。输出首包绑定、各自真实反馈、实际分类调用、
原生停止及物理结果。固定候选数与调用数不等于完整等成本：
结构计算和硬件成本必须分开报告。此方案是在观察已知根结果后
提出，仅用于开发，不是独立确认、P1 机制证明或公平强基线。
