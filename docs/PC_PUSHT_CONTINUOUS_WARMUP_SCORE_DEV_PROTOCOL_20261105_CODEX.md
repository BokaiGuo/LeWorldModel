# PushT 连续 warmup 的固定库评分开发诊断

## 目的与权限

检验两个已筛选并重放过的物体运动目标下，冻结模型预测评分与真实后继编码评分的候选排序；不评价自动搜索或规划优势。序列 9、11 已按物理位移筛选，来源独立性未知，故为特权选根的开发面板，非确认实验。

每条序列从记录的第 0 帧和 agent 速度创建环境，连续执行记录动作 0–9 形成观测历史，时刻 0、5、10 的 RGB 和 proprio 构成合法模型输入。目标是同一环境继续执行记录动作 10–24 的末帧；参考动作仅用于离线构造目标和评价，不进入模型候选库或构造候选分布。对每个候选从同一第 0 帧重新连续执行同样 warmup，再执行候选动作，检查整个历史一致，避免中间帧重置及其物理小步偏移。记录实际目标和候选的完整末态、可见性、动作与 RGB；参考链物理重放检查与数据记录状态的误差。

## 固定候选与评分

两根共享独立随机数种子 `2026110702` 构造 64 条动作：第 0 条全零；其余 63 条每条 3 个五步恒值 packet，每坐标独立均匀 `[-0.2,0.2]`，float32。该库不依赖任一参考后缀，不能事后加入或移除候选。候选逐帧在目标及训练来源允许的声明范围内仅是实验假设，模型没有自动搜索。所有候选包括出画者一律保留，报告中心越界次数与全部分母。

冻结视觉 worker 在读取真实候选末帧前先对全部候选生成预测；评分为预测末态与目标编码均方误差，随后另行用真实候选末帧编码给出同一目标评分。物理成功：agent 与物体联合位置欧氏距离 <20 像素，周期角误差 <π/9。分别报告每根成功数、两个评分的首选成功及首个成功排名、预测与真实编码评分的非并列成对同序数，以及评分与物理目标误差的对应。若固定库没有成功候选，首个成功排名为 null，不能推断评分漏选成功动作。

预测与真实评分仅针对已经查询的候选，不证明未查询动作效果预测；参考链目标可达不等于固定库或预算内规划可解。无强基线、完整系统成本、来源独立或同版本闭环认证。完整记录运行器、物理后端、协议、数据、候选输入、worker 及输出哈希；保留全部失败，不重选任务。不修改 PC0–PC5。
