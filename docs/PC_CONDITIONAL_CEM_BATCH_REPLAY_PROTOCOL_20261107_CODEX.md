# 条件尾部 CEM 批大小敏感性审计协议

对已封存、已曝光的 TwoRoom roots 20–49，使用同一 RGB 输入、冻结 checkpoint、动作归一化器和完整保存动作，分别以批大小 16、32、64 重新计算 2 个 incumbent 和每臂三轮各 64 个候选的全部五个预测时刻代价。incumbent 仍单独评分，候选按原臂、原轮顺序评分。32 模式与原运行的批次划分一致。

核验上游 plan、候选池、输入、原运行器、协议、模型和 normalizer 指纹。分别报告相对原始分数和 32 批模式的最大误差、各轮 elite 集合是否变化、末帧最佳候选索引和动作字节是否变化；包含 root 38 的变化情况。相同动作但不同索引应单独识别。所有评分和记录保存为新文件，不覆盖旧结果。

本实验固定旧动作池，不重新自适应生成后续候选，因此 elite 变化无法推导完整重跑的选择或物理成功率；没有变化也不能排除跨设备、其它输入或重规划差异。不给出事后门槛，不以数值审计改判科学 gate。物理真值不参与评分和选择。
