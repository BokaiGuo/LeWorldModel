# 相同动作模板联合 CEM 开发对照

此事后协议在先前结果揭晓后固定，仅使用八个已暴露精确动力学开发任务；不构成独立 PC3。完整动作模板与程序臂相同：前两步均分总转角、接着四步恒速，再两步均分总转角、最后八步恒速。四个归一化自由参数分别为前转角/pi、前速度/.3、后转角/pi、后速度/.3，均限制在 [-1,1]，故覆盖程序臂使用的离散前缀与连续后缀，同时允许连续联合优化。

以每臂完整链评价 1145、2169 为硬预算（含零动作 incumbent 一次），四个起点均为零，四轮 CEM，初始标准差 .5、最佳八分之一精英至少 2、标准差底限 .02、同一任务种子 2026111900+index；余数依次分配到前面的轮次。各预算非嵌套。实际完整链 replay，绑定因子结果和后端哈希。与原始 diverse 两臂配对报告，不包含额外参数更新、筛选和墙钟开销，不能宣称总算力公平或穷尽全部强对照。
