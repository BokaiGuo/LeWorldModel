# 共同排序错误的模型／编码分解协议

在 `PC_CAMERA_MULTIVIEW_ENSEMBLE_DEV_PROTOCOL_20261106_CODEX.md` 已封存的 1884–1891 选择和同一物理重放上，只做事后诊断，不改变模型或动作选择。对每个任务视角和三个动作，用与 centered 完全相同的目标 RGB 位移变换目标图像及真实执行后的末帧，冻结编码器得到真实末帧到目标的编码代价；与先前封存的 centered 预测代价及真实末态位置距离比较。

每任务视角分别报告三种排序、预测选择／真实编码选择／物理最小的相同情况、成对排序；对于 1887 偏移视角记录完整三动作结果。真实末帧只可供评估端使用，不可作为规划输入。固定分母 16 个视角，不据此把相同任务的视角视为独立样本。包括编码与同步计时，成本不代表可部署方法。该分解是 state-assisted 模型在已暴露任务上的诊断，不是 RGB-only、反馈、机制或 gate 证据；编码误差也不自动证明模型实现错误或理论错误。
