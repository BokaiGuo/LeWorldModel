# 已选链的事后机制开发诊断

本协议在因子实验结果揭晓后制定，故只能做事后开发诊断，不能改变原选择、结果或作为独立机制确认。检查全部八任务、两预算和八个保留—优化器组合，不按结果挑臂。读取并哈希绑定原筛选封存、完整原结果和依赖；选中前缀及后缀必须与原完整动作逐元素一致。

对每条选中链分别用 selected、zero 和 same-bank greedy 三个前缀，执行共同的 11 个固定后缀以及该选中链后缀。报告所有共同后缀的绝对终距与相对各自零后缀的变化，不将同一前缀内的主动响应误记为跨前缀差异。各前缀自行重规划使用原同一个优化器、同样的 incumbent 及其原预算和任务种子；所需但原未计算的控制续规划另作诊断计算，不反馈给选择器。

沿用原有限机制资格：实际 selected 前缀即时终距不小于起点，且选中后缀对 selected 的相对零后缀变化严格优于两个对照，并且 selected 自行规划终距严格优于两个对照。此条件是有限开发探针，不等同完整 PC2，不要求修改选中链，不排除噪声和碰撞解释。原先已算的前缀—优化器计划复用并核对，否则重新按原算法计算。详细保存前缀、共同后缀结果、各自优化后缀、末端和 replay，统计额外开销。

本环境是精确已知状态的手工程序库，不是自动从冻结视觉动力学生成程序；不宣称 RGB、PC2 通过、PC3 强基线或独立确认。
