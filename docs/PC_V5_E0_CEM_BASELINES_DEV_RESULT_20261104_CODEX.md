# V5 E0 同预测 token CEM 开发对照结果

在 18 个已暴露根上，按[事后固定协议](PC_V5_E0_CEM_BASELINES_DEV_PROTOCOL_20261104_CODEX.md)，将已封存的 v5 与两个三次独立随机流的零初始化 CEM 对照；每臂每根消耗 1920 prediction-token。

| 方法 | 平均终距 | `<0.05` 成功 | v5 对该臂胜/平/负 |
|---|---:|---:|---:|
| v5 response | 0.501111 | 0/18 | — |
| 四结点 smooth CEM | 0.500959 | 0/18 | 9/0/9 |
| 逐步 action CEM | 0.501239 | 0/18 | 10/0/8 |

平局容差 `1e-10`；每根三次重启的最优值算一次，不能当成 54 根。两种 CEM 都从零均值出发，虽然探索全动作，仍不代表充分调优或结构化初始化的强搜索上界。三臂预测 token 一致不表示 SVD、筛选、调用和墙钟等总成本一致。此前解析轨迹诊断证明这些任务在所声明动作域与时域中存在解，却不能代替基线成功或排除其他搜索策略。

[原始候选与完整代记录](../le-wm-main/results/pc_v5_e0_cem_baselines_dev_20261104_codex_result.json)和[审计](../le-wm-main/results/pc_v5_e0_cem_baselines_dev_20261104_codex_audit.json)绑定源计划，重新计算 36 条计划的 23,040 条轨迹及每条所选最优链；仍共享精确动力学实现。该面板和 v5 结果在协议制定前已暴露，不是独立确认。结果未显示本配置下 v5 有稳定的实际幅度优势，也未证明方法理论无效或 PC3 通过。
