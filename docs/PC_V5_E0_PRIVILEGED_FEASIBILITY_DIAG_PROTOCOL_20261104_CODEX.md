# V5 E0 特权可行链事后诊断协议

使用已暴露的 18 根和已封存 v5 计划；不更改或重运行规划器。对每根分别调用既有解析两侧绕墙见证生成器，保留 15 步内、合法归一化动作的见证。通过与 v5 计划相同的 float32 动作转换、精确动力学端点和欧氏目标评分重放，并与封存链重算及全部已评分完整链的最优分比较。仅对成功见证报告假想完整链评分排序；它不测试将见证注入 v5 内部搜索或中间剪枝。

所有动作、路径、分数、限制、计划与代码哈希保存为新的不可覆盖结果。没有见证或见证失败不能证明任务不可行；该特权诊断不是方法性能、PC2/PC3 通过或独立确认。若发现精度、分数或动作合同不一致则报错，不改历史结果。
