# JEPA PushT 静态图像因子：重放及碰撞叠加控制

此前两个静态图像协议因严格图像校验失败而停止，不予覆盖。针对跨实例图像不匹配，绘制回调追踪记录了额外红色线段；[独立标志控制](../le-wm-main/results/pc_jepa_native_contact_overlay_probe_20261104_codex.json)表明关闭原生 `DRAW_COLLISION_POINTS` 后该对图像的差异从 242 通道变为 0。原生观测可能包含碰撞调试图形，因此不能把禁用它的图像称为原始观测。

本协议固定使用两臂各帧 10、15、20、25，帧 10 两臂重复。对每个边界独立从 seed reset、重放保存的暖身及派发动作到该边界；逐帧要求 RGB、状态和 proprio 与源逐元素一致，否则停止。目标由同后端原目标 reset 重放，要求图像和状态精确一致。每个边界验证后，不再推进物理，只在原环境直接更换 agent 与物体几何并重新索引，生成 base、agent-only、object-only、both 四项；每组同时保存默认原生绘制和取消碰撞点绘制的图像。然后恢复几何并要求默认图像和该边界原图完全一致，不满足则停止。

保留由原物理轨迹留下的碰撞缓存，因此反事实的默认绘制可能携带不一致的碰撞线；禁用碰撞线版本虽隔离几何，不等于真实规划输入。两个版本分别报告并标识，不将反事实认定可达物理状态。目标图同样保存默认和去碰撞线版本；每种评分都与对应版本目标图比较。图像要保存全部 8 边界 × 4 因素 × 2 绘图模式及两个目标。严格核对 baseline 原始图；并以完整图像编码分别计算主效应和交互，不筛除任何边界；如果 `both` 去碰撞图不等于目标去碰撞图即停止。

图像生成与模型评分分离；模型使用闭环相同冻结 JEPA encoder、变换、模型哈希、单图批形状、共享 GPU 锁和固定 UUID。记录图像、特征及依赖哈希，另以 CPU 重算分数。结果仅限这一个已暴露根的特权后验静态敏感性，既不是物理可达性、动态因果效应、规划收益，也不是任何 PC gate 通过。模型训练与 normalizer 来源仍未知。
