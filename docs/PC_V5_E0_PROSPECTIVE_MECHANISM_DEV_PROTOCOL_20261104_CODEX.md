# V5 精确动力学新网格：事前机制开发协议

## 固定范围与来源

在查看本批任何运行结果前固定以下网格：初始位置 `x=-0.5`，`y∈{-0.29,0.08,0.39}`，航向 `θ∈{-0.8,0.25,0.9}`，目标 `x=0.5,y∈{-0.15,0.15}`，按字典积顺序共 18 根。执行时检查网格内部无重复，且与已封存 v3 tail-local 及 v5 24 根相同任务不重合。它只是相对这些明确面板的新开发网格；完整历史搜索范围未认证，不能称来源合格独立确认集，不能用新根或新种子证明 checkpoint、normalizer 或训练外独立性。

冻结 `pc_target_reach_canonical_v5` 的 `response` 策略、初次 15 步开放环、1920 token 和既有精确 Wall 动力学；不调整阈值、动作、随机种子、候选数及优化。先独立封存全部 18 根的最终链及轨迹，逐批重算并验证每条最终链是全部已评分完整链中的最优值。只有全部计划及审计成功，才可执行事先定义的干预。优化失败、异常和弃权均记录，禁止事后替换计划。

## 固定机制判定

对每根将最终实际 selected 链拆为前五步前缀 `P` 和后十步 `S`。对照为同库 zero、即时贪心、同库 lookahead 和单条固定 random bridge。lookahead 用完整九候选中每个各 119 条采样的同种 CEM 最优结果选择；其额外候选搜索成本和选择偏差单列。随机桥用 `2027112300 + root` 的正态四结点线性插值、裁剪动作域，只生成一条。

1. 每一对照前缀及 selected 应执行同一固定六尾族：zero、`(±0.5,0)`、`(0.5,±0.5)` 常量尾和该根 selected 尾；记录绝对终距和各自相对零尾的变化。
2. 各前缀使用相同零尾初始、三个共同随机流 `2027112400+root*100+repeat`，每流 480 次候选的 CEM；比较三流终距的根内均值，不把重复当独立任务。对 lookahead 的候选选择使用独立的上述 119 次 CEM 流，与后续三流区分。
3. 对所有前缀用共同 selected 尾部（首五尾步裁剪到 `[-0.9,0.9]`）在 `.01/.05` 中心差分计算后继响应矩阵、目标距离梯度及障碍分支稳定性；记录裁剪和近零梯度。该局部响应不能无条件外推到未裁剪动作。

每根事前机制标记：selected 前缀和尾部非零；前缀距离相对初始不改善（容差 `1e-10`）；在 selected 尾下相对各自零尾的终距变化严格优于 zero、greedy、lookahead、random bridge 各 `1e-10`；三流平均重规划终距也严格优于每个对照 `1e-10`；两尺度对每对照的响应矩阵差及目标梯度差均大于 `1e-6`，所有相关前缀的所有扰动障碍分支各自稳定。任一响应的目标距离梯度未定义时标记不满足，不填造值。另报告仅对 zero、greedy 的较小交集；报告所有分量和失败，不事后修改规则或挑选更好的种子。

本机制判定是开发性的可证伪实验，不要求先赢 PC3 全部规划器；同时单个随机桥、有限 CEM、共享动力学代码与局部响应都限制解释。它不自动授予 PC2，通过与否需对照原方案的完整合同与来源要求，更不授予 PC3–PC5。不得用其他版本正结果补强本方法。
