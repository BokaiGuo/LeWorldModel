# 固定前缀编译器：RGB 轨道工程连通性

新增 `pc_fixed_prefix_compiler_20261107_codex.py`：在固定合法动作
前缀上为共同尾部探针评分，按指定规则保留前缀，仅查询保留前缀的
尾部；最终从已评分父链、探针组合、允许查询的尾部组合中选择完整链。
预算不足、非法动作、输入附加字段和无效模型分数均拒绝运行。

它直接使用已审核的 `RGBLeWM` 边界，实际查询生成对应输入收据；
该接口是数据流约束，不是 Python 安全沙箱。当前实现只接入 RGB
LeWM，尚未接入 state-assisted JEPA，也没有实现完整反馈、成本计时、
机制干预或后果描述的科学认证。vector 和 shuffle 只是已有开发规则的
工程实现；不把历史未通过的配置重新标为有效方法。

在此前已曝光的 3 个 TwoRoom 任务上，实际加载冻结模型并使用 GPU
运行 lookahead 流程：每根 3 条父链、6 条前缀—探针组合、2 条
保留前缀—尾部组合，共 11 次逻辑候选评分；另外对最终选择做 1 次
核验评分，再由评价端物理执行选中链。3 根中 2 根在记录的 25 步内
曾成功。此数仅是工程冒烟，不构成基线对照、闭环或 gate 证据。
模型权重前后哈希一致，选中链分数在 `1e-3` 内容差内重算一致；
环境有既有 Gymnasium 观测类型和动作转换警告。

新选择器及编译器合计 6 项测试通过，覆盖父链保留、禁止非法输入、
预算上限、固定种子及候选身份。逐任务动作、物理轨迹、输入收据与
查询计数见 `le-wm-main/results/pc_fixed_prefix_compiler_smoke_20261107_codex.json`。
没有改变 PC0–PC5 状态。
