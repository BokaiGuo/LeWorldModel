# 有界双分支结构对照：开发结果

按 `PC_BOUNDED_BRANCH_STRUCTURE_DEV_PROTOCOL_20261105_CODEX.md`，
固定 task seed 42、reset seed 771001，对三个求解器 seed 比较
不使用响应的双分支与单分布有界 CEM。每次规划均按协议计费
3000 条完整链评分；50 个任务的首次物理快照逐项一致。

| 求解器 seed | 双分支成功 / 50 | 单分布成功 / 50 | 仅双分支成功 | 仅单分布成功 | 双分支规划次数 |
|---|---:|---:|---:|---:|---:|
| 42 | 43 | 47 | 0 | 4 | 66 |
| 1042 | 43 | 43 | 2 | 2 | 67 |
| 2042 | 45 | 42 | 3 | 0 | 67 |

对照单分布规划次数分别为 63、67、69；因此仅每次规划的
评分数量相同，闭环总查询量并不完全相等。双分支三臂实际
执行 1461、1531、1490 步，均无物理动作越界。分支初始聚类
退化而使用预定交错回退的规划分别为 0、5、2 次。

结果没有呈现跨求解器 seed 稳定的成功优势；同一任务面板重复
三次亦不是独立任务泛化。双分支末尾在两个均值中按额外模型
评分选择，单分布直接返回均值，因此差异混合了分支表达和
选择规则，不能将其独立归因给结构。该实验没有使用响应或后果
描述，也不能证明响应增量。初始簇内部仍对完整链求均值，
不保证每一条原始前缀—尾部配对都被保持。

所有 trace、运行指标及每次评分账本位于
`le-wm-main/results/pc_bounded_branch_cem_task42_solver*_20261105_codex*`；
汇总可运行 `python -m experiments.pc_bounded_branch_cem_analysis_20261105_codex`。
未进行墙钟公平性、独立确认或 PC gate 晋级。
