# v7 PushT 同候选库物理排序：后验开发诊断

固定 v7 已暴露单根第三轮的同一真实物理边界；不重新规划、不增根、不调候选。候选为该轮原封存的全部九条 `first_bank` 五步动作、实际执行完整链（此轮长度五步）以及本臂传入 carry，所有动作和模型分数直接绑定原决策记录。候选可能相同，保留身份不将它们当独立任务。模型分数分别取该轮原候选库同批预测、最终配对选择或 carry 重评分；每类分数的批次可能不同，浮点排序有数值敏感性。

对每个候选独立重置相同 episode、执行原 15 步暖身和前两轮 v7 实际派发，并确保第三轮根 RGB、目标和完整状态与原始封存边界一致；再经与原运行相同的 RGB guard 派发五步。逐命令记录 guard、状态、RGB 与终止标记；遇到拒绝或终止保留失败，不补齐数据。对完成分支保存物理状态、终点 RGB 与官方指标，并用同一冻结 encoder 对真实终点 RGB 计算目标 latent MSE。

仅在完成的候选间报告模型预测分数、实际 RGB 目标 latent MSE、物体位置误差、角度误差、官方成功与两两排序一致率，明确并列排除规则与有效对数；候选和根高度相关，不视作独立样本。物理状态和事后分数仅用于评价，不输入规划器，不能用物理最优候选替换实际派发链；这是后验分析，不是 PC2 同链机制或 PC3 确认。
