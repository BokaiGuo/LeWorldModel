# Reacher fixed-action prediction / real-RGB / physical replay

All 52 fixed arms (two exposed roots × 13 prefixes × two previously generated
L2/Q tails) were replayed on host CUDA and the real simulator. The saved
consumer verified the action sequence and normalized prediction tokens,
matching cp5 RGB/history, matched original cp5 and terminal joint distances
within 1e-8, event order, terminal RGB/history, finite metrics and unchanged
model parameter hash. It is a saved-record consistency check, not a separate
attestation that every recorded neural operation or physical step occurred.
These are repeated measurements on development roots, not independent
outcomes. The first sandbox attempt failed before inference or physics because
NVIDIA device nodes were not exposed; its journal is retained separately.

The comparisons below use **unweighted L2** distance in the declared planning
coordinate for predicted and actual-RGB latent, and wrapped joint distance for
the physical outcome. In particular, the Q-tail group label refers to how
its actions were generated; this table is not a Q-weighted ranking analysis.
For each 13-action panel, counts are within-root pairs for which the two
distances rank the actions oppositely. There are 78 pairs per panel; none are
independent roots. Exact ties are excluded from the denominator.

| Tail / root | Prediction vs real RGB | Real RGB vs physical | Prediction vs physical |
| --- | ---: | ---: | ---: |
| L2 / 20263160 | 32/78 | 22/78 | 42/78 |
| L2 / 20263161 | 41/78 | 8/78 | 49/78 |
| Q / 20263160 | 9/78 | 19/78 | 26/78 |
| Q / 20263161 | 13/78 | 8/78 | 17/78 |

For the 13 same-prefix Q-versus-L2 suffix pairs, prediction/real-RGB,
real-RGB/physical, and prediction/physical reversals respectively were
3, 2, 3 on root 20263160 and 0, 0, 0 on root 20263161. All 13 comparisons
were non-tied under exact equality in each case. No near-tie threshold was
predeclared, and these descriptive counts should not be treated as an
inference about a population.

This separates two observed failure links under the chosen L2 readout:
prediction-to-observation and observation-to-joint-distance. It does not
attribute either to a unique implementation defect or prove that Q is better
as a planner. The two tail sets were generated by different objectives on
already-open roots, and Q/L2 share prefixes. These results cannot establish
non-greedy reconfiguration, an independent planning advantage, or P1.

## Post-hoc Q-metric decomposition

The same saved predicted, observed and goal vectors were additionally scored
with the goal-encoder Gram matrices authenticated by the Q-CEM plan. This is
the square root of the Q quadratic cost, so it preserves that cost's ordering.
It is a post-hoc analysis of the same actions, not a fresh physical experiment.

| Tail / root | Q prediction vs Q real RGB | Q real RGB vs physical | Q prediction vs physical |
| --- | ---: | ---: | ---: |
| L2 / 20263160 | 11/78 | 25/78 | 34/78 |
| L2 / 20263161 | 5/78 | 9/78 | 10/78 |
| Q / 20263160 | 27/78 | 20/78 | 47/78 |
| Q / 20263161 | 14/78 | 4/78 | 18/78 |

Changing the readout changes the observed ranking mismatch, but does not
eliminate both links across panels. These pair counts are correlated, use
exact-tie handling, and cannot establish that one metric generalizes better.
The Q scorer's diagonal closed form and invalid Gram rejection passed six
tests together with the L2 pairwise checks.

## CEM winner score bound

For all 52 arms, the score recomputed from the replayed prediction is no
greater than the original final CEM elite-mean score plus `1e-5`. The L2
arms use mean squared latent error; Q arms use the original goal-Gram
quadratic mean. This is a necessary consistency check because the final
winner was the best sample and therefore could not be worse than the elite
mean. It is **not** an equality check: the historical journal saved the elite
mean, not the selected sample's individual score. It cannot certify exact
numerical parity or exclude every action/history/normalization wiring error.
The bound and duplicate-source rejection were checked in fixture tests.
