## 各自规划和结论边界

本表另绑定了从各自真实 cp5 RGB 出发的四起点 Adam 后缀及真实
物理结果；anchor 3 的后缀越界删失，不补终点。另外，已验收的
单起点真实中点反馈控制对照中，5 条可执行 selected 均无原生
成功，物体终点位置误差相对 zero 为 5/5 更高、相对 greedy 为
4/5 更高；参见 `D2P_P1_RESPONSE_MIDPOINT_CONTROLS_20261031.md`。
两类优化合同不可混成同一次公平对照；都共享已知根，且总前缀
计算成本未认证。

本批共同后缀的物体位置结果不支持该候选相对 zero 的所测响应
优势；对应反馈结果也未建立可规划能力优势。它不能证明其他
候选、其他物理指标或理论不可能。历史同动作 CUDA 分析已发现
真实中点刷新后平均预测 MSE 降低，但刷新和时域同时变化，且
任务指标与 latent 排序仍可能不一致；不得把这称作单独因果
归因。仍需固定任务指标、使用新候选及独立根、同预算和强对照。
