# RGB 规划进程文件系统白名单开发协议

复用四个已曝光任务的无标签公开输入、冻结 TwoRoom LeWM checkpoint 和此前梯度规划代码，不更改候选生成或选择。新进程运行于 bubblewrap 私有文件系统与 PID 命名空间；只挂载系统运行库、Python 虚拟环境、实验代码、评估图像预处理源码、指定 checkpoint、指定公开输入，以及临时输出目录。不得将研究仓库根、结果目录、HDF5 数据集或用户主目录整体挂入。

规划进程在加载模型前检查以下路径不可读取：实际 TwoRoom 数据集、旧梯度物理结果、旧选择计划及此前评价记录；同时确认公开输入与 checkpoint 可读取。使用私有 `/tmp`、私有 `/proc`，关闭继承文件描述符。GPU 设备按本机需求挂载；本机不支持新网络命名空间，故不声称网络隔离。系统目录、设备及可执行代码仍可见，这不是对恶意代码、GPU 侧通道或所有路径别名的完全安全认证。

规划进程结束后，由外部评价进程加载原公开计划，比较模型摘要、四任务动作、梯度、分数和选择，`rtol=1e-5, atol=1e-3`；不读取物理状态或结果来修改已封存选择。保存命名空间配置、路径探针、结果摘要和哈希。任何源依赖缺失、禁读路径可读、输出缺失或数值失败均失败退出，不能静默换模型或放宽挂载。运行不进行新的物理评价，不作为 PC gate 或算法增量证据。
