# 可执行行动后果向量：冻结 RGB 模型接口检查

新增的后果库对每个可执行前缀，分别拼接相同时长的参考动作和共同
探针，计算“参考链代价减探针链代价”；它检查动作形状、有限性和
边界，记录完整链评分次数和动作字节哈希。参考动作由调用者明确
提供，不把零动作自动认定为物理静止。

在已曝光 TwoRoom 根 10、20、30、40 上，使用冻结 RGB LeWM 实际
执行 GPU 评分，每根 8 个前缀、8 个探针和一个等时长零动作参考，
共 **288 条完整链评分**。64 条探针链相对先前保存分数的最大误差
依次为 `0.0000610`、`0.0000610`、`0.0000610`、`0.0002137`，
均小于本次接口校验容差 `0.005`；权重指纹未变化。两项单元测试
通过，覆盖方向、参考相减、查询计数、维度及非法动作拒绝。

逐前缀 `参考代价 - max(后果向量)` 与固定探针 ordinary lookahead
最优终点代价一致。这是定义直接推出的恒等式，不是新的规划收益；
要证明完整向量的贡献仍需在相同候选和优化机会下超过普通 lookahead
及身份打乱，并在真实执行中兑现。**本轮没有物理重放或闭环评估。**
零动作仅是合法参考动作，尚未认证其在所有状态下物理静止；不能将
本次结果登记为 PC1 任务相关性或任何 gate 通过。

`experiment-code` 用于约束可执行动作、候选身份、计数和测试；未把
接口测试当作方法效果。结果按既有工程文件组织，未生成没有研究
意义的训练曲线。
