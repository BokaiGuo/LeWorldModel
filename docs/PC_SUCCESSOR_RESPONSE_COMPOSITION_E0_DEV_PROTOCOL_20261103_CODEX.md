# 后继响应自动组合：wall 精确动力学开发协议

运行前固定。复用 `pc_wall_response_side_20261103.tasks()` 的 8 个已暴露几何任务和精确碰墙动力学；长度 15 的归一化动作映射为物理动作 `[.3*v, (pi/2)*omega]`，后补一个零动作以调用原 16 步后端。每前缀长度 5，组合中第二段长度 5，最后后缀长度 5。目标是完整时域真实终距；精确动力学仅是开发预测器，不得输入正式 RGB 选择器。任务为已暴露开发集，并非独立确认。

在两个预固定预算 960、1920 个五步预测 token 上分别运行：

1. `successor_response`：第一段从 zero 和两个固定名义点的完整响应 SVD 自动生成三个候选；对每个第一段，分别在该后继条件下、两个相同名义第二段附近计算完整响应，生成 zero 和两个响应第二段，形成九个可执行两段程序。
2. `successor_nominal`：同样的第一段响应库、同样两个第二段名义动作及 zero，但不提取后继响应。
3. `successor_random`：同样的第一段响应库、第二段名义动作和 zero，以预固定种子对各第二段作最大分量 0.5 的随机扰动。
4. `no_composition`：同样第一段响应库，不预生成第二段，剩余十步交给相同优化器。
5. `same_bank_greedy`：从相同第一段库按即时目标距离选取一个，余下十步用相同优化器。
6. `full_cem`：直接优化全部 15 个动作，不承担候选生成开销。

每臂分别生成、分别计费；第一段每名义 21 次五步预测、第二段每名义 21 次十步预测，SVD 另计。实际模型评分在预测接口按 batch × 时域／5 从预算扣除。候选臂把生成筛选后可用完整链样本的 3/4 向下取整，均分给候选作迭代 CEM；余数以最优完整链为初值进行相同联合精修，精修前最佳链必保留。greedy 只给选中的同库前缀分配后缀样本，full_cem 全部预算直接优化。所有臂允许完整动作合法范围；zero 包含在候选中，但不强制选出无即时进展前缀。

各任务预算、所有实际模型输入动作、预测评分、候选、分配、选择、计算账本及依赖 hash 先封存；独立审计逐批重算并核验最终完整链及 token。额外独立干预只针对 `successor_response` 的最终选中链，比较 zero 与同库 greedy：应用相同预设十步后缀族（全零、恒定 `(±.5,0)`、恒定 `(.5,±.5)` 及选中链实际后缀），并为每个前缀各用 120 次完整链评分、相同随机 seed 的迭代 CEM 重规划。先定义有限机制条件：五步前缀终距不小于初始（容差 1e-10）、实际后缀相对各自零后缀的变化严格优于两控制、重规划终距严格优于两控制。对同一条精修后实际选中链核验，不使用未选中候选补证。

报告两预算的终距、成功阈值 `<.05`、机制条件及实际成本；不按结果选择预算。两档和八根不是 16 个独立任务，equal token 不是 equal FLOPs；手工已知可行见证不注入生成与评分。本实验没有真实 RGB、独立确认或训练来源认证；不自动通过 PC2、PC3 或历史 P1。
