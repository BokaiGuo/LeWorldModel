# V5 E0 已暴露新网格：同预测 token CEM 开发对照

使用 v5 已封存的 18 根和最终链，不重跑或更改 v5。事后固定两个全动作 CEM 臂：四结点插值 smooth 和逐步 15 结点 action，均调用现有 `core.cem`、从零链初始化、每根三个独立确定性流，各 213 次采样；先共同评价一次零链，共 640 条 15 步链、1920 token。三个 restart 的最佳完整链与零链共同参与最终选择，均允许平移与转向同时发生。随机种子为 `2027112600 + root*100 + restart`，两臂共用；同一根三个流不是独立根。

每批保存请求和实际 float32 动作、端点、分数与 token，记录每代 CEM 状态；选择器保留三起点历史最优。独立重算保存动作、评分、预算及全链最小值并验证原 v5 计划审计。报告逐根胜平负、终距与成功 `<0.05`；分解和时间等额外资源另列，预测 token 相同不等于 FLOPs 相同。诊断面板此前已暴露，对照事后固定，不能称预注册独立确认、充分调优的强基线上界或 PC3 通过；多起点仍都从零均值开始，也不覆盖解析或任务结构初始化。
