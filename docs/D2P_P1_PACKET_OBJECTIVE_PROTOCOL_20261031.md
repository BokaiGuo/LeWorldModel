# P1 中间状态与终点共同目标：开发对照

目的：检验终点-only 评分是否遗漏中间状态信息；不声称 latent
距离是原生成功，也不修改 P1 gate。此设计是在观察历史物理与
预测结果之后提出的，全部 24 个输入均为已知开发根。

对固定的 selected、zero、greedy 三种真实 cp5 RGB 上下文，
沿原模型以五步动作包开放预测两次，优化
`0.5 * mean((z5-goal)^2) + 0.5 * mean((z10-goal)^2)`。
同一 logical pair 的三种前缀使用与历史终点-only Adam 相同四个
起点、20 次更新、学习率 0.05、动作盒和 winner tie-break；
两包预测的调用及 backward 均计费，不用物理真值选择动作。
在生成任何新模型结果之前固定公式、角色、输入和计数。

模型比较包括 24 槽、每槽四个起点；记录每起点两个阶段分数、
联合分数、选定动作字节、耗时和模型哈希。计划后必须完整绑定
新动作并对所有预定槽真实执行，再以历史终点-only 实验作为
探索性参考；历史结果不是独立确认，也未认证全流程等预算。
若推理、绑定、越界或提前停止发生，分别记录，不补固定终点。

冻结模型及编码器，不训练 policy、critic、adapter；神经计算仅
用主机 CUDA。此目标未显式表示任意中间步的成功，也不保证更好；
结果不能作为 P1 通过或动态程序优势证据。
