# PushT dev305 原生高分辨率与固定裁切对照

本开发协议在执行前固定。对打开过的 dev305 种子 301000005，使用原生
PushT renderer、`with_target=False`，分别以 224 和 512 分辨率执行
独立环境 reset；不执行 `step`、不访问环境状态用于评价或选择。保存两个
reset 返回的目标 RGB 及当前 render。224 目标和当前图必须匹配已封存
dev305 对应的 RGB 像素哈希；512 全画布按原 OpenCV resize 降至 224
也必须逐像素匹配相应 224 采集，否则工程失败、禁止候选选择。

固定备选视场是原生 512 画布内的 `[32,64,480,512)`，即 448×448
画素，经 OpenCV 相同插值缩放至 224；目标及当前观察均使用相同裁切。
它是显式、新的开发视场，不是旧合同中原始图像。所有分析只使用 RGB。
先用既有颜色 mask 的同一阈值在 512 分辨率测目标和当前图：两类 mask
必须非空且每个 mask 像素全部位于裁切内；然后对 224 裁切目标和当前
分别应用未修改的 8 像素 RGB guard。原生全画布对照也应用原 guard。
任一不满足或身份绑定失败时阻塞，不调用选择器、不派发动作。即使全都
通过，也仅表示裁切接线可进入后续校准，未证明同色遮挡、相机坐标映射、
模型输入适配、控制安全或旧 gate 通过；本协议不执行候选器。

不因结果修改裁切坐标、不使用归档以外目标、不改变 margin、不根据
物理 outcome 调参。该裁切不能恢复原 512 画布之外的视觉信息；模拟器
没有公开相机位姿或更宽视野参数。错误、图像与停止状态保留在新目录，
资源账本记录 reset、渲染、零动作和零神经调用。开发根已打开，不是
独立确认或真实世界摄像机采样。
