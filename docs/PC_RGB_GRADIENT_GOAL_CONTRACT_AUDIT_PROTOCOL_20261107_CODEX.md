# RGB 梯度候选的目标合同审计

本开发审计固定已封存的四个任务、五条候选和已记录的真实末帧及预测特征，不重新生成候选、不改变物理执行。逐任务从相同 reset 和数据行恢复评价端目标状态，比较：

1. 公开规划输入目标图像与该物理目标状态在当前模拟器重渲染的目标图像，包括 RGB 绝对差、差异像素数及图像形状。
2. 将评价端代理置于物理目标状态时的环境距离、成功判据和实际渲染图像，验证距离与目标渲染含义；恢复候选初始状态时须精确复现公开当前图像。
3. 用相同冻结编码器、图像变换及封存预测和真实末帧编码，分别对公开目标和重渲染目标计算五个末帧代价、候选排序、选中候选的真实物理末距。公开目标计算须复现已封存代价，`rtol=1e-5, atol=1e-3`。

重渲染目标和物理状态仅供事后评价，不回流正式规划器。图像差异本身不证明物理状态不匹配；模型对目标图像敏感也不证明部署能够合法获取重渲染图像。该实验仅对已曝光任务和已封存候选进行假设生成，不更改成功标准、gate、历史结果或自动替换目标。记录所有任务包括初始已成功任务，分别报告差异与选择后果；连续末距不等于曾成功。
