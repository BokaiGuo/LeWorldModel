# Three-prefix own-suffix development experiment

Freeze both known roots, all three prefix roles, and the current target.
Generate the original eight optimized DLS H3 candidate plans at boundary 0.
All roles pay for that generation and eight additional H1 stage replays.

- selected: original H3 model-selected candidate;
- zero: five exactly zero physical actions;
- greedy: candidate with minimum H1 model latent cost in that same bank,
  with the lowest index breaking ties.

Greedy means library-restricted model-greedy, not global optimal physical greed.
No physical outcomes enter prefix selection. Record the complete candidate bank
and stage scores before dispatch. All three roles use the same original
structured planner, candidate rules, optimization counts and real RGB feedback
at boundaries 5, 10 and 15, with original stopping rules. This experiment has no
carry selection: it isolates prefix effects with a common own-suffix planner.

Both roots and all roles must be retained, including failure or early stop.
At matched boundaries report task position, angle, pusher, native success and
stop/censor status separately. Do not pad missing post-termination observations.
These are known-root development runs, not independent confirmation.
The common-suffix intervention is separate and remains required.
