# P1 已知根全部非赢家后缀的物理对照

目的：区分四起点候选均不适合真实任务，与模型选择的赢家错过
已有真实有效候选。固定 24 个已封存的 selected / zero / greedy
前缀及其真实 cp5，执行四个固定 Adam 后缀中的三个非赢家；
赢家沿用已有物理结果。对于每个前缀，按原起点索引升序排列
三个非赢家，分别组成 rank 0、1、2 三个完整 24 行面板。即使
候选动作重复也全部保留。不得按模型 margin、物理结果、根或
动作差异筛选；不可将这次事后探索用作新根确认或学习选择器。

非赢家动作来自固定重放，不是原运行封存动作；此前 24 组四个
分数、赢家和赢家动作字节均精确重现，并经显式动作包路径复算。
准备阶段必须验证来源哈希、每个赢家字节、全部候选动作哈希、
分数和索引以及前缀、目标、cp5 绑定。真实物理执行复用既有
逐步记录和保存验证；结果按同前缀比较成功、停止状态、返回步数
及同时间物体位置、角度和推杆指标。提前停止不插补固定时域终点。

物理成功只用于事后诊断，不进入规划选择；不能声称更换模型
评分即可泛化，也不能把不同逻辑臂视为独立任务。若非赢家成功
且赢家未成功，说明该候选集存在模型排名与观察结局的差异；
若全失败，只说明此有限候选集的物理结果。它不是共同后缀族
机制实验、全流程等预算比较或 P1 通过。
