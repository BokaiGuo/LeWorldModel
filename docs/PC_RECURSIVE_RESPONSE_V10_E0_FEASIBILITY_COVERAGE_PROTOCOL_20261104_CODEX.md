# v10 E0 可行性及固定尾覆盖：后验诊断

在八根开发结果已知之后，固定复用既有解析见证构造器的两个高度 `-1.1`、`1.1`，不调整见证、任务或规划。对每个构造器声称所需步数不超过 15 的动作，按声明动作域归一化到 float32、重放前 15 步并检查终距 `<0.05`；其他标记未认证。记录全部见证和失败，不能把它们输入 v10 或当方法成绩。

对每个已成功见证，取其第 6–15 步作为**共同特权固定后缀**，分别拼接该根 v10 单／双模态各自首层全部自动候选，与见证自己的前五步形成对照。记录每个候选终距、最小动作空间距离，以及原先保留集合和全集中满足 `<0.05` 的索引。统计按根和高度分层，不根据候选搜索结果选后缀；这些高度是特权解析见证，不是可部署输入或独立确认。

固定尾成功仅表示首层候选与这个特定尾可连接；失败不排除其他更好后缀，保留集合损失亦仅针对这个共同尾。若见证自身未能通过，则不能对该高度声称覆盖或未覆盖。独立重算完整链及索引，封存来源和代码哈希。探索性后验诊断不重开此前开发面板调参，不证明 PC2/PC3。
