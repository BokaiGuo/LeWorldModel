# RGB 搜索区域多时域动作导数开发核验结果

按预先写入的 `PC_RGB_SEARCH_REGION_MULTIHORIZON_DERIVATIVE_PROTOCOL_20261107_CODEX.md`，在 GPU 上完成 4 个已暴露 TwoRoom 任务、3 种时域、每种 2 个方向，共 24 个方向的冻结 RGB 模型标量目标导数核验。物理动作经过标准化后输入模型，自动微分与同批大小中心差分比较。

| 差分步长 | 达到开发数值判据 | 最大绝对误差 | 最大相对误差 |
| --- | ---: | ---: | ---: |
| 0.001 | 24/24 | 0.04149 | 0.04704 |
| 0.002 | 24/24 | 0.06062 | 0.05365 |
| 0.01 | 24/24 | 0.04002 | 0.01338 |

5、15、25 步时域各有 8/8 方向在三个尺度均达到判据。三个尺度不是独立任务，也不能据此推断统计泛化。名义链裁到内点；按任务和时域统计共 175 个动作坐标被裁剪，重复方向未重复计数。因此结论不能直接推广到原边界动作或裁剪非光滑点。

本实验使用封存数据集初始 RGB 帧，未验证其与物理 reset 后渲染帧的一致性；无真实环境后果或实际部署收益评价。它只支持所抽取内点附近标量评分方向导数与有限差分的数值一致，不能证明完整潜变量 Jacobian、模型物理预测正确或响应描述具有价值，也不改变旧零动作实验的冻结判据。PC0–PC5 均未因此改判。

代码、输入、协议、冻结模型与归一化器的指纹保存在 `le-wm-main/results/pc_tworoom_search_region_multihorizon_derivative_20261107_codex.json`。解析模型链式法则、合法边界和确定性方向的 3 项单元测试通过。
