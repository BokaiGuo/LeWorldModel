# Common selected-tail warm-start replan: post-hoc diagnostic

The mode-count plan and prior intervention outcomes are already exposed.
This is not prospective PC2 confirmation. For every one of the eight
two-mode selected chains, take its actual selected tail and provide the
identical tail as the initial suffix to selected, zero, same-bank greedy,
lookahead and random prefixes from the sealed intervention. The tail is
method output, not a physical oracle, and is shared with every control.

For each prefix, evaluate that common initial tail once, then use the same
four-knot CEM, three fixed paired seeds and 480 samples per restart as in
the existing intervention; preserve the initial complete-chain incumbent.
Compare absolute scores and paired mean own scores, save every scored action,
and verify actions and scores using alternate same-environment geometry.
Count all roots including failures. This diagnostic changes optimizer
initialization relative to the original contract and cannot retroactively
change its intersection or confer a gate.
