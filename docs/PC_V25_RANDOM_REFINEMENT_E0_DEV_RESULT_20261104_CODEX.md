# v25 随机完整链精修起点：等预算开发结果

按预定协议，八根新开发任务、v25 原方案与替换精修起点两臂全部完成。两臂的成功率均为 **0/8**；以随机精修臂终距与原 v25 比较，为 **0 优、6 平、2 劣**。同一根两臂 token 完全一致：七根 1,920，一根 1,918。每根精修样本数亦相同（112–120）；每根有三个原精修起点被替换，首个完整链 incumbent 未替换。

随机臂实际评估的三个起点为均匀随机完整动作链，且被替换前的响应／全局起点构建成本仍计费。因此这是精修起点策略替换的等预测 token 结果，不是纯粹的固定前缀尾部初始化对照，也没有得到完整链质量优势。

事前零改动测试核对原 v25 的全部预测动作与选择；面板审计检查所有动作和 token、初始全局库、完整链最优、随机策略元数据、另一同环境几何实现与确定性编译器重放。它们不构成独立复现，亦未证明各根可在正式 oracle 预算下求解。GPU、编码和反馈成本不在本 E0 测试范围。

补充事后配对账本核查：8/8 根两臂的首次动作分叉均为四条完整链精修起点批次，该批首条 incumbent 字节级一致，其余三条与预定随机种子一致；首次分叉前的动作、预测及评分完全相同。记录见 `le-wm-main/results/pc_v25_random_refinement_divergence_posthoc_20261104_codex.json`。此核查不构成独立复现。

这一结果不否定此前特权固定前缀下随机尾部的开发信号：两者初始化空间、保留前缀和预算分配不同。不能据此宣布理论失败或 PC2/PC3 通过。
