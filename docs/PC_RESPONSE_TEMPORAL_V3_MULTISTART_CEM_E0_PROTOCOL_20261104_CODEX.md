# v3 开放环同预算多起点 CEM 开发对照协议

为排查现有单次 CEM 对照是否过弱，在 24 个已暴露 Wall 开发根的
相同初始上下文，与已封存 v3 response 首次 15 步选中链比较。
预先固定三个新的不分阶段 CEM 配置：4、8、15 个时间结点，均在
相同二维动作域上以四个独立随机起点运行；每个起点分布以全零
动作链为均值，种群 12、精英 4、初始标准差 0.35、下限 0.07，
即多次独立随机搜索而非四个不同均值。所有起点共享一次零链
评分，余下 639 个完整链样本以 160、160、160、159 分配，各自
保留局部 incumbent，最后从四个起点和零链选全局最低。每根每臂
预测开销均为 1920 个五步 token，完整记录每批 float32 动作、
预测、分数、分布、采样及种子。

在本次开发对照不调整方法、预算和根；事前报告每臂平均终距、
终距 `<0.05` 数目及相对 v3 response 的逐根胜数。计划和审计独立
排他封存，所有精确预测及预算逐批重算。原 response 计划的源码、
协议和既有审计哈希必须保持不变。该比较只是排查单配置弱基线，
不是调参充分证明、全部成本等价或 PC3 独立确认；三配置不事后
挑选最优后声称确认。
