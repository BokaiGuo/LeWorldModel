# PointMaze 因果残差额外开发面板协议

固定轨迹 1892–1899，历史帧 0 至 5、目标帧 10，两个相机 `(3,3)`、`(3.5,3)`，候选动作及单位残差系数与原开发协议完全一致。此前部分轨迹已暴露，其余来源及训练成员不明；本面板不是独立确认。

先对每条轨迹的前 15 步逐步重放，状态最大绝对误差必须不超过 1e-4；绑定源数据和重放文件。随后在隔离进程中制备输入、封存选择与预测、后置审计。未来状态和真实候选后继不得参与选择。沿用原始协议的八任务开发出口，不事后更改阈值。另报告 persistence 后继编码 MSE、每任务及每视角选择和物理遗憾。若开发出口失败，停止该固定单位系数单残差构造，不调整系数以争取阳性。

模型使用官方所需完整 proprio，结果仅属 state-assisted 开发；不能升级为 RGB-only、闭环收益或 gate 证据。样本、每次规划的三动作池以及有限时域不能代表完整规划器。
