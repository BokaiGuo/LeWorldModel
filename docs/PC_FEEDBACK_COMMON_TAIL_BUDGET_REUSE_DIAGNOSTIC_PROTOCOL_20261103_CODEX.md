# 共同实际尾部替换一个 CEM 评分名额：事后诊断

固定上一份已暴露反馈尾部干预及其先前同前缀 120 样本 CEM 跟踪，不重新
优化和不增加根。对每根每个前缀，将原时间顺序前 119 个完整链和该根实际
执行尾部拼接所得链作为 120 条已评分候选，比较其中最低分。所有五个前缀
获得相同的一条共享尾部和相同数目原始候选；末一个旧候选被丢弃。追溯
重算所有候选的 float32 精确动力学评分，并记录旧 120 最低分、新 120
最低分、获胜来源、与 zero/greedy 的逐根比较。

这不是完整重新运行的 CEM：原 CEM 第 120 次之前的自适应分布没有接收
共享尾部反馈，因此不能作为注入后的 CEM 性能。实际尾部来自反馈后的
事后信息，不能进入部署策略或 PC2/PC3 正式结论。只用它区分“已知共同
候选与当前有限搜索所得最佳值不同”这一优化诊断，不能宣称充分优化或
用新计算替换原干预。
