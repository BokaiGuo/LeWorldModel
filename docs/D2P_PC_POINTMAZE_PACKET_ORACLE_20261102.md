# PointMaze：模型 packet 对齐的固定动作库物理 oracle

原先的固定库 oracle 将一个候选执行一次作为前缀、执行两次作为终态；已有后续审计明确指出，一个模型 packet 对应五个档案环境动作，因此不能把旧结果直接解释为模型 packet 时域上的规划结论。本次保留旧报告，另在相同八个已打开 root、各自固定 32 动作和首个 active waypoint 上，令每个候选连续执行五个档案动作，分别评估一包及两包的全部 `32 + 32×32` 条序列，共 8,448 条物理模拟序列。

在相同两包总执行时域内，比较「一包最优首动作，再为它选最好的第二包」与「联合选最优两包」。有 6/8 个 root 的首动作不同，且这六个联合选择的首包 waypoint 距离较一包贪心更差，后续两包终距则更好；剩余两个平局。旧一／两档案动作分析是 2/8 首动作不同，时域确实影响判断。差值按根保存，不能把两种不同时域的结果直接当作同一次实验。

这是使用特权模拟器状态和真实物理后果的**有限动作库、单次决策 oracle**，不是 learned-world-model 的可部署选择器；waypoint 不是最终任务成功，八根也已用于开发。它不包含真实反馈重规划、完整状态合同或等计算强基线，不能据此声明非贪心能力机制、PC0 完整通过或 P1 通过。物理后端 5/10 档案动作沿用已封存 position-only 合同；全状态、接触及训练外独立性未认证。

报告 SHA-256 `3b38090507edc8f787cf0981e4d93a0d9d76636a593e2356e77386a4953a7b2e`；保存分析 `fe521f3ef0f0e9fc6b91105be9f7eb20167b1fa40a732481095354ca3f64b4e9`。分析对每根独立复算全库 argmin，并在物理后端重放一包及联合两包所选动作；新旧时域单元测试共 5 项通过。下一步必须从相同 RGB 历史对完整固定库运行冻结模型评分，并执行公平实际规划，才能判断这些物理候选是否能事前由模型发现。
