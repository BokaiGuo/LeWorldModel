# 已有差分输出能否提示墙体分支不稳定：事后诊断

此前实际探针的分支检查显示部分后继响应在 ±0.05 下跨越墙阻挡分支。
固定一种无需读取墙体或特权状态的代理：每坐标计算
`||p+ + p- - 2 p0|| / (||p+ - p-|| + 1e-8)`，两个范数使用同一
二维输出。分母很小时该比率不稳定，须同时报告绝对中点残差及分母；
不将其解释为导数误差或作为 planner 的新过滤规则。

按已封存 v8/v7 的全部 first 和 successor FD 批次逐坐标与刚完成的
分支标签匹配；报告不同标签组的中位数、基于全部坐标的排序 AUC
（平分得 0.5）及预先在本分析固定的阈值 0.5 的混淆计数；另报告
按根聚合的结果。阈值仅作为量纲无关的示例，不按结果挑选、调参或
声称适合 RGB。根已暴露、标签相关、协议在原运行后制定；
任何发现均是后验开发线索，需独立任务和真实模型检验后才能用于新方法。
