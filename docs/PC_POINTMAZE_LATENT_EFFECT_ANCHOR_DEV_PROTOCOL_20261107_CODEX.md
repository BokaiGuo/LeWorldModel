# PointMaze 当前编码锚定的行动效应：开发协议

针对已暴露的 1884–1891 固定相机面板，检查预测的共同表示偏移是否影响动作选择。与旧实验同样使用旧 centered 变换、当前 RGB、完整当前 proprio、目标 RGB 及 zero/+0.1/−0.1 三个五步动作包；不使用目标 proprio 或候选未来真值。每个视角一次编码当前和目标，预测三个后继。原始评分为预测后继到目标的 MSE；新评分为 `当前编码 + 该动作预测后继 − 零动作预测后继` 到目标的 MSE。

这是假设性的共同偏移扣除，不是物理恒等式：零动作可能继续移动，当前编码不是真实零动作后继，动作相关误差也不会被共同偏移修复。已有 RGB 位置锚定实验操作的是状态位置而非此 latent 表示，但同样提示不可假定零动作保持。不能把此构造称为模型代码 bug 修复。

用独立评分进程读取既有公共输入，比较原分数与先前选择记录（atol `1e-6`、rtol `1e-5`），封存 16 个视角的两臂选择；之后评估进程才读取物理后继距离。若任一视角被拒绝，不按完整面板报告。记录两视角间选择一致性、逐根平均 regret、1887 偏移视角及实际模型调用。额外当前图像编码需计费；同三个候选的零动作预测并非免费查询。

预定开发出口：8 根至少 5 根两视角平均 regret 严格改善、整体均值严格下降、1887 偏移视角严格改善；否则停止此构造，不以更换权重或阈值争取阳性。面板结果已知，因此只是后验设计的固定候选开发实验，不是独立确认或闭环；模型使用完整当前 proprio，属于 state-assisted，不能晋级 RGB-only 或任何 PC gate。
