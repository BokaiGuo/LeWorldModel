# E3 已知根 cp5 目标：四臂真实反馈开发合同

事前固定使用第二个已知根、该根历史 control5 RGB 及其完整原生状态
作为同一目标；该目标在 control0 不满足原生成功，历史五步动作
为可达性见证。四臂均从同一 control0 开始，在 0/5/10/15 使用各自
真实 RGB 和动作历史规划，最多执行 20 步，原生成功或截断则停止。
按既有 extra32 合同运行 structured、native-style、random 和
immediate-progress。目标图像的冻结模型编码用作规划目标；原生
状态只用于环境目标和评价，不能输入模型选择动作。

必须检查目标图片文件与像素哈希、真实 cp5 latent、源根状态及
历史、目标条件成功判据，并对运行期间目标和模型参数进行绑定。
前缀/后续规划按既有资源账本记录，实际编码和物理开销分列。
这是已知根、历史见证目标上的开发实验，不是独立泛化、正式 E3
通过、P1 机制证明或已认证的公平强基线。不可用该目标替换
旧 G1 数据，不做新训练，不按结果筛选或改变停止判据。
