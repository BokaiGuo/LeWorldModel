# 条件尾部 CEM 失败任务完整候选池复盘

对既有 30 根条件 CEM 的实际物理结果，事后选出任一臂未曾成功的全部 root（38、39）。对每根两臂各自有权使用的两条 incumbent 和全部 192 条尾部候选逐条从原初态物理重放，执行满 25 步，记录完整逐步距离、终止和截断。共同候选可以复用但两臂各自登记；先验证选中动作哈希与既有选择、复放旧选中链逐步轨迹一致。

模型分数和动作来自物理结果之前封存的原池；不使用物理结果更改排序。分别报告每臂曾成功链数、末帧成功链数、模型评分最低成功链的排序、已选链物理结果、同池有解但选择失败、以及模型最优评分与最好成功链代价。完整池仅包括两个 incumbent 与该臂自己的 192 条候选，不声称涵盖之前 600 条初始搜索链，也不把初始搜索的候选成功情况当作已知。

这是根据已有失败结果挑选的事后诊断，只说明两根任务各臂的候选覆盖与选择；真实状态和成功用于评价而非规划，不提供独立性能或 gate 证据。若重放轨迹或来源哈希不匹配则停止并报告，不覆盖历史实验。
