# P1 新前缀历史输入绑定对照

对固定 24 个 uphill planner 输入，按已封存的根与渲染条件重建真实
warmup 三帧 RGB 和十步原始动作。冻结模型在主机 CUDA 对三帧逐帧
编码，按原顺序和 `root_latent_history` 的三个位置逐元素比较；
动作按 bundle 声明的 mean/std 逐步归一化、按时间顺序组成两包，
与 `root_action_history` 逐字节比较。所有行保留，不使用真实
控制结果或后验挑选；计划和模型均不改变。

该对照核查保存历史与可追溯输入在当前模型上的一致性，不认证
训练时 normalizer、训练数据、视觉域或者潜在动力学的正确性。
即使全部一致也不打开 P1；无需也禁止 CPU 神经推理。
