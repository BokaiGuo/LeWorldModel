# 实际链前缀：同预算尾部重优化开发对照

使用已封存共同尾部干预的全部 3 个已曝光任务和原、零、随机、greedy、
lookahead 五种前缀，不按物理成功筛选。每个前缀固定不变，以先前实际
派发的同一尾部作为共同初始尾部；它是评价端提供的合法动作见证，并
非可部署在线算法的免费信息。每臂独立优化其后的实际剩余动作长度，
超过原实际链长度的补零动作仅用于满足 25 步模型预测，不参与执行。

每臂使用相同预定随机流的 3 轮 CEM、每轮 16 条完整链评分、4 条
精英；每轮保留当前最佳已评分尾部并记录完整候选及分数。尾部随机扰动
仅在合法 `[-1,1]` 内，初始和最低标准差分别为 0.4 和 0.05；若原
尾部不足 20 步，剩余补零不参与优化。选择全程实际评分最低的完整
链，不使用真实环境结果。单臂 48 次，三个任务五臂共 720 次逻辑
完整链评分；前缀生成、选中和原始反馈开销另行说明，不当免费成本。

先封存全部候选和模型选择，再从相同初态物理执行五个选中链，按原
链实际长度上限、成功或截断停止。比较固定前缀条件，不把重优化后
的新链称为原算法已执行链。报告前缀内成功和尾部后成功；包含全部
失败。该小面板不预设胜出，lookahead 前缀来源见证为事后信息，结果
不是公平端到端规划对照，不能单独通过 PC2 或证明描述贡献。
