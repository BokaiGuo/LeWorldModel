# PushT 四根非特权动作后果开发诊断

按[运行前协议](PC_JEPA_MULTIR_ROOT_ACTION_EFFECT_DEV_PROTOCOL_20261105_CODEX.md)，四根各执行相同的 64 条预定随机动作链；目标来自独立 reset，不使用物理见证生成动作。四根、256 条均完成物理执行、模型预测和真实末帧编码，未运行规划器。每根先固定全部预测，再读取真实末帧；所有动作都已被模型查询。

| 根 | 精确物体姿态数 | 不同于零动作末态的位置数（1e-6） | 预测 latent MSE / 持久基线 MSE | 预测评分与真实编码评分同序 / 非并列对 | 真实编码评分与物体位置误差同序 / 非并列对 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 0 | 20 | 19 | 0.2233 / 0.5821 | 1431/1763 | 803/1026 |
| 1 | 64 | 63 | 0.4407 / 0.8079 | 1344/1994 | 975/1993 |
| 2 | 21 | 20 | 0.3134 / 0.5117 | 1330/1785 | 785/1070 |
| 3 | 12 | 11 | 0.1836 / 0.5041 | 1387/1740 | 349/638 |

这些是相关动作的逐根描述，不是独立动作对的统计检验。均值预测误差低于持久基线不保证动作排序可靠；根 1 和 3 的真实编码评分与物体位置误差在本动作库上接近半数同序，提示评分与物理目标的关系值得检查，但物体角度、agent 及遮挡同时变化，不可归因于某个单独因素。角度对照与并列数见[完整报告](../le-wm-main/results/pc_jepa_multiroot_action_effect_dev_20261105_codex/report.json)。

特别注意：根 2 的 64 条末态都不同于动作前的物体位置，但零动作自身也产生约 `0.00685` 的位置漂移；相对零动作末态只有 20 条超过 `1e-6`。根 1 零动作漂移约 `1.88144`，因此不能把“不同于动作前”直接解释为动作造成的变化。

[独立审计器](../le-wm-main/experiments/audit_pc_jepa_multiroot_action_effect_dev_20261105_codex.py)重新生成动作库、在同一物理后端逐条重放 256 条并检查图像及状态，并用独立循环重算排序与 MSE；[审计记录](../le-wm-main/results/pc_jepa_multiroot_action_effect_dev_20261105_codex/audit.json)通过。它未独立重跑神经网络，也不排除共享物理实现或语义错误。预测计 768 prediction tokens，未包含编码和全系统成本。

根、目标和动作种子是事前固定的开发配置，但开发外、normalizer 拟合外及 checkpoint 训练外仍为 unknown；目标未证明在 15 步可解。此结果不构成未查询动作预测、独立确认、规划优势或 PC0–PC5 通过证据。
