# Wall 响应程序与联合精修 E0 开发协议

在运行前固定。使用八个已暴露的精确 wall 开发任务、既有 16 步四参数动作模板及 1145/2169 全链 rollout 上限；不是独立确认，也不属于 RGB 模型。目标条件化谱方向、最大奇异值方向、无 SVD 岭响应、随机初始化和普通联合 CEM 五臂使用同一个 CEM 联合优化器及最终完整终距选择。禁止特权解析解或已知成功链进入生成与选择。

每任务同一固定种子生成四个四维名义动作向量，均匀分布于 [-.6,.6]。前三臂在每个名义动作处用正负有限差分（eps=.01）获得二维终点对四参数的响应矩阵，并额外计算名义端点，计 4×9=36 次完整 rollout。对残差 goal−endpoint：目标谱按原方案 q 排序选首模态及对应阻尼系数；最大奇异值选第一模态及对应系数；岭解使用相同阻尼 .001 的完整响应求解。所得更新按最大分量裁剪到 .5，并整体裁入动作域。随机臂与 flat 臂均使用相同四个名义向量，但前者为公平对应随机候选分别再以固定随机方向扰动，后者直接作为起点；不无意义计算响应。

对四个起点各做一次完整链评分，保存精修前最佳 incumbent。剩余预算均分四起点×四轮，余数依顺序分配；各起点 CEM 初始标准差 .5、精英为最佳八分之一至少两个、标准差下限 .02，所有方法按任务共享随机种子。每次全链预测都扣预算，各方法最终选择所有起点及其精修样本中终距最小链。记录 Jacobian、候选、动作、所有评分、SVD/求解次数、全链调用和耗时；不把梯度、SVD 次数与 rollout 数简单相加为总计算公平。

事后对实际选中链做共同后缀对照和即时进展核查，选中链不是机制见证即如实记录；不以机制资格改变选择。全部八任务每预算作为配对开发观察，两预算不是独立样本；该实验不证明 PC2/PC3、P1 或视觉部署。
