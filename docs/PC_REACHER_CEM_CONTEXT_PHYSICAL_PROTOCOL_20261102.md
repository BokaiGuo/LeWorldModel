# Physical replay of the complete development context-sensitivity panel

This follow-up is designed after the model-only results were opened. It
executes every saved pair, including identical and differing tails: two
previously exposed roots, prefixes 0 and 12, both fixed CEM budgets, three
fixed seeds, and predicted/observed contexts, for 48 fifteen-step branches.
Neither roots nor outcomes are independent. It is not a P1 admission test.

Each physical arm reuses the exact previously sealed five-step raw prefix,
then CPU-decodes its own stored ten-step CEM parameter tail using the bound
action statistics. The input plan binds both source journals and receipts,
the statistics and code. CPU versus CUDA tail decoding is not guaranteed
bitwise equivalent. Each arm restores the same root and goal; the executor
records an intent before and a return after every action, and retains stop,
error and incomplete trajectories without filling missing values.

The frozen comparisons are paired final physical joint distance (observed
context tail minus predicted context tail) for all 24 pairs, with initial and
cp5 distances, stop state, and actual action hashes. Both tails were computed
before this new replay using already archived contexts: this is not a new
online feedback controller experiment and no computation-cost advantage is
claimed. No fitting, training, new GPU inference, or outcome-selected arms.
Execution, source and simulator attestations remain separate from the
saved-file consistency verification.
