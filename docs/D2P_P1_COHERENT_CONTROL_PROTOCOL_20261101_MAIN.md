# P1 动作包一致方向候选：开发对照

本设计是在居中原H4四臂0/4成功后提出，明确属于自适应开发，
不是独立确认或预先独立的显著性检验。

假设：五步动作包内的逐步随机方向可能相消；低频、持续动作的候选
可能更容易搜索到接触及重配置。该假设不是已经确认的失败原因。

四臂全部运行同一个已知平移任务，不筛根。所有动作生成仍仅依赖
真实RGB latent、冻结模型、目标RGB和固定随机种子。

- structured：对原192×40 raw-action Jacobian按每包五步求和，
  得到192×(2H)的常量包动作响应；在同一目标Q中求原SVD/DLS，
  再将每包二维动作重复五步。这里必须求和，不是求平均。
- native/random/immediate_progress：初始高斯采样形状改为
  (count,4,1,2)，重复五步；种子、数量及筛选规则不变。
- structured反馈混合中的随机部分同样用常量包动作。
- 仅改初始化；六次full-action梯度更新、首包保护、后缀交换、
  旧计划尾部重评分、真实RGB反馈和停止规则保持不变。
- 仍计算原完整Jacobian，按原成本记账；不得宣称减少VJP计算。

四臂须全部报告，包括失败/删失和真实终态；不调学习率、数量或阈值。
报告原H4与此变体结果，但两者均来自已知开发根。
即使该变体成功，也不能直接宣称非贪心能力机制或独立泛化成立。
