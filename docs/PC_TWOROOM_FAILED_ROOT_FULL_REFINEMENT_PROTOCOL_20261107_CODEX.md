# TwoRoom 失败任务的完整精修候选物理重放协议

上一步 8 条模型最优代表在 4 个 lookahead 失败根均未成功后，固定选择这 4 根及原先封存的全部 `8 × 36` 条精修链：共 1,152 条，每条真实执行 25 步。逐链保留前缀编号、样本编号、原模型分数、动作指纹、逐步距离和成功；按既有正常环境几何、原数据初态及目标执行，即使中途成功仍完成 25 步。不能按模型分数筛链，也不能重新生成或优化动作。

每根报告完整 288 条精修链的成功数量与前缀分布；若有成功，再与原 lookahead 和描述臂的保留前缀、最终链评分逐条比较。每前缀先前的最优代表应与上一步封存结果逐步一致；否则终止分析。4 根均原 lookahead 失败，因此找到真实成功链只说明候选池存在物理可解动作，不说明规划器会选它。若未找到，结论只覆盖这 288 条，不包括初始 300 条、全局链、64 条交叉组合或所有可能动作，也不能否定参考链的可解性。

此事后物理真值仅供诊断，不能用于原方法决策或更改停止规则。候选来自已暴露开发任务，不是独立测试、完整规划成本或 gate 证据。
