# TwoRoom RGB 闭环剩余时域评分：开发结果

此前四臂闭环每次都对候选执行完整 25 步预测，即使任务离 25 步执行上限不足 25 步。按[开发协议](PC_TWOROOM_RGB_DEADLINE_SCORING_PROTOCOL_20261107_CODEX.md)，本次只改变评分时域：在每次真实反馈后，所有臂均评分到本任务剩余时域的末端；候选生成、旧尾、13 条链评分和真实停止规则保持一致。

| 规则 | 固定 25 步评分 | 剩余时域评分 | 剩余时域相对旧规则独胜／独负 |
| --- | ---: | ---: | ---: |
| 父链 | 23/40 | 27/40 | 4 / 0 |
| 普通 lookahead | 21/40 | 25/40 | 4 / 0 |
| 向量多样性 | 21/40 | 26/40 | 6 / 1 |
| 动作身份打乱 | 21/40 | 26/40 | 5 / 0 |

这是 40 个已曝光任务上的同根开发比较，且两种评分目标不同；不能将结果升级为独立收益或认定原 MPC 设计是实现 bug。第一轮剩余时域为 25 步，160 个臂／任务的首轮选链均与旧版本一致；之后真实状态和观察会随选择分叉。

剩余时域下向量臂相对 lookahead 独胜／独负为 **2／1**，且打乱臂同为 26/40；没有建立动作身份或描述组件的独立贡献。该实验也未将更高预算 CEM 以同一剩余时域重跑，因此不能与先前固定时域 CEM 公平比较。

## 核验、成本和限制

- 新适配器仅把实际剩余的 1–5 个动作包送入 RGB 模型。剩余时域与未来动作非干预、非法时钟及共享核心测试 **6 项通过**。
- 对全部 **160** 条轨迹和 **625** 次决策按保存评分重建选择，校验每次模型动作包数、RGB 与目标输入收据，再用相同环境执行 **2883** 步；物理距离最大差为零。审计没有用 GPU 重新计算这批候选分数。
- 四臂整面板的模型包转移分别为 6747、6630、6643、6682；评分次数分别为 2067、2002、2015、2041。相对于固定长时域，每条评分的模型计算并不等量，且尚无完整系统成本计时。
- 模型输入为 RGB、目标图和空动作历史；物理状态用于环境初始化与评价。数据源、任务及相机已曝光，环境 reset 类型与动作转换警告仍存在。PC0–PC5 未改判。
