# RGB 时钟修正版：GPU 闭环回归协议

目的：检查返回动作时域修正后，在真实冻结 LeWM、真实渲染及持续执行下，
已评分候选、选择和实际动作是否与历史运行一致。这不是性能实验。

固定四个已曝光 TwoRoom 开发 root：10、11、17、21。它们分别包含历史
提前终止和运行至 25 步的情况；四个原有策略全部运行，每个策略使用原
候选与策略随机种子、动作域、成功与停止规则和每次评分次数。总计 16 条
闭环轨迹，每次最多五次重规划。规划输入仅为当前 RGB、目标 RGB 和
声明为空的动作历史，环境真值只用于初始化和执行结果评价。

修正版必须返回严格等于剩余步数的动作；旧尾只能来自该动作的未执行
部分。运行时不读取历史轨迹用于选择；全部轨迹结束后，按同 root、策略
及轮次对比历史记录：实际动作、选择来源及索引、模型输入／候选收据、
各候选分数、物理距离和终止状态。数值分数容差 `rtol=1e-5, atol=1e-4`，
距离容差 `atol=1e-5`；逐字节相同单独记录。模型不变、动作合法和时钟
断言失败即停止，不覆盖任何既有结果。

输出各轮原始动作、评分、收据、执行轨迹、来源哈希和逐项比较；无论
通过或不通过均如实报告。此面板及方法已经曝光，不能作为独立确认、
RGB 方法收益或任何 gate 通过证据。
