# Dev305：第三反馈边界风险误判分解

## 对照

对已保存的第三边界六条物理分支，使用同一冻结模型在主机 CUDA 编码真实第 5 步 RGB；将真实目标编码差与原五步模型预测分别输入**同一个**局部 RGB 切线投影器。真实终帧只用于事后诊断，不进入规划器。输入动作、终帧哈希、预测、投影及环境轨迹均从既有合同复核。编码器和 projector 各调用 7 次（六帧加目标），模型权重前后不变。

## 关键反例

`zero__risk_selected` 的 `toward_02`：

| 物体左边界 | 结果 |
| --- | ---: |
| 模型预测 latent 经投影 | 9.34 像素 |
| **真实终帧 RGB 编码**经同一投影 | 10.71 像素 |
| 真实终帧颜色框 | 6 像素 |

原 guard 要求边界至少 8 像素，因此前两者都预测可见，而真实终帧不可见。真实与预测 latent 的均方差为 0.02209；但更换成真实 latent 后仍误判，说明在这个实例中，预测误差**不是 false-safe 的唯一必要解释**。当前局部线性投影忽略旋转、形状变化及大位移非线性，编码本身亦可能有信息损失；该对照无法单独区分这些因素，也没有证明坐标或动作绑定存在新错误。

另两条所选分支是 zero 并分别重复执行，两对重复不能视为四个独立样本。此结果只覆盖一个开发根，不应据此调整 margin 后宣称校准或安全。真实 RGB 提升的是事后信息，不能接入事前选择器；下一步需要有可审计覆盖的风险模型／策略与新物理对照，同时继续推进谱程序和任务指标。
