# 有界双分支：条件化响应与普通 lookahead 配对开发协议

目标是比较同样分支表达、动作域、每轮评分数和调用分批下，利用
各分支尾部有限差分响应构造两个组合，是否比将同等额度留给
普通随机完整链更好。这是开发实验，不预设响应有效。

固定已有 50 个 task seed 42 任务、物理 reset seed 771001；
solver seed 42、1042、2042 独立覆盖。模型、目标、实际时钟与
有界动作合同同 `PC_BOUNDED_BRANCH_STRUCTURE_DEV_PROTOCOL`。
均采用原 300×10 双分支初始化及独立更新，每计划 3000 次完整链
评分。第一轮完全一致；后九轮各分支 150 条（最后一轮 149 条）：
其中四条为当前分支完整链基础上的两条共同尾部方向的正负探针，
两条为被替换槽位；其他为普通随机链。先同批评分普通链及
四条探针，再评分每分支最后两个槽位。普通 lookahead 臂最后
两个槽位使用原生成的随机链；条件化臂以探针正负代价差各自
确定两个方向符号，然后形成归一化的和、差。两臂都执行同数
完整探针和两批模型调用；不附加免费的 response 查询。
各分支内部由各自 elite 更新完整链均值／方差；不同分支不混合。
收尾共同评分两个均值，选择较低分链；仅针对该选择作实际执行。

随机种子独立于任务种子；相同步数及探针数不意味着分叉后
两臂仍有相同候选池。首次迭代须核验相同采样、探针与成本；
执行动作必须在模型评分前受同一物理域约束，计划每个候选
数量及首次链动作须留痕。记录每次计划的完整评分数、查询批次、
真实执行和物理快照。每任务 episode 属于开发集，不作 PC3
独立确认；主指标环境成功，模型分数与缓存时间不得替代。
结果如无增量，应先排查探针是否真的改变候选和实际选链，再
报告该配置的证据边界，不以失败推断一般理论不成立。
