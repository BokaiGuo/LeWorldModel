# 固定同 cp10 双动作的预测—真实对照

对两个已知根，每根固定已执行的开放与反馈两条后缀；两臂前十步
动作、RGB 和物理状态已经逐帧验收。统一从真实 cp10 RGB 和同一
动作历史出发，对两条已执行的最后五步分别预测终态，用冻结 encoder
编码对应真实 cp15 RGB；保存完整预测和实际向量、动作哈希及原生
物理终点。反馈动作的模型目标距离须复现原选中候选分数。

逐根分别比较模型预测目标距离排序、真实 RGB latent 目标距离排序、
物体位置／角度、推杆及原生成功，不将 native7 中速度变化当成物体
进展。必须执行全部四个预定动作，不根据物理结果挑选。此次只复用
已封存动作及图像，不重新规划或执行；是开发根事后归因，不是公平
基线、独立验证，也不得直接宣称 P1 机制成立。
