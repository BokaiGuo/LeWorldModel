# P1 四候选：同一五步时刻的排序失配

固定绑定之前主机 CUDA 的 96 条五步预测、对应真实 RGB 编码和
最近逐步 RGB 结果。逐候选核对角色、索引、停止状态、五步 PNG
像素哈希、真实目标分数及原始终点评分。每个前缀的四候选形成
六对，共 24 × 6 = 144 对；事后固定数值平局容差为 `1e-6`。

| 五步预测与五步真实 RGB 目标距离排序 | 对数 |

| 一致 | 111 |

因此即使不比较第 7/8 步真实结果与第 10 步预测，在这个面板中
仍有同一时间点的预测—真实编码排序反转。144 对共享两个已知根、
候选和轨迹，不是独立样本，不能估计泛化错误率；这种现象仍可能
包括尚未认证的训练 normalizer 或共享上下文接线问题，不能仅据此
断言理论失败或排除代码问题。

开放第十步目标 MSE 换成五步预测目标 MSE，分别沿用原物理结果：
