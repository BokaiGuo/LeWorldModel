# PC1：RGB 多方向后继候选的十步响应诊断

在物理后继结果读取前固定。使用四个暴露 PointMaze 开发根的首轮
多方向 RGB 计划：两个已保留五步父候选分别对应的完整后继候选库。
不重跑规划器、重选父候选或将物理状态输入规划。后续 10/5 步反馈没有
两层后继搜索，不计入本实验。

每个父分支读取后五步名义动作、后继 `2×10` 模型 Jacobian、模型
名义中心、整个后继库和十步候选评分；从封存预测 trace 核对完整
父前缀加后继动作、名义中心、候选输出和评分。计算后继动作相对名义
的模型预测位移、模型 Jacobian 线性位移和物理位移。物理分支采用
原后端，依次执行相同热身、同一父动作及后继候选；名义与每个候选
均单独从根重放。每个父动作对应的热身及父动作轨迹必须与上一轮
首候选物理审计逐位一致；它是事后固定动作回放，不是真实反馈选择。

分别报告谱候选和 zero 的模型线性误差、模型相对物理位移误差、方向
余弦、相对名义评分差与物理目标距离差的排序；范数 `≤1e-8` 时不用
相对误差和余弦。每个父分支另报告模型最佳后继的物理排名、物理最佳
是否在当时“最佳加最远”留存集合、两者绝对终距及分数；平局按原候选
顺序处理。各组依附四个开发根，不是独立样本；选择模型所用目标评分
与物理目标距离仅比较排序。名义和候选模型动作采用 float32，而物理
执行保留原始浮点，记录舍入上界。

不将候选筛选的物理反事实当作已执行轨迹、PC2 程序发现或 PC3 优势。
它仅检查特定冻结模型、实际候选、十步路径和暴露根；不自动证明任何
gate 通过或误差由代码造成。输出绑定已封存决策、上一轮物理诊断、
原后端及协议哈希，排他创建。
