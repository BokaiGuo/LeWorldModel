# dev305 冻结模型选择 RGB 接触候选

对同一已知开发根的三个真实反馈点，分别从 RGB 几何构造四个固定
五步动作包：朝物体 0.2、反向 0.2、零动作、朝物体 0.5。使用该点
三帧真实 RGB、实际动作历史及原始目标图，在冻结模型中预测一包后
的 latent，以目标 latent MSE 最小值选动作。选择器不读取物理状态；
目标图仍未通过原边界可见性筛查，故这是事后开发实验。

三个状态的模型都选中朝物体 0.5。封存选择后，从各自精确重放的
状态执行全部 12 条候选，而非只执行选中项。每条执行满五步、均未
原生成功。选中项与零动作比较如下：

| 前缀 | 选中项：物体位置 / 角度误差 | 零动作：物体位置 / 角度误差 | 选中项 / 零奖励 |
| --- | --- | --- | --- |
| candidate_02 | 216.15 / 0.162 | 249.46 / 0.439 | -501.83 / -499.24 |
| candidate_00 | 248.53 / 0.037 | 249.48 / 0.419 | -571.31 / -501.64 |
| zero | 219.97 / 0.237 | 251.81 / 0.561 | -480.51 / -487.86 |

三个选中动作的终帧都未通过既有可见性 guard，三个零动作终帧均
通过；本次是固定五步实验，未在中途失效时提前停止。模型选择在本
单根上使物体位置和角度误差小于零动作，但前两项原生奖励更差，
也无法继续以合格 RGB 可靠闭环。不能把物体进展等同任务成功或
P1 能力机制，亦不能把有缺陷的目标图用于正式部署。

模型计数：编码器、投影器各 10 次；预测器和动作编码器各 3 次、
12 个样本。结果保存预测差向量，物理验证复核模型 argmin、动作、
72 帧哈希和原生停止状态；测试 5 项通过。全部都是同根开发结果，
不是事先独立测试，也未认证完整预算或强基线。
