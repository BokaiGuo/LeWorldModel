# P1 两包目标的同动作物理一致性诊断

对刚完成的固定 24 槽逐一重放各自选定的动作包，不按结果挑选。
绑定物理准备文件、完整运行报告、逐槽保存态消费、动作字节、
cp5 RGB 与对应第 5/10 步图像和物理状态。所有槽必须完整执行
十步，任何缺失或身份不符拒绝本轮；不重置或重新执行物理。

在冻结 checkpoint 上，主机 CUDA 重新编码 cp5、真实第 5 和第
10 步 RGB，并从 cp5 对同一动作做开放两包预测。核对两个预测
目标距离及其均值与规划保存值，记录预测、真实及目标 latent，
便于独立重算；物理位置、角度、推杆、成功只作离线评价，不输入
规划器。该诊断在观察结果后提出，不能用于独立确认或选择历史
候选，不把已知根或相同轨迹当独立样本。
