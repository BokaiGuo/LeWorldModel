# A/B 尾部前缀保留：事后物理核查

原模型侧开发结果已公开；本核查不是事前盲分析。重运行相同固定
种子的 A/B 构造和每前缀等机会优化，保存每个前缀 B 最佳链及
优化期间模型分数最优链；核对对应分数和保留集合与已保存结果
完全一致后才进行物理重放。重运行的模型调用是诊断成本，不声称
算法没有额外花费。

每条链都从数据目标对应的原始 reset 重放真实第一段 25 步，逐步
检查物理快照，再执行待评估的 25 步合法动作，记录首次成功。
对每任务及父链、probe-min、probe-mean、打乱身份排序，统计其事前
按模型／A 信息选出的 4 个前缀中，B 最佳链及独立优化最佳链
各有多少真实成功。物理标签仅用于事后评估，不回流排序或规划。
同时报告全体 12 前缀作为覆盖参考；此面板无法证实任意描述的
总体物理预测性、独立确认或完整成本优势。
