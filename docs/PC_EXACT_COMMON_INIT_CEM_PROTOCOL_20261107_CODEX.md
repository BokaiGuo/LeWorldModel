# 精确墙障共同初始化与完整链精修：事前开发协议

问题：上轮四维原语 CEM 的成功率低，是否仅仅因为全局初始化没有覆盖几何桥接程序的低维候选集合？比较共享前 128 条目标相对单中间点候选后，剩余 256 次评分用于四维原语 CEM，还是继续采样目标相对中间点。此实验改变的是后续搜索调度，不检验响应描述。

沿用 24 个已暴露 exact-wall 开发根、15 步动作、精确起点／朝向／目标与同一物理后端。每根偏移随机流 `2718000 + root` 产生 384 个 `[-1.9,1.9]` 均匀偏移；几何分支评分全部 384 个，新臂共享前 128 个并将它们转换为等价的两段转向／直行四参数。较先前 `[-2,2]` 范围略收窄，确保各段距离均不超过四维原语参数上限。转换后动作必须与共享候选一致，否则停止。两臂共用前缀不意味着新臂免费获得其评分：各臂均计 384 次完整链评分。

用共享前 128 条的最低代价 16 条初始化四维 CEM；另用随机流 `2719000 + root` 运行四轮、每轮 64 条，更新前 16 条，逐坐标标准差下限 0.08、裁剪到 [-1,1]。最终选择各臂所有已评分链中最低目标末距，包含共享 incumbent，平局取首项。没有墙坐标、真实成功标签、解析见证或实际未来真值参与生成；精确动力学用于统一模型评分。记录完整动作、候选来源、代价、种子和用时。

事前判定：联合精修仅在最终严格成功数至少高 3 根且几何臂独胜不超过 1 根时作为进一步开发候选；若相反则不扩大此固定 CEM 配置。另报告配对独胜、初始共享池成功、均值终距与精修替换数。任何结果不改变历史负结果，不声明充分调优强基线、视觉或完整成本优势。审计应独立重建随机偏移、候选转换及 CEM 更新，重放所有动作并检查选择、初始机会及预算；同一后端重放不代表独立物理引擎认证。
