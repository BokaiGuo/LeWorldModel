# Wall E0 负结果的接线与覆盖事后审计

本审计按独立诊断协议，固定此前八个已暴露任务及原始结果，不改旧规划选择。解析动作见证只用于注入测试，没有进入规划器。

- **动作模板及评分：**八个已知可行完整链均能无损反解并重新编码，同一精确 rollout 的终距与原记录一致；在每任务两预算的 16 次注入排序中，见证均被选为最低终距。结论限于该固定动作评分和选择检查，不证明其能被搜索到。
- **导数接线：**192 个已封存名义响应矩阵按原 `0.01` 步长重新计算，全部逐项一致；未发现零 Jacobian。36/192 名义链发生碰撞（存在重复根与预算，不能视作独立样本）。
- **非光滑与尺度：**相对 `0.01` 矩阵，改用 `0.001` 时 18/192 的矩阵相对差超过 0.1，改用 `0.05` 时为 36/192；绝对矩阵差的中位数／最大值分别为 0.00041／11.91 和 0.01226／7.00。尺度差异提示局部有限差分不稳定，不足以单独判定具体物理碰撞事件是唯一原因。
- **候选覆盖：**192 个名义—响应候选配对中，180 个候选改善自身名义终距、12 个变差，但没有候选达到 0.05 成功阈值。此前完整搜索也未成功；有限差分改善局部终距并不保证生成绕墙程序。
