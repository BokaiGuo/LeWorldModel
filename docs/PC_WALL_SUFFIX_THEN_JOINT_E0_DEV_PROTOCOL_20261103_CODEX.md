# 先后缀再联合的预算分配：开发协议

在已暴露任务和先前负结果后固定，仅为优化器开发。使用前一固定/联合对照的八个相同起点、相同全链 rollout 预算、相同种子和预算分配。每起点第一轮固定前缀，只优化后缀；第二轮从第一轮精英均值开始联合精修，前缀标准差固定为 0.1，后缀标准差沿用精英估计（下限 0.02）。整个过程中保留已评价的最佳完整链，包括第一轮最佳动作。先前固定两轮及联合两轮两个同预算控制从已封存结果读取，不重新选择。

保存实际所有样本、分数、选中动作和成本；比较八根配对距离与成功数。该测试单独改变预算分配及前缀扰动尺度，不能区分两项各自作用，不能称精确模型手工前缀为完整 Planning Compiler，也不构成独立确认或等总硬件成本。
