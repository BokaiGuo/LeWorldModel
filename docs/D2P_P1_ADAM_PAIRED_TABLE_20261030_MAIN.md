# P1 三前缀、共同后缀与 Adam 独立后缀配对

本表将既有 24 前缀 × 42 共同后缀与同前缀独立 Adam 规划、
实际物理执行连接，不产生新的 CUDA 或物理实验。CSV 有 1,008 行；
每个前缀的 Adam 结果在 42 个共同后缀行中重复展示，不能视为
42 次独立执行。根、条件、逻辑槽、任务、前缀动作和后缀哈希均保留；
相同动作哈希及共享根不是独立样本。

前缀前后物体位置、角度、推杆、联合位置及成功分栏；差值是前缀减初始，
负值表示误差降低。共同后缀有绝对终态和相对自身零后缀的变化；
Adam 有自己的绝对终态、相对自身零后缀和同逻辑槽 zero 前缀独立
Adam 的差值。共同后缀的效果不能单独证明可规划能力。原生成功是
布尔判据，联合位置距离不是完整成功判据。

原合同下 `native_stopped` 的十步终点仍为空，即便第十步停止；
`adam_last_native_success` 和步数另报已观测成功，不补造固定终点，
因此涉及删失端点的差值也为空。共同后缀的状态和删失字段分别保留。
完整 JSON 还保留共同后缀响应和之前优化器、反馈数据。

示例：根 0/on 的两个 selected 槽前缀物体位置和角度误差变化均为 0，
推杆误差变化约 -1.00；这不是整个任务没有进展的证明。两槽各自
Adam 后缀均未成功，物体终误差约 36.10、60.95；对应 zero 槽一条
第十步原生成功、一条未成功。已知根、重复前缀和事后优化器选择
使这些结果只能用于探索，不能认定 P1 通过或估计独立成功率。

Adam 各行相同的四起点、20 次更新为后缀局部控制，不等于包含前缀
结构计算的公平总预算。CSV 的预测与反向调用为代码路径计数，并非
完整独立 hook；不同调用轴没有相加或强制填满。编码、前缀、结构、
筛选、真实反馈及总耗时仍需共同预算合同和完整计量后才能认证。

连接器校验原始文件 SHA、24 行、前缀与目标身份、动作哈希和停止合同。
四项测试检查完整分母、停止删失及前缀/动作/身份篡改拒绝；不构成
神经模型重算或独立数据来源认证。
