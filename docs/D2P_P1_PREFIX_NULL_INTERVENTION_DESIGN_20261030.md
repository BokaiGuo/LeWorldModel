# P1 非零重配置前缀的无动作对照：待实现设计

## 问题与边界

已知成功实例（root 0 / on，两个相同动作的重复臂）中，selected 的五步前缀只有第一步非零，其后四步 raw 动作为零；物体在前五步没有移动。对应 incumbent 在第 4 步已推动物体，其第 15 步物体结果比 selected 差。该现象与“重配置改变未来能力”相容，也与“延迟或减弱推力避免过冲”等替代解释相容；仅凭现有记录不能区分。

下述设计是在看到历史 outcome 后提出的已知根探索，**尚未构成可运行协议、独立验证、P1 通过或等预算规划比较**。不得仅选择成功实例进行执行或把重复逻辑臂计为独立任务。

## 固定候选干预

沿用已封存的全部 8 个 root/condition/arm selected 计划，以同一真实根、同一目标、同一 warmup 和同一后十步 raw 动作为基础，逐计划比较：

1. `selected_prefix`：原计划第 1–5 步动作，随后原 selected 第 6–15 步；
2. `zero_prefix`：第 1–5 步固定为五个 raw 零动作，随后使用与 `selected_prefix` **逐字节相同**的原 selected 第 6–15 步。

两个角色都执行全部 8 个逻辑计划，固定分母 16 条；根据计划字节和任务身份标记重复，不能把相同动作及根条件作为独立任务。零动作不意味着环境静止：warmup 遗留速度和环境动力学可能导致移动，必须记录实际状态与速度。既有成功轨迹只作为先验来源，不能用其替代本对照的新执行。

固定逐步记录 raw 请求和实际动作、RGB、可见物理状态、速度、原生终止及成功。第 0、5、10、15 步分别报告物体位置误差、环形角度误差、推杆位置和速度；保留完整逐步轨迹。独立复核状态与动作来源。画布外或原生提前终止按执行前固定的合同保留分母与删失原因，绝不填补缺失或放宽 RGB 守卫。若任何路径的有效性无法证明，应保留失败而不是改称科学负结果。

## 可回答与不可回答

该配对仅改变前五步的动作，因此若在同后缀和有效执行下得到不同真实结果，可支持“这五步干预对该具体轨迹有作用”；仍须检查起点速度、物体/推杆几何和接触过程，不能直接推断效果来自可控性提升。若结果相近，仅说明这一具体无动作对照没有区分该历史实例，不能证明所有前缀无作用。该对照也不能排除后缀参数差异、动作时域或基线搜索预算造成的优势。

为支持 P1 机制，还需固定共同能力探针并比较干预后可执行动作响应、真实任务收益及非贪心条件，再于认证训练来源和历史排重的独立根上对强基线做等预算验证。
