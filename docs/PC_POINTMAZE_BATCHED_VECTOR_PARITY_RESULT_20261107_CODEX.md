# PointMaze 双前缀批处理决策核验结果

在三个已曝光 state-assisted 任务、四种保留规则共 12 个条件下，
逐条与批处理路径均为每臂 19 次逻辑候选评分。最大分数绝对差为
**5.96e-6**；保留前缀、最终候选身份和动作分别为 **12/12 一致**，
满足本面板预定 `1e-5` 与决策一致条件。

这不是所有规则都退化为相同保留：任务 1885 的 parent、lookahead、
vector 分别保留 `[1,2]`、`[0,2]`、`[0,1]`；任务 1886 的 vector
与行内身份打乱分别保留 `[2,0]` 和 `[2,1]`。但同一任务的四规则
最终均选择相同动作，本次没有建立保留策略的独立行动收益。

预测使用冻结 JEPA 和完整当前及目标 proprio；模型权重指纹前后
一致。该核验仅覆盖小型、已曝光候选池，不能保证近并列情况下的
决策一致，也没有执行新物理实验。行内身份打乱不等于跨 root 的
描述打乱。结果不构成 RGB-only 证据或任何 gate 通过依据。

`le-wm-main/results/pc_pointmaze_batched_vector_parity_20261107_codex.json`；
协议见 `PC_POINTMAZE_BATCHED_VECTOR_PARITY_PROTOCOL_20261107_CODEX.md`。
