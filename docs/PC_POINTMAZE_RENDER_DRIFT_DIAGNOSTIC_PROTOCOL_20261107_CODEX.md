# PointMaze 历史帧与重渲染帧：编码及选择敏感性诊断

此前新增 ±0.03 真实后继图像的逐步重放状态匹配，但 ±0.1 视觉编码未通过旧特征 `1e-5` 等价检查。本诊断不放宽容差，也不继续把新帧与旧预测视为已认证同分布。

在四个已曝光根、两个视角及 ±0.1 同一实际动作上，使用相同冻结模型重编码历史后继图像和物理状态一致的 v2 重渲染后继图像。分别与相同的历史目标编码比较，检查历史重编码对封存真实编码的最大差、两版图像像素差、两版编码均方差、目标分数及其两动作选择；物理目标距离只用于评价。目标和模型保持不变，重渲染及其评估不进入任何规划动作选择。

两视角和两动作不是独立任务；本诊断不规定额外阈值、不事后改判旧实验，也不称新的渲染路径与历史路径等价。若能重现历史特征但重渲染偏差存在，只能定位到输入或渲染路径差异，不足以确定图形驱动、渲染参数或某一行代码是根因。模型与两版图像的具体哈希及物理轨迹身份均记录。
