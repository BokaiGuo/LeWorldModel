# P1 动力学多样候选与共同后缀的固定面板连接

在已观察旧结果后，将现有 8 臂 × 20 候选的任务响应多样性选择，
与每个候选均采用同一回溯优化器的已保存后缀连接。每臂选择此前
确定的四个候选，然后仅在这四个候选内依据回溯正则终态分数选最小，
平局按原索引。全部八臂保留；报告所选动作、模型阶段变化、完整
两包动作和相对于全集选优及原候选 0 的模型差值。

这是事后开发分析：之前完整 20 候选已经计算，不能把它称为只花
四候选预算的实测，也不能用已知物理 outcome 选动作。结果仅用于
判断这个实际动力学筛选是否产生新候选、是否值得固定新 CUDA 及
物理执行合同；没有真实能力或公平预算结论，也不打开 P1。
