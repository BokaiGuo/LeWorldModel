# State-assisted 局部外推失败：精度与尺度分解

本结果按 `PC_STATE_EFFECT_PRECISION_CAUSE_PROTOCOL_20261106_CODEX.md` 对已暴露的4个 PointMaze 任务、两个相机做事后工程诊断，不是独立验证或新方法的注册试验。

## 执行与复核

使用实际 CUDA、冻结 JEPA 兼容模型和相同的 FP32 输入编码，分别用 FP32/FP64 预测器扫描7种动作步长。FP32 的零动作及 ±0.003 代价在8个条件均复现上一轮；FP64 计算结束后将预测器还原 FP32，整个模型参数指纹与运行前一致。

共272次预测、48次动作反向求导，计算阶段同步墙钟5.44秒，不含加载和全部任务成本。所有8个条件中，FP32 与 FP64 在零点动作梯度的最大绝对差为 `4.18e-7`。独立重算保存的差分、曲率与二阶外推误差；相关权限及数学测试 **30 passed**。

## 主要结果

| 条件 | FP32 | FP64 |
|---|---:|---:|
| 8条件平均未查询幅度二阶外推 MAE | 0.00607923 | 0.00607965 |
| 1882/camera0 外推 MAE | 0.03769478 | 0.03768838 |
| 1882/camera0、步长0.003二阶差分 | 15.06011 | 15.05776 |
| 1882/camera0、步长0.1二阶差分 | 0.949395 | 0.949395 |

在异常条件上，零点两侧 ±0.001 的 FP64 梯度分别为 0.199442 和 0.227982；不同动作尺度的响应变化是真实存在于该模型计算路径中的，而非仅由二阶差分的 FP32 精度损失造成。

更小步长仍可能放大数值误差：异常条件在0.0001步长的二阶差分，FP32 为14.90、FP64 为11.90。因此“精度无影响”也不成立；结论仅是它不能解释0.003步长处的主要失败。

## 研究决策

保留上一轮二阶配置未达到预定准入标准的结论；不以切换精度或重选步长追溯改判。响应具有明显的**模型内局部尺度依赖**，不证明真实物理世界具有同样曲率或失效边界。先前物理选择与相机敏感性问题仍未解决。

不把此结果用于放宽 RGB-only 权限，不把 State-assisted 诊断升级为正式 PC1–PC5 通过。下一阶段若评估完整有限动作后果向量的保留价值，应固定动作库和共同优化机会，与普通 lookahead、身份打乱及无描述结构对照；不能把二阶配置改名后直接接入搜索。
