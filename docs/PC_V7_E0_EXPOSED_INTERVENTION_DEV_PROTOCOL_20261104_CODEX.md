直接调用既有确定性干预计算实现，但将每根计算结果与原始已审计 v5 干预产物逐项比较、将所有新生成动作和预测数组与旧数组逐项比较，并把每根 v7 输入链和输出绑定到新记录。即使结果相同，也将其描述为新版本在已暴露根的重算，而非独立复现；如有任何差异记录并停止，不拼合结果。该诊断不提供强基线优势或视觉控制结论。
