# 低调用方向：探针与编辑归因结果

按照[事前协议](PC_CHEAP_DIRECTION_PROBE_ABLATION_DEV_PROTOCOL_20261105_CODEX.md)，在已暴露 16 根、两随机流下对六条共同探针做去除编辑消融。probe-only 不生成 12 条方向编辑，所有探针依然计入 incumbent；固定机会使用相同 84 次 CEM 评分，等 token 则将省下的 12 次评分交给 CEM。

| 比较 | 方法 | 平均最终终距 ↓ | 成功 / 32 | tokens |
|---|---|---:|---:|---:|
| 固定精修机会 | 仅探针 | 0.34621 | 4 | 273 |
| 固定精修机会 | 探针＋方向编辑 | 0.36034 | 1 | 309 |
| 等 token | 仅探针 | 0.33194 | 7 | 471 |
| 等 token | 探针＋方向编辑 | 0.33178 | 7 | 471 |

固定机会下，方向编辑按根平均两个随机流后为 0 根更好、7 根更差、9 根相同；编辑产生的新起点会改变后续 CEM 随机样本，因此即使多了已评分候选，最终质量也不保证逐次提高。等 token 时方向编辑为 4 根更好、3 根更差、9 根相同，平均差 `-0.00016`，成功次数相同。**本开发面板没有显示明确的方向编辑增量；此前低调用臂的有限结果不能归因于方向外推。** 两种固定机会方法的总 token 不同；两种等 token 方法的 CEM 机会不同，不应将两行比较混为一种因果效应。

[原始结果](../le-wm-main/results/pc_cheap_probe_ablation_dev_20261105_codex/summary.json)保留 64 次运行和逐调用动作。[审计](../le-wm-main/results/pc_cheap_probe_ablation_dev_20261105_codex/audit.json)逐次验证六条探针与原低调用臂一致、重放预测、预算、已评分最佳链及返回动作。重放使用相同动力学实现，不是独立实现验证。相关三项测试通过。

这是事后根据开发结果设计的消融，任务、父链和随机流均已暴露，不证明随机方向在其他条件下无效，也不认证 PC0–PC5 或完整系统成本。合理的下一步是停止将这一特定方向编辑作为当前增量主张，保留探针效果作为待独立验证的普通搜索候选，并针对预定的跨片段组合或视觉评分假设另行开发。
