# RGB 梯度规划进程分离回归协议

目的仅为修复旧梯度开发运行器把含物理标签的历史文件读入选链进程的问题，
并核验拆分后是否复现既有计算；不作为新方法或确认实验。

1. 评价准备进程核验旧谱计划、物理记录和本地数据，按其四个已曝光
   episode 重新渲染真实初始 RGB。仅输出 `episodes/current/goal/nominal/
   action_mean/action_scale` 六个公开数组。动作 normalizer 与旧路径
   采用相同动作列拟合；不向规划进程提供物理状态、成功、距离或未来后果。
2. 独立规划进程仅加载上述公开数组、冻结 RGB checkpoint 与代码，复现
   梯度和五候选评分，封存模型计划；不得打开原始数据集、旧计划或旧物理
   记录。通过系统调用跟踪检查实际文件读取；跟踪不是安全沙箱。
3. 独立评价进程在计划封存后，使用物理数据重置并逐候选执行，输出
   轨迹；然后与旧运行按 episode 比较候选、分数、选择及真实轨迹。
   原纪录不覆盖。若跟踪不可用或权限检查无法确认，必须报告限制。

旧任务、名义链及方法均已曝光，属于开放环工程回归；即使完全一致，
也不证明独立泛化、行动后果描述增量、闭环收益或任一 gate 通过。
