# Planning Compiler：固定 reset 开发执行状态

本次仅在当前工作区增量开发和评价，不改历史记录、PC0–PC5 的合同
或已登记结论。研究问题仍为冻结模型中的行动后果信息是否可信，
以及能否被规划器有效利用；谱不是预设必要条件。

## 新证据

1. 原生 PushT 的本地评测数据没有 reset seed；无种子初始化同一
   任务的两次物理隐藏状态在 18/50 任务不同，零动作轨迹也不同。
   同一显式 seed 的正对照 50/50 一致。见
   `PC_PUSHT_RESET_HIDDEN_STATE_AUDIT_RESULT_20261105_CODEX.md`。
2. 固定 reset 的 50 任务中，原生、内部响应、匹配随机分别
   47、42、43 成功；共同评分选择与原生均值／样本最优另行比较。
   仅开发结果，不是完整成本或独立确认。见
   `PC_PUSHT_SEEDED_RESET_CONTROL_DEV_RESULT_20261105_CODEX.md`。
3. 首次候选的物理重放先通过 50/50、1199 步的精确一致性。
   共同合法的 49 对中，均值／样本／模型共同评分的首次 25 步
   成功为 36／34／35；另一个样本成功使用越界动作。见
   `PC_PUSHT_SEEDED_TRACE_COUNTERFACTUAL_DEV_RESULT_20261105_CODEX.md`。
4. 条件化尾部对比共享尾部及原生 CEM，在三个开发 seed 未产生
   稳定增量；相同评分次数不意味着完整成本一致。见
   `PC_NATIVE_PREFIX_CONDITIONAL_DEV_RESULT_20261105_CODEX.md`。
5. 条件化和原生各有 14 条首次计划满足宽松的非即时进展／删改
   初筛，13 个任务重合；接触审计发现条件化臂其中 2 条全程不接触
   物块且初始物块已在或接近目标，因此不能直接登记为物体重配置
   见证。见 `PC_PREFIX_SELECTED_CHAIN_INTERVENTION_DEV_RESULT_20261105_CODEX.md`
   和 `PC_PREFIX_CONTACT_AUDIT_DEV_RESULT_20261105_CODEX.md`。

## 不得提前宣称

- 固定 reset 修复了本地重置随机性，但并未完成权威上游等价、数据
  与 checkpoint 来源、所有动作域、任务精确重放认证；PC0 未通过。
- 局部探针或接触日志不证明 held-out 动作预测性及 PC1。
- 首次计划干预不证明组件发现贡献、最终闭环链机制或 PC2。
- 无稳定独立性能／完整成本优势，PC3 未通过；PC4 跨状态反馈与
  PC5 未见任务、checkpoint、架构的确认均未闭环。
- 训练任何读出或 adapter 另归训练主线，不能借用冻结模型成绩。
