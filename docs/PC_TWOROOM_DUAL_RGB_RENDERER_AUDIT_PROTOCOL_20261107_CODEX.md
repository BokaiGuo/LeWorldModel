# 双 RGB 合成图像的评价端渲染核对

双 RGB 重建完成后，对全部通过重建检查的任务，用本地 TwoRoom 默认环境恢复已封存目标位置，并以目标位置分别平移 `(+4,0)、(-4,0)、(0,+4)、(0,-4)` 像素渲染红色对象；记录合成图与相应渲染图的逐通道最大差、整图平均绝对误差、不同像素数和不同像素上的平均绝对误差。若原始目标图与相同状态的本地原始渲染相比存在差异，也记录其数值，不强求逐位一致。

该核对可使用 HDF5 的物理坐标和环境渲染器，但只能在图像构造完成后作为评价标签，不得输入 RGB-only 算法；平移后图像不一定是合法或可达的环境状态。先前 9 根弃权保留，不为了产生成功图像去读取隐藏坐标。此评估检查图像合成的特定环境像素近似，不等价于预测后继正确、行为收益或跨外观泛化。
