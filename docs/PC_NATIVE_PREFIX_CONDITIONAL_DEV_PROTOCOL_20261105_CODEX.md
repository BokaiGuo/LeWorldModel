# 前缀条件化尾部候选：开发原型协议

2026-11-05，运行前。该原型只测试响应是否随前缀条件而改变尾部
候选，不能单独声称 PC2 或真正发现必要的重配置。

使用显式物理 reset 受控协议、冻结原生模型及其全链评分接口。
每轮前两 packet 作为前缀、后三 packet 为尾部：从当前均值与一条
普通随机候选取得两个前缀；两者共享相同名义尾部和两条随机尾部
方向。按每个前缀分别查询四条正负尾部扰动（共八条全链），由
正负代价差决定该前缀尾部方向的符号，再对每个前缀各生成两条
组合尾部（共四条全链），与其余 288 个普通 CEM 候选一起按模型
评分、做相同 top-30 更新。首轮不注入，最后返回均值。每迭代
300 条完整链评分。全链预测包含对应前缀的后继，且不接收物理真值。

匹配对照用完全相同的两个前缀、方向、八次探针及四次组合评分，
但对第二前缀复用第一前缀得到的符号；比较条件化是否真正提供
增量。另比较原生 CEM、内部响应与随机替代。记录两个前缀响应
符号是否分歧、组合是否进入 elite、预测成本、物理成功与开销。
分歧是候选生成差异，不是机制见证。预先规定方向幅度 0.25、任务
seed 42、固定 reset 771001、50 个开发任务。先合成测试和真实 smoke。

必须另外证明前缀改变的是可利用的后继状态、最终选中链在同链
干预下失效、评分和完整成本可信；更强全链优化、局部梯度和独立
确认尚待。该原型调用全链模型多次而非缓存显式预测后继，不声称
后继预测缓存或高效程序组合。

扩展：观察 seed 42 后，固定增加 seed 43、44 的原生、条件化、共享
三臂，维持每 seed 50 行和 reset 基础种子 771001；不排除任务、不调参。
这是开发随机流稳健性检查，不是独立确认。任务采样与规划随机 seed
仍耦合，不可据此拆分方差。
