# 模型分差回退：留出开发根结果

先以已曝光根 10–19 的模型分差中位数标定阈值 **49.1201**；
不读取物理结果，在根 20–49 封存全部二选一动作，再评估原物理轨迹。
每根 64 对先平均，30 根再等权平均：

| 规则 | 平均末距 | 曾成功比例 | 每根平均选择探针次数 |
| --- | ---: | ---: | ---: |
| 两链模型最低分 | 41.19 | 28.18% | 27.6 / 64 |
| 分差门控，否则回退参考 | 39.42 | 25.68% | 10.8 / 64 |
| 始终执行参考 | 39.84 | 21.67% | 0 / 64 |

相对直接选择，门控平均末距降低 **1.77**，其中 **28/30** 根
末距均值严格降低；但曾成功比例降低 **2.50 个百分点**，超过
协议预定最多降低 1 个百分点的限制。因此此固定门控**未通过开发
出口，不接入正式规划器**。末距和曾成功分别衡量不同目标，不能
用前者改善掩盖后者退化，也不能由此否定其他可信度方法。

校准与评估根在本次规则中分开，但这些任务和轨迹在此前研究中已
曝光；每根 64 对共享前缀和候选，不是 1,920 个独立任务。本实验
只比较固定动作池中两条完整链的离线选择，不是实际部署的单次
规划成功率、反馈控制或成本优势。模型分差无需新增模型查询，但
原始模型预测、候选生成、真实执行和系统成本并非零。物理状态
仅用于封存后的评价，PC0–PC5 不改判。

筛选、平局、非法输入及真实结果映射等定向测试共 **4 项通过**。

保留违反停止条件的结果。
