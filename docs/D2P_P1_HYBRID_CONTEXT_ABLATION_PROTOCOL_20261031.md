# 修复后轨迹：同动作上下文替换消融

固定同一 RUN02 四个五步动作及对应真实 RGB 标签。每个时刻比较：

1. 连续开放预测历史；
2. 保留开放预测历史的前两项，仅将最后一项替换成该时刻真实 RGB 编码；
3. 三帧历史均来自原真实反馈规划路径。

三者均使用相同的当前五步动作和相同动作历史，运行时严格检查动作
历史相等。分别保存目标 latent MSE、同时间真实 latent MSE 和完整向量。
验证每个节点本来三片段预测赢家分数、任务摘要和物理动作绑定。
四个时间点是一条已知轨迹，非独立样本；第二组仅是离线反事实诊断，
不是新的在线控制器或因果保证；不增加物理试验、不训练模型、不
用这些事后结果选阈值或更改 P1 gate。
