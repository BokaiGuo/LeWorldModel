# v10 递归响应：固定 E0 开发面板

事前固定八个任务：起点 `[-0.5,y,theta]`，`y∈{-0.21,0.23}`，`theta∈{-0.5,0.6}`，目标 `[0.5,gy]`，`gy∈{-0.1,0.1}`，按列举顺序笛卡尔积。仅检验任务与已引用 v5 18 根不重复；没有完整历史排重与来源证明，不称独立或确认面板，不根据结果调整根、成功阈值、预算或配置。可行性未事先认证，失败不证明任务无解。

五臂共享每根 1920 预测 token 上限、15 步二维动作、五步一个 token 和原解析后端，物理终距 `<0.05` 仅按预设报告。v10 固定两组 v7 名义动作、两种扰动幅度 0.25/0.5、beam 四个、两个即时最优槽与两个特征距离槽、三个递归片段；分别采用目标贡献前一和前二非零模态，均计量所有响应、分支、完整链、精修和配对弃权。单模态与双模态成本、精修样本量可能不同，是预算分配比较，不能独立归因于谱方向。v10 生成正常候选时不输入特权轨迹。

对照为未改动 v7 与两种完整链 CEM（四结点及逐步），每种 CEM 从零和两个固定随机初始化分别重启，使用此前已固定的 213/212/212 样本分配。该开发设置不是强基线上界；各臂同 token 不代表 SVD、CPU 时间等总成本相同，需分别报告。记录所有实际 float32 动作与预测、计数、v10 响应及保留、最终完整链、预测及终距，联合精修后与零首段同批比较；不能拼接不同版本结果。

审计全部轨迹动作、端点、评分、token 和实际选中链，另核验 v10 响应差分、每层候选及模式排序的对应关系；同一后端审计不构成独立复现。此为新版本的有限功能和搜索诊断，不推断 PC2 同链机制、PC3 优势或泛化。完成后停止此固定开发面板；机制干预及独立确认须另立合同并仅对实际选中链进行。
