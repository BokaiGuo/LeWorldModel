# 多方向编译器 PointMaze RGB 固定终点开发协议

本协议在运行前制定。四个既有暴露开发根、冻结 checkpoint、normalizer、
目标图像与桥接后端沿用固定终点 RGB 对照；不证明训练外、normalizer 拟合外
或开发外独立性。实际输入为 RGB 及历史动作，位置和速度估计从图像得到；
初始模拟器状态仅用于环境设置，不传给规划器。目标投影是模型内代理评分，
物理状态仅可用于事后重放评价。

每臂各自执行真实反馈，热身后严格执行 15 个动作；在 0、5、10 步规划
剩余 15、10、5 步，每次只执行前五步，不延长终点。首决策调用
`pc_multidirection_successor_compiler_v1.decide`；后两次调用
`pc_multidirection_feedback_v1.decide`，在新上下文重新评分 carry。
10/5 步不声称仍包含首决策的两层后继组合。对照调用既有固定终点
full-CEM 决策；两臂每决策至多 480 个五步预测 token，预测采样的
实际长度计费。结构分解、编码及时间单独报告，不将等 token 等同总成本。
此 CEM 为单配置开发对照，不能称为强搜索上界。

原始二维动作限制为 `[-1,1]`，预测前用冻结数据 normalizer 标准化，
执行时派发选中链的原始浮点值；模型先转 float32，因此二者可能有浮点
舍入差异，须记录并在事后核对，不能宣称逐位相同。有限差分名义动作取现有实现的
`[0.25,0]`，扰动幅度 0.05；每次调用另行检查实际动作有限且合法。
记录每批请求、模型 float32 动作、投影和评分、token，以及执行链、
未执行尾部、图像哈希和实际时间戳。锁定并记录实际方法、对照、桥接、
runner、优化器和响应代码哈希；依赖仍须随结果审计，不能凭标签证明
完整来源或完全计费。

所有输出使用独立新前缀和排他创建，发现已有部分结果即停止，不覆盖
历史。异常或资源不足记为失败，不更换根或临时调整超参数。结果仅用于
评估此冻结版本的开发行为；不从代理预测声称真实成功，不拼接精确状态
结果声称同链机制，不判 PC2–PC5 通过。执行后应以独立物理重放逐步
评价并记录模型与执行差异。
