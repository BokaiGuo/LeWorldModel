# PushT 复位物理子步：固定首计划配对结果

## 目的与范围

在[冻结的开发协议](/home/gbk/code/LeWorldModel/docs/PC_PUSHT_RESET_TICK_SAME_CHAIN_PROTOCOL_20261107_CODEX.md)下，对 50 个已曝光任务、两条既有首计划，分别用标准 `_set_state`（包含一个物理子步）和直接设置可见状态并刷新形状索引（不推进子步）初始化，然后执行完全相同的 25 个动作。没有重新规划或根据真实状态选动作。两臂有 10 个任务的动作链相同，因此不能把 100 条链视为 100 个独立任务。

标准路径与已保存轨迹的可用逐步动作、状态及成功标签核对通过。保存了两条件逐步动作、物理快照和成功状态的[原始记录](/home/gbk/code/LeWorldModel/le-wm-main/results/pc_pusht_reset_tick_same_chain_20261107_codex.json)。环境和来源文件哈希见记录。

## 配对结果

| 指标 | 首计划臂 0：标准 / 无子步 | 首计划臂 1：标准 / 无子步 |
| --- | --- | --- |
| 25 步内曾成功 | 20/50 / 20/50 | 22/50 / 22/50 |
| 第 25 步成功 | 13/50 / 13/50 | 13/50 / 12/50 |
| 终点成功仅标准 / 仅无子步 | 0 / 0 | 1 / 0 |

标准复位的七维可见状态最大绝对误差按任务中位数为 **0.655**、最大 **2.139**；无子步条件最大误差为 **2.85e-14**。初始图像平均绝对像素差的任务均值为 **0.472 / 0.451**（标准 / 无子步，8-bit 色值）。无子步状态更贴近所存七维状态，但初始图像并未完全一致。

两条件在第 25 步的 block 位置差，中位数 **0.326**、95 分位 **1.826**、最大 **7.670** 环境坐标单位；agent 位置差中位数 **0.779**、最大 **2.178**。这些是同一批候选的描述性数值，不是独立样本统计或成功率优势。

## 结论与限制

标准复位的额外物理子步确实使记录状态和实际规划起点不同，固定链执行后的状态也可能产生差异；但这批实验中曾成功结果完全相同，终点标签仅 1/100 条发生变化，且无子步条件少一次成功。因此没有证据将已有退化主要归因于该子步，也不能把无子步条件称为已验证的控制修复。

数据不包含 block 的线速度、角速度和接触缓存，七维状态匹配不等于完整隐藏物理状态复原。测试只覆盖固定首计划的开放环执行，不是完整闭环比较或独立确认；不改判 PC0–PC5。

相关测试 **2 passed**，覆盖合法动作验证和真实 Pymunk 渲染形状缓存回归。扫描中，其他明确使用 agent/block 直接赋值的若干历史诊断已经显式刷新 shape 索引；该字符串检索不是全仓语义审计，也不能保证发现所有别名或间接调用。
