# PushT 既有完整首轮池：预测时间评分开发检验

数据为已曝光 seed-85 四任务、每任务 630 条按动作字节去重的完整首轮候选池。模型所有五个预测包时刻与终点评分已经封存，全部候选已有 25 步物理重放。选择只使用记录中的候选动作、各时刻模型预测和目标编码；物理标签和状态仅在选择后评价。

预先固定两个同池选择规则：`endpoint` 取第五个预测包时刻的平方目标距离最小链；`min_predicted` 取五个预测包时刻中最小平方目标距离对应的链，选择同一链时也记录代价最低的包时刻。排除输入初始帧，数值并列依照物理记录的候选索引及更早包时刻稳定决胜。两臂共享相同候选集、已付费的同一组模型 rollout、动作域和初态；本次不重新优化，不能据此声称改变 CEM 目标后的性能或成本。

每个选中链报告原生实际 25 步内曾成功、第 25 步成功，以及 `min_predicted` 所选包时刻（5、10、15、20、25 环境步）的环境成功。`endpoint` 同样报告其 25 步的成功；历史已执行选择另列。不能将链在别的时刻曾成功当成在预测的截止时刻成功，更不能假设线上有特权成功停止器。记录两臂的模型评分、时刻、候选来源与动作哈希。验证每条动作哈希、封存末帧得分与重算值，并用环境原生 `eval_state` 逐包时刻核对第 25 步成功；数据和目标只用于评价端。

数据和原结果已曝光，四任务不是独立确认；此为事后方法可行性筛查，不设追溯通过标准。即便出现优势，也必须另行统一基线目标、计入重新优化和反馈总成本，并在独立任务与合法停止规则上验证。不得用此判定 PC0–PC5 通过。
