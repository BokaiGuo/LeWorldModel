# TwoRoom 目标像素差与失败链选择：事前诊断协议

问题：已暴露数据行 82490 中，真实末帧编码对目标图的距离倾向一条失败链而非 12 条成功链。此前该面板的数据目标图与按环境物理目标重渲染的目标图只存在少量 1/255 像素差；检查这种差异是否能造成该案例的评分排序翻转。

沿用已封存的 12 条成功候选及 parent、lookahead 两条失败候选，动作、原始预测分数、真实末帧编码、模型与 normalizer 指纹均来自原记录；不得把真实成功标签、真实后继或重渲染图用作规划器输入。重渲染目标图只作为评价端合同诊断。使用相同冻结模型和 ImageNet 预处理分别编码数据目标图与重渲染目标图。模型预测对两种目标图分别复算，核对它们的预测后继与手算末帧平方距离，并与原封存分数对齐；真实末帧特征直接读原封存值并对两种目标向量重新计分。

报告目标图像像素差、目标编码差、预测与真实编码的各候选分数变化，以及 parent 对全部 12 条成功链的两种评分排序；平局明确标记。若数据图与重渲染图产生任何胜负翻转，才值得进一步检查该像素差的实现来源，否则不能把此差异当作该候选组排序错误的解释。即便排序翻转，也不证明它是总体退化主因。原案例属于已暴露、事后选择的单根；该实验不更改任何历史得分、实际选择或 gate。
