# PushT 静态 RGB 因子诊断 v2：明确 reset 速度

前版在第一个边界停止：官方 `_set_state` 将给定速度写入推杆后执行一次 `space.step(dt)`，所以输入位置并非 reset 后位置；失败和原封存保持不变。本版本另立协议，只研究静态图像，不宣称恢复真实动力学状态。

固定与前版相同的两臂四边界、base/agent/object/both 四种位置和角度替换；所有 reset 输入的推杆速度统一置零。每次严格核对 reset 后推杆、物体位置及角度与指定值相等、速度为零，核对原 base 图像与保存的真实边界 RGB 逐像素一致，并核对固定目标图像；任何不符立即停止并保存失败。图像一致只证明渲染层面，不证明包含接触隐状态、速度或合法未来轨迹的状态复现。

沿用前版 frozen encoder、同一 goal RGB、目标 latent MSE 与 2×2 交互分析；保留全部图像、状态、哈希和失败。反事实移动可能造成遮挡或几何重叠，也可能不可达。因子效应仅是这些图像上的评分敏感性，不能作为控制动作、因果机制或通过证据。
