# TwoRoom 成功精修链的模型—真实编码对齐

在事后发现的行 82490 上，固定选择完整精修池中 12 条物理成功链，加原 parent、lookahead 最终实际链，各自身份和动作来源不变。复算冻结 RGB 模型预测末端表示及目标分数；从相同初态独立重放并编码真实末帧，计算相同目标 latent 代价、物理终距、曾成功与表示均方误差。检查模型是否优先评分失败链、真实编码是否也优先评分失败链，且保留全部 14 条及动作指纹。
