# P1 已知根真实中点的共同多起点后续规划

对原赢家的全部 24 条轨迹，保持原前缀及后缀前五步动作，
读取其真实中点 RGB，以相同冻结模型为剩余五步重新规划。
每条使用四个起点：原第二包、全零、以及用 `20261031 +
logical_pair` 固定随机种子生成的两个均匀原始动作包；每个
前缀角色使用同一随机生成规则。四个起点分别 Adam 更新 20 次、
学习率 0.05，逐动作投影至 [-1,1]。完整记录四个动作与分数，
并把未修改的原第二包作为额外候选。选择最小预测目标 MSE，
平分时固定先原动作再按起点索引；选择不读取物理真值或成功。

真实执行时必须从原根重放并验证前缀和第一包身份，再执行选定
第二包，记录原生成功、停止步与物理指标，早停不补十步终点。
比较既有开放执行、单起点真实反馈和该多起点反馈，三者均为
已知根、事后开发证据；额外调用分别记账，不宣称等预算。
同一个原第一包和真实中点得到重规划，不是同时观察所有候选的
oracle。不能借此宣称 P1、独立泛化或机制通过。
