# TwoRoom 分段动作与 CEM 的 50 任务开发对照

固定既有 50 条 seed-42 数据行、冻结 RGB LeWM、相同目标 RGB、
动作 normalizer、25 环境步和真实成功规则；任务及数据已曝光，不是
独立确认。先封存所有模型动作及分数，再从相同物理初态执行选中链；
物理状态、未来真实后继与参考动作不进入规划。

每根每臂均评估 300 条完整动作链，均选择已评分最优链：

1. 逐步 CEM：三轮各 100，10 elite；归一化空间每步独立采样，
   初始为物理零动作，每轮第一个样本为当前均值，方差下限 `1e-5`。
2. 分段随机：300 条，5 个独立均匀分布的物理二维动作，每个保持 5 步。
3. 分段 CEM：三轮各 100，10 elite；每个模型包只有一个归一化动作，
   展开为五个相同环境步，初始化、均值候选、边界与方差下限同逐步 CEM。

三臂使用预定不同随机流。每次模型调用都计实际候选数；记录 CUDA
同步的逐臂生成加评分时间，但不以它冒充整个任务成本。前十根的
随机分段与逐步 CEM 必须重现前轮已封存候选和选择；动作数、归一化
往返及物理 bounds 必须检查。单根只执行一条链，无在线反馈。

报告全体 50 根及最后 40 根（不含上一轮前十根）的成功率、配对独胜/
独负、曾成功/末步成功、分数及时间。开发出口预先设为：分段随机或
分段 CEM 相对逐步 CEM 在最后 40 根至少独胜 4、独负不超过 2；
不满足则不将该臂作为待确认的优势候选。若胜出，仍需在来源独立任务、
充分调优基线、完整成本与真实 RGB 闭环验证；这一实验不包含描述增量、
程序干预或 PC gate 验收。
