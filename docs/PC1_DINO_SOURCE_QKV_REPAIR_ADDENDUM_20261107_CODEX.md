# DINO 修正第二版：对齐 QKV 运算路径，不放宽容差

第一版原始产物保留于 `results/pc1_dino_source_compatible_20261107/`。
64 组 encoder 逐层测试均通过，位置嵌入逐元素一致；首层 attention 开始
出现约1e-6的算术差，原生518分辨率碰巧逐元素一致。
前4根完整rollout通过；1836/shifted 的预测视觉表示有6个元素超出既定
`5e-4+1e-4*abs(reference)`，max_abs=0.0009741783，relative_L2=2.78265e-6。
这不表示大范围动力学差异，也不能因平均误差小而宣布整张量验收通过。
未读取这一新版本的物理结果以选择修正或阈值。

源码与HF的另一区别为QKV：固定源码将三投影合并为一次linear，
HF分别计算query/key/value。v2将原三个权重在运算时拼接，用同一
scaled_dot_product_attention布局，不新增或训练参数，不更改参数键名。
不修改共享依赖或历史源码。此修正针对已定位的第一处算术路径差异，
不是改变理论、目标评分或动作权限。

第一版协议的全部任务、候选、时域、数值容差、评价和成本边界不变。
新目录 `results/pc1_dino_source_compatible_v2_20261107/` 从头执行同一
源码验收；失败尝试计入研发开销，不抹去失败，也不宣称更低系统成本。
若仍失败继续定位，不调整成功阈值。修正只是state-assisted实现一致性，
不得用于通过RGB-only gate。
