# 固定原后缀的三前缀控制实验

全部 8 个逻辑臂、各自 selected/zero/greedy 五步前缀共 24 条，
施加预先封存在该臂 H10 计划中的 `original_selected_tail`，
不做任何后缀优化。三个前缀使用完全相同动作字节、同一根、
目标与条件；记录各自原生成功、停止步、物体/推杆指标及删失。
不依物理结果挑选臂或方向。

该后缀源自 selected 的联合计划，因此不是公平强基线；相同
后缀只比较对应动作的效果，不证明各前缀可规划能力差异。与
真实 RGB 刷新后重新规划的暖启动和零启动对比时，反馈机会与
计算成本不同，须明示。该已知根事后开发实验不打开 P1。
全部 42 后缀族的共同干预仍须完成，24 行不能替代完整面板。
