固定终点三轮各执行 5 步，规划剩余 15/10/5 步；每轮以本臂真实反馈重编码、旧尾在当前上下文重评分，记录所有原始与 float32 动作、预测、轨迹分数、最终同批弃权、真实 RGB 和封存／派发时钟。每轮总预算至多 1920 prediction-token，包括最终配对比较；单独保留编码和规划时间，不能声称总算力等价。
