# P3 H3：固定动作的真实上下文 CUDA 重放

在既有同动作模型／物理方向分析之后，固定使用已封存的完整 H3
面板：36 个逻辑 old/new 对中，只有双方均有第 20 步终点、且
第 15 步真实状态和快照一致的对可以比较；其余状态原样报告，
不补值、不按预测效果筛选。全部逻辑重复均保留，并按既有输入
去重组报告；不将其称为独立根或事前确认。

对每条完整轨迹读取真实第 5、10、15、20 步 RGB，核对已验收
报告、像素哈希、物理动作及目标身份。在冻结模型的主机 CUDA
上分别编码前 5、10、15 步图像作为三个状态 token，用实际执行
的第 6–10、11–15 步动作按保存 normalizer 构造历史 token，再
用同一 old 或 new 第 16–20 步动作预测第 20 步 latent。第 20
步 RGB 编码作为真实观测对照。对应开放想象结果、目标 latent
与相同动作从旧封存重放读取。保存两种预测、真实编码和代价；
比较误差与排序时逐对报告，避免把动作对或重复轨迹当独立样本。

此对照同时替换三个状态上下文，不改变后缀预测时域。它可以检验
实际上下文与保存想象上下文下的后缀预测差异，但不能单凭它
判断所有接口正确或控制收益，也不是重新规划。冻结模型参数和
buffer 前后哈希须一致；不更改 gate、不训练模型、不降级 CPU。
该分析在既有结果开放后制定，是探索性事后诊断。
