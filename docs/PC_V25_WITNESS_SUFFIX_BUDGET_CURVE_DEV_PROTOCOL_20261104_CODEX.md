# 已知可行前缀：等预算重启曲线协议

对既有 8 根、每根 2 个特权见证前缀，比较逐步动作 CEM 的零初始化和均匀随机初始化；见证尾部不可参与。每个前缀每臂固定 8 次独立重启、每次 121 个完整链评价。仅报告预定重启数 2、4、8 的累计最佳分数：每前缀对应 242、484、968 样本，或 726、1452、2904 prediction-token。所有重启无论是否提前成功均执行，禁止依据结果扩展或替换任务。

沿用前次初始化和种子规则，前两次重启应能精确复现前次表达对照；新增重启使用相同预先确定的种子生成规则。两臂每个预算点样本相等，并记录每次模型调用和失败，报告每个前缀及每根任务成功数与终距。不声称等 token 即等墙钟／GPU 成本，也不将特权前缀结果计为正式方法成绩。

封存实现、来源和任务；审计逐批动作、费用、另一同环境几何实现以及全部优化器提案回放。诊断只研究给定前缀下优化预算，不证明自动候选覆盖、PC2 或 PC3，也不能据有限重启结果认定理论成败。
