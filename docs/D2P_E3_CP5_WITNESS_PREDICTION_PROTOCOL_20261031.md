# E3 已知 cp5 目标：五步动作见证预测

对两个既有根固定使用 control0 的保存 latent/action 历史以及原样
五步动作见证，按部署均值和标准差恰好归一化一次，调用冻结
PushT 世界模型预测 cp5 latent；与已独立 CUDA 重编码、逐字节
一致的真实 cp5 RGB latent 比较。另报告模型内零动作预测，不
把未执行的零动作预测称为真实零动作结果。

只读固定 resolver 和此前 cp5 编码结果，绑定输入、代码和模型
哈希；两根全部运行，不按误差筛选。使用主机 CUDA、FP32 和
MATH attention，保存预测、目标、动作、MSE 和模型前后哈希。
这是已知根上的同动作五步预测诊断，不是规划、物理新执行、
模型训练、独立确认或 P1 准入。cp5 目标及动作见证来自同一
历史轨迹，不作为泛化测试。
