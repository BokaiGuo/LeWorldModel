# 两包反馈动作的共同后缀机制干预

在观察反馈结果之后，将全部 8 个 logical pair 的三条固定反馈
十步动作链作为后缀族，不按成功或模型分数选择。对每个 pair 的
selected、zero、greedy 三种已认证前缀，各执行相同的四个十步
后缀：全零，以及该 pair 三种前缀各自产生的反馈十步动作链。
共 8×3×4 = 96 条物理分支；保留重复动作和提前停止。

跨前缀的反馈后缀是固定动作迁移，**不是**在目标前缀重新观察
中点或在线重规划。真实反馈中点只属于生成该动作的来源轨迹；
不得把它当目标前缀的新观测。验证根、目标、各角色原始前缀、
三个动作的来源哈希和逐位绑定；固定 96 分支执行后验收保存态。
分析时同时分列初始/前缀物体位置、角度、推杆、联合误差、
共同后缀终点、相对各前缀零后缀的变化、原生成功和删失。第十步
达到成功且有状态时另列，不补第九步停止的第十步。

该事后设计使用两个已知根，后缀来自不同前缀的优化结果；共同
动作的差异只能提供该动作的响应机制线索，不能证明各前缀
可规划能力、独立泛化、等预算优势或 P1 通过。所有物理分支均
执行，不使用其结果改变模型、规则或 P1 gate。
