# 已知根 DLS 前缀共同后缀物理干预

根 0 固定使用来源修复后的四条真实轨迹的首五步作为四种前缀，
并在每种前缀后交叉施加同样六个十步动作，合计 24 分支：
零动作、structured 实际后缀、native 实际后缀、immediate 实际
后缀、random 已执行的八步后缀加两步零动作、structured 后缀
逐项取负。后两项是明确构造的固定探针，不是假装随机轨迹在
成功后还执行两步，也不是对成功动作的在线反馈。

每条从同一个经核验的初始状态和原生目标重放；第 5 步必须逐项
匹配原前缀的物理快照和 RGB。记录全部实际状态、接触计数及
原生停止和越界；提前停止不补终点。对共同后缀同时报告绝对
终态及相对同一前缀零后缀的变化。物理执行没有神经推理。

这些前缀和三个已执行后缀属于看过结果后的已知任务开发诊断；
并非零前缀、认证 greedy 或独立根的完整 P1 对照。它只检验固定
后缀效果，不能证明各前缀的可规划能力或公平优势，也不能因为
任何单条成功而宣布 P1 通过。不得将物理状态用于模型选择。
