# P3 RGB 弃权后的缓存后缀回退：探索合同

现有规则在 cp15 使用真实 RGB 边缘预检，拒绝时不执行后五步。
新候选被拒绝时，可考虑转而执行在相同真实前十五步前已缓存的
原后缀；放行则使用新后缀。这一规则在观察现有事故和弃权后
提出，属于事后工程探索，不能作为安全或科学确认。

本次只使用完整固定面板的受保护与未保护物理记录，按同一 pair
身份连接，不额外选择根、候选或阈值。受保护分支双方完整时，
取其中新后缀结果；双方在 cp15 弃权时，取未保护实验同一原后缀
的实际结果，并保留来源，不能称在线回退已经执行。任何身份不符、
原后缀未完成或不同状态均保留为未知或拒绝分析，不补造终点。
重复动作身份去重并要求结果一致，列出成功、物体位置、角度和
推杆等指标，不把联合距离或弃权当成功。

未来在线实现须在新后缀派发前验证真实 cp15 身份与缓存动作，
明确记录选择、回退动作、预检和额外计算费用，并以独立根、
公平反馈和预算验证。预检基于静态 RGB 不保证旧后缀安全；
本次不更改原保护或 P3/P1 gate。
