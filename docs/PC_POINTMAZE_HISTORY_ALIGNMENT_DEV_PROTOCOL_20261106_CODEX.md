# PointMaze 真实动作历史对齐：开发诊断

使用已暴露数据集 1884–1891，观测帧 0、5、10，已发生动作 0–9，固定后缀动作 10–14，真实目标观测为帧 15。所有臂使用相同 checkpoint、冻结编码器、动作归一化、帧及后缀。后缀与帧 15 仅用于离线预测诊断，不得据此声称在线可知未来。

对照单帧上下文、三帧且历史动作嵌入补零、三帧且实际两段已发生动作拼包。真实历史通过既有 `unroll_history` 传入，每包恰有五个连续归一化动作；三帧来源为真实轨迹，禁止复制静帧或用后缀充当前缀。报告每任务一步真实编码 MSE、预测差异及运行时、GPU 调用，检查动作和上下文位置。模型、normalizer 不变。

在本固定面板上预定开发出口：真实历史 MSE 在至少 6/8 任务严格低于单帧，且任务平均 MSE 低于单帧；相对补零单独报告。不达标不得声称真实历史提升预测；即使达标也不等于原始帧 0 案例已有历史或性能已修复。数据暴露、state-assisted，不是 RGB-only、独立确认或闭环 gate 证据。
