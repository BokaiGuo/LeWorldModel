# RGB 编码缓存：CEM16 反馈决策重放

依照[事前协议](PC_RGB_CACHE_FEEDBACK_REPLAY_PROTOCOL_20261107_CODEX.md)，重建 40 个已曝光 TwoRoom 任务的 CEM16 baseline 反馈轨迹；每个观测时刻使用相同 seed、旧尾和 16 条链预算，分别运行完整原始和缓存规划路径。环境状态只用于重置和评价，规划输入保持 RGB、目标图及显式空历史。

## 结果

- **128/128 次决策**，三轮候选分数满足预定容差，elite 选择、最终链索引与动作一致，原始路径选择也与历史记录一致。
- 两路径候选分数最大绝对差 `1.22e-4`，旧尾分数最大差 `6.11e-5`。每次决策最小与次小评分的最小间隔为 `0.0460`；本面板没有间隔不超过 `0.001` 的决策，因而不覆盖极近并列。
- 缓存对象跨观测保留，128 次决策各触发两次图像编码；对应当前与目标图像。实际派发动作与记录一致，物理距离及成功/截断标记逐步重放一致。
- 含冷缓存建立、采样、评分和边界检查的 128 次同步规划计时合计：原始 **4.447 秒**，缓存 **3.242 秒**；单决策中位数分别 **34.49 毫秒**和 **26.95 毫秒**。顺序按任务与迭代交错；这只是一次同机配对重放，不是完整任务成本曲线或统计上的速度保证。
- 本轮新增与既有缓存、单帧合同测试共 **14 项通过**。模型和 normalizer 与历史记录校验，模型状态在重放前后保持冻结。

这里使用环境重置和历史派发动作重建观测，验证了物理轨迹与评分，却没有逐像素核对每次重建的 RGB 是否与历史收据完全一致；不能把它表述为历史所有图像逐位复现。环境包装器仍发出 observation 类型及动作转换警告。两条规划路径在同一实际观测上配对运行，环境只执行历史动作一次，因此不是两次独立闭环控制，也不是效果或成本优势的独立确认。

缓存仅适用于当前单帧 LeWM 的 inference 路径，不能用于训练、动作梯度或含历史输入的其他协议。所有比较臂均应获得相同权限；本实验不证明 Planning Compiler 的描述增量，也不改变 PC0–PC5。
