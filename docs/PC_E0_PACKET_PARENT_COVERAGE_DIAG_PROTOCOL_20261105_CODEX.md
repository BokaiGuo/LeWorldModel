# E0 父链时序结构与可解性开发诊断

新参数面板三臂均 0/32，不能直接归因理论。当前全局父链库逐步独立均匀采样，15 步内动作可能相互抵消。本事后提出、运行前固定的开发诊断比较：保持同一 16 根、两个随机流、库大小、动作域、CEM 及总 prediction token；只将父链库由逐步独立采样替换为三个五步常值 packet。

packet 库种子 `2052000000+2*root+repeat`，每条链的三个 `2D` packet 各坐标均匀 `[-1,1]`，重复 5 次；首链零动作，其余 63 条随机。逐步库复用上轮已封存、已审计 CEM 运行；其随机种子与 packet 库不同，因此是独立随机库比较，不是逐链配对或单坐标因果干预。两臂各从 64 条库中选择最低终距父链，用相同优化 seed `2051900000+2*root+repeat`、157 次完整链评分的 CEM 精修；每臂分摊总 `64+157=221` 次评分、663 tokens。每次实际调用及最终已评分最佳链均记录。

报告起点终距、最终终距、成功数 `<0.05`、每根两个随机流均值的配对结果以及库和 CEM 资源。测试预算内检出，不能把未找到解释为不可解，也不证明 packet 是唯一原因。源面板与结果已暴露，来源独立性 unknown；不能当作 PC0 的正式可解性认证或 PC3 强基线独立确认。编码、系统成本和共享父链的其他开发成本未计入。
