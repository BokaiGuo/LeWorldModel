# 跨任务误差跨度：探索性开发结果

## 方法

上轮按绝对代价误差检查排序界，会受到所有候选共同分数偏移影响。本次按[协议](PC_CROSS_ROOT_ERROR_SPAN_PROTOCOL_20261107_CODEX.md)计算每根全部 64 个候选的“预测代价减真实编码代价”跨度；共同偏移不会改变这个跨度。根 0–4 和 5–9 互换校准与评价角色，每折用校准根的最大跨度作经验阈值；评价根只用预测的前两名前缀机会差判断是否触发。

此条件只针对固定候选池中的**真实末帧编码代价排序**。校准需其他任务的真实后继；没有训练或更新世界模型，但也没有证明这五根提供可靠的未来误差上界。

## 结果

| 指标 | 结果 |
| --- | ---: |
| 两折阈值（校准根 0–4／5–9） | 196.76 / 114.50 |
| 评价根实际误差跨度被另一折阈值覆盖 | 7/10 |
| 前两名预测间隔超过阈值 | 3/10 |
| 全部根：预测最优前缀也是真实编码最优 | 6/10 |
| 触发根：预测最优前缀也是编码最优 | 3/3 |
| 全部根：模型实际选中的 B 链曾成功 | 8/10 |
| 触发根：模型实际选中的 B 链曾成功 | 3/3 |

三个触发根为 1、3、9；未触发的 7 根中实际选中链有 5 根成功。此次的简单事后对照中，若仅按预测间隔挑出全体最大的 3 根，则为 9、3、5，同样 **3/3** 编码最优、**3/3** 实际选链曾成功。这个“选全体前 3”对照需要知道整个评价批次，因此本身也不是在线规则；它说明当前样本没有显示额外校准比简单间隔更有信息。

## 边界

这是已经曝光的 10 根和事后计算出的固定两折分析，不是未见任务确认；所有 B 的 64 条动作链已被模型评分，不能作为少查询方法的免费结果。`7/10` 的覆盖表明此校准阈值不能视为可靠误差上界；触发的 3 根过少，成功均不构成正式选择性风险保证或规划器增量。物理结果只用于事后评价，最优前缀的评价端物理末距亦不能输入规划器。

分析先固定两个拆分并保存逐根结果；`experiment-design` 用于分离校准、评价和简单对照。共同偏移不变及阈值未覆盖时不误认保证等 **4 项测试通过**。没有新增 GPU 查询或环境执行；不改判 PC0–PC5，也不把此阈值直接接入闭环。
