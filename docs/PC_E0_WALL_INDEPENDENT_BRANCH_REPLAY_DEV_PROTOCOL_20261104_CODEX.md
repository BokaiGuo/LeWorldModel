# E0 墙体独立几何及搜索分支审计：事后诊断

对已封存并经原后端审计的 v8、v7、smooth CEM、action CEM 共 72 条
首次决策，复用全部原始 float32 动作，不增加搜索。另写独立的二维线段
与墙交点实现和动作时序：每步先按旧航向平移，若线段与 x=0 墙体
在 |y|<1 内相交则整步平移拒绝，随后更新转角；墙端点按原合同允许。
同样适用端点相交和近零 dx 规则，检查逐批终点、欧氏目标距离及动作域。
对最终 selected 链逐状态、每步阻挡与原后端比较。独立代码不是独立
物理世界或正式 benchmark，但能检测共享重算路径中的几何接线错误。

分别统计所有已评分完整 15 步链中至少一次进入 x>0、至少一次受阻、
最后进入 x>0、终距 <0.05 的条数，以及最终选中链的同类事件。重复
评分单独计入并披露；数量依赖采样策略、并非独立任务或估计总体概率。
另区分 v8 前 49 条暖搜索完整链与其余链，不按结果重定义阶段。
记录每根每臂计数和依赖哈希；任何预测不匹配均停止并保留失败，
不得据此自动认定理论失败或修正历史记录。此为同任务事后故障定位，
不是 PC0/PC2/PC3 通过或来源独立证据。
