# 有界条件化候选对完整共同池的新增性：开发协议

目的：检验先前 211/576 的组合集合分歧，是否真正增加了相对
普通候选、共同探针及共享响应组合均不存在的合法完整链；不把
符号差异或 elite 次数直接视为发现价值。

固定 PushT 已暴露 task/solver seed 42 与 reset seed 771001，
50 个开发任务，300×10、两前缀条件化求解器。新版本在每次
模型评分前将普通样本、探针和组合统一投影到训练 normalizer
换算的物理 [-1,1]；分布更新使用投影后候选。记录实际求解器
300 条评分和返回均值。此求解器不同于旧无界版本；不将两者
成功率当成算法增量比较。

对每个后续迭代，固定完全相同的父链、噪声方向和 A 探针；
构造共享响应的四条对照组合。在原条件化 top-k 确定之后，
以额外四条模型评分测其代价；共享对照不参与求解器选择或更新。
每条条件化组合对比共同普通样本、共同 A 探针及共享四条组合
组成的完整池，以逐坐标最大绝对差 <=1e-6 判匹配。
分别记录独有条目数、其模型代价与完整对照池最低代价之差、
是否进入原 top-k，以及每个有独有候选上下文的最优候选动作；
还记录对应对照池最优动作及分数。逐条数是条目而非组内去重。

额外共享评分单独计费，不作为等成本规划结果；产生负分差仅
表示模型认为独有条目更优，不代表真实成功。首次单元测试必须
证明打开／关闭该额外审计时动作、elite 和主求解器评分一致。
逐步物理动作 trace 检查完整执行范围与初始化配对。此阶段不
宣称最终均值依赖某条候选，也不将事后统计当作独立确认。
