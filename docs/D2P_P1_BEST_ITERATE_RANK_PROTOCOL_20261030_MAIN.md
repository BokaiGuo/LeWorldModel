# P1 最佳迭代与信赖版的同动作后果分解

对已执行的 24 条固定逻辑行，使用各自的实际信赖版和最佳迭代版
第二包、相同认证真实 RGB 中点和实际历史，重新计算冻结模型终点
预测及对应真实终点 RGB 编码。只比较两版均按原合同具有未删失
十步终点的行，其余保留停止标记，不补终点。每条单独报告预测
目标 latent MSE、真实目标 latent MSE、预测误差、物理位置、角度、
推杆及联合位置误差；模型规划目标另含动作信赖项，不能把仅
latent MSE 的排序当作正则化目标排序。

所有动作、文件、图像和身份须与物理 journal 绑定；编码及模型
预测仅在主机 CUDA 上执行。两版动作相同的逻辑行保留但不得
当作有效动作差异或独立实验。面板与方法均已知，分析只能作为
事后诊断，不能改变选择器、门槛、旧结果或声称 P1 通过。
