# v22 固定候选库物理评分后验诊断

研究对象为已暴露、已停止的单个 v22 构造目标；本协议只做评估，不恢复原规划面板、不产生反馈决策。目标是区分该固定库上的模型预测评分、真实末帧编码评分和物理指标，检验是否存在可用于诊断的物体位姿变化。

严格沿用 v12 固定库方法：从首个 response 决策保存的全部 15 步评估中，按时间顺序使用 `np.linspace(0,N-1,56,dtype=int)` 选出 56 条，重复动作保留；再加入 8 条仅供评估的特权见证变体（五个固定缩放、两个固定截断和时间反转）。这些见证动作不进入规划输入，报告时单列；这个库不是未查询动作泛化验证，也不是预算匹配方法比较。

对 64 条在已验证的同一 seed、warmup 和物理初态下各重置回放一次，逐条保存动作、终止、状态与末帧；冻结模型以原上下文单独重算预测评分，另以图像隔离编码真实末帧。核验输入、动作、图像及输出哈希。要求原 saved-data、chronology 和物理重放审计绑定；失败记录保留，不因结果改变候选库或重试规划。

分别报告 planner slice、特权 slice 和整体的物体位姿数量、任务成功、预测/真实编码与物理目标误差的非并列排序及并列数。64 条候选相互依赖，动作对不是独立任务；原目标按特权轨迹构造，不能将有利见证评分归功于候选发现或认证可推广性。本诊断不训练、不选择新策略，不改变 PC0–PC5。开发外、checkpoint 训练外和 normalizer 拟合外来源仍为 unknown。
