误差替代原生成功。成功后的轨迹不补后续步数。

实际执行动作。该检查未独立复演整个物理事件链；调用计数不
等于完整 FLOPs 或总成本。两个根和目标均为历史开发资产，四臂
成本尚未认证等价，native-style 不是官方强基线；不可宣称 E3、
P1/P3 或独立跨任务泛化通过。
