# P1 四起点独立后缀配对视图

在已有 24 前缀、1008 条共同后缀视图上，按索引、根、条件、
前缀角色和动作哈希加入四起点、各二十步的独立后缀物理结果。
数据见 `le-wm-main/results/codex_p1_multistart_paired_view_20261030_main_RUN01.json`，
SHA-256 `d378b83c4cbc7c2434b44bad901c7eb186da147acdc0c8f5cd1a9dfc1045b551`。
每个前缀仅有一个该配置的优化后缀，不能乘以 42 当成独立样本。
测试验证完整分母、提前停止不补值、身份和动作哈希不匹配拒绝，
共 2 项通过。该视图是既有结果的合并，不是新物理实验。

四起点结果有 22 条完整十步、两条提前原生停止；提前停止的
十步终点和依赖它的差值均为空，并保留最后接受状态和实际步数。
记录每项规划调用和物理计数，但规划调用为代码路径计数，规划
耗时不含模型加载；上游前缀计算及全流程资源仍未完全认证。
不能把不同调用轴直接相加，也不能称完整方法等预算。

举例，根 0/on 的两条 selected 记录，前缀的物体位置及角度误差
变化均为 0，推杆位置误差变化为 -1.002，原生联合位置误差变化
为 -0.921：物体未动并不意味着联合任务没有改善。分别独立规划
后，selected 相对同组 zero 的物体位置误差差为 +7.001 和 -7.622，
推杆误差差为 +34.924 和 -5.043；selected 两次均未原生成功。
两条共享同一历史前缀而采用不同初始化种子，不是两个独立任务。

共同后缀比较回答动作效果是否因前缀而变；独立后缀比较才针对
同一优化设置下的可规划后果，但当前仍是两个已知根、探索性搜索、
不完整的总成本合同，不证明独立泛化、P1 机制或公平强基线优势。
物体位置、角度、推杆位置与原生联合成功仍须分栏解读。
