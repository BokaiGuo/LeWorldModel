# P1 Adam 预算候选的同动作真实 RGB 编码合同

对已完成的 5、10、20 更新物理面板固定全部 72 条记录，使用
各自已验收物理动作、前缀和真实终帧。只对实际完成十步后缀的
记录编码第十步 RGB，并从同一真实 cp5 和动作历史重新预测该
动作的第十步 latent，分别保存预测目标距离、真实编码目标距离、
预测与真实 latent 的均方误差及物理指标。原生提前停止的记录
保留停止状态，不构造第十步图像或终点。

各终帧必须与保存态验收、轨迹状态、渲染条件、像素哈希和派发
动作绑定；预测分数必须复现原预算候选评分。参数冻结，所有神经
计算使用主机 CUDA。此为看过结果后的已知根误差分解，不用于
在线选择候选、不训练模块，不等于真实反馈规划或独立确认。
不能把 latent 对齐或任意单项物理误差当作原生成功或 P1 通过。
