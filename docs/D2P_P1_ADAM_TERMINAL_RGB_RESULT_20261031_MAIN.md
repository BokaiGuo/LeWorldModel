变化方向相反按两者差值乘积严格小于零计数，不把零变化算反转。
5→10 的 21 对中，9 对模型分数下降而真实 RGB 距离上升；10 对
模型分数下降而物体位置误差上升，二者交集为 8 对。另有 2 对
真实 RGB 距离下降但物体位置误差上升。由此可见该具体面板同时
存在预测—真实编码排序失配和编码—物理任务评价失配，但不能从
此推出唯一根因，也不能排除其他接口问题。
