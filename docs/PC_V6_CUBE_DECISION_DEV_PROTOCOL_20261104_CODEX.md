# v6 Cube 单根模型决策与探针重算：开发协议

目的为检验 v6 五维动作的实际搜索调用是否接通原冻结 Cube 模型及确定性 packet 接口，不是效率比较、机制验收或真实控制。选择已暴露的源 P0 面板 seed 202610250 的第一根（四根抽样规则不变）；三帧因果 RGB 和动作历史、同 episode 后续五步 RGB 目标均来自 SHA 绑定数据。该目标只是离线目标图像，不能证明部署可用、开发外或训练外。

在 CUDA 上关闭 matmul 和 cuDNN TF32，并捕获声明依赖及模型参数哈希。使用 v6 `response` 保留策略、root 编号 0、首个 15 步固定终点决策、1920 packet-token 上限、两个无特权固定 nominal：五维动作各分量分别全零及全 0.2，5 步重复；这些只是本开发配置，不是 Cube 通用最优动作。以目标 latent 方向加随机正交方向构造二维 chart，完整 latent MSE 评分。保留所有实际 float32 输入、chart 输出、评分、候选、精修、选择及资源记录；同步后计时。模型调用计数不包含编码、SVD 和独立审计，不能称总计算成本。

事后独立审计首个 51 动作 FD 批次的相同输入：分别以批量、逐条运行，记录 chart 及评分最大绝对差；核算两种中心差分矩阵与相对范数差（近零同时报告绝对差），并比较第一、第二、第二十六个探针和最终选中完整链的逐条既有 root-anchored reference rollout。只作数值诊断，审计调用不用于选择、不计入规划预算，另记成本。位置误差目标 `2e-5`、评分 `2e-6`，观察不满足时如实保留；不预先假定 FD 的相对误差阈值。

过程不派发动作，不读取物理状态用于编译，不将数据目标未来动作纳入候选，不做新根挑选。任何决策模型分数不得称环境成功或机制见证；结果不改变 PC0–PC5 状态。不存在同预算强基线或真实执行时，明确保留这些缺口。
