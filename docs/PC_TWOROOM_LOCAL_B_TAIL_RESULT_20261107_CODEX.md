# TwoRoom：局部 B 尾部生成开发结果

按照[预定协议](PC_TWOROOM_LOCAL_B_TAIL_PROTOCOL_20261107_CODEX.md)，在已曝光的 40 个任务上固定普通 lookahead 的两个前缀、共同 A 查询和共同 incumbent，比较原均匀 B 尾部与围绕各前缀 A 最低分尾部的局部高斯扰动。两臂各有 16 次 B 候选评分的逻辑预算；新方法使用冻结 RGB 模型选择，计划封存后才进行物理执行。

| 指标 | 均匀 B | 局部 B |
| --- | ---: | ---: |
| 开放环实际曾成功 | 38/40 | 38/40 |
| 相对另一臂独胜 / 独负 | 0 / 0 | 0 / 0 |
| 所选链来自各自 B | 0/40 | 8/40 |
| 每臂完整链逻辑评分 | 690/根 | 690/根 |

局部臂在 8 根选择了不同的动作；相对均匀臂，模型代价平均下降 5.787，单根最大下降 76.764，但没有改变任何根的二值成功结果。当前证据因此不支持该局部生成规则改善实际成功率；按协议停止扩大此具体配置。这不排除其他生成器、预算或任务上的效果，也不能把模型分数下降直接当作控制收益。

代码检查重建了 40 根的局部随机候选、A 中心、前缀保持、模型分数选择、所选动作指纹和物理结果；均匀臂实际轨迹与历史结果逐步一致。局部生成合法性和确定性测试 **2 项通过**。本次新评分 640 条完整链，共同来源和均匀臂评分复用历史结果；未作等完整系统墙钟对照，且模型分数未独立重算。环境提示 Gym 观测类型及动作转换警告。

这些是开放环、已曝光开发任务，不是纯视觉闭环性能证明；普通 lookahead 用于固定前缀，本实验没有比较向量描述，不能证明或否定描述的独立价值。`experiment-design` 用于固定对照、候选和计费规则；PC0–PC5 不改判。
