# PointMaze 分段 CEM 真实反馈开发比较

固定已曝光的八个同根第 25 帧任务、state-assisted 观测权限、25 环境步上限、冻结 checkpoint、相机和五步动作包。使用已封存的 160 评分分段 CEM 选链执行首包；随后每执行五步获取真实 RGB 与 proprio，以剩余时域重新规划，共四次。每次 3 轮 × 16 候选，4 elite；首轮第一个候选是未经修改的旧尾，其余来自固定随机流。旧尾重新评分并可与所有新候选竞争，最终从全部已评分链选择，末包也执行而非提前停止。

与原 160 评分开放环链按相同根比较；反馈共额外支付 192 链评分，且需记录模型步骤数、目标编码、观测、模型同步时间与整任务墙钟，不能称为等成本比较。物理状态是真实官方 proprio 轨道的合法输入；目标隐藏状态仅用于事后距离和成功评价，不进入规划。预设报告全体、初始未成功子集、实际派发动作和每轮完整候选评分；不得以此证实纯视觉或独立性能优势。

执行器以单一持续仿真进程交互，不从中间四维状态重置仿真；核对首包末状态与已封存轨迹、初始像素及动作时钟。任务和模型已曝光，结果只决定后续是否值得更严格比较。
