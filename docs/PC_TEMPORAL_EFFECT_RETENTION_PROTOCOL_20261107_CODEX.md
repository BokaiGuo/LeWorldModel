# 时序行动后果保留：已曝光开发实验

目的：检验前缀后的动作身份向量是否比相同查询机会的普通 lookahead 改善实际选链。前缀前最低分可能掩盖尾部差异，故描述使用第 15、20、25 步最小代价，所有方法的最终选择均使用第 5、10、15、20、25 步最小代价。零动作仅作为等时长参考动作，不宣称通用物理静止。

固定已曝光 TwoRoom roots 20–49；每个 root 使用旧的 8 个前缀、共同 A 8 个探针、共同 B 8 个独立尾部。每臂访问相同 A、参考和两个旧全链 incumbent；按照 A 信息选两个前缀后仅访问各自 B 的 16 条。用 A 全部链、被允许的 B 和两个 incumbent 竞争，记录实际完整动作。原始 600 全链候选已用于前缀和 incumbent 产生，计入逻辑成本；两个 incumbent 重评分也计入。历史预算和此次 GPU 实际并集计算分别报告，不能当完整墙钟成本。

四臂：普通 lookahead 保留 A 的前两名；vector 先保留 lookahead 第一名，再从全部其他前缀选择中心化后果向量距离最远者；gated 从 lookahead 前四中选距离最远者；shuffled 使用相同 gated 规则，但每个前缀内独立打乱动作身份。向量为相同时长参考代价减探针代价，逐行中心化；打乱不改变各行数值集合。所有排序稳定，平局按索引。

开发出口预定：gated 对 lookahead 和 shuffled 分别至少 2 个真实曾成功独胜且至多 1 个独败，并且各臂的终点成功、末距完整报告。未达到则停止这一具体构造；不以更多 seed 挽救。若通过，仍只作为后续开发候选，不能认定机制、独立结果或 gate 通过。

使用合法 RGB 和冻结 LeWM 评分；动作必须落在 [-1,1]。先封存模型分数、各臂前缀与实际动作和文件哈希，再在独立物理重放阶段读取状态和成功，状态和真实后果绝不进入选择。每条运行满 25 环境步，记录首次成功与终点成功。结果为已曝光开发固定首计划，不是 RGB 闭环收益、独立确认或正式 PC0–PC5 判定。
