# 第 25 帧目标：前缀保留和小预算 CEM 开发结果

## 为什么重做

前一实验的目标是同根归档轨迹的第 **5** 帧，不是长期独立目标；多数保留臂选了同一父链或 A 探针。因此其 7/8 只能说明该近目标固定池的开放环结果，不能说明程序结构解决了复杂任务。

本次按[协议](PC_POINTMAZE_GOAL25_RETENTION_CEM_PROTOCOL_20261107_CODEX.md)保留同一八个曝光根，改用各自第 **25** 帧图像与完整 proprio 作为目标，规划和执行时域均为 25 环境步。目标来自同一归档轨迹；其原始动作仅在选择封存之后作为评价端可解见证，不进入任何规划臂。该面板不是独立任务集。

## 物理结果

| 方法 | 最终成功 | 初态未成功子集 | 平均最终物理末距 |
| --- | ---: | ---: | ---: |
| 固定均匀前缀 | 8/8 | 7/7 | 0.2866 |
| 父链评分 | 8/8 | 7/7 | 0.2360 |
| 普通 lookahead | 8/8 | 7/7 | 0.2367 |
| 向量保留 | 8/8 | 7/7 | 0.2873 |
| 身份打乱 | 8/8 | 7/7 | 0.2367 |
| 小预算 CEM | 7/8 | 6/7 | 0.3201 |
| 归档动作见证，仅评价端 | 8/8 | 7/7 | < 0.000001 |
| 零动作，仅评价对照 | 3/8 | 3/7 | 0.7837 |

各根归档见证在原始 float64 初态重放后的最终四维状态与目标最大误差均低于 **1.2e-7**，动作在合法范围。一个任务初始即满足 `<0.5` 成功阈值，已在全部和初态未成功子集中分别报告。成功是第 25 步物理位置判定，不是闭环成绩。

向量保留没有优于普通 lookahead；两臂在 7/8 根上选中同一物理末距，在 root 1890 分别为 0.4359 和 0.0313。该结果不支持当前向量规则的独立增量。固定前缀臂超过这次 CEM 的 8/8 对 7/8 只是小样本开发观察：CEM 仅 3×16、4 elite，未经充分调优，且动作生成分布与固定程序库不同，不能说超过强 CEM 或存在公平的完整成本优势。

## 计算与核验

六个规划臂每根各评分 **48 条完整链**，实际动作有界；目标编码单独计时。为防止未评分均值被当作 CEM 选择，CEM 从所有已评分样本中选最低分链。独立选择审计从封存随机种子与每轮分数重建全部 CEM 候选，核对 8 根每臂的预算、共同评分、保留规则及实际选链，全部匹配；重建候选也单独封存。相关新增及既有测试 **6 项通过**。

这仍是 **state-assisted、已曝光、同源目标、开放环**实验，没有证明描述发现机制、RGB-only 闭环、独立泛化或 PC0–PC5 通过。`scientific-critical-thinking` 用于追查前一目标时域、分离初始成功和评价见证，并避免将小预算基线当作充分调优对照。
