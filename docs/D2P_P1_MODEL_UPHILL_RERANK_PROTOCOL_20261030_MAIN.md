# P1 已存候选的模型内非即时进展重选：探索协议

为检查联合终态优化是否把拟议的重配置前缀优化掉，复用此前主机
CUDA 已封存的 8 臂 × 20 候选 × 5 迭代动作、前缀 latent 和终态
latent；不重新运行模型，不以真实物理结果挑候选，不训练模型。
此分析在看到既有物理结果后提出，是事后开发，不是独立确认。

对每个候选的全部五次迭代，计算前缀 latent 到目标的 MSE 和根
latent 到同一目标的 MSE。仅将前者不小于后者的记录视为模型内
“无即时 latent 改善”；在这些记录中以终态 latent MSE 最小为
选择规则，平分按候选索引、迭代索引排序。如果一个臂没有符合
条件的记录，输出 null，不回退到不合格候选。同步记录不受约束的
原终态 winner、可行计数、完整候选分数和动作见证。

该规则不是物理任务非贪心判据，latent 与物理指标已有已知失配；
也未直接测量前缀改变了后续动作响应。未来必须先固定来源、动作、
greedy/zero 对照及物理指标，再进行共同后缀干预和各前缀独立
优化后的真实执行。它也不保证生成的选择优于无约束强基线，
更不能开放 P1。模型预测误差、候选来源成本和独立新根另计。
