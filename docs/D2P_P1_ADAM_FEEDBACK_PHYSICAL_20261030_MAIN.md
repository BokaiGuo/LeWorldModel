# P1 Adam 真实中点重规划与物理回放

在既有结果已知后，针对全部固定 24 条 Adam 轨迹，先保留原前五步，
使用这五步后的真实 RGB 与实际动作历史，在冻结模型上用 Adam
优化最后五步：原后缀初始化，学习率 0.05，20 次更新，动作投影至
[-1,1]；在真实中点的模型评分中，按固定规则从原后缀和优化后缀
选择较低者。主机 CUDA 完成 24 条，模型参数及 buffer 前后哈希一致。
该规则是已知根开发实验，不是预注册的独立确认。

对选择的所有动作进行新的物理回放，24/24 记录完成，保存消费通过；
逐槽核对新旧前五步的实际动作、状态、动力学快照、停止标志和
中点 RGB 像素哈希均相同。RGB 是从既存物理轨迹离线提供，新的
动作再整体重放验证中点一致；这不是现场在线规划。

开放计划原生成功 5 条记录，重规划后成功 1 条记录，均为 zero
前缀；此前根 1/on 的两条成功为同一动作和轨迹的重复，不能计成
独立任务。重规划的唯一成功也对应原计划成功，并非新增成功。
双方均有原合同完整终点的 19 条中，重规划的物体位置、角度、
推杆误差分别有 9、7、8 条下降。任一分支原生停止时，十步端点
差值保持空；成功与停止步数单独保留。因两个已知根、重复动作
与事后设计，不作独立样本统计推断。

这批结果不支持“真实 RGB 刷新加后缀优化必然改善控制”；前一轮
预测均方误差下降也未转化为一致物理收益。新旧路径前五步得到
逐位物理验证，但这不能排除训练 normalizer 来源、任务评分或更
广泛的部署接线问题。该对照增加每行两次编码、22 次预测及 20 次
反向的显式路径调用，未认证全部成本，不能称等预算。它也不能
代替 selected/zero/greedy 的公平强基线、共同后缀机制干预或 P1
独立确认。
