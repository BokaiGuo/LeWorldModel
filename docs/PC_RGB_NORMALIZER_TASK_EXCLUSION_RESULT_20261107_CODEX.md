# TwoRoom 评估任务参与 normalizer 拟合：开发核验结果

按照[事前协议](PC_RGB_NORMALIZER_TASK_EXCLUSION_PROTOCOL_20261107_CODEX.md)，核对了当前实际 normalizer 拟合行，并将 episode 9000–9039 的全部动作从拟合中排除后，使用同一冻结 RGB 模型重新进行真实反馈。

## 来源发现

历史 `model_setup` 对本地 HDF5 全部非 NaN 动作拟合；对照历史 normalizer 的动作字节哈希和均值、尺度均一致。**40/40 个评估 episode 确实包含在该拟合中**，各贡献 53–100 条有效动作，共 **3,798 条**；全量拟合共 910,809 条，排除后为 907,011 条。因而对于这些历史实验，“评估任务未参与 normalizer 拟合”不只是未证实，而是与当前实现记录不符。

| 统计量 | 原全数据拟合 | 排除 40 个 episode |
| --- | --- | --- |
| 均值 | `[0.00309342, -0.05298254]` | `[0.00311434, -0.05313005]` |
| 尺度 | `[0.86754736, 0.86863831]` | `[0.86755077, 0.86863534]` |

这不证明原 normalizer 与 checkpoint 的训练合同相符或不符，也不证明评价 episode 是否参与 checkpoint 训练。新的排除式统计同样没有训练运行绑定；它不是官方复现配置。

## 同任务真实反馈

| 方法 | 原全数据 normalizer | 排除任务 normalizer | 排除式独胜／独负 |
| --- | ---: | ---: | ---: |
| effect | 32/40 | 32/40 | 0 / 0 |
| CEM16 | 31/40 | 31/40 | 0 / 0 |

两臂在 40 个任务中均无轨迹长度变化。effect 的实际派发动作和记录的物理距离逐值一致；但 144 次配对决策中有 5 次候选来源或索引不同，不能说完整选择一致。CEM16 的 128 次配对决策所选索引均一致，但归一化及逆变换改变了动作数值：398 个派发步的至少一个坐标差超过 `1e-6`，最大坐标差约 `3.87e-6`，最大物理距离差约 `2.75e-4`。这些现象与重新拟合数值敏感性一致，不构成两版本逐位等价证明。

本次是已曝光任务的开发敏感性对照，原臂使用先前封存记录；没有进行新模型训练、独立任务确认或描述机制验证。全数据统计参与评估任务这一来源限制必须保留，不能因为本面板成功数不变就升级结果。两项排除和非法输入测试通过；Gymnasium 环境警告仍存在。PC0–PC5 未改判。
