# JEPA 分批评分与选择：小面板开发协议

运行前冻结：沿用先前 JEPA 本地兼容 runner、单帧上下文、seed 1、
5 个任务、CEM 8×2、2 elite、6 packet 一次执行。两臂除每次 unroll
按完整 8 条或 4+4 条候选推理外相同；关闭 decoder，仍使用本地
DINO 兼容 shim，不是完整官方协议，也不是 300×30 的全预算认证。

4+4 臂对每轮实际候选在同一进程、同一输入上额外计算整批模型代价，
恢复并保留原随机状态；逐轮记录成本最大绝对差、完整排序和前 2
elite 集合。以代价差 `1e-4 + 1e-5*abs(reference)` 为预设数值
容差，另报告排序和 elite 是否一致；近并列与边界交换不可隐去。
随后比较独立进程两臂实际执行动作、状态及成功，允许不同并如实报告。
这个有限面板不能外推到 300 条候选、不同 decoder 或其他模型。
