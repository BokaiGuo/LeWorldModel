# 完整池独有链与共同池链：同机会精修开发协议

复用有界条件化完整池审计，固定已暴露 task/solver seed 42、
reset seed 771001、50 个任务。仅对首次规划，在九个后续迭代
中按预先固定的最小模型代价差，事后选择一条相对共同池独有链
及其同轮共同池最低分链；无独有链的任务记为空。选择和精修
均在主规划器 300×10 更新完成后进行，绝不更改主规划器动作。

两条链作为独立的全时域精修起点，共用一个另设随机流生成的
相同 32 条噪声；每臂分开维护均值和标准差，三轮各 32 次评分、
每轮 elite 4、初始标准差 0.25。每轮评分前投影到统一物理
动作域，候选 0 保留当前均值；每臂返回该臂起点及 96 个
评分样本中的最低模型代价链，起点分数已由共同池审计提供，
不重复评分。额外收费为每个有配对任务 192 条完整链，另加
审计的共享候选查询；不声称等成本线上规划收益。

分别保存原始与精修链、成本、随机种子、调用计数和主规划器
最终首链与逐步物理 trace。先通过 50 个任务真实首链
动作／物理状态重放，再在完全相同初态与目标事后执行两条
精修结果，报告全部 50 任务分母、合法性、物理成功和配对结果。
若无独有链、精修错误或 parity 失败不得静默删除。

此开发实验只检验选定起点的同机会精修后果，不证明在线发现、
最终链依赖、动作身份语义、泛化或总体成本优势。共同池最低分
在每轮已知，事后选择的上下文不是独立确认。
