# P1 回溯前缀与真实反馈：探索合同

本合同用于准备已知根上的新探索，不修改旧实验合同，不授权独立确认或
P1 准入。将保留全部八个回溯逻辑臂及重复；不得按成功、误差或收益挑臂。
冻结 PushT 原 checkpoint 与其已有输入、动作归一化、目标图像和原生成功
语义；训练身份与独立根来源不明时明确标记 unknown。不能训练世界模型、
policy、critic 或 adapter，神经计算必须在主机 CUDA 执行。

## 三种前缀与固定后续

同根同目标分别执行模型事先选中的回溯前缀、同长度 raw-zero 前缀及
事先按模型即时目标选择的 greedy 前缀。greedy 不是 incumbent 的别名：
必须以该任务同候选库、同目标、完整选择分数和确定性 tie 规则证明身份。
找不到可验证来源即该臂未定义，不以 incumbent 替代，不开启三臂比较。
前缀及重放后的原生状态、图像、终止与动作原样记录；任何身份不符在后续
动作之前 fail closed。历史 selected/zero 的 outcome 已公开，所以这些根
仅用于开发和机制探索，不是前瞻性独立 outcome。

三臂后继在相同真实反馈机会下使用同一个后缀规划算法、动作域、时域、
预算与停止规则；规划器只能接收 RGB、已执行动作和合法任务目标，
物理 state 仅用于执行身份守卫与事后评价，不能作为 planner 输入。
后缀的模型非线性 rollout 和最终选择及实际执行均留证；不以零点 Jacobian
单独决定完整幅度动作。先把计算计划和故障处理固定再揭示新结局。

已完成的旧四槽真实观察后缀实验是另一组前缀／合同，真实物理
success 0/4 且角度全部受损，不能因为新方法而抹除；也不能把它当成
回溯前缀上的本合同结果。

## 非贪心、能力和收益分别测量

原方案判据为短期**不降低**任务误差，允许持平，并非普遍要求严格变差。
针对新合同，分别保留相对自身初始值、同长度 zero、同库 greedy 的位置、
环绕角度差及原生成功；每项采用原始物理计算，不将 native7（含速度）
代替成功，也不将其中任一个事后改成唯一正式主指标。针对未来正式确认，
须在观察新结果前规定任务标量/合取、对照和数值精度处理；本探索不凭
任选单轴或浮点近零单独宣称非贪心通过。既封存合同的严格条件不因此改变。

对同三前缀后继执行相同的预定动作后缀族，逐动作保留物体位置、角度、
绝对终态、相对各自零后缀的变化和原生成功；记录每侧删失、原生早停，
不可补值。五步小幅坐标探针和与真实执行匹配的十步后缀属于不同尺度，
分开报告，不用局部负结果否定十步接触效果。后缀族必须在看到相应
新物理结果前固定完整内容及分母；不得挑有利方向。固定后缀因果干预
能说明前缀影响某些动作后果，但不自动证明全局可达集扩张或在线策略获益。

## 公平比较与开放条件

后续正式比较至少包含完整 D2P、zero 和 greedy 加同一反馈后缀规划器、
无重配置谱规划，以及原方案列出的 CEM/MPPI、梯度 MPC、GRASP、局部
Gauss–Newton、kinodynamic 等强对照。固定相同反馈次数、执行时域和
停止协议；记录各方法从前缀生成到后缀规划的 encoder、predictor、
action encoder、reverse、时间及峰值内存。不得只匹配后缀成本并忽略
回溯生成的成本，也不能把作者报告数值作为同协议本地结果。
若目前不能实现等总资源，明确标记不匹配，不宣称公平胜出。

完成开发后再另行冻结方法和确认协议，事前规定独立根生成、样本量、
失败/删失与统计规则；开发未见与训练集未见分别认证。当前 checkpoint
训练数据/normalizer 的 authority 和历史 reset 排重范围尚缺，不能标记
训练外或历史独立。通过本合同的工程接线与已知根探索不构成 P1 通过。
