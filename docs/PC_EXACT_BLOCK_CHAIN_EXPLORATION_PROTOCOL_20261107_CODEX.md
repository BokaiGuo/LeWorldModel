# 精确墙障完整链成块探索：开发协议

针对既有 24 个已暴露 wall 开发根，检验覆盖缺口是否能由**全链**时序参数化缓解；不使用解析见证、地图中间点、物理成功标签或固定越墙前缀生成动作。环境动力学为精确评估器，不是视觉模型。

两臂使用相同 15 环境步动作域与目标末距，均计 384 次完整链评分（1152 个五步 token），包括零链。基线为已有逐步完整链 CEM（每批 12、4 elite），新臂使用三个独立五步常值动作块组成完整链，在六维块空间中以相同批量、elite 数、迭代次数及初始标准差运行 CEM。各臂随机流由根编号确定；不以任何事后越墙或真实成功标签选择分布，且都返回已评分最低代价链。每个采样链及分数留存，以确定覆盖和最终选择是否一致。报告越墙候选及根数、选中链成功数（固定原标准末距 <0.05）、逐根差异和总查询；墙钟仅作开发测量，不推断端到端效率。

本实验只比较新的完整链参数化与逐步 CEM，不涉及先前被停止的固定前缀尾部成块扰动；不能称为响应描述贡献。预定开发出口：新臂成功数至少 4/24 且比逐步 CEM 至少多 3 个，同时根级配对成功差为正；不满足则不扩大此具体配置。全部候选不越界、重算分数一致、选中链来自已评分样本和预算正确是结果有效性的必要条件。该开发门槛不是 PC0–PC5 标准。
