# Exact-wall 盲脱困对照：开发协议

本协议在运行盲脱困臂前固定；24 个任务及受阻臂结果已经曝光，因此
不是独立确认。沿用原始 384 个 waypoint 偏移、15 步、终距小于 0.05
的成功标准及末端距离最小选择。每臂每任务 5760 次动力学步。

盲臂对所有候选在第 5 步动作执行后，按照既有候选索引确定的左右方向
和 0.3/0.6 半径插入一次侧向目标；不以受阻与否决定触发。采用相同
逐步伺服和动作上界。比较已保存的受阻触发及无脱困同伺服臂。
验证所有动作合法、与无脱困臂前五步一致，并逐链重放。计数仅涵盖
模型动力学步，验证重放另外列出，不声称墙钟相同。

开发出口事前固定为：受阻臂相对盲臂至少 3 个任务独胜且至多 1 个
独负；未达到则不能把先前提升归因为受阻触发优于此盲策略。该规则
不是 PC gate。盲策略仅有一个固定时刻，不代表全部非响应策略的上界。
若达到也只支持已曝光的精确状态与精确动力学中的局部对照，不证明
行动后果描述、视觉闭环或独立泛化。
