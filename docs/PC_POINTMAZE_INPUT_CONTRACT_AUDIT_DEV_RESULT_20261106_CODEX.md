# PointMaze 输入封装：标准化和视觉编码接口核验

针对已封存的 1892–1899 开发面板，复用实际 GPU 模型及输入，检查 16 个当前图像／原始完整 proprio。该实验只检查本地兼容封装，未访问候选真实后继，不测试闭环成功。

`encode` 自行使用 preprocessor 对原始 proprio 标准化；实验调用方传原始物理状态而不是预先标准化状态，接口方向正确。将封装内部 proprio 输出与“手工标准化一次后调用 proprio encoder”比较，16 个视角最大差为 **0**。相同图像经视觉-only 入口和多模态入口的视觉特征最大差为 **0**。故未发现该面板上的重复标准化或两个入口视觉特征空间不一致。

反向检查显示，若错误地在外部先标准化、再传入该封装，所有视角的 proprio 特征都会改变，最小最大元素差约 **0.5253**。因此不能为了修复此前负结果而再做一次归一化。这是接口诊断，不是证明现有编码、训练统计、预处理或兼容分支完整等价于官方实现。

脚本 `le-wm-main/experiments/pc_pointmaze_input_contract_audit_20261106_codex.py` 验证了原封存输入与模型指纹、GPU 运行前后模型指纹；逐任务结果在 `le-wm-main/results/pc_pointmaze_input_contract_audit_20261106_codex.json`。相关测试 6 项通过，包含纯合成接口测试；不能把测试通过当成模型控制成功。本实验属于 state-assisted 开发，PC0–PC5 不改判。
