# 多名义响应 RGB 固定终点开发协议

结果前固定。沿用 `PC_FIXED_TERMINAL_FAIR_FEEDBACK_DEV_PROTOCOL_20261103_CODEX.md` 的四个已暴露根、冻结模型、真实 RGB、动作历史、MuJoCo 后端、反馈时刻和每决策 480 个五步预测 token。15/10/5 步对应同一执行终点；已有尾部先在新观测下重评分并计费，较优时保留。

比较六臂：完整响应 SVD、数学等价岭求解、同名义动作不加响应、同名义随机扰动、响应候选同库即时 greedy、完整时域 CEM。两条名义前缀分别为每步 `(+.25,0)` 和 `(-.25,0)`，另加 zero。响应每名义 21 次五步模型预测；随机扰动固定种子、每点最大分量 0.5。响应与岭各自计入两次分解/求解及时间，生成预测从相同 480 token 扣除；这不是等总 FLOPs。

15/10 步：除 greedy 外各候选均分配剩余完整链样本的 3/4（向下取整）；greedy 仅选择同库即时前缀评分最优的一条，剩余预算遵守同一比例。每条候选用相同 CEM，多批采样、保留最佳；剩余 1/4 用完整动作 CEM 从已选择完整链初始化联合精修，始终保留精修前最优链。zero 也是候选，不强行选响应前缀。5 步时先给候选评分，再用剩余资源从当前最佳完整动作初始化同一联合优化。CEM 臂将全部剩余预算用于完整动作 CEM；所有臂共同采用 12 样本批次和精英规则。最终以完整链模型分数选取，并与重新评分的旧尾部比较。记录实际最终选择的动作，不能把精修前机制资格转移到精修后。

真实动作执行后单独物理重放；计划、候选、资源、链及哈希先封存。四根是开发样本，不用于独立推断或改 gate。此版本仅检验多名义初始化加完整优化的 RGB 接线与开发效果；没有跨后继响应程序组合、PC2 干预或完整计算公平认证。SVD 与岭分支等价，不能以两者一致判实现失败或宣称 SVD 独立增量。
