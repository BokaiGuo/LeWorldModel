# PushT 目标图局部时间与目标标记：开发性探查

> 本协议首次执行的输出无效：姿态修改后未刷新 Pymunk shape 索引，画面可能仍为 reset 状态。保留数据供代码审计，不用于时间对齐推断。

复用上一次重绘审计的 50 个已曝光目标数据行，固定使用对应目标前后 `-2,-1,0,+1,+2` 个数据行的物理状态，仅限同一 episode，分别设置到相同环境的渲染姿态，不推进物理。对于每个姿态渲染目标标记开启、关闭两个图像，与固定的原目标图计算逐像素平均绝对差、最大差和完全相等标志；记录每行数据索引与越界原因。所有重绘均只用于评价端，不能作为 RGB-only 规划输入。

对每个目标报告各偏移和开关的配对误差，并计数相对同偏移标记开启的变化，以及固定开启标记下最小误差对应偏移；平局全部保留。多次比较属于探索性定位，不定义任何正式验收阈值。邻近状态更接近不证明数据具有时间错位，因为物体运动、遮挡和渲染差异均可能造成同样现象。

记录输入源哈希、渲染环境实现哈希、版本、姿态回读误差及输出；保留此前目标重绘结果，不覆盖、不重估 gate。
