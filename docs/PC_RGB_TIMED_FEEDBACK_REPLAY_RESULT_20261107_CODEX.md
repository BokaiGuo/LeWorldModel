# RGB 时钟历史接线复验（开发）

## 范围

在已暴露的 PushT root 0 上，将现有 RGB 反馈 CEM 的模型调用通过新适配器接入严格时钟历史边界，保留原生成器、预算、随机种子、模型、normalizer 和环境初始化。每完成五个实际派发动作，记录观测时钟和动作历史；旧运行结果只在新 episode 完成后读取比较。

这是单任务接线复验，不是新方法、独立性能比较或 PC4 通过证据。历史时钟和动作仍由调用方声明；本适配器不是防恶意访问的隔离环境。

## 验证

针对缺失绑定、历史改变、候选中历史前缀不一致、非法时钟、空未来及动作梯度建立测试；与原严格历史接口测试共 14 项通过。实现前确认新测试因适配器不存在而失败。

真实 checkpoint GPU 运行完成三次规划，实际时钟依次为 5、10、15 步。三轮中，与封存历史臂逐轮比较：

- 被选中的完整归一化动作链最大绝对差均为 0。
- 真实派发动作最大绝对差均为 0。
- 两个最终候选的模型代价最大绝对差均为 0。
- 绑定历史 receipt 与旧运行相应三次模型查询记录一致。

适配器调用原有 `score_future` 时验证每个候选共享的历史前缀，再把未来动作交给 `TimedHistoryRGB`；模型权重运行后经完整摘要复核不变。原运行文件没有改动。

## 限制

一个已暴露任务上的数值一致不能证明所有初态、设备或长轨迹等价；也不能证明当前评分与物理成功一致。该复验没有测量新增开销的竞争性，不证明反馈带来收益，也不改变 PC0–PC5 判定。结果保留在 `le-wm-main/results/pc_rgb_timed_feedback_replay_20261107_codex.json`。
