# 几何候选首轮物理与编码对齐：开发协议

固定既有 V2 的全部 40 个已曝光任务，每任务取模型臂首轮的完整
16 条动作链；对同一初态分别重放全部动作 25 步，不按成功筛选。
重算冻结 LeWM 每 5 环境步的预测表示与评分；在真实执行的第
5、10、15、20、25 步重新渲染并用同一冻结编码器编码。即使中途
成功也继续评价到第 25 步，并单独记录 25 步内曾成功、首次成功时间
与各步物理距离。重放只做评价，真值不可供选择器使用。

统计每个任务的候选成功数量、模型选链与固定几何链的物理成功、
最小预测代价与最小真实编码代价，以及预测、真实编码和真实最小距离
对候选成功/失败的任务内配对排序。任务内所有跨成功/失败对先汇总为
该任务的正确率，再对有可区分对的任务等权汇总；平分视作 0.5，不将
相关候选对当独立任务。无成功/失败差异的任务单独计数。

此对照只回答这些给定、事后已曝光的几何候选中信息是否有辨别能力；
不能宣称未查询组合泛化、描述贡献、闭环优势或独立确认。任一步的
预测/真实表示和目标时钟必须严格对齐；允许浮点误差但重算的每个
候选最小评分应与 V2 原始记录满足 `rtol=1e-4, atol=1e-3`。
