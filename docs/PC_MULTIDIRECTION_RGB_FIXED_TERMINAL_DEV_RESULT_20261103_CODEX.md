# 多方向编译器固定终点 RGB 开发结果

依照[事前协议](PC_MULTIDIRECTION_RGB_FIXED_TERMINAL_DEV_PROTOCOL_20261103_CODEX.md)，
在四个已暴露 PointMaze 开发根分别运行多方向编译器和单配置 CEM；每臂
使用各自真实 RGB 反馈，执行热身后的固定 15 步。首轮使用多方向后继
编译器，后两轮使用同一版本的剩余时域反馈入口；后续 10/5 步并非两层
后继组合搜索。下表终距来自执行动作的原生后端事后重放，较小为好：

| 根 | 多方向 | CEM |
|---:|---:|---:|
| 0 | 0.19710 | 0.14662 |
| 1 | 0.08797 | 0.05480 |
| 2 | 0.05638 | 0.43373 |
| 3 | 0.04875 | 0.11549 |
| 平均 | 0.09755 | 0.18766 |

两臂各在两根上终距更低；平均差值受到根 2 较大差异影响。四根均已暴露，
没有独立样本或统计确认；此 CEM 只是单配置对照，不能据此宣称强基线
优势或谱结构增量。预测所用目标投影不是物理真值；上表是后验物理重放，
不反馈给规划器。重放核验的是已封存动作和同后端物理轨迹，尚未证明
重放中每一物理状态与原 RGB 执行逐位相同。

多方向每次决策实际消耗分别为 478、480、480 个五步预测 token；
CEM 为 480、480、480。分解、编码及其他计算未合并为同一成本轴，
因此不能宣称总成本相等。逐批预测动作和分数、决策图像与动作绑定、
执行图像、carry 和源码哈希已保存；独立脚本检查每批及总 token、
图像时钟、选中动作与实际派发、carry 和当前源码哈希，再执行物理
重放。计划值与模型 float32 输入最大舍入差约 `2.97e-8`；该数值是
动作数值差，不代表物理结果误差上界。预测 token 不是完整资源认证。

这完成了此版本在暴露根上的 RGB 接入和一次受控开发运行，不证明 PC2
事前同链机制、PC3 独立强基线优势、PC4 长时域收益或 PC5 泛化。
normalizer 拟合成员与 checkpoint 训练来源边界仍按既有记录保留；
不以新 seed 替代独立性。该单配置结果保留，不后验追加根或调参。
