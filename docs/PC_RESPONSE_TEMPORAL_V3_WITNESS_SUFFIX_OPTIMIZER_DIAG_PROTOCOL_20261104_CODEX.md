# v3 根 20 固定前缀充分后缀优化诊断协议

此前事前机制协议仅给每个前缀 120 次评价的单次零初始化 CEM。
选中尾部本身的终距 0.10883 而 selected 重新规划仅 0.37898，提示
优化可能不足。为区分前缀质量与单次搜索限制，事后固定根 20 的
五类已封存前缀与同一真实起点，不重新选择根、前缀或方法。
本诊断不能提升该事前见证的统计或来源独立性，也不是完整方法
同预算比较。

每个前缀使用相同 CEM，完整链评价数固定为 120、480、1920，均
包括各自一条初始尾部评分；每个预算使用 3 个共同种子，每种使用
4 和 8 个等间隔动作时间结点、种群 12、精英 4、初始标准差
0.35、标准差下限 0.07 和跨代 incumbent。两类起始尾部分别为零，
和该根事前 selected 链的后十步；后者对五个前缀完全共享，仅作
候选质量干预，不进入正式方法。各自独立运行所有预算、起点与种子，
总计 5×3×3×2×2 次优化、151200 次完整链评价。

每次保存实际 float32 动作、预测终点、终距、逐代分布和计数；
封存后逐批重新计算。按预算、结点、初始化分别列五类前缀的三种子
终距，及 selected 对每个对照的逐种子胜数。比较质量—评价次数，
不能将不同预算累计成正式方法成本，也不能事后挑有利配置声称
机制稳健；缺少梯度或更强全局搜索时不得称 CEM 全局上界。
