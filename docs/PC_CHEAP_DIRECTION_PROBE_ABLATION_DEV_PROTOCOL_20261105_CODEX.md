# 低调用方向：探针与编辑归因开发协议

前序开发结果显示 32 次低调用运行有 21 次直接以探针为精修起点。本实验在结果已暴露后制定，属于针对性开发消融，不是未见数据确认。

沿用相同 16 根、两随机流、父链、六条探针、动作域与 CEM。probe-only 保留父链及六条探针中的最佳链，不构造 12 条方向编辑；fixed 继续使用 84 次精修，total 则把省下的 12 次完整链评分交给同一 CEM（150 次），使总预算为 157。与此前 cheap_fixed（103 次）和 cheap_total（157 次）逐根逐随机流比较，前者控制相同精修机会但总成本不同，后者控制相同 prediction tokens 但优化机会不同。每次完整链 3 tokens，所有真实探针参与 incumbent。不得解释为测得独立泛化、机制或总系统成本优势。

报告起点与最终终距、成功数、根级配对差、实际 token 和外部同口径计时。逐调用记录，并在事后重放父链、已评分最优与预算；目标、父链和数据来源仍已暴露。PC0–PC5 不变。
