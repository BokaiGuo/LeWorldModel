# PushT 本地验证数据固定窗口可行性筛查协议

目的：寻找后续受控视觉开发任务的候选来源，不评价规划器或模型，也不认证 checkpoint 训练外、normalizer 外或开发外来源。

对本地 `pusht_noise/val` 每一条序列，固定截取状态索引 10 至 25（含端点）和动作索引 10 至 24；不搜索其他时间窗口或替换失败序列。固定报告总数、数据不足数、物体在端点的欧氏位移、角度变化、agent 与物体中心是否整段都在 `[40,472]²`、动作是否有限且缩放后逐坐标在 `[-1,1]`。开发筛查的候选条件预设为：数据长度至少 26、有限数值、物体端点位移至少 20 像素、整段中心合格且动作合格；同时列出每项独立失败原因和全体分母。

`states.pth` 与 `rel_actions.pth` 的索引对应、RGB 可用性、实际物理重放、完整几何体可见性、目标可解性及来源独立性均未由此筛查认证。参考动作若用于构造目标，只能作评价端见证，不得泄露给正式规划器或用来构造正式候选。需另行冻结候选、任务、物理重放及模型评分协议，再运行任何后续面板。
