# Five-prefix coherent own-suffix development comparison

Known translated root, five fixed actual prefixes (structured, native, random,
immediate_progress and zero). Use the actual step-5 RGB from each corresponding
common-tail intervention branch. No future image, future action, physical
outcome, state value or witness action is available to the optimizer. Physical
state is hashed solely as a prefix-identity receipt.

Each prefix gets its own frozen-model encoding and the same coherent structured
H3 node, six full-action updates, identical Q, budget and candidate rules. Its
context contains the target receipt's last two warmup latents and its own cp5
encoding. Its two action packets are the actual last warmup five and prefix
five, normalized by the frozen original normalizer.

The incumbent is explicitly a predefined hold reference: actual prefix followed
by fifteen zeros. It is not a previously selected model plan. Each of the five
encodes has a separate durable charge; each node uses the unchanged H3 node cost.
The selected suffixes are open-loop model proposals, not physical outcomes.

This is a post-outcome, known-root, exploratory capacity comparison. It is not
independent confirmation, fairness proof, a P1 admission, or evidence of a
stronger physical controller. Subsequent physical execution is separate.
