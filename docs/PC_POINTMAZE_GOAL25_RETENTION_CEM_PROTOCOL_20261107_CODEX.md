# 同源第 25 帧目标：固定前缀与 CEM 开发比较

上一保留面板目标是同根第 5 帧，不能代表长距离任务。本实验保留曝光的 1884–1891 八根，将每根 0 帧作为初态、25 帧作为目标，固定 25 环境步规划与执行时域。归档原始动作 0–24 仅放入评价端私有见证，不提供给任何规划臂；重放时必须逐根报告动作合法性、末态与归档目标状态误差、是否实际到达。目标图和完整目标 proprio 在 state-assisted 轨道可用。

各臂输入同一归档帧 0、归档帧 25、当前和目标 proprio、同一冻结模型，context window 2、相同多模态末点目标。五个固定前缀保留臂及其父链/A/B 库沿用前一协议，分别独立评分 48 条完整链。另增 48 次评分的开发 CEM：3 轮各 16 个完整原始动作链，4 elite，初始均值零、标准差 0.5，动作裁剪到 `[-1,1]`，每轮第一个是当前均值；采用全部已评分样本中最低分的合法链，避免返回未评分均值。CEM 的随机流按任务预定，并记录每轮分数、选链、实际 batch 和同步时间。它不是已调优强基线，方法间采样分布不同；这只是等评分次数的开发比较，不能作为完整成本或公平调参结论。

在任何物理结果或见证动作被读取前封存所有臂选链。然后用原始 float64 初态和已封存的选链做物理重放；另外重放 25 步归档见证与 25 步零动作作为评价对照。完整保存时间轨迹；记录初态、末态和曾达到 `<0.5` 的结果，按全部任务和初态未成功分层，初态成功不能算控制增益。固定候选、生成器和目标均为已曝光开发资产，不能计入独立确认。

本实验检验更长目标条件下同一批候选能否兑现真实控制，并检查归档动作合法见证；不宣称 PC2 机制、最强 CEM 对比、闭环、RGB-only 或 PC0–PC5 通过。
