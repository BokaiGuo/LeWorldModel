# Wall 多样性程序与完整时域 CEM 开发对照

此协议在因子实验结果揭晓后制定，仅限八个已暴露精确动力学任务的事后开发比较，不是独立 PC3。分别使用完整链评价 1145、2169 次，对应多样性程序在 128、256 后缀预算下每臂的 33 次筛选加 8×(11+预算) 次评价。每次评价均为 16 步完整链；额外多样性距离运算、重放、墙钟和硬件费用单列或标未知，不声称等总算力。

完整时域基线使用已存在 `pc_wall_response_side_20261103.plan` 的 flat CEM：16×2 全动作自由变量，四起点、四轮、同任务随机种子、精英和动作约束按其实现；以指定评价次数为硬上限。基线不使用程序候选、解析解或手工路径；不增加特权几何输入。固定预算不跨预算嵌套，记录所有实际得分、动作及逐步轨迹。对比原封存 diverse_original 与 diverse_stratified 两臂，报告每根配对终距、阈值成功与评价预算；不得据此修改原结果或宣称所有强基线公平。
