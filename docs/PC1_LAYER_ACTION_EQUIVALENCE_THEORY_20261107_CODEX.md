# 逐层动作后果等价性：条件、证明与实现边界

本文件落实用户新增理论附件，结论是固定支持集上的条件性数学事实，不是 OSFAL 的世界模型定理，也不是当前模型已通过 PC1 的声明。

固定目标 g、时域 H、合法且等时长的有限动作集 U={U0,...,Um}，真实代价 J*(s,g,U) 与相对后果 D*(s)=(J*(U0)-J*(Ui))i 定义行动后果等价。它只比较当前目标和动作支持；D* 相同不保证绝对价值相同，不保证未查询动作等价，也不是全局 bisimulation。

## A. 有限域可读出性

在给定有限样本域上，确定函数 q(h)=D* 存在，当且仅当 h 相同的样本具有相同 D*。必要性来自函数单值性，充分性来自在每个特征等价类上赋唯一标签。若样本特征全部不同，这个条件总成立，因此实际有限样本上“没有精确碰撞”几乎不能说明泛化、稳健性或可实现预测质量。

完整 token hidden state 经确定性后续层演化。如果完整状态完全相同，后续层不能将它们重新区分。**中间 CLS 相同不等于完整 hidden state 相同**；patch token 可保留区别。任何 pooling 或归一化指标下的接近，也不是精确不可辨识性证明。

## B. 混叠下界

令真实描述差为 Delta=||D1-D2||inf。两个完全相同特征必须得到同一读出，三角不等式给出 max(e1,e2)>=Delta/2。

若特征距离至多 delta，读出在该度量下为 K-Lipschitz，则
Delta <= e1 + K delta + e2，
故 max(e1,e2)>=(Delta-K delta)_+/2。没有实际成立的 K 上界，不能把小特征距离直接代入并宣称模型误差存在正下界。当前实验不会估造 K，亦不会将像素近似或 CLS 近似替代完整状态碰撞。

## C. 选择稳定性

在同一有限候选集、相同真实与预测代价单位下，若 max_U |Jhat(U)-J*(U)|<=epsilon，则对预测最优动作 Uhat：
J*(Uhat)<=Jhat(Uhat)+epsilon<=Jhat(U*)+epsilon<=J*(U*)+2epsilon。
唯一真实最优动作的间隔严格超过 2epsilon 时，各满足该误差条件的视角选中该动作。视角一致但共同选错构成反例：一致性本身不控制真实 regret。

latent L2 与物理距离不是同一单位；本实验不直接相减以估计物理 epsilon。排序、符号、物理 regret 分开报告。预测表示与真实编码的误差只在同一特征空间内测量。

## D. 两段程序

对同一有限 B×Q 全链集合，min 算子为 sup 范数 1-Lipschitz，故每个 B 的预测与真实有限库机会误差<=epsilon，选择 B 的有限库 regret<=2epsilon。

**必须修正附件中的支持范围歧义：**若 O* 的最小值覆盖所有合法 Q，而误差只在已查询有限 Q 上成立，上述结论不成立。需要让两侧最小化使用同一支持集，或额外控制库外优化间隙。自适应生成、未查询动作和闭环还需额外覆盖保证；本命题不能证明它们。

实现测试覆盖 CLS/完整状态反例、共同排序错误、混叠下界、固定支持 regret 界、库外最优反例、正交等距性和秩亏。通过这些测试是数学实现校验，不是模型实证通过。
