# 结构化前缀：同动作预测与真实 RGB 误差

按 `D2P_P1_RESPONSE_CP5_SAME_ACTION_PROTOCOL_20261031.md`，对固定
16 行中的 13 条完整十步后缀，在主机 CUDA 重放物理执行过的原始
动作；2 条 cp5 前越界、1 条后缀中越界，均不构造终点。规划器
预测分数重放通过 `1e-5` 容差检查，真实 cp5、终端动作、图像、
物理状态和先前消费结果完成绑定。保存 latent 的五类距离使用
独立 NumPy 路径重算，容差 `1e-6`。

13 条开放十步预测与真实终点 latent MSE 的均值为 **0.26404**；
从真实中点 RGB 和实际前五步动作刷新上下文后，后五步预测到同一
终点的 MSE 均值为 **0.08100**，13 条中 10 条下降。这里同时改变
了观测与预测时域，并非反馈带来控制收益或单独因果归因。

同 slot、条件和 arm 的即时种子与第二个多样前缀中，5 对双方均有
完整终点。预测与真实 RGB 目标距离的前缀间排序在开放预测中
反转 0/5，在中点条件预测中反转 1/5；不应将旧实验的反转比例
套用到本面板。真实 RGB 距离与物理终点位置、角度、推杆及联合
XY 误差的排序反转分别为 0/5、2/5、2/5、1/5。使用的是各自
规划的不同后缀，因而它们不是共同动作机制干预。两个已知根、
多重共享动作以及删失使上述计数不构成独立样本统计。

结论仅为：这批动作的重放分数与规划分数一致，短时真实观测条件
下平均预测误差更低，而任务指标仍可能与编码距离不一致。它不能
排除共享模型实现错误、训练 normalizer 来源缺失、未测试的接口
问题，也不能证明 P1、完整等预算优势或训练外泛化。目标仍需
共同后缀干预、可执行候选生成和独立确认。
