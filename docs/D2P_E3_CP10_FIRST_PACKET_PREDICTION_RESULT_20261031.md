# E3 cp10：四臂首包的模型与真实反馈

按事后诊断合同，在主机 CUDA 对两根四臂实际执行的首五步动作
进行预测，并编码各自真实第五步 RGB。输入保留对应根的初始
latent 历史、实际两包历史动作、目标编码和动作归一化；报告、
保存检查、首包动作和实际帧逐项绑定。

第五步八条均未原生成功。根 0 的四个首包按模型与真实编码目标
距离的排序一致；根 1 中模型首选 immediate-progress，真实编码
首选 random，二者排序反转。但物体、推杆和完整任务判据并不等价：
根 1 random 的物体更靠近目标，而推杆不如 immediate-progress 近。
两个根是开发任务，四动作并非独立任务，不能推断总体准确率或
把这次反转直接归因某一个代码错误或理论问题。

这是同一初始根下的首包诊断；实际执行器按三包终态评分并滚动
反馈，**首包排序不是原选择器优化目标**，不能据此断言选择器
选错，也不能把真实物理状态输入规划器。完整模型调用 8 次图像
编码、8 次动作编码、8 次预测；没有新物理执行或训练。

独立 NumPy 保存向量复算通过，目标与错误根测试及损坏向量／
角色拒绝共 5 项通过。原生环境成功及物理误差按保存状态重算；
这不替代完整物理事件链重演、独立根或公平总预算验证。P1/E3
仍未通过。
