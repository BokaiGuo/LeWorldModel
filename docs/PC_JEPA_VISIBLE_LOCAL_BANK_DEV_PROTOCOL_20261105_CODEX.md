# PushT 可见目标与局部动作库：开发诊断合同

## 目的和权限

在参考动作产生的目标中心位于画布内时，比较冻结模型预测评分和真实末帧编码评分能否从一个固定动作库选择物理成功动作。动作库包含参考动作附近的扰动，**属于特权条件化评估库**；不能用作正式规划输入、自动发现结果或预算内 oracle。所有 64 条均直接由模型评分，不是未查询动作预测。与前一随机面板不同，这是按观察结果提出的开发版本，不是独立确认。

## 固定设计

- 四个 root seed `2026110621` 至 `2026110624`；物理后端、10 步 warmup、历史、15 步时域、normalizer、冻结模型、成功判据与上一面板一致。
- 每根共享同一个由 `default_rng(2026110620)` 事先生成的参考链与固定评估库：三个 5 步 packet 恒值；参考每坐标均匀 `[-0.12,0.12]`；32 条邻域候选在参考 packet 参数上加独立均匀 `[-0.01,0.01]`；32 条全局候选每参数均匀 `[-0.2,0.2]`。全部裁剪到 `[-1,1]` 并转 float32。拒绝完全相同的动作；参考链自身不进入模型查询。
- 对每根从同一初态独立执行全部 65 条；目标取参考链末帧。根合格规则事前固定为目标 agent 与物体**中心**的横纵坐标都在 `[40,472]`；这不是完整形状可见性证明。所有根均记录，未合格根标记并计入拒绝分母，不替换、不随成绩筛选。全部 64 个候选均评分与报告，包括中心不在范围内者。
- 检查候选中成功／失败数，按全库和局部／全局各子库单独报告预测首选、真实编码首选的成功和首个成功的排名；任何子库无成功则相应排名为不可识别。目标物体位移、画布外候选、所有根及动作计数必须保留。候选不是独立任务。
- 预测全部固定后读取真实末帧；参考动作、物理状态和成功标签只供评价。物理重放验证目标、历史和候选；与同一后端重放不等于独立实现。封存依赖、模型 worker 回执和原始数据。

该设计只验证一个构造分布上的评分选项，不可推出接触能力、实际规划或训练外泛化。四根可能没有足够物体运动；不改变 PC0–PC5。
