# 四臂真实反馈：模块调用核验合同

使用既有 root 0 的四臂共同后缀执行链和原有同频真实 RGB 反馈；
目标仅为在每个规划节点独立记录 predictor 和 action encoder
模块的前向调用数，与该节点账本的已完成声明调用逐项核对。
每个节点在开始及结束同步 CUDA 后计墙钟时间；报告包含核验和
日志开销，不等于无干扰的纯 GPU 运算耗时。每个节点检查完毕才
执行该节点动作；任何不一致或钩子错误导致当前执行失败关闭。
所有臂及其已有资源上限保持原合同，不据此宣称等总预算或
强基线；实际调用类型不加权合并，也不要求浪费计算凑齐。

这些 hook 仅观察两个指定模块的调用，反向、编码器、模块外
工作、数据传输、额外进程和总成本没有独立覆盖；不能把
账本一致解释为公平、隔离或完整计费。冻结模型，主机 CUDA，
不训练，不使用 CPU 进行神经推理。结果为已知根探索，不打开 P1。
