# 相机预处理分歧保护：开发外推协议

目的：检验 raw 和目标图像居中产生不同决策时，选择预定零动作是否能限制此次观察到的退化。规则只使用同一当前图像的模型评分，不使用物理标签或另一相机观测；它是保守动作，而非安全保证，也可能拖慢或阻止任务完成。

固定任务 1884–1887、帧 0 的当前状态和帧 5 的目标，两个既有相机平移，动作 zero、+0.1、-0.1、每个执行 5 步。此前这些任务已有研究暴露，此试验仅为额外开发外推，不能称为独立确认。目标 RGB 定位失败必须整体记录为拒绝，不得排除任务或无提示回退。

固定四臂：raw、centered、disagreement_guard（两个选择相同时采用该动作，否则 zero）、always_zero。模型评分和选择先封存，物理标签后置读取。报告每任务、每视角物理遗憾及变化、分歧频率、跨视角选择不一致次数和完全任务分母。guard 的模型查询成本为 raw 与 centered 之和，不能将每臂单独计时当作完整系统成本。

预定开发出口：所有任务完成几何合同；guard 平均遗憾不高于 raw 和 centered，且没有任务的两视角平均遗憾同时比两者更差。不达标则停止此固定 guard，不以改阈值或者新增 seed 挽救。无论结果如何，此试验不是闭环、PC gate 或 RGB-only 证据。
