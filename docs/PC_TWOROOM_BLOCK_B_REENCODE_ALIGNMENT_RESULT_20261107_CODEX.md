# TwoRoom 分段 B 池：模型、真实编码与物理后果对齐

按 `PC_TWOROOM_BLOCK_B_REENCODE_ALIGNMENT_PROTOCOL_20261107_CODEX.md`，
对已曝光的 10 根、每根 64 条同一动作链重新计算预测表示，重放物理
执行并编码真实末帧。目标图像、时钟、动作与冻结模型均绑定原实验。

| 根内指标，10 根等权平均 | 结果 |
|---|---:|
| 预测分数与真实末帧编码分数 Spearman | 0.708 |
| 预测分数与真实末距 Spearman | 0.121 |
| 真实末帧编码分数与真实末距 Spearman | 0.131 |
| 预测 latent 与真实编码 latent 的均方误差 | 0.1434 |

直接查询全部 B 的模型最低分链曾成功 8/10；以事后真实末帧编码分数
选择也为 8/10，两个方法在 5/10 根选择完全相同的链，成功和失败根
相同。候选池曾成功上限为 9/10。真实末帧是评价端 oracle，不能作为
规划器输入或免费用于在线选链。

这些观察表明本面板的平均排序在预测分数和真实编码分数间较一致，
而它们与物理末距的关系均较弱，值得优先检验目标编码/任务度量的对齐。
这**不能排除动力学误差**：预测与真实 latent 仍有误差且逐根差异明显。
另外末距与「25 步内曾成功」是不同目标，不能仅凭末距相关性判定成功
规则或评分必然有错；这也不是改变正式优化目标的依据。

## 实现核验与边界

- 在读取真实末帧之前，重算并封存全部 640 条模型预测；模型代价与原
  B 池记录逐项一致。全部 640 条物理链的每一步距离与终止标志均与
  原记录一致；逐根初态 RGB 重渲染与数据帧的最大通道差为 0 或 1。
- 同实现审计重编码 192 张固定真实末帧和三个目标图，latent 最大误差
  0；预测 latent 和目标的平方距离与模型代价最大差 `6.1035e-5`。
  相关单元测试 4 项通过。该审计未使用独立模型或环境实现。
- Gymnasium 仍提示 reset 观测类型与动作转换警告；本结果不构成环境、
  数据独立性或官方来源的完整认证。
- 原始预测、末帧、真实 latent、每根指标和审计文件前缀为
  `le-wm-main/results/pc_tworoom_block_b_reencode_alignment_20261107_codex`。
  任务来自已暴露开发集；PC0–PC5 不改判，也未证明描述或闭环收益。
