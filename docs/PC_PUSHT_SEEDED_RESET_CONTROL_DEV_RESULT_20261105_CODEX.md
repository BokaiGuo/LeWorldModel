# 固定环境 reset 的开发对照

按 `PC_PUSHT_SEEDED_RESET_CONTROL_DEV_PROTOCOL_20261105_CODEX.md`，
50 个 seed 42 任务使用共同 reset 基础种子 771001。评测前执行的
单任务 smoke 验证了入口可运行；首次启动曾因 Hydra 配置路径、
随后一次因沙箱 GPU 不可见失败，均未产生正式评测结果，修正后
从新路径运行。

| 方法 | 成功 / 50 | 评分预算 / 次规划 |
|---|---:|---:|
| 原生 CEM | 47 | 300×10 |
| 原生 CEM 重复 | 47 | 300×10 |
| 内部响应替代 | 42 | 300×10 |
| 匹配随机方向替代 | 43 | 300×10 |
| 均值选择 | 47 | 300×10+1 |
| 已评分样本最优 | 46 | 300×10+1 |
| 均值与样本共同评分 | 45 | 300×10+1 |

原生两次逐任务成功标记完全相同；原生对响应有 5 个仅原生成功、
0 个仅响应成功，原生对随机为 4、0；响应对随机为 2、3。
共同评分对均值为 1 个仅共同评分成功、3 个仅均值成功。
均值、样本、共同评分三臂首次 50 个环境的候选与代价逐项完全一致；
后续重规划状态可能不同。评分数相同不表示完整成本相同。

这是已知开发面板、单任务随机流与单个环境种子设置，不能推断总体
统计优势或独立确认。显式 reset 避免本地审计发现的无种子初始化
不一致，但未认证上游等价，也未证明参考动作严格合法或逐步物理
回放一致。真实逐步轨迹与反事实重放另行验收，PC0–PC5 不改判。
