# v7 PushT 单根真实 RGB 闭环：开发协议

复用 v5 已暴露 PushT episode 0、原冻结模型、公开动作统计、同一合法目标、官方环境和观测 guard。暖身 15 步后运行 v7 response 三轮，规划固定终点剩余 15/10/5 步、各执行 5 步；两条二维 nominal 与 v7 Reacher 一致。每次规划以本臂自己的真实 RGB 和动作历史重新编码，保留 carry、全部请求和实际动作、候选、评分、配对弃权与派发事件。两种 TF32 设置均关闭，保留旧结果不覆盖。

每轮预测 token 上限 1920，包括 v7 最终同批比较；单独报告编码、SVD、同步时间等尚未完整认证的其他成本。依赖清单包含 v7/v6 核心、动作变换、数据、模型与运行器，并在执行前后检查。对于 guard 拒绝、环境终止或其他异常，封存停止与部分事件，不把其作为成功。

事后按实际 30 条动作逐条以相同官方后端重放，核验状态、RGB、终止标记与四个上下文；对每个保存预测批以显式 packet 展开重算，检查同批最终选择、float32 转换和预算。分别报告物体位置、角度、官方成功、latent MSE，不用模型分数代替物理成功。与旧版和已暴露 CEM 只作开发背景，不声称独立泛化、强基线优势或 PC gate 通过。
