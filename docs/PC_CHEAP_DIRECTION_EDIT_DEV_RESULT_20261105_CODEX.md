# 低调用任务方向修改：E0 开发结果

按[事前协议](PC_CHEAP_DIRECTION_EDIT_DEV_PROTOCOL_20261105_CODEX.md)，在已暴露的 16 根、每根两个预定随机流上执行八臂，共 256 次。低调用方法每个片段使用一组双向随机方向割线；它不是完整响应矩阵或自动微分 VJP。32 的分母为根×随机流，不是 32 个独立任务。

| 比较 | 方法 | 平均最终终距 ↓ | 成功 / 32 | prediction tokens |
|---|---|---:|---:|---:|
| 固定精修机会 | 低调用方向 | 0.36034 | 1 | 309 |
| 固定精修机会 | 完整响应 | 0.35065 | 4 | 471 |
| 固定精修机会 | 随机编辑 | 0.36301 | 1 | 291 |
| 固定精修机会 | 直接 CEM | 0.35580 | 3 | 252 |
| 等 token | 低调用方向 | 0.33178 | 7 | 471 |
| 等 token | 完整响应 | 0.35065 | 4 | 471 |
| 等 token | 随机编辑 | 0.34495 | 7 | 471 |
| 等 token | 直接 CEM | 0.33723 | 7 | 471 |

固定机会下，低调用方向平均精修起点终距为 0.39454，完整响应为 0.41047，随机为 0.40237；但它最终平均终距没有优于完整响应或 CEM。低调用臂 32 次中有 21 次将有限方向探针本身选为起点，探针是真实计费的完整链候选，不可将其收益全部归为方向外推。

等 token 下低调用方向的平均终距比 CEM 低 0.00545，但以每根平均两次后的配对差计算，7 根更好、8 根更差、1 根相同，二者成功次数均为 7/32；该均值差并不支持稳定优势。相对完整响应为 13 根更好、3 根更差，说明在这套有限预算和已暴露父链上值得进一步检查成本分配；不能由此证明组件独立贡献或新任务收益。运行时间为单进程开发计时，不是包括共享父链、模型加载、GPU、峰值内存的完整系统成本。

[运行器](../le-wm-main/experiments/pc_cheap_direction_edit_dev_20261105_codex.py)保存逐次调用及动作。[逐调用审计](../le-wm-main/results/pc_cheap_direction_edit_dev_20261105_codex/audit.json)重放全部 256 次预测、核对预算及实际最低分已评分链，并确认沿用 V2 的 192 条对照最终动作与分数完全一致。[方向重建审计](../le-wm-main/results/pc_cheap_direction_edit_dev_20261105_codex/direction_replay_audit.json)对 64 次低调用运行重建所有请求；两种审计复用相同动力学或算法实现，不是独立实现或独立复现。两项测试检查边界动作、零响应、预算和 incumbent。

实验使用已暴露任务和共同父链；没有隔离探针与方向外推、没有测试真正跨片段组合、没有独立来源或视觉执行。PC0–PC5 不变。下一项应在预定任务和相同总预算下隔离“六条探针自身”与“方向编辑”作用，再决定是否继续投入更完整的组件及真实闭环实验。
