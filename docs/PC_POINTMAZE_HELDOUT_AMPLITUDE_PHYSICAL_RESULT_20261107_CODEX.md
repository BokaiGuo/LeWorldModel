# PointMaze 未查询幅度：真实物理后果开发结果

依照[协议](PC_POINTMAZE_HELDOUT_AMPLITUDE_PHYSICAL_PROTOCOL_20261107_CODEX.md)，先封存此前已计算的模型和局部近似选择，再用 MuJoCo 实际重放每根的 `-0.1、-0.03、+0.03、+0.1` 五步动作。四根均保留，两相机仅作为同任务视角，不当作独立任务。

| 原封存选择规则 | 两视角先平均后的四根平均物理距离遗憾 |
| --- | ---: |
| 模型直接预测代价 | 0.03717 |
| 父代价常数 | 0.01084 |
| probe-min 常数 | 0.01084 |
| AD 线性近似 | 0.03846 |
| 二阶 Taylor 近似 | 0.03889 |

直接模型对 8 个任务—视角条件各 6 个非并列动作对共判对 25/48；这些动作对和视角共享四个任务，不能算 48 个独立样本。常数对照因四个预测值相等、按固定动作顺序破平局，始终选择 `-0.1`，其较低遗憾不证明固定动作是通用策略。尤其 1883 根两视角的模型对动作对分别仅判对 1/6 和 0/6，两个视角的物理轨迹相同。

评价端还重放 zero 和 ±0.1，并逐时刻与此前物理记录核对；状态最大误差满足 `1e-9`。新增 ±0.03 不再只具有模型内标签。但本面板和原模型预测此前已暴露，模型也曾对四个动作直接评分；“未查询”仅指这些动作未参与 ±0.003 局部描述拟合。目标位置距离不是标准成功指标，不能据此宣称闭环性能或独立统计结论。二阶外推先前的停止决定不变。

完整 proprio 输入使该实验属于 **state-assisted**；它不能证明 RGB-only，也未完成 PC1 或任何 gate。测试 1 项通过，技能 `experiment-code` 用于封存预测后分阶段运行和核对时钟，并未把负结果当作实现错误。
