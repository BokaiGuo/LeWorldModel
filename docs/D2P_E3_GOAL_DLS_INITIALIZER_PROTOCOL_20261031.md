# E3 目标条件化 DLS 初始化探索合同

在已封存的 structured-extra32 两个已知根 cp10 实验上，仅替换
structured 的八个初始动作。使用同一次、同样计费的 192 行动作
Jacobian 和模型零动作预测，以目标残差计算阻尼最小二乘：
`V diag(s/(s*s + 0.01*s_max*s_max)) U.T (goal - nominal)`。
将解按最大绝对分量限制到至多 1，再生成幅度
`[-1, -0.5, -0.25, 0, 0.25, 0.5, 0.75, 1]` 的八个候选。
零 Jacobian 时全部返回零；非有限输入和无效形状拒绝。

其余三臂、反馈、动作域、额外 32 次 structured 更新、后缀优化、
原生停止与资源账本不变。该初始化使用 RGB 目标 latent，不使用
物理状态；未训练模型。SVD 及矩阵运算占用原有 SVD 阶段，但完整
硬件成本需另报，不能声称等预算。此方法在已观察开发结果之后
提出，不是独立确认，也不是完整的重配置程序。原实验保留。
