# 时序后果保留：实现与数值一致性审计

使用已封存的 roots 20–49、A 和已查询 B 候选及两个 incumbent，不生成新候选、不读物理标签进行选择。重建同一参考和动作链，GPU 分批重新计算每个预测时刻的代价。比较保存值的最大绝对差、各臂保留前缀与完整动作身份；重新封存审计结果，不覆盖原产物。数值差超过 `1e-3` 或完整动作发生变化时标为需进一步调查；阈值是本次数值检查阈值，不是科研 gate。

核对逐行中心化是否消去等时长参考：`(ref-probe)-mean(ref-probe)` 等价于 `-(probe-mean(probe))`。同时核验原有已封存动作与候选来源、原模型分数选择相符。此代数性质反映当前实现的表达范围，不自动认定为 bug，也不追溯改变旧实验出口。

审计为已曝光开发数据上的同实现复算，不能认证上游动作时钟、物理模型准确性、独立任务或实际闭环收益。
