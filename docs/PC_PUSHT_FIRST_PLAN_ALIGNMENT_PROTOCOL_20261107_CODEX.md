# PushT 首计划配对对齐开发协议

使用已曝光 seed 85 的 50 个任务，比较原显式前缀均值与已评分候选保留两臂的首次计划，不改变其候选或选择。所有动作仅来自既有审计；反标准化后检查物理边界。每条链从对应数据行状态与目标重置，在 25 个物理步结束前即使成功也继续，以便比较每 5 步的真实后继。已经派发的首计划部分须与原轨迹的动作、前后物理快照及终止标志吻合；此后为离线反事实而非闭环执行。

RGB 初始及目标输入使用原数据图，模型逐包预测表示，真实观测使用环境渲染及已有 resize/编码路径；比较每个包时刻的预测、真实编码、成功与末帧代价。重算的末帧预测分数须与既有审计分数满足 `atol=0.002, rtol=0.0002`，否则中止并调查，不能把输入不一致解释为预测误差。固定各臂及代码、数据文件元信息与模型指纹，保留全部 50 对和相同链，物理成功不同子集另列分母；成功是曾成功及终点成功两项。

该实验仅为已选择首计划上的配对诊断，不能代表候选池、完整闭环、独立任务或因果组件收益；不把事后物理结果提供给规划器，也不改判任何 gate。源帧初始化与真实重渲染初帧有已知差异，须在解释时保留。
