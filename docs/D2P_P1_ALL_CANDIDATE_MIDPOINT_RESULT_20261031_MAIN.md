逻辑臂共享物理根与动作，尤其 selected 行 6、9 的成功候选是
同一动作链；不能把这些计数作为独立成功率。刷新会改变评分，
但并非一致改善：zero 的事后成功记录减少。真实中点刷新是在
**各候选分别真实执行之后**取得的观测；在线选择时无法免费
同时获得所有候选的中点，所以该表是 oracle 诊断，不是可部署
重规划或公平性能实验。

例如行 6 的原赢家与成功非赢家，开放终态评分分别为 0.0970、
0.1508；使用各自真实中点后为 0.3603、0.1311，排序反转。
行 18 同样反转，但两者刷新分数仅约相差 0.0053。成功轨迹分别
于后缀第 8 步停止，因此没有十步真实终态可与预测同时间比较。

下一步需让每种方法只执行自己选中的前缀/动作并取得同频真实
反馈，然后重新规划；不能把此离线 oracle 当作可直接修复评分
或 P1 通过的证据。P1 共同后缀、独立根及总预算对照仍需完成。
