# P1 同起点 Adam 后缀优化探索

此实验在既有面板结果之后确定，是已知两个根的开发探索，不是
独立确认。针对普通固定步长梯度搜索可能覆盖不足，保持 24 条
真实 cp5 RGB、冻结 checkpoint、目标 MSE、四个 raw 动作初值和
每个初值 20 次更新不变，将 SGD 更新改为 Adam（学习率 0.05，
默认 betas 和 epsilon），每次更新后投影到 [-1,1]。选分数最低
的候选，不使用既知成功后缀或物理真值。24 行初值哈希与已有
SGD 四起点版本全部一致。

主机 CUDA 中，Adam 相对 SGD 的模型目标 MSE 20 行更低、4 行更高。
根 0/on 的两个 selected 逻辑槽分别为 0.10416/0.09676，SGD 为
0.38747/0.26268。这是同更新数而非认证的等总计算量比较；每行
代码路径计数都是编码 1、action encoder 168、predict 168、
backward 80、最终候选评分 4，但 Adam 的更新计算及上游前缀、
耗时未纳入可比较总预算，计数不是独立 hook。

全部 24 个赢家逐一物理执行并通过保存消费：19 行执行满十步，
5 行原生停止成功。5 条均为 zero 前缀，来自根 0/off 两条不同
规划动作、根 0/on 一条和根 1/on 两条完全相同的动作与轨迹；
不得视为五个独立任务，也不证明重配置机制。根 0/on selected
两槽均未成功，推杆误差为 10.68/3.97，物体位置误差为
36.10/60.95，角度误差为 0.134/0.309 rad。相对于之前 SGD
的推杆远离目标实例，Adam 在这两槽把推杆移近，但物体任务仍失败；
模型评分显著改善不保证联合成功。

按旧合同，任何 native_stopped 行的十步 endpoint 保持空值，
即使停止恰在第十步；成功和实际停止步数另存。与 SGD 做同索引
描述性比较，双方都有完整终点的 17 行中，Adam 的物体、角度、
推杆和联合位置误差分别有 9、6、14、13 行更低；不是独立任务
统计或公平总预算优势。相同根与共享轨迹及事后方案选择均保留。
