# PointMaze 分段 CEM 与选链评分分解：开发结果

## 范围与结论

本次使用已曝光的八个 PointMaze 根、同根第 25 帧目标和经开发校准的相机，属于 **state-assisted、开放环开发实验**，不是 RGB-only、官方协议认证、独立确认或完整闭环结果。模型使用视觉与 proprio；各根原始归档动作仅在选链后作为可解性评价端见证。八根参考动作均到达目标，其中一根初始已成功。

对照参数化后，之前固定前缀对弱 CEM 的表面成功率优势不能作为方法优势。48 次评分的分段 CEM 在该面板上达到 8/8，平均末距低于固定前缀 lookahead；这只是八根、每根一个随机流的开发结果，且基线未经充分调优。

160 次评分所得模型最佳已评分链的预测代价不高于 48 次，却在四个不同选链的根上给出了与真实末态编码相反的排序。这个事后现象指向值得进一步检查的预测—观测失配，但尚不能区分模型误差、重渲染和预处理误差等来源。

## 对照与成本

分段 CEM 使用 5 段二维动作，每段保持 5 环境步；每轮 16 条、4 elite，分别从前 3 轮与前 10 轮的已评分样本中取最优，总计 48 与 160 次评分，未把未评分的均值作为结果。48 和 160 是同一次运行的嵌套预算，并非独立重复；两者也不是等成本。原 48 次 CEM 则直接优化 25 个二维动作，与固定前缀的分段参数化不同。

| 方法 | 总评分 | 全部成功 | 全部平均末距 | 初始未成功子集成功 | 子集平均末距 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 分段 CEM | 48 | 8/8 | 0.14508 | 7/7 | 0.13982 |
| 分段 CEM | 160 | 7/8 | 0.24985 | 6/7 | 0.25460 |
| 原逐步参数 CEM | 48 | 7/8 | 0.32011 | 6/7 | 0.33965 |
| 固定前缀普通 lookahead | 48 | 8/8 | 0.23673 | 7/7 | 0.21100 |

分段 CEM 同步评分时间约为 48 次 1.03 秒、160 次 3.40 秒，目标编码另计；这些数字不是包括环境、观测和重规划的整任务成本。原逐步 CEM 的物理轨迹重放与已有结果最大差异为零。

## 预测、真实编码与物理末距

事后对已选中的 48／160 两链进行末态重渲染，使用同一冻结编码器及归档目标计算评价端真实编码代价；真实后继没有参与规划选择。数字顺序均为 48 次、160 次：

| 根 | 预测代价 | 真实编码代价 | 物理末距 |
| --- | --- | --- | --- |
| 1884 | 0.01694 / 0.01482 | 0.01802 / 0.00555 | 0.04009 / 0.03839 |
| 1885 | 0.02799 / 0.02419 | 0.01975 / 0.04816 | 0.08395 / 0.32192 |
| 1886 | 0.02197 / 0.01770 | 0.02893 / 0.03537 | 0.18188 / 0.21663 |
| 1887 | 0.03355 / 0.01756 | 0.02038 / 0.02494 | 0.03245 / 0.12301 |
| 1888 | 0.04456 / 0.04456 | 0.03760 / 0.03760 | 0.19381 / 0.19381 |
| 1889 | 0.06599 / 0.06599 | 0.08466 / 0.08466 | 0.26025 / 0.26025 |
| 1890 | 0.04857 / 0.02350 | 0.03716 / 0.08876 | 0.15502 / 0.78441 |
| 1891 | 0.01570 / 0.01562 | 0.05332 / 0.00208 | 0.21317 / 0.06041 |

1888、1889 两预算选中同一条链，作为平局保留，不计入排序分母。其余六对中，预测与真实编码排序一致 2/6，真实编码与物理末距排序一致 6/6，预测与物理末距排序一致 2/6。1886 初始已成功；保留在全体中，不作为前缀产生后续机会的阳性证据。物理末距不是完整成功规则，六对一致也不能认证全候选池的真实编码评分。

根 1890 的 160 次预测代价从 0.04857 降至 0.02350，但真实编码代价从 0.03716 升至 0.08876、物理末距从 0.15502 升至 0.78441。目标重渲染与归档图不是逐像素一致：八根像素 MAE 约 0.003–0.034，最大单像素差 17–68，不能忽视重渲染差异，也不能仅凭排序反转断言已发现某个动力学代码 bug。
