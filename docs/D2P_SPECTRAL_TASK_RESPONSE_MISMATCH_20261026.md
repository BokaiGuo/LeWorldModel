# 新谱前缀的真实响应：能力指标仍计入物体不动时的推杆运动

本轮新增了直接物理证据，将失败进一步定位到当前 Q 的任务对应关系，而不是笼统归因于理论不可行。尚未修复目标度量，更没有通过 P1。

## 真实探针与源码核验

runner：`le-wm-main/experiments/spectral_reachability/run_pusht_spectral_response_physical_cuda.py`。

产物：`le-wm-main/results/pusht_spectral_response_physical4_v1_20261026_cuda/report.json`，`diagnostic_completed`，退出码 0，8 项完整性门全 true。四个已知校准根，每根严格使用上一轮封存的所选前缀及零前缀；不按新物理结果换候选。每个上下文执行固定 5 个后缀参数探针：零和两个坐标的 ±.05，共 40 分支，全部完成，40 次实际主机 CUDA 终态编码。禁止模型 predict；无神经 CPU 回退、额外训练或物理状态规划输入。

每条前缀的 RGB 和真实状态都与封存执行的第 5 步精确匹配；所有探针前重置并重建根。后缀命令按 float32 参数经 tanh 映射、重复五次，中心差分分母使用实际 float32 参数间距，不重复应用动作尺度。所有失败分支必须保留；本次没有观察丢失。参数、buffer、eval、输入和源码封存检查通过。

本轮使用调试技能分离实现核验与机制解释；这项新证据不推翻此前 AD/神经有限差分一致的事实，也不重写旧失败。

## 固定残差后比较响应，而非比较距离

纯数组模块 `pusht_fixed_residual_response.py` 用独立 augmented-lstsq 解 ridge。每根先固定 `r=goal[0]−零前缀的保存 nominal suffix terminal`，再将同一 r 和 Q 用于两个不同前缀后的 Jacobian。真实 J 由相同冻结 encoder 编码的物理中心差分构造。

| 根 | 模型预测的所选−零局部改善 | 真实 latent 的所选−零局部改善 |
|---|---:|---:|
| 0 | +0.242850 | +0.240121 |
| 1 | +0.463903 | +0.119011 |
| 2 | +0.052084 | −0.001515 |
| 3 | +0.011238 | +0.035176 |

这与上一轮变动残差的 V 分解不是同一指标，并不矛盾。它表明三个所选前缀在同一 latent 方向下确有较强有限尺度响应，不能继续笼统说“所有真实能力都没有改变”。但 latent 响应是否属于物体任务，必须另行核对。

## 直接的物体任务对应检查

只读分析：`analyze_pusht_spectral_response_physical.py`。
保存产物：`le-wm-main/results/pusht_spectral_task_response_audit4_v1_20261026.json`。
物理状态仅在这一步作 evaluator 标签，不回灌给 selector、Q 或动作生成。

| 根 | 所选前缀五个探针的物体 [x,y,angle] 完全一致 | 所选前缀的真实 Q-latent 动作改善 | 零前缀下物体是否会响应探针 |
|---|---|---:|---|
| 0 | 是 | 0.266062 | 是 |
| 1 | 是 | 0.135111 | 是 |
| 2 | 否 | 0.025996 | 是 |
| 3 | 是 | 0.059949 | 是 |

所有八个上下文的推杆 XY 差分范数均约 271.886。根0/1/3的所选上下文物体 XY 与角度差分均严格为零，五次物体位姿原值也完全相同，不靠任意小阈值宣称不动。零前缀则保留了物体响应。

因此，当前“有限 goal-agent 差异 span 的正交补 Q”并未在这些新状态上排除物体不动时仍存在的推杆相关视觉变化。Q 后的真实 encoder 响应本身就可能奖励这种变化；仅把 imagined successor 改成真实反馈、或把 Jacobian 算得更精确，并不足以修正它。当前物体任务失败不能仅靠“模型不知道真实动作动力学”解释，也不能被这个 latent 能力指标的改善掩盖。

这是一项**当前任务度量／机制合同不足**的证据，不是原 SVD/ridge 公式错误的证据，也不是理论不可能的证据。官方任务还包含推杆目标位置，与 object-only 研究任务不能混用；本表专门解释物体任务的落差。

## 仍待解决与科学边界

需要构造真正任务条件化、在新状态排除无关推杆响应且保留物体相关方向的临时 Q，并与前缀谱、后缀优化、stage、reach 和 terminal 一致接线。只能使用部署可得 RGB/目标与冻结模型，不准用这些 evaluator 状态训练 readout、按物理后验挑根或调出通过阈值。

这是仍待实施和验证的修复，不在本轮虚报完成。当前诊断仅一档固定 eps=.05、五个物理步，不能视作接触切换处严格的无穷小导数、全动作域不动或长期无控制能力；没有独立 outcome、非贪心机制或闭环收益。P1/P2/P3/P5 仍保持未准入，完整研究目标继续有效。

新增局部合同测试 9 项；包括有限实数/形状、固定残差 ridge 闭式对照、差分参数单位、失败不补齐、推杆运动不得当作物体响应。逻辑测试不替代上述 CUDA/真实物理产物。
