# 联合优化前缀后的独立 CUDA 后缀规划

对固定八组 selected、zero、greedy 共 24 个前缀，从各自真实 cp5
RGB、原始动作历史、同一冻结目标和归一化出发，各自用同一零
初始化、同一两步有界梯度优化和同一 CUDA 预算规划 10 步后缀。
不读取物理状态或共同后缀效果来规划，不训练模型，不选择根。
selected 的图像及动作来自已封存新物理执行；zero/greedy 沿用
已封存盲输入，逐项核对根、动作、目标和图像身份。

记录编码、预测、反向及动作字节；现有调用账本覆盖不完整、进程
隔离未认证，前缀生成成本尚未统一计入，故这只是已知根开发实验，
不是公平总预算或 P1 通过。模型分数不是物理收益；规划后需要
绑定原生源及执行每条后缀，再复核中止与分项物理指标。
