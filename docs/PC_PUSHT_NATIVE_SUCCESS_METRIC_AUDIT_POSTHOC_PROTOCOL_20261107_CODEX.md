# PushT 原生成功与奖励语义：后验对照

此前新几何面板用物块中心/朝向诊断代价评价动作排序；本地 `swm/PushT-v1` 的成功条件同时依赖推杆和物块的四维联合位置误差，奖励另含推杆速度和未包裹的角度差。因此不得把该物块指标的反序直接解释为原生任务失败或模型错误。

固定已采集、独立重放的 16 根、两背景、左右、三个动作；不筛选根、不改变规划器。逐最终状态验证本地 `eval_state(goal,state)` 的成功与奖励距离等于重算值及已记录的成功标志。比较相同评分选择在三个评价量下的遗憾：历史物块代价、原生状态距离（即负奖励），以及仅作诊断的 `联合位置距离²/20² + 包裹角差²/(pi/9)²`。最后一项不是原生成功规则，也不是奖励；其意图只是连续显示成功判据的两个分量。报告实际成功分母和全体终点，不把代理指标代替成功。

比较模型预测、真实后继编码和零动作；输出每根、条件、候选、误差分量、重算成功与保存成功的一致性。对各指标按根平均四个条件后统计。物理状态仅用作后验评价；真实后继编码不能用于部署。由于本协议在面板及部分结果公开后写成，它是后验诊断，不能以此改判 PC gate、声称模型收益或进行独立统计确认。
