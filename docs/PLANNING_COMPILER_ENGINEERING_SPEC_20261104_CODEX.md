# Planning Compiler 工程规范与实施任务书

状态：工程目标规范，2026-11-04；不是确认实验预注册、不是科学 gate 通过证明。适用对象为冻结世界模型上的 Planning Compiler / D2P。旧 ATM/MSE P1、GDD-WM 及早期 D2P 准入函数属于不同合同，不得用其结果替代 PC0–PC5。

2026-11-04 实现状态更新：v25 是目前 E0 开发候选而非已冻结正式方法；其递归搜索、后继价值保留、多起点精修和配对弃权均已实现。v25 PointMaze 已有开发适配器，真实运行不得仅凭入口声称完成。前缀随机尾部的 15/10/5 开发适配器在单片段时回退 v25，此为时域兼容处理，不是响应可信度回退。v25 事前同链开发面板机制交集 0/8，保留该负结果；任何正式候选仍须另行冻结并以同版本证据验收。

本规范将附件所述职责映射到本地已有开发实现；附件针对公开 main 的有限审查不代表当前磁盘状态。新接口是目标合同，不表示已经实现。历史实验的协议、阈值和停止规则保持不变；新设计、新阈值或新面板必须事前版本化，不得追溯更改。

## 1. 不可变研究边界

1. 一项结果必须绑定同一版本的候选生成、剪枝、优化、选择、弃权、执行和反馈，不得把不同版本的阳性结果拼成 Full D2P。
2. 冻结 checkpoint 与 normalizer；模型不做后训练。参数冻结和动作求导是两回事：动作 AD/JVP/VJP 路径不能整体置于 `no_grad` 或 `inference_mode` 中。纯 FD 路径须如实标识，不能声称使用 AD。
3. 规划器只能接收协议允许的观测、目标、动作历史和记忆。RGB-only 与 RGB 加合法本体输入分别声明并公平比较；物理状态、接触标签和未来观测仅可用于明确隔离的评估或 oracle 诊断。
4. 研究执行完成与证据支持分别记录；组件测试、模拟重放、模型内得分和特权 witness 均不能自动提升为真实控制或独立复现。
5. 对负结果先检查接口、优化、时钟和评价；只有定位具体错误并有对照时才称 bug。无法排除时报告实现风险、搜索不足或该协议下未显示优势，不预设理论成立或失败。

## 2. 目标调用链与接口合同

```text
合法观测和历史 → 冻结模型上下文 → 动作响应 → 候选生成
→ 后继响应及有界组合搜索 → 共同后缀优化 / 可选联合精修
→ 完整链比较和弃权 → 封存决策 → 派发动作 → 真实观测 → 重规划
```

每次决策输入必须绑定 `run_id`、方法及依赖哈希、模型参数哈希、normalizer 哈希、根及目标、合法输入来源、原始动作单位与界限、动作/观测历史及时间戳、剩余任务时域、反馈时刻、随机种子和资源政策。输出必须包含所有候选来源与可执行原始动作、前缀/后缀长度、预测中间及最终状态或可重算引用、生成/筛选/优化成本、优化前后动作、评分、完整链 incumbent、弃权原因、选择封存及实际派发动作。采样统计须包含批次数、每批样本、精英更新、再次采样和末批处理。

固定终点任务中，执行 5 物理步、总计 15 步时，决策时域为 15/10/5；持续控制须另立合同并记录未执行尾部和收益兑现时刻。旧尾在新观测下重评分，与新候选在相同上下文比较；对照也须获得协议规定的热启动和精修机会。完整链的最终选择必须包含合法 incumbent；精修或弃权后，机制判定重新针对实际派发前缀。

物理步、帧跳、模型 packet、搜索片段和计费单位是不同字段。动作打包必须与 checkpoint 训练语义一致，不能为凑整静默补零、截断或重复。实现须显式支持合法余段或在运行前拒绝；同一动作链改变搜索分段不得改变物理时刻或模型输入，实际调用成本按真实 packet 和调用计。

## 3. 响应、可达价值和候选

对名义动作链 `Ū` 和时域 `H`，定义 `G_H = ∂Φ_H(z,U)/∂U | Ū`。声明任务度量 `Q_g`、动作度量 `R` 与归一化，再计算 `K = Q_g^(1/2) G_H R^(-1/2)`。`Q_g` 须半正定、`R` 正定；奇异或数值退化情况须声明正则化或有效子空间，不能隐式求逆。局部岭价值 `Vλ = min_w ||r_g-Kw||² + λ||w||²` 是局部无约束近似，不是动作盒约束下的物理可达性证书。坐标变换不变性仅在度量同步协变变换及相关逆存在时声称。

长度为 `k` 的前缀只允许使用 `H-k` 的剩余时域。每个候选和后继必须由可执行动作经完整非线性 rollout 得到，不能把无动作见证的 latent waypoint 当程序。谱贡献用于排序、筛选还是实际预算分配必须写明：仅重排而最终生成全部方向不构成谱压缩。独立谱增量另遵守 [高维谱合同](PC_HIGH_DIM_SPECTRAL_INCREMENT_CONTRACT_DRAFT_20261103_CODEX.md)；SVD 与等价岭求解一致是代数预期，并非失败或独立收益。

响应验证覆盖正式使用的 nominal、方向、组合、尺度、后继和完整时域；同时记录 AD/FD 数值误差、非线性近似、物理响应与任务排序。近零范数报告绝对误差；接触分支的非光滑性单列。缩步、重线性化或非局部回退必须预定、计费并消融，不得按根临时选择。

## 4. 分层诊断和对照

固定候选库时分别审计：生成是否覆盖有效区域、哪些候选被保留或剪除、统一后缀优化后质量、联合精修是否改变优势、最终选择是否丢弃已评分的更好完整链。比较即时 greedy、普通 lookahead、状态多样性、响应/局部价值保留和随机保留；先给相同后缀机会，再做生成起全部计费的端到端比较。解析解、强基线计划及已知好前缀仅用于隔离问题，不得进入正式方法成绩。

PC2 对最终选中的同一链，封存后对 selected、zero、same-bank greedy、lookahead 和 random 前缀施加预设共同后缀族，报告绝对终距与相对各自零后缀变化；另对各前缀用同优化器、同预算自行重规划。要建立非即时进展、任务相关后续响应改变及可利用收益，排除被动运动和即时优势等替代解释。随机/普通 lookahead 是必要对照；与其可重复性能优势属于可事前注册的更强机制或 PC3 主张，不能追溯加入旧 PC2 阈值，也不要求 PC2 先赢所有强基线。

PC3 开发期调优并冻结多起点/热启动 CEM、适用梯度/GN/混合、普通 lookahead、原方案适用的 GRASP/AP 及关键消融。区分 memory-free 与 memory-available 权限；同模型、动作域、时域、任务、反馈和预算配对。分别计量编码、预测、微分、分解、筛选、缓存、反馈、同步 wall time、内存/GPU；prediction token 相等不等于总成本相等。预先规定成本轴与共享开销，绘制质量—成本曲线。

## 5. PC0–PC5 与 E0–E5 验收

| Gate | 必需的实质证据 |
| --- | --- |
| PC0 | 冻结模型和动作时钟、重置、后端及规则一致；原始基线复现；声明动作域与终点时域内有可行见证。候选 oracle 未找到解只能记 unknown。 |
| PC1 | 实际使用范围内响应数值正确，并对任务代价/动作排序有预定义的相关性；局部及非光滑失效范围明确。 |
| PC2 | 正式方法自动生成、事前选中并实际执行的同一链满足预定义非即时机制和共同后缀、等预算干预。 |
| PC3 | 冻结版本在来源合格的独立配对任务上，对强基线和关键消融达到预定实际效果及统计标准，或证明同质量下可信成本优势。 |
| PC4 | 同版本用合法 RGB 真实执行、观察、更新历史、重编译，长时域真实控制改善；排除未来信息、特权输入和时域错位。 |
| PC5 | 固定核心算法和调参规则，在未见目标、独立 checkpoint、另一架构和声明任务范围复现机制或优势。 |

PC0 的诊断应区分真实候选 oracle、完美动力学 MPC、真实后继加冻结评分、学习后继加 oracle 任务评分、冻结模型加原始 CEM；它们不能越过信息隔离进入正式 RGB planner。E0 为精确动力学；E1 Reacher；E2 TwoRoom/PointMaze；E3 PushT 接触；E4 Cube 长时域；E5 跨模型。导航收益不能替代接触机制，模型内 Cube 决策不能替代真实执行，后训练修复模型不能替代冻结模型主结果。

## 7. 运行、封存和统计合同

每次新实验在执行前写入不可覆盖的协议和 manifest：代码/配置/模型/normalizer/数据依赖哈希、任务生成与排重、输入权限、比较臂、资源、随机性、终止及失败规则。原始逐决策动作、预测、候选来源与选择、真实反馈、审计和分项成本必须可追溯；原子写入或排他创建，部分运行须明确标记，不覆盖历史产物。审计应从原始轨迹和依赖推导结论，不能只相信自报的 `privileged=false` 等布尔值。

确认前冻结主物理指标、最小实际效应、样本量及功效依据、配对单位、最强合格基线、失败处理、多重比较及停止规则。附件提到的 128–150 queries 只是样本量规划建议，非已冻结标准。开发外、normalizer 拟合外、checkpoint 训练外是三个独立命题，各有来源证据；缺失即 unknown，禁止提升为确认数据。

每项 gate 记录执行状态与科学证据状态两列。执行状态可为未开始、运行中、完成、失败或外部阻塞；科学状态可为未评估、证据不足、不满足或通过，并引用具体冻结合同和证据。非完整记录、未知来源或缺失成本不得自动通过；同环境第二实现重算是实现一致性检查，不自动等于独立复现。

## 8. 已封存开发结果与后续工作

截至本规范编写时，[v13 新 Wall 面板](PC_V13_NEW_FEASIBLE_WALL_DEV_RESULT_20261104_CODEX.md)为 4 根开发任务、v13 0/4、同 global bank 全动作 CEM 2/4；事后特权 witness 证明四根可解，不能作为方法输入或成绩。该面板已按协议停止，不重跑、替换根或调整标准。[v13 前瞻机制](PC_V13_E0_PROSPECTIVE_MECHANISM_DEV_RESULT_20261104_CODEX.md)有有限基础见证，但完整对照交集未建立；PC2/PC3 不能据此宣称通过。这些仅是有界开发结果，不是理论否定。

依序执行：统一版本、动作/计费与反馈接口；证明任务可解并认证实际响应与视觉评分；用新协议分解生成、保留和后缀搜索损失；封存并实施 PC2 同链机制；开发强基线与成本曲线后冻结 PC3；推进同一版本的真实反馈与独立跨模型确认。来源补证并行。每一轮记录观察、可证伪假设、对照、是否定位错误、回归与剩余解释；已达停止条件的构造不重开。最终交付代码入口、冻结协议、原始轨迹、机制与成本审计、统计、失败边界和干净环境复现命令；研究闭环可产生有界负结论，不能由代码完成推断 gate 通过。
