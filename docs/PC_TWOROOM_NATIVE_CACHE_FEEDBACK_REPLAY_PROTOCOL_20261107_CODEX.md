# TwoRoom 单帧原生缓存接口：闭环回归协议

目的：检查原生缓存接口替换历史诊断中的临时模型方法替换后，是否在
实际 RGB 重观测和想象状态反馈中保留原有计算行为。不是收益试验。

使用历史事后选取的已曝光 roots 38、39、原初始前缀、旧尾规则、种子、
搜索预算、模型和环境；只替换 latent rollout 接口。两臂运行器与模拟器
同进程，状态只用于 reset 和物理评价；这不是操作系统级隔离。

逐臂检查任务数、动作、每次选择哈希、每次全部评分、查询与模型动作包
步数、重规划次数、逐步距离、终止与截断。动作、哈希和计数须完全一致，
评分绝对容差 0.001，物理距离容差 0.0001；有缺失或不符即报告未通过。
保留所有失败，包括接口预检、运行异常和差异，禁止覆盖旧结果。
同步时间只作运行记录，不解释为效率比较。

对照为同一历史诊断结果，并非独立任务或独立物理引擎。脚本对使用的
外层包装、原运行器、原生缓存接口和协议分别计算哈希；保留原始运行
结果和审计摘要。该复验不改变研究 gate。
