# v3 新网格精确动力学事前机制开发协议

冻结 v3 算法，事前固定 24 个精确 Wall 任务的笛卡尔网格：起点
`[-0.5, y, theta]`，目标 `[0.5, gy]`，依次枚举
`y=(-0.40,-0.10,0.20,0.40)`、`theta=(-0.9,0.15,0.9)`、
`gy=(-0.30,0.30)`。与先前 24 根网格的完整任务参数不同，但仅
核对已引用根不构成全仓历史排重或来源独立认证；本实验仍是开发，
不可声称独立确认。每根固定 15 步、单次开放环选择：response、
matched_random、smooth_cem 各用 v3 相同 1920 token 限额。不得
事后改网格、种子、预算、筛选方法或追加根。

在所有任务的规划封存后，逐根对 response 事前所选的完整链作
同链干预，不根据是否看起来非即时选根。五种前缀为实际选中、
zero、同首库即时 greedy、matched_random 选中前缀、smooth CEM
选中前缀。共同后缀族是 10 步全零、四种预设常动作
`(+.5,0),(-.5,0),(+.5,+.5),(+.5,-.5)` 及选中链自身后 10 步；
最后一项由规划选出，不称独立样本。报告每项绝对终距及相对该
前缀零后缀的变化。

每前缀再以同一四结点 CEM、相同随机种子与 120 次完整链评价
（含零尾初始化、后续 119 样本）独立重规划，记录终距及动作；
每前缀测零尾附近下一个五步动作响应的中心差分矩阵，步长 0.05。
干预开销另列，不包含在规划 token 中。

预定严格见证为：非零 selected 前缀本身的目标距离不小于初距减
`1e-10`；相对自身零尾的 selected 后缀变化严格优于 zero 与 greedy；
各自重规划终距也严格优于 zero 与 greedy；selected 对这两者的
后续响应矩阵 Frobenius 距离均大于 `1e-6`。另报告同时优于全部
四个对照的交集、全部数值、对照别名与绝对终距；不将这些阈值
改成原方案 gate 的通用定义。不存在满足条件的链即报告零见证，
停止该网格，不额外调参。候选与对照的完整链、实际 float32 评价、
规划计量和干预分开封存，逐批重算规划并确定性重建干预。

这些前缀、数据、阈值和干预均在新网格结果揭晓前制定，但网格
不能自动代表未见任务，结果也不能取代 RGB、多模型或 PC3 强基线。
