# P1 多样性候选的已知根物理探索合同

固定已保存的八臂多样性候选与各自 incumbent，共 16 行，每行
独立创建环境、恢复同一原生根与目标、执行原始十步 warmup 后
执行 15 步见证动作。完整动作由先前封存的 CUDA 重放逐位绑定；
执行器沿用 `model_selected` 角色名，来源连接器明确保留其实际
含义 `diverse_selected`，不声称是旧的 20 候选全局最优。

每行保持原生提前成功／截断，不补未观察时域终态；检查全部
dispatch 字节、初始状态、历史 RGB、目标、每一步状态、帧哈希和
原生指标。固定的预算为原执行合同，不进行新神经推理，不训练。
报告每行的物体位置、角度、推杆位置、成功及停止状态；必要时
分开报告实际最后状态与 15 步端点。物理值仅用于事后评价。

这不是共同后缀能力干预，也不是统一资源下的各前缀独立规划；
两个已知根及重复动作不能当作独立确认。已有 20 候选的完整搜索
成本不能伪装为四候选成本。本结果不授予 P1 或后续阶段准入。
物理源连接器绑定了新 replay 与准备文件，运行时另行检查实际
reset、warmup RGB、动作派发与目标；保存结果必须独立消费。
