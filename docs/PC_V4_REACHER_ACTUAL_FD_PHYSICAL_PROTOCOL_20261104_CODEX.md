# V4 Reacher 实际有限差分探针的物理响应诊断

固定已曝光 v4 轨迹第 10 步上下文和它实际使用的两个名义动作。直接读取原 trace 中两个 21 样本批次：名义动作、10 个 `+0.05` 坐标扰动、10 个 `-0.05` 扰动；必须先从它们重建原 `2×10` 响应矩阵。逐个重置同一模拟后端，重放共同热身与真实前两包，以 root RGB、关节、速度和目标一致约束初态，实际执行每个五步动作并保存末帧和物理状态。

在同一 checkpoint、预处理及原二维 chart 中编码 42 张实际末帧，与原 trace 的模型投影计算相同中心差分矩阵。报告矩阵绝对误差、范数、有效范数下相对误差及方向余弦，以及每列误差；比较模型和实际编码的目标 MSE、关节终距在对应正负动作对上的排序。额外存完整 latent，不以局部 chart 为物理 qpos。保存动作、输入、RGB、物理状态、latent 及哈希，验证同一次编码的名义动作重现此前反事实封存帧。

这是已曝光单根、一个时刻、两个名义点和一个扰动尺度的数值及物理响应诊断；像素量化会影响差分，不能等同连续物理状态导数。后继前缀、多尺度、谱方向、AD/FD 和其他根均未由此覆盖，不构成 PC1 通过、物理模型训练外认证或控制成绩。根据证据报告实际差异，不能预设负结果来自 bug。
