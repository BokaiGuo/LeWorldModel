# v7 Reacher 实际有限差分探针物理重放：开发协议

使用已封存的 v7 真实 RGB 反馈单根第三轮（剩余 5 步）两条 nominal 及其实际执行器请求的 `±0.05` 中心差分，共 42 个五步动作包。先验证这些批次确实对应 v7 生成器记录的 2×10 响应矩阵，使用原始 float32 动作。每个分支重新 reset 到同一已暴露根、执行完全相同的真实 warmup 和前两轮 v7 实际派发动作，检查目标 RGB、第三轮根 RGB 与首个分支的物理 qpos/qvel 一致，随后只派发该分支动作。

保存所有终点 RGB、动作、物理状态和冻结编码器产生的终点 latent。沿 v7 当轮固定 chart 对模型预测与物理 RGB 编码分别计算两组 2×10 中心差分，报告矩阵绝对误差、相对范数误差、方向余弦；同时报告 42 个模型与物理后继 latent 相对于同目标的 MSE、排序相关或排序一致性。对近零范数报告绝对值而非强行给相对值或余弦。该比较不将 chart 轴直接称为物理关节坐标；MSE 为编码空间指标，不替代真实任务成功。

保持原 checkpoint、预处理和 TF32 关闭设置；在 GPU 协作锁下执行，模型和动作均不从物理特权状态生成。该单根、单时域、单尺度开发诊断不认定 PC1 通过；首两轮物理动作、模型预测和新分支均有哈希绑定，不修改既有轨迹或结果。逐分支完整中间物理状态、长时域及独立模型不在本次覆盖范围。
