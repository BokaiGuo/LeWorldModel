# 已执行前缀后果：共同探针物理与 RGB 模型对照

对上一轮 40 个开发任务中有完整五步实际派发前缀的全部 35 个，重放 original、lookahead、zero、random 四种已封存前缀。每个前缀之后，分别从该真实后继执行相同 5 步探针：零动作以及幅值 0.6 的正负 x、正负 y 常值动作。原 effect 实际链第 6–10 步存在时，将其作为该任务第六个共同探针；不足 10 步时不补造此探针。所有探针均从同样重置和同一前缀后继出发。

真实任务效果定义为同前缀下：零动作 5 步后目标欧氏距离减去指定探针 5 步后的目标距离；模型效果定义为相同参考的冻结模型目标编码平方距离之差。零动作是合法参照，不假定物理静止，模型和物理效果的数值单位不同，主比较为方向和排序，不直接比较数值幅度。

记录逐步物理轨迹、首次成功、前缀前后距离、模型预测和真实图像编码向量，以及原实际链第 6–10 步的行动效果。比较 original 与 zero 后的真实探针相对排序变化；对前缀未成功且实际后缀可用的分层，再检查原实际后缀在原前缀及零前缀后相对各自零动作的效果。相对排序变化不自动证明新控制机会，因不同物理位置和目标距离本身亦可改变响应；须结合原链与干预结果解释。严格正负比较对物理距离采用 1e-5 单位容差、latent 代价采用 1e-6 数值容差；分别报告平局，不当作正确分类。

成功后继续执行五步是对齐诊断，不是原实际闭环。物理标签只用于评估，不作为模型的选择输入。本实验是已曝光开发面板的事后机制检查，无独立性或显著性声明，不更改 gate。
