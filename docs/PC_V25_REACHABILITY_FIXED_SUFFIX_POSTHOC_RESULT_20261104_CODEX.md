# 可达价值保留与共同后缀机会：事后结果

按 `PC_V25_REACHABILITY_FIXED_SUFFIX_POSTHOC_PROTOCOL_20261104_CODEX.md`，将同一 16 根、1920-token narrow 源面板首层候选与已审计的固定后缀机会逐项绑定：候选动作完全一致。逐根记录见 `le-wm-main/results/pc_v25_reachability_fixed_suffix_posthoc_20261104_codex.json`。

响应规则在 6/16 根相对状态多样性增删了候选。各保留集合中最好候选按已记录的每候选 49 次共同后缀评分评价，响应相对状态多样性为 **0 根更好、1 根更差、15 根相同**；相对 greedy 为 2 根更好、6 根更差、8 根相同。被探测候选的两两比较共 96 对：响应启发式值与后缀得分排序一致 60 对、相反 36 对；这些对共享根和候选，不能当作 96 个独立任务。

这是一种有限求解机会下的事后描述：49 次评分的已知见证检出率曾为 0/32，不能把此处未获益当作前缀不可行；49 次求解的随机性、响应生成与探针成本也不能被忽略。上述集合内最优分数不是完整递归、联合精修或实际部署性能，更不是 PC2、PC3 验证。本分析没有改变源面板或证明理论失效。

复现：在 `le-wm-main` 执行 `.venv/bin/python -m experiments.pc_v25_reachability_fixed_suffix_posthoc`；脚本拒绝覆盖已存在结果，须先保留原结果并为新运行指定不同输出路径。脚本检查源审计、依赖哈希、任务身份、选择记录哈希及候选动作。源实验已经暴露，因此该分析不构成事前或独立确认。
