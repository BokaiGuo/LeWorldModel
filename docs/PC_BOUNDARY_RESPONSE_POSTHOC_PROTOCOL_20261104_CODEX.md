# 已封存链的动作边界响应敏感性：事后协议

对象为 v25 narrow prospective 面板全部 16 根已封存干预，包含 selected、zero、greedy、lookahead、random 前缀；共同尾部取实际最终选择链的后十步，不改变原名义动作。前五步尾部逐坐标按 0.01 和 0.05 扰动：两侧均可容纳完整步长时用两侧割线，否则用可行侧单边差分；实际 float32 动作差为分母。无可表示完整步长则报错，不截断。

在请求前保存原始动作、控制、步长、方向和计数，分别运行 endpoint 与 wall rollout；比较两者末位置，记录每个坐标的阻塞序列是否改变、矩阵及目标距离梯度。与旧裁剪名义的对应矩阵及分支情况进行描述性比较。单边、中心割线和跨分支割线不应一概解释为光滑导数。

这是对已观察面板的事后敏感性检查，不计算新机制交集、不修改旧结果、阈值或停止规则，不是 PC2 确认。计算单位为完整 15 步动作链次数，endpoint 和 wall 的计算分别计数；不宣称相等于原规划 token 或 GPU 成本。部分失败记录保留且不当作成功。
