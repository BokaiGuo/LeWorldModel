# P1 两阶段现场规划：开发合同

固定已知 24 行前缀与任务，不选择 outcome。现场物理执行前缀后
对实际 cp5 RGB 编码，按已封存四起点、每个起点 20 次 Adam、
学习率 0.05 和目标 latent MSE 规划十步，执行赢家第一包；然后
认证实际动作和现场 RGB，以刚才的赢家第二包为初值，执行 20 步
信赖系数 0.1 的 Adam，选目标最小的迭代并执行其五步。

规划只接收 RGB、已执行动作和任务输入，不接收物理状态或未来
outcome；所有模型计算在主机 CUDA，模型冻结，记分母、阶段动作、
停止、资源和逐步物理日志。发生原生停止或截断后不得继续。所用
24 行和初始前缀来自已知实验，故本实验是现场接线/部署探索，
不是预注册确认或 P1 公平对照。前缀本身非现场生成，因此不是
完整从头 D2P。保存消费者须检查现场首包与既有离线四起点动作，
现场第二包与既有现场最佳迭代实验的同输入差异；重复结果不是
独立样本。显式路径计数不是完整硬件 hook，资源分轴报告。
