# 旧 P1 稳定排序：独立开发协议

2026-11-03；在运行本协议的回顾性对照前写定。此处“事前”仅指本次开发对照，
不是历史实验预注册。旧实现、历史匹配阈值、报告和 gate 一律不修改。

独立选择器输入为同一固定候选池的 checkpoint 字符串身份和六项原始指标
（prediction_mse、action_inverse_risk 和原 benchmark 的四项 METRICS，
均越小越好）。身份必须是非空、无首尾空白的字符串，在候选池内唯一；
缺失、重复、非有限数值、空池或维度不一致均报错。指标严格数值相等时，
使用零起始平均名次；六项名次取等权均值。综合分数精确相同时按 checkpoint
字符串的 Python Unicode 字典序升序选择；MSE 相同时亦按同一身份规则选择。
无容差并列，无使用 outcome 的选择。身份排序是确定性约定，不意味着科学优先级。

回顾对照仅使用两个历史 panel 已保存报告的逐 stratum 匹配集合和可识别性，
从原记录加载六指标与 planning risk，使用历史 train-only 风险尺度；身份必须
在各 stratum 无歧义、保存池可完整重建，否则中止。将修正选择和保存的原选择
逐 stratum 对比，汇总同一尺度的 ΔR，并使用旧统计函数及原 seed 描述；
其 positive_gate 字段不输出为新 gate。读取前后核对原报告及记录哈希。
输出写入全新独占目录；固定记录重排测试选择不变。此结果只描述已打开数据的
敏感性，不是确认、独立重复、新样本或任何 P1 admission，也不重新认定匹配池。
历史数据的因果、独立性与来源限制维持不变。
