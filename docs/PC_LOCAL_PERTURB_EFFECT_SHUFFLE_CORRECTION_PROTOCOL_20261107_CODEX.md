# 小扰动身份打乱对照：事后修正协议

上一轮打乱的是其他父链的原始扰动分数，因而把父链间分数水平也混入
对照。它符合当时写下的公式，但不是只隔离动作身份的打乱；此前的
8/10 对 4/10 不能解释为动作身份贡献。

本次复用封存的同一 10 根、同一父链、同一 320 条扰动分数和同一错配。
对父链 i 及其四个扰动定义 `delta[i,j] = child[i,j]-parent[i]`；
匹配分数为 `parent[i]+mean(delta[i,:])*4/5`，修正打乱分数为
`parent[i]+mean(delta[mapping[i],:])*4/5`。每根 mapping 保持原固定
无自匹配置换。此对照仍保留每个父链的原始目标代价，改变整组效应与
父链的对应；它不是同一个扰动方向跨父链的严格动作身份干预，因为各
父链的扰动动作不同。评分及选择先独立封存，物理评价再读取轨迹。

从环境同一初态真实执行修正对照选出的十条父链，每条 25 步，并与
既有 640 条父链轨迹核对。报告三臂配对成功、末距、前缀成功、
选择变化。全部数据及成功结果已曝光，修正是事后分析；不能追溯
改变先前事前停止规则或主张统计显著、行动后果贡献或 gate 通过。
