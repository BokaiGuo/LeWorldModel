## 归因边界

当前同时出现模型预测误差及目标度量与物理任务不一致；不能只归因于动力学预测，也不能称整个理论被否定。已使用独立增广最小二乘审计检查全部编译数组，并核对 tanh 参数到命令的映射；真实执行使用既有五步 packet 合同，提前终止会记为失败而非静默吞掉。本轮没有失败分支。

有限目标图像差分投影只消除给定 nuisance 子空间，并不保证投影后距离具有物理任务单调性。本轮结果说明其任务适用性仍需验证，不能把该度量视为已解决的目标合同。尚未证明具体代码错误是历史 P1 的根因，也不应跳过渲染、目标、动作归一化与时序绑定的进一步核验。

这仍是已知根固定程序库的校准证据，不是新根泛化、谱前缀生成、真实未来能力改变、等预算基线胜出或 P1 准入。P1 及其依赖阶段保持未通过，研究未闭环。
