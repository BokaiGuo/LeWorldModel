# Guarded spectral prefix common-suffix development protocol

Before executing, fix both roots and all three prefixes in
`reacher_pc_guarded_spectral_physical_20261102_v1/report.json`. Use every one
of the three previously executed ten-step suffixes plus ten zero actions,
without ranking or selecting a subset. Execute all 3 x 4 combinations from
the identical captured root for each seed. Bind source report hashes and check
original prefix qpos distance within absolute tolerance 1e-8. Save actual
actions, qpos, qvel, evaluator distance, reward and stop/censoring status.

Report absolute final qpos distance, and each suffix's final distance relative
to the same prefix's zero suffix. Both measures are evaluator-only, not inputs
to the RGB-only planner. An independently optimized suffix comparison is
already recorded in the input report and remains distinct. These suffixes and
roots have been exposed to prior outcomes; this intervention is exploratory,
not independent confirmation, a formal statistical test, or PC admission.
