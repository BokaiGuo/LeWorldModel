# PushT RGB 目标角度容差评分：固定池开发试验

动机是已曝光任务 1 的静态交叉中，实际成功阈值内不同物块角度对应很大的原 latent 代价差。检验一个明确、可被否定的版本：只从原目标 RGB 以固定颜色规则提取可见物块，将分割区域绕其图像质心旋转 `-8°、+8°` 并用周围 RGB 修补空洞；原目标也保留。若检测未通过则弃权回退原目标。合成图不保证是可达或真实渲染，遮挡、JPEG、修补伪影和颜色变化均可能使近似失效；旋转图像质心也不保证对应物体真实旋转中心。本方法只使用 RGB，不读取物理姿态，也不训练或重新拟合模型。

冻结已有四个开发任务各 301 条共享前缀动作及共享前缀后的真实观测，使用单帧冻结 LeWM 预测后继，对同一预测分别以原目标和三张目标编码的最小平方距离评分；后者是独立评分版本。两臂候选、模型和预测完全相同；所有三张目标编码的额外成本必须明确记录。按稳定顺序各选一条动作链，评分和动作身份封存后，才读取此前完整物理回放的逐链真实成功标签。真实末帧编码仅另列为评价端 oracle，不输入规划器。目标图提取与分支始终不看真实后果。

报告每任务检测及弃权、原目标重编码误差、每臂实际选择、已评分池成功数、首选实际成功与成功链排名、评分时间及额外编码数。此面板、尤其任务 1，已事后曝光，不能作为独立效果证明；本面板只有有限成功链。若容差评分既没有使已知任务 1 的预测首选成功又保持任务 0 原预测成功，停止扩大这个具体变换，不把目标分数下降或候选改变当控制收益。该开发出口基于已知失败案例而定，不是 PC1/PC3 及统计确认阈值。若达到也仅表示值得在新的、事前冻结的任务和公平完整预算下验证，不能通过 gate。
