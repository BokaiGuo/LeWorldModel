# TwoRoom 旧尾精英更新修正：配对开发协议

旧版在首轮将合法旧尾作为候选，但无条件排除其参与块参数的精英更新。修正版仅在五步块完全恒定时将其精确映射到块参数并正常参加稳定排序；不可表示的旧尾仍仅参加最终选择，不改变旧行为。此差异是可验证的工程设计改动，不预设其改进物理控制。

固定已曝光开发根 10–49，逐根重置同一状态和目标；旧版、修正版均使用 baseline 搜索、每次 680 候选、同一规划种子、相同 25 环境步上限及五步反馈周期。每臂使用自己的真实 RGB 反馈，旧尾重评分并参与最终选择；物理状态仅用于评价端初始化和结果记录。记录每次规划查询、实际执行动作、原始候选评分、旧尾排名、GPU 同步规划时间、成功及整任务时间；早停带来的总预算差异单独报告。

首先执行可表示性与等价单元测试，再执行 GPU 配对实验。各根作为配对单位，报告成功数与双向独胜、代价、查询及任务耗时；比较属于探索性工程验证，不设置事后成功门槛，不作统计显著性、描述组件贡献、独立泛化或 gate 通过声称。保留历史产物，禁止覆盖。
