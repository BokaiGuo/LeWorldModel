# RGB 反馈图像时钟：物理重放审计

对既有 PushT 开发根 0、8 的单帧和历史两臂，从封存初态重新执行已派发动作。每个五步动作包结束后实际渲染，并将重新生成的合法 RGB 历史经原图像预处理后的张量指纹，与该轮三次模型评分的 `pixels` 收据比较；目标图像同样逐次比较。物理状态仅用于评价端重放，不输入规划器。

四条轨迹各 15 步，共 **60 步**；每步隐藏状态快照和奖励最大绝对误差均为 **0**，结束标志一致。每条轨迹的 3 次规划、9 次评分，共 **36 次评分**的 RGB 历史及目标输入指纹均一致。初始快照和像素也与原面板一致。帧顺序篡改测试会使核验失败；相关测试 **3 项通过**。

结果补充了原先仅验证动作历史与派发一致性的审计，但范围仅限这两根、当前环境和记录的单帧／三帧运行；重放使用同一个环境与渲染实现，并非官方实现的独立等价认证。它未重新计算模型分数、证明候选结果的物理排序正确或证明闭环收益。没有发现这些轨迹的图像时钟错位，也不能据此断言不存在其他实现问题；PC0–PC5 不改判。
