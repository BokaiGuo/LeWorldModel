# dev305 切向评分复算与扰动检查

本次使用主机 CUDA 对同一固定模型、同一三前缀及 17×17 两包候选重算，
新增保存全部 `17×17×192` 预测终态减目标 latent 向量及每组 `192×5`
图像切向矩阵。离线重建岭回归分量评分，与本次报告及上一轮报告逐项
一致；分量 argmin 也一致。基础 latent 分数与更早封存结果的最大差为 0。
这填补上一轮无法仅靠保存向量复算评分的缺口，不证明这些分数具有
物理任务语义。

对三幅当前 RGB，分别测试五个扰动轴的负、零、正幅度。四个平移轴的
颜色掩码质心偏移均严格为预期的正负 4 像素；零扰动不改变像素；
45 个扰动均未改变另一对象在原 RGB 中已识别的掩码像素。这里的检查
仅覆盖阈值识别到的像素，不证明分割完整、被遮挡区域正确、旋转角度
等于物理角度或合成图像属于模型训练分布。

没有发现这些已测环节中的简单平移符号、零扰动或另一对象掩码覆盖错误。
但这不排除动作历史、接触建模、图像合成、目标裁边以及编码特征混叠
等其他问题；更不能据此断言负结果是理论失败。该已知根、事后开发
对照仍无新物理执行和独立确认，不改变任何阶段门。

主机 CUDA 成本为编码器 / 投影器各 40 次、动作编码器 / 预测器各
102 次、1734 样本；该费用不覆盖候选生成或物理执行。相关测试 4 项通过。
