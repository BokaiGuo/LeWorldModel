# 精确墙障：预测受阻后侧向脱困开发结果

按[事前协议](PC_EXACT_BLOCKED_DETOUR_PROTOCOL_20261107_CODEX.md)，在
24 个已曝光 exact-wall 任务上，沿用每根 384 个固定 waypoint 偏移。
新臂在预测状态下逐步构造动作；非零移动预测为原地不动时，按预先
规定的侧向和距离插入脱困目标。每条链最多 15 步，每臂每根计 5,760
个动力学预测步。旧对照使用原先封存的 waypoint 链。

| 指标 | 原 waypoint | 预测受阻脱困 |
| --- | ---: | ---: |
| 终距 `<0.05` | 12/24 | 16/24 |
| 配对独胜 | 0 | 4 |
| 平均终距 | 0.25902 | 0.14945 |

新增成功为 roots 9、11、12、14；四条被选中的新链均触发一次脱困。
原先冻结的开发出口为至少 3 根独胜、至多 1 根独负，**此固定配置
达到该开发出口**。这是候选生成的开发信号，不是行动后果描述通过。

## 同控制器消融

原 waypoint 按整段均分步长，新臂逐步采用饱和动作，这也是方法
差异。因此看到结果后，按[补充协议](PC_EXACT_BLOCKED_DETOUR_SAME_SERVO_PROTOCOL_20261107_CODEX.md)
增加同逐步控制器、仅关闭脱困触发的对照；每根仍为同样 384 个偏移、
15 步及 5,760 模型步。

| 指标 | 同控制器无脱困 | 脱困 |
| --- | ---: | ---: |
| 终距 `<0.05` | 12/24 | 16/24 |
| 配对独胜 | 0 | 4 |
| 平均终距 | 0.26349 | 0.14945 |

所有候选在脱困臂首次触发动作之前及该动作本身完全一致，未触发的
候选全链一致；因此在这个固定开发池中，差异由触发后的动作变化
产生。该消融是在看到初始结果后制定的，不是独立预注册确认。

## 核验与范围

重建与重放审计核查 **9,216 条**脱困链、138,240 个候选模型步、
动作边界、16,602 次触发、逐链代价及选中链；同一环境的另一端点
实现与保存轨迹最大误差为 0。无脱困臂也逐链重放，并核对触发前
动作一致。相关测试 **7 项通过**。两个端点计算仍共享底层动力学，
不是独立物理引擎认证。

本结果使用精确状态、已知动作尺度和精确动力学作为预测器；任务、
候选生成方法和开发历史均已曝光。新臂没有访问墙坐标或物理成功
标签，但用了预测的逐步位置和手工侧向策略。相同动力学步数不等于
完整墙钟或资源成本相等。也没有验证未查询后果描述、随机身份打乱、
同等能力的非响应强规划器、真实 RGB 观测反馈或独立任务。

因此，下一阶段可以保留该配置作为**exact-state 开发候选**，先针对
同预算更强控制器和行动后果信息的独立贡献开展事前固定对照；不能
把它当作 RGB-only 或完整 Planning Compiler 优势。PC0–PC5 不改判。
