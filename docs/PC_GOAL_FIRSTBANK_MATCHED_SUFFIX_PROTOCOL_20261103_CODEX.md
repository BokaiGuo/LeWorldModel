# 目标条件化首候选库：共同多起点后缀诊断

目标条件化单配置已按原协议停止；本协议是在看到其结果与覆盖归因后，
对其封存首候选库进行的**新后验诊断**，不续跑原编译器或改变原结果。
问题是：留存阶段有无丢弃在相同固定搜索条件下更容易优化的前缀，以及
搜索结果是否随预算和起点数量改变。它不能完全识别生成、留存、后缀
优化与全链联合精修的因果贡献，更不是独立确认。

对 goal 臂 24 个已暴露根，每根原始全部首段候选（含 zero）固定
五步前缀，后十步均使用同一 floor-CEM、相同四个种子、每起点 160
条完整链；同根不同候选使用共同随机数，随机种子按根与起点固定。
每起点从零均值、标准差 1/3 开始，批量 12、精英最多 4、标准差
下限 0.05；保存所有分数、每起点最佳完整动作、调用数及累计最优。
前缀不得变化；末批、incumbent、动作界限和最终得分须重算核对。
160/640 样本仅为规定诊断预算，不声称已达到搜索上界。

分别在 1、2、4 起点下，基于**同一批各前缀后验搜索结果**报告：
原始 best+farthest 保留两前缀、按原即时评分选前两项、以固定种子
随机选两项、所有前缀的事后 oracle 的最小已找到终距。前三个集合
依据后缀结果出现前就已知的信息定义，随机种子固定为 `2030110300+root`；
但它们的后缀搜索结果仍属于后验诊断，不能称完整规划器成绩。
报告各根完整库 oracle 是否在原保留集合、每种集合与 oracle 的配对
距离差、成功数 `<0.05` 和原始最终链分数；不可用后验 oracle 充当
真实筛选策略。总体耗费计入全部五类前缀的所有搜索，逐项记录
模型调用、链数、五步 token、墙钟时间；此成本不与原 480 token
结果直接作公平优势比较。

复用原精确动力学、候选、已封存协议和审计，核对哈希及根数；所有
输出排他创建。完成后相同种子重跑并逐分数、动作验证，不能将确定性
重放视为独立复现。结果无论正负均停止本诊断，不在此协议上追加
搜索/样本，也不据此改变 PC gate。
