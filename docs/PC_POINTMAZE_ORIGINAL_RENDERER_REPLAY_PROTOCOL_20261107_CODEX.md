# PointMaze 原始渲染器重放：差异定位

针对历史渲染帧与两次新渲染的差异，原样调用 `pc_real_camera_effect_dev_20261106_codex.py` 的 `--backend`，输入旧记录相同的 8 个初始/目标状态、当前官方 XML 和历史脚本指定的 legacy MuJoCo 环境。逐帧比较新输出和历史物理文件中的状态、图像、相机默认值和时钟，并比较两次新实现的相关末帧。

记录原脚本、XML、输入状态、历史及重放输出哈希和本次 MuJoCo 版本。若原脚本当前可复现旧帧而新脚本不能，优先检查新脚本实现；若原脚本当前也不能复现旧帧，则说明差异不只由新脚本造成，但仍不能仅据此断言是驱动、其他依赖或历史文件错误。无需修改旧产物或把当前结果宣传成官方等价。
