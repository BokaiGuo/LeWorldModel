# P1 保存候选的线性与非线性可达评分对照

在先验证 MAIN01 报告、saved receipt、prepare 哈希并重跑已有保存差分审计后，对同一 prefix、同一 suffix 的已保存模型终态进行探索性复算。该分析不执行模型或物理，不改变 P1 gate。模型终态评分为真实保存的模型 latent 终距平方均值，加与原线性代理相同的 logits 正则项；每个候选和其所在臂的 winner-prefix baseline 一致计算。线性 sent 代理则把 `tanh(logits)` 代入相同 Jacobian，保留原正则项。

160 个候选包含每臂一个自身 baseline；排除这 8 个后，152 个候选中，原线性 logits 和线性 sent 代理各有 0 个优于同臂 baseline，而已保存的非线性模型终态评分有 6 个更好，6 个比较的线性 sent 与非线性差值符号不同。最大线性预测向量误差 L2 为 6.6182。六个均位于同一已知 slot，两个方法臂中首个相同候选重复，不能当作六个独立根或六个独立动作。逐项查原报告，六者都 `stage_uphill=false`，虽然 `terminal_better=true`，仍不满足原 P1 非贪心合取。

因此这批证据表明，在这些固定动作上零点 Jacobian 代理与非线性模型 rollout 的候选排序存在失配，值得进一步做预先固定的有限差分、局部尺度和新根验证；它不证明梯度实现错误、物理任务收益或理论失败。模型端使用的非线性评分也不是固定 gate 的替代品，不能因事后看到结果重新定义通过条件。

## 主机 CUDA 同上下文方向有限差分

为区分导数错误与有限幅度非线性，固定使用四个 slot、projected-ascent 臂 winner-start 的迭代 0–3，共 16 个已知上下文，不依赖观察到的排序选择。每个上下文以已保存 suffix 的实际 raw 动作向量为方向，在 `0.001, 0.01, 0.1, 1.0` 四个幅度计算正负对称有限差分，比较保存的 zero-suffix Jacobian 方向乘积；另重放零动作及原后缀。共 160 次 predictor/action-encoder 显式调用，模型张量散列前后一致，16 个零动作与原后缀的 latent 重放最大绝对差均为 0。调用数为脚本显式计数，不是硬件计量或 FLOPs。

16 个方向的相对 L2 误差（分母为对应 `||Jd||`，中位数取排序后第 9 项）如下：

| 幅度 | 最小 | 中位 | 最大 |
| --- | ---: | ---: | ---: |
| 0.001 | 0.000180 | 0.000375 | 0.000953 |
| 0.01 | 0.000200 | 0.000344 | 0.000784 |
| 0.1 | 0.0180 | 0.0318 | 0.0743 |
| 1.0 | 0.3243 | 0.4616 | 1.3237 |

这些结果支持所测方向的局部 Jacobian 与小步模型变化一致，而较大幅度的对称割线与零点导数明显偏离；它不是对全部方向的梯度正确性证明，也不能独立证明物理排序、最终成功或某个理论命题。幅度 1 的数字是对称割线误差，不等于单侧终态误差；方向范数和尺度均保留于来源候选及输出。新实验未训练模型、未访问物理、未打开 P1。

## 上坡前缀与非线性后缀联动探索

针对同一四槽八臂全部 160 个已保存 prefix occurrence（包含跨臂及不同 start 的重复项），固定从原 ridge 后缀出发，对每个 prefix 的预测后继执行 8 步实际模型终距梯度更新；更新使用 raw 动作梯度、一次 `tanh` 链式规则和原动作球投影。九个迭代点按模型终距加同一 logits 正则项选最低分，同臂 winner-prefix 也按相同预算优化。原 P1 gate 未改变，这里的非线性比较仅为事后探索性替代指标。

主机 CUDA 完成 1440 次 predictor、1440 次 action encoder 入口和 1280 次显式反向，模型散列前后一致；160 个原 incumbent 模型终态精确重放。122 个候选是模型阶段上坡；8 个候选的非线性正则化后续评分优于同臂优化后的 winner-prefix，16 个优于原 winner 终态，但所有此类候选都不属于上坡集合，三条件合取为 0。8 个均属于同一 slot 的两个臂，其中存在相同动作，不能当作独立样本。故对这批固定候选，补做非线性后缀优化仍没有获得短期上坡且后续受益的模型见证；不能据此对新前缀、独立根或真实物理下结论。

结果 `le-wm-main/results/p1_uphill_nonlinear_suffix_host_20261029_MAIN01.json` SHA `57ebca39de04755c1a5e3b91d388cbca80b50311772a41d73ce7f5aa16c5c4ef`。独立 saved consumer 重算所有保存的动作、迭代、目标值、argmin 和合取，通过；它不重新执行模型或计算梯度，也不提供硬件真实性证明。工程测试 2 项通过。该探索是在观察历史结果后提出，不能作为预注册独立确认或绕过物理、强基线和科学门槛。

## 分离目标接近与额外 ridge 增益

对同一 160 个 joint Vreach 候选 occurrence，按各自零后缀 nominal MSE 减有界 ridge 目标计算正则化线性增益，并与同臂 winner-prefix 计算相同增益。74/160 的增益更高，其中 60 个同时满足模型阶段上坡；但原模型终态优于 winner 与上坡的交集仍为 0，因此上坡、增益更高、终态更好的交集也为 0。候选跨臂和起点有重复，四槽只有两个已知根；这些数字不是独立样本。该事后指标是模型局部代理，不替换原 gate、不产生新动作或物理结果。
