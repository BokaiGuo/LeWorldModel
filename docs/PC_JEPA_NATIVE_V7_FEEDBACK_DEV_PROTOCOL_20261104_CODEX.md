# JEPA 原生 PushT：隔离 v7 真实反馈开发协议

## 范围

在已暴露的原生 seed 2026102701 上做一次两臂开发性闭环，检验历史保持 JEPA rollout 与 v7 编译器能否在实际原生环境闭环接线。不得声称该 seed、目标、checkpoint 或 normalizer 独立；不将单根结果作为 PC0–PC5 通过、强搜索上界或统计优势。

固定种子生成器和官方 wrapper 的生成规则，取同一个 `RandomState(2026102701)` 的第二个 state 为指定目标；目标经另一个同配置原生环境 reset 得到目标 RGB 和物理评价状态。目标在规划前固定，目标物理状态不传给规划器；不使用未来轨迹、逐根调参或后验换目标。目标 reset 多走 0.01 秒的实际状态作为评价状态。

每臂从各自原生实例 reset，按既有固定 schedule 前 10 步暖身，并将 0–10 每个边界的 RGB、状态、proprio、公共物理状态、transition 与封存参考精确比较；任一步不一致则该臂停止，不派发规划动作。保持实时环境继续执行，不通过七维状态恢复。两臂先后运行，规划器仅接收该臂已有 RGB、本体、历史动作、固定目标 RGB、模型元数据和自身旧尾部。

## 规划与物理

- 每臂三次决策：固定终点剩余 15/10/5 原生命令，每次执行完整链前 5 步。历史图为物理时间 0/5/10、5/10/15、10/15/20；历史动作相应平移。每轮保留自身旧尾部并在新观测下重评分。
- 冻结同一 v7 response 核心、JEPA checkpoint 和历史保持 rollout；另设四结点 smooth CEM。两臂各 1920 prediction-token/轮，包含初始化及最终比较。CEM 首轮从零链；后两轮在共同评分 zero 与自身 carry 后，以两者为基底近等分剩余样本并保留所有已评分的最好链。此为开发对照，不等于完成强基线调优；相同 token 也不意味着计算总成本相同。
- 模型目标为完整链终态视觉 patch MSE；二维 chart 的目标方向和固定种子随机正交方向仅用于 v7 响应生成，不输入物理状态。保留全部候选动作、模型预测、精修、弃权、计量和完整所选链。
- 动作是原生 env 参数 `u`，每坐标限制 `[-1,1]`，物理 `env.step(u)` 内部乘 100 并以当步 agent 坐标为相对目标。模型按原生统计 `(u-mean)/std` 打包；不额外除以 100。每 packet 五个连续命令；每条命令前持久化绑定决策与意图。
- 物理进程只将白名单输入包挂入 bwrap 规划进程；隐藏原数据、旧结果和其他臂，禁止网络。记录禁止路径探测；这是针对已知位置的开发隔离，不是恶意代码信息流形式化证明。GPU 任务使用共享锁和固定 UUID。
- 实际评价单列 agent/object 位置误差、角度误差及官方 wrapper 规则：前四坐标联合欧氏差小于 20 且 wrap 角差小于 π/9。记录每条状态和每个边界 RGB，不把模型 MSE 当成功。无视原生覆盖奖励作为此目标成功指标；超时、非有限、提前停止或模型／重放错误均原样记录，不换根、不重新挑结果。

## 停止和审计

发生接口、来源、重放、时间或资源合同异常时停止该臂并保留失败；不因负结果自动改配置。所有文件新建且不可覆盖。之后对派发动作、时钟、输入白名单、每轮预测计量和物理结果进行独立保存数据审计；必要时再以同后端重新执行。整个协议是 single-root development，不宣称训练来源、拟合来源、物理可解性或 PC gate 通过。
