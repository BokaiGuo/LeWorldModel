# 分段 CEM 48/160 选链的事后评分分解

针对已观察到的 48 与 160 次预算的物理差异，进行明确标记为事后探索的同链分解：沿用两条先前已封存的选链、预测目标代价及物理轨迹，不重新选择动作。每根从轨迹末态以校准相机重渲染两个后继，并从私有目标状态重渲染目标；记录重渲染目标相对归档目标图的像素误差，不据此挑选样本。

冻结同一模型和同一视觉加 0.1 proprio 目标，对两个真实重渲染末态编码，分别记录预测代价、真实编码代价和物理末距，逐根检查三种排序；比较编码选项只是评价端 oracle，不能回流规划。两条链相同时标记并保留，不能作为排序正确对。当前只覆盖八个已曝光任务，目标图与后继重渲染可能存在差异，末距不是完整成功规则，也不能把任何单一不一致自动归因于特定模型或评分 bug。
