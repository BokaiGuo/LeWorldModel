# State-assisted 目标图像平移归一化：开发协议

此试验针对已观察到的相机平移敏感性，不属于此前二阶外推配置，也不改变其停止结论。本地 PointMaze JEPA 使用 proprio，所有结果仅为 `official_state_assisted`。

## 规则与边界

仅从当前任务的目标 RGB 估计变换：选取同时满足 R>150、G>80、10R>12G、10R>14B 的像素，要求像素数不少于1000、外接框宽高均在80–180像素，取外接框中心。将中心平移到既有 224 像素标准视图中心 `(x=111.5,y=125.5)`，四舍五入为整数位移，超出20像素则拒绝。边界用最近像素填充；记录填充区域，不称其真实相机观测。对当前 RGB 和目标 RGB 应用**同一个由目标图像计算的平移**。不读取物理状态、相机参数、其他任务图片或未来观测来估计变换。

该颜色阈值和标准位置是在已暴露面板上制定的任务专用启发式；无法泛化的样本必须拒绝，不得隐式回退或挑掉失败样本。不训练网络。部署时 state-assisted 模型仍按官方配置接收当前 proprio，不能叫 RGB-only。

## 固定实验

使用既有4个 episode（1880–1883）、起点0/目标5、两视角与 raw x 动作 zero、+0.1、-0.1，5个环境步。两臂是 `raw` 和 `goal_rgb_centered`，同模型、当前 proprio、目标、候选与动作归一化，仅图像预处理不同；各臂分别记录输入、候选代价、选择、完整调用数、同步耗时及图像变换耗时。目标变换、编码和所有预测均计入各臂测量；模型加载和物理评价不计入规划测量。该小样本不代表完整闭环成本。

旧实验已暴露该面板，raw 评分须与原实验一致（atol=1e-6, rtol=1e-5）。对同一任务同视角的当前、目标图像核验它们应用完全相同的目标变换；报告两视角有效重叠区域的像素差，不使用该差反向调参。

选择先封存，物理轨迹和位置标签由独立的后置审计读取；物理遗憾相对 three-action bank 最佳终点，另外报告 zero baseline。报告每任务两个视角合并后的统计。

预定开发出口：相对 raw，归一化后的跨视角选择不一致任务数减少，且归一化双视角平均物理遗憾不高于 raw；同时4任务全部通过图像几何合同。即使满足，只允许后续做更严格的未暴露任务和完整成本验证，不能认定规划优势。失败则停止此具体启发式，不换阈值挽救。
