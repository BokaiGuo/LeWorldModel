# PushT 任务／求解器种子分离与执行动作审计（开发）

固定既有 PushT 任务采样 seed 42、reset seed 771001、50 个
任务、25 步目标偏移、50 步执行预算；仅将原生 CEM 的求解器
seed 分别设为 42、1042、2042。均为 300×10，使用相同
checkpoint、预处理、原生最终均值和评价规则。该开发运行不
调整动作、不裁剪、不筛除失败；对每一步记录执行时真实动作、
完整环境快照和终止状态，报告越界次数及涉及任务。

每臂任务列表必须相同，比较每个 reset seed 的首次动作之前的
完整物理快照；不匹配则拒绝将其称为配对结果。环境任务采样 seed、
求解器 seed、reset seed 分别记录。任务从开发集选取，不作
独立确认；reset 一致不能证明重建了数据集原有全部物理状态。

动作合法域由 `PushT.action_space` 的 Box 给出；不额外更改
原生 CEM。记录原始真实成功，也报告严格动作合同下越界情形，
但不删除案例或重新定义原生成功。下一阶段另行实施与测试受约束
求解器，在候选生成、评分、执行各阶段使用一致的动作边界。
所有结果路径预先约定并拒绝覆盖。
