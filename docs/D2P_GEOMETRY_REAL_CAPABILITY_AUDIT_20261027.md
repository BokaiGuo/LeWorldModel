## 候选生成：修复数值参考，不修改科学目标

旧 full-packet 编译器从当前根生成十个固定谱候选，并逐个重算未来 K。
这不是证明有错误的 detach：固定候选时 detach 合理；但候选生成没有直接搜索
未来 K(B) 的变化。因此新增 full-geometry 与 stopK 对照，各保留原十候选，并
添加两个由有限差分优化得到的候选。只有 stopK 导数评分冻结中心 K；两者都
刷新状态、残差和阶段代价，执行相同探针测量预算。

v2 实际完成 3,092 个 CUDA 预测样本、936 次向量化 Jacobian、179,712 个标量
VJP 方向，96 次独立两 token 重放精确一致，但六个候选的 NumPy float32 tanh
参考误差为 1.1920928955078125e-7，超过原 1e-7 验证界。原失败报告保持不变。
这属于验证参考数值问题，不是理论负结果。

v3 仅改用 float64 数学 tanh 参考，阈值仍为 1e-7，最大差约 8.274e-8；目标、
候选搜索和动作限制不变。实际同等预测/Jacobian预算下六项门全部通过，
`plans_sealed`，96 次重放精确一致。

四根的 geometry-term/full-gradient 范数比为 .4730/.4459/.3515/.6054，半步
差分相对差异约 .95%/.91%/2.32%/1.82%。但八个 root/arm 的最终赢家仍全部
来自原共同十候选。根1 geometry 的 selected=6、greedy=10 是 greedy 参考
改变，不是选出了更好的新策略，更不能由此声称 P1 成立。

## 123 分支真实能力探针：RGB响应不等于物体响应

根资格仅来自封存v3模型报告（geometry selected != greedy），得到根1；没有
读取96分支物理标签来选根。固定selected/greedy/zero三个前缀，每个前缀接
zero后缀及十维动作在 .05/.1 两档半径上的正负坐标后缀，共41×3=123分支。
后缀围绕零而非模型优化tail；所有分支均5+5步；不优化、重选或训练。

主机实际运行已完成：123/123完整分支，1,230步骤，246次CUDA编码，6/6响应组，
六项完整性门全true，failures为空，`diagnostic_recorded`，新增预测为0。
输出为
`le-wm-main/results/pusht_geometry_capability_20261027_v1_cuda_v1/report.json`。

真实有限差分响应分别在原192维RGB/Q和固定物体特征
`phi=[x,y,20cos(angle),20sin(angle)]/512` 中测量。phi是诊断代理，不是新官方成功
定义，不进入方法选择。两空间均用原 .002 ridge 和 sqrt(5)*.75 动作球，但
空间维度/尺度不同，不能比较跨空间拟合值的大小。
拟合本身是平方和加`.002||u||²`，再整体除以维数报告，不是
`MSE + .002||u||²`；同lambda不等于跨空间同等正则化强度。

| 前缀角色 | 物体响应Frobenius范数 eps=.05 | eps=.1 |
| --- | ---: | ---: |
| selected | 0 | 0 |
| greedy | .01894999 | .01860587 |
| zero | .08279824 | .08267576 |

selected 的RGB原始响应范数分别21.71799/17.75195，RGB响应随eps变化很大，
相对矩阵差约1.1504。故此处不能把latent响应解释成稳定的物体可控性提高。
结论限于这个前缀、五步后缀和两档小探针；不声称更大动作/更长horizon无效。

selected减greedy的拟合代价（负值较好）：

| 诊断 | eps=.05 | eps=.1 |
| --- | ---: | ---: |
| RGB-Q，分别使用各自残差 | −.163832 | −.213283 |
| RGB-Q，固定zero角色公共残差 | +.229333 | +.087276 |
| 物体phi，各自残差 | +.00331350 | +.00331006 |
| 物体phi，公共残差 | +.0000122483 | +.0000131246 |

各自残差改善并不能独立识别几何提升；固定残差后selected不优于greedy。
这使“表示/评分偏好agent运动而未恢复物体控制”成为更具体、待修复的机制
缺口，不是已证明全局理论失败，亦不是已经排除了所有代码问题。

独立复核进一步确认selected的41个后缀物体x/y/angle全相同。物体pose由
root初始54.4502升至selected第5步113.2919，而zero后缀第10步仍113.2919：
这是已观察退步，尚未证明“暂时”及恢复。selected的Q线性拟合达到动作球上限、
跨epsilon响应变化大，拟合动作没有执行，不可当作已实现收益。另外复用的编码

输入、日志与PNG哈希。9项正确与损坏收据反例测试通过，实际复算通过：
