# TwoRoom 原搜索链保留：已曝光开发诊断

上一轮保留 A 最佳链但遗漏了来源 block-CEM 和 block-random 的原最佳
完整链。这是候选选择规则的限制，不能凭模型分数推断修复后的真实
成功。这里使用已曝光的 root 10–49，固定选择和评估规则，不更改
上一轮结果或 gate。

每根取上一轮四臂各自实际选择链，以及原两组 300 链模型分数最小的
各一条，按相同 RGB、goal、动作归一化、冻结 checkpoint、同批次重新
评分六条链（重复链也计次）。各臂只将自身旧选择与两条共同 incumbent
竞争，按新模型分数最小者选择，平分先旧选择、再 CEM、再 random。
先封存动作、分数、选择及源数据哈希，再在评估端实际 reset 并逐步
执行各臂选中链；必须与对应来源链已保存的物理轨迹完全一致。

比较修改前后各臂物理曾成功、最后成功、成对独胜／独负，以及新增
模型评分、旧新评分漂移和近并列。统一评分不使用未来真值。所有臂
共享相同候选权限；两原池的各 300 次生成评分和原 88 次臂评分都
计入来源成本，本次每根额外 6 次评分为实验联合审计成本，单臂逻辑
需要 3 次统一重评分，不能将其与 300 次基线宣称等成本。

此规则在查看上一轮结果之后提出，所有根均已曝光；无论结果如何均
为开发诊断，不能回溯改变原开发出口，更不能据此宣称独立性能或
Planning Compiler 机制。模型分数变优不保证物理成功。
