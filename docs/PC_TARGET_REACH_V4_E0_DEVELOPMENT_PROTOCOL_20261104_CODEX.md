# v4 目标可达与后继响应：E0 开发协议

新版本使用目标残差按 `σ²/(σ²+0.1)·(uᵀr)²` 排序局部
响应模态，对两个名义动作的非零模态生成正负前缀。对全部候选
在同一名义后缀计算后继响应和无约束岭局部价值；保留即时最佳、
局部价值最低，再按后继响应矩阵的最小距离依次选择至多四项。
其余后缀 CEM、全链联合精修、非线性最终评分和零前缀弃权沿用
相同职责，所有探针从 1920 token 上限扣除；两个 SVD 实际均计数。
该版本是二维、五步 packet、固定 15/10/5 时域的开发实现，
不是通用维度或完整原方案，也不预设谱增量。

在已暴露的 tail-local 24 根上，仅运行首次 15 步规划，对照同根
封存 v3 response；输出完整预测、响应、局部价值、保留、精修、
选择及成本。事前固定比较平均终距、中位数、`<0.05` 数目、
配对胜平负、各阶段 token 和响应／SVD 数；不得事后更改预算。
计划和逐批重算审计独立封存。比较仅是方法开发，不是闭环性能、
来源独立确认、PC2 机制或 PC3 通过。不得将 v3 的旧机制见证
嫁接到 v4；v4 的实际精修后选中链须另行干预。
