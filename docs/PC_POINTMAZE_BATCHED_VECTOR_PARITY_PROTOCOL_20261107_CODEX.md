# PointMaze 双前缀保留的批处理决策核验

在原 1884–1886 已曝光 state-assisted 输入上，使用相同种子预定生成
3 父链、4 条共同探针尾部和 2 条共同评价尾部。测试 parent、
lookahead、vector 和行内动作身份打乱四个现有规则，均保留两个前缀；
每个任务规则先用逐条、再用批量 4，使用同一冻结权重、目标、标准化
和完整 proprio。每臂 `3+3*4+2*2=19` 次逻辑评分。

保存每臂全部父链、探针和尾部代价、保留前缀及最终动作，比较最大
绝对分数差与实际决策。因近并列可能放大数值差，只有每臂在 `1e-5`
内且所有保留、最终候选和动作一致，才允许宣称**本面板**批处理
决策一致；不预设全模型等价。额外记录前两个保留槽的选择是否不同，
而非只看最终动作。预测调用和 GPU 同步时间单独记录。

这仅是批处理可用性测试，不扩大先前已停止的向量方法实验，不含
新物理或预测后继标签，不能建立算法、RGB-only 或 gate 收益。
