# 统一模型调用预算开发对照 v1

本协议是四个已暴露 PointMaze 开发根的探索性比较，不是独立确认。沿用封存真实 15 步运动热身、同一冻结模型、目标 RGB 和动作归一化；每臂执行 15 步，先执行 5 步，获得真实 RGB 与实际动作历史，再规划执行 10 步。

四臂：谱候选库完整链选择、固定/随机无谱候选库完整链选择、谱同库前缀即时评分 greedy、直接完整 15 步 CEM。谱候选在零动作附近中心有限差分获得两个响应方向正负，包含 zero、固定和随机动作。无谱使用同一固定和随机库；greedy 使用与谱臂相同候选库，仅选择即时评分最佳前缀。每臂独立运行，不共享免费计算；采用相同模型评分和三帧历史接口。该试验测已有谱方法，不根据后验结果挑前缀。

每臂 root 阶段上限为 1300 个预测 token-样本（每个动作包预测步计一 token）；cp5 阶段上限为 200 个预测 token-样本。编码上限为每阶段三次上下文编码；全局目标编码与模型加载分别报告为一次性共享开销，不分摊或假装零。前缀 5 步预测消耗 1 token，15 步预测消耗 3 token，10 步后缀预测消耗 2 token。有限差分的预测也从同一额度扣除；无谱、greedy 与 CEM 可将未用于谱计算的额度用于自己的后缀/全时域搜索。不将 SVD、编码或反向机械折算为预测样本；分别记录样本、调用、token、SVD、反向和同步 wall time。此处无反向，SVD 无统一等价换算，wall time 只测量并报告，不能从共同 token 上限断言完全等算力。

谱臂每个候选 24 个 15 步链样本，无谱每候选 36 个；批量确定性采样取最低模型目标。greedy 在选择前缀后用剩余 token 上限优化尾部；CEM 使用预算内完整链样本。各臂 cp5 采用 96 样本固定噪声的相同后缀优化器。保留所有 root 计划及 cp5 计划，分别在执行前封存，记录实际 RGB 和动作绑定。

物理结果只在全部决策封存后回放；预算曲线仅有 root 终点和反馈后终点两个固定预算点，不能将它们解释为完整时间-性能曲线。相同数据与计算上限不保证各方法的实际 wall time 相等；训练来源和独立根未知。
