# TwoRoom RGB 几何候选开发结果

## 决策

修复一个确定的重规划实现问题后，固定几何规则与冻结模型选链均为
**40/40**。因此本实验没有显示模型评分相对固定几何规则的成功率增量，
更不能据此宣称行动后果描述或 Planning Compiler 的增量。40 个任务已
用于先前开发，不是独立确认，也不是官方标准性能集。

| 版本与臂 | 成功 | 全任务评分链数 | 模型 packet 步数 |
| --- | ---: | ---: | ---: |
| V1 模型选择 | 40/40 | 2,656 | 8,944 |
| V1 固定几何选择 | 17/40 | 2,816 | 9,088 |
| V2 模型选择 | 40/40 | 2,704 | 9,024 |
| V2 固定几何选择 | 40/40 | 2,592 | 8,864 |
| 既有 CEM16 | 14/40 | 3,104 | 9,488 |
| 既有 CEM300 | 37/40 | 48,900 | 165,000 |

几何臂实际不需要模型评分；本实验为了记录同池模型分数仍执行并计入
所有 16 链查询，因此不能将表中几何臂的查询数当成其最小运行成本。
两臂采用相同候选生成规则，但执行分歧后观测和候选池不再逐项相同。
既有 CEM 同任务、同动作与时域，但候选生成不同，不是描述组件消融；
也未在本实验同步重测 CEM 的完整墙钟成本。

## 实现问题与修复

V1 每次重规划重新把机器人送向固定门前点。任务 0 在靠近门的
x≈106 时再次向左，造成持续后退；V1 的 40 对 17 不能作为模型优势。
V2 在已越过门前点时先在当前位置对齐门，再前往另一侧；其余候选偏移、
评分、预算、执行规则不变。V1 和 V2 原始结果均保留。

V2 的 331 次规划没有视觉解析失败；记录中的最大起点识别误差约
0.198 像素。视觉解析和两侧偏移是 TwoRoom 专用、手工设计的几何先验，
不应扩展为通用视觉模型结论。两臂中模型执行了额外评分，而几何臂可
直接行动；因此当前数据更支持把该几何规则作为受限开发任务的强基线，
不支持进一步扩大此候选集以证明描述贡献。

新增测试 **9 项通过**。独立脚本复现了 331 个候选池和 **1,481**
个物理步，核验候选、选择索引、时钟、动作、距离和终止；未重新运行
GPU 模型评分。权重运行前后指纹一致。评价端使用真值重置和评估，
规划接口只传 RGB、旧尾和模型分数，但本次未进行进程级隔离。Gymnasium
仍报告观测类型与动作转换警告。

下一项方法探索不能以这个饱和几何面板作为独立确认；应继续固定权限和
真实成本，检验后果信息在普通几何或 lookahead 无法解释时是否改善
合法搜索。PC0–PC5 不因本结果改判。
