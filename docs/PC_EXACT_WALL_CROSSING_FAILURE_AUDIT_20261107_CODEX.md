# 精确墙障候选越墙审计

对已封存的逐步和时序成块尾部实验，重新执行全部候选链的精确动力学；
本次是事后失败分解，不是新搜索实验。

| 统计 | 逐步 CEM | 时序成块 CEM |
| --- | ---: | ---: |
| 候选链 | 73,728 | 73,728 |
| 曾到墙右侧的候选 | 16 | 357 |
| 出现过越墙候选的根 | 6／24 | 11／24 |
| 八前缀最低代价链曾越墙的根 | 0／24 | 0／24 |
| 至少一次撞墙被拒的候选 | 42,678 | 49,881 |

成块臂的 357 条越墙候选有 336 条来自同一个根，不能将它们当成
独立任务。该根最好的越墙链终距约 0.59247，最好未越墙链为
0.50004；其余出现越墙候选的根也由未越墙链取得更低终点代价。
因此当前有限预算内不仅越墙候选稀少，出现的越墙链也没有完成
后续回到目标附近的动作，末帧目标距离会选择墙前停留。这个观察
不能证明所有越墙链都会更差，也不能证明模型实现存在 bug。

审计重算两臂共 147,456 条链的终点代价，逐条检查与原记录一致；
区分曾越墙、最终在墙右侧与碰撞拒绝。针对越墙统计和代价不一致拒绝
的相关测试共 3 项通过。这里的精确墙障是分析环境，不是 PushT 或
RGB 物理实验。后果描述、算法收益和 PC0–PC5 均未由本审计通过。
