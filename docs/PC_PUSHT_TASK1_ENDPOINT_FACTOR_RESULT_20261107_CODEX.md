# PushT 任务 1 成功／失败末态静态交叉干预

对上一轮候选池中唯一末帧成功链和原选失败链，分别取其物块姿态和推杆位置，交叉生成四个零速度静态状态；同一冻结模型和原目标图评分。所有状态的位置重置误差为 0，两张原始配对图的编码与先前真实末帧编码最大误差分别为 9.54e-7、1.14e-6。

| 物块姿态来源 | 推杆位置来源 | latent 目标代价，越小越优 |
|---|---|---:|
| 失败链 | 失败链 | 71.776 |
| 失败链 | 成功链 | 58.467 |
| 成功链 | 失败链 | 230.004 |
| 成功链 | 成功链 | 224.532 |

固定失败／成功物块姿态时，把推杆位置从失败链换到成功链，代价分别下降 13.309／5.472；固定失败／成功推杆位置时，把物块姿态从失败链换到成功链，代价分别上升 158.228／166.066。该案例的错误排序在两种推杆位置下都保留，不能简单归咎于推杆位置。

环境实际成功规则是**推杆及物块二维位置的联合距离 < 20，且物块角度差 < π/9**。四格联合位置距离依表顺序约为 43.50、27.05、37.42、15.50；物块角度差分别约 0.154、0.154、0.305、0.305 弧度。成功链物块位置更接近目标，但角度反而更远；它们同时变化，因此这个二维交叉并不能单独判断评分偏重角度、位置、遮挡还是其他视觉因素。

交叉状态属于静态评价端构造，可能不可达或存在几何遮挡；重置状态验证不能证明完整物理动力学与原轨迹等价。这是事后挑出的单任务机制诊断，不是部署评分、描述贡献或闭环性能。物理状态未用于规划器，PC0–PC5 不变。相关已有身份与评分测试 **6 项通过**。
