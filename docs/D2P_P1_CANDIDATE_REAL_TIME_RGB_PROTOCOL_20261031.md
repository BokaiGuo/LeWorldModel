# P1 四起点候选：逐步真实 RGB 目标距离诊断

对已固定的 24 个前缀、每个前缀的四个已真实执行候选，编码每个
已返回后缀步的真实 RGB，记录其距原任务目标 latent 的 MSE、物理
状态和原生终止。所有可用帧均纳入；原生停止后不构造缺失帧。
同前缀按相同步数比较模型赢家与其他候选，重点单独报告非赢家
实际成功的时刻，而不能用后验物理成功重新选择规划动作。

逐个绑定既有来源、候选动作、物理报告、帧与状态身份；冻结模型、
归一化及目标沿用原合同，主机 CUDA 编码，不训练。此实验只回答
真实 RGB 表示与物理结果在观察时刻是否一致；不能从真实未来 RGB
获得一个可部署的事前 selector，不是公平成本或独立泛化确认。
