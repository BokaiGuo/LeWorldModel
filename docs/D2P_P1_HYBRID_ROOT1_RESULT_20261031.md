# P1 混合谱候选：已知根 1 开发结果

> 更正：随后发现本次实现对 SVD 右奇异向量单独做符号规范化后才
> 计算阻尼解，破坏了左右奇异向量的配对。因此本次 RUN01 不能作为
> 正确目标条件化混合方法的结果；以下仅保留为代码缺陷运行记录。
> 修复、测试和 RUN02 见 `D2P_P1_HYBRID_SVD_SIGN_REPAIR_20261031.md`。

按 `D2P_P1_HYBRID_ROOT1_PROTOCOL_20261031.md` 固定候选顺序与去重规则，
主机 RTX 5060 Ti CUDA 完成四次规划及 20 步真实反馈执行，原生成功为 false，
未发生执行错误。最终物体位置误差 66.00148、角度误差 0.19442。
同一已知根上的旧谱初始化分别为 56.3030、0.10359，目标条件化初始化
为 147.7689、0.58752；三者均未原生成功。这些是开发性描述，不能作为
独立确认或公平预算胜负结论。

新方案四个节点初始候选均有八个互异动作；选中序号依次为 0、1、1、6。
首节点最佳模型 MSE 为 0.30141252，与旧谱报告的 0.30141 一致到其
报告精度；后续真实状态随所选动作变化，不能视为同状态配对。
没有从该结果得出目标方向必然有效或无效的结论。

保存态检查验证四节点初始候选互异、动作字节与执行一致、保存分数、
模型冻结以及预测 hook 和 Python autograd 调用账本：每节点 75 次预测、
208 次 grad。物理事件链未独立逐事件复演，调用数不等于完整 FLOPs，
且前缀生成总预算和其他强基线尚未公平认证。

重复候选是可证实的计算浪费，新混合库是探索性算法变更而非对历史
科学结论的自动修复。本次没有完成共同后缀因果干预、独立根或强对照，
不能证明真实重配置能力，也不能开启 P1。
