# v22 单因素角度：静态开发诊断

按[协议](PC_JEPA_V22_STATIC_ANGLE_PROTOCOL_20261105_CODEX.md)，对一个已暴露任务的八个末态分别改变物体角度，保持 agent 和物体位置，使用去碰撞点的静态绘制及冻结 encoder 评分。每个末态的原生图和状态与物理记录逐元素一致；恢复角度和位置后原生图逐像素一致。64 张图评分完成，未运行规划器或物理反事实。

| 末态索引 | 前缀类型 | 评分与绝对角偏差同序 / 非并列对 | 零角偏差的分数排名（1 为最低） |
| ---: | --- | ---: | ---: |
| 8 | 零 | 22/25 | 1 |
| 9 | 零 | 25/25 | 1 |
| 24 | response | 21/25 | 1 |
| 25 | response | 24/25 | 1 |
| 40 | CEM | 25/25 | 1 |
| 41 | CEM | 23/25 | 1 |
| 56 | 特权见证 | 16/25 | 5 |
| 57 | 特权见证 | 19/25 | 2 |

每行另有三个绝对角偏差并列对；候选图并非独立任务。前六个末态的目标角分数最低，但两个见证末态不满足这一点；这提供了评分对角度有敏感性、且在某些固定几何下排序不单调的有限证据。agent 与物体位置、遮挡和目标图仍会影响评分；不能据此断言 encoder 忽略角度，也不能认定真实执行的因果失败。

本实验在预检中发现一个具体的测量实现问题：Pymunk 修改角度时 `block.position` 可随之变化。第一版在位置校验处失败；第二版设置角度后恢复位置，但严格浮点相等在第七个末态失败。最终第三版保持恢复位置，并以 `1e-10` 绝对容差检查非角度几何；此前两次失败记录保留，不能计为实验结果。目标的原生图与去碰撞点图相差 21 个像素通道；八个末态分别相差 0、0、0、0、24、9、21、90 个通道。最终比较两侧均使用去碰撞点图，不代表真实观测无 overlay。

CPU 单独循环重算八行全部成对排序，并核对评分向量，算术一致；未独立重跑 encoder 或渲染实现。完整输入图、评分及记录见[运行结果](../le-wm-main/results/pc_jepa_v22_static_angle_v3_20261105_codex/report.json)、[渲染记录](../le-wm-main/results/pc_jepa_v22_static_angle_v3_20261105_codex/render.json)与[编码记录](../le-wm-main/results/pc_jepa_v22_static_angle_v3_20261105_codex/output/encoded.json)。编码成本未做完整系统计量。

此图像集含评估专用特权见证、单根目标与相关末态；几何修改不保证可达，不检验动作预测或规划收益，也不是独立确认。PC0–PC5 均不改判。后续应在来源合格的多根、非特权可执行动作上区分预测误差与评分误差。
