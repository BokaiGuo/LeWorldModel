# v3 目标距离响应：事后归因

按[诊断协议](PC_V3_TASK_RESPONSE_ATTRIBUTION_PROTOCOL_20261104_CODEX.md)，
对 24 个已暴露根、五种前缀和两个尺度计算目标距离梯度；随后用
同一精确动力学重新执行 **5040** 条扰动轨迹，终点和阻挡序列与
封存结果一致（最大终点误差为零）。结果和[重算审计](../le-wm-main/results/pc_v3_task_response_attribution_20261104_codex_audit.json)
均独立保存。

对原 1/24 见证的根 20，在 `.01` 尺度取 selected 的单位负距离
梯度作为共同动作方向，距离方向导数为：

| 前缀 | 名义终距 | 共同方向上的距离导数 | 与 selected 梯度差范数 |
| --- | ---: | ---: | ---: |
| selected | 0.10883 | -1.18222 | 0 |
| zero | 2.76302 | +0.84994 | 2.04493 |
| same-bank greedy | 1.27767 | -0.92475 | 1.29695 |
| matched random | 2.19372 | +2.43554 | 3.75655 |
| 原记录中的 lookahead | 2.15386 | +1.76815 | 2.98230 |

两尺度下该根的阻挡分支均稳定；selected 的距离梯度在 `.01`
与 `.05` 两尺度之差为 `0.00098`。但 selected 离目标较近，直接
距离中心差分与链式梯度的 L2 差在 `.01/.05` 分别为
`0.01039/0.18265`，提示较大扰动下距离非线性不可忽略。
全 24 根最大梯度差约 `1.18636`，不得把这个线性近似视为全域有效。

这些量表明该见证附近存在任务距离方向上的局部差异；不同前缀的
名义终点和目标残差也不同，因此它们不是单独隔离动力学响应变化
的因果干预。共同方向由 selected 事后构造，不是其实际执行动作；
原 `lookahead` 来自整链 CEM，不是同库普通 lookahead。不能据此
追加事前见证、证明完整中介机制或宣称 PC2 通过。
