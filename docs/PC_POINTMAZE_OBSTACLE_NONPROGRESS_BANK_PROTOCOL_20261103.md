# Model-selected non-progress spectral bank: development protocol

Use the four previously exposed obstacle roots and the frozen model and RGB
goal from the sealed obstacle source experiment. Derive the two right
singular directions of the repeated-action five-step proprio-token
Jacobian at zero. Form exactly nine raw action candidates: zero and
`+/-0.3`, `+/-0.6` times each of the two unit singular directions, each
repeated for five physical actions. Score all candidates with the same
frozen model and target-token squared distance.

For exploratory selection compare the predicted successor score to the
current encoded token's target distance. Among nonzero candidates whose
predicted score is at least the current score, select the lowest predicted
score, breaking ties by bank index. If none exists, report no selection,
not a gate pass. Also retain the unconstrained bank minimum and the zero
candidate. Execute all nine candidates for every root, preserving the
selected identity before physical evaluation. Report true initial and
step-five goal distance for all candidates, plus RGB observations and model
scores. Initial RGB has the source contract's zero-velocity estimate;
physical velocity may differ. Do not use physical outcomes to choose actions.

This is a proposed proxy on exposed development roots, not the original
pre-registered gate or a complete future-value selector. It does not show
improved future capability, independent generalization or equal-budget
planning. The score compares learned proprio representations, so its
non-progress condition is not equivalent to true physical goal distance.
