# 固定前缀共核 RGB 接入：GPU 工程等价结果

按 `PC_FIXED_PREFIX_SHARED_RGB_PARITY_PROTOCOL_20261107_CODEX.md`，
在三个已曝光 TwoRoom 任务上，以相同 RGB 输入、父链、探针和尾部，
对比旧 RGB 编译器与新共核 RGB 适配器。四种规则共 12 个条件，每个
条件两实现各评分 11 条链，合计 264 条逻辑评分。

- 所有父链、探针和尾部评分最大差 **0**；保留前缀、最终候选身份、
  动作和计数均一致。
- 冻结模型指纹前后相同；全部运行收据的轨道为 `primary_rgb`。
- 两版编译器与共享核的合成测试共 8 项通过，其中包含保留两个前缀的
  四种规则对齐。GPU 检查每次只保留一个前缀，**未检验实际模型下
  vector 多样性第二个前缀的数值稳定性**。

原始逐条件结果和来源哈希见
`le-wm-main/results/pc_fixed_prefix_shared_rgb_parity_20261107_codex.json`。
这是工程等价检查，不重新评估已停止的向量构造，不证明闭环、方法收益
或模型间等价；PC0–PC5 状态不变。
