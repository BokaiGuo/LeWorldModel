序列 9、11 的物体位移分别约为 59.01、70.09 像素，端点朝向变化分别约为 0.466、0.802 弧度。三条中心不合格序列保留在分母。这两个序列仅是下一步物理重放和可见性审计的候选，不是预先认证的独立测试集。

状态与动作索引关系、动态状态恢复、渲染和完整物体几何可见性均未核验；不能以状态文件的轨迹宣称参考动作可由当前环境重现。数据与 checkpoint、normalizer 和以往开发的来源关系仍未知；筛查也不证明模型准确、目标可解或规划器有效。参考动作仅可用作离线评价见证，不能泄露为正式规划候选。

筛查实施遵循 `experiment-design` 技能的分阶段原则：先核验数据与任务可用性，再独立冻结后续物理重放、候选生成和模型评估。PC0–PC5 状态不变。
