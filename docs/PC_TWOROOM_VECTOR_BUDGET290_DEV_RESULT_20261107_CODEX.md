## 核验和边界

- 每臂逻辑评分为 `200+10+64+16=290`；实际联合运行复用 A 与各臂
  重叠 B 查询，平均 B 并集 36.2 条。原 200 次为此前实际执行并封存
  的评分，不是免费候选。290 对 300 只是模型链评分数接近，不代表
  GPU 时间、CPU、环境、闭环或完整系统成本已匹配。
- 与 CEM 结果不同的三根任务为 root 20、39、45。重新加载相同冻结
  模型，在 GPU 上复算其两组来源前 100 个候选与所有新评分；来源
  incumbent 排序一致，新评分最大差 **0**。向量臂三条实际动作链
  重新物理执行后，轨迹均逐步一致。
- 查询集合约束、共享 incumbent、并列和缺失查询等 **4 项测试通过**。
  环境 reset 观测类型和动作转换警告仍存在。
- 任务此前已曝光，模型和模拟器审计并非独立确认；没有完整墙钟曲线、
  真实机制干预或 RGB 闭环证据。PC0–PC5 不改判。
