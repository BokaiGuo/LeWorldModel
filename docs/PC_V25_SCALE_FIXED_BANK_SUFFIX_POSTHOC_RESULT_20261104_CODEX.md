# v25 幅度面板：固定候选共同后缀诊断结果

按冻结协议，八根任务、原幅度与小幅度两臂的首层固定候选全部完成共同后缀搜索和审计。每臂均有 18 个前缀，每个前缀使用两次、每次 121 样本的逐步动作 CEM；同一根各候选和两臂共享种子表。lookahead 在优化前独立计算并封存。

| 量 | 原幅度 | 小幅度 |
| --- | ---: | ---: |
| 全库找到 `<0.05` 终距的根 | 0/8 | 0/8 |
| response 保留集包含全库最佳分数的根 | 4/8 | 1/8 |
| response 相对 diverse 的保留集合改变 | 3/8 | 3/8 |
| response 相对 diverse 的最佳后缀分数更优／相同／更差 | 0 / 8 / 0 | 1 / 7 / 0 |

原幅度 root 0 的全库最佳终距约 `0.05931`；其余根中最佳终距未达到成功阈值。留存、lookahead、随机及 greedy 的逐根分数和候选记录见原始审计。没有候选在本次有限共同优化中成功，不能证明前缀不存在其他可行后缀；不同根和候选也不能作为独立统计样本支持性能结论。

每个根×臂的附加 lookahead 使用 1,350 token，共同后缀优化使用 13,068 token；原方法各自的生成与规划使用 1,918 或 1,920 token，见原始幅度面板账本。这些诊断支出并非原方法预算，不能把结果当作等总成本规划优势。

逐批动作与输出经哈希账本核验、同环境另一几何实现重算，并对全部 CEM 采样做确定性重放；这不是独立复现。特权几何见证未用于后缀初始化。该结果不通过 PC2 或 PC3，也不能排除尾部优化不足。
