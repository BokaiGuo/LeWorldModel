# P1 双包 AD 标量目标独立审计

双包 native audit 可从保存的 native IO 重建反向调用和方法过程，但此前没有独立根据目标向量与 AD 端点复算其标量损失。主线程增加 `le-wm-main/experiments/spectral_reachability/p1_scalar_objective_audit_20261029.py`：对每臂 8 次更新的阶段与后缀共 16 个损失，用保存的 float32 端点和目标复算 identity-Q 均方误差，并检查浮点归约允许误差。

独立测试 6 项通过，覆盖错误目标、错误损失、缺失迭代、次序错误和非有限值。此检查只证明保存的标量与保存的目标、端点数值一致；不证明梯度正确、模型或物理行为正确，也尚未在新生产链上运行。现有生产证据没有因此被判为错误，P1 门不变。新双包宿主需要将此检查及源码绑定纳入保存消费。
