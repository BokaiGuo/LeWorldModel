# 已知根四臂模型赢家追加预算：探索合同

在既有共同优化及八候选完整模型重放后，对 native-style 和 random
臂的模型赢家追加两步同配置优化，再独立模型重放新候选；只有严格
改善终态 latent MSE 才替换，平局及退化保留原动作。结构化与即时
进展臂保持原算法。选择不使用真实结果，记录修改前后动作、分数和
追加调用。所有臂继续共享真实 RGB 反馈时刻、物理时域和逐轴上限。

这是看到旧结果后提出的已知根探索，不是独立确认，也不是官方
GRASP/CEM。预测、动作编码、反向、重放和筛选分别计量；不将不同
资源相加，结构化 Jacobian 计费。共同上限不等于完全等成本。
保留停止与失败，不更改 P1 gate，不以模拟器状态选动作。
