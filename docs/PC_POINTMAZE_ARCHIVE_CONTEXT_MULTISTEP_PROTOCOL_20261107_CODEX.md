# PointMaze 归档动作的窗口 1/2 多时刻预测诊断

对已曝光 1884–1891 八条轨迹，预先固定真实动作 0–24，分别从归档
帧 0 和对应完整 proprio 预测 5、10、15、20、25 环境步。两臂仅
改变模型自回归窗口：旧实现 1、配置绑定实现 2；目标及未来真实
状态不用于预测。输入准备只复制帧 0、初始状态和固定动作；读取
`.pth` 时须加载整个文件，但不复制未来帧，模型加载器读取归档统计
的既有行为不构成操作系统级隔离。

先分别封存全部预测 latent、模型及输入指纹；之后才对同源归档未来
RGB 和 proprio 用同一冻结编码器编码，并计算逐任务逐时刻视觉及
proprio token 的均方误差，另报告沿用初始编码的 persistence 基线。
所有时刻先按任务汇总，比较窗口 2 更低误差的任务数量，不能把
时刻或 token 计为独立样本。第一包应在 1e-5 内一致，不满足则拒绝
继续。数值误差不是控制质量，未来真实状态只用于评价。

评价阶段还从每条相同初态在 legacy MuJoCo 重放 25 个归档动作，
检查每步状态误差上限 1e-4 与动作时钟；不符时保留失败并停止
对该实验宣称已对齐。该实验比较固定归档动作而非规划器生成动作，
不测试反事实候选排序、任务成功、闭环收益或新目标泛化。
完整 proprio 将其限定为 state-assisted；未认证原版 DINO 及官方
完整运行，因此不变更 PC0–PC5 gate。
