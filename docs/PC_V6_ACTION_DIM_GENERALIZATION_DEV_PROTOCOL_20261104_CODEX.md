# V6 动作维度泛化开发合同

Cube 冻结模型的原始动作是每步五维、五步一 packet；v5 多处写死每步二维，不可直接用于 Cube。另立 v6 开发版本：保持目标投影二维、每 packet 五步、最多三 packet、v5 的局部目标加权响应、后继保留、共同 CEM、完整链 incumbent 与弃权；把动作维度和两条合法名义动作改为显式输入，动作空间仍为逐坐标 `[-1,1]`。本版本不声称任意 packet 长度、输出维数或环境已泛化；不同模型的 nominal policy 需先固定，不能读取物理特权状态。

先在二维使用与 v5 完全相同的两名义动作、预算、随机流和已暴露 E0 任务，比较每批原始动作、预测、候选、保留、完整链和计数；该等价性仅针对固定任务、已测步与数值环境，不让 v5 旧见证自动成为 v6 机制通过。另在五维使用合成可控预测器做接口数值回归，仅验证形状、五维扰动与动作边界，不作为 Cube 实验。其后才可在冻结 Cube 模型的合法上下文检查动作历史、归一化与 packet 时钟，真实反馈和方法主张另行预定。
