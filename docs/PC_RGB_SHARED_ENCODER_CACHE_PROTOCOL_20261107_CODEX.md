# RGB 单帧共享编码缓存：等价与成本开发协议

固定已公开的 episode 9000、9013、9022、9032 输入和梯度计划中每根五条动作；逐根分别测试 5、10、15、20、25 物理步，即 1–5 个模型动作包。模型、规范化、动作域和 192 维表示与已有单帧 RGB 合同一致，不使用物理状态或成功标签。

对每个任务/时域，同一动作分别由原 `SingleFrameRGB` 与缓存包装器评分。后者只在完全相同当前图像和目标图像的同一次观测内复用冻结编码；画面、目标、设备、dtype、形状变化必须重新编码，不能缓存跨观察后继或动作。仅允许 inference mode；保留原输入权限、动作边界和模型冻结校验。检查预测逐时刻向量及分数 `rtol=1e-5, atol=1e-3`、稳定排序、argmin；记录差异，不以逐位相等作为必要条件。

性能为同一任务同一时域重复同一动作批次，双方预热后分别做 30 次、每次 GPU 同步的计时；缓存端预热建立缓存。记录中位数和 GPU、批量、时域。计时包含权限检查及收据，不包含模型加载、环境执行、复位和序列化；该微基准不是全任务成本曲线，不支持描述或方法优势。重复相同输入是专门测试预期复用场景，不代表全部规划调用。

本审计是已曝光任务上的工程开发，不改变历史实验或 PC gate。缓存验证失败则不能接入任何正式比较；通过亦需后续完整闭环比较。
