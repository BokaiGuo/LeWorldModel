# v4 选中链同库机制开发诊断协议

对已暴露的全部 24 个 v4 E0 任务，使用 v4 封存的同一最终选中
完整链和其首层九项候选，不使用 v3 的 selected 链或机制见证。
为每个候选及最终 selected 前缀分别执行零尾评价及 119 次四结点
CEM，前缀内共同零初始化、根固定种子；在九项中选最低分为普通
lookahead，同库即时最低为 greedy。对各前缀另执行同一 selected
尾部，报告绝对终距与相对零尾变化。每候选总计 121 条完整链。

对全部 selected、zero、greedy、lookahead 前缀，额外在共同
selected 尾部首五步的安全名义点计算 `.01/.05` 中心差分响应，
重放全部扰动的阻挡序列，并报告后继响应矩阵差和任务方向
梯度差。若 selected 前缀或 selected 尾部为零，明确记录，不能
将其称为非即时重配置。每项数据均应记录并审计。

该面板先前用于开发且 v4 选择已见，属于事后诊断，有限 CEM
不等于充分优化。lookahead 从九个有噪搜索中取最优有选择偏差；
selected 前缀联合精修后可能库外。使用相同精确动力学重算并非
独立模型复现，不改写任何 PC2 事前合同。
