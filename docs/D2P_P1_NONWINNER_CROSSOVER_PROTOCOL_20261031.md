# P1 四起点 selected 候选：跨前缀干预

目的：在已观察到 selected 前缀存在模型未选但物理成功的候选后，
对全部 8 个固定逻辑槽、selected 角色的全部四个模型优化候选，
不按成功或模型分数筛选，将同一十步动作分别施加到同根同任务
的 zero 和 greedy 前缀。共 8×4×2=64 条新分支；selected 自身
的 32 条动作已在赢家/三个非赢家实验执行，消费其原有报告，
不把重放或同根重复当独立任务。已有零后缀基准单独绑定。

逐条保存动作来源、完整字节、前缀和物理事件；第十步未观测时
不插补。原生成功按各自真实停止时间报告，物体位置、角度、
推杆和联合 XY 在有观测的同一时点分栏；相对各前缀零后缀
另计。真实模拟器状态不反馈给模型选择器。跨前缀相同动作
只测动作后果，不等价于这些前缀在同预算下自行规划的能力。

本分析属于两个已知根上的事后机制探索；不能据此选根、
更改原 selector、声称独立泛化或 P1 通过。模型冻结，不训练；
若报告或动作身份不一致则拒绝，不把代码错误当物理负结果。
