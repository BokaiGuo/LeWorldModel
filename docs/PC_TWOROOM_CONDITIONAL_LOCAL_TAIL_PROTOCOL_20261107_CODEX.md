# TwoRoom 条件局部尾部：开发筛选协议

问题：此前完整候选竞争中，随机 B 尾部从未被选中，因而前缀保留
变化没有传递到最终执行。检验固定预算的条件局部尾部是否能使新链
进入最终竞争，以及描述保留是否在共同局部优化机会下产生增量。

复用已曝光的 40 个 TwoRoom 任务、冻结 RGB 模型、每根八个前缀、
各八条共同 A 尾部、已有 A 代价及经核验的共同最佳 incumbent/A 链。
模型只接收当前 RGB、目标 RGB、合法动作与冻结 normalizer；真实
状态仅用于评价端重置与回放。该面板和既有物理结果已曝光，不是盲测。

保留规则固定为已有 `lookahead`、质量约束 `gated`、相同质量约束
动作身份 `shuffled`；沿用原计划中每臂两个前缀，不根据物理结果改动。
每个前缀以其 A 代价最低的尾部为共同起点，用独立固定随机流生成八个
候选；对三个五步动作块的二维动作加独立高斯噪声，标准差 0.2，裁剪
至 [-1,1] 并逐块重复五次，前十步严格不变。候选与扰动由任务和前缀
确定，因此不同臂在同一前缀上机会相同；不根据真实 B 最优链生成。

每臂将 16 个所保留候选与 64 条共同 A 及两条 incumbent 同场竞争，
按模型最低代价选一条合法完整链；同分优先共同最佳链，再按固定前缀
及候选顺序。所有选择和完整动作先封存，再按同初态独立物理执行。
不计模型额外调用时不能称等完整成本：每臂逻辑成本沿用原 690 条完整
链评分（前期 600、A 64、父链 8、incumbent 2、局部 16），本轮另复评
共同最佳链 1 次以核对批次，合计 **691**；运行时可
共享跨臂重复候选，并单独记录联合物理查询。保留规则和局部候选使用
的信息不能含物理标签。

报告每臂成功及配对独胜／独负、实际选中局部链数量、模型评分差、
单臂逻辑和联合查询次数。与原随机 B 方案作事后配对参考，但不能把
两个不完全相同的测量路径当成严格同步墙钟比较。筛选出口：`gated`
相对 `lookahead` 和 `shuffled` 均至少 2 个独胜且至多 1 个独负；同时
相对自己原随机 B 方案至少 2 个独胜且至多 1 个独负。否则停止扩大
这一固定局部方案；该出口只约束本开发实验，不是 PC gate 标准。

逐候选输入、成本、选择与动作哈希封存；选中链保存逐步物理轨迹。
实验不测试闭环、独立任务或全链最优，也不证明前缀机制，不能作为
RGB-only 性能确认或任何 gate 通过。
