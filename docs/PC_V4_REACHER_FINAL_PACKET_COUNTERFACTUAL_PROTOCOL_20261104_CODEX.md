# V4 Reacher 最末动作包反事实诊断协议

观察到单根最后一包距离反弹后，使用该 v4 已封存的第 10 步决策和实际前两包；模型评分和轨迹此前已经可见，此为**事后诊断**，不是事前确认或 PC3 性能比较。固定五个五步动作：实际 selected、来自前轮的 carry、全零，以及编译器首次响应时使用的两个固定名义动作。它们不由反事实物理结果选取；各动作都必须能在该轮封存的模型预测 trace 中精确匹配 float32 动作并提取得分范围。

每个动作分别从相同 seed 完整重置，回放真实热身和已派发的前两包，到第 10 步后验证根 RGB 哈希、关节位置、目标及不同分支初始 qvel 一致，再执行五步并保存逐步 qpos、qvel、目标和距离；必须重现 selected 的原执行边界。对模型评分与物理末距报告两两排序和绝对值，保持二者单位区分。封存运行依赖及源计划、审计、参考预测重算和物理重放哈希。

这仅能定位该单根、有限动作库中的模型评分—物理排序是否一致；无动作重新规划、没有独立任务、未控制每个 latent 方向的物理意义。不能将任一事后最佳物理动作当正式计划、宣告方法优势或确认 PC1/PC4。若存在排序反转，它可能来自模型表示、目标编码、预测误差、数值/时间接口或距离指标差异；逐项排查，不直接判为代码错误。
