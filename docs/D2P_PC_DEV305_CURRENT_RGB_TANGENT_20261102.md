# dev305 当前 RGB 切向评分开发试验

先前目标 RGB 的物体 bbox 为 `[65, 162, 120, 220]`，未通过既有 8 像素
边缘可见性条件。该结果被保留，未放宽目标图 guard。三个实际前缀后 RGB
均通过同一 guard；本次新开开发协议，在各自当前 RGB 上按已有方法固定
扰动物体的 x、y、角度及推杆的 x、y，经冻结编码器构造 192×5 局部切向
矩阵、正定 Q，再用 Q 评价预测终态与原始目标编码的差。目标图仍用于原始
目标编码，没有用目标图构造切向量，也没有用模拟器状态选择动作。

候选是先前 17×17 两包动作库。每个模型候选均重新做非线性预测；原始
latent MSE 与封存同动作报告逐项完全相同。结构评分选出的动作按索引
关联先前真实执行，**未新增物理执行**。候选物理结果已在制定此变体前
打开，故这是探索性事后开发，不是盲选或独立验证。

Q 变体的原生奖励在三组均更高，但三条轨迹的终点物体姿态与相应前缀后
相同，物体位置和角度误差均大于原始评分。它不能支持任务能力或方法优势；
不应仅根据奖励改善选为正式方法，也不能由此否定所有切向度量。三组
均是单个已知开发根，目标边界遮挡风险和模型训练 normalizer 来源未知。

模型额外计量：编码器/投影器各 40 次，动作编码器/预测器各 102 次、1,734
样本；此前动作库和物理执行成本尚未并入完整公平预算。保存验证由切向
Jacobian 重构 Q、复核正定性与 trace、选中索引和物理配对；未重新计算
神经输出。相关测试 4 项通过。不能将 Q 的局部正定或模型评分当成真实
控制能力证据。
