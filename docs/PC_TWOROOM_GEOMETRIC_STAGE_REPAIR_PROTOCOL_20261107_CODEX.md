# 几何候选阶段切换修复：配对开发协议

继承 V2 的 40 个已曝光任务、RGB 解析、候选数、门偏移、增益、25 步
时域和初始零动作。只改变内部路径跟踪：阶段到点容差从 `1e-4` 像素
变为 0.5 像素，且每个坐标的动作不得越过当前目标点；依然保持动作在
`[-1,1]`。增益 1.2 可能因合法动作和防超调约束与其他链重复，必须
报告实际重复数，不能把重复当独立证据。

每任务对修复后的全部 16 条链分别做冻结模型评分和 25 步物理重放；
按同一候选索引、同一起点与目标比较 V2 已存物理结果。报告每增益
成功数、阶段推进、动作重复、模型选链成功及评估成本。真实后果
只用于事后评价，不反馈模型选链。数据已曝光，不用于独立确认；
若候选全部成功，则不具备验证成功/失败辨识力。
