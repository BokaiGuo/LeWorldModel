# RGB 时序近并列选择：开发反馈结果

按照[事前协议](PC_RGB_TEMPORAL_TIEBREAK_PROTOCOL_20261107_CODEX.md)，在已曝光的 40 个 TwoRoom 任务上，比较原时序最低分选择和“时序近并列后按末帧评分、再按候选顺序”的新规则。每种规则都分别运行原始和缓存模型，四臂各自实际执行、观测及重规划。

| 指标 | 原选择规则 | 近并列新规则 |
| --- | ---: | ---: |
| 原始／缓存完整计划及来源一致 | 34/40 | 40/40 |
| 原始模型实际闭环成功 | 32/40 | 32/40 |
| 缓存模型实际闭环成功 | 32/40 | 32/40 |
| 原始模型实际环境步 | 650 | 652 |

新规则相对原规则的成功独胜／独负为 **0／0**，满足本实验事前限定的数值稳定性开发出口；这不是规划收益或非劣效确认。原始模型下，5 个任务有一次或多次最终计划或来源变化，两个任务的实际轨迹变化；其中一个仍失败，另一个仍成功但用时从 22 步变为 24 步。其余 35 个任务的选择和完整动作不变。新规则可能在 `1e-3` 容差内选择并非严格时序最低分的链，属于另一个选择版本，不能追溯覆盖旧结果。

独立算术重算对新规则的 **144 次**实际反馈决策重新运行 GPU 模型，按单独的列表筛选重建并列集合、末帧次排序和稳定次序；同时重放对应物理轨迹，结果均与记录一致。该审计复用相同模型、候选生成及物理后端，不是独立引擎验证。近并列、边界、无效数据及配对检查的测试共 **9 项通过**。

本面板已曝光，1e-3 是沿用此前重放容差而不是证明所有输入或设备都有该误差上界。新规则解决了本样本中缓存导致的完整链分歧，但没有改善成功率，也没有证明行动后果描述的增量；不能据此直接用于正式确认。PC0–PC5 未改判。
