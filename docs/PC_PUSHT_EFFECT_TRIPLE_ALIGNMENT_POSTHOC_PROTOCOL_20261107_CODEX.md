# PushT 新几何面板三方动作排序：事后诊断协议

数据是已经看过总体遗憾的 [16 根开发面板](PC_OSFAL_PUSHT_HELDOUT_GEOMETRY_RESULT_20261107_CODEX.md)；本协议晚于物理与模型结果，不是预注册或独立确认。直接读取已独立重放并绑定哈希的物理记录、冻结模型分数及重放审计，不重新跑模型或挑选层。

每根、背景、侧别，固定比较三个无序动作对 zero/plus、zero/minus、plus/minus。利用历史物理 pose cost 和预测、真实编码目标分数分别计算差值。物理差绝对值不超过 `1e-9` 为物理并列；模型或真实编码分数差绝对值不超过 `1e-4` 为数值并列。此处 `1e-4` 是诊断容差，不是科学 gate 阈值，原始差值保留；不把物理并列当正确或错误。对物理非并列对，分别统计预测与真实编码的同号、异号和并列，以及二者相对于物理标签的四格（其中任一评分并列单列为 uncertain）。动作组合、是否涉及真实 agent-block 接触均单独分层；相关条件和成对动作不作为独立样本，按根保存分子分母及均值。

物理代价与 latent 代价单位不同，因此只比较符号与排序，不报告未经校准的跨单位 MAE。将“预测方向不同于真实编码”称为预测—编码排序失配，将“真实编码方向不同于物理”称为编码评分—物理失配；两者可以同时发生。这些是现象而非充分因果归因，不能单凭该面板证明模型动力学、图像编码或代码哪一处是根因。真实后继和物理标签只用于离线评价，不能输入 planner。未查询动作、闭环、校准、PC0–PC5 均未因此通过。
