# P1 图像形状门控反馈：开发合同

该合同在看过先前同一面板结果后定义，仅用于开发探索，非独立确认。
使用同一 24 个固定行、同一冻结模型、两阶段规划与原生执行合同。
第二阶段只有在 RGB 分割通过、物体 mask 的对称 Chamfer 距离不大于
`20 * 224 / 512 = 8.75` 像素且推杆距目标大于 8 像素时，使用事先
固定的五个相同 0.2 相对动作；其余有效行沿用模型后缀，分割失败
继续拒绝。8.75 是环境原生位置尺度向渲染尺度的换算，不代表
Chamfer 距离等同物体位置误差，也不是原生成功的代理或安全保证。

动作决策仅使用当前与目标 RGB 和模型动作，模拟器真值只用于事后
评价。保留所有拒绝和停止；验证逐行中点动作、状态、RGB 与原模型
实验一致后，分物体、角度、推杆、原生成功和成本轴报告，不据此
宣称机制、等预算优势或 P1 准入。

## 已执行结果

主机 CUDA 与真实物理 24 行均完成记录并通过保存消费；共同前五步
动作、状态快照和 RGB 均逐行与原模型实验匹配。15 行执行五脉冲、
6 行保留模型动作、3 行视觉拒绝；21 个完整端点可比较。两个
greedy 记录在末步原生成功，是同一根与相同物理轨迹的重复，
与前一五脉冲实验相同，不能计为独立成功。

以门控版减原模型版表示误差（负值较低）：

| 指标 | 均值差 | 门控更低 |
| --- | ---: | ---: |
| 物体位置 | +8.6919 | 4/21 |
| 物体角度 | +0.1128 | 0/21 |
| 推杆位置 | -7.8593 | 13/21 |
| 原生联合位置 | -3.3868 | 9/21 |

与无形状门控的五脉冲比，21 行平均物体位置差为 -1.3621，
角度差 -0.0512，推杆位置差 +0.5189，联合位置差 -0.7021。
逐行验证 21/21 的终点精确等于对应已封存的五脉冲或原模型终点：
这轮物理重跑验证了一个**既有动作之间的事后拼接规则**，没有发现
新的执行轨迹或新的成功案例，不是独立样本。由于动作与结果已知
时制定规则，均值和行数仅为描述。

对 P1 更关键：两个成功记录都是 greedy，不是 selected；selected
中 3 行视觉拒绝、其余 5 行均未原生成功。在此固定探索条件下，
RGB 门控没有建立非贪心前缀的能力改变或胜过 greedy 的闭环收益。
必须继续解决候选生成、视觉遮挡和模型／物理评价一致性，不能
将门控成功案例写作 P1 机制证据。
