# v4 目标可达与后继响应：E0 开发结果

新[开发入口](../le-wm-main/experiments/spectral_reachability/pc_target_reach_feedback_v4.py)
接入目标残差加权模态排序、逐候选后继响应、局部岭可达价值、
响应矩阵多样性保留、共同 CEM、全链精修及最终弃权。其输入仍限定
二维目标和动作、五步 packet 与固定 `15/10/5` 时域。
相应回归及 v3 回归共 **12 passed**。

按[协议](PC_TARGET_REACH_V4_E0_DEVELOPMENT_PROTOCOL_20261104_CODEX.md)
在相同已暴露 24 根进行首次 15 步开放环规划；v3 引用同任务封存
结果，不能拼接它的机制见证：

| 方法 | 平均终距 | 中位终距 | `<0.05` 根数 |
| --- | ---: | ---: | ---: |
| v3 response | 0.411433 | 0.500680 | 3/24 |
| v4 目标可达／后继响应 | 0.500797 | 0.500733 | 0/24 |

按差值 `1e-12` 为平局，v4 对 v3 胜／平／负为 9/5/10。
每根两者使用 1920 预测 token；v4 在每根记录 231 个有限差分
探针和 22 次 SVD（每个局部响应做一次排序分解与一次岭计算
分解），后缀 CEM 为 357–360 个样本、联合精修为 119–120 个；
v3 分别为 409–412 和 137–138 个。额外后继探针与优化采样之间
存在实际预算竞争，但这本身不能证明性能下降的唯一原因。

[逐批审计](../le-wm-main/results/pc_target_reach_v4_e0_20261104_codex_audit.json)
验证了 **24** 条计划；[完整记录](../le-wm-main/results/pc_target_reach_v4_e0_20261104_codex_plans.json)
保存响应、选择与动作。复用的旧 runner 在终端固定打印“三臂／72
条”，与本协议的单臂不符；实际 manifest 和审计均为 24 条，不能
把该输出计作 72 条实验。审计共享同一精确动力学代码。

这是有界开发负结果，不是理论否定或已定位的动力学 bug。在二维
场景中两个非零模态均保留，目标排序可能只影响其顺序；不能据此
宣称谱排序有独立增量。局部价值无动作约束、只在名义点近似；
响应矩阵差异也未等同可利用收益。必须继续做同预算消融、探针
成本分解、实际 v4 选中链的机制干预及 RGB 接口认证；PC2–PC5
均不能从此结果或 v3 的结果直接提升。
