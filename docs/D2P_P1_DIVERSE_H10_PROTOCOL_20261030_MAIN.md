# 新多样性前缀的十步共同后缀干预

已知根开发性实验，不是独立确认。固定完整面板中与旧 selected
前缀不同的三个逻辑槽：0/on/projected、1/on/projected、
1/on/outward。后两槽动作相同，保留逻辑分母但不得算独立实例。
其余五槽的 selected 前缀与旧十步实验逐字节一致，不重复物理运行；
能否复用其结果须另行校验完整任务与快照。

每个新前缀均执行旧十步探针合同的零动作和 40 个坐标脉冲，以及
新候选自己已知的十步后缀，共 42 条；每一条重新恢复原生根、
warmup 和该前缀，并逐帧核验先前物理轨迹。前 41 个共同后缀
与同根、条件和逻辑槽的既有 zero/greedy 对照逐字节一致；第 42
项是新 selected 自己的后缀，不自动与旧后缀等同，若未在对照
上执行不能用于跨前缀同动作比较。该后缀是已见 outcome 的探索项。

逐步保留状态、帧、原生停止、越界及删失；先对固定时域可比较
条目分项报告物体位置、角度、推杆和原生成功，分别计算绝对
终态与相对同前缀零后缀的变化。共同后缀仅回答动作响应差异，
不能证明可规划能力；独立优化后缀和总预算公平性另行验证。
所有数据仅用于探索，不改变 P1 门，不按结果选样本或训练模型。
