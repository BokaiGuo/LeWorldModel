八根任务各两条特权见证前缀，比较逐步动作 CEM 的零初始化和随机初始化；每次重启均为 121 个完整链样本，预定 2、4、8 次重启，全部执行完毕。记录每个前缀在该预算点之前的累计最好终距。

两次重启检查点与前次对照逐前缀完全一致；所有调用经哈希账本核查、另一同环境几何实现重算及优化器逐批提案重放。预算点使用累计嵌套样本，前缀共享任务，不能作为独立样本作显著性确认；相同 token 也不代表相同全部计算成本。

本开发面板显示尾部初始化和重启预算可实质改变已知可行前缀的搜索结果，进一步排除了将先前 1/16 简单解释为理论失效。它不能证明任一策略对自动生成前缀有效、实现已无 bug、方法获得等资源优势或 gate 通过；见证前缀不可进入正式规划器。
