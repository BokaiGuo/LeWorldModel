# 未查询 B 尾部真实后果：开发结果

依据 `PC_PREFIX_HELDOUT_PHYSICAL_DEV_PROTOCOL_20261105_CODEX.md`，
先核验所记录的实际执行链：50/50 任务、1193 步的动作和完整
物理状态重放均一致，动作及状态最大绝对差均为 0。然后在相同
初始化下评价全部父链和 B 尾部，无异常。

50 对前缀的 400 条 B 链中 4 条在 25 步内成功，均来自同一
任务；49 个任务的两个前缀均没有成功的 B 链，1 个任务仅一个
前缀有成功 B 链。在该单个可区分任务上，模型最低 B 代价排序
选择了有成功的前缀；50 个任务中模型最低代价的 B 链实际成功
1 条。全部 400 条 B 链的完整计划动作均在声明域内。
两条父链各自直接执行的 100 条中，有 1 条成功。

这个结果说明随机局部 B 库缺少足够真实成功来评价跨前缀排序，
而不是证明描述有效或无效；单个可区分任务没有统计确认价值。
该面板已用于开发，物理后果只用于事后评价；固定前缀后的独立
优化及真实闭环尚须单独实验。

完整结果为
`le-wm-main/results/pc_prefix_heldout_physical_replay_seed42_20261105_codex.json`，
可用 `python -m experiments.pc_prefix_heldout_physical_analysis_20261105_codex`
复算；原始模型查询和动作 trace 位于同名 `.audit.jsonl` 与
`.trace.jsonl`。结果不改变任何 PC gate。
