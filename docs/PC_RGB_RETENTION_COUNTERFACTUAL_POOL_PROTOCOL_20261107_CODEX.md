# RGB 保留路径反事实池：事后开发诊断

使用已曝光的 40 个 TwoRoom episode 和已封存的四臂闭环记录，不生成新任务。对 lookahead/effect 的共同派发历史中，旧尾亦相同的每次决策，重建原三个前缀和两个共享尾部，枚举 **3×2** 合法完整链。候选由原 seed 和旧尾确定，不按真实结果筛选。

每条链从该次决策的同一重放物理状态开始执行，记录各步距离、成功与终止；单列前缀结束前已成功的链。用同一冻结 RGB 模型计算原时序和末帧代价，比较原臂保留的尾链模型分数与已封存日志。原决策已固定，真实结果只用于离线评价，不参与选链、保留或优化。

报告每次决策各臂保留集合对六链中成功链的覆盖、前缀未成功而尾段成功的覆盖，以及最终实际选中链；按任务归并另报，不把链或决策视为独立任务。保留集合覆盖不等于实际执行成功，也不能说明完整机制、模型信息增量或 PC gate 通过。本诊断为事后开发分析，没有预注册的统计门槛；仅用来区分固定随机尾部池的覆盖与最终选择损失，不等同等预算尾部重优化或独立确认。
