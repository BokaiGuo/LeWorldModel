# CEM16 方差实验 GPU 候选重算

对[方差下限开发实验](PC_RGB_CEM16_VARIANCE_FLOOR_RESULT_20261107_CODEX.md)的全部 40 个任务、两臂反馈历史，按[复核协议](PC_RGB_CEM16_GPU_REPLAY_PROTOCOL_20261107_CODEX.md)重新生成候选，从重放后的真实 RGB 观测出发，在同一 GPU、冻结模型、normalizer 和批次大小下重算时序评分。

- 原版 128 次、下限版 129 次，共 **257 次决策、4,112 条候选链**；动作、已派发历史和物理距离重放核对通过。
- 15 条采样链的重算分数与已记录分数最大绝对差为 **0**；选中分数最大差为 **0**，257 次重算最低分索引均与原选择一致。
- 旧尾候选在 76 次决策中被选中，其重算分数与已保存的选中分数均一致。其余决策的旧尾历史分数当初未单独保存，因此不能声称那部分旧尾历史分数逐项验证；本次重算则包括全部旧尾与采样候选。
- 评分复核与原方差实验相关测试共 **9 项通过**。实验沿用同一编码器、物理引擎和硬件，不是独立实现或跨平台等价认证。

在此复算范围内，没有发现候选重建、原始采样分数或最终最低分选择错误；方差下限配置仍未达到其事前开发出口。不能由此排除其他代码、物理模型或评分失配，也不能推广为 Planning Compiler 理论的否定。复核不新增控制结果，不改变 PC0–PC5。
