# TwoRoom 双 RGB 目标扰动背景恢复：开发合同

此前仅使用目标图修补红色对象覆盖的背景时，10 个已暴露任务中 9 根原位重建失败；本次只验证一个明确的实现修复，不调整旧阈值或重判旧实验。规划器合法输入已有当前 RGB 和目标 RGB。若两图具有共同静态背景，可用当前图对应位置恢复目标红色对象下的背景；两个对象重叠且当前图也严重遮挡时，必须弃权，不用环境状态或真实后继填补。

固定使用已封存 seed-42 全部 50 对输入图像，不按任务成功筛选。两图均按 `R−max(G,B)>3` 检测红色对象；目标红色像素数限 100–5000，平移 ±4 像素不得出界。两图红色区域之外的平均 RGB 绝对差须不超过 1，单通道最大差不超过 5；否则拒绝使用静态背景假设。目标遮挡区域中，当前图没有红色的像素直接取当前 RGB；存在红色但 alpha 至多 0.95 的像素按红色 alpha 合成公式求背景；若任何所需背景像素的当前 alpha 大于 0.95，则该根弃权。目标图原位重合成的红色区域平均 RGB 绝对误差仍须不超过 4/255。对通过者生成目标红色图层在水平／垂直 ±4 像素的四张图；不对环境作物理操作。

逐根保存检测、重建误差、弃权原因、背景一致性和扰动图像与输入指纹。先只做图像工程验证：若不少于 40/50 根通过，再考虑将同一冻结模型上的目标切空间作为另一个开发评分版本；否则停止此双图修复，不运行大面板或放宽阈值。此门槛是图像处理开发出口，不是 PC gate 或方法收益。图像合成是反事实且可能超出训练分布；原位像素一致也不能证明隐藏背景在遮挡处被正确恢复。
