# PointMaze 多模态目标评分：已暴露面板开发协议

固定先前相机实验的 1884–1891 八根、每根两个视角、zero/+0.1/−0.1 三个五步动作包和旧 centered 图像变换。比较视觉末帧 MSE 与视觉 MSE 加 `0.1 ×` 预测 proprio token 的目标 MSE；权重取本地官方 PointMaze L2 评估配置，不根据本面板调参。后者要求目标的完整 proprio，与已有实验只使用目标图像不同，因此是更高目标输入权限的 state-assisted 对照，不是对仅图像目标方法的公平同权限替换，也不是 RGB-only。

准备进程从既有物理数据导出目标初态 proprio 和已有公共当前输入，绝不导出任何候选动作后继；独立评分进程只读取导出文件，在读取物理结果前封存全部候选分数和两臂选择。核验视觉评分复现旧封存结果（绝对容差 `1e-6`、相对容差 `1e-5`）；核验加权结果与官方 `ReprTargetDistMPCObjective` 一致。评价进程以物理末态到目标位置的距离计算每视角 regret，逐根汇总，同时报告 1887 偏移视角。严格保留全部 16 个视角；不把两个视角当独立根。

这些根、候选和已有结果已暴露，本实验是事后提出假设的开发诊断，不是盲法确认。预定开发出口：视觉复现及官方目标公式一致；八根中至少五根的两视角平均 regret 严格改善，全部根的平均 regret 严格降低，且 1887 偏移视角不劣化。即使满足也只允许作为 state-assisted 固定候选开发线索；须在新任务、同权限、同成本且真实闭环中确认。任何结果不自动改变 PC0–PC5，不得拿物理后继反选动作。
