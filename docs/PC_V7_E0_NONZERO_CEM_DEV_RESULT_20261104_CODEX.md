# v7 与多初始化 CEM：已暴露 E0 开发比较

依据[事前开发协议](PC_V7_E0_NONZERO_CEM_DEV_PROTOCOL_20261104_CODEX.md)，在 v7 已暴露的 18 根上分别运行一个零初始化和两个非零随机初始化的三重启 CEM。两个基线的 36 条计划、**23,040 条轨迹**已在同一精确动力学后端逐条重算；[结果](../le-wm-main/results/pc_v7_e0_nonzero_cem_dev_20261104_codex.json)和[审计](../le-wm-main/results/pc_v7_e0_nonzero_cem_dev_20261104_codex_audit.json)保留动作与计量。每臂每根均为 1920 packet-token。

| 方法 | 平均终距 | 终距 `<0.05` | v7 对基线胜／平／负 |
|---|---:|---:|---:|
| v7 response | 0.501111 | 0/18 | — |
| 4 结点 smooth CEM | 0.501265 | 0/18 | 9／0／9 |
| 15 结点逐步 action CEM | 0.501926 | 0/18 | 11／0／7 |

该对照补充了此前全部从零均值重启的局限，但两条随机基底不是充分调优、任务结构初始化或强搜索上界。面板及 v7 结果已暴露；不得解读为独立确认、稳定实际优势或 PC3 通过。预测 token 相同也不表示编码、响应、分解、筛选及总墙钟成本相同。
