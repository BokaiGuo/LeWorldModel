# DINO 源码兼容修正与同池后果复核

本协议在本次修正版输出前冻结。旧的插值隔离实验和单面板修复失败决定不变：
它们已证明插值约定不同，且仅换后端不足以解决旧面板动作排序。
本实验不重复“是否有差异”，而将该实现偏差修为独立、可复用、显式选择的适配器，
以源码等价性而非物理成绩决定修正是否正确。历史 shim 及绑定其哈希的工件不修改。

## 修正边界

HF DINOv2 嵌入层在非原生分辨率用目标尺寸进行 bicubic 插值；固定 Meta
源码 `7764ea0f912e53c92e82eb78a2a1631e92725fc8` 的 vits14 默认使用
`scale_factor=(目标patch数+0.1)/原patch数`、`antialias=False`。
仅修正此约定，参数对象、数值、键名、predictor、动作预处理均保持不变。
不拟合映射、不读评价标签、不选择中间层作为 predictor 输入。
只认证这份源码与同份已缓存 HF 权重的实现一致性，不冒充权重来源独立认证。

## 实现验收

使用先前同步渲染面板的根 1832、1840、1848、1856 初态，两视角真实图片。
输入标准化完全复用现有 JEPA preprocessor。在 196×196、224×224、
224×280、518×518，batch 1 与 3 比较：
embedding、12 个完整 transformer block、最终 CLS/patch。
源码后端严格载入同份 HF 权重的全量映射；校验全部权重映射成功。
逐元素容差 `atol=5e-4, rtol=1e-4`，同时要求相对 L2 ≤ `1e-4`。
这是本次跨实现浮点验收容差，不修改此前单张目标重编码容差。
必须列出最大误差，不要求逐位相等，不根据物理结果放宽容差。
原始 shim 只作为偏差对照，不能要求它通过源码一致性。
修正前后权重指纹必须相同；配置/源码指纹必须不同且分别记录。

## 决策与后果复核

固定此前 1832–1863 的 32 根、当前及目标同步渲染 RGB、两个相机、
zero/±0.1 的三条25步完整链，评价5/10/25步，不增加候选或重选任务。
它们已曝光，本次是实现修正的配对开发复核，不是独立确认。
使用完整当前和目标 proprio，全部登记为 state-assisted。
所有模型预测和代价先封存；之后才读取既有物理后继文件进行评价。
每根同时以源码后端验证修正版的预测、各模态代价、候选排序及最终选择。
分数容差同上；若模型选择不同，报告近并列边界，不隐去差异。
只有全部选择一致才能称本有限面板决策等价；不能推广为整个CEM/闭环等价。

同步真实末帧编码也采用各自后端；比较模型误差、真实编码排序和物理regret。
旧 shim 的预测/真实编码读取已有封存结果，不重新选择；逐根保留完整分母。
按根汇总，原校准/评价16+16拆分保留但均标为已曝光；报告root bootstrap。
额外查询和编码计数、GPU同步时间、加载边界单列；不称完整任务效率优势。
本次无新控制方法准入阈值，不恢复已停止的历史残差/正交/标量描述实验。
若修正后仍失配，应将剩余误差定位为此模型/支持集边界，不自动断言理论失败。

## 工件与停止规则

输出到 `results/pc1_dino_source_compatible_20261107/`，按阶段排他写入，
完成阶段验哈希后恢复；保留失败记录。只保存必要表示，避免重复全部中间层。
任何等价测试失败先定位第一处差异，不调物理目标或阈值挽救。
完成本实验不等于整套研究完成；PC0–PC5不自动晋级。
