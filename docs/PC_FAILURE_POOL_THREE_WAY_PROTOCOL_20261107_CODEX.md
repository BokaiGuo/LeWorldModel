# 失败候选池的预测、真实编码和物理三方对齐

对既有失败任务中实际未成功的三臂（38／temporal、39／endpoint、39／temporal），逐臂使用其完整 194 条已评分链。先在原 RGB 初态、目标和冻结模型下重新计算全部候选预测末状态及目标分数；与封存分数逐条核验，封存预测后才采集真实末帧。再按原初态执行全部链、核对每步物理记录，编码末帧和原目标图。

逐臂报告成功与失败之间的预测代价、真实编码代价的两两排序一致比例（并明确平局）、真实编码 oracle 选中链的成功、各自与物理成功最相关的排名和选中链，保留所有失败分母。它仅是事后评价：真实后继与成功标签绝不反馈进入规划，三臂共享两个任务，不能当作三个独立任务。若模型分数、动作或物理重放不匹配则停止，不修改旧结果。
