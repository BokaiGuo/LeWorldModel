# 已封存多方向搜索的非即时覆盖归因

按照[诊断协议](PC_MULTIDIRECTION_NONPROGRESS_COVERAGE_ATTRIBUTION_PROTOCOL_20261103_CODEX.md)，
重放 24 个已暴露精确 Wall 任务的封存候选与完整链，没有追加规划、调整
预算或变更选择。非即时沿用此前 `末距 ≥ 初距 − 1e-10`；为避免把零动作
自动当作有效提案，下表同时要求前五步存在非零 float32 动作。

| 位置 | 含非零非即时前缀的根数 |
|---|---:|
| 第一候选库 | 24/24 |
| 已保留十步组合 | 20/24 |
| 至少一条已评分完整链 | 24/24 |
| 实际最终选中链 | 7/24 |

四个留存组合没有此类前缀的根为 4、6、17、19；后续联合精修可改变
前缀，因此这四根在全部已评分完整链中仍有非零非即时前缀。这些计数
包括重复采样，不能视为独立候选或独立样本。

总计 2,824 次已评分完整链，其中 1,212 次具有非零非即时前缀；24 根各自
最好的此类链，其终距平均为 0.71575，最小为 0.50790，没有达到原
`<0.05` 成功阈值。最终选择与每根所有已评分完整链的最佳分数一致，
最大差为零。故在这批已评分链内，没有发现最终选择丢掉更优链的错误；
也不能将未选中的非即时链作为 PC2 见证。

这一归因显示，简单的“完全没有生成非即时前缀”不能解释开发结果；
但有限采样下没有低终距非即时链，无法单独区分后缀优化不足、动作空间
覆盖不足、留存策略或该任务约束。它不证明这些前缀不可行，也不排除
未评分链存在解；不应据此认定理论失败或继续重开已停止的单配置。
该结果不替代事前同链机制或独立强基线比较，PC2、PC3 状态不变。
