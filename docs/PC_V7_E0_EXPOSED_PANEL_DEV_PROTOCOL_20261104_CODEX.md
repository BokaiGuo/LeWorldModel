# v7 精确动力学已暴露面板：开发回归协议

在 Cube 检出并修复“同一实际动作跨批误判弃权”之后，使用 v7 完整入口重跑既有 v5 18 根精确动力学开发面板。该面板已暴露，作为新版本接口和选择敏感性诊断，不是前瞻确认。每根根状态、目标、方向、优化器、1920 packet-token 总上限与现有 v5 面板一致，v7 为最终同批配对评分预留 6 token；不能称优化器内部预算完全相同。

记录所有实际请求及 float32 动作、位置、得分、候选、精修、比较和最终选择；对每条轨迹使用同一精确动力学重算，验证最终选中动作正是配对批中的相应动作与得分、所有 token 计数、同动作确定性弃权。报告配对选择与 v5 结果的变化及完整链终距，但不将其解释为独立泛化或强基线优势。机制资格必须另行对 v7 最终链做既有共同后缀与重规划干预，不能从 v5 迁移。
