[运行器](../le-wm-main/experiments/pc_pusht_proposal_scale_coverage_dev_20261105_codex.py)保存全部动作、目标、warmup 末态、候选末态和逐链控制步越界标签；[原始报告](../le-wm-main/results/pc_pusht_proposal_scale_coverage_dev_20261105_codex/report.json)包含输入哈希及分组执行时间。[算术审计](../le-wm-main/results/pc_pusht_proposal_scale_coverage_dev_20261105_codex/audit.json)重新生成动作并独立重算指标；它**没有物理重放**，也不能排除共享环境的错误。两项候选及指标单元测试通过。统计仅有两个已选开发任务，训练外、normalizer 外和开发外来源未知；未调用模型、未测评分、未运行规划器或真实反馈，PC0–PC5 不因此改变。

相关实验技能促使本次事前固定动作生成、分母和指标，并将执行完成与科学验收分开。下一步若要识别幅度与时间结构各自作用，应正交控制两者并加入预定、不同来源的任务；若研究成功链错排，则应另测合法视觉评分而不是把本结果当作评分证据。
