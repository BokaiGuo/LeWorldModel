# P1 居中可见性诊断（开发任务，不是独立确认）

在运行前固定：把已知 root0 的 reset 状态以及原生占位目标的推杆、
物体 XY 坐标均平移 (-80,-100)，不改角度、速度或 warmup 动作。
实际重新执行十步 warmup，保存三个真实历史帧及状态；禁止沿用旧 latent。
warmup 状态须与原状态平移结果在绝对 1e-7 内一致，否则停止。
原生终止始终有效；不关闭 success，不挑选新根。

任务生成器沿用 V3 的固定相对路点：
(130,-100,4), (-100,-110,6), (-70,-70,3), (0,70,5), (130,80,2)。
这是 privileged task generation，不是 RGB planner，不算方法成功。
保留原 complete20、初始不成功、物体移动至少20、向初始推杆移动、
cp5物体不变、cp5 jointXY非改善条件；额外要求所有历史与20步帧中
物体及推杆通过固定8像素RGB边界筛查。筛查不能证明无遮挡。
拒绝也保存完整记录，不根据结果调路点、偏移或门槛。

此任务只隔离画布裁切混淆；平移可能改变模型表现，不是新的独立根。
只有任务合格后才能新编码历史与目标、接入原评分的规划对照。
