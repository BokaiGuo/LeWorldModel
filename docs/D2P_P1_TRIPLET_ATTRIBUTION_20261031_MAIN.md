# P1 三前缀、三后缀策略对齐分析

对既有 8 组固定任务，按根、任务、条件、逻辑臂和 selected /
zero / greedy 前缀对齐：前缀相对初始状态的变化、各自后缀
优化的模型分数、开放执行、真实中点重规划、信赖域重规划。
各后缀策略的前五步一致及动作执行绑定沿用已封存的逐步
检查；新表核验三份物理对照的成功与停止状态彼此一致。
各前缀**自行规划不同后缀**，不是共同后缀因果干预。

两个 root 0 条件下的 selected 前缀物体位置和角度误差变化均为
零，但推杆位置误差分别下降约 2.7873 和 2.5903，native joint
XY 误差分别下降约 2.5587 和 2.3780；因此不能把物体未移动
直接当作整个任务没有即时进展。root 1 的 selected 前缀物体
位置和角度误差也略有下降，而推杆误差增大；不同指标方向
不同，须按原预先固定的具体判据判定，不能事后挑选一个。

原开放四起点规划中，8 个逻辑配对有 5 组 selected 的模型
终态 latent 分数低于 zero；其中 3 组发生 selected 未成功、
zero 成功。这三组属于同一个已知物理根，且模型比较的是
各自优化的不同动作，不是相同动作的预测误差实验；它们
说明模型分数不能在这些案例中替代实际成功，不足以单独区分
模型预测误差与 latent 任务评分失配，也不足以断言选择器 bug。

所有 8 组 selected 在三种后缀策略中均未成功；zero 在开放、
真实中点、信赖域分别有 5、1、2 条成功记录。部分逻辑臂共享
动作和根，不能把这些计数视为独立试验。root 0/off 第一组
zero 的原开放和信赖域在不同步数原生早停；表格分别保留状态、
步数和 null 固定时域终点，不能把其终点直接与完成十步的
selected 数值比较。
