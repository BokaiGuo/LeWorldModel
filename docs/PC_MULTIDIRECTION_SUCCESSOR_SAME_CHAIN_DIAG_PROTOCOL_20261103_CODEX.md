# 多方向后继编译器：最终链事后机制诊断

在编译结果与停止决定之后制定；不重开原规划或修改链。对 24 个暴露根，
固定最终精修与弃权之后的 selected 前五步、zero、同首段候选库即时
greedy，以及同任务历史 random bridge / lookahead 首五步。后两种控制
来自先前封存的其他方法，属于事后控制，不称作同版本事前对照。

逐前缀复用此前开发诊断：共同施加零、四个预定常数动作和 selected
最终链后十步，报告绝对终距及相对各自零后缀变化；再用相同 floor-CEM、
120 完整链评分、同根相同随机数给各前缀自行重规划。非即时条件沿用
`prefix_distance >= initial_distance - 1e-10`；selected 在共同的
selected 后缀上相对零后缀变化及各自重规划终距均严格优于 zero、greedy
的阈值为 `1e-10`，报告三个条件同根交集和四控制交集。先前已发现该
120 次后缀优化不一定充分，这种比较不能视为规划上界。

另对每个前缀施加十步零尾部，在其后五步动作十个坐标上做 `±0.05`
中心有限差分：每次执行该前缀及十步尾部，测量最终二维位置，记录
`2×10` 响应、奇异值、与 zero 和 greedy 的响应差。该诊断使用同一实际
float32 动作与 exact 模型，不把响应差本身当成可利用收益。调用计数单列，
不计入原编译器预算或原结果。

所有候选与分数逐条重放，绑定协议、源码、原结果及审计哈希；不覆盖任何
原文件。事后挑选的 selected 后缀和历史控制不能提供独立确认；即使出现
交集，也必须另设事前机制协议和验证，不自动宣布 PC2、PC3 或 RGB 通过。
