# 高维谱结构增量合同：开发草案

状态：设计草案，**未冻结、未运行、未通过原谱增量合同**。本合同检验
有限资源下谱方向选择或压缩是否有实际价值，不要求与其数学等价的
岭求解得到不同结果，也不以低维 2×2 实验支持高维效率结论。

## 实验对象与预检

使用冻结动力学模型的多步动作到任务相关输出的响应算子，而非仅把二维
问题补零。预先定义真实有效的动作坐标维度、输出投影、规划时域和模型
输入；如果多步 PointMaze 模型不能提供稳定可微且任务相关的响应，则
报告不适用，不将不可部署的物理真值用于正式规划器。用实际归一化、
时钟及有限差分检查 JVP/VJP，再做开发集上的响应秩、谱间隙及局部
线性有效范围诊断。不得根据某方法输赢筛选确认任务。

## 比较臂

相同冻结模型、初始状态、动作边界、损失、反馈和下游优化器：

1. 截断谱子空间（固定预声明的秩及提取算法）；
2. 独立随机同秩正交子空间，按预声明种子重复；
3. 直接任务梯度方向，明确每次更新及多步优化预算；
4. 完整响应求解／完整动作强优化，记录收敛与数值稳定性。

所有臂包含生成、响应提取及后续优化成本；记录模型编码、前向、
JVP/VJP、反向、分解、内存峰值、同步后 wall time 与最终真实任务
指标，按原始单位报告。预算点、计时硬件和共享开销政策在运行前固定。
若完整分解须先构造全矩阵，其代价必须全额计入，不能仅计截断后的
维度。绘制配对任务上的质量—成本曲线，而非只报告一个事后最优点。

## 声明边界与冻结条件

谱是否胜同秩随机方向、直接梯度及完整求解各自是独立对照；等秩不是
等成本，结果必须包含实际提取成本。二维 SVD 与岭求解相等是预期的
代数结果，不是实现失败。合成或精确动力学预检必须单列，不能替代
冻结视觉模型或真实任务证据。

在实际确认之前，必须确定高维任务及来源、独立根、秩/随机种子、
预算点、主要物理指标、实际意义阈值、样本量、统计和失败规则，并
对协议及依赖生成冻结哈希。当前这些尚未确定，因此此草案不能作为
事前注册或谱增量成立的证据。PC2 同链机制与 PC3 公平规划优势还须
由响应程序合同独立证明。
