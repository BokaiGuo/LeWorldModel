# dev305 RGB 局部切向分量探索

在已打开物理结果的开发根 `301000005` 上，固定同一 17×17 两包动作库，
分别以当前 RGB 五个固定扰动构成的编码 Jacobian 的物体三列、推杆两列、
五列联合坐标评分。岭系数固定为最大奇异值平方的 0.01。局部坐标只是编码
空间代理，不能直接解释为真实物体运动；目标图仍未通过原边界 guard，
因此该试验不是合格的正式部署或独立验证。

冻结模型在主机 CUDA 重算全部候选；三个前缀的原 latent 分数与封存的
同动作预测逐项一致，模型权重前后哈希一致。编码器与投影器各 40 次，
预测器和动作编码器各 102 次 / 1734 样本。这包括重新构造当前 RGB
切向矩阵，但不包括上游候选生成、历史物理执行等全部成本。

物理值按索引关联既有 867 条执行记录，没有新物理执行；所有列出动作均
执行满十步且未原生成功。所有终态物体姿态与各自前缀后的姿态相同。
与旧 latent 评分选择相比，物体位置和角度均未改善。因此拆分评分能改变
动作排序，却没有在该固定开发候选库中恢复物体控制；不能认定 P1 机制
成立，也不能断言该局部代理或模型在其他条件下一定失败。

保存检查核对了来源哈希、867 个唯一配对、岭系数、评分求和、argmin 和
物理时域。预测 latent 差向量未封存，所以无法仅从该报告独立复算评分，
需要重跑模型；这是当前产物的明确限制。下一次实验应保存这些向量并核验
图像扰动的方向和动作响应，再对符合目标图可见性合同的新候选作真实反馈
对照，而非事后选取本表中最有利的分量。
