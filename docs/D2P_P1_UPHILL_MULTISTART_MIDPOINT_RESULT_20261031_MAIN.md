# P1 多起点固定动作的真实中点刷新

主机 CUDA 对全部 19 条合法十步轨迹重放原选中动作：开放十步
目标分数均通过原规划分数核对，实际中点与终点图像及动作按哈希
绑定。五条早停轨迹没有补齐十步终点。结果为
`le-wm-main/results/p1_uphill_multistart_midpoint_20261030_main_RUN01.json`，
SHA-256 `572805d5eca7c160075c3c62f3dbad519ac0b856d0d038ff236d8a6e3caa671e`。

| 描述性指标 | 19 条记录均值 |
| --- | ---: |
| 预测五步与真实 RGB 编码 MSE | 0.24444 |
| 开放十步与真实 RGB 编码 MSE | 0.27760 |
| 真实中点刷新后的十步预测与真实编码 MSE | 0.10858 |

真实中点刷新后 14/19 条误差下降、5/19 条上升。已知根、
共享轨迹和重复臂使这些记录不是独立样本，不能解释成总体频率。

三个双方都走满十步的 selected-minus-zero 目标 MSE 差如下，负数
表示 selected 分数较低：

| logical pair | 开放预测 | 中点刷新预测 | 真实 RGB 编码 |
| --- | ---: | ---: | ---: |
| 3 | +0.005926 | +0.138733 | -0.377594 |
| 4 | -0.004251 | +0.059260 | -0.000250 |
| 5 | -0.017298 | +0.115274 | +0.064255 |

刷新在第 5 组修正了原排序反转，第 3 组仍反转，第 4 组则从
一致变为反转。因而该批证据支持中点漂移影响预测，但不能认为
单纯刷新可以解决所有排序或真实控制问题。

首次运行在任何神经推理之前触发 `KeyError: condition`：盲
规划包有意不提供条件字段，而新诊断程序误从该包读取。已改为
使用验收过的物理报告条件，并重跑成功；这是诊断代码问题，
不能作为理论或模型负结果。该实验没有根据真实中点重规划或
执行新的动作，不是在线反馈收益、独立确认或 P1 通过。
