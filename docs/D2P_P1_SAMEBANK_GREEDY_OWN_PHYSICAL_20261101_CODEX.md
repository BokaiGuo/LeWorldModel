# Same-bank greedy own-suffix physical replay

This is a known-root exploratory single-prefix development comparison, not P1
admission or independent confirmation. The roster is exactly
`same_bank_greedy`; the replay executes its sealed greedy prefix followed by
its selected own suffix. No neural calls, witness actions, or future physical
outcomes enter planning.

Before any physical execution, the consumer checks the supplied completed CUDA
report SHA, preparation/binding/source closure, frozen model identity, original
same-bank scoring argmin and actual prefix, actual cp5 PNG/state identity,
reconstructed task and normalized history, predefined prefix-plus-zero hold,
both durable ledgers and contracts, exchange argmins, selection argmin and
selected full-plan identity. The physical executor checks centered warmup and
root, all returned actions and goal identity, and cp5 pixels/state against the
planning input. It saves checkpoints and explicit completed, native-stopped,
canvas-censored or failed status; it does not pad a stopped run.

Without `--authorize-physical`, the command only validates the plan and writes
nothing. With explicit authorization and an exclusive output, it performs the
single physical replay. The validator is read-only with respect to all inputs.
CPU fixtures and the pre-run check do not establish the replay outcome.
