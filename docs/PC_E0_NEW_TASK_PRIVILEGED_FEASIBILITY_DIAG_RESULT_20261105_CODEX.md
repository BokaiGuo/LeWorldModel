# 新参数 E0 面板：特权几何可达性诊断

按[协议](PC_E0_NEW_TASK_PRIVILEGED_FEASIBILITY_DIAG_PROTOCOL_20261105_CODEX.md)，对新参数开发面板 16 根分别构造经过墙上、下两个预定几何点的评估专用动作链：**32 条均未超过 15 步且均达到终距 `<0.05`，16/16 根至少有一条成功**。[逐链动作、轨迹和碰墙记录](../le-wm-main/results/pc_e0_new_task_privileged_feasibility_diag_20261105_codex/report.json)保留。

这证实这些任务在当前声明的动作域、15 步时域及该精确动力学下存在成功链，因此不能把前一轮三种方法均 `0/32` 简单解释为任务物理上不可达。但这两条路线使用了**特权壁面几何**，且在负结果后构造；它们没有进入正式规划器，不是合法预算内 oracle、自动发现或模型内收益。规划器零成功也仍不能排除其他接口或实现问题。

[独立标量几何重放审计](../le-wm-main/results/pc_e0_new_task_privileged_feasibility_diag_20261105_codex/audit.json)以不同于批量动力学的标量计算重放 32 条轨迹和碰撞，最大逐状态差为 0；它仍实现同一壁面与动作数学假设，不是另一物理环境的外部复现。一项测试核对动作边界与超时域候选不得截断。未认证真实视觉环境、训练来源、normalizer 或 PC0–PC5。

后续应在不泄露特权几何的前提下改进合法候选与多起点搜索，并让 CEM 及其他对照拥有相同表达和总预算；独立任务、实际最终链机制及完整成本仍需单独验证。
