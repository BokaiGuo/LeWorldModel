# 共同排序错误：平移集成开发协议

固定已暴露任务 1884–1891，帧 0 为当前、帧 5 为目标；两相机位置；候选为原先零、正、负三个动作，每个执行五步。1884–1887 是已观察结果的开发面板，1888–1891 是事前锁定的额外开发外推，非独立确认，也不证明训练外。物理重放固定后，将图像和当前 proprio 导出到单独的规划输入，评分进程只读取该文件；物理评估在选择文件封存后作为第三个进程进行。这个约束是研究流程约束，不是操作系统安全隔离。

共同从目标 RGB 确定居中位移：raw、centered 与 multi 分别选择原图分数、居中分数、五个居中后额外位移 `(0,0),(-2,0),(2,0),(0,-2),(0,2)` 的分数算术均值最小者；两个图始终施加同一位移。若越过平移边界或检测失败，保留拒绝及全分母；不得调阈值、跳过或静默回退。guard 是 5 次集成中的各单视图选择不全一致时采取零动作，否则采取共同选择。zero 恒为零动作。使用原始代价而非根据物理结果重新加权。

指标为逐任务、逐视角三动作池相对最低物理终点距离的遗憾、视角不一致和模型代价；整个池不是任务成功，也不是闭环。主比较 multi 对 centered；同时列 raw、guard、zero。按任务聚合，不把视角视为独立任务。必须计入 5 倍图像编码和 5 倍预测；输出同步计时，明确其不含物理和加载。

预定开发出口：所有 16 个视角完成几何合同；multi 在 1887 的偏移视角相对 centered 物理遗憾严格减少；并在两个预定四任务面板内分别满足 multi 平均遗憾不高于 centered，跨视角不一致任务数不多于 centered。若不满足，停止本次固定五视图均值构造；不通过继续换位移或 seed 补救。即使通过也只能考虑候选，不能提升任何 gate。
