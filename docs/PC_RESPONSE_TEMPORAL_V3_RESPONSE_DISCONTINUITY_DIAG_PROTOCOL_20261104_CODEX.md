# 事后响应尺度敏感性的阻挡分支诊断

在已有多尺度归因基础上，事前固定对全部六个非即时根、selected、
zero、greedy 三类前缀，使用裁剪的选中尾部首五步名义动作，按
0.01、0.05、0.1 各生成中心、十坐标正负扰动，再接五步零动作。
对相同 float32 动作运行原精确 Wall 后端，记录每条 15 步轨迹的
阻挡布尔序列、后继端点及中心差分矩阵；核对矩阵与已封存归因一致。

按前缀分别报告扰动正负对的阻挡序列不一致数量，以及各扰动与
中心阻挡序列不一致数量；另报告选中与 zero、greedy 响应差异。
诊断可支持“差分跨越了离散阻挡分支”的具体判断，但不能证明
真实 RGB 模型的机制，也不能改变事前机制负结果或事后重新定义
通过标准。保留完整阻挡序列以便复查，输出不得覆盖。
