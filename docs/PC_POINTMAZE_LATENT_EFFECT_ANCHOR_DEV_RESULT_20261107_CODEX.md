# PointMaze latent 行动效应锚定：开发结果

## 结论

在已暴露的 1884–1891 固定候选面板，将预测行动差值锚定到当前 RGB 编码后，1887 偏移视角的物理 regret 从 **0.143465** 降为 **0.069119**，但所选动作由 `+0.1` 变为零，而不是物理最优 `−0.1`。八根平均 regret 从 **0.013466** 升至 **0.024994**，仅 **2/8** 根的两视角平均 regret 改善。预定开发出口失败，应停止该固定构造，不能作为问题修复。

16 个视角中选择改变 8 次；两视角选择不一致由 1/8 根降至 0/8 根。这再次说明视角一致性本身不是物理质量保证。零动作的真实后继可能移动，锚定当前编码是模型修正假设而非物理恒等式；结果不能证明代码 bug 或否定一般行动效应方法。

## 合同与检查

- 同一固定的三个五步合法动作、旧 centered 图像和冻结模型。原始分数逐候选复现既有记录；额外锚定分数为当前编码加动作预测减零动作预测后的目标 MSE。48 次模型预测，另有 16 次当前图像编码；没有报告整任务墙钟或闭环成本。
- 评分读取旧公共当前图像、目标图像及当前 proprio；封存选择后，独立评价进程才读取物理后继。流程隔离不是操作系统访问控制，也不是独立盲测。
- 输入包含完整当前 proprio，属于 **state-assisted**；没有目标 proprio，不属于 RGB-only。结果不能晋级 PC0–PC5，也不能与视觉闭环性能混淆。
- 本轮相关测试 **22 passed**，包含完整面板、封存选择和评分路径检查；合成测试不构成控制收益证据。
