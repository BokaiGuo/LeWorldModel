# PointMaze 相机几何修正及同动作诊断

## 发现与修正

在 1884–1891 八个已曝光任务的相同物理初态上，旧开发相机 `(lookat x,y)=(3,2.5)` 相对归档帧的平均绝对像素误差约 **17.65/255**；图像整体存在约 14 像素垂直偏移。该偏移是实验输入合同问题，不能据此将此前负结果直接解释为理论失败。

按[相机检查协议](PC_POINTMAZE_CAMERA_GEOMETRY_CALIBRATION_PROTOCOL_20261107_CODEX.md)，在预定 25 个相机位置中，用前四根初态图选择 `(3,3)`；该设置在前四根和其余四根初态上均与归档帧 **逐像素一致**。旧 `(3,2.5)` 图像也逐像素复现了之前工件，因此差异来自被测试的相机设置，而不是无意改变物理初态。后四根同属已曝光面板，并非独立确认。预选网格、所有图像、默认相机参数和逐根误差保存在 `le-wm-main/results/pc_pointmaze_camera_geometry_20261107_codex_*`。

## 同动作预测与物理评价

按[第二份协议](PC_POINTMAZE_CAMERA_CORRECTED_EFFECT_PROTOCOL_20261107_CODEX.md)，修正当前及目标相机，固定 8 个任务、每任务 8 条动作、物理轨迹、模型和目标代价；先封存预测，再重渲染并编码真实后继。以下均为各任务等权平均：

| 指标 | 原 `(3,2.5)` 窗口 1 / 2 | 修正 `(3,3)` 窗口 1 / 2 |
| --- | ---: | ---: |
| 第 5 步视觉表示 MSE | 0.3376 / 0.3376 | 0.02079 / 0.02079 |
| 第 25 步视觉表示 MSE | 0.6533 / 0.6474 | 0.05104 / 0.04841 |
| 预测代价与物理末距排序一致率 | 0.6830 / 0.6518 | 0.7768 / 0.7813 |
| 模型选链的物理末距遗憾 | 0.3329 / 0.3262 | 0.2074 / 0.1942 |

修正后第 5 步视觉 persistence MSE 为 0.1193，故预测在本面板上优于该基线；预测与真实编码的排序一致率为窗口 1 的 0.7946、窗口 2 的 0.8080，真实编码与物理末距为 0.7679。排序每根均为 28 对候选，但统计单位仍是任务，不是 224 个独立样本。

不包含初态已成功的两根时，窗口 1/2 的平均遗憾分别从 **0.3335 / 0.3245** 降至 **0.2705 / 0.2589**，预测—物理排序一致率分别从 **0.7083 / 0.6369** 变为 **0.7500 / 0.7440**。全部任务及初态成功标记保留在原始结果中。逐任务并非单调改善：例如 root 1885 的窗口 2 遗憾从 0 升至 0.7796，root 1887 的窗口 1 遗憾从 0 升至 0.5029。

## 边界

校准使用已曝光归档数据；逐像素初态匹配并不独立认证官方原始相机、所有时刻现场帧或真实部署相机。后继图从物理状态重渲染，不是执行期间现场录像。该实验只检验固定动作池的开放环末距，**没有运行闭环规划器，也没有建立成功率或成本优势**。当前及目标完整 proprio 使其仅属 **state-assisted**；不能升级为 RGB-only 或 PC0–PC5 通过证据。

这次结果确认了一个具体的本地渲染几何差异，并显示它对模型预测和选择评价具有实质影响；它不证明其它偏移视角的泛化或剩余负结果全部来自相机。

原始输入、预测、每时刻图像与逐任务结果位于 `le-wm-main/results/pc_pointmaze_camera_corrected_effect_20261107_codex_*`。新增相机网格测试及相关测试共 **6 passed**；这些测试不是闭环认证。`code-debugging` 用于核查源码渲染合同并通过最小相机变更做配对验证。
