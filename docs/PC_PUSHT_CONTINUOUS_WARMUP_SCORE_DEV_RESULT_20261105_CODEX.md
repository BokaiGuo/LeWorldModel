# PushT 连续 warmup、独立固定候选库：视觉评分开发结果

## 结果

按[事前协议](PC_PUSHT_CONTINUOUS_WARMUP_SCORE_DEV_PROTOCOL_20261105_CODEX.md)，对已按物体运动筛选的本地验证序列 9、11，从初始状态连续执行记录的前十个动作形成历史，再分别执行共享的 64 条固定候选；目标为原记录动作的后继。随机候选库不由参考后缀生成，参考动作未进入模型候选输入。

| 序列 | 目标物体位移 | 目标中心合格 | 候选中心不合格 / 64 | 物理成功 / 64 | 预测评分首选成功 | 真实后继编码首选成功 |
|---:|---:|:---:|---:|---:|:---:|:---:|
| 9 | 59.01 px | 是 | 1 | 0 | 否 | 否 |
| 11 | 70.09 px | 是 | 0 | 0 | 否 | 否 |

中心合格仅指 agent 和物体中心位于 `[40,472]²`，不保证完整几何体可见。**两根均无成功候选，因而本实验不能测量评分是否漏选成功动作，也不能将首选失败归因于模型。** 目标参考链可以产生目标，但不在候选库中，也不是预算内自动规划证书。

在各自 2016 个候选动作对中，预测与真实编码评分的同序数分别为 **1842、1929**。候选动作对高度相关且只有两根，不能把动作对数当作独立任务数，也不能把排序一致视为评分能够识别物理成功。原始成功标签、候选评分对数和物理评分关系见[汇总](../le-wm-main/results/pc_pusht_continuous_warmup_score_dev_20261105_codex/report.json)。

## 核验与范围

130 条链从同一初态连续执行 warmup，没有从第 10 帧重置。目标第 25 帧的 agent、物体坐标与记录数据最大差异分别不超过 `3.1e-5`、`1.6e-5` 像素。独立审计器重建随机库和参考动作，在同一后端重放全部 130 条物理链，逐项核对历史状态、RGB、终态、目标帧，以及保存的 latent 排序和物理成功算术；见[审计记录](../le-wm-main/results/pc_pusht_continuous_warmup_score_dev_20261105_codex/audit.json)。神经输出核对回执与哈希，但未独立重跑模型；相同物理后端重放不能排除共同实现错误。

两根共记录 384 prediction tokens，不包括编码、物理执行、环境或系统成本。首次 GPU worker 在外层沙箱内因网络命名空间权限失败，没有生成输出；获授权后在沙箱外启动、仍使用隔离 worker 完成。模型、normalizer、数据的训练外和开发外来源均未认证。

这次的改进是排除中间帧重置漂移，并用有实际物体运动的目标和不依赖参考后缀的固定库检查评分；结果表明该随机库的覆盖不足，不证明视觉评分失真或规划方法失败。后续需在事前冻结协议下构造有成功与失败候选的合法动作库，分别检查预测误差、真实编码评分和物理结果，并避免参考动作泄漏到正式规划器。PC0–PC5 不变。
