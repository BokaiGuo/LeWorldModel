# E3 两根既有见证轨迹的 cp10 目标：探索合同

固定 E3 两个既知根，各取历史 P3 物理报告中 endpoints 臂的第
10 个控制步 RGB 及同时间物理状态作为目标；不根据结果选择根、
臂或目标帧。目标来自已有轨迹，非新根或独立样本。分别检查与
原始 E3 根 c0、前五步 c5 的状态与像素身份；源报告、事件日志、
cp10 PNG 的文件与像素哈希必须绑定。目标初始原生成功时不得
作为非初始成功任务；同时逐步报告历史见证最早成功步。

仅用主机 CUDA 的同一冻结 encoder 对目标 RGB 编码；模型哈希
前后一致。先保存目标 latent 和物理评价状态，不能将后者作为
规划器输入。此次不运行四臂规划，不宣称某一任务必定需要两个
反馈周期或 E3 已通过。后续比较须另定同反馈、成本和失败合同；
由于该目标来自已观察轨迹，只可用于开发验证。
