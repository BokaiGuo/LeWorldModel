# RGB 几何链与条件 CEM 链共同评分协议

目的：区分“没生成几何链”与“生成后模型也不选择”。固定已曝光
roots 20–49，每根仅有三条既有合法动作链，顺序为 geometry、endpoint、
temporal；完全相同起始 RGB、目标 RGB、normalizer 与五个动作包。
冻结 LeWM 在 GPU 对全部三条同时评分，按预测末帧编码目标代价排序，
平分采用数组较早索引；时序最小代价作为附加诊断，不替换旧算法。

先单独封存模型预测及两种排序，再读取三个已有物理回放结果，
统计两两比较和三链模型所选实际成功率；成功按原规则为 25 步内
曾终止。先前模型选择的 endpoint 和 temporal 实际各是不同候选池，
因此这里人为合并的三链池只是事后组件诊断，不是部署规划成绩。
模型各得分重算须与已封存两 CEM 链端点分数在 0.005 以内一致；
动作签名、模型权重、时钟、输入和来源文件绑定，不重新调参或
使用物理结果决定排序。完整成本比较与独立任务确认不在本实验内。
