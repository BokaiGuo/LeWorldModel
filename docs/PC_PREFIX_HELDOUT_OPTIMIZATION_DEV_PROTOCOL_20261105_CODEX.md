# 固定前缀的独立尾部优化：开发协议

在既有固定 reset、task/solver seed 42 开发面板首次规划的第二轮，
保留同一对父链及 A 构造探针。在当前规划器 top-k 确定之后，
针对各父链分别固定前缀，只对剩余尾部进行独立 CEM：32 个
候选、3 轮、每轮保留 4 个，两个分支使用相同随机噪声和独立
后验分布；单独的随机流不得参与当前规划器。各分支使用其 96 条
已评分候选中模型代价最低的完整链，额外成本共 192 条全链评分。

尾部候选在模型评分前按训练数据 normalizer 换算的物理
[-1,1] 域投影，前缀不变；记录前缀合法性和投影数。
父链前缀若不合法，仍需记录但不能作为严格合法样本。A 的预测、
尾部优化结果和父链被完整记录，优化结果不参与原策略更新。
比较父链代价、A 最低分及 A 相对父链改善对两分支优化结果的
排序；此处模型评分是结果而非物理成功。

同时保存原策略首链和实际动作／状态 trace；50 个重放一致
后，评价端执行两个优化结果的真实后果，所有任务计入分母并
记录合法性。数据、求解器及任务已暴露，结论仅为开发性；没有
证明描述的跨任务泛化或分支搜索对闭环有益。
