# OSFAL 启发的 PushT RGB 逐层诊断：预定开发协议

复用已封存的 16 个几何开发根、左右接触就绪状态、白/灰背景、zero/plus/minus 五步轨迹及目标图，全部根和条件纳入；不按预测或物理成功筛选。检查物理记录绑定的图像哈希及有效性。左右是不同物理配置，白/灰是背景变化而不是相机视角；任务根均已曝光，不是独立确认。

冻结原生 RGB LeWM，采用其原始图像预处理与 12 层 ViT 的 CLS token；提取同背景初态、实际后继与目标的表示，另记录正式 projector 后的编码。分别计算：同物理状态跨背景差、左右接触就绪初态差、同条件动作后继两两差、每动作的真实后继到目标的特征代价，以及由真实物块位置与周期角代价得到的物理遗憾。逐条件记录，每根汇总。真实状态、实际后继仅在离线诊断使用；不得作为规划输入。

逐层特征不与末层预测直接相减。将正式输出与既有模型报告的真实编码代价核验，容差绝对 1e-3、相对 1e-4。另引用同一封存面板的既有预测代价作为动力学预测参照，不能将不同表示的差值混为预测误差。按 1e-9 物理遗憾处理并列；比较物理遗憾而非仅比较 argmin 序号。

此实验没有相机变化、跨根学习、未查询动作、闭环执行和公平规划比较；选择最优层属于后验探索。不得把表征差异、背景不变性或真实后继选择结果当成 PC1/PC2 通过或规划收益。若进行层选择、校准或预测接入，必须另固定开发选择规则并用独立根验证。
