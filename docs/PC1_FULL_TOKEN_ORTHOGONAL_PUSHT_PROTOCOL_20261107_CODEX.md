# PC1 完整 token 与正交探针：PushT 事后开发协议

本次固定使用两个已有且已曝光的 16 根几何面板，共 32 个几何配置；前面板用于校准，后面板仅用于本次拟合的隔离评价。两组位置、角度不重叠，但同族规则生成，且历史结果已曝光，**不是独立确认或训练成员认证**。每根两侧、白/灰背景、零/正/负三个五步动作；背景变化不是相机变化，不将此结果计为真实 E1 camera 证据。

1. 重新 GPU 提取 12 个 block 的完整 token 和 CLS，并提取正式输出。各块的 tensor 形状必须符合 257×192；重算正式输出代价与既有真实后继编码逐项一致，模型指纹一致。完整 hidden state 只用于离线表示比较，不能直接替代 predictor 输入。
2. 所有层同时报告；不再次挑一层代替主方法。CLS 与完整 token 各自展平、按样本 L2 归一化后报告背景差异、左右初态差异、后果检索。这是固定度量的诊断，不能从归一化表示接近宣称信息不可恢复。
3. E5 仅使用校准组的初态与目标图配对拟合灰→白正交映射，不使用末帧或物理标签拟合。CLS 拟合 192 维旋转；完整 token 只拟合在所有 token 共享的 192 维通道旋转，而不是 49344 维任意旋转。报告秩、样本数、正交残差，以及评价组的恒等/均值平移/正交残差。秩亏必须保留，不通过增加末帧到校准库“修复”。
4. 隔离根的初态+目标特征向量，从校准根的初态+目标特征最近邻检索真实相对动作后果，与校准均值描述比较。检索标签仅是离线可读出性诊断，不能成为部署组件；报告物理原生七维状态距离的 regret 和 action-pair agreement。评价组按 root 汇总，两侧不是独立根。
5. 使用既有冻结模型预测、真实后继表示和物理代价做 E6 三方比较。校验源 NPZ/JSON 哈希与预测/真实分数对应；不将不同单位标量相减来估计理论 epsilon。正交映射对两侧共同作用时的代价不变单独验证，跨来源映射效果仅离线报告。
6. 主要评价指标固定为原生七维状态距离及原生成功分母，物块 pose 另作为已有局部诊断，不能替代任务成功。本面板局部动作并不以原生任务可解为前提；零成功时不声称控制有效。

每层保存拟合参数、逐根统计和摘要，沿用 research_runtime 原子 JSON 写入；输出已存在时拒绝覆盖。原始图像、物理来源、模型与脚本哈希绑定；不覆盖历史记录。以 root 的描述性 bootstrap 区间展示波动，但不声称同族根 IID。E1 真实相机、PC2 搜索与 PC3–PC5 仍需各自证据，本协议不会提前提升它们。
