# 精确墙障预测后继条件组合：开发协议

## 假设与范围

旧 waypoint 完整链先按自由空间计算中间点和尾部，若前缀碰墙，其尾部仍以假定的位置和朝向构造。检验：先对每条合法五步前缀查询精确后继，再从该预测后继重构剩余十步，是否在等动力学步数下增加成功。预测是精确模型输出，不从真实评估端读取；使用 exact-state 起点、朝向及目标，非 RGB-only、非行动描述增量。该假设基于已暴露任务提出，结果为开发证据。

## 比较

沿用 24 根已暴露任务及原实验每根封存的偏移顺序。新臂取前 192 个偏移，构造与原方法相同的五步前缀；实际调用精确后端预测这 192 个前缀的完整后继状态。若原自由空间计划的中间点应在五步内完成，尾部从预测后继直达目标；否则先从预测后继尝试到中间点，再到目标。尾部仅用十步，截断或零填充。每条完整 15 步链再从原始起点完整评分，最终选最低终距，记录全部前缀、预测后继、完整链、评分及耗时；不得用成功标签选链或调用未来真实反馈。

对照为原同任务、同偏移顺序前 256 条自由空间 waypoint 完整链，选其中最低代价。新臂 `192×5 + 192×15 = 3840` 次动力学步，基线 `256×15 = 3840`；均计入所有前缀及完整链调用。为避免原后端每次无条件补到 16 步带来计费歧义，使用相同物理步函数的逐步向量化后端，并与原 16 步 padded 实现复核。两臂算法生成和系统时间另外报告；相同动力学步数不保证相同完整墙钟成本。旧 384 候选基线结果作为额外背景，不当作等预算对照。

## 固定出口

记录全部 24 根严格成功（末距 `<0.05`）、配对独胜独负、平均终距及阻挡步数。若新臂至少独胜 3 根、独负最多 1 根，允许后续在独立开发任务进行相同权限和完整成本验证；否则停止此固定组合规则。该出口不是 PC gate，也不能追溯调整。无论结果如何，不将其归因于描述，或升级为 RGB 主论文结果。
