# 两包目标动作链：真实中点反馈开发对照

对全部 24 条已执行且完整的两包目标动作链，不按历史结果筛选。
第一包保持原始动作字节；在其真实第 5 步 RGB 后重建模型历史，
以原第二包初始化，单起点 Adam、20 步、学习率 0.05，动作范围
`[-1,1]`，仅当新模型终点分数严格降低时使用优化动作。
同一规则应用于 selected、zero、greedy；模型冻结、不输入模拟器
状态、不训练额外网络。记录编码、预测、反向调用及耗时。

随后全部固定槽物理执行，第二包派发前验证实际中点 RGB、状态
和快照与离线规划使用的中点一致；不一致则停止该槽并记录工程
失败。比较原动作链与反馈动作链的成功、位置、角度、推杆、
联合指标和提前停止；不填补停止后的终点。反馈增加了编码与
规划成本，本实验是事后设计、已知根上的反馈开发对照，不是
同预算强基线、独立确认或 P1 准入；不修改原 gate。
