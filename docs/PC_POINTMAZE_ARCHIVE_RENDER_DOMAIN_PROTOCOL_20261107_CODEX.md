# PointMaze 原帧与重渲染输入的配对诊断

已曝光开发根 1880–1883。该比较使用同一冻结的 state-assisted JEPA
和完整 proprio，不属于 RGB-only，也不是独立确认。

准备阶段从归档提取帧 0、初态和动作 0–4，封存为单独输入；
原始 `.pth` 必须整文件读取，但不会把后续帧复制进输入。
预测阶段读取这一输入及此前封存的当前图像，模型载入器按原合同
读取完整轨迹统计；不读取归档帧 5 或反事实真实后继。对四个固定
常量动作和归档实际动作预测，保存模型输出及输入、脚本和模型哈希。
第二阶段核验预测封存后，以归档帧 5 对比归档实际动作的预测；
并以每个相机的重渲染后继对比相同动作下原帧输入与重渲染输入
的预测。真实后继不参与选择。

报告初态像素差、两种输入对相同渲染后继的编码 MSE、归档实际
动作对归档后继的 MSE。不同动作分布不能作为严格的单因素结论；
相机不同造成的参考坐标、预处理和实际渲染差异都需保留。按任务
汇总，不事后声称选择或控制收益，不将该分析作为 gate 通过标准。
