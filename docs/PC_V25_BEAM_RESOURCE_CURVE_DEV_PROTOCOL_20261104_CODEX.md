# v25 搜索宽度与资源曲线：新开发面板

目的：检验缩窄递归搜索束、将释放的预测预算交给现有共同 CEM 精修，是否改善自动选中完整链的成功率或质量。不是单独的响应方向贡献检验；束宽也改变保留候选、后继探针与后续搜索内容。

事前固定 16 根 exact-Wall 任务：起点 `(-0.5, y, theta)`，目标 `(0.5, gy)`；`y=±0.165`、`theta=±1.09`、`gy∈{-0.14,-0.06,0.06,0.14}` 全组合。对明确列举的旧面板去重，不据此声称训练外或广义来源独立。每根三个方法、两个预测 token 上限 1,920 和 2,880：

1. v25 原配置：beam 4、greedy 2；
2. v25 窄束：beam 2、greedy 1，保留一个非 greedy 槽；
3. 相同全局候选库、相同 CEM 多起点及配对弃权的 shared CEM，无响应搜索。

其余配置、动作域、任务、时域、名义动作、模型、评分、随机种子、反馈权限保持一致。每个独立预算点使用同一固定随机种子；各点不是独立样本，也不预设嵌套。每根每臂从生成开始计费，记录所有模型请求、样本、候选、保留、完整链、精修、SVD 和耗时；失败按失败记录，不补跑或换根。成功定义终距 `<0.05`，报告逐根结果、成功与终距及使用 token；算实际成功数时失败计入分母。预测 token 不是全部墙钟、内存或 GPU 成本。

运行完成后逐批核算另一同环境实现、合法动作、选中完整链和实际最优评分，重放编译器和 CEM 的每条预测请求并验证计数；不同臂共享首批全局候选。额外的可行性见证或独立来源不由此面板假定。该面板为开发、不是预注册确认或 PC2 同链机制；不据此宣告 PC0–PC5，通过与否保留原合同。
