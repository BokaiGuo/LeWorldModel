# E0 四结点后缀表达：特权事后投影诊断

沿用特权前缀诊断的 18 根及每根第一条合法成功解析见证。前五步保持见证的 float32 动作；以固定、与原 CEM 插值一致的 10 步四结点分段线性设计矩阵，对解析后十步分别按动作坐标做无权最小二乘拟合，结点裁剪至 `[-1,1]` 后插值并以 float32 精确后端重放。另重放原解析全链和特权前缀加零后缀。逐根保存设计矩阵、结点、三条动作、端点、终距以及动作空间投影误差；报告各链成功数和终距分布。

这只是固定见证在动作均方意义下的一个投影，**不是有界最小动作误差解、最优四结点轨迹、最优物理终距或方法可达上界**。投影可能改变动力学分支；投影失败不证明四结点无法表达任何可行后缀。见证及诊断均为特权和后验，不输入规划器，不作为 PC2/PC3 证据。独立 CPU 检查矩阵构造、动作、同后端端点和汇总；不可覆盖已有结果。
