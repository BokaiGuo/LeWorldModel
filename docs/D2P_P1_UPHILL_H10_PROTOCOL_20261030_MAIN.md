# 模型内重选前缀的 H10 干预合同

目的：对已封存的全部八个逻辑臂，分别比较重选 selected、zero 和
greedy 三个五步前缀。所有前缀来自同一物理根、目标和观测条件；
每臂共同使用从该臂重选动作尾部构造的固定 42 个十步后缀。
这些前缀来自已观察结果的开发流程，既不是独立确认，也不得按
物理成功挑选子集。逻辑臂和条件可能共享相同物理根或动作。

输出要求分列前缀前后物体位置误差、角度、推杆、原生联合误差与
原生成功；每个共同后缀需报告绝对终点、相对各自零后缀的变化、
停止或删失及返回步数。早停不得补全不存在的十步终点。
同后缀差异仅说明该动作的效果，不证明可规划能力；后者还需要
各前缀基于真实 cp5 RGB、用同优化器和固定预算自行规划后缀，
再做实际物理执行。评测不得把模拟器状态输入 RGB 规划器。

规划性能比较另需统一资源约束，给基线使用结构计算占用的预算
的机会，分类记录编码、预测、反向、结构计算和时间，不未经约定
将不同调用相加，也不强制浪费计算。该干预不修改 P1 gate，
不训练模型，不支持 P1 通过或独立泛化的主张。
