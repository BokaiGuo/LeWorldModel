# 前缀条件化候选集合配对审计：开发协议

目的：在现有条件化规划器运行时，固定相同前缀、方向及响应，
比较条件化与共享响应生成的无序完整链集合。此实验只检验候选生成，
不推断真实收益、样本外预测能力或发现贡献。

使用固定 reset 的既有 PushT 开发 seed 42、50 个任务，300×10
规划器、原评分和原生返回均值。条件化候选照常评分；同时构造但
不评分的共享候选只用于集合比较，因此不增加模型评分次数。每轮记录
两个集合中在对方找不到逐坐标最大绝对误差不超过 1e-6 的候选数；
该数量按生成条目计数，不声称已对集合内部去重。记录符号分歧、
候选对应掩码和计分数。该审计不会识别哪条新增链更好或最终链依赖它。

任务与优化 seed 尚未解耦，固定 reset 不是原始数据状态复原证明，
动作合法性也未由此实验认证；不将本实验用于 PC0 或性能比较。
若结果目录已存在则退出，不覆盖历史结果。此开发面板不用于确认。
