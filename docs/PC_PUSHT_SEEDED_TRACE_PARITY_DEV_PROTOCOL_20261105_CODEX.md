# PushT 固定 reset 的逐步物理重放一致性协议

2026-11-05，执行前：单独重复运行 `mean` 选择臂，保留每次 solver
首次规划候选与代价，并在真实环境执行每步记录 reset seed、原始动作、
完整物理状态、公开状态、终止标志。与不加 trace 的相同受控配置比较
逐任务结果；记录钩子及文件写入不应被计为无开销。

对每个任务，根据数据行及 `771001 + 环境序号` 复刻原生初始化顺序，
使用与评测同源 action 标准化器对 solver 的均值动作做逆变换，执行
首次动作链，逐步比较日志里的动作、状态及物理状态。只对真实已经
执行过的步比较；动作绝对容差为 `1e-6`，物理状态逐坐标绝对容差为
`1e-4`。若任何状态或动作未在容差内匹配，明确
报告不一致，不用该重放产出可信的物理反事实结论。
完成均值链一致性后才能使用同一初始状态重放样本最优反事实；
反事实只涉及首次开放环 25 步，不等于 50 步反馈闭环的最终成功。
物理数据仅用于评价，不输入规划器；报告全部越界动作及异常。
