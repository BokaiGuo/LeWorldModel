# 模型分数差的动作回退：固定池开发检验

流形残差筛选失败，但简单模型分差在 10 个已曝光根上出现方向
一致率差异。本实验检验不同假设：当模型偏好某探针但分差很小时，
是否回退等时长参考动作可以降低真实末距。所有动作是既有合法
完整链；这不是新训练、真实状态输入或描述保留机制。

用已曝光根 10–19 的全部参考—探针模型绝对分差的中位数确定
阈值；没有物理数据参与标定。将阈值和根 20–49 上全部成对选择
索引先行封存，再读旧物理轨迹。30 根是固定留出开发评估，并非
来源合格的独立确认：这批任务和许多轨迹在前期研究中已曝光。

对每根 8 个前缀各 8 次参考—探针二选一，三臂共享全部模型查询：
1. 直接按两条模型分数中较小者选择，平局保留参考；
2. 仅当探针较优且绝对分差严格大于标定阈值时选探针，否则参考；
3. 始终参考。

评价每任务内 64 对的实际所选链 25 步末距、25 步内曾终止比例，
再按任务等权；记录每任务所有选择与真实结果。预定开发出口：
门控相对直接选择平均末距至少减少 0.5 个坐标单位、至少 18/30 根
末距均值严格降低、曾成功比例最多下降 0.01。若不达标停止该
固定阈值和回退规则，不事后调阈值。曾成功与终距为不同目标；
这不是原始规划器成功率、完整反馈或等成本净收益。

本地物理状态只在评价端读作先前轨迹，不参与阈值、分数或选择。
所有源文件哈希、门控动作数、每根指标及协议绑定留存。
