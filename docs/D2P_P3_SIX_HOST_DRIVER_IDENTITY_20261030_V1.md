# P3 六槽身份接线和保存消费

新增独立预加载模型 driver 与保存消费者；没有命令行启动器，也不加载模型、启动 GPU 或物理环境。本次未执行生产，未修改现有科学门或既有封存。

driver 需要调用方显式提供主线程授权标记、协调记录、资源计划及其哈希、源码合同和三个实现文件哈希；它在独占外层目录写入 fsync 的 begin，再创建独占六槽输出并用相同 model/device 构造原生 factory、`NativeTree` 和 `RecordingBackend`。复用身份桥接的前后权重、buffers、源码、精度和 UUID 检查。数值调用前后检查精度、UUID、存储/墙钟和 CUDA 峰值；守卫异常毒化 factory，阻止后续环境创建。完成后写独占 fsync end，异常时尽力写 failure，保留已有 run 和失败文件，不覆盖。

独立消费者要求外部传入 begin/end、资源计划、源码和 terminal 哈希；检查记录之间的关联、资源配置及峰值，并调用既有 source-bound 六槽严格数学消费者。任一缺失、篡改或不完整运行均不可作为成功消费。测试为 CPU 替身，外层记录调用实际 fsync；未验证真实 GPU、权重或物理执行。

限制：标记和本地哈希不构成真实授权、可信时间戳或硬件证明；需主线程审定实际六槽限额和运行准入。模型及 CUDA 上下文由调用方预先创建，模型加载与其资源成本不在该 driver 的墙钟计量内；已有峰值不重置，但仍需全程资源准入。guard 不覆盖所有物理/编码操作，也不能证明两次快照间没有瞬时身份变化；producer 已封存后才写外层 end，若后检或写入失败，必须同时保留并拒绝单独使用该 producer 输出。外层 failure 仅尽力保存，I/O 故障可能使其缺失或不完整。底层原生构造器返回句柄前抛错时的资源释放仍未闭合。独立消费者不是完整 HOST/物理认证，也不证明科学通过、等算力或泛化。
