# V4 固定候选配对保留质量诊断协议

开发诊断，事前写定；不是 PC2/PC3 确认。使用已暴露的 24 个 E0 根及两个封存计划中的同一九候选、各自四候选保留索引。核验来源及保留重建审计哈希，不能重新选择集合。

每根、每候选使用三个预设随机种子 `2027111900 + 100*root + replicate`，零尾部为初始 incumbent，四结点 CEM 采样 119 次，总计每候选 120 条链。相同根和重复的不同候选共享随机种子；同一候选在两个集合中只有一份结果。保存动作、预测、评分和每代信息；对全部批次独立重算。每个策略在每根每重复只从其四个固定候选中选最低终距；报告逐根三次平均的均值、中位数、胜平负、每次及逐根平均小于 0.05 的数量，以及全九候选 oracle 和即时 greedy，后两者仅为诊断。

三次随机重复不视为独立任务；不做显著性结论。两个策略每候选搜索数相等，但离线评估九个候选的真实开销不等于部署四候选方法的总成本，且不含联合精修或反馈。固定零尾搜索不复现 v4 后继响应初始化。结论只针对此候选库、优化器和协议；不得据此宣称 PC gate 通过或单独证明谱增量。
