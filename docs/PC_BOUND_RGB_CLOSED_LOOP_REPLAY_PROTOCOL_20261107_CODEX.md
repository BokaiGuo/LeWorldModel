# checkpoint 绑定边界：RGB 闭环接入重放协议

使用既有已曝光 TwoRoom episode 9000–9003，同 checkpoint、normalizer、RGB 输入、动作时钟、候选随机种子与剩余 25 步时序目标，实际重新运行原 `lookahead`、`effect` 与 `cem16` 三臂；每次最多执行 5 环境步并重新观测，首次成功或截断停止。任务物理状态只用于评价端 reset 和真实结果，不进入模型输入。

各臂均使用同一个 `CheckpointBoundRGB`，启动与最终封存均检查运行中的每个参数与 buffer 精确匹配指定 checkpoint；冻结权重、输入与模型指纹。所有决策分别记录实派动作、选择、完整查询与模型包数、输入收据和执行轨迹；新增边界核验时间单独统计。重新执行结果逐任务核对原封存的剩余时钟、查询数、所选完整动作（绝对容差 `1e-6`）、实际分派、每步物理距离（`1e-5`）和成功/截断标志；不一致即拒绝登记等价。

预期 12 个实际闭环任务，无预先假定成功率；训练成员和早期曝光未知。该重放只验证严格边界接入同一实现的行为，非独立模型、环境、科学确认或性能比较。记录检查所用额外时间，但不把一次顺序测量解释为正式成本曲线；独立输入权限和 PC0–PC5 科学证据需另行完成。
