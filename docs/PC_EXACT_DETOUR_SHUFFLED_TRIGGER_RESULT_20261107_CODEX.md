# 精确墙障：触发时序打乱诊断结果

按[新臂运行前的事后消融协议](PC_EXACT_DETOUR_SHUFFLED_TRIGGER_PROTOCOL_20261107_CODEX.md)，
对已曝光 24 个 root、每个 384 条候选，将原受阻触发时序在相同侧向
和半径组内随机重新分配。每组逐时刻触发次数精确不变；固定随机种子
产生 95/9216 个候选保留自己的原时序。

| 指标 | 打乱时序 | 原受阻时序 |
| --- | ---: | ---: |
| 终距 < 0.05 | 13/24 | 16/24 |
| 平均终距 | 0.22085 | 0.14945 |
| 独胜 root | 7 | 9、11、12、14 |

这在该开发池中显示候选与触发时序的绑定可能有价值，但不是独立
证据，也不能单独归因于实时受阻检测。打乱时序取自同一任务的原臂，
并非免费可部署输入；打乱后新轨迹的受阻时刻可以不同。每组保持
触发总量、时间分布与侧向/半径类别，但各候选触发次数未必相同。
此前预定的固定时刻盲对照开发出口未达到，本次不能追溯改判。

已逐动作用原时序重建全部 9216 条原臂候选，打乱臂逐链验证动作
界限和重放，验证置换及逐组逐时刻触发分布；相关测试 9 项通过。
原臂、新臂各需每任务 5760 动力学步；时序采集依赖原臂结果。
身份重建与新臂重放各另计 138240 动力学步，两者仍共享同一底层
动力学，并非独立仿真器或完整墙钟计费。

结果仅限精确状态、精确动力学及曝光任务，不是 Action-Effect
Descriptor、RGB-only、真实闭环或独立泛化证据，PC0–PC5 不改判。
