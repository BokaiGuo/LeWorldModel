# RGB LeWM 单帧动作时钟：接口诊断协议

对已封存的 PushT RGB 接触面板固定根 0、1、8、9、白背景左右两侧，使用对应的 plus、minus 五步原始动作，按原 normalizer 编为两个十维 packet。用真实 GPU 冻结 LeWM 比较 `get_cost`／`rollout` 与单帧编码后连续两次显式 predictor 调用，检查初态、五步预测与十步预测的张量与末帧目标成本。

单帧 context 的 `action` 字段分别填零和固定非零占位，候选动作不变；检查两者输出相等，并单独改变候选 packet 观察实际响应。逆归一化须还原全部五步原动作。该对照只核验调用约定，不以一次响应非零认证物理准确性或控制收益；本地兼容版本与 checkpoint 为开发条件，旧图像和 roots 已暴露。

没有真实未来观测输入；没有环境重放。先后两预测点只声明模型时钟，物理五步对齐依赖既有独立物理记录，不借此证明更长闭环。输出绑定模型、输入、代码、动作统计指纹，不改写旧产物。
