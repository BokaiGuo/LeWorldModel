# TwoRoom 四个失败根：完整已评分池物理覆盖

基于原规划器封存的 4 个 lookahead 失败根（62735、82490、86996、168250），按原顺序重建并物理重放每根所有 300 条生成链、4 条全局链和 64 条共同尾部组合：共 1,472 条、36,800 环境步。原 288 条各前缀精修链已有完整物理重放；逐根合并后覆盖原实验实际评分的 656 条，不去除重复动作、不把额外前缀精修计入每臂的部署预算。

初始候选和组合动作直接从原计划恢复，反归一化使用同一数据 normalizer，并核查其原始动作哈希。每条从相同数据初态和目标 reset，在默认环境几何下执行满 25 步，记录动作字节指纹、模型分数、前缀和尾部来源、逐步距离和成功。此前已执行的 incumbent 或最终选中链若逐字节相同，其轨迹必须完全匹配原封存记录，否则中止。

逐根报告 368 条新增链与 288 条精修链的成功数量、最低模型分数、成功链是否优于实际选择，以及成功链在候选生成、保留和最终选择中的来源。排序使用事前模型分数；真实成功仅为评价端标签。若全部 656 条无成功，则只能说在此离线配对所实际查询的有限池无成功，不能说任务不可解、部署计划池无解或其他规划器无解；精修中有六条前缀并不属于原 lookahead 臂的 440 条部署预算。

这是在原结果和精修物理结果已知后的事后失败分解，不重写原性能或停止规则，不把标签或参考动作交给规划器，不改变 PC gate。
