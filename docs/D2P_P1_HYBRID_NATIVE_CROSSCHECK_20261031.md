对已封存的共同 H10 与自主 cp5 物理轨迹补做保存态交叉复核：

因此当前没有证据将这批失败归因于这些指标或动作账本的接线错误。
这不证明模拟器、观测输入、模型预测或其他代码不存在错误，
也不证明理论失败；检查限于这两个已知根及其保存的轨迹。
