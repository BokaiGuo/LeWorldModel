# 双轨回执修复：版本化 GPU 冒烟协议

目标是检查新版边界对官方直接模型调用的数值一致性和成功调用留痕，不评价规划性能。冻结既有数据、检查点与动作输入，复用旧冒烟的 RGB 三个动作和 state-assisted 三动作×双相机；分别绑定 v1/v2 包装器、原冒烟脚本和本运行器的哈希。逐轨比对包装器与直接调用的输出、记录调用次数、前后模型指纹与输入回执。两轨分开运行和存档。

新版输入回执仅表示一次模型调用正常返回并且前后仍处于 eval、参数冻结状态，不能证明模型权重未被原位修改、动作合法、实际 episode 完成或任何 gate 通过。它不是 Python 安全沙箱；模型前后指纹另行核对。新版 call manifest 必须与旧 `completed` 科学证据注册表区分，不能由单次调用冒充完整实验。

失败注入、模式改变、参数解冻、权限隔离及动作梯度由单元测试验证。若已有结果文件存在则拒绝覆盖。旧包装器不可覆盖，以保留历史依赖哈希。
