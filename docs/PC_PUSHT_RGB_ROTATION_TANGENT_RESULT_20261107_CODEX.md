# PushT RGB 旋转切向投影：固定池开发结果

按[事前协议](PC_PUSHT_RGB_ROTATION_TANGENT_PROTOCOL_20261107_CODEX.md)，
复用四个已曝光任务的共同前缀和每任务 301 条候选。冻结 RGB LeWM 在
GPU 重算条件预测；原始目标平方距离、去掉目标 RGB 合成旋转切向后的
距离，以及固定种子一维随机方向投影共用这些预测。选择先封存，再
读取原先同链物理重放标签。

三种评分在 **4/4 个任务选中完全相同的候选**，各有 **1/4** 条曾
成功且末步成功。任务 1 唯一末步成功候选的预测排名从原始的
**186/301** 变为旋转投影的 **103/301**，随机投影为 **184/301**；
但首选仍是同一失败链。任务 2 唯一曾成功链的排名从 11 降为 23，
它本来就不在末步成功状态；任务 3 的池内没有曾成功链。

因此排名变化不能替代选中链成功，且本结果**未达到预定开发出口**。
停止扩大这一固定一维旋转投影；它不证明其他 RGB 目标函数无效，也
不证明当前模型或任务整体不可解。该评分没有测试描述保留、真实
在线反馈或同预算强基线。

## 核验与成本边界

- 三项单测通过，覆盖方向投影、缩放／反号不变性、无效方向弃权和
  非有限输入拒绝。四个方向均有效，未发生弃权。
- GPU 重算 1,204 条候选；按另一代数形式 `||d||²-(d·v)²` 重算所有
  投影分数，最大差小于 `1.2e-13`。原评分与上一实验最大差小于
  `3.1e-5`。这不是独立模型实现的重算。
- 原目标及两张合成目标的编码来自上一实验，需计三张图的编码；本次
  未测完整规划、加载、执行和反馈耗时。合成目标未认证为真实可达的
  物理角度，局部投影也可能丢弃与成功有关的信息。
- 真实前缀后 RGB 来自既有实际重放；真实未来帧和物理标签只用于
  评分封存后的评价。本次没有新增物理重放，是已曝光固定池的反事实
  分析，不能作为独立确认或任何 PC gate 通过。
