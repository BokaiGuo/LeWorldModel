# PushT 周期角度评估：修复版本与有限影响核对

## 错误与修复

原 JEPA-WMS `PushTWrapper.eval_state` 的角度计算为 `min(|Δ|, 2π-|Δ|)`；`|Δ| > 2π` 时可能产生负数，从而让本应失败的角度通过。位置条件仍必须同时满足。用真实原包装器与合成状态重现：位置相同、角差 `2π+1` 时，原规则判成功，周期规则判失败。

新增独立的 [周期评估器及环境工厂](../le-wm-main/experiments/pc_pusht_periodic_eval_v1.py)：使用 `abs(atan2(sin Δ, cos Δ))`，保持原来的位置阈值、角度阈值和原始 `state_dist` 定义，对不合法状态报错。工厂创建实际 PushT 环境、修复版 wrapper 和原 TimeLimit。原上游文件未改，既有封存实验仍指向其旧版本。

该工厂是**显式选择**的新版本；原 JEPA-WMS 的默认环境注册入口仍调用原工厂，既有规划入口不会自动使用修复版。正式新实验需显式接入并封存此工厂及依赖，然后核验端到端调用链，不能把这次工厂测试当作正式 RGB 闭环修复。

测试包含真实原包装器反例、正常范围与多圈旋转对照、错误输入以及真实工厂经 TimeLimit 调用修复版：`8 passed`。测试仅覆盖该评估接口，不证明全规划系统正确。
