# PushT 受控动作后果等价：四任务 pilot

按[事前协议](PC_CONTROLLED_EFFECT_EQUIVALENCE_PILOT_PROTOCOL_20261106_CODEX.md)，
使用冻结 LeWM、四个已暴露任务、两种推杆位置、模拟器原生白／浅灰
背景以及零／正／负 x 控制，每个动作执行五步，共 48 条真实动作轨迹。
同一状态、同一动作在两种背景下的已记录物理轨迹逐项一致；所有
预测和真实后继都使用对应背景的目标图像。动作 packet 逆归一化与
物理动作一致，渲染前后记录的物理快照不变，模型参数哈希未变化。

## 描述性结果

白背景 24 条轨迹中有 14 条记录到接触；其中 3 条是零控制轨迹。
这说明“左／右位置”不能自动称为稳定的左右接触模式，零动作也不能
当作不发生物理变化的保证。所有轨迹均保留，没有按接触或成功筛除。

八个白背景状态条件中，正／负动作的相对排序：

| 比较对象 | 顺序一致数 |
| --- | ---: |
| 模型预测 vs 真实后继冻结编码 | 6/8 |
| 模型预测 vs 真实物理状态距离 | 7/8 |
| 真实编码 vs 真实物理状态距离 | 5/8 |

八个条件来自四个任务，不是八个独立任务；此 pilot 没有预定确认性
阈值，比例不能作为 PC1 通过证据。物理距离是环境状态向量到目标的
欧氏距离，包含推杆位置和速度，不能当作纯物块位姿误差或严格成功。
这些比较只看排序，不把 latent 代价与物理距离当成同一单位。

同一状态和动作的模型相对后果，白／灰背景差异平均绝对值约 2.328，
最大约 7.942（latent 目标代价单位）；这只是扰动幅度的描述，不是
已经认证的误差容差或有害性结论。预测向量不是常数，但该观察本身
也不证明它可信或改善决策。

## 工程与边界

单步 packet 时钟使用安装的 `LeWM.rollout` 实际接口核对：一／两个
packet 分别产生一／两个预测后继；对应两项测试通过。独立审计检查
图片 hash、数据 normalizer 的动作逆变换、后果差分、背景物理轨迹
和物理距离，并重算上述统计；它没有重新运行模型，因此不是独立的
模型预测重放认证。

背景是原生渲染外观变化，**不是相机变化**；当前二维渲染接口没有
已认证的第二物理相机，不能由此声称多视角不变性。接触时序、真实
物块运动、画面遮挡与 reset 穿透仍需进一步检查；现有样本不证明
反事实状态实际可达或左右接触均成立。后续须使用合法接触构造、独立
roots 和真实视角设备／渲染器，预先固定物理尺度、容差及样本量。
任何真值只可进入诊断评价，不能泄漏给冻结 Planner。
