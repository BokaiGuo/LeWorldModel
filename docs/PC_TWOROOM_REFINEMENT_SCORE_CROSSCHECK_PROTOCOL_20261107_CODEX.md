# TwoRoom 精修评分路径交叉核查

对上一项已封存的 40 根、每根 Adam 和随机各 9 个动作，使用相同冻结模型、同一 RGB/goal 和动作归一化，以原生批量 RGB 评分接口重新计算目标代价；以相同 math SDPA 与 TF32 禁用设置运行。比较原带历史逐条评分与批量评分的每条绝对误差、最低分链和动作身份。

开发期预定容差为每条绝对误差 `0.005`，同时单独列出排序或动作变化及原始最小分差；近似相等不自动免除选择改变。失配则检查时钟、归一化、批量和数值后端，不能直接认定研究假设失败。保留原模型链和评分，禁止使用真实后继选择。此项为同模型接口核查，不是独立模型、环境或方法收益证明。
