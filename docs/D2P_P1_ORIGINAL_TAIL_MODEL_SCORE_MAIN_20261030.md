# P1 固定共同后缀与独立优化后缀的模型评分

目的：检查物理上出现过成功的固定原后缀，是否也被同前缀上的
冻结模型评为比二十步零初始化优化后缀更好。该分析在看到物理结果后
提出，是事后诊断；它不把已知成功动作喂回正式选择器。

24 条固定前缀分别重放各组 `original_selected_tail` 与同前缀
二十步优化后缀。两者使用相同真实 cp5 RGB 编码、目标、历史、
归一化和两包十步 rollout；动作通过原 prepare 哈希及已执行
规划行绑定。主机 CUDA 上模型参数和 buffer 前后哈希一致；优化
后缀得分与原保存得分逐行相差小于 `1e-5`。按模型目标 latent MSE
比较，原后缀在 24 条中 16 条更低；8 条 selected 记录中均更低。
各行共享两个已知根，部分动作与执行重复，不能看成独立样本。

关键根 0/on 的 selected 重复记录具有完全相同动作与结果：模型
MSE 为原后缀 `0.25733`、二十步优化后缀 `0.55748`。原后缀在
第十步实际原生停止成功；优化后缀执行满十步未成功。该原后缀的
共同后缀终点仍遵守既定封存规则保留 null，实际停止状态另见
`D2P_P1_H10_INITIAL_RESULTS_MAIN_20261030.md`。
这表明对该固定动作对，模型目标分数和实际结果均有利于原后缀，
但从零初始化的二十步局部优化没有找到这一更低分动作。它支持
搜索覆盖／初始化不足作为具体开发线索；不证明代码错误，也不能
排除其他候选或其他任务的预测和物理评价失配。

例如根 0/off 的两个 selected 中，原后缀模型分数更低，但其物体
位置误差分别约 `36.72`、`36.43`，优化后缀约 `32.26`、
`33.37`；单个 latent 分数与单个物理指标并不总同向。不得据此
忽略角度、推杆或原生联合成功。

输出 `le-wm-main/results/codex_p1_original_tail_score_20261030_main_RUN01.json`，
SHA-256 `8032e470ab46fc72fa906ead51940bf03b8f73084c4574e4db6d313ff9a30ffd`；
24 次 cp5 编码、96 次 action encoder、96 次 predict，各轴不加和。
生成代码 `le-wm-main/experiments/spectral_reachability/codex_p1_original_tail_score_20261030_main.py`，
固定来源与停止状态测试 2 项通过。未测原后缀真实末帧编码与模型
预测向量的误差，未认证全部运行依赖闭包和 checkpoint normalizer
训练来源，也没有等预算强基线或独立确认。P1 未通过。
