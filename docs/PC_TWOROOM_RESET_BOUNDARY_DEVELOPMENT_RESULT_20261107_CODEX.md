# TwoRoom reset／step 边界不一致及受控修正

核查上轮四个 RGB 开发 seed 时，发现本地 TwoRoom 环境的 reset 位置采样范围与 step 的碰撞边界不完全一致。seed **2717103** 起点为 `(92.4051, 207.1975)`，而该环境在半径为 7 时把位置限制到每轴 `[21, 203]`。对这一原始起点执行零动作，位置被夹到 `(92.4051, 203)`，发生 **4.1975 像素**位移；其余三根在边界内且零动作不移动。

这是真实可复现的本地实现／合同差异，不是“零动作必然静止”的有效假设，也不能将它推广为上游所有版本的问题。新加 `border_contract` 和 `require_legal_border` 可对候选初态失败即拒绝；它们**没有接入或改变历史官方协议运行器**，只检查边框，不认证墙体、目标、隐藏状态或完整 reset 合同。相关测试 **4 项通过**。

按单独预定的受控修正协议，将该根起点的 y 裁到 203，保留相同 seed、目标图像、动作和模型；规划器只读取修正后的实际 RGB。零动作不再移动。原始与修正初态的 25 条相同动作链中，4 条末端真实目标距离发生变化，最大绝对差 **2.7905**。两种初态各 25 条链均无成功：

| 指标 | 原始初态 | 修正初态 |
| --- | ---: | ---: |
| 预测后果 vs 真实编码符号一致 | 12/20 | 12/20 |
| 预测后果 vs 真实距离符号一致 | 7/20 | 7/20 |
| 任一侧平局 | 5 | 5 |
| 预测 vs 真实距离两两排序一致 | 17/50 | 16/50 |

修复边框后的这一根没有显示后果可靠性改善；不据此否认其他实现问题或所有描述方法。修正改变了初态，因此不能把它当作官方复现成绩，原面板没有删除或替换该根。最短距离和预算覆盖的分析仅针对这 25 条候选：原四根的最佳十步终距分别约为 101.33、67.24、84.07、90.40；不能以此证明任意合法规划器不可解。

独立审计重放修正初态的 **25 条链、250 步**，距离和标志一致，重算 25 条 GPU 模型预测并验证图像及动作收据；真实后继只用于评价。原本固定面板的 100 条链也已逐步重放。该单根受控诊断非独立确认、非闭环收益，PC0–PC5 不改判。

原始根边界记录：`le-wm-main/results/pc_tworoom_reset_boundary_contract_20261107_codex.json`；修正实验和审计：`le-wm-main/results/pc_tworoom_corrected_border_result_20261107_codex.json` 及 `pc_tworoom_corrected_border_audit_20261107_codex.json`。
