# Reacher 目标图像与静态关节几何：单根诊断

在原实验的同一后端和目标下，直接设置目标关节配置重渲染，得到的 RGB 与原目标图像**逐像素一致**，目标关节距离为零。五条目标至已封存末状态的最短角度插值在比例 1.0 处，也分别与原反事实的五张末帧逐像素一致，编码最大差异均为零。由此排除了这次单根分析中“保存的目标图像不是该目标关节姿态的渲染”这一具体接口疑点；不能据此排除所有视觉、时序或任务定义问题。

每条方向取目标及 `0.25/0.5/1.0` 三个静态位置，共 16 个去重构造点。角度距离与插值比例符合预期。[数值审计](../le-wm-main/results/pc_v4_reacher_goal_geometry_20261104_codex_audit.json)检查图像哈希、关节、MSE 和插值：

- latent 目标 MSE 在 selected、carry、nominal1 方向出现非单调；例如 selected 方向在目标、0.25、0.5、1.0 处分别为 `0 / 0.491795 / 0.904204 / 0.769165`。
- 同五条方向的像素目标 MSE 都非递减；但跨方向时，像素距离同样不必保持关节距离排序。
- 在这 16 个相关点的 120 个未并列配对中，latent MSE 和关节距离的排序相反 25 次；像素 MSE 也为 25 次。这是描述性计数，不是 120 个独立实验或显著性检验。

结论是该特定目标图像及状态绑定在所测点上复现一致，而冻结 encoder 的全 latent MSE 在这些具体方向上不能充当关节距离的单调尺度。不能将此推断为一般表征失效、v4 理论失败或已确认的规划代码 bug。中间姿态通过特权直接设置，**不是规划器生成的候选或可执行轨迹**；不得当作控制成绩或 PC1/PC3/PC4 通过。

实验按[协议](PC_V4_REACHER_GOAL_GEOMETRY_PROTOCOL_20261104_CODEX.md)生成 16 张静态图像与 latent；原始数据与封存位于 `le-wm-main/results/pc_v4_reacher_goal_geometry_20261104_codex_{manifest,result,arrays,audit}`。本次审计重算保存数组上的指标，未再次运行 encoder；五个末点编码此前已有独立参考路径重算。
