# P1 已知根固定同后缀尺度对照

探索实验，先固定合同再执行；不改变 P1 科学门，结果不能作为独立根确认。

使用既有 16 个物理前缀锚点，每个相邻 incumbent / selected 配对得到同一组 21 个五步 raw 后缀：零动作；从该配对各自保存的第 6–10 步原动作分别按 `±0.25、±0.5、±0.75、±1` 缩放得到 16 个动作；恒定 `(+0.5,0),(-0.5,0),(0,+0.5),(0,-0.5)` 四个动作。动作按 float32 算术和原字节封存、范围不超过 [-1,1]。每个配对中的两种前缀使用完全相同的 21 个后缀；全部 16 个逻辑锚点均执行，不根据先前物理 outcome 筛选。原动作本来是经过模型选择的，因此此动作集属于已观察实验之后的探索性选择，不是独立确认或公平基线。

沿用严格物理执行器：每个后缀新建环境，重建 10 步 warmup 和固定 5 步前缀，以 51 张帧及可见状态逐位核对后才执行后缀，保留求解器内部缓存未能独立序列化的限制。各分片失败立即停止，无重试；固定分母 336，保留失败和原生提前停止，不补结果。任务指标分开报告物体位置和环形角度，不合成未标定度量，不以单个最佳后缀宣称机制成立。分析须核对真实输入输出和动作位级记录；统计上只有两个历史根，重复臂不视为独立样本。
