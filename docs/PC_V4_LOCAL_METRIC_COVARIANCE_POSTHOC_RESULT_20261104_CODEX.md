# 局部可达价值的度量变换边界

## 结论

局部无约束岭价值在**坐标和度量一致变换**时保持不变；仅变换坐标而重新使用单位度量，会改变所定义的目标，可能改变候选排序。v4 当前调用使用单位度量，并不能因此宣称对任意坐标尺度不变。

对已封存的 24 个暴露 E0 根、每根 9 个后继响应，共 216 个矩阵执行[后验协议](PC_V4_LOCAL_METRIC_COVARIANCE_POSTHOC_PROTOCOL_20261104_CODEX.md)：一致变换后的局部价值最大绝对差 `1.67e-16`，原岭解与直接线性方程解最大范数差 `1.95e-15`，变换后动作解最大差 `2.37e-15`，24 根的最低价值候选均未改变。若变换后误用单位度量，则 4/24 根的最低价值候选改变；逐根差异在两种评分下均大于 `1e-10`，不是浮点近并列。

## 推导与适用条件

设残差 `r`、响应 `G`、输出度量 `Q`、动作度量 `R`，其中 `Q` 半正定、`R` 正定、`λ>0`：

```text
V(G,r;Q,R) = min_u [(r-Gu)ᵀQ(r-Gu) + λuᵀRu] / d
u* = (GᵀQG + λR)⁻¹GᵀQr
```

`d` 是保持不变的输出维数。对可逆 `A,B`，令 `r'=Ar`、`G'=AGB⁻¹`、`u'=Bu`、`Q'=A⁻ᵀQA⁻¹`、`R'=B⁻ᵀRB⁻¹`，则两项二次型逐项相等，所以 `V'=V`，唯一最优解满足 `u'* = Bu*`。这同时适用于秩亏响应：正定 `R` 和正的 `λ` 保证岭方程唯一可解。SVD 与直接岭求解相同是此目标的代数等价，**不构成谱搜索的独立增量证据**。

代码中的 `sqrt_q` 实际作为左因子 `q` 使用，故 `Q=qᵀq`；`inverse_sqrt_r` 是动作白化因子 `L`，应满足 `LLᵀ=R⁻¹`。本诊断的原始度量为单位阵，使用 `q'=A⁻¹`、`L'=B` 实现上述变换，不要求这些因子本身为对称平方根。独立审计直接构造 `Q'`、`R'` 并求解一般岭方程，最大差 `2.37e-15`。

这个结论不自动扩展到完整 v4：真实动作盒必须同步变换；有限差分扰动、模态截断、退化奇异空间中的基选择、`L∞` 幅度归一化、模型非线性、最终评分和反馈规则也都必须逐项变换或另证。特别是任意非正交输出变换后的单位度量，已换了任务几何，而非单纯重命名坐标。本分析不证明 PC1–PC5、物理机制或实际规划优势。
