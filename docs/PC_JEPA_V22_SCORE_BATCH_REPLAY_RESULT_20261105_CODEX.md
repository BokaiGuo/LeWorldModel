# v22 选中链评分：批形状重算结果

按[协议](PC_JEPA_V22_SCORE_BATCH_REPLAY_PROTOCOL_20261105_CODEX.md)，在同一设备、冻结模型及六条原选中链上，交叉重算编码批形状与预测子批形状，没有重新规划或执行物理。

| 编码 / 预测 | 六例相对原记录的最大绝对评分差 | 与原记录完全相同 |
| --- | ---: | ---: |
| 分开编码 / 原预测子批 | 0 | 6/6 |
| 分开编码 / 单链预测 | `1.1325e-6` | 0/6 |
| 五帧合批 / 原预测子批 | `2.9802e-6` | 0/6 |
| 五帧合批 / 单链预测 | `3.8147e-6` | 0/6 |

最后一组逐项复现了先前后验诊断中观察到的完整链分数差。分开编码与五帧合批编码的最大 feature 绝对差为 `2.6083e-4`；六个原预测子批大小分别为 4、4、2、3、4、2。结果支持本次差异由计算批形状变化产生：编码和预测批形状分别改变时都能观察到分数变化，但它们的效应不必相加。该结果不是其他硬件、动作或评分间隔上的误差上界，也不能认证候选排序或物理预测正确。

运行产生 48 次 predictor module 调用，模型前后收据一致；计时和调用数不是完整系统成本。原输入、命令和后验审计绑定在[运行回执](../le-wm-main/results/pc_jepa_v22_score_batch_replay_20261105_codex/wrapper_receipt.json)中，六例四组合的原始数值见[结果](../le-wm-main/results/pc_jepa_v22_score_batch_replay_20261105_codex/result.json)。此为同实现数值重算，不是独立模型实现、真实执行或控制收益；PC0–PC5 状态不变。
