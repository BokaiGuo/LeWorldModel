# P1 两个预测时域的一致性选择：已知根探索合同

已有十步 latent 评分和五步 latent 评分的选择在部分前缀上表现
方向不同。为避免直接混合尺度，固定一个不训练的候选规则：
对每个既有前缀的四个封存候选，分别以模型预测五步目标 MSE、
十步目标 MSE 升序排序，得 0–3 名次；相同数值先按原候选
索引。两名次相加最小者获选，和相同先按十步名次，再按候选
索引。仅利用模型预测，不读取真实中点、真实终点、物理指标
或成功作为选择输入。对相同四候选同时报告原十步最小与五步
最小选择作为描述对照，事先固定所有 24 行，不跳过失败或早停。

这是已经看过单时域物理结果之后提出的事后开发探索。五步评分
来自已有 CUDA 推理，候选动作来自已有 CUDA 重放，物理结果来自
既有执行，既不是实时重规划也不是新物理试验。两时域计算成本
分别报告为额外开销而非等预算收益；在每个方法统一反馈、预算、
独立任务和 P1 机制确认之前不能声称改进或通过。
