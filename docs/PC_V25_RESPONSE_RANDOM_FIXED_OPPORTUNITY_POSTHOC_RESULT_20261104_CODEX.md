逐根比较的相等容差为 `1e-12`。全库最优是事后查看每个候选的诊断上界，不是可部署选择；全库、greedy 和 lookahead 不能当成三个独立任务。当前机会和初始化下没有观察到成功尾部，故不能据此判定库中所有前缀都不可行。随机方向经动作裁剪后可能改变实际范数，且不保留谱方向的跨候选相关结构。

每库每根新增候选评分和 lookahead 使用 504 prediction-token，统一尾部优化使用 2,646；响应库原始首层另有 42 token 的差分探针和 2 次 SVD。原规划的全局库、后继探针、其他层和精修账本另见 `audit.json` 的 `source_stages`。该固定机会诊断使用远高于原规划上限的额外费用，不能当作等总成本方法比较；之前的完整方法资源面板仍是单独证据。

新增动作、预测、选择封存、尾部优化及原始规划阶段成本均可在 `le-wm-main/results/pc_v25_response_random_fixed_opportunity_posthoc_20261104_codex/` 查验。逐批提案重放和同环境另一几何实现评分核对通过；不是独立复现。任务已暴露，来源独立性未知；没有得到响应程序机制或 PC2/PC3 通过证据，也不能用该局部实验否定理论。
