# v8/v7 E0 实际响应探针的墙体分支检查

事后使用两个版本 18 根封存并审计的首次决策，只读取各自实际产生的
两条首层和每条首层候选后继的 21 点中心差分批次。按执行次序验证
nominal、前缀、正负扰动、float32 实际动作和记录矩阵；对实际动作以
独立几何代码逐步回放墙体阻挡事件。对于每个动作坐标，分别判断正负
探针的完整阻挡事件序列是否与同批 nominal 一致，并记录矩阵范数、
目标加权模式顺序及差分条件下的分支不稳定坐标数。

同一个中心差分跨越不同墙体分支时，仅标记“该尺度下非同分支局部响应”，
不自动判定计算错误、导数不存在于所有尺度或候选必然无效。并报告
首层与后继层、根内样本数和分支稳定情况；不将高度相关坐标当作
独立任务。不得修改方法或事后选择根。此为同后端解析模型的事后
实现风险诊断，不是物理响应认证、PC1 通过或 PC2 见证。
