# PushT 相对动作与可见局部候选审计

## 动作语义和分布

环境声明 `[0,512]²` action space，但默认 `relative=True` 时，`step(u)` 将目标设为当前位置加 `100u`；代码没有按声明空间拒绝输入。负相对动作与该声明冲突，但不因此证明相对动作本身无效。现有 v22 反馈入口在记录前将输入乘 100 再除回去，选中动作直接交给环境；后续[派发审计](PC_JEPA_V22_ACTION_DISPATCH_AUDIT_20261105_CODEX.md)已逐条核对两臂的记录命令和历史归一化，但仍不是运行时独立参数拦截。

[可复现分布审计](../le-wm-main/experiments/audit_pc_jepa_action_scale_distribution_20261105_codex.py)读取本地数据文件及长度元数据，以每条序列前 `seq_lengths` 项作为有效前缀并除以 100；哈希及全部结果见[记录](../le-wm-main/results/pc_jepa_action_scale_distribution_audit_20261105_codex.json)。这不是 checkpoint 的训练来源证明，也不能排除有效前缀中的末项并非真实动作。

| 数据 | 动作坐标标准差 x/y | 绝对坐标的 95% 分位 | 负坐标比例 |
|---|---:|---:|---:|
| 本地 train，有效前缀 | 0.2085 / 0.2067 | 0.4385 | 50.65% |
| 本地 val，有效前缀 | 0.2063 / 0.2073 | 0.4316 | 51.87% |
| 旧随机面板候选 | 0.5597 / 0.5557 | 0.9293 | 48.96% |
| 可见局部候选 | 0.0894 / 0.1011 | 0.1735 | 37.50% |

训练数据样本中动作间有时序关联；两组候选采用连续五步常值 packet。因此这些帧级分布仅说明幅度差异，不证明轨迹分布匹配或因果原因。按声明 `[0,512]²`，本地 train 的约 75.65% 动作至少一个坐标为负；这进一步显示声明空间和相对动作语义不匹配，不能仅据此把所有输入视为物理无效。未经事前协议，不静默裁剪旧轨迹。

## 可见局部候选库

[预定协议](PC_JEPA_VISIBLE_LOCAL_BANK_DEV_PROTOCOL_20261105_CODEX.md)生成四个参考目标，每根构造 32 条参考附近候选及 32 条较宽候选；参考自身不作为候选。**近邻候选由生成目标的参考动作构造，因此是特权条件化评估库，不是合法规划器可用的候选生成方式，也不是未查询动作预测实验。**

| root | 目标中心满足预定区间 | 物体位移 | 不满足中心区间的候选 / 64 | 全库成功 | 预测首选成功 | 真实后继编码首选成功 |
|---:|:---:|---:|---:|---:|:---:|:---:|
| 0 | 是 | 0 | 0 | 34 | 是 | 是 |
| 1 | 否 | 0.00885 | 32 | 34 | 是 | 是 |
| 2 | 是 | 0 | 0 | 34 | 是 | 是 |
| 3 | 是 | 0 | 0 | 34 | 是 | 是 |

中心区间为每个 agent 和物体中心 `[40,472]`，不等同于完整几何体可见。root 1 保留在分母，不做事后替换。四根的每条近邻候选均达到本实验的联合位置与角度成功判据；其中四根物体几乎静止，局部候选的成功主要反映条件化设计，不能当作推物接触能力、自动搜索或独立泛化证据。全库首选成功也不建立独立动作上的预测能力。远端 32 条每根仅有 2 条成功；root 0 的真实后继编码评分首选失败，不能将编码分数视作物理成功的普遍保证。

[独立审计算法](../le-wm-main/experiments/audit_pc_jepa_visible_local_bank_dev_20261105_codex.py)重建候选、逐条重放 260 条动作链及共同历史，并核对末态、RGB、分组成功和评分排序；[审计记录](../le-wm-main/results/pc_jepa_visible_local_bank_dev_20261105_codex/audit.json)及[原汇总](../le-wm-main/results/pc_jepa_visible_local_bank_dev_20261105_codex/report.json)保留。重放使用同一物理后端，神经输出仅核对回执与重新计算分数，未独立重跑模型。记录的 768 prediction tokens 不包含编码、物理执行及系统成本。来源独立性仍未知，PC0–PC5 不因本实验变化。

下一步应先统一相对动作接口、训练分布与实际派发的可重放合同，事前定义视野和物体实际位移要求，记录不合格率，再构造不依赖特权参考动作的评估库；不应以本面板的高成功率替代真实控制证据。
