# dev305 同幅度反馈与保守边界对照

在同一已知开发根的三个反馈点，固定最多五步、每步真实 RGB 观察：
方向逐步更新与初始方向固定均使用原始动作幅度 0.2，另有零动作。
第四臂在逐步反馈策略上额外要求当前图像通过 16 像素边界筛查；其余
各臂沿用原 8 像素检查。16 像素是新开发筛查，不是修改原合同或预测
下一步的可见性保证。所有策略是 RGB 几何探针，没有世界模型评分。

| 反馈点 | 更新方向 | 执行步数 / 终帧可见 | 终态物体位置 / 角度误差 | 原生奖励 |
| --- | --- | --- | --- | ---: |
| candidate_02 | 更新 | 5 / 否 | 244.72 / 0.156 | -491.44 |
| candidate_02 | 固定 | 4 / 否 | 246.69 / 0.197 | -496.19 |
| candidate_00 | 更新 | 4 / 否 | 248.50 / 0.178 | -506.94 |
| candidate_00 | 固定 | 5 / 否 | 249.71 / 0.143 | -520.90 |
| zero | 更新 | 5 / 是 | 246.31 / 0.304 | -484.54 |
| zero | 固定 | 5 / 是 | 244.95 / 0.327 | -476.71 |

各臂均未原生成功；前两组更新与固定的停止时刻不同，不能把表中
终态当作同一时刻的公平性能比较。第三组五步可比较，但固定方向的
位置误差及奖励更好，反馈方向的角度误差更小；仅一根不能推断稳定
优势。该结论也不能代替共同预算的世界模型基线或重配置机制验证。

额外 16 像素筛查在三个起点都在任何动作前停止，故没有奖励或新物理
效果。它在这批状态上过于保守，不能作为可用的风险解决方案；也不能
用零步终态与执行五步的轨迹比较。8 像素 guard 仍是反应式，执行满
五步不意味着最后一帧通过 guard。

来源、动作和所有保存 RGB 帧已重新绑定，逐帧复算动作和停止条件；
四项测试通过。下一步要用模型或 RGB 动作响应设计能提前预测裁边风险
的候选筛选，计入计算预算，并在新的开发状态执行；不应继续增加固定
边界常数直至已知根看起来成功。
