# PushT 共同候选池：推杆位置评分混杂检查

对四个已暴露任务的 301 条共同前缀末态，按事前固定的开发阈值配对：物块中心相差不超过 5 像素、角度差不超过 0.1 弧度，且推杆到目标图推杆位置的距离相差至少 20 像素。比较每对中推杆更接近目标图位置者是否获得更低的 latent 目标代价。

| 任务 | 候选对数 | 真实末帧编码：近推杆较优 / 远推杆较优 / 平局 | 单帧预测：近 / 远 | 三帧预测：近 / 远 |
|---|---:|---:|---:|---:|
| 0 | 19,919 | 19,753 / 157 / 9 | 19,839 / 80 | 19,865 / 54 |
| 1 | 634 | 481 / 153 / 0 | 353 / 281 | 384 / 250 |
| 2 | 6,542 | 6,028 / 514 / 0 | 6,257 / 285 | 6,241 / 301 |
| 3 | 5,982 | 4,563 / 1,419 / 0 | 4,260 / 1,722 | 4,291 / 1,691 |

这说明这些配对中评分经常偏好推杆更接近目标图位置的候选，但**不能把相关性视为因果效应**：5 像素和 0.1 弧度并非相同物块姿态，遮挡及其他图像变化也可能影响评分；候选对共享链，不能按候选对数计算独立样本显著性。

任务 1 唯一末帧成功链的推杆到目标推杆位置距离约 14.79 像素，只有一个符合上述阈值的成功／失败配对。因此本结果不能解释其真实编码评分排名第 195 的具体原因，也不构成新的可部署评分或行动后果贡献。物理状态仅用于评价，不传入规划器。阈值是此已暴露开发池上的诊断设置，不是确认标准；PC0–PC5 不变。
