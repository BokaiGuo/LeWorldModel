新臂在 8 根的终距严格更差、其余 16 根相同，没有严格更好的根；**未达到预定开发出口，停止该固定组合规则**。4,608 个五步前缀中有 1,926 个至少一步被阻挡，说明该面板确实包含前缀阻挡，但不能由此推断阻挡一定是选中链失败的唯一原因。

事后限定到两臂共享的前 192 个偏移作补充：原规则及条件组合均为 12/24 成功；新规则 0 根终距更好、7 根更差。这个补充对照没有给原规则补足相同动力学预算，因此只用于理解固定前缀差异，不替代上述预定等步数比较。

## 实现和局限

新臂实际计算并记录每个前缀后继，在该后继构造尾部，随后从起点重新评分完整链。独立审计用旧的 16 步补零后端重放全部 4,608 个前缀和完整组合，检查前缀、后继、阻挡、每条成本、选中链与预算；两条路径使用同一底层物理步函数，并非独立物理引擎认证。动作边界、后继依赖和新旧后端等价测试 3 项通过；测试先于实现并确认缺失模块时报错。

规则按**自由空间计划**判断五步内是否应到达中间点；即便该计划中的前缀实际受阻，它也可能切换到目标而不再尝试中间点。这是已声明的构造限制，不是对所有后继条件组合的否定，不能根据本次结果事后改规则并保留原出口。

原自由空间基线评价 256 条，新臂评价 192 条并为每条增加前缀查询；此处只匹配动力学步数。代码当前计时边界不同：新臂复用了基线生成的前缀，因此不报告两臂计时差，也不能声称完整系统成本优势。

所有任务是已暴露 exact-state/exact-dynamics 开发根；它既不是 RGB-only 证据，也未测试行动后果描述、闭环、独立任务或 PC gate。完整候选与独立审计分别见 `le-wm-main/results/pc_exact_prefix_successor_composition_20261107_codex.json` 和 `le-wm-main/results/pc_exact_prefix_successor_composition_audit_20261107_codex.json`。
