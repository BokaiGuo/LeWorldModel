# 全候选选择的已知根物理执行合同

仅在 16 行主机 CUDA 重放和保存态消费全部通过、native source
身份闭合后执行；不训练模型，不进行新的神经调用。固定四个
根/条件槽、两臂，每臂 incumbent 与全候选选择，共 16 行，
不按分数或物理结果筛行。每行记录前缀和后缀全部动作、根、
目标、reset、warmup、环境状态、RGB、资源与原生终止。实际
提前结束或错误保留，不插补。已相同的动作链或同根共享条件
不能计为独立实例。

此实验为事后开发的已知根物理探索；与已有数据重复的动作只
是重放。不同方法完整计算成本、独立根、同前缀能力干预和强
基线均未认证。物理结果不能自动打开 P1 或用于确认性统计。
