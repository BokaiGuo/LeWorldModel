# PointMaze 后继预测与目标评分的事后分解

对已封存的 1892–1899 开发面板进行事后诊断：重新编码每条实际后继图像，并使用同一目标图像和同一 MSE 目标代价，与事前封存的原模型预测以及实际目标位置距离比较。后继图像和物理距离仅用于评价，不能用于部署动作选择。本面板是已暴露或独立性未知的 state-assisted 数据，不是新测试集，也不是 RGB-only 证据。

八任务两个相机的平均物理 regret：模型预测选择为 **0.024522**；假设能取得候选真实后继、再用相同视觉目标分数选择为 **0.007708**；同一三动作池的物理最优是 **0**。真实后继编码选择与物理最优的动作编号一致为 9/16 视角，模型预测选择与真实后继编码选择一致为 10/16。视角、动作对来自同一任务，不能作为独立样本。

三候选两两差分共 48 个比较，模型与真实编码的动作效果向量平均余弦为 **0.3740**，相对 L2 误差平均为 **1.2642**。这些是探索性汇总，不是事前通过标准；相对误差可能受真实差分接近零影响。按任务的原始结果和全部差分都保存在 JSON 中。

结果支持两个同时存在的限制：模型预测后继与真实编码的动作排序不总一致；即使用真实后继，当前编码目标分数也并非总选到物理最优。例如 1897 的偏移相机下真实后继编码仍选候选 0，物理最优是候选 2，regret 为 0.075792。另一方面 1898 的偏移相机，真实编码选择反而比原模型选择略差，不能把 oracle 平均结果理解为逐例改进。

对于所有候选施加同一个历史残差时，候选之间的 latent 向量差分不变；但候选与目标的平方距离差会随公共平移变化，因此动作排序可能改变。降低绝对后继 MSE 并不能保证行动效果或目标排序改善。这解释了为何前一轮的修正即便降低误差仍可能损害选择，但不证明模型本身或预处理没有 bug。

脚本 `le-wm-main/experiments/pc_pointmaze_effect_decomposition_20261106_codex.py` 在读取后继前检查已封存输入、预测、物理文件和模型指纹，结果在 `le-wm-main/results/pc_pointmaze_effect_decomposition_20261106_codex.json`。三个合成单元测试通过；这些测试验证计算而非规划性能。现阶段不改判 PC0–PC5。
