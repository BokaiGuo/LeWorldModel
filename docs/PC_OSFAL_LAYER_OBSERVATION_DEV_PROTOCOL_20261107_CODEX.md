# OSFAL 启发的逐层真实观测诊断：开发协议

范围：官方 PointMaze JEPA 本地兼容实现的视觉编码器诊断；整模型属于 state-assisted，不是 RGB-only 规划评估。冻结权重，不训练、不校准，不改变规划器。

固定既有真实相机轨迹的四个已曝光根 1880–1883：每根偶数索引为起点，后续奇数索引的初始帧为目标。比较起点执行五步的三个固定动作（零、正、负 x）在两个固定相机下的末帧，与各相机目标帧；不得按成功或结果筛选。物理状态与相机轨迹先做一致性校验。数据仅四根，不作独立确认。

对 12 个 transformer block 的 patch token（排除 CLS，未施加末层归一化）和正式编码器输出分别记录：同一动作的跨视角均方差、同视角三个动作两两均方差、各动作距目标的均方代价、真实位置距目标及选中动作的物理遗憾。统计按根汇总；不把相机、动作或 patch 当独立任务。差异同时报告原值和跨视角/动作差异之比；分母为零时记录 null。零动作只是参考，不是假定的静止控制。

末层 block 经模型自身 layernorm 后，与正式视觉编码输出逐元素核验；各中间层只用于真实观测分析，不能与预测 latent 直接比较。评估端真实状态仅用于离线测量，不参与在线规划选择。选择策略、目标、数据与指标不根据结果修改。

输出保留逐样本代价与物理距离、每根汇总、模型及源文件哈希和冻结指纹。此诊断不产生校准映射，不证明未查询动作预测、搜索增量、RGB-only 控制或任何 gate 通过；后续是否拟合跨视角映射须另立协议并按根隔离拟合与评估。
