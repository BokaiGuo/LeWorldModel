# v25 多深度响应诊断

对已封存的八根 E0 事前同链开发面板做事后分析，不新增预测或物理调用。逐组核对原始 nominal、中心差分动作、响应矩阵和候选记录；评分排序仅比较同一 nominal、同一前缀下的候选。相对误差以实际位置变化范数为分母，小于等于 `1e-8` 的情况不纳入相对误差统计。

| 深度 | 名义点组数 | 扰动候选数 | 位置绝对误差中位数 | 位置相对误差中位数 | 排序一致 / 不一致 / 平局 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 0 | 16 | 128 | 0.12614 | 0.42854 | 385 / 63 / 0 |
| 1 | 64 | 508 | 0.17918 | 0.54311 | 1443 / 321 / 6 |
| 2 | 64 | 432 | 0.17094 | 0.52453 | 1291 / 214 / 7 |

成对比较共享候选、nominal 和根，不能当作独立样本做显著性推断。此分析只覆盖实际生成的单模态候选和精确动力学的已暴露任务，不提供 AD 与 FD 对照、不测视觉模型与真实物理的差异，也不能证明误差造成了规划失败或通过 PC1。空响应、没有生成扰动候选的组保留在组数中，但不计入候选误差分母。
