One known development root; non-neural PushT replay only. The ordered roster is
the same structured actual prefix followed by (1) sealed CEM selected15,
(2) sealed structured own planned15, and (3) zero15. No outcome-based choice.
This is a conditional suffix comparison, not a matched full-controller cost,
official baseline, independent confirmation, or P1 admission.

Before physics, verify the externally specified CEM report hash; exact
prepare/binding, unchanged frozen model hash, CEM ledger and 195-call caps,
trace chain, reconstructed seeded CEM bank/updates and selected winner.
Recheck the six-prefix summary source closure, the five-plan collector, and
the structured own and common/zero physical reports. Bind prefix actions, original cp5 RGB/state digests, original
action-history normalization and goal; source model scores are not physical
outcomes. The ledger reports `closed_unverified`, not independent model-hook
coverage.

All three schedules and all sources are sealed in a new protocol before
environment creation. Each branch resets the centered root, replays ten warmup
actions, checks the three original warmup images, restores the same goal, and
executes the exact prefix; cp5 rendered pixels and physical state must match
the source before any suffix action. Record actual actions, reward, stop,
state/RGB/metrics at 0, 5, 10, 15, 20 and on earlier stop. Stopped branches
are not padded. Sources are checked before every branch and at completion.
Native success is reported separately from termination; no terminal metric
is fabricated for missing step 20.

CPU tests use generated scalar objective scores, not neural inference. The
physical run uses `CUDA_VISIBLE_DEVICES=''`, no model load or prediction.
