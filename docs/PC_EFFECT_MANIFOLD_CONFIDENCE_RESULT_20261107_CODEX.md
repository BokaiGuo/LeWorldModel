# RGB 模板流形残差：后果方向筛选结果

对已曝光的 10 个 TwoRoom 任务，使用合法当前 RGB 与目标 RGB
构造合成模板；仅用冻结模型预测和模板特征封存筛选索引后，再
读取先前的物理重放结果。10 根均通过图像构造，每根有 64 个
参考—探针对；除全体对照外，每个规则保留 32 对。

| 筛选 | 按任务等权的模型—物理方向一致率 | 评价对数 | 真实物理效果绝对幅度均值 |
| --- | ---: | ---: | ---: |
| 预测 latent 最靠近合成图像流形 | 62.50% | 320 | 14.46 |
| 模型分数绝对差最大 | 72.50% | 320 | 18.56 |
| 固定种子随机 | 63.75% | 320 | 16.07 |
| 全部动作对 | 62.81% | 640 | 15.84 |

流形筛选只在 **2/10** 根严格优于模型分数差对照，没有满足
预定至少 6 根及对三个对照分别提高至少 5 个百分点的开发出口；
**停止扩大这一固定流形残差筛选构造**。该结果不否定其他不确定性
估计，也不重启此前已停止的最近模板选链配置。

模型分差筛选在此面板上方向一致率较高，但它选出的物理效果幅度也
更大；这是不同动作对上的描述性比较，不能归因于可靠性校准，也不
证明闭环收益、可部署的错误概率界或 PC1 通过。接下来若使用该信号，
必须在此前未用于调参的任务上核验覆盖、物理效果难度和实际决策，
而不是将 72.50% 当作已认证指标。

合计编码 **2,414 张**模板，GPU 同步编码计时约 **1.88 秒**；
包含模板构造在内的逐根计时合计约 **3.69 秒**，不含模型加载、
既有 720 条链的预测或环境执行，不能作为整任务成本。合成模板不保证
物理可达；物理状态和后继标签没有参与预测或筛选。根和候选早已
曝光，同根动作对不独立；PC0–PC5 不改判。相关测试 **4 项通过**。
`experiment-code` 用于固定随机对照、可复现筛选及负结果记录。
