# P1 前缀—共同后缀—独立优化配对视图

从封存的 H10 配对表、既有来源连接及两档独立后缀物理消费结果
生成 24 条前缀记录；每条包含 42 个共同后缀及各一次的两步、
二十步独立优化后缀。前缀变化、物体位置与角度、推杆位置、
原生联合距离与成功状态分栏；两档优化各保留停止状态和成本账。
结果为 `le-wm-main/results/codex_p1_complete_paired_view_20261030_main_RUN01.json`，
SHA-256 `096210929f78f2d8477a3705713dc4c0498e4bf826d89ae580b8652765d0b850`。

共同后缀结果保留绝对终态、相对于本前缀零后缀的变化、相同后缀
相对于 zero/greedy 前缀的变化及对应的响应差。两条第十步原生
停止记录遵守原封存合同：终点保留 null，不按完成分支补算。
独立优化结果则分别报告终态相对于本前缀零后缀，以及相对于
zero 前缀独立优化终态的差值；每条前缀的独立后缀只记一次，
不因与 42 个共同后缀并列而虚增样本。负的误差差值代表更低。

说明性检查中，8 条 selected 记录的二十步独立终态相对同组 zero
前缀，物体位置误差有 4 条更低、4 条更高；这些记录包含重复动作、
仅涉及两个已知根，不是 8 个独立任务。同组条件下角度与推杆差异
也可能方向不同，不能用单项认定原生成功或 P1 机制成立。
部分 selected 前缀已改变物体目标误差，另一些物体不动但推杆
位置改变，故“物体没有即时进展”不等于整个原生任务没有进展。

两档优化步数不同，不能跨档称等预算；各前缀使用相同设置也不
证明包含前缀生成在内的总资源公平。零动作后缀与优化后缀成本
不同，差值仅是描述性控制效果。该视图使用的独立后缀是既有
开放执行，不是新完成的中途真实 RGB 重规划；训练来源、规划
完整资源计量和独立确认仍未完成。共同后缀效应不等同于可规划
能力优势。
