# PointMaze 原始渲染器重放结果

按[协议](PC_POINTMAZE_ORIGINAL_RENDERER_REPLAY_PROTOCOL_20261107_CODEX.md)，使用历史脚本、相同输入状态和哈希一致的 XML 重新渲染。历史原脚本当前重放的 ±0.1 末帧与新脚本 v2 对应帧 **逐像素一致**；两次新脚本结果也逐像素一致。

但原脚本重放与历史图像仍有差异：全部历史帧平均绝对差 **0.02846/255**、最大 **56/255**；先前编码诊断使用的末帧平均差 **0.02871/255**、最大 **48/255**。轨迹与时间最大误差均为 0，相机默认参数一致，历史与当前记录的 MuJoCo binding/runtime 版本均为 `2.1.2.14`。

因此，差异不能仅归因于新增渲染脚本；目前也不能从已记录的版本信息确定图形驱动、硬件、其他运行依赖或历史运行条件中的具体原因。相同版本号不证明所有渲染依赖完全相同。既有 ±0.03 模型预测与新渲染后继仍不能当作已认证的同输入分布结果；原失败的严格编码检查不予放宽，历史文件未改动。

分析脚本第一次运行时，NumPy 高级索引将动作轴提前，形状保护阻止了错误比较；现改用指定轴的 `np.take`，复用已生成的重放文件并增加回归测试。相关测试 **5 项通过**。`code-debugging` 技能用于复现原始实现、定位并修复本次分析索引错误；该错误不属于历史规划器或原物理重放错误。

该核验使用 state-assisted 开发资产，不证明 RGB-only 效果、模型等价或任何 gate。记录：`le-wm-main/results/pc_pointmaze_original_renderer_replay_20261107_codex.json`；原始重放：`pc_pointmaze_original_renderer_replay_20261107_codex.npz`。
