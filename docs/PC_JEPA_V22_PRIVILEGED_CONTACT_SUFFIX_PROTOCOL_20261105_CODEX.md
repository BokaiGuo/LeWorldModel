# v22 特权接触覆盖：共同后缀后验开发诊断

在已暴露 v22 单根，使用四个五步前缀：零动作、已执行 response 首 packet、已执行 CEM 首 packet、评估专用物理见证首 packet。共同十步后缀按固定顺序为：零尾；见证后十步分别乘 0.25、0.5、0.75、1；`default_rng(2026110504)` 的三条逐坐标 `[-1,1]` 均匀随机动作；以及 `default_rng(2026110505)` 在见证后十步上加入八组逐坐标 `[-0.2,0.2]` 均匀噪声并裁剪至 `[-1,1]`。全部转为 float32。前七个非零后缀为构造组，八个扰动为验证组，四个前缀共享。零尾允许与原查询重合；其余完整链如与原两臂首轮查询精确重合则拒绝。见证及其变体本身已暴露，不能称为独立动作分布或未知见证。

设计针对上一固定随机库没有覆盖物体运动的诊断缺口，物理状态生成的见证只供本评估使用，禁止注入任何规划器。与前次诊断使用同一物理边界、相同冻结模型、预测和真实 RGB 编码工作器；固定全部 64 条动作和失败分母后执行。分前缀、构造/验证组，报告物体姿态数量、物理成功、预测与真实编码评分排序、相对零尾改善误差，以及物体位置/角度的非并列排序；提供所有并列数。保留绝对评分、逐动作、状态和图像。验证动作直接被模型评分，不能作为“描述预测未查询动作”的证据。

同后端物理重放及独立 CPU 统计审计，检查动作构造、源哈希和零尾查询重叠。依赖实现相同，不是独立物理/神经实现。根、任务和见证已暴露；不进行策略选择、重规划或训练，不改原 gate 或声称公平规划/泛化优势。
