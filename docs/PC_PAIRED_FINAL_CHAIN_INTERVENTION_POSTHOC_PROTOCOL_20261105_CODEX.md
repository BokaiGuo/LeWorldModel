# 双片段搜索最终链：事后共同尾部和重规划诊断

对已暴露的 16 根、两随机流全部 32 条 pair 臂最终实际动作链做统一干预，不按组合见证、成功或结果筛选。源搜索已结束且结果已查看，因此这是**事后开发诊断**，不称为事前机制确认；不替代原 PC2 合同。目标、任务和父链来自已审计源；来源独立性 unknown。

把最终动作前五步作为 selected 前缀，分别与同一搜索父链的前五步（parent）和五步零动作（zero）对照。三个前缀共享两条十步尾部：全零尾和实际最终链尾。记录两条绝对终距与各自相对零尾的改善；selected 相对对照的共同尾部增量定义为所选尾改善之差，正值表示 selected 上所选尾相对零尾多改善。预定实际差异阈值为 `>=0.01`。这不保证对照在时刻五有相同位置或同一被动状态，不能把差异直接视作纯接触因果效应。

每个前缀分别以**同一零尾**为 CEM 唯一初始点，运行 3 条共享随机流 `2051500000+root*100+repeat*10+k`，每次 120 条完整链评分，batch 12、elite 4，剩余十步全部可优化。所有前缀享有相同优化次数和随机流，但起点不是全局最优；记录每次最优终距及动作，未检出不等于不可行。记录三次均值差，`>=0.01` 仅为本开发诊断的实质差异阈值，不回写旧 gate。

另记录所选前缀五步终距和起始终距，非即时进展按前缀终距 `>= 起始终距-0.01` 计；记录最终链与原父链的物理重放得分、成功阈值 `<0.05`。完整输出含每次预测、动作、预算、依赖哈希与失败；模型调用成本单列，不混入原搜索成本。相同动力学重放不证明独立物理系统、视觉或泛化，也不自动证明后续能力变化由前缀造成。
