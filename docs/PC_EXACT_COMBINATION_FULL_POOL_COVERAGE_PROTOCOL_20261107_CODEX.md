# 精确墙障未查询组合：评价端全池失败分解

本次事后审计已封存的 24 个开发根，不更改任何策略选择、停止标准或历史结果。
从记录的偏移和原动作生成函数重建共同名义链、64 条 A 组合以及全部 512 条 B
组合。先核对历史依赖指纹、名义和 A 的原始代价、每臂的八个 B 代价、最终链
与最终成本；任何不匹配停止审计。

对每根以此前实际共享的 72 条链最低代价为 incumbent，评价端额外评分全部
512 个 B 组合，报告：

1. 全 B 池中比 incumbent 低的组合数，及是否有新的严格成功链（距离 <0.05）；
2. 每臂已查询的八条链是否覆盖上述改进或新成功，以及相对全 B 池最优的距离遗憾；
3. 保留所有 24 根及全部失败，按根统计；B 池与历史规划成本分开记录。

本次全池真值是事后评价端信息，绝不回流规划器、重选动作或充当免费提案。
固定任务族和实现已暴露；即使找到改进链也只是覆盖上界，不证明任何方法
能够在原预算下找到它。精确动力学同时用于预测和评价，不是视觉或独立物理
验证，也不能改变 PC0–PC5 判定。
