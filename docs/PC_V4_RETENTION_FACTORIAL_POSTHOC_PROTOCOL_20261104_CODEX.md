# V4 保留规则 2×2 后验诊断协议

前次配对诊断结果已经可见，本分析及新规则均为后验探索，不能称独立确认。固定已封存的 24 根、九候选、位置与后继响应，以及每候选三个已评分 CEM 重复；不追加优化或寻找新根。两个因子为：是否在即时最佳后保留局部可达价值最小者，以及剩余名额按响应矩阵距离或后继位置距离作最远点保留。局部价值候选与即时最佳相同时不额外占位。每组均保留四个不同候选，平局依候选原始次序确定；完整规则及集合逐根保存。其两个对角组必须精确重建既有两个保留集合，否则停止。

每个固定集合在每根每重复使用先前每候选相同的已保存分数选最优；报告四组每根三次均值的均值、中位数、`<0.05` 根数，以及两项条件对比和交互的配对根均值。还需报告四组保留集合重复、局部价值候选是否改变、指标选择及资源边界。三个重复不是独立任务，不进行显著性推断；不同集合共享候选搜索结果。

因为规则是在查看前次差距之后定义，不能用于宣称事前机制、优化器充分性或 PC2/PC3 通过。探索的中间组从未执行 v4 联合精修、反馈或同成本完整规划；离线全九候选代价也不能作为部署成本。价值项是否有增量只能解释为这种四名额启发式中加入第二个种子的条件效应，而非对局部价值原理的普遍判断。
