# Zero-reference 后果反馈的 CEM16 开发对照

对已曝光 roots 10–49，复用既有 16 查询 zero-reference 四臂的 RGB-only 任务、模型、初始状态、目标、25 环境步截止、每五步反馈、提前成功停止和末尾剩余时域目标。新增 CEM16：每轮规划旧尾或零链 1 条，加 3 轮各 5 条合法常量五步动作包，取每轮前 2 条更新均值方差、标准差下限 1e-5；最终从全部已评分链选最小预测末帧代价。旧尾补零仅填充未执行部分且共同计费。每根随机流 `8140000 + root*10 + iteration`。

原研究源四臂和 CEM16 使用各自闭环观测，并报告根级配对成功、实际重规划次数、全部模型评分、包转移及局部同步计时；16 次每规划不等于整个任务同成本。与 effect 臂的配对结果为开发比较，不更改该臂原停止结论；本 CEM 不是充分调优基线。每轮所有动作、评分及输入收据留存；真实状态只用于环境初始化和结果评价。不存在独立任务或正式 gate 主张。
