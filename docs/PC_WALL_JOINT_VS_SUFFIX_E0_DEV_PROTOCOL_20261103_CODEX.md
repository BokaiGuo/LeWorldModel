# 相同起点下固定前缀与联合优化开发对照

此协议在多样性联合精修结果揭晓后固定，是暴露任务上的机制与优化器开发诊断，不是独立确认。使用同一八个精确 wall 任务、旧事前封存的每根八前缀、相同 16 步四参数模板、同预算 1145/2169。逐前缀评价旧固定 11 后缀并取最优，作为两臂完全相同的八个起点，计入 8×11 次完整 rollout；前缀筛选计入 33 次。保留这八个起点中最好的 incumbent。

余下预算由 8 起点×2 轮 CEM 使用，每起点初始标准差 .5，精英为最优八分之一且至少两个、标准差下限 .02。两臂共享相同四维预生成正态随机数和预算分配：

- `fixed`: 前两个参数固定为各自起点的原前缀，仅优化后两个后缀参数。
- `joint`: 四个参数均可优化，运行时仍保留精修前 incumbent。

最终对所有起点与样本按实际完整链终距选择，并回放实际选中动作。记录起点、样本、评分、实际预算、耗时以及前缀变化。该实验只比较两种特定 CEM 参数化和资源分配，不能声称所有联合优化或程序方法的上界，不以共同随机数等同硬件成本。非即时条件在最终选中前缀上评价；不运行或反馈物理 witness；不改 PC gate。
