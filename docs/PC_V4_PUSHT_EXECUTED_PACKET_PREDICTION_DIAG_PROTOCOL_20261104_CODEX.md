# PushT 已执行片段的模型—真实编码诊断协议

这是针对已暴露单根反馈结果的新事后诊断，不追加规划、不改变原实验，不作为确认性评估。固定使用 response 与双起点 CEM 的三次已执行五步动作、四个已保存 RGB 上下文和现有执行审计；仅评价实际发生的六个转移，不构造后验最优动作。

对于每次转移，用决策前 RGB 历史、动作历史及实际派发的五步动作，在同一冻结 checkpoint 和同一公开动作统计下预测下一 packet latent；分别重新编码执行前最后一帧和执行后最后一帧。报告预测对下一真实编码的逐维 MSE、L2、最大绝对误差；以“下一编码等于当前编码”的持久基线为对照，报告真实 latent 位移、预测 latent 位移及其误差。另报告当前、预测和执行后真实 latent 到同一目标编码的 MSE 与变化方向；同时列出仅用于评价的物理物体位置、角度和官方距离变化。

实际未来编码与预测 latent 的差异不能单独定位到模型、动作统计、预测时钟或视觉域差异；与 goal MSE 一致也不证明物理目标一致。物理状态不输入预测器。只重算单 packet，与原始剩余 15/10/5 步计划终端不同，不能将执行后的真实状态和原完整链预测直接视为同一轨迹：后续动作在反馈中被重新规划。

运行前验证原 manifest、结果、每臂执行及上下文和决策哈希、原始逐步重放审计；冻结模型参数前后哈希，记录所有依赖和输出哈希。结果是每臂三个相关转移，不推断总体性能，不宣告任何 PC gate 通过。
