# 时序目标：固定动作对结果

## 先核对回退退化的来源

30 个已曝光根的 1,920 个参考—探针对中，分差回退改变 **504 对**：
直接选择独胜 **48 对**、回退独胜 **0 对**、两者都成功 **86 对**、
两者都失败 **370 对**。48 条直接选择独胜链全部在第 10 步前缀之后
首次成功，其中 **34 条到第 25 步已不再成功**。这复现了先前
曾成功比例的净下降，没有发现上轮选择映射或成功汇总错误。

## 同动作对的预测时序选择

GPU 对 30 根的 **2,160 条**已有完整链重算五时刻预测；末帧与旧
封存值最大差为 **0**。封存模型选择后才读取先前物理轨迹：

| 规则 | 25 步内曾成功比例 | 平均第 25 步末距 |
| --- | ---: | ---: |
| 预测末帧最低分 | 28.18% | 41.19 |
| 五时刻最低预测分数 | 31.04% | 41.03 |
| 严格前缀后（15、20、25 步）最低分 | 31.98% | 42.43 |
| 已停止的分差回退 | 25.68% | 39.42 |

严格前缀后规则相对末帧，30 根中成功比例严格提高 **21 根**、
下降 **0 根**，但平均末距增加 **1.24**，超过预定最多增加
0.5 的条件；因此**未通过该固定规则的开发出口**。

全五时刻最低分相对末帧在根级成功比例上为 **18 根提高、3 根
下降、9 根不变**，并且平均末距略低。这是值得保留的探索信号，
但本实验的预定出口针对严格前缀后规则，不能事后把它改记为通过。
先前完整 RGB 反馈实验中时序最终选择已有开发信号，但未超过
高预算 CEM；本次二选一结果也不证明行动后果描述的独立增量。

数据和根均已曝光；各根内的 64 对共享动作，不是独立任务。
曾成功与末距属于不同目标，物理重放为了对齐旧合同在终止后继续，
不能将其等同真正的在线停止或反馈性能。真实物理结果只在模型
选择封存后用于评价。

GPU 同步时序重算约 **1.45 秒**、10,800 模型 packet 步，未计模型
加载、环境执行或完整搜索。时钟、前缀掩码、选择映射与成功分区
测试合计 **6 项通过**；`code-debugging` 用于核对选择、时钟与标签。
PC0–PC5 不改判。
