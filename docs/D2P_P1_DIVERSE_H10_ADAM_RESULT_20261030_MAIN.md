## 同后缀描述性比较

对 40 个非零且与控制匹配的后缀，使用事后 `1e-6` 容差，仅描述
物体位置误差（不是显著性检验）：

- root 0/on/projected：selected 和 zero 的绝对终态、减各自零后缀
  的响应差异均为零；这是同前缀复现。
- root 1/on 的两个重复臂：selected 的绝对终态位置误差在 40/40
  个匹配后缀上更大；先减去各自零后缀后，20/40 的位置误差响应
  更大，另外 20 在容差内相同，没有更小的。角度、推杆及原生
  联合指标须查看逐行表，不应由位置结果推断。

上述后缀来自两个已知根，后缀共享前缀和轨迹，不是独立样本；
同后缀仅检验指定动作的后果，不能证明独立规划能力。最终
结论是此批新前缀没有建立 P1 机制或独立公平优势，不是证明
理论不可能；下一步须对候选筛选与实际部署重新设计，并在新根、
统一资源合同及公平强基线上确认。
