# RGB 编码缓存完整反馈配对成本协议

固定已曝光 TwoRoom episode 9000–9039，比较 effect 和 CEM16 各自的原始、单帧缓存实现，共四臂。每臂独立 reset 并执行其自行选出的动作，任务、随机种子、25 步上限、每五步观测、旧尾、冻结模型及选择规则不变。使用 `CachedJEPA` 的完全相同图像键控，不用于动作梯度或多帧历史；缓存对所有比较算法开放，不作为行动后果模块独有优势。

逐任务配对要求记录每次完整计划、选择、模型查询、派发、物理距离及终止，动作误差不超过 1e-6、距离误差不超过 1e-5；不一致如实记录，不用历史轨迹代替新臂执行。每臂任务计时从 reset 前到停止后，规划计时前后同步 GPU；固定计时边界，不计模型加载和数据打开。每任务根据 episode 奇偶交错两种缓存顺序；不作随机化和统计效率主张。40 个任务来源独立性未知，只能作开发重放。

本比较检验完整反馈是否与已认证的单次缓存结果一致，以及同机开发成本；不设非劣效主张，不证明描述方法净收益、独立泛化或任何 PC gate。若运行不一致或计时污染应保留证据并排查，不更改已封存历史实验。
