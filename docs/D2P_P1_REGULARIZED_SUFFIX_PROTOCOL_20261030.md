# P1 双包后缀目标一致性探索

既有双包实验用终态 MSE 的梯度更新，而候选选择用 MSE 加 logits 正则。此次仅更正优化梯度，使其与已使用的正则评分一致：每包在原有 `dMSE/draw * (1-raw²)` 之外，加上 `2*0.002*logits/192`；每包仍投影到相同原动作球。保留同样 160 个 occurrence、原始初始化、8 次更新、9 次评估和同臂基线。候选、根、评分均曾观察，因此这是探索性的代码/方法差异对照，不是独立确认，也不修改 P1 gate。

单次实际 CUDA 计划 2880 predictor、2880 action encoder、1280 reverse；不训练模型。GPU 结果仍须完整来源校验和保存算术复算，若训练/历史绑定/设备或调用数错误则工程失败，不视为理论负结果。

## 固定步长的保存轨迹诊断

使用 `p1_saved_step_diagnostic_20261030.py` 对封存报告的 160 项、各 8 次更新做全分母复算；原 saved consumer 再次通过，新增诊断 2 项测试通过。按保存的 raw 梯度和 producer 的正则项重建一阶方向，与实际 logits 位移求内积：1280 次均为负；其中 242 次下一迭代的实际正则评分反而上升，涉及 120 个候选。最大单步上升为 1.378280963591148，对应 slot 3、outward_free_tangent、start 3、prefix iteration 3、suffix iteration 6，方向内积 −0.5570762576222192。

这支持将固定步长和有限幅度非线性列为后续受控实验因素，不能仅凭此判定梯度错误、具体曲率大小或 P1 理论失败。这里重用保存梯度，没有重新执行神经网络或物理实验；float32 tanh、投影及实际模型损失的有限精度也不能由该方向内积单独排除。下一步可在新协议中固定所有候选、上限及独立的模型调用账，比较固定步长与有界回溯，并在任何新的物理评估前封存选择规则；这是观察旧结果后提出的探索，不能当独立确认，也不能放宽 P1 gate。
