# V5 PointMaze 已封存预测参考路径重算协议

使用 v5 已封存三次决策的 RGB 帧、动作历史、目标图像与全部原始动作批次，重新加载同一冻结 PointMaze checkpoint 和同一归一化统计。单独实现显式历史 packet 与候选 packet 的逐步 predictor 展开，不调用原 `unroll_with_action_history`；重算二维投影与目标分数，并检查动作 float32、每批 token、全部完整链最优选择及模型哈希。容差分别为位置 `2e-5` 和分数 `2e-6`，超出即停止。

该事后检查重用同一 checkpoint、同一输入图像、编码器和代价函数，只检查实现路径与记录一致性，不是独立数据、模型或物理反馈认证。绑定完整已列依赖及各项源文件；未列环境闭包与训练来源仍未知。
