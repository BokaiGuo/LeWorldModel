# P3 画布边缘：RGB 预检探索合同

此合同在既有越界事件之后提出，是已知根上的开发诊断，不是
独立确认。冻结模型与已封存动作均不变；不更改旧实验。

对真实 cp15 RGB 使用现有 PushT 精确推杆颜色检测。若图像
类型／形状不符合要求、颜色点少于 8、颜色分量不唯一、标记
接触画面边界，或其包围盒距离任一画面边界小于 8 像素，则
拒绝进入后续规划；其余图像返回可进入。8 像素是本次固定的
工程探索值，既不声称物理安全距离，也不据观察结果事后调参。
此输入检查只使用 RGB，不使用模拟器位置、速度、目标或成功
标签；若拒绝，不能伪造动作和终点，也不能作为已有实验的
结果替换。

固定评估 `p3_h3_real_context_replay_20261031.collect()` 的全部
52 条已完成轨迹的 cp15 图像，不按动作、真实成败或越界结果
选择输入；以像素哈希记录可复核的逐行结果。事后关联既有
画布事件仅用于说明诊断覆盖，不回传给预检。拒绝意味着保守
弃权，不意味着理论失败；通过亦不保证后续动作在画布内，因
为惯性、接触、预测误差和后续动作都未被安全证明。

不执行新物理动作、不调用神经模型；后续如要把预检用于在线
控制，必须在同机会、同资源和真实 RGB 反馈下对全部方法公平
应用，并事先固定拒绝／失败处理。
