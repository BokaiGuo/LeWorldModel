# TwoRoom 向量保留数值压力检查

对此前 290 评分实验的 40 个已曝光任务，重新计算共同探针上的
lookahead 首前缀和向量最远第二前缀，并验证与原记录完全一致。

- 将评分由存储的 float64 转为 float32 后，**0/40** 根的前缀对改变。
- 对每根做 256 次、每个分数独立的 `±0.000466` 均匀扰动，首前缀和
  第二前缀均为 **0/40** 根出现变化。
- 第二前缀的最小最远距离平方间隔为 **485.951**，单位是此描述空间
  的代价平方，不可直接解释为物理距离或成功裕度。

扰动幅度来自另一批次曾观察到的分数差，是压力尺度而非该实验误差的
严格上界；这些试验也不能覆盖所有对抗扰动或其他候选分布。结合当前
结果，没有证据把该面板的向量保留负结果归因于这一级数的精度扰动，
因此不为这个面板事后更改规则。合成近并列案例仍然可能出现切换，
其他数据上的数值稳定性不能由本检查担保。

本次只读取封存模型分数，没有重跑 GPU 或物理环境；不改变历史停止
规则、性能结论或 PC0–PC5 状态。选择重建和异常输入测试 2 项通过。
逐根结果见
`le-wm-main/results/pc_tworoom_retention_numerical_stress_20261107_codex.json`。
