# 新前缀独立 Adam 后缀的物理验证

固定原 16 行已知根动作清单，仅将第 5、13、15 行 selected 的后十步
替换为各前缀真实 cp5 RGB 上独立 CUDA Adam 规划的赢家动作；其他
13 行原样重放以沿用已审计的 16 行执行器。它们是重复执行，不构成
新独立样本或与新后缀的等预算基线。第 13 和 15 行前缀、赢家动作
相同，仍按逻辑合同执行但不能算独立实例。

来源分开记录：原 CUDA replay 只认证原动作及新动作的共同前缀，
新后缀来源于独立 Adam 规划结果，不能声称原 replay 认证了它。
运行前验证赢家是保存的四个分数中的稳定最小值，动作字节和
cp5/前缀身份一致；运行中逐条重建 warmup、原生根和 RGB，检查
前缀及后缀的真实 dispatch。完整保存态验证是后续分析的前置。
所有原生停止和截断按原合同保留，不补造固定时域终点。

本批不增加神经调用，物理状态仅用于回放认证和评价；它不证明
额外能力改变、不具独立新根，也不证明统一总预算。已有共同后缀
机制实验和各自独立优化的性能实验应分开，不根据结果更换门槛。
