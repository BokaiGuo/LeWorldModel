# TwoRoom 向量保留的数值敏感性：已封存分数压力检查

对既有 290 次实验已曝光的 root 10–49，读取每根原 8×8 A 探针代价，
重算 lookahead 第一前缀与中心化后果向量最远的第二前缀，不读取物理
成功或 B 尾部。比较原 float64 存储计算与先转 float32 的计算；另以
固定随机种子在每个评分上独立添加均匀 `[-0.000466, 0.000466]`
扰动，每根 256 次，记录第一和第二选择是否变化、向量距离边界间隔。

`0.000466` 是另一项同模型复评分中观察到的最大差，只是事前固定的
压力尺度，不是该池误差上界或误差分布模型。按任务和条件报告，不将
扰动抽样视为独立任务。本检查不改变规划器、不推断成功收益，也不
重启已停止配置；如出现敏感点再另立规则和公平比较。
