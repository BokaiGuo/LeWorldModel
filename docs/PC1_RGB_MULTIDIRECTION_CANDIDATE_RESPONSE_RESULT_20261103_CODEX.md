# PC1：RGB 多方向候选响应与物理重放

按[诊断协议](PC1_RGB_MULTIDIRECTION_CANDIDATE_RESPONSE_PROTOCOL_20261103_CODEX.md)，
对四个暴露 PointMaze 根、每根三次真实 RGB 决策的实际首段候选，
重放 12 个名义动作和 60 个候选分支。物理分支从相同热身及决策前
实际动作历史出发，分支前状态与时钟与既有原生重放逐位一致。

| 候选 | 比较 | 绝对向量误差中位数 / 最大 | 相对误差中位数 / 最大 | 方向余弦中位数 / 最小 |
|---|---|---:|---:|---:|
| 48 个谱候选 | 模型线性近似 vs 模型实际位移 | 0.06077 / 0.21270 | 0.21504 / 1.19613 | 0.99615 / 0.79697 |
| 48 个谱候选 | 模型实际位移 vs 物理位移 | 0.03292 / 0.22827 | 0.10850 / 0.72465 | 0.99848 / 0.76193 |
| 12 个 zero | 模型线性近似 vs 模型实际位移 | 0.03908 / 0.10067 | 0.20477 / 0.53533 | 0.99526 / 0.97235 |
| 12 个 zero | 模型实际位移 vs 物理位移 | 0.02225 / 0.04526 | 0.11720 / 0.23836 | 0.99771 / 0.97421 |

位移都相对于各自名义动作；相对误差的分母为对应比较的实际参照
位移。此面板没有范数低于协议阈值的参照；12 次决策和候选不是独立根。
所测方向的中位方向一致性较高，但较大候选幅度下模型的线性近似误差
可明显增大，物理响应也有幅值及方向偏差。因此原来的两个坐标轴、
小尺度 AD/FD 结果不足以认证当前谱候选的全幅有效性。

比较每个候选相对名义动作的模型任务评分差与物理目标距离差，57/60
排序同向、3/60 反向、0 平局。三个反向分别为：

| 根 / 决策 | 候选 | 模型评分差 | 物理距离差 |
|---|---|---:|---:|
| 0 / 2 | zero | +0.00546 | −0.11337 |
| 1 / 0 | 第二方向负号 | +0.03662 | −0.01709 |
| 2 / 2 | 第二方向负号 | −0.04047 | +0.00820 |

正值代表该侧认为候选比名义动作更差。模型评分与物理距离量纲不必
相同，表中只比较符号。**事后探索性归因**：如果特权地用物理名义
终态及物理目标对齐基准，再叠加模型位移，排序同向为 58/60；后两处
反向仍存在。这不是部署方法，也不能单独确定误差来自预测、目标编码、
图像状态估计、模型误差还是物理接线。

预检时发现最后五步 zero 动作在不同预测批次的评分最多相差
`2.09e-7`、投影位置最多相差 `6.75e-7`。诊断按 trace 顺序绑定
实际候选库评分，并保留重复差值；它们不能证明存在实质代码错误。
独立审计重跑 72 条物理路径并重建 12 个 Jacobian，重放轨迹一致、
Jacobian 最大重建误差为零。这是确定性回放，不是独立泛化证据。

该诊断只覆盖五步首段候选，不包括后继响应、其他模型或独立来源；
PC1 仍未整体通过，PC2–PC5 状态不变。没有修改历史选择或将物理状态
输入规划器。
