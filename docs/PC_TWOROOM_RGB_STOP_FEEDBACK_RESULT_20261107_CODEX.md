# TwoRoom 终止即停：纯视觉反馈接口复核

## 对上一轮结果的修正

上一轮终止即停执行器读取了 reset 信息中的物理距离，以判定是否
在初始状态停止。这是特权物理信息，不能将该执行器本身认证为
RGB-only 控制流程。原报告中的“初态已成功为 0”是事后评价事实，
不能消除该执行路径的权限缺陷。本次面板中这条判断没有触发，
因此需要核验而非直接推断其后续结果是否改变。

## 本次执行

按[协议](PC_TWOROOM_RGB_STOP_FEEDBACK_PROTOCOL_20261107_CODEX.md)，
将尾部选择函数的输入限定为当前 RGB、目标 RGB 和两条合法动作尾部，
不接收环境对象、状态或成功标签；环境执行端依据 Gym 的
`terminated/truncated` 停止。reset 返回的物理距离不用于动作或停机
决定。初态是否已经成功不由规划器判断；本面板的初态事后均未成功。
这不是对其他初态处理规则的认证。

冻结模型在 GPU 上重新执行 40 个已曝光任务的两种前缀，共 80 条轨迹：

| 前缀 | 执行动作后成功 | 实际派发步数 |
| --- | ---: | ---: |
| 原选中 | 39/40 | 839 |
| 逆序 | 36/40 | 864 |

全部 80 次反馈决策、现场图像指纹和 1703 个派发动作与上一轮一致；
物理轨迹在原先的 `atol=1e-5` 内一致，160 个评分最大差为 0。
单元测试覆盖决策接口拒绝额外状态参数、非法动作与终止／截断即停；
连同旧候选测试共 4 项通过。模型运行前后指纹一致。Gym 仍有
torch 观测类型与声明空间不一致和动作转换警告。
