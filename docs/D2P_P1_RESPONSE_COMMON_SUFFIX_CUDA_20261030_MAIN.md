# P1 模型响应多样性与共同后缀：已知根探索

将既有四槽八臂、每臂 20 个已封存候选接到同一个冻结模型后缀
优化器。两种四候选集合分别为：

- 任务方向 Jacobian 响应多样性筛选；
- 模型即时代价最低的四个候选。

每个候选从其**模型预测**的 prefix 后继及其动作历史出发，使用
相同零 raw 初始化、五步投影梯度更新和五动作后缀；按最终模型
latent MSE 在各自集合选最小值。两个集合的重复候选只计算一次，
因此本次不是两臂各自独立计费，也没有包含上游 20 候选和
Jacobian 的生成成本。无实际 RGB 更新、物理执行或训练。

主机 RTX 5060 Ti 完成 8 臂、54 个不同臂内候选，显式路径计数
action encoder 324、predict 324、backward 270；这些不是独立
hook 的全流程总成本。模型参数和 buffer 散列前后相同。结果
`le-wm-main/results/p1_response_common_suffix_cuda_20261030_main_RUN01.json`
SHA-256 `4b05a43e09711cc52ad4d1cf3b717b27524b3c4d7e1fddea57202708b4dd0d5d`。

八臂两种集合均选择同一个 index 0，模型终态得分因此逐臂相同；
四槽分数依次约 0.5731、0.6345、0.3117、0.3184，两种原候选臂
在各槽重复。说明在本次固定候选、优化器和预算设置下，多样性
筛选没有改变模型内最终选择；不是独立样本统计，也不是物理或
P1 科学负结论。五次更新可能不足，且这些候选本身基于先前结果
选取，不能事后调整本次合同或将其用于泛化结论。

该结果为下一步提供具体方向：若要继续这条方法路线，需要新合同
测试更充分的共同优化、完整前缀生成成本和真实 cp5 RGB 反馈，
并把选择不改变与物理任务评价失配分开。正在运行的新前缀共同
后缀干预不受本次结果影响，P1 保持关闭。
