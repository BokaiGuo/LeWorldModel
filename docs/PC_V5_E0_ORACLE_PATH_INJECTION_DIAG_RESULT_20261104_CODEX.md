# V5 E0 好链路径注入诊断结果

18 根原 v5 控制重跑的最终链、首层候选、保留序号及确定性计数均与封存记录一致。事后将第一条特权解析见证通过跟踪钩子交给真实 v5 完整链 `tracked` 后，18/18 进入精修起点、以原动作保持至最终选择，弃权 0/18；相同精确后端重放全部达到 `<0.05`，最大终距 `1.39e-7`。注入的三个预测 token 包含在每根 1920 token 内，精修相应少一个完整链样本。

这说明对这些链、该精确后端及这次插入位置，完整链评分、incumbent、最终选择和动作回放未显示错误；不代表正常生成器会找到它们，也不认证真实 RGB 的模型预测或物理派发。

另一项事后反事实将每根同一见证的前五步加入封存首层候选库，以实际 v4 响应及保留函数重新选择：仅 **3/18** 个见证前缀被保留。见证前缀到最近原生成前缀的动作空间欧氏距离范围为 0.768–1.238，均值 1.049。这提示该特权解的前缀不在原候选库中，且即使加入亦常被该规则裁剪；不能由此认定裁剪一定导致正式搜索失败，因为后缀并不保证优化得到，其他有效程序也可能存在。

[预定诊断协议](PC_V5_E0_ORACLE_PATH_INJECTION_DIAG_PROTOCOL_20261104_CODEX.md)记录首轮对照重跑误将运行耗时视为确定性字段导致的诊断脚本中止；修正后才执行注入。[原始诊断](../le-wm-main/results/pc_v5_e0_prospective_mechanism_dev_20261104_codex_oracle_path_injection_diag.json)绑定源码和输入；[另行编写的重放与保留谓词审计](../le-wm-main/results/pc_v5_e0_prospective_mechanism_dev_20261104_codex_oracle_path_injection_diag_audit.json)通过 18 根。两者仍共享精确动力学后端，非独立模型复现。钩子使用运行时跟踪、未更改 v5 正式实现，结论仅限其插入时机；这不是 PC2/PC3 通过证据。
