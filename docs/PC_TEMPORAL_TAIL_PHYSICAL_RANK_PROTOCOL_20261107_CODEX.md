# 时序尾部预测与真实物理排序：已曝光开发诊断

固定复用已封存 TwoRoom roots 20–49，每根 8 个前缀、每前缀 8 个同动作身份探针；参考链只用于核验同前缀真实轨迹及成功分层，不参与探针排名。模型输出来自已有完整动作链预测，目标为第 15、20、25 步的最小潜在目标代价；同时报告第 25 步预测作为对照。真实物理质量分别为第 15、20、25 步的最小距离、尾部 11–25 的逐步最小距离，以及尾部实际成功状态。

每个前缀比较 28 个不同探针对：当物理距离差大于 `1e-6` 且模型分数差大于 `0.005` 时计为有效，报告同向比例；并报告模型平局和物理平局，不将无效对算为正确。按任务先算比率再等权平均，同时报告有效对总数；不得把相互依赖的对当成独立任务。另比较模型选出的真实距离与该前缀 8 个探针的平均距离、评价端最优距离，报告它们是事后指标而非可部署 oracle。

完整分母与“前 10 步未曾成功”的诊断分层均报告；分层按环境终止信号，不剔除难任务。尾部成功二分类按 11–25 步是否出现成功，分别统计同前缀中成功和失败尾部同时存在时模型优选的成功率。包括已经在前缀成功的所有链，不把它们当作重配置机制证据。

所用候选和任务已曝光，分析与上轮结果相关；本诊断不设追溯性的通过阈值，不构成 PC1 通过或独立证据，真实距离及成功标签不能回流 RGB 规划器。
