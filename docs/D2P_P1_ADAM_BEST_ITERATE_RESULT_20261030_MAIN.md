# P1 中点重规划的最佳迭代开发结果

[预先固定的开发合同](D2P_P1_ADAM_BEST_ITERATE_PROTOCOL_20261030_MAIN.md)
在主机 CUDA 完成 24 条，并将全部动作做物理回放和保存消费。
冻结模型权重和 buffer 哈希前后一致。输入通过新停止检查并重用
原 journal、动作及中点 RGB 认证；新旧物理分支的前五步动作、
状态、快照、停止标志和中点 RGB 逐槽相同。

这一改动只改变同一 20 步 Adam 轨迹上的候选保留；中间迭代的
目标已在梯度前计算，因此显式路径上的调用数没有增加。24 条的
末次及初始目标与原信赖版完全一致；7 条的最佳目标严格更低且
动作不同，17 条仍选最后一步。模型目标下降不等于物理效果变好。

与原信赖版逐槽比较：两版各有 2 条原生成功记录，均为根 0 的
zero 前缀，分别为 off/on 条件。22 条两侧均有未删失终点，新的物体
位置、角度、推杆及联合位置误差分别有 1、1、4、4 条更低；对应
平均差为 -0.1704、-0.000189、-0.3734、-0.4301。多数动作没有
改变，不能将这些计数当成独立统计证据。

在 7 条动作改变中，1 条两侧均原生停止并成功；其终点按原合同
删失。其余 6 条均未成功，物理指标有改善也有恶化。例如根 0/on
的 selected 行 6，模型目标降低约 0.000028，但物体位置、角度、
推杆与联合位置误差分别上升 1.261、0.00855、4.072、3.470。
因此“只保留最后迭代”确实丢失了模型内较优候选，但本批结果
不支持把 P1 失败归因于这一点，也没有建立 P1 机制或控制优势。
