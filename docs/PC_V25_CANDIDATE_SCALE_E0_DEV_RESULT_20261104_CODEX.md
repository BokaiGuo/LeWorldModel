# v25 候选幅度消融：E0 开发结果

按预先保存的协议，八根任务的原幅度 `(0.25, 0.5)` 与小幅度 `(0.125, 0.25)` 两臂全部完成。两臂在 `<0.05` 终距成功标准下均为 **0/8**。以小幅度终距减原幅度终距计，小幅度为 **0 优、3 平、5 劣**；不作显著性结论。

每臂预测 token 上限均为 1920；15 次运行使用 1920，原幅度 root 3 使用 1918。每臂的其他开销和精修样本可不同，不将等 token 解释为等墙钟或等 GPU 成本。所有调用已记录；审计核对初始全局候选、预测账本、最终完整链及另一同环境几何实现的预测。审计不是独立复现。

事后检查 incumbent 来源：原幅度的 8 根中，5 根来自完整链精修、2 根来自后继探针、1 根来自全局候选 carry；小幅度分别为 5、1、2 根。两臂每根的全局候选最初选择索引一致，最终均未弃权。这些来源标签只是路径记录，不能将完整链质量差异因果归于精修或探针。

该实验仅说明此次缩小固定候选幅度没有带来可观察的成功收益；它不检验自适应缩步、重新线性化、非局部回退或完整响应移除，也不能排除搜索覆盖、优化、环境或实现等其他原因，更不能证明理论失效。根的更广来源仍未知；此结果不能作为 PC1、PC2 或 PC3 通过证据。
