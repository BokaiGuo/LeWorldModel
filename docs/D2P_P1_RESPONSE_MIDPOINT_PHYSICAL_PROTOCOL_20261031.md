# P1 新响应前缀中点重规划物理回放

对固定 CUDA 计划中的 13 条执行完整轨迹逐条回放：同一根、相同
warmup、相同 cp5 前缀及原后缀前五步，然后派发重规划的后五步。
另外三槽按已有越界情况保留，不补值、不按结局选择。每条在派发
第六步之前，检查真实中点所选 RGB 像素哈希、七维状态和模拟器
快照与规划使用的封存中点完全一致；不一致立即停止该次批量并
记为接线／物理重放问题，不能当作科学负结果。原生提前停止或
越界不补齐时域终点。

这是已知根上的离线重规划后物理回放，不是实时在线反馈；同一
物理环境可能重现已保存动作，因此逐步重放和中点绑定是前置
条件。记录物体、角度、推杆、原生成功及每个删失状态，并对照
同一行的原后缀；不得把不同前缀的后缀或未经认证的资源混排。
原规划、额外中点编码与优化的资源分类列出，不宣称总预算公平、
独立根泛化或 P1 通过。
