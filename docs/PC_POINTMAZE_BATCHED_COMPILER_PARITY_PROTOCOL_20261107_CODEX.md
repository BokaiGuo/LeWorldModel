# PointMaze 状态辅助批处理：数值及耗时核验

保留原逐条状态辅助适配器，新增可选批处理实现；两个适配器调用
同一共享搜索核、同一官方配置目标函数与冻结模型。使用已曝光面板
1884–1886 的 camera 0、两对 proprio、固定随机生成的相同候选库：
3 父链、6 探针链和 2 条尾链，每臂 11 次逻辑评分。候选和 retain
规则均固定为 lookahead、保留 1 个前缀，批大小为 4。

每任务先各热身一次，再交错重复逐条和批处理各三次；使用 GPU 同步
的整次编译时间，模型加载、硬件初始化及环境执行不计。比较每条
模型评分绝对差、保留前缀、最终候选身份与动作；阈值预定为 1e-5，
任何选择变化均须报告。逻辑候选数不等于底层调用数；逐条预期 11 次，
批处理按每次共享核调用的批次计，预期 4 次。审计权重指纹、输入
收据以及每次实际批大小。该结果仅为状态辅助开发的单机工程对照，
不是 RGB-only、完整任务系统成本或任何 gate 的通过证据。
