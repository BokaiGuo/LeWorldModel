# 四结点机制重规划求解器：事后检出率校准

固定已有的 16 个已暴露任务，每任务取既有可行性文件中前两条成功见证的前五步；缺见证记未知，不以特权尾部初始化、不供正式规划器使用。全部任务和见证事后已知，本实验不是独立确认，也不修改任何旧面板。

使用 `pc_response_temporal_search_v1.cem`，四结点、零尾、初始化单独评分一次、每次重启后续评分 480 次；和旧机制相同动作域、任务评分及 15 步长度。每前缀用四次预定独立随机种子，分别计算前 1、2、4 次重启的最佳分数，累计成本为 481、962、1924 次完整链评分。成功条件固定为终距小于等于 0.05；同时保存连续终距、实际调用动作、预测和失败状态。此预算曲线隔离重启数量而非优化分布或动作参数化；不与逐步 CEM 的 121 样本成本视为相等。

记录所有前缀（最多 32）和失败分母，审计实际样本与评分，并在同环境独立几何实现复算；已见证前缀不意味着四结点动作参数化可表达其见证尾部。结果只说明这些具体预算、初始化、种子和任务上的检出能力，不是前缀不可行证明或 PC2 门槛。
