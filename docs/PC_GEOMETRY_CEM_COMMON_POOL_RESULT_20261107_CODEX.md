# RGB 几何链与条件 CEM 链：共同池模型评分

按[协议](PC_GEOMETRY_CEM_COMMON_POOL_PROTOCOL_20261107_CODEX.md)，对 30 个
已曝光 root，每根把已执行过的几何链、末帧 CEM 链、时序 CEM 链放入
同一三链候选集；用冻结 RGB LeWM 在 GPU 上重算五个 packet 的代价，
封存预测后才读取已有物理回放。候选与模型未因物理标签调整。

| 指标 | 结果 |
| --- | ---: |
| 几何链曾成功 | 30/30 |
| 模型按末帧最低代价选中链曾成功 | 29/30 |
| 模型按五个 packet 最低代价选中链曾成功 | 29/30 |
| 末帧评分直接选择几何链 | 10/30 |
| 几何链末帧评分优于末帧 CEM 链 | 11/30 |
| 几何链末帧评分优于时序 CEM 链 | 11/30 |

两个关键失败任务的末帧预测代价如下，越低越优：

| root | 几何链（成功） | 末帧 CEM | 时序 CEM | 模型末帧选择 |
| --- | ---: | ---: | ---: | --- |
| 38 | 14.22 | 159.89（成功） | 72.95（失败） | 几何，成功 |
| 39 | 24.56 | 14.13（失败） | 21.78（失败） | 末帧 CEM，失败 |

因此，root 38 的问题在这个人为共同池中可以通过引入几何链改善；
root 39 则仍有选择损失：成功几何链已在候选池内，模型末帧和时序
最小评分都选择失败链。该结果只说明这一已曝光任务的固定池决策，
不能据此判断模型错因或证明通用几何提案能修复规划。

原两条 CEM 链的模型末帧代价重算最大误差为 `0.0001374`，低于
事先规定的 `0.005`；候选动作哈希、normalizer 和模型权重检查通过，
新增选链与非有限值测试 **4 项通过**。本轮运行 GPU 模型评分但未重复
执行物理环境；物理标签来自此前的独立封存重放。三个候选原本来自
不同生成流程，事后拼池不等于公平预算的端到端规划器，也不是对
描述、程序结构或真实闭环收益的证明。PC0–PC5 不因此改判。
