# PC1 多步响应开发诊断

本协议在运行前固定；四个已复用 PointMaze 开发根不构成独立确认。共同使用原有 15 步真实动作热身、RGB 帧 5/10/15、动作 6–15 作为历史、冻结模型和既有动作标准化。预测器只能读取 RGB 和动作历史；物理状态仅用于事后评价。

在零动作名义序列上，分别使用 5、10 个原始动作步；每个时刻均沿 x 或 y 单位轴施加同一扰动。模型输出为执行器现有的二维位置投影。计算该输出对原始动作的自动微分方向导数（两次反向向量积）和中心有限差分，尺度分别为 0.005 和 0.05；保存正负预测值、方向导数、计数、哈希。比较绝对误差及响应范数非零时的相对误差。

模型结果先写入不可覆盖的文件，再在 MuJoCo 2.1.2.14 正式场景从相同初始状态回放同一热身和所有正负动作，按第 15+H 步取物理位置。报告物理中心差分、与模型同尺度有限差分的向量误差与余弦；零范数时余弦记为 null。检查相同根各分支的热身状态一致，保存逐步状态及模型文件哈希。任何不匹配停止，不能向模型反馈物理状态。

这是局部接口、响应和尺度诊断，不测独立泛化、规划优势或 PC2 重配置机制；不能基于结果调整本协议，也不能由通过数值比较宣称 PC1 整体通过。不同响应向量的一致性不保证动作排序或控制效果。
