# P1 固定物理探针：分离物体位置与角度

16 个逻辑锚点、每个 21 条后缀的已知根探针均已完成。全部 16 个分片各有 21 个完整端点，通过保存消费器对动作、51 帧前缀、状态、记录链和操作计数的检查；这不是独立根或 P1 准入。

新增 `p1_backtrack_object_capability_analysis_20261030.py`，在固定全部分片完成后对严格消费后的实际物体终态计算：

- 坐标按原模型动作 logits 的 ±0.25，中心割线分母为 0.5；记录物体二维位置各坐标的响应及其奇异值，单位为环境位置单位／logit。
- 单独记录物体角度的环形差分，单位为弧度／logit；先相对零后缀包裹角位移，避免直接跨角度表示边界相减。
- 基于相同任务根状态和目标定义的固定物体位置方向及角度方向分别报告响应；不将位置与弧度混合为一个未标定分数。
- 分别记录每个后缀相对零后缀的物体位置和角度误差变化，并给出完整 21 项中的各自最大改善。两个最大值可能来自不同后缀，不代表同一动作同时改善两项；这是已观察实验后的探索性汇总，不是预注册的优势门或公平闭环选择器。
- 某条后缀因原生停止未完成五步时，相关坐标留空，不插值、不补值；记录完整端点数。

分析器要求全部 336 分支所属的 16 个分片存在，并复核原准备文件、执行 binding、输入和代码哈希与逐分片保存数据；单独保存分片报告哈希。相关 P1 和 P5 联合回归 11 项通过。这些有限幅度 secant 不是局部 Jacobian 的精确证明；同根、同动作重复和历史结果已知亦不能视为独立确认。尚不能用位置／角度响应差异替代原 P1 的完整机制与真实闭环对照。

因此，这批证据**没有支持“成功前缀使该固定局部探针的物体控制能力优于 incumbent”**；同时不能否定更大或组合后缀可能具有的能力。下一步应在不按结果挑选根、且不放宽原门的前提下，固定不同幅度和组合的共同后缀及相应公平对照，审计接触、推杆相对物体几何与物理执行；再以独立根检验机制和收益。
