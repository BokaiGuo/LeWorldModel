# 时间相关响应反馈：真实 RGB 接线与物理诊断协议

## 预先范围

将精确反馈面板中同一复合版本 `response_temporal_fixed_terminal_dev_v1`
接入冻结 PointMaze RGB 模型；选已暴露根 0，运行 response 和
smooth_cem 两臂，分别在自身实际图像反馈上规划与执行。两臂每次
决策均上限 1920 个五步预测 token；热身之后固定 15 个动作，在
0、5、10 步分别规划剩余 15、10、5 步并派发选中链前五步，不延长。
这是接线和开发诊断，非独立样本或充分基线调参，不能据此判 PC3/PC4。

## 输入与记录

继承已认证模型参数、checkpoint、normalizer 数值、摄像头和图像目标，
校验共同真实热身及全部列出的依赖哈希。仅将 RGB、RGB 推导的状态、
动作历史和目标图像提供给模型；物理状态仅用于环境初始化和事后
独立重放，不输入 planner。目标投影是模型内评分代理。

所有请求以冻结 normalizer 输入模型，实际模型动作转换为 float32；
执行也派发选中链的 float32 前五步，决策封存后才执行。记录两个
相邻图像帧、历史动作、carry、目标、时钟、模型和 normalizer 的
哈希绑定；每个请求的原始动作、float32 动作、预测输出和 token；
逐代优化分布、最终选择、弃权、未执行尾部及实际 RGB。执行末尾
检查模型参数和列出的依赖未变。模型、SVD、编码和墙钟分别记录，
不声称 token 是完整资源等价。

## 验证和限制

事先排他创建 manifest，发现已有任一产物则停止；错误或预算不足不
更换任务、不覆盖或追加。对全部决策和图像独立核对计量、被评分
选择、carry 重新评分、实际派发及时间顺序。然后对封存动作使用
同场景原生后端重放，记录固定终点物理距离与完整轨迹，并与原 RGB
执行数据分列：未经逐状态对齐不能声称物理状态逐位重现。

开放环 E0 机制见证与本次 RGB 分属不同任务、输入和轨迹，不能拼成
同链证据。报告原始开发结果，无论正负；来源独立性保持 unknown，
不把预测代理分数、单根或两臂结果宣称为门槛通过。
