# 原生相机动作后果对照：开发合同

使用本地官方 XML 构造与 MuJoCo 2.1.2/mujoco-py 路径，不通过图像变换模拟相机。
固定已暴露 archive episode 1880–1883 的帧 0、5；帧对作为两个真实状态，不宣称接触侧对照。
每状态执行 zero、+x、-x 三个动作，幅度 0.1，五个环境步；每环境步五个物理步，执行前速度限制 [-5,5]。
保留原始速度，故零动作不要求静止。

两个视角：lookat=(3,2.5) 和 (3.5,2.5)，azimuth=90、elevation=-90；其他相机参数保持默认并记录。
这是相机平移，不是透视旋转，也不宣称训练分布内。
每条动作链从完全重置的相同模拟状态分别运行两个视角，逐时刻保存 RGB、qpos/qvel、物理时间及接触信息。
在相同动作下要求两视角物理轨迹绝对差 ≤1e-10，render 前后物理状态完全相同，图像至少一个像素不同。
完整根、状态和动作分母都保留，不能按物理成功挑选。

本阶段仅认证真实相机与物理后果解耦；不将真值送入视觉规划器。
冻结模型评分、未查询动作预测和搜索利用须另行绑定模型、预处理、动作时钟及评价合同。
若物理对照失败，先调查模拟器/渲染状态；不得据此下视觉模型结论。
