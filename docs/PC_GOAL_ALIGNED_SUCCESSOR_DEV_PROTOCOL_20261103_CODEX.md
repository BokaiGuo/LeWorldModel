# 目标条件化多方向后继搜索：开发协议

## 假设与范围

旧多方向响应函数的 `target` 只用于检查维度，方向由右奇异向量和奇异值
决定，目标只参与后续候选评分。此处检验更具体的假设：在同一有效响应
子空间中，将一个方向旋转到 `Jᵀ(target−center)`，是否改善自动候选
生成和可利用的非即时程序；不预设该设计更优，也不称旧方法为 bug。
这是新版本、独立开发协议，不重开按规则停止的旧构造。

## 算法及对照

对于每个首段/后继名义动作，用原来的 21 次五步/十步有限差分预测
构造 `J`，按原 `1e-10` 阈值确定最多两个有效奇异方向：

1. **goal**：令 `g=Jᵀ(target−center)`。若有效秩为二且 `‖g‖>1e-10`，
   在两个右奇异向量张成的动作子空间中构造单位 `g` 和与其正交的单位
   方向；其他情况退回有效右奇异向量。保留 zero、各方向正负扰动和
   原 `0.5/maxabs` 幅度及动作裁剪。旋转不增加候选数或调用预算。
2. **svd**：同一响应矩阵和有效秩，不旋转原奇异方向，作为直接消融。
3. **random**：同一响应计算与秩、共同候选数，从固定种子生成同秩
   正交动作方向。该控制为匹配生成结构而支付响应计算，不是可跳过
   响应成本的最高效随机方法，不能用于成本公平的普遍结论。
4. **full-CEM**：直接搜索完整十五步二维动作，使用全部预算；无响应
   或 SVD 费用。

前三臂均复用原版本的最佳加最远父和后继留存、每个十步组合的共同
floor-CEM、全动作联合精修、全局已评分 incumbent 与 zero-prefix
比较；以完整链终距选择，不强制选非即时动作。各臂固定 480 个五步
预测 token 上限，所有生成、分支、搜索及比较调用计费，SVD 和运行
时间另记；full-CEM 可使用其全部预算。各臂同根同程序阶段采用相同
优化种子，随机方向单独固定种子。全动作约束与反馈条件相同，此次仅
首次 15 步精确状态规划，不声称同版 RGB 或反馈。

输出候选、响应、目标残差、方向、所有请求与 float32 实际模型输入、
预测、完整链、预算及弃权；逐批重放并验证最终已评分最优。24 个已暴露
Wall 开发根，每根每臂一次，计划及审计排他创建。分别报告终距、
`<0.05` 成功数、逐根差和算力轴；四臂与根配对，不计算独立确认。
计划事前固定的 24 根与 480 预算，不追加根、种子或选择有利版本。
结果若无必要机制或收益则停止此单配置；若有线索须对最终实际链做
共同后缀、相同预算自行规划和后继响应干预。PC2 与 PC3 分开，随机、
ordinary lookahead 和强规划器仍需要充分开发与独立认证。
