# 多方向开发版：统一决策接口与重放合同

该接口统一已存在的多方向 `v1` 首轮和剩余时域反馈路径，不创建新的
科学正式方法，不复活已停止的单配置，也不将不同算法的结果拼接。
目标对齐和零空间构造未接入此版本；`v1` 首段响应实际上只使用
target 的维度，不能声称方向由目标条件化。

输入为根编号、决策索引 0–2、二维目标投影、可调用的合法模型预测器、
上下文标识及上轮计划的未执行尾部。模型预测器接受 `[N,T,2]` 原始
规范化动作并返回 `[N,2]` 投影位置和 `[N]` 评分；T 限于 5、10、15，
原始动作域 `[-1,1]`，一包 5 步，评分越低越好。目标、观测、模型、
normalizer、历史、时钟和来源的真实性由调用方构造并独立认证；
上下文标识只是绑定标识，不是合法性或数据来源证明。

接口在实际调用边界统一计数完整 prediction call、样本和五步 token，
每个决策上限 480 token；分别记录算法 SVD 次数和内部时间，不将其
合成总成本。初始调用执行既有后继组合编译器；后两轮执行既有反馈
编译器。输出实际选择、五步派发片段、剩余尾部、未改写核心结果、
逐批请求与 float32 动作、模型响应、计量、核心源码哈希及上下文
标识。输入不合法或预测响应非有限立即失败，不做静默裁剪。

验证先使用已封存的 4 根 × 3 次 RGB 决策逐批轨迹喂入，核对每次
提案、响应、评分、完整选中链、carry、弃权和 token。原决策未记录
实际目标投影，而当前 v1 只检查目标维度；轨迹回放使用零向量作为
二维占位符，**不能**认证目标来源或目标条件化。逐批原动作严格
匹配才消费封存响应；任何不一致立即失败。还需用精确动力学开发
预测器做实际端到端多轮执行检查，并在来源未知时保留 unknown。
这仅为接口及确定性轨迹等价，不是独立物理、视觉或 gate 证据。
