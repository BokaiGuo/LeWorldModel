# TwoRoom 数据帧与重渲染输入：固定动作决策核验

在已暴露的 10 个开发根上，固定每根原 656 条合法动作；分别输入数据集 current/goal RGB 和由同一记录状态重渲染的 current/goal RGB。每臂使用相同冻结模型、动作 normalizer、批大小 32 和推理路径，不读取物理后继作为规划输入。

两种输入分别重新生成并编码各自 RGB 字典，并对各自完整候选池预测；字典弃权时回退该臂原 latent 评分。报告输入差异、字典有效性及模板集合、预测代价最大差、top-30 集合交并、原评分及字典选链身份、距离分数前两名间隔。模型重新评分和此前封存分数的数值差也单独报告，以免将设备或批次差异误当输入效应。当前和目标重渲染使用评价端状态恢复；只作为合同诊断，不供正式 RGB-only 规划器访问状态。

记录模型权重及输入、候选、脚本哈希，检查模型前后冻结。结果仅定位当前输入扰动下的数值和决策稳定性，不声称官方协议等价、物理收益或任何 gate 通过；不对已停止选择器的效果重新作准入裁决。
