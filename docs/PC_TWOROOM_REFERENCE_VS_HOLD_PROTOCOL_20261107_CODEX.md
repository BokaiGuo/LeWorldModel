# TwoRoom 参考动作与保持动作的预测—真实对齐协议

固定此前 seed-42 的全部 50 个参考行。每行候选为数据集 25 步参考动作和 25 步零动作，不按模型分数或物理成功筛选。每条动作序列必须有限且属于 `[-1,1]`；按连续 5 步打包，保持实际环境时间一致。零动作在先前逐根边框检查中均未造成初始位移；仍逐步实际执行并报告结果，不假设后续物理行为。

先将数据集当前 RGB、目标 RGB 和两条合法动作封存，再用冻结 RGB TwoRoom LeWM 和现有动作 normalizer 预测两条链末端表示与目标代价；预测及模型指纹写入后，才进入物理评价阶段。对每个候选从同一数据初态、目标和默认环境几何重置，执行满 25 步，记录逐步距离和成功，保存真实末帧；真实末帧和目标经同一冻结编码器评分。分析时每根分别比较模型分数、真实编码分数、物理末距离对两候选的排序，以及参考动作与保持动作的任意时刻成功；平局显式记录。

参考动作来自数据集，仅作为评价端可解见证和固定候选诊断，不是合法部署规划器的候选生成来源、不能宣称实际规划收益。该面板已经用于开发与 normalizer，不能作独立确认；环境默认几何与数据生成配置尚无完整权威认证。预测—编码排序不一致是表示与评分复合差异，编码—物理距离不一致是评分失配候选，两者均不单独证明某个代码错误；统计单位为任务，50 根完整保留。模型使用 RGB、目标图像和合法候选动作，不读取物理状态。全部结果属于离线诊断，不改判 PC gate。
