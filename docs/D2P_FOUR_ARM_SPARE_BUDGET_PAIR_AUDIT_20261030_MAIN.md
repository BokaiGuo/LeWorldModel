# 追加优化为何未改变四臂执行：已知根配对诊断

对旧 hook 与新 spare-budget 两次真实 CUDA 运行中 native-style、
random 的八个反馈节点，核对了根、目标、动作域、历史、模型、
优化器及配置的合同哈希；每对初始候选与未追加优化的候选
2–7 也逐字节一致，后者模型评分完全一致。

八节点中，接受两次额外迭代的 16 个候选全部发生非零动作更新，
其终态 latent MSE 全部下降；更新后的最优追加候选仍比节点
赢家高 0.0753 至 0.5435，因此没有被选中。这个结果支持
“优化生效但不足以改变排序”，而不是“优化没有接上”的解释；
该检查不保证反向图正确，也不证明 latent 评分对应物理任务。

所有完整 task 哈希不同，不能简单宣称整个任务输入逐字节一致。
本诊断只断言列出的合同身份字段和候选数组相同；历史哈希、
目标等一致并不能替代对所有运行时输入和执行事件的独立证明。
源数据均为同一已知根、同一动作链上的探索，不是独立样本或
公平预算、P1 通过的证据。
