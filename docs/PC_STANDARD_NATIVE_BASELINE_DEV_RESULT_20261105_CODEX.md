## 约束与后续

- 本地 PushT 结果说明低预算压力集的零成功不能代表这里的原配置；它不消除既有候选覆盖和预测评分选择问题，也不证明 Planning Compiler 增量。
- 相同数值 94% 不能自行证明与论文版本、任务和实现一致。checkpoint 键映射、本地环境／库版本、归一化及数据来源仍需比对；本地评价数据还被用于拟合 normalizer。训练集排除、normalizer 排除和确认面板来源尚未认证。
- 入口从有效行采样而非保证 episode 不重复；代码 `choice(len(valid_indices)-1, ...)` 排除了最后一个有效行，是可定位的抽样范围偏差，但尚未证明影响此次指标。应单独做修复与配对对照，不追溯改写本次结果。
- 运行期间出现 Lance fork 风险提示；TwoRoom 还有 Gym observation 类型提示。运行已正常结束，提示不是实际错误证明，仍需检查后端与并发行为。
- 原生输出只保留聚合结果、逐任务成功布尔和视频，未完整记录动作、每步状态及任务 ID；PushT 行号在上面补记。需新增可审计记录和参考重放后才能支持完整复现。
- 本地默认 Reacher 数据文件 `datasets/dmc/reacher_random.h5` 未找到；本轮没有替代其他数据。JEPA 官方原配置、多个独立 seed、标准面板来源、规划器公平对比、真实反馈机制和 PC0–PC5 均尚未完成。
