# v22 fixed-bank successor-response retention development result

All four preregistered roots completed. For each root, the ten v22
first-layer candidates received the same three 120-sample suffix CEM
starts. The best final distances across the full candidate banks were
0.500281, 0.500395, 0.500345 and 0.500256. None of the five fixed
retention strategies, nor any sampled full-bank continuation, achieved
the existing `<0.05` success threshold.

Response/ridge retained the all-bank sampled best on roots 0 and 2;
greedy did so on roots 0, 1 and 2. Differences are small and no
practically meaningful effect threshold was preregistered. This does not
establish either a response-retention benefit or the nonexistence of a
successful continuation; suffix-search sufficiency was not established.

After sealing the panel, a separately specified privileged geometric
constructor produced two legal, successful 15-step witnesses on each of
the four roots (8/8); both implementations of the same environment agreed
on their endpoints. These witnesses establish task feasibility only and
were not available to any planner or selector. They do not establish that
the generated prefixes have feasible continuations.

Per root, candidate generation used 1,918–1,920 prediction tokens;
all-candidate response probes used 1,230, lookahead 720 and suffix search
10,800. These are diagnostic costs, not an equal-total-resource method
comparison. The saved-action audit checked all trajectories with alternate
same-environment geometry, recomputed selectors and outcome accounting;
an additional audit checked exact finite-difference inputs for all 40
candidate probes. This is not independent replication.

The four-root protocol has reached its stopping rule. Do not rerun or
retune this panel. Artifacts, audit and probe-input audit:
`le-wm-main/results/pc_v22_response_retention_fixedbank_e0_dev_20261104_codex/`.
