# RGB CEM 已评分样本保留：开发协议

目的：检查已有 RGB 单帧 CEM 在采样阶段是否丢弃比最终均值／旧尾更低分的合法完整链，以及该选择变化的真实执行后果。最低预测代价不预设意味着较好控制，已有其他选择消融结果不被覆盖。

在已暴露 PushT 接触根 0、1、8、9，白色外观 side=+1 上，使用原目标 RGB、冻结 LeWM、原动作 normalizer、单帧历史、每次三包十五步、两轮各 32 样本和 8 elite；根的随机流为 `4200 + root`，沿用原反馈规划器。对同一次候选生成记录全部 64 样本、最终均值和旧尾的实际分数；旧选择为最后两项低者，新选择为 66 条已评分链中的最低分（稳定先后顺序）。两者共享全部模型查询和候选，不增加搜索预算；候选的预处理、裁剪、归一化和随机流不可改变。

评分进程仅打开固定初始图像、目标图像、模型和动作 normalizer，不读取物理标签或后继；评分完整封存之后，评价进程才读重置状态，独立重置并各自执行两臂选中链，最多 15 环境步，遇终止或截断停止。记录逐步动作、奖励、成功与隐藏状态；同时报告首 5 步及最终负距离奖励，完整重放验证。选中链归属、同候选预算、动作合法性及模型分数单调性必须审计。

这是固定开发面板、首次开环的选择消融：根是配对统计单位；没有正式显著性或 Gate 门槛。只有模型分数降低、但物理后果混合或更差时，不能据此改成新默认；需要实际执行各臂才能解释。该实验不是行动后果描述增量，也不是 PC4 完整反馈或独立确认。
