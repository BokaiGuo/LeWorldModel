# PushT 接触目标参考条件化混合候选：评分开发协议

两根固定为上轮已筛选、连续 warmup 的本地验证序列 9、11，同样的历史、目标和 15 步时域；来源独立性未知。目的仅为在同一接触目标下，观察物理成功候选存在时冻结模型预测评分和真实后继编码评分如何排序。

**特权边界：**本面板 32 条候选由该目标的真实参考后缀逐帧扰动构成，仅供评分诊断，既不进入正式规划器，也不能支持自动发现、未查询动作预测、预算内 oracle 或 PC2–PC5 声明。参考后缀本身不加入候选。两根此前已经被选择和观察，结果不是独立确认。

每根固定 64 条：索引 0–31 为上轮已执行的独立固定库前 32 条（含零动作）；32–47 为参考后缀逐坐标独立均匀噪声 `[-0.015,0.015]`；48–63 为 `[-0.15,0.15]`。每根以 `default_rng(2026110710 + sequence)` 生成，噪声加到 float32 参考后缀后裁剪到 `[-1,1]` 并转 float32；候选不得等于参考或彼此重复。噪声和数量事前固定，不根据实际成功数调整。所有候选保留，无成功时如实报告。

独立库前 32 条复用已封存物理状态和真实 RGB；其余 32 条从原始记录第 0 帧启动、连续 warmup 到第 10 帧后执行，以避免中间帧重置；目标和 RGB 历史逐项与来源一致。预测 worker 对 64 条全部预测后再读取真实后继图片。逐根及各子库报告物理成功数、预测／真实编码首选成功、首个成功排名、成功与失败候选评分排序；报告每根而非把候选当独立任务。成功使用联合位置 `<20` 与周期角 `<π/9`；目标及候选中心范围单独报告。若动作碰撞或评分失败不能删除数据；应保留记录，标记无法判断。

不训练模型或 readout，不改变旧数据和 gate。模型误差、编码评分失真、候选分布和目标条件化作用须分别讨论，不能将本面板结果拼接成规划优势或独立泛化。
