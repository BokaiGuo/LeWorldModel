# V5 PushT 单根真实 RGB 反馈开发协议

延用已暴露训练档案 episode 0、诊断目标、冻结 checkpoint、公开动作统计、15 条真实暖身命令、五动作一个 packet、官方相对动作环境及逐步可见性 guard。以未修改的 v5 response 核心替换 v4 的 response 臂，不额外重复先前双起点 CEM；固定 15/10/5 剩余步与每轮 1920 预测 token，每轮封存选择后执行五条动作并使用自身新 RGB 和历史重编译。若 guard、终止或异常触发，保留失败及部分轨迹，不补造动作。

前置核验 v5 四个保存上下文逐 packet 审计和来源绑定；捕获本协议、适配器、核心及依赖哈希。实际执行全量逐步事件、候选、时钟、RGB 和状态另存，状态仅用于独立评价，不输入生成与选择。事后同模型显式 packet 重算以及同后端逐步动作、状态和 RGB 重放，报告官方成功和物体位置、角度，不将 latent MSE 作为真实控制指标。

这是旧根的新版本开发诊断，不是独立确认或接触重配置机制实验。动作统计与 checkpoint 训练来源未知、token 不等于全成本；不凭本根决定追加根或改变历史规则。
