# 多样性前缀后的响应生成与联合精修：开发协议

事前固定，使用既有八个已暴露精确 wall 开发任务、33 前缀库、状态多样性保留规则和已存筛选封存；精确状态是特权开发工具，不声称 RGB-only 或自动发现前缀。每根 8 个封存前缀分别产生一个后缀初值，再使用完全相同的四参数联合 CEM 精修完整链。最终从完整链终距最小者选择，保留所有精修前 incumbent，不按机制资格强选。

每个前缀的名义后缀参数固定为 (0,.5)。goal 和 ridge 分别以 eps=.01 对二维后缀参数估计终点响应（名义一次、四次中心差分），对目标残差使用目标相关首谱模态或无 SVD 全响应阻尼岭解（lambda=.001），更新最大分量限制为 .5、裁到合法域；另设最大奇异值模式、random 方向和无响应 nominal 对照。random 用确定性种子，既不调用物理特权见证，也不白白支付响应开销。

各臂计 33 次前缀筛选（实际计算成本遵照旧执行方式），对每个生成初值实际 rollout 一次；响应臂再计 8×5 次。总全链评估上限分别 1145 和 2169，剩余平均分给 8 前缀×2 轮精修，余数顺序分配；所有臂、同根共享优化随机种子。缓存旧筛选而作为各臂 33 次计费。分别报告 SVD、岭解和时间，不称等硬件成本。计划执行期只用精确模型，不读原物理成功索引或解析后缀。

保存所有候选、完整动作、优化样本与得分、原始状态和总调用；对实际选中完整链记即时距离和普通固定后缀对照。无 greedy 前缀独立重规划的结果不能称完整 PC2 见证。该协议是新开发实验，不能改判原 E0 负结果或旧停止规则；不构成独立 PC3 或 RGB 结果。
