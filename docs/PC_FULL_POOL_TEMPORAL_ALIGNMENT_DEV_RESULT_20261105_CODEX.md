## 预测、真实图像编码与物理后果

对每臂确定性的事后代表：模型分数最低链、成功链中最低分、失败链
中最低分和最终选中均值，按 0、5、10、15、20、25 环境步对齐。
物理重放状态与完整池普查一致，目标图编码与采集的目标表示之差
平方和约 `1.49e-11`；物理标签只用于评估，未输入规划器。

模型预测和真实编码存在显著数值差异，但不能直接归因动力学：
**采集的初始模型像素与数据轨迹图完全相同，而与按物理状态 reset
后重新渲染的图像不同**。预处理后 150528 个元素中 19656 个差异
超过 `1e-6`，平均绝对差约 `0.01031`，最大约 `2.84271`；初始
预测／真实编码平方距离约 `0.23470`。物理状态一致不等于初始图像
一致；该差异的具体视觉来源尚未定位。目标输入一致也不消除初始
观测差异。严禁据此宣布已单独分离模型动力学误差。

代表链由实际成功标签事后挑选，仅作诊断；未评估整个池的真实图像
编码。采集的输入含评估端物理状态等敏感字段，仅用于审计，未馈送
规划器；未改变动作选择。模型指纹与此前开发诊断一致。
