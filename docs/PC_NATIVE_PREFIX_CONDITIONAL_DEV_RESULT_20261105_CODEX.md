# 前缀条件化尾部：固定 reset 开发结果

按 `PC_NATIVE_PREFIX_CONDITIONAL_DEV_PROTOCOL_20261105_CODEX.md`
执行单任务 smoke、合成测试和固定 reset 的 seed 42、50 任务开发。
所有方法均为每轮 300 条完整链评分，末轮返回分布均值；评测物理
初始化使用共同的显式 reset seed。

| 方法 | 成功 / 50 | 原始 evaluation_time（秒） |
|---|---:|---:|
| 原生 CEM | 47 | 29.43 |
| 前缀条件化尾部 | 44 | 37.64 |
| 尾部响应共享给两个前缀 | 43 | 37.72 |
| 内部响应替代 | 42 | 38.80 |
| 匹配随机方向替代 | 43 | 37.76 |

条件化相对共享尾部有 1 个仅条件化成功、0 个仅共享成功；对原生
有 0 个仅条件化成功、3 个仅原生成功。只有一个已暴露 seed，不能
据此推断总体差异或非劣效；时间不含初始化，不是完整资源核算。

条件化臂 640 个环境迭代的日志均为 300 次全链评分，两个前缀对应
方向符号共出现 448 次分歧，组合候选进入 elite 1058 次；这些是
搜索过程计数，不是最终链依赖该机制的证明。共享对照也进行了
同数探针，只在第二前缀构造时复用第一前缀的符号；两臂一旦模型
更新不同，不再是相同候选池。

3 项针对性测试验证了等评分数、初始共同探针、生成链保留对应前缀、
非有限值拒绝与非法时域拒绝；真实 smoke 只证明可运行。该原型
用全链评分间接依赖预测后继，并没有缓存或单独核验后继 latent。
未证明最终链非贪心或同链干预机制、没有强全链优化和独立泛化；
不声称 PC2/PC3 通过，也不据此排除其他组合设计。

## 开发随机流扩展

固定物理 reset 后，按扩展协议得到：

| 方法 | seed 42 | seed 43 | seed 44 |
|---|---:|---:|---:|
| 原生 CEM | 47 | 42 | 38 |
| 前缀条件化尾部 | 44 | 43 | 39 |
| 尾部响应共享 | 43 | 43 | 41 |

每格为 50 任务。条件化相对共享的仅一方成功数，三个 seed 分别
为 1:0、0:0、0:2；相对原生分别为 0:3、1:0、3:2。
四个新增条件化／共享日志的每轮评分数均为 300。其间有并行单元
测试，扩展实验墙钟未做隔离，不用于成本推断。
这是已知开发随机流，任务与优化随机 seed 仍耦合，不能视为独立
任务泛化或稳定收益；真实执行动作合法性仍需单独核查。
本地数据的行抽样复核显示，每个 seed 的 50 行各来自 50 个 episode；
seed 42 与 44 共享 1 个 episode，42 与 43、43 与 44 均无 episode
交集。因此这三个开发面板不能作为严格 episode-disjoint 的三份确认集。
