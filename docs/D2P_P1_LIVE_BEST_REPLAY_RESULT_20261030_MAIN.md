停止标志）一致。两者各有 2 条原生成功记录，均为根 0 的 zero

实际观测另列。

断言所有在线部署都等价。第一包来自既有固定规划结果，不是本次
现场从头编译的完整 D2P。消费器复用了既有物理生命周期检查，
模型调用计数由代码路径声明、没有独立 hook 验证；前一 latent
未独立封存，动态来源闭包、FLOPs 和强基线总预算未知。因此不
证明 P1 机制、独立泛化或公平规划优势。
