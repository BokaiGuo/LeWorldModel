# 精确墙障：候选间触发时序打乱诊断

已有 24 个任务、受阻脱困和固定时刻盲脱困结果均已曝光。本协议在
新臂运行前固定，是开发集上的事后机制消融，不是独立确认。

将已保存受阻臂的每条候选 15 位触发时序作为诊断输入，在同一 root
内按候选索引模 4 分组，分别以 `20261107 + root` 随机排列来源。
四组分别保持原侧向和半径类别。结果精确保留每组触发次数与触发
时序的联合分布，但打乱其与 waypoint 的对应；可能出现原候选被分配
到自身的情况，完整记录置换，不作结果依赖的重抽。

对新臂，照原实现的先执行动作，再以动作前朝向及动作后位置计算
侧向目标，仅将条件从当前预测受阻替换成分配的触发位。其他控制、
候选、终距选择和预算不变。先用各候选原触发时序重建原臂并逐动作
核对，再对打乱臂验证动作界限、逐链重放、触发分布和计数。每臂每
root 为 384×15 动力学步；构造时序所需的原臂运行和重放额外计数。

按 root 报告成功（终距 <0.05）、配对独胜独负和平均终距；不在此
已曝光面板新增事后门槛。打乱时序来自同任务原臂，因此不是可免费
部署的盲控制器，也不能代替独立任务、强搜索器或正式行动后果描述
对照；原时序与其新轨迹的实际碰撞不必一致，触发次数按组而非每个
候选匹配。
