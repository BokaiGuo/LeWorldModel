# V4 与双起点 CEM：PushT 真实 RGB 闭环开发协议

预定本地 HDF5 第 0 episode 初始状态、最初 15 条记录动作暖身，以及 packet 合同既有固定诊断目标；来源是公开训练档案中的已暴露根，非独立任务。环境使用官方 `swm/PushT-v1`、relative action、224 RGB、五条物理命令一个模型 token。实际目标图来自 reset 返回的官方图像，并由单独环境重渲染校验，不从 planner 内读取物理状态。公开动作均值/方差仍属未认证的 checkpoint 训练约定。

两臂各自从同一初始条件和相同 15 条暖身动作重建：不变 v4 response 与既有零链/自身旧尾双起点 smooth CEM。每臂固定 15/10/5 步剩余时域、每次 1920 prediction-token、实际执行前五个命令；真实 RGB 更新后再重编译。三帧为当前边界及紧邻前两边界 F1/F2/F3，动作历史为 A0/A1/A2，模型使用 A1/A2 与未来 packet；后续按实际历史滚动。记录规划前已封存决策、完整候选轨迹、图像与动作历史、旧尾重评、时钟及预算；冻结模型参数和 buffer。

每物理步先经既有 canonical RoyalBlue 可见性 guard 检查新图像；可见性缺失、提前结束、裁剪或异常时停止该臂并保存部分失败轨迹，不补造后续动作。物理 `state`、官方成功和物体位置/角度只由评价记录使用，不进入模型、候选、选择或 guard。固定终点不延长；每次决策的未执行尾部必须保存。

运行前绑定选定数据行哈希、checkpoint、代码、物理合同收据；各臂、决策、图像和步骤事件排他保存。事后同后端重放及参考预测重算，明确覆盖范围。该单根、已暴露、训练来源未知的开发实验不能证明 PC3/PC4/E3、独立泛化或接触重配置机制；prediction token 相等不代表总计算相同，不以结果决定追加根或修改规则。
