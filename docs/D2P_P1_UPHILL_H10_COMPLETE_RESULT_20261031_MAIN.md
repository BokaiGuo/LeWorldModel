## 相同后缀：物体响应与推杆响应须分开

以 selected 减 zero 前缀、每臂 41 个非零共同后缀为描述对象，
采用事后 `1e-6` 容差。对 root 0 的每个逻辑臂，有 40 个可比较
固定终点、1 个提前停止不可比较；40/40 的物体位置与角度响应
差均在容差内，但原生联合 XY 响应差为 20 个负、20 个正，说明
不能称所有物理响应都相同。

对 root 1，位置响应差按每臂为：off 条件各 1 负、20 平、20 正；
on 条件各 0 负、20 平、21 正。位置绝对终点在 off 条件每臂
1 个更低、40 个更高，在 on 条件每臂 41 个更高。角度响应每臂
1 负、20 平、20 正；联合 XY 响应每臂 11 负、30 正。负号是
selected 的相应误差或响应变化更低，不自动等于机制通过。

后缀、逻辑臂和部分动作共享两个已知根，以上是面板描述，
不是独立样本数、统计显著性或对全部动作的结论。共同后缀仅
说明指定动作效果，不等于各自可规划能力更强。对真实 cp5 RGB
共同四起点 Adam，selected 原生成功 0/8、zero 5/8、greedy 0/8；
记录可能重复，前缀成本及总预算未认证。其他零／暖初始化与
中点反馈结果见长表，暖初始化非对称，不能混作公平基线。

该面板没有建立预定的非即时进展、真实任务相关能力改变及
独立公平收益合取；也不能证明理论不可能。下一步是使用真实
RGB 重算新预算轨迹的同动作预测—观察分解，并以完整账本及
未按 outcome 挑选的新任务检验候选生成与选择规则。P1 保持关闭。
