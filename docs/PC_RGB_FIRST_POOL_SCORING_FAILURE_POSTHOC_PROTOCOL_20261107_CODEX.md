# RGB 首轮固定探针池：成功与评分分解（事后）

在已曝光的 40 个 TwoRoom 任务上，只使用已重放、且同时具有模型
预测和真实末帧编码的 3 前缀 × 3 探针链。排除初态已成功的任务
后，逐任务比较：池中至少一条链曾经成功、模型末帧目标分数最小
链是否曾成功、真实末帧编码目标分数最小链是否曾成功。也按末帧
是否成功分别报告，分数相同按原始平铺索引选择首项。

真实末帧编码只作为评价端反事实，不得输入部署规划器；上述最小
模型分数只针对这九条链，不是包含原始父链和后续尾部的真实规划器
最终选择，也不能推出闭环成绩。三项指标都以任务为单位，不把
同任务候选当独立样本。池无成功仅限该九链子集，不代表全搜索池
无解。列出每任务动作索引与成功标签，校验数据和来源哈希；不修改
已有数据、停止规则或 gate。此协议在本次计算前编写，但输入已经
曝光，故不是事前注册或独立确认。
