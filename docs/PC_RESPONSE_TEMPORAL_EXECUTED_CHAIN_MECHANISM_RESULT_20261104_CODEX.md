# 时间相关反馈：实际执行组合链的机制诊断

按[事后诊断协议](PC_RESPONSE_TEMPORAL_EXECUTED_CHAIN_MECHANISM_PROTOCOL_20261104_CODEX.md)，
对已封存的全部 24 条响应臂反馈轨迹，将三次实际 float32 派发的五步
动作拼接，并从原精确状态重新回放。所有组合链的终态均与封存反馈
终态一致。使用实际执行的后十步作为共同后缀，重新完成五类前缀、
各自 120 链搜索及后继响应差分。

非零非即时前缀为 **3/24**；共同实际后缀的相对零后缀变化与等预算
自行重规划都优于 zero 和同库 greedy 的交集为 **2/24**，同时优于
随机反馈臂与平滑反馈臂首包的交集仍为 **2/24**（根 0、21）。

| 根 | 起始距离 | 实际首包后 | 实际闭环终距 | 自行重规划：selected / zero / greedy |
| ---: | ---: | ---: | ---: | --- |
| 0 | 1.00499 | 1.26520 | 0.00076 | 0.20694 / 0.50618 / 0.51247 |
| 21 | 1.00499 | 1.17271 | 0.00236 | 0.03698 / 0.50303 / 0.50197 |

根 0 的实际后十步相对各前缀零后缀的变化为 selected -1.26444、
zero -0.49150、greedy +1.25282；根 21 分别为 -1.17035、+1.11851、
+1.14623。根 0 selected 的后继响应矩阵与 zero、greedy 的差分别为
0.7693、1.1125；根 21 两项均约 1.3365。其他固定共同后缀和完整
矩阵见原始记录，不能据此声称所有后缀都优于对照。

这比继承未执行的首轮尾部更准确地描述了**实际执行链**，但存在重要
限制：该协议在反馈结果揭晓后制定，实际尾部依赖后续观测与重规划，
不是独立事先固定的后缀；24 个任务已暴露。额外自行重规划不是原
闭环方法的预算。结果是精确动力学的事后开发机制线索，不是 PC2
独立确认，也不是 RGB、PC3 强基线或泛化证据。

每个控制 146 次诊断 rollout，五控制、24 根共 17,520 次，额外计费；
全部 24 组干预及比较经同代码确定性重建，不是独立复现。
