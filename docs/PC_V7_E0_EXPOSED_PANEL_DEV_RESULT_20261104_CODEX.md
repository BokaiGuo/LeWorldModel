# v7 精确动力学已暴露面板回归

按[事前协议](PC_V7_E0_EXPOSED_PANEL_DEV_PROTOCOL_20261104_CODEX.md)，v7 在 v5 已暴露的 18 个精确动力学开发根上各规划一次，并逐批重算全部 **13,266 条轨迹**；[结果](../le-wm-main/results/pc_v7_e0_exposed_panel_dev_20261104_codex.json)和[重算审计](../le-wm-main/results/pc_v7_e0_exposed_panel_dev_20261104_codex_audit.json)绑定。每根总资源均为 1920 packet-token，包含 v7 最终配对评分。

18/18 根的最终 float32 完整动作链与 v5 完全一致，终距逐根相同；两版本均 0/18 弃权。v7 在这 18 根中均未遇到两条配对动作完全相同的情形，因此这些根不复现 Cube 的选择标签错误，也不能作为该边界的实证覆盖。v7 搜索内部留给优化的预算较少，结果一致不证明两个算法在其他任务中等价。

这只认证同后端的已暴露面板轨迹和配对选择，不能视作 v7 的自动机制见证、强基线优势、真实 RGB 控制或独立泛化。必须以 v7 自身最终链重新计算事前规定的共同后缀、同预算重规划和任务相关响应干预；不能把旧版本的结论直接并入 v7。
