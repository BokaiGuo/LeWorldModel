# P1：真实与想象中点的匹配重规划对照

事后开发对照的 24 条固定记录均已完成主机 CUDA 规划和真实物理
执行，并通过保存态消费。两臂使用同一前缀、第一动作包、第二包
初值、20 次 Adam、约束和回退规则；第二包优化使用的中点分别为
真实 RGB 编码和模型预测。逐条校验两臂前五步动作字节、状态、
快照以及 terminated/truncated 完全一致。

唯一不同的成功记录为 index 7，真实中点臂原生早停成功；
该对没有固定十步终点差。其余 23 对均完成固定十步，所有
逐条物理指标与删失状态见配对结果。两个已知物理根和重复逻辑
臂不是 24 个独立任务，不能据此估计泛化成功率或宣称 P1 通过。
匹配结果不能支持“真实中点本身使成功从 5 降到 1”的解释：
想象中点的匹配重规划也只有 0 条成功。它提示额外后缀优化与
选择是值得检查的因素，但没有把优化过程的每个因素独立随机化，
不能证明其为唯一原因。

真实中点与想象中点每条规划代码路径分别记录：
encoder 2 与 1、predict 22 与 23、action encoder 22 与 23、
backward 均为 20；这不是全流程等 FLOPs 认证。模型参数和缓冲区
重规划前后哈希一致。规划运行设备为 NVIDIA GeForce RTX 5060 Ti
CUDA，冻结模型未训练。
