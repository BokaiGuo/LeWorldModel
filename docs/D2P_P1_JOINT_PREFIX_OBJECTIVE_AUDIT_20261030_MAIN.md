# P1 联合优化前缀的目标与物理即时进展审计

## 结论

这批 selected 前缀不能仅凭后缀获益被视为 P1 的非即时进展见证。
根因线索是**实验目标与机制目标不同**：联合优化器对整个 15 步
动作序列只最小化最终预测 latent MSE，并按该分数选择迭代和候选；
它记录前缀 latent，但没有对前缀的即时任务进展或后继响应施加
约束。代码位置为
`le-wm-main/experiments/spectral_reachability/p1_joint_prefix_suffix_cuda_20261030.py`
的 `evaluate`、`optimize` 和 `winners`。这是按既定探索协议执行的
目标设计，不是证实了实现 bug，更不是对理论不可行的证明。

依据已验收的
`le-wm-main/results/p1_joint_anchor_table_20261030_RUN01.json`，
selected 前缀相对各自根的实际误差变化如下；负值代表误差下降。
重复的同臂数据不作为独立样本。

| 根/条件 | 臂 | 物体位置 | 物体包角（弧度） | 推杆位置 | 原生联合 XY | 原生成功变化 |
| --- | --- | ---: | ---: | ---: | ---: | --- |
| 0/off | projected | -39.86 | -0.401 | -53.98 | -64.29 | false → false |
| 0/off | outward | -40.15 | -0.397 | -53.57 | -63.97 | false → false |
| 0/on | 两臂 | -53.64 | -0.335 | -60.00 | -73.14 | false → false |
| 1/off | 两臂 | -0.106 | -0.00119 | +4.36 | +3.22 | false → false |
| 1/on | 两臂 | -8.03 | -0.0972 | -5.30 | -9.27 | false → false |

物体位置、角度、推杆和原生成功必须分开看；success false → false
不意味着其他指标没有进展。root 1/off 的微小物体误差下降没有
预先确定的非贪心容差，也不能事后把它定义为无进展。
目标与根、动作和 cp5 像素在前缀表中均按固定来源绑定；该表的
作用是发现资格线索，不是独立确认。

## 对后续实现的影响

下一版候选生成需要在模型可用的观测与目标表示上**事前**定义
即时进展与未来响应的选择规则，避免无约束终态优化覆盖重配置
目的；真实物理状态仍只能用于验收，不能流入 RGB 规划器。候选
必须完整保留，固定选择规则后再执行全部事先指定对照。当前运行的
共同后缀面板应按原合同完成，不因这里的观察改变分析或门槛。

独立后缀的 20 步实验也只是比较各前缀的相同局部优化器，未计入
前缀生成的完整资源；账本注明实际用量覆盖未认证。两步与 20 步
是开发预算点，不能事后选择有利点作为确认结果。进一步仍需
真实反馈、共同资源约束、强基线和独立新根。
