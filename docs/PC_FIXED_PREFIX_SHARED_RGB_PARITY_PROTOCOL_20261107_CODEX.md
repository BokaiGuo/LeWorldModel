# 固定前缀共核 RGB 接入：工程等价协议

复用已曝光 TwoRoom root 10、11、12 的同一前三条候选作父链；按固定
种子为每根生成两条共同探针和两条尾部，各保留一个前缀。分别用原 RGB
编译器与共核 RGB 适配器执行 parent、lookahead、vector、shuffled
四种规则；输入、模型、候选和随机种子完全一致。

逐项核对三类全部模型评分，绝对容差 `1e-5`、相对容差 `1e-6`；
保留前缀、最终候选身份、动作字节与逻辑评分次数必须相同。每条运行
11 次逻辑评分；两次实现各自计费，不把重复计算当单臂性能。检查
checkpoint 前后指纹及 RGB 收据，记录所有结果与来源哈希。

这只是软件等价与权限检查，不重开已停止的向量配置，不测物理成功、
不作为 gate 证据，也不支持 JEPA 与 LeWM 模型输出等价。
