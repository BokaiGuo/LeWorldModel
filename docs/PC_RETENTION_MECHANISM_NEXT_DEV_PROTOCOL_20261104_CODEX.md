# 两种保留准则的同链机制开发面板

目的：固定前一开发比较的 ridge 与 probe_min 两个配置，在原 E0 Wall 任务族上比较最终链，并对每臂自动选中的最终链做事前确定的共同尾部与等预算重规划。独立根只用于配对单位；任务族、模型、调参均已开发暴露，不能视为 PC3 独立确认。本协议不是完整科学 gate 的放宽。

任务固定为 `start=(-0.5,y,theta)`，`y∈{-0.195,0.195}`、`theta∈{-0.97,0.97}`，`goal=(0.5,gy)`、`gy∈{-0.1,-0.03,0.03,0.1}`，共 16 根。执行前检查不与此前窄束、ridge/probe 及明确列举的相关面板完全重复；精确去重不证明分布独立。两臂配置同上一轮，seed `2032500000+root`，全局候选、生成、截断、保留、联合精修及弃权保持，2880 prediction-token 封顶。先全部计划、记录、审计并封存，再执行任何干预；失败不替换，分母固定 16。

每个精修和弃权后的最终链，构造 selected、zero、same-bank greedy、ordinary-lookahead、random 五种前缀。greedy 为首层即时分数最优；ordinary-lookahead 对首层同库每个候选以及 zero，使用零尾及四结点 CEM（初值评分 1 加 119 后续评分，公共 seed `2032600000+root`）独立优化十步尾部，取最小实际终距，平分按固定索引决胜；该选择另行计费，不得当作免费。random 为固定种子的四结点随机前缀。对所有前缀使用相同六条共同尾部（零、四条预定常量、最终选中尾部），并从零尾三次独立四结点重规划（每次 1+480 次评分），各前缀使用相同随机种子。各阶段动作、预测和真实预算分别记录。实际链尾的 20 坐标、0.01 和 0.05 两尺度采用边界感知差分和逐坐标分支记录。

开发期、预定严格光滑诊断，所有条件必须在同一最终链成立：selected 首五步非零且末十步非零；selected 前缀的即时目标距离不小于初始距离减 `1e-10`；对 zero、greedy、lookahead、random 每个对照，selected 的实际共同尾相对各自零尾改善严格大于该对照至少 `1e-10`，且三次重规划平均绝对终距小于该对照至少 `1e-10`；selected 与每个对照在两尺度的完整尾部端点割线矩阵及目标距离梯度的欧氏/Frobenius 差均大于 `1e-6`；selected 和全部对照的所有坐标、两个尺度的扰动分支均与各自名义分支一致。梯度未定义则不通过。数值容差沿用旧诊断，不是实际效应阈值。报告每项、基础 zero+greedy 交集及全部对照交集，任何规划/干预失败保留为未认证；不能由单项或不同链拼接。

对非光滑区域，另报告实际共同尾部下 selected 与各前缀的碰撞阻塞序列是否不同及对应可执行动作的绝对终距、相对零尾收益和重规划分布；这只是有限干预的描述，不称作 Jacobian、因果分支机制或 PC2 通过。共同时出现分支差异和收益仍不足以排除其他变化。最终报告 token、实际墙钟及分支重放；后者和控制选择/干预成本不与正式规划混算；并行缺少全系统 GPU/内存计量需明确。

原停止面板及阈值不重判；本面板是开发机制筛查而非独立确认，连续指标、失败及分母全部呈现，不能因阳性挑根、挑尺度或修改协议。现有四结点见证检出率有限，未检出不等于不可行；三次均值也未被最佳检出率校准。本面板不替代 PC0、PC1、强基线、真实 RGB 或来源认证。
