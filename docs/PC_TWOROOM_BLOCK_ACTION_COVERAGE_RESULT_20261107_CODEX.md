# TwoRoom 分段动作覆盖：RGB 开发结果

依照[事前协议](PC_TWOROOM_BLOCK_ACTION_COVERAGE_PROTOCOL_20261107_CODEX.md)，
在同一冻结 RGB LeWM、同一 10 个已曝光任务及 25 步动作域下，
每根评分 300 条五步分段常值随机链，并与原来 300 条 CEM 候选的
最优已评分链比较；各臂实际选中的链随后在环境中执行。

| 指标 | 分段随机生成 | 原 300 次 CEM |
| --- | ---: | ---: |
| 25 步内曾成功 | 9/10 | 7/10 |
| 第 25 步成功 | 8/10 | 7/10 |
| 配对独胜／独负 | 2／0 | 0／2 |

原完整 656 条已评分链均无成功的三个根，额外重放新生成的所有
300 条链，分别有 **14、5、7** 条曾成功；规划器选择的链在前两根
成功、第三根失败。这同时显示新的覆盖信号和剩余的选择损失；
第三根的事后候选池成功不等于规划器成功。

实验达到本次固定的开发出口。候选重建、原 CEM 选择、全部 3,000
条 GPU 分数及动作哈希核查通过，分数最大重算误差为 0；三个失败
根的原 CEM 选链与既有完整池轨迹完全一致。审计使用同一模型和
物理后端，未独立重新实现环境。相关生成器和 RGB 权限测试
**19 项通过**。环境继续输出 Gymnasium 观测类型／转换警告。

本结果的增量来自**候选生成**，不是行动后果描述、bridge 保留或
程序机制证据。10 根及相关既有结果均已曝光；每根只有一个预定
随机流，原 CEM 不代表充分调优的最强基线。每臂均评分 300 条，
但 CEM 分布更新、预处理、模型加载、环境执行等完整成本未对齐。
分段臂同步评分与选择平均约 0.122 秒，不是端到端时间。原始计划、
物理轨迹、汇总、审计位于
`le-wm-main/results/pc_tworoom_block_action_coverage_20261107_codex_{plan,physical,result,audit}.json`。

该信号支持继续以同样动作合同测试生成器，并与强 CEM 及普通
lookahead 公平比较；不能因此宣布任何 PC gate 或独立闭环通过。
`experiment-design` 用于预先固定候选、基线、真实覆盖及停止规则。
