# 固定候选诊断：特权前缀检出能力校准

对已暴露并停止的 16 根束宽面板，读取事后物理几何见证，每根取前两条成功见证的前五步，丢弃见证尾部；不足两条时如实记录未知与根的分母，不替换任务。此特权前缀只用于检验尾部求解诊断的灵敏度，绝不进入正式规划器。

对每个前缀固定四次逐步 CEM 重启，每次 121 个完整链样本，batch 12、4 精英。第一重启的初始化和 CEM 种子与响应／随机固定机会诊断完全一致；其前 49 次样本为当时的单起点机会。其余重启使用预定的独立随机初值和独立种子，每根内对两条前缀共享随机流。事前报告嵌套检查点：`1x49`、`1x121`、`2x121`、`4x121`，分别为每前缀 49、121、242、484 样本。第一个检查点与原诊断优化机会一致；后续不是原来“相同预算”，而是额外诊断曲线，不可当作原规划的 1,920 token 成绩。

以 `<0.05` 判成功，按前缀与根分别记录检出率、平均终距、每次累计最好值和实际费用；失败保留，不换根和重跑。对原见证和其来源哈希核查，逐批持久化请求及结果；重放同环境另一几何实现、预定 CEM 提案、完整链前缀、成本与各检查点最优值。此处 `1x49` 成功检出偏低只能说明该求解器／初始化/任务族的灵敏度不足，不能推出某个自动前缀可行或不可行。已暴露任务、特权前缀、同环境重算均不构成 PC0 预算内 oracle、PC2 机制、PC3 优势或独立复现。
