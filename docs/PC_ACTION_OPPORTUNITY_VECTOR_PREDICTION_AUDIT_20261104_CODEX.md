# Action-opportunity full-vector prediction audit
**动作身份对照更正：** 下文的固定列反转同时作用于训练和测试数据。对具有各维相同惩罚的岭回归，这只是特征坐标重命名，预测按构造应不变；因此该对照不能检验动作身份是否有用，也不能据此推断动作身份无贡献。原结果保留；有效的身份对照需要定义会破坏候选间身份对应关系的置换，并预先控制其引入的分布变化。

日期：2026-11-04。性质：对既有 Stage-1/Stage-1b 精确动力学输出的 root-held-out 诊断；不重跑模型、不接入 planner，不是物理确认或 PC2/PC3 证据。

入口：

`le-wm-main/experiments/audit_pc_action_opportunity_vector_prediction_20261104_codex.py`

## 1. 设计

目标是预测未参与构造的 B 探针质量 `max(b_improvements)`。每个 root 留出，训练只使用其他 root 的 A 探针数据。比较：

- `scalar`：`max(a_improvements)` 加即时分数、可用的零尾分数和剩余时域；
- `vector`：完整 A 后果向量加同样控制；
- `permuted_vector`：固定反转 A 向量列身份后的对照。

该目标只是有限 B 探针质量，不是最优后缀真值、真实物理后果或独立确认。

## 2. 结果

| 面板 | scalar Spearman | vector Spearman | 反转身份 Spearman | scalar MAE | vector MAE |
| --- | ---: | ---: | ---: | ---: | ---: |
| 固定/常值-交替探针 | 0.2211 | 0.5662 | 0.5662 | 0.1080 | 0.0878 |
| 随机探针 v2（含零尾记录） | 0.7310 | 0.7923 | 0.7923 | 0.0573 | 0.0478 |

上述为 2476 个候选的 root-held-out pooled 描述；每个 root 的结果均已写入审计 JSON。随机探针 v2 已补写 `baseline_score`；原 v1 结果不覆盖。

## 3. 解释边界

完整向量在该有限 held-out probe 目标上比最大改善标量更有预测性，但反转动作身份几乎不改变结果。这至少说明：

1. 向量内部的幅度/形状信息可能有用；
2. 固定列反转是坐标重命名，无法检验后缀身份是否提供独立信息；
3. 不能把该结果解释为真实行动机会、最优后缀质量或规划收益；
4. 仍需独立后缀、独立优化随机流和普通 lookahead 的同成本比较。

因此当前仍不把完整描述接入正式 retention。下一步应在同一候选池上记录完整绝对代价向量、动作身份、零尾基线和失败状态，并用真正独立的验证库完成固定候选/等槽位和全成本两层比较。
