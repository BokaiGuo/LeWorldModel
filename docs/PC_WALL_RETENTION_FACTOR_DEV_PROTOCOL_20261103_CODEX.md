# Wall 保留策略 × 后缀搜索开发协议

预先固定，沿用八个已暴露开发任务、33 个前缀、16 步动作和原先成功阈值；不作为独立确认、视觉或谱证据。保留原结果及停止规则，不使用后验解析见证。

分别比较原 greedy、原随机、原 lookahead 和多样性保留（每种保留 8 个），与原双起点 CEM、固定分层四起点 CEM 两种后缀优化器形成因子比较。原先三种保留及原 CEM 直接复用已封存的全库诊断，核对依赖哈希；新保留列表在任何新后缀结果产生前单独封存。

多样性：从同库即时 greedy 出发，依次保留与已保留状态的最近距离最大的前缀；状态特征是前缀末的 x、y、cos(朝向)、sin(朝向)，位置除以 1，朝向分量乘 0.5，欧氏距离，平局按索引。该规则不读取目标以外的特权几何、物理最优索引或后缀结果；它是精确状态开发诊断，并非可部署 RGB 策略。

分层 CEM：四个起点的二维均值依次为 (-.75,0),(-.25,0),(.25,0),(.75,0)，每起点四轮，初始标准差 (.25,.5)，其余精英、截断和下限同原版。每前缀总采样分别为 128、256，与原优化器相同。噪声种子 2026111800+任务，所有前缀共用以便配对。原固定 11 后缀最佳值为已计费初始 incumbent。每臂选择保留集合中完整链终距最小者；保留、优化器和成功资格均绑定实际选中链。

输出逐任务、预算、保留、优化器的保留索引、已选动作、终距、成功、调用次数；分开统计筛选与实际候选续规划成本，lookahead 已用的 11 探针不重复记费。保存新优化器采样和评分，验证动作回放与源哈希。每个任务各预算属于配对重复设置而非独立任务；额外计算不与 CEM 混为等资源。该协议仅检验两个具体实现的开发效应；不得将结果上升为 Planning Compiler 的机制或公平规划优势。
