# v9 中点残差掩码：已暴露 E0 新假设

前述分析在已暴露 v7/v8 探针上发现部分中心差分跨墙体分支，且其
输出中点残差代理在这批数据上能识别已观察到的分支切换。本协议在
看到该分析后固定，因此不是独立确认：仅检验遮蔽不稳定列是否改变
原 v7 完整搜索的开发行为，不声称估计导数或真实接触分支。

复制冻结 v7 算法为独立 v9，不修改 v7。对每个原有 21 点 FD 批次，
仅用预测输出计算每个坐标的
`||p+ + p- - 2p0|| / (||p+ - p-|| + 1e-8)`；
当比值严格大于 0.5，将该坐标响应列置零，再用于模式、局部价值、
后继响应多样性和候选生成。保留未修改矩阵、掩码及原始预测；不读取
墙体、状态、干预标签或物理最优。已有预测样本重复利用，不新增 forward；
如果秩为零，保留 zero 候选，最终由同一完整链评分和弃权规则决定。
保留 v7 相同其他配置、随机流、1920 token 和成对最终比较。

对封存的相同 18 根首次决策运行一次；逐批重放预测、独立重算掩码、
计数 token，比较 v7 和同预算 CEM 的终距及严格成功数；并记录多少根、
多少后继响应以及多少被保留候选受掩码影响。结果不佳不重复调阈值；
该暴露集比较非独立确认。若要声称 PC2 必须在最终选择链上另运行
共同尾和同预算重规划机制干预；真实 RGB、PC1 和 PC3–PC5 均未由此证明。
