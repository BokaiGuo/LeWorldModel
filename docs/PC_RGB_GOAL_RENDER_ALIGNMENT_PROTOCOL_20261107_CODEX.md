# TwoRoom 目标图像与环境目标状态对齐诊断

复用已曝光 episode 9000–9039 和上一轮共同探针记录。对每个任务，以相同 reset 和状态设置重建环境起点及目标；记录数据集起始帧/目标帧与相同物理状态下重绘帧的 RGB 差异、预处理后差异及冻结编码差异。状态向量逐项核对，像素接近不能替代状态认证。

在已封存的物理探针和预测/真实后继编码上，分别使用原始数据目标图、环境按相同目标状态重绘的目标图，计算相同 latent 代价与动作效果方向，比较物理距离效果。真实后继与重绘目标只用于评估端；后者由环境目标状态生成，属于 privileged 反事实诊断，**不能输入 RGB-only 规划器或宣称闭环性能**。

统计 40 个任务图像对齐和 35 个完整前缀任务的原/重绘目标评分；动作、状态、前缀和物理结果不变。目标外观差异不自动证明代码错误：本地 reset 场景参数也可能不同于数据集生成条件。该面板已曝光、无显著性预注册，不改变任何 gate。
