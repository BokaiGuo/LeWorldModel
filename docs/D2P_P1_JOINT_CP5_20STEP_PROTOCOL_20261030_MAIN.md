# 联合前缀的 20 步共同优化器预算探索

在已观察两步优化结果后，对同一 24 前缀盲输入、同一零初始化、
同一有界梯度优化器固定 20 步、步长 0.05，比较较大局部规划
预算是否改变计划。所有前缀均使用同一规则，不按物理结果筛选。
此预算是事后提出的开发探索，不是预注册确认；每行上限为编码
一次、两包预测每更新一次及最终重放，prediction/action encoder
各 42 次、反向 20 次（上限与实际应分开），不将不同资源相加。

仅对冻结模型在主机 CUDA 优化动作，记录真实账本与输入哈希；
随后须固定完整动作名单并真实执行。前缀生成成本、完整账本覆盖、
OS 隔离及整体等预算尚未认证；不得仅用模型评分声明物理收益或 P1。
