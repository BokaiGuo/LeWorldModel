# 合法接触就绪对照：开发结果

协议：`PC_GEOMETRIC_CONTACT_EQUIVALENCE_DEV_PROTOCOL_20261106_CODEX.md`。

## 已完成

16 个预定几何根、左右两个接触就绪初态、两种背景、三个动作，共 192 条五步轨迹。全部根通过无穿透、1 像素初始间隙、零动作稳定、向内动作触发 agent–block 接触及背景物理一致性检查。独立重放全部轨迹，初末 RGB 逐像素一致，状态在绝对容差 1e-9 内一致。保存特征重算的目标代价与模型日志一致。两个相关测试文件共 7 项通过。

旧 pilot 的 8 个白背景初态中 **3 个存在穿透**。因此旧 pilot 不能认证合法稳定的左右接触对照；历史结果保留，不追溯替换。

## 结果

白背景 32 个状态条件（属于 16 个根，不是 32 个独立任务）：

| 指标 | 结果 |
|---|---:|
| 接触轨迹 / 全部轨迹 | 32 / 96 |
| 零动作接触轨迹 | 0 / 32 |
| 模型选择与物理最优的 argmin 编号相同 | 1 / 32 |
| 模型选择的平均物理遗憾 | 0.242684 |
| 真实编码选择的平均物理遗憾 | 0.220419 |
| 零动作平均物理遗憾 | 0.264949 |
| 背景变化的模型动作效应 MAE | 1.157891 |
| 背景变化的真实编码动作效应 MAE | 1.805243 |
| 背景变化的物理动作效应 MAE | 0 |

物理代价为预定的物块位置与周期角误差，不是标准任务成功率。遗憾相对该状态三个动作中的最低物理代价。argmin 编号会受并列影响，因此不能将 1/32 直接解释为成功率；连续遗憾是更稳妥的描述。模型代价与物理代价单位不同，不跨列比较效应大小。

追加并列审计（原始 index 审计保留）：以物理遗憾 ≤1e-9 判为并列最优，模型为 **25/32**，真实编码为 **26/32**，零动作为 **24/32**。原 1/32 只是 argmin 编号一致，不是可靠的动作选择准确率。模型相对零动作仅在 **1/16** 根平均遗憾更低，其余 15 根相同；全部平均改善来自根 9。故不能从总体平均值推出稳定收益。该容差为事后统计纠错，不追溯充当实验通过门槛。

## 决策与边界

初始化缺陷得到具体定位并在新版本中修正，但修正后仍存在预测、真实编码评分与物理后果的差异。不能把全部负结果归给旧初始化，也不能把小幅平均遗憾下降宣布为规划优势。三动作直接评分属于普通 lookahead，本实验没有建立描述超出 lookahead 的增量。

背景不是相机。左右状态是无穿透的**接触就绪**状态，不宣称初始持续接触。几何开发根不是来源合格的训练外确认。PC0–PC5 不改判。
