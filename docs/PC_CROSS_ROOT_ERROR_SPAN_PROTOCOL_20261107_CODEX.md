# 跨任务误差跨度：探索性可用性诊断

沿用 10 个已曝光 TwoRoom 根的 8 前缀 × 8 条同动作 B 尾部，预测分数和真实编码目标分数来自既有封存数据。定义每根 `e = 预测分数 − 真实编码分数` 的全部 64 个值的跨度 `max(e)-min(e)`。这对共同分数偏移不敏感：若某根的误差跨度不超过 `R`，两个前缀的预测机会差大于 `R` 就能保证该有限候选集上真实编码机会排序一致。先用合成测试验证不等式和共同偏移不变。

固定根 0–4 与 5–9 两半，互换校准和评价角色。每次使用校准半边每根误差跨度的最大值作为经验阈值，在另一半仅用预测分数选择最低机会前缀并计算其与第二名的间隔。阈值只来自其他根的真实后继；评价根的真实后继和物理轨迹在选择封存逻辑之后仅读作离线评价。没有向模型训练新网络或读取评价根未来物理状态作为规划输入。

完整报告两折校准阈值、每个评价根是否被阈值覆盖、是否触发“间隔大于阈值”、触发与未触发的编码机会排序和物理结果；同时给出所有根的普通模型最低分选择作为简单对照。标明每根 B 全部 64 条已评分，候选与结果先前均已曝光，校准和评价也是事后分析。五个校准根不提供分布无关的高覆盖保证；未证明任务或训练来源独立，任何阈值都不能直接投入正式闭环或当作 PC1 通过。
