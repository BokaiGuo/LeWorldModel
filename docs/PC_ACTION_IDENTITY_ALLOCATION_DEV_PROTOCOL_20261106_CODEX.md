# 固定前缀行动身份对照：开发协议

本协议在查看新增描述结果前固定。复用任务 15、25、35 的既有 12 前缀、
A 库及 B 库和等机会优化的模型与物理结果；所有数据均为已暴露开发集。
恢复原种子生成共同 A 库 8 条尾部，并核验每个前缀 A 最低及平均代价
与原结果一致，否则中止。

对每个前缀，将 A 尾部展开为 30 维，分别减去 A 样本均值，并将成本
减去对应前缀 A 平均成本。以固定岭系数 1.0 拟合线性行动—代价关系：
`w = X.T @ solve(X @ X.T + I, centered_cost)`。描述的保留分数为
`mean(cost) - ||w||_2`，越小越优；此分数表示以单位正态尺度探索的
线性乐观估计，不是物理成功概率，也不是训练后的模型。对照包括
父链成本、A 最低成本、A 平均成本，以及对每个前缀独立打乱 A 分数
和动作的对应关系后按同一公式得到的分数；打乱严格保留该前缀
的八个分数和动作各自的集合。固定随机种子 62001+任务编号。

每臂保留 4/12 个前缀；完全复用每个前缀事先已有的 B 最优链与
三轮等机会优化链，汇报覆盖的真实成功链数和至少一条真实成功的
任务数，另报告模型代价及选择集合。B 库及物理后果不进入打分。
B 最优链作为后续优化起点是评价端共同额外机会，不可用于声称该
策略已实现部署成本或端到端增益。任何分数为零或没有成功均照实记录。
单次打乱及 3 个任务不足以确定统计显著性或通过 PC1–PC3。
