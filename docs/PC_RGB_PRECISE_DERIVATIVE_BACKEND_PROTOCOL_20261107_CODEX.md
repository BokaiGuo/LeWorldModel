# 纯视觉动作导数精确后端回归

事后修复验证：复用已曝光的 24 个封存任务方向和原实验确定的相同投影，float32 下通过局部 `precise_action_derivatives` 上下文同时禁用 cuDNN/matmul TF32 并启用 math SDPA，重算 JVP、VJP、三个尺度有限差分；沿用上次开发判据，原实验失败不改写。逐样本对比原结果中的前向与导数，以及模型权重和输入指纹。检查调用前后 TF32 状态相同。

此验证不是新的统计确认，不代表部署正常推理后端处处等价；后端标志是进程全局状态，不能与依赖其他精度的并发调用混用。评估只针对 RGB 模型数值，不建立真实后果、规划收益或 gate 通过。
