# v3 固定终点精确闭环开发协议

在执行前固定：在此前已暴露的 24 个 Wall 开发任务上，运行 v3 的
response、matched_random、smooth_cem、action_cem 四臂，各臂从同一
初始状态独立运行 15 个物理动作，在第 0、5、10 步分别规划剩余
15、10、5 步并实际执行选中链的前五步。每决策最多 1920 个五步
预测 token；真实计量全部预测，不将其等同总计算成本。v3 根据所有
已评分完整链选择联合精修起点，精修后再作零前缀比较；基线沿用
既有实现。结构、完整链、carry、每批请求与 float32 实际输入、
预测、选择、物理派发、最终状态均封存。

事前指标：实际终距平均值、终距 `<0.05` 的根数、各臂 token 及
响应臂相对每个对照逐根胜数。描述性开发比较，不据此宣称 PC2 或
PC3：这些任务已暴露，基线只有单套配置，尚无独立来源、统计合同、
充分的梯度及消融对照。结果可正可负，不据结果继续追加根。

独立审计逐批重算精确端点、评分、计量，验证反馈 carry 与实际派发；
每个响应及随机臂的联合精修起点必须是精修前全部完整链评分最小值，
最终选择是包括弃权比较在内全部已评分完整链最小值。核对实际
重规划产生的轨迹，而非将原未执行尾部视为轨迹。随机数规则和其余
编译细节由封存的 v3 代码指定；依赖与协议哈希进 manifest，输出
排他创建，错误、已有产物或依赖变化均停止，不修改历史面板。

这次不进行同链机制干预；反馈链的共同后缀和同预算重规划需要另立
事前协议，且不能借用 v1 的机制资格。真实 RGB 与独立 checkpoint
亦未在此协议中完成。
