# P1 真实 RGB 中点动作信赖惩罚：开发对照

上一轮发现真实中点重规划丢失部分原生成功，直接失败判据常为推杆
和物体联合位置距离超限。本轮在看到该结果后固定一个开发方案：
维持 24 条同一前缀和第一包，第二包从原后缀初始化，冻结模型的
目标 latent MSE 加上 `0.1 * mean((action-original)^2)`，Adam
学习率 0.05、20 次更新、动作投影到 [-1,1]。原后缀与优化后缀
以同一正则化目标比较，取分数较低者。规则只使用真实 RGB、
模型和动作，不使用模拟器状态；权重是事后开发选择，不是
预注册确认，也不是物理成功保证。

24 条规划在主机 CUDA 完成，冻结权重和 buffer 前后哈希一致；
24 条物理回放全部完成并通过保存消费。与原开放计划逐槽核验
前五步动作、状态、完整动力学快照和中点 RGB 均一致。RGB 中点
来源于封存轨迹，后续通过物理重放验证一致，不称现场在线规划。

原开放计划 5 条成功记录；加惩罚后 2 条成功，均为 zero 前缀、
均对应原有成功，其中一条原始无惩罚重规划未成功。原始五条含
根 1/on 的重复轨迹，不能视为独立样本；此已知根探索不能证明
信赖惩罚的总体优势或机制。两侧均有未删失终点的 19 条中，
信赖版物体位置、角度、推杆误差分别有 8、9、8 条降低；提前
停止及第十步原生停止的固定终点依原合同保持空值。

此规则能改变已执行的方案，但仍未恢复全部开放成功，更未证明
selected 前缀的能力变化或优于公平强基线。原开放与信赖版计算
预算不同；本版每行额外显式路径计数为编码 2、预测 22、反向 20，
未做完整 hook 与总资源认证。训练数据 normalizer 来源仍待核验。
