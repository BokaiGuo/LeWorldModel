第一个前缀与旧 zero **动作字节完全相同**，cp5 状态、完整物理
快照和 RGB 哈希均相同，独立 Adam 后缀哈希也与旧 zero 相同；
其成功是同一 zero 动作链的重复，绝不是新的重配置成功。后两个
逻辑槽的前缀和后缀相同、结果重复；其旧 zero 对照曾原生成功，
不能把这两条未成功记录当作两个独立样本。具体比较仍须对齐
删失与旧结果的来源限制。

原多样性连接器允许零前缀进入所选结果：它确实在既定候选和模型
评分规则下被选中，但单靠“与旧 selected 字节不同”不足以证明
发生重配置。这是候选选择／解释层面的缺口，不是模型理论被否定。
新增 [数值非平凡性审计](../le-wm-main/experiments/spectral_reachability/p1_prefix_nontriviality_20261030_main.py)
明确将正负零都识别为零，并保留非零不等于机制成立的边界；三项
测试通过。该审计未改动历史选择器或实验门槛，后续若把它接入
选择器，必须冻结新规则后重新验证，不能事后宣称已有实验通过。

已新增一个独立开发版
[非零选择器](../le-wm-main/experiments/spectral_reachability/p1_nonzero_diverse_selector_20261030_main.py)：
四个事先给出的候选中数值零前缀不进入重配置选优，若无非零候选
则弃权，其余按原正则模型分数及原索引稳定选优。正负零均识别
为零；三个选择器测试通过。对既有已知面板的事后复算
`le-wm-main/results/p1_nonzero_diverse_selector_20261030_main_RUN01.json`
SHA-256 `b3630b27e4cf077ab14540b759ba9ac08be03577597dcaa2933fac4e83670da8`：

把零动作当重配置的选择缺口，并未产生该槽新的非贪心候选，也
没有新的模型推理或物理验证。不得将事后复算当成独立确认。
