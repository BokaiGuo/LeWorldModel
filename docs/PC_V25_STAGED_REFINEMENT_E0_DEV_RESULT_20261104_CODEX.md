# 两阶段精修预算分配：端到端开发结果

依照[事前协议](PC_V25_STAGED_REFINEMENT_E0_DEV_PROTOCOL_20261104_CODEX.md)，16 根新开发任务、两个 token 上限、四臂共 128 次规划完成；两阶段策略在对应的 64 次运行均实际启用，而非触发预算不足回退。

| token 上限 | 方法 | 成功根 | 平均终距 | 精修完整链样本／根 |
| ---: | --- | ---: | ---: | ---: |
| 1,920 | 窄束 v25，均分 | 1/16 | 0.3872 | 294–304 |
| 1,920 | 窄束 v25，两阶段 | 2/16 | 0.4048 | 294–304 |
| 1,920 | 共享 CEM，均分 | 3/16 | 0.3683 | 573 |
| 1,920 | 共享 CEM，两阶段 | 2/16 | 0.3528 | 573 |
| 2,880 | 窄束 v25，均分 | 4/16 | 0.3056 | 614–624 |
| 2,880 | 窄束 v25，两阶段 | 1/16 | 0.3489 | 614–624 |
| 2,880 | 共享 CEM，均分 | 4/16 | 0.3555 | 893 |
| 2,880 | 共享 CEM，两阶段 | 5/16 | 0.3268 | 893 |

以 `1e-12` 为相等容差，两阶段相对均分：响应臂在 1,920 为 2 优、1 平、13 劣，在 2,880 为 5 优、0 平、11 劣；共享 CEM 分别为 5 优、0 平、11 劣和 8 优、0 平、8 劣。平均值和成功数并不总与多数逐根变化方向相同。结果不支持将此两阶段策略默认替换 v25 均分策略；它也不是响应独有能力，因基线获得了同一优化器。

两阶段改变了优化随机流与重新评分开销，因此这是完整分配策略对照，不能将差异单独归于晋级排序。两个预算点是同一组 16 个任务，不是 32 个独立任务。当前任务的声明预算下可解性、广义来源独立性和完整 GPU／编码成本未认证。

已审计逐批请求、token、共同全局候选、另一同环境几何、完整链最优选择及优化分配的确定性重放；相关预算、incumbent 和基线接线测试通过。重放不是独立复现。结果未建立自动选中链的 PC2 机制，也不是 PC3 强基线独立确认；不能据此断言理论失败或代码无其他问题。
