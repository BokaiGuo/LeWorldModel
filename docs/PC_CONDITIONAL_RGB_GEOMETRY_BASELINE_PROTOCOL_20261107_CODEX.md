# 条件尾部面板的 RGB 几何基线开发协议

目的：在已曝光的 TwoRoom 条件尾部面板上，检验已有的任务专用 RGB
几何规则是否是比两种条件尾部 CEM 更强的开放环参照。此前几何实验
使用不同的构造面板；本实验不是独立确认，也不是描述组件消融。

固定 roots 20–49、各自已有起点和目标 RGB，使用既有修复后的
`candidate_pool`，不重新调参，选择索引 1（零偏移、增益 1.0）并
封存完整 25 步动作；解析失败必须记录弃权，不能利用物理状态修复
或遗漏分母。动作生成只读图像，不读取环境状态或后续物理评价。

之后独立阶段重置到对应数据行的初态和第 25 步目标，逐步执行已封存
动作，完整记录 25 步的距离、终止与截断；同原记录，主指标为 25 步
内曾终止，另报最后一步状态。与既有 endpoint 和 temporal 各臂配对
比较，报告各臂独胜、独负、弃权及总成功；后两臂沿用旧物理轨迹，
不声称两种方法有同模型查询成本或相同搜索机会。

输入、源结果、运行器、协议和动作封存哈希绑定；不得覆盖已有产物。
此几何规则手工使用 TwoRoom 门位置和动作尺度，若性能高，仅支持它
作为本环境参照，不能证明世界模型、后果描述或其他任务的增益。
这些 roots 和候选规则已经曝光，不能把本结果视为预注册独立检验。
