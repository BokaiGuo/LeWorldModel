# P1 新前缀：真实中点反馈重规划

使用已验收多起点实验的全部 24 条轨迹及原后缀动作；不按成功、
预测误差、前缀角色或停止结果筛选。每条轨迹原后缀的前五步均
已执行且不在这五步内早停。读取该真实中点 RGB、原 cp5 RGB 和
原历史动作，保持原第一包不变，在真实中点用固定单起点 Adam
（初始化为原第二包，20 次更新，学习率 0.05，逐项限制 [-1,1]）
重规划五步。比较原第二包与更新后的模型分数，严格更低时选
更新后的动作，否则保留原动作；同规则作用于所有角色。

主机 CUDA 规划不输入模拟器状态，冻结模型。随后从原根真实重放
全部轨迹并验证前五步动作、状态、图像与原实验一致，然后执行
新第二包；报告原生成功、停止、物体位置/角度及推杆等指标。
相同首五步可以排除前缀及第一后缀包变化，但本设计的反馈同时
增加真实中点编码与优化，不能独立归因于观测刷新，也不满足
全流程等预算。该实验使用已知根和事后方案，不能打开 P1。
