# PushT 有界 CEM：动作合同开发协议

目的：为后续公平比较提供一个从生成、模型评分到执行都一致的
物理动作域合同；不将该新求解器称为未经修改的原生 CEM。
先用训练数据 action 的非 NaN 行计算与原生一致的 StandardScaler。
将物理 Box [-1,1] 换算到标准化动作域，留 1e-6 内缩量以防
浮点逆变换越界。对每条 CEM 样本**在模型评分之前**投影到该域，
且基于投影后的候选更新分布；输出均值必须也处于相同凸域。
动作块按原有相邻两个坐标排列，所有时刻均适用同一边界。

明确报告投影样本的比例与物理逐步执行动作；额外约束改变了
候选分布，因此它与历史原生结果分开。相同任务 seed 42、reset
seed 771001，求解器 seed 42、1042、2042；每次 300×10，
完整动作 trace；不可把未有对应边界的其他方法当成严格公平对照。
真实执行出现任何越界则合同失败，不能事后排除该案例冒充通过。
先测试边界变换、评分前投影与输出合法，再运行面板。
