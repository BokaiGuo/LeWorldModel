# 条件尾部选中链的预测与真实时序对齐

对已曝光 TwoRoom roots 20–49 的两臂各自封存选中链全部评估，不筛成功案例。先以原规划输入、冻结 RGB LeWM 和合法动作重算 0、5、10、15、20、25 步预测表示，验证预测目标分数与原记录（绝对误差上限 0.005），并将预测和动作哈希封存。随后从原物理初态重放相同链，核对每一步距离、终止和截断与旧记录一致，在各五步边界采集渲染图像；使用同一冻结编码器计算真实编码及目标编码。

记录预测表示、真实表示、目标表示、逐时刻模型与真实编码目标代价、预测—真实特征均方误差、物理距离和成功状态；同时记录原规划数据图与重置渲染图的像素差，不把图像接近当作隐藏状态一致。比较各 root 内两臂预测排序、真实编码排序与物理距离排序，以及 root 38 的五个时刻。真实重编码是评价端信息，不进入规划器或事后重选。

该面板与两臂选择均已曝光，且两条链高度相关；结果用于失败分解，不代表随机样本或 PC1–PC5 确认。历史预测若不能复算或物理轨迹不一致则停止，不将生成结果登记为成功对齐。
