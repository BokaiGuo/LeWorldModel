# 双轨输入权限：实现与小样本合同

主轨 `primary_rgb`：仅 RGB、目标图像和合法动作历史。辅助轨 `official_state_assisted`：允许官方 PointMaze JEPA 的 RGB + proprio；本地数据路径中 proprio=state，字段为 x,y,vx,vy。冻结权重不等于纯视觉。辅助轨不得支持第一篇 RGB-only gate 晋级。

新实验通过 `experiments.pc_input_permissions` 调用模型；旧脚本不修改、不自动获得认证。Python API 白名单不是恶意代码安全沙箱；进程/文件访问隔离和完整闭环权限认证仍需单独完成。

实现阶段：
1. 输入审计绑定权重、配置、预处理、normalizer 数据与运行代码。逐调用记录张量形状和哈希。
2. 缺失轨道、缺失必需输入、未知输入、跨轨道证据、依赖漂移一律拒绝；不填补 proprio。
3. 冻结模型、同权限比较；缓存包含轨道与输入审计。科学状态初始 not_evaluated，不能从接口运行通过推导科学通过。

首轮 smoke 在运行前固定：
- B：此前几何 PushT 根0、白背景、左侧接触就绪，zero/plus/minus 三条链。只读取图像与公开预定动作，初始历史沿用该开发协议显式空历史占位；不声称真实多帧历史认证。
- A：此前 PointMaze 相机面板第一个状态、两视角、zero/plus/minus 三条链，使用各自当前完整 proprio。5个环境步打包为10维归一化动作；上下文1帧。状态仅允许进入A。
- 两轨各自与绕过封装的同模型直接调用比较，容差 atol=1e-5、rtol=1e-5。记录有限性、形状、输入收据与权重前后摘要。
- 本地 JEPA 包装器和 DINO 加载存在兼容路径：绑定实际源码；权重不改，不将其称为已认证官方实现等价。

这只验证接口封装与数值保持，不是描述、搜索、控制、独立确认或跨模型性能结果。PC0–PC5 不改判。进一步算法开发按描述→保留→组合顺序，完整查询计费，同轨道公平对照。
