# 固定上下文未查询尾部：探索性开发协议

在固定 reset、seed 42 的既有 50 任务开发面板，仅首次规划的第二轮
比较两个现有候选前缀，保持原有条件化求解器及 A 探针和 top-k。
在选出 top-k 后，用独立随机流生成四条合法动作参数空间的共同
有限幅度 B 尾部，并对每个前缀额外评分原父链与四个 B 后缀；
每个环境多 10 条完整模型评分。B 及其分数不得参与候选生成、
排序或分布更新，测试运行须验证该隔离。这里“合法”只指遵循
现有模型动作参数接口，并不认证逆归一化后的物理动作合法性。

预先报告每对前缀按父链成本、A 最小成本、A 相对父链改善
对 B 最小成本或 B 相对父链改善的配对排序一致、反向和并列数。
两类目标分别代表绝对质量及相对改善，不拟合新读出器。
B 的方向、评分均不用于规划，独立于 A 随机流；但与 A 同为
随机有限幅度单步方向，仅检验近邻模型评分上的样本外关系，
并非真实后果、独立优化或更宽动作分布泛化。

日志记录父链、A、B 每条模型代价及额外查询成本；不使用 B 做
候选选择、调参或成功率筛选。样本内前缀和 episode 相关，开发
统计不视为独立确认；此实验不测执行成本、合法物理动作或 PC gate。
结果文件必须独立，禁止覆盖旧运行。
