# 重选前缀的独立后缀规划开发实验

使用重选 H10 固定名单的全部 24 个前缀：各自由真实五步 RGB
观测刷新上下文，同一冻结 checkpoint、零初始化和同一优化器，
分别优化十步后缀。固定 20 次梯度更新、步长 0.05；不使用物理
结果挑选前缀或规划输入。模型和 buffer 必须保持不变，神经
推理只在主机 CUDA 上执行；随后仍需执行全部物理动作。

这是已观察候选和旧结果后的开发探索，不是独立确认。三角色
共享相同后缀优化约束不意味着包含前缀生成成本的全流程等预算；
分类记录实际编码、预测、反向次数及耗时，不混合计数。规划器
输入仅含 RGB、合法动作历史、冻结模型目标编码与归一化信息；
模拟器真值不得用于选择。输出文件白名单不是操作系统级隔离。
