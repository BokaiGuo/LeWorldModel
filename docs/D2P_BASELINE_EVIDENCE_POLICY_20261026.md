# 对比实验：论文报告值与本地验证的证据边界

## 当前授权与用途

用户允许并行推进对比实验，并直接引用对比论文已经报告的数值，以减少不必要的复现。引用不是本地复现，也不自动构成同协议或等预算比较。

当前研究对象仍是冻结动力学自动生成可执行动作程序，以及暂时退步、真实未来能力改变和最终任务收益的机制链。公开性能表不能替代这一机制链。

## 两条并行证据轨道

| 轨道 | 产物 | 可以支持 | 不可以支持 |
| --- | --- | --- | --- |
| 原论文报告 | 原文表页、版本、URL、数值和完整设置 | 有出处的文献性能参照；协议一致时的直接指标比较 | 本地复现、配对显著性、当前 P1 准入 |
| 本地冻结协议 | 源码封存、CUDA 收据、逐根结果、独立复算 | 对应协议下的性能、资源和机制验证 | 未运行环境或不同 checkpoint 的泛化 |

## 纳入规则

1. 优先原论文或官方补充材料；标题相似、搜索摘要、第三方转述和模型记忆均不能作为数值出处。
2. 必须记录指标定义、方向、单位、环境和任务、划分、checkpoint、观察、动作空间、执行长度、预算、评价协议，以及原文披露的种子和不确定性。缺失项写 `unknown`，不得补造。
3. `paper_reported` 与 `local_reproduction` 分列。协议不一致时标 `context_only`，不能计算跨协议提升率、加粗为公平胜出，或混入本地均值与配对区间。
4. 只有关键设置逐项核验一致才可标 `direct_comparable`；元数据不足则标 `insufficient_metadata`。资源未知不允许声称等预算。
5. 原文没有报告的失败或不确定性不能被假定为零；不得只选最有利的模型、任务或统计量。
6. P0/P1 的本地准入及科学负结果仍须相应代码、协议、资源证据；不能用公开报告绕过门槛。

## 已分派的独立工作

- GRASP / Hi-LeWM：原文报告值与协议核验。
- LeWM / PlanWAM：原文报告值与协议核验。
- 本地基线真实性：识别必须运行的等预算对照与可文献引用的部分。
- 结构化注册器：校验出处、数值与可比性，禁止混淆证据来源。

以上是已分派任务，不表示数值已核验、对照已运行或研究已闭环。
