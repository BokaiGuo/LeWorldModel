# P1 incumbent 与 greedy 的动作身份

新响应面板的 8 个 incumbent 与历史 greedy 按 logical pair 逐一
对应。核对封存输入后，8/8 的五步前缀字节、cp5 完整 checkpoint、
后缀优化初始化哈希和所选十步动作哈希均相同。随后，8/8 真实
中点图像像素哈希、现场／离线中点第二包字节及两次模型评分也
相同。验证绑定了配对分析的全部固定来源哈希。

因此，这八对是相同动作及状态的现场／离线重现，而不是八对
不同规划方法的比较；不可将它们的结果一致作为独立机制优势，
也不可把两个标签计为独立任务。这解释了先前配对表中 incumbent
与 greedy 终点物体位置误差差值均为零，不需要假设模型预测或
控制能力不同。该身份关系不涵盖 `model_selected` 候选，也不
决定共同后缀实验的整体结果。
