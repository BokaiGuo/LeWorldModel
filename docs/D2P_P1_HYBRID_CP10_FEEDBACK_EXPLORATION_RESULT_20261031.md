# 真实 cp10 反馈重规划：已知根物理配对

按 `D2P_P1_HYBRID_CP10_FEEDBACK_EXPLORATION_PROTOCOL_20261031.md`，
固定两根的前五步混合前缀和原后缀第一片段，以真实 cp10 RGB
更新上下文后，在主机 CUDA 对第二片段做四起点、每起点 20 步
Adam 优化，随后实际执行。执行第二片段前逐帧核对首个后缀片段的
五张 RGB、状态和动力学快照与原记录一致；保存态验收检查该验证
发生在第六步动作派发之前，同时检查动作字节、图像及停止状态。

这不是跨根稳定收益。根 0 的原生七维距离反而从 243.482 增至
372.941，不能将其与不含速度的物体／联合位置指标混为一谈。
此前同动作预测消融中的刷新误差改善，也不自动保证重规划成功。

每根反馈方法额外使用两次图像编码、84 次动作编码与预测、80 次
反向；这是代码路径计数而非独立 hook/FLOPs 认证。原开放方法没有
获得对应额外计算，故该比较不是等预算。两根均为已知开发根，
不能证明独立泛化、重配置改变真实能力、强基线优势或 P1 通过。
原混合前缀本身已有即时推杆／联合任务进展，不能据此声称满足
针对完整任务的非即时进展判据。
