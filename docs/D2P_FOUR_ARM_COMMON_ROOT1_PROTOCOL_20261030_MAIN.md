# 四臂共同优化器：第二已知根物理探索

固定使用既有来源包第 1 个根、其历史和目标，不按任何结果选根。
四臂沿用 root0 的相同候选生成方法、共同后缀优化器、四次 RGB
反馈时刻和逐节点计费规则；每臂各自执行动作和更新自身历史，
执行上限 20 步，记录原生成功及未完成分支。主机 CUDA 执行，
模型冻结，独占 prepare 和输出，并使用现有 GPU 合作锁。

本实验针对已知根的探索，不是预先盲选的新根确认；以往动作和
结果已见。结构化初始化与其他臂工作量不同，共同上限不代表
等成本；native-style 不是认证强基线。不同臂自行优化后缀，
不替代同后缀机制干预，不打开 P1 gate。来源或 root/history
精确回放不通过则保留失败，不修改封存输入。

## RUN01 结果

主机 CUDA 与物理执行完成，四臂均通过各自初始状态、动作历史和
动力学快照的精确守卫，均执行 20 步，原生成功均为 false；16 个
控制节点封存，报告无错误。结构化、native-style、随机、即时
进展四臂的末态物体位置误差依次为 56.303、89.524、48.248、
30.311；对应物体角度误差为 0.104、0.697、0.857、0.985 rad。
这些指标不能代替包含推杆位置的原生成功判据，且不同指标排序
不一致；不构成胜负结论。

保存检查独立复核 16 个候选 trace 哈希，选中优化后第一动作包、
节点 receipt 和记录的实际动作字节一致；范围仅限该接线及运行
报告／journal 文件哈希，不等于完整物理事件和资源覆盖验收。
启动器对应的两项根编号和桥接测试通过；测试不证明根输入端到端
身份，运行时原有精确守卫提供额外检查。
