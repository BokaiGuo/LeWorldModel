# P1 最佳迭代信赖惩罚消融：开发合同

在已知结果后开展单因素开发对照：对 24 条固定的原始前缀、首包、
真实 RGB 中点与原后缀初值，保持冻结模型、[-1,1] 动作边界、
学习率 0.05、20 步 Adam、最佳迭代选择和停止检查不变，只将目标
中的信赖项系数从 0.1 改为 0。按模型纯 latent MSE 选择 0 至 20
步中的最优动作，平分保留较早迭代；不使用物理状态作为规划输入。

全部行主机 CUDA 规划、实际物理回放与保存消费；将动作和中点
绑定到 journal，保留全部停止、删失和拒绝。逐槽比较信赖最佳迭代
版本，分别报告物体位置、角度、推杆、联合位置、原生成功与实际
资源。与先前无惩罚仅末次选择的报告对照最终迭代分数，用于核查
代码路径是否一致。结构计算与完整资源没有在本实验中重新认证。

本研究是在两根已知面板已有结果后设计的开发探索，存在重复轨迹；
不是独立确认、P1 机制或等预算强基线证明。结果可以为负，不按
结果选择实验行、不改变或覆盖历史实验。
