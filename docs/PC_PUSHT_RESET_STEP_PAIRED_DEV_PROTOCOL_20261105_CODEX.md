# PushT 中间帧重置漂移：配对开发诊断

上一轮在序列 9、11 观察到，`reset_to_state` 的额外物理小步可能导致 agent 初始位置偏移。本诊断检验这一具体原因，不能回溯宣称旧实验已经修复。

对两个序列的 `t=10..24` 共 30 个记录状态，配对使用同一个已有后端、相同记录动作：

1. 标准 `reset_to_state`；
2. 同样 reset 后，将 agent 位置和速度重新设置为所记录值，调用后端 `reindex_shapes_for_body`，不推进额外模拟步，再执行相同动作。

比较两种模式的 reset agent 位置误差、一步后 agent 与物体位置及周期角误差，保留每个配对。只更改新诊断中的状态准备，不修改原环境或已冻结实验。物体速度、角速度、接触缓存仍不可恢复；位置纠正不保证原完整动力学状态，也不等于合法 RGB 闭环初始化。基于记录状态的干预只用于评价，不能作为正式规划输入。报告差值而不根据观察结果设置通过阈值；本实验不证明评分或规划优势。
