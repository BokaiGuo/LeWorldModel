# 结构化前缀：固定共同十步后缀干预

使用已封存的 16 行中的所有 14 个真实 cp5 可用前缀；两行前缀
越界不补 cp5、不替换候选，留在 16 行分母。每个可用前缀使用对应
历史 logical pair 的 42 条既有固定十步后缀，包含零后缀；同组的
两种前缀使用动作字节相同的后缀库。共预定 588 分支；该库与
已保存的旧 zero/greedy 面板有来源关联，不能当作新颖或预注册独立
测试，且须验证任务和根身份后才能关联旧面板。

每个分支重放并逐帧核验真实根与前缀，再执行固定后缀；原生停止
或严格证明的越界保持删失，其余工程错误停批。逐分支保存动作、
状态、RGB 和资源；消费器逐行验收。结果按绝对终态、相对各自零
后缀的变化分别报告物体位置、角度、推杆、原生联合指标与成功。
共同后缀仅验证特定动作效果，不代表可规划能力。之前的四起点
后缀独立规划另行报告，不能以共同后缀代替。

该面板对已观察的已知根为探索性续版，不按结果筛选行、样本或
后缀，不修改 P1 gate，也不声称独立泛化或全链等预算。物理执行
无神经调用；后续神经计算仍只使用主机 CUDA。
