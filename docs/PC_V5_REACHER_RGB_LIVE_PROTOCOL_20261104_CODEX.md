# V5 Reacher 单根真实 RGB 反馈开发协议

在已暴露的 Reacher 根 `20263160`，复用既有冻结模型、动作统计、环境、历史热身、目标与反馈执行器，仅将 response 臂替换为原样 v5 核心的签名适配。固定终点 15 步，三轮各规划 15/10/5 步并分别执行 5 步；每轮 1920 token，保存原动作、预测批、旧尾、选择、弃权、实际 RGB 和派发，先封存每次决策再执行。每轮只使用该臂自身真实观测历史，不用特权状态生成或评分。

运行前检查 v5 保存上下文结果和逐批参考审计绑定，绑定适配器、核心及依赖；使用既有 GPU 协作锁和新的不可覆盖输出。分别记录真实物理距离和模型 latent MSE；既有 v4、CEM 可作为暴露根开发背景，不作为独立配对确认。事后执行记录审计、同模型参考预测重算及同后端物理重放。该单根诊断不证明 PC4 成功率、PC3 优势或独立泛化，来源和全成本仍有限。
