# v22 单根未查询后缀行动后果开发诊断

在已经暴露的 v22 构造目标和原首轮合法上下文上，只评估预定动作，不重开原规划、不把物理结果反馈给规划器。选四个五步前缀：零动作、原 response 首个实际 packet、原 CEM 首个实际 packet，以及使用 NumPy `default_rng(2026110501)` 对 `[-1,1]` 均匀采样的固定五步前缀。后两条原始规划动作是已暴露开发数据，不是独立任务。

共同十步后缀为零尾、7 条构造探针、8 条验证探针；构造探针和验证探针分别使用 `default_rng(2026110502)` 与 `default_rng(2026110503)`，逐步逐坐标从 `[-1,1]` 均匀采样并转 float32。按前缀主序、后缀次序形成 64 条完整链。程序检查前缀和后缀互异，并将全部完整链和 v22 两臂第一轮原评分记录逐一精确比较；四条零尾作为基准，允许曾被查询且分别登记；若其余 60 条中有任何一条曾被查询则整项拒绝。准备阶段检查发现全零链曾被查询，故在任何新物理或模型调用前明确这项基准例外。该精确比较不证明分布或任务独立。

全部动作生成后封存；不按结果调整前缀、探针、动作或阈值。使用原物理初态及上下文，分别计算冻结模型预测、真实末帧编码和物理误差。对每个前缀分别报告构造/验证组的绝对评分及相对零尾评分、物理物体位置/角度误差、真实姿态数与成功；以验证组的逐动作预测和真实编码相对零尾改善差、同组排序和物理比较作为描述性诊断。验证数据不得进入描述构造、前缀选择或拟合。数值并列明确计数；不可计算的相关记 null。

物理回放和模型评分均为评估用途；不训练 readout、不改变任何历史结果。每条动作独立从同一已审计边界重放，记录终止、错误、末帧、末态、输入和脚本哈希。保留失败，缺项不能被算成成功。核验预测与编码 worker 的隔离输入和身份、同后端重放与数值算术；预测调用和编码费用与规划成本分开。

仅四个相关前缀、一个已暴露目标、同一模型与物理后端，不是独立确认、最优后缀证书或 PC0–PC5 通过；候选来源及 checkpoint、normalizer 独立性均不因此成立。若全体动作物体未改变，只能报告覆盖不足，不能通过或否定物理相关性。
