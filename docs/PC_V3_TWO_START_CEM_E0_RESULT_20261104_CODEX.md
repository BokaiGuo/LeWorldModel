# 零链与旧尾部双起点 CEM：E0 开发结果

按[事前协议](PC_V3_TWO_START_CEM_E0_PROTOCOL_20261104_CODEX.md)，
在 24 个已暴露 Wall 根完成三轮闭环。每次决策使用 1920 预测
token；第 2、3 次决策将预算均分给零链和本臂旧尾部两次 CEM。

| 方法 | 最终距离均值 | 中位数 | `<0.05` 根数 |
| --- | ---: | ---: | ---: |
| v3 response | 0.396386 | 0.500058 | 5/24 |
| 原 smooth CEM | 0.458722 | 0.500050 | 2/24 |
| 单起点热启动 CEM | 0.479329 | 0.500026 | 1/24 |
| 双起点 CEM | 0.458540 | 0.500033 | 2/24 |

按差值 `1e-12` 以内视为平局，双起点相对 response 的逐根
胜／平／负为 14/0/10，相对原 CEM 为 13/2/9，相对单起点热启动
为 7/0/17；许多差异极小，不能解释为有实际意义的优势。根 0
双起点最终距离 `0.001985`，上一轮单起点为 `0.500021`；这与
起点覆盖不足的假设一致，但预算分配和随机搜索也发生变化，不能
仅凭此根证明因果或声称找到全局最优。
