# 时序行动后果保留开发结果

按 [预定协议](PC_TEMPORAL_EFFECT_RETENTION_PROTOCOL_20261107_CODEX.md)，对已曝光的 TwoRoom roots 20–49，使用同一冻结 RGB LeWM、相同 A 探针库、独立 B 尾部和共同全链 incumbent 比较。先完成 GPU 评分并封存动作，随后独立重置环境并实际执行每臂选中链；每条执行 25 环境步。

| 方法 | 曾成功 | 终点成功 | 首次成功在前缀后 | 平均终点距离 |
| --- | ---: | ---: | ---: | ---: |
| 普通 lookahead | 28/30 | 22/30 | 20/30 | 9.978 |
| 向量 | 28/30 | 22/30 | 20/30 | 10.789 |
| 质量约束向量 | 28/30 | 22/30 | 20/30 | 10.789 |
| 动作身份打乱 | 28/30 | 22/30 | 20/30 | 10.712 |

质量约束向量对普通 lookahead 和打乱对照分别均为 0 独胜、0 独败，未满足事先规定的至少 2 独胜、至多 1 独败出口。21/30 根的保留前缀不同，但最终实际选中动作仅 1/30 根不同；强 incumbent 和共同 A 候选参与了全部方法的最终竞争。这个结果支持停止本次具体保留构造，不证明所有时序描述或程序搜索无效。

每臂逻辑成本为已有全链生成 600、A 及等时长参考 72、各自 B 16、incumbent 重评分 2，共 690 条链；共享执行实际 B 并集平均每根 27.73 条。新增 B 与 incumbent 评分及相关循环的同步计时为 0.965 秒，**不包括**历史生成、已有 A 评分、模型加载和环境执行，不能当整任务时间或成本优势。模型轨迹评分只用于规划；物理状态用于重放初始化和评价。

测试：`tests/test_pc_temporal_effect_retention_20261107_codex.py`，2 项通过。动作、保留决策、模型分数、哈希与物理逐步轨迹见 `le-wm-main/results/pc_temporal_effect_retention_20261107_codex_{plan.json,pool.npz,physical.json,result.json}`。

本实验是已曝光开发集上的固定首计划比较，不是独立确认、真实反馈闭环或 PC0–PC5 通过证据；也不能把完成运行等同于机制成立。Gym 环境重置产生了观测类型及 numpy 转换警告，实验使用环境自身的状态重置和 step 输出，未据此认定环境接口完全认证。
