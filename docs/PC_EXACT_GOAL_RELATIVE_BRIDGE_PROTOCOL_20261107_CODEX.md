# 精确动力学目标相对桥接提案：开发协议

上轮全链成块 CEM 发现越墙样本，但终点选择仍停在墙前。本次检验一个不同的候选生成假设：仅用精确动力学任务允许的起点位置、起始朝向和目标位置，在起终点中点两侧采样垂直偏移，构造“转向—直行至中间点—转向—直行至目标”的有界开环动作。偏移幅度按起终点距离缩放；不读取墙的位置、解析可行见证、真值未来轨迹或成功标签。该手工几何先验在已暴露墙障家族上提出，并非中立随机搜索，也非视觉方法。

每根独立固定随机流均匀生成 384 个中间点，横向偏移为起终距离的 `[-2,2]` 倍；每段先用最少数目的合法原地转向，再用最少数目的合法直行动作。链总时域截断或零填充到 15 步；中间点不必真实到达，只有整条链通过动力学预测与评分后才是候选。所有完整链逐条计费，最终选择目标末距最小的已评分链；不另加真实后继或执行次数。

对照复用上一轮同根逐步 CEM 的 384 条完整链和结果，其输入、15 步动作域、物理目标与成本单位一致；但初始化与采样方式不同。该 CEM 不是已认证最强基线，且额外几何计算、完整墙钟要单独报告，不能只凭候选次数宣称系统效率。记录所有动作与分数，事后逐根报告成功（原标准终距 <0.05）、成对独胜、越墙覆盖、平均终距和候选成本；独立审计重算全部候选、合法性、动作与所选链。

事前开发出口：新臂至少 4/24 成功，且比基线多至少 3 个成功；否则停止该固定采样范围。满足也只允许设计公平的共同候选保留与描述消融，不证明 PC2，也不能将坐标输入用于 RGB-only。原候选集合及所有失败保留，不按物理成功筛选。
