# 行动后果保留：绝对探针代价修正审计

日期：2026-11-04。性质：对已有精确动力学开发数据的后验重新分析，不是预注册实验、端到端规划、真实物理验证或独立确认。

## 修正的问题

原固定机会审计中 `probe_min` 实际按 `max(零尾代价 − 探针代价)` 选择，并不是按探针绝对代价最小选择。不同候选的零尾代价可能不同，这两项不等价。此外，原审计的两个候选来源使用了不同探针库。上述问题不改变原始模型数据，但限制了原审计对照的解释。

本次对 `random_direction` 和 `spectral` 候选都使用既有随机探针 v2 中的同一 A 后缀库，分别在每个 root、depth 0/1 和候选来源内部固定候选池与两槽：

- `absolute_probe_min`：保留即时 greedy 槽，第二槽按 `baseline_score − max(a_improvements)` 最小选取，即已有 A 探针的绝对代价最小；
- `relative_improvement`：保留 greedy，第二槽按最大相对改善选取；
- `effect_complement`：保留 greedy，第二槽按标准化 A 改善向量与 greedy 的距离选取。

之后读取各被选候选既有的有限预算后缀求解结果。每个 root 对两个 depth 等权取平均，再在 16 个 root 上配对汇总。这里的候选质量依赖已有求解器，不能当成最优后缀真值；不同 root 也没有来源独立认证。

## 结果

| 候选来源 | 绝对探针最小 | 相对改善最大 | 后果互补 | 后果互补较绝对探针更好/更差/持平的 root |
| --- | ---: | ---: | ---: | ---: |
| random_direction | 0.501640 | 0.502402 | 0.502042 | 4 / 7 / 5 |
| spectral | 0.501128 | 0.499417 | 0.501958 | 0 / 11 / 5 |

数字为每 root 两个 depth 的平均终距，再对 16 个 root 等权平均；越低越好。两种候选来源的 32 个 root×depth 候选池在原有限预算后缀求解下均未检出成功。后果互补在该后验面板没有显示优于绝对探针最小的稳定信号。结果不证明它在其他任务或策略下一定无效，也不证明两种生成器的因果差异：候选池不同且该面板不是生成器随机化实验。

## 完整性与限制

审计验证候选键、即时分数、后缀最佳分数及成功标记一致，拒绝重复键、失败行和覆盖缺口，并记录一个描述源和全部 32 个候选质量源的哈希。描述源不保存前缀动作哈希；因此按键与分数匹配不是对前缀动作的密码学绑定。代码还记录当前审计脚本与复用的选择函数文件的哈希，但这不是完整运行依赖封存包。

计算只复用已经生成的探针和后缀结果，未重新预测或计量端到端成本。当前互补规则仅最大化向量差异，没有任务收益约束，不能代表所有行动后果利用方式。对策调整必须另立开发假设与未参与设计的评估数据，不能根据本面板事后挑选获胜配置。
