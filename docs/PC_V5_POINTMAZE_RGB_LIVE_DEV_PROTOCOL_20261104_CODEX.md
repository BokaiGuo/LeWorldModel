# V5 PointMaze 单根真实 RGB 反馈开发协议

复用已暴露的旧 PointMaze 根 0、冻结 checkpoint、原动作统计、场景及共同暖身；用仅适配签名的包装器调用未改动的 v5 response。目标、速度与位置由历史及目标 RGB 按现有图像管线估计，不以物理状态驱动候选或评分。执行 15/10/5 固定终点三轮，每轮 1920 prediction-token，封存完整链后实际派发前五步，使用自身 RGB 和动作历史重规划。

独立记录审计检查上下文、裁剪和时钟、carry 重评分、全部完整链最小值及计数，并单独以 native 后端重放暖身和全部动作。若没有逐帧物理状态配对或参考模型重算，不声称其已验证。配置、依赖、图像、动作、预测和输出不可覆盖。只运行一个事前固定的已暴露根；来源、normalizer 拟合外和 checkpoint 训练外均未认证，不能据此声称 PC0/PC3/PC4 通过、独立确认或推断平均优势。
