每格有两条重复臂，且 on/off 共享物理根；不能把八条成功记录
当八个独立成功。此前相同 24 前缀用零初始化、同样 20 次更新
后，原生成功为 0/24。暖启动对照表明**初始化会实质影响同一
RGB 后继下的实际控制结果**；这不是已经证明的代码 bug，也
不证明反馈刷新本身有害。两组均使用真实 RGB 刷新。

关键限制是：root 0 的 zero 前缀也在暖启动下成功。因此成功
本身不能归因于 selected 的重配置能力；暖启动共享来自 selected
联合候选的原后缀，也不能称公平的原生基线。早停分支的固定
十步终点在本合同下保持 null，实际停止步和原生成功另行报告；
不要用最后观测补成终点。规划账本仍未认证全流程实际成本。

这是一组已知根、事后开发对照。新重选前缀的共同后缀干预、
能力变化、独立新根和公平强基线仍未完成，P1 保持关闭。
