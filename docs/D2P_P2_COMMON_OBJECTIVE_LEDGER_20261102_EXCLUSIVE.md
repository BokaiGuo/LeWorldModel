# P2 known-root common objective: development contract

This is a partial integration, not a launch authorization. The inherited B0
shared-RGB pair is read-only authenticated using its saved-pair and capture
auditors; its prefix-chain selected raw action is the composition initializer.
It is a known root with previously observed outcomes.

The new adapter accepts one context and one goal and applies exactly the same
two native raw-action packet transitions and terminal 192-dimensional mean
squared error to either initializer. The common optimizer is the existing
eight-step projected gradient implementation. All ten actions may move, so
the optimized composition-initialized action need not retain a composition
witness. CPU analytic fixtures are contract tests, not model evidence.

The new append-only journal separates shared setup, inherited composition,
SRA initialization, common optimizer per arm, and final replay. It fsyncs
attempt, return, and failure events and chains records by SHA-256. Native
model hooks can record nested action encoder, predictor and projection calls;
autograd API requests are distinct from unknown engine internals. The journal
alone does not recover historical costs, enforce a cap, or prove that every
future runner call was instrumented. FLOPs, energy, I/O bytes and engine
internal calls remain unknown, not zero.

Remaining execution blockers: produce and independently consume a native SRA
online source/journal/receipt for this exact B0 context, target, model and
normalizer; bind that verified action to the common adapter, authenticate all
runtime sources, write an exclusive pre-run execution contract and ledger,
and enforce the host cooperative CUDA lock for the entire neural run. The
existing SRA candidate-only audit is insufficient. No such B0 SRA receipt was
found by the current JSON search. This document does not override the older
sealed contract's execution prohibition.

No equality of total budgets, physical improvement, fresh root, P1 admission,
P2 admission, or independent confirmation is claimed. The shared RGB encoding
and composition initializer have inherited costs, not zero-cost operations.
