# v25 幅度面板：见证前缀共同后缀诊断协议

对每根已封存任务的两条已验证特权见证，固定各自前五步，丢弃已知后十步，使用与固定候选诊断相同的 CEM（逐步动作、每前缀两次重启、每次 121 样本、batch 12、精英 4、每根相同种子表）从零尾部优化。动作、结果、费用与失败逐批记录；不将见证前缀或尾部注入规划器。

审计对所有实际调用重算同环境另一几何实现，并用记录调用逐批重放 CEM，检查前缀、样本数、代际更新和最优结果。报告每根两个前缀的终距和 `<0.05` 成功、调用 token 及失败。若未找到成功尾部，不证明尾部不可搜索；若找到，也仅证明对特权前缀的诊断能力。此额外诊断不算正式方法成绩或 PC2/PC3 通过。
