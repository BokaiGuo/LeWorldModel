# DLS 首包同动作预测诊断

使用根 0 来源合同修复后的 DLS 轨迹与根 1 原封存 DLS 轨迹，
固定四臂的实际首五步及第 5 步真实 RGB。其他三臂与此前四臂
执行动作相同，但本诊断仍逐臂保留固定来源。对每臂使用其首节点
的真实历史、动作归一化、初始 latent 和相同 cp10 目标，主机 CUDA
预测同一动作，并编码真实第 5 帧。输出向量与物理状态用于比较
预测目标距离、真实 RGB 目标距离、位置和推杆误差。

固定两根四臂，不能按 outcome 选取；checkpoint 不训练。只诊断
首包，不等于原规划器的三包终态评分，不能据此判定选择器算错、
证明能力或宣布 P1 通过。根均为已知开发根，结果不是独立确认。
