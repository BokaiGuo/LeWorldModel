# 第二根四臂：同动作五步预测与真实 RGB

对第二已知根的 16 个真实执行节点，主机 CUDA 对实际五步动作
预测并重新编码同一时刻 RGB。预测与真实编码的 MSE 范围为
0.01360–0.17958，平均 0.09021；这 16 条共享一个根和四条
连续轨迹，不是 16 个独立任务。

四臂在初始节点具有相同历史和目标；按模型预测目标距离排列：

| 臂 | 预测目标 MSE | 真实 RGB 目标 MSE |
| --- | ---: | ---: |
| random | 0.73477 | 0.77373 |
| native-style | 1.09301 | 1.07097 |
| structured | 1.18897 | 1.06074 |
| immediate-progress | 1.24018 | 1.08018 |

六个初始动作配对中，native-style 与 structured 的预测排序
和真实编码排序反转；其他五对方向一致。这是后验描述，不能
推断不同根的错误率。后续节点各臂处于不同真实状态，不能
混作同状态的排序实验。真实编码距离也不等于物理成功。

固定输入重建包含 16 节点事件链、动作、历史、帧和冻结模型
身份检查；没有重新执行物理动作。CUDA 进行 16 次预测、16 次
action encoder 和 16 次目标帧编码；模型前后哈希一致。该
对照仍不能排除共享模型接口/训练 normalizer 来源问题，也不
证明 P1 机制、独立泛化或等预算优势。
