# 零链与旧尾部双起点 CEM：E0 开发协议

事前固定原 24 个已暴露 Wall 任务、三次固定终点反馈和每次
1920 预测 token 上限；首轮与已有 CEM 相同。每次反馈先各评价
本臂零链和本臂旧尾部，将剩余完整链样本数按二者平均分配，
奇数余数给尾部。分别使用不同但预定的随机种子、相同四结点
smooth CEM，保留两个起点和所有采样的最优链，再执行前五步。
不读取 response 的轨迹、候选或执行后指标。

将完整闭环输出与封存的原 smooth CEM、v3 response 配对报告；
同时可参照单起点热启动开发结果。完整预测、预算、动作和每次
CEM 更新必须封存，统一使用已有逐批动力学与派发审计，并额外
核验两个起点的样本分配。预先记录均值、中位数、`<0.05` 根数及
逐根胜平负，不选择最有利指标；不设事后成功标准。资源仅在
预测 token 轴匹配，计算时间等另报；结果不构成 PC3 独立确认。
