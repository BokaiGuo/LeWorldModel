# v22 reserved-refinement paired E0 development result

The preregistered eight-root paired panel completed all 32 plans. Under
the fixed terminal-distance `< 0.05` success criterion, v17 and the
shared-bank multistart CEM each succeeded on 1/8 roots (the same root);
v21 and v22 each succeeded on 0/8. Per-plan prediction expenditure was
1,918–1,920 tokens of the 1,920 cap. This development panel is not an
independent PC3 confirmation.

The existing replay audit checked saved actions and scores using another
implementation of the same geometry, selection and token accounting.
An additional saved-trace audit reconstructed elite means and scales:
each v22 root had four refinement starts, each with 26–28 samples across
three generations; the next generation used the updated distribution.
This resolves the specific one-generation budget issue, not whether
refinement is sufficient.

v21 used six successor probes per root and v22 used three, so the
comparison changes both probe and refinement allocation. It does not
isolate the causal effect of iterative refinement. The result establishes
no planning advantage and does not invalidate the theoretical proposal.
