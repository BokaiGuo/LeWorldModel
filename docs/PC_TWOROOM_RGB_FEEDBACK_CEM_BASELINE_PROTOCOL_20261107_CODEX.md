# TwoRoom RGB 反馈分段 CEM 开发基线

在此前四臂闭环消融同一组已曝光 root 10–49、同一实时 RGB、目标、环境复位与成功／截断停止规则下，独立执行分段 CEM，五段各保持动作五步，每执行至多五步重新观测。旧尾补零作为每次规划的已评分候选，与新候选竞争。所有物理动作合法，真实状态仅用于环境复位和评价。

两项事先固定的开发预算：

- `cem13`：旧尾或零链 1 次评分，加三轮各 4 条候选，每轮 2 elite，共 13 条评分；
- `cem300`：三轮各 100 条、10 elite，首轮含旧尾或零链，共 300 条评分。

两臂在标准化动作坐标中以固定种子产生候选，保留全部已评分最佳链而非返回未评分均值；方差下界 `1e-5`。记录所有候选、分数、实时输入收据、实际动作、停止时刻、每次查询和同步规划计时。对之前程序臂只作同任务的配对开发比较；13 次是每次规划评分数匹配，不代表整任务成本匹配。300 次用于检查预算尺度，不宣称充分调优或统计前沿。未见任务及正式统计规则不在本实验中。
