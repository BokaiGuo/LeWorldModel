# 零空间候选版本：实际选中链机制干预协议

规划和轨迹审计封存后、读取规划汇总前固定本干预。对 24 个暴露根
`null` 臂最终（含全动作精修及弃权）实际链，复用已有相同模型、
相同预算的机制分析器，不重跑或更改规划选择。

对 selected、zero、同首库即时 greedy、历史 random-bridge 和普通
lookahead 五个前缀：执行共同的五种固定十步后缀及选中链后缀，
报告绝对终距和相对于各自零后缀的变化；每个前缀均以相同 CEM、
相同种子、120 条链重规划，并对后继五步动作取中心差分响应矩阵。
历史 random/lookahead 来自暴露任务上的先前配置，仅作开发对照，不
是本次完全配对、等资源基线。

严格的有限交集要求所选前缀非即时进展，并且选中共同后缀相对零
后缀的改善、各前缀等预算重规划的终距均严格优于 zero 与 greedy，
另报告再同时胜两个历史控制的交集以及后继响应差。共同后缀效果、
重规划和响应变化须保持在同一最终选中链；所有诊断成本独立计量。
非即时不等于重配置，响应差不自动等于可利用性。对全部 24 根运行，
结果排他封存及哈希绑定，重放核对；不得追选未选链或补充种子直至
显著。负结果触发新构造的停止条件，不改原 gate。
