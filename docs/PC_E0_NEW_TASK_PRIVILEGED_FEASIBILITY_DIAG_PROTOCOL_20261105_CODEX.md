# 新参数 E0 面板的特权几何可达性诊断

为排查三种规划臂零成功是否来自 15 步任务本身，事后使用环境壁面几何构造评估专用的两条候选链，分别经 `(0,1.1)` 与 `(0,-1.1)` 再到达目标。它使用特权几何、在结果暴露后编写，不输入任何规划器，不是合法规划方法或原合同预算内 oracle。

每段路径先计算当前位置到目标方向，使用不超过 `π/2` 的原地转向步，再使用不超过 `0.3` 的直线步；对每个任务计算两条候选的所需物理步数，超过 15 步时标记为“本构造超时域”且不得裁剪成有效见证。将不超时域的动作归一化到 `[-1,1]`、补零至 15 步，使用原精确动力学分别重放；记录每步轨迹、碰壁标记、终距、动作和成功阈值 `<0.05`。

每根仅评估两条固定几何路径，任一成功可证明**该环境实现下存在一个合法、15 步的特权链**；两条均失败不证明不可达。同实现验证不能排除共同物理模型错误，不承认 PC0、正式自动发现、视觉模型可解或独立来源。保留全部 16 根，记录协议及动力学依赖哈希。
