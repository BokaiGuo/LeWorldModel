## 特权前缀与后缀优化能力

每根选择一条已知解析可行轨迹，分别固定其前五步及前十步；同一后缀 CEM 在 192 和 384 次时：

- 固定解析前五步：两档均 **0/8** 成功。
- 固定解析前十步：两档均 **6/8** 成功。

对这 16 个固定前缀，独立回放原解析可行后缀，完整链均达到数值零终距。这证明所选前缀确有可行后缀，但不意味着 CEM 必须能以当前预算找到它；解析后缀没有注入优化器。结果提示：当前自动候选在该固定后缀 CEM 下没有提供足够起点，同时连已知可行的五步前缀也不能让该具体后缀搜索成功。不能仅将上一轮失败归因于候选、分配或某个代码 bug，也不能据此推断其他优化器的上界。

## 绑定与边界

共计 256 个固定前缀（其中 16 个为隔离的特权前缀）、98304 条完整链评分，8192 个预测批次。全部动作、评分及两个嵌套预算的最佳链已封存；独立审计逐批重算评分、核验固定前缀、384 次预算及最佳值。原始数据、审计和特权后缀回放结果存于 `le-wm-main/results/pc_successor_wall_fixed_prefix_diag_20261103_codex_*`，均与源计划和协议 hash 绑定。相关回归测试 **45 项通过**。

该结果完成了预定的候选质量／搜索能力分离诊断：当前构造在这组已暴露任务未产生足够证据，按协议不应默认继续对同一组根增加候选或预算。可行性轨迹只是排查参照；本轮不是自动程序发现、RGB 闭环、独立优势或 PC2／PC3 通过。
