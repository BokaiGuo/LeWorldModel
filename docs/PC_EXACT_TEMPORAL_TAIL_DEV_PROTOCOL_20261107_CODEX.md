# 精确墙障任务：时序成块尾部优化开发协议

目的：针对已暴露的 24 根 exact-wall 开发面板，检验前次发现的高维尾部
优化缺口是否能通过时序一致的动作扰动缓解。该实验只比较尾部优化器，
不重新开放已停止的描述器，不使用解析可行见证作起点或搜索输入。

固定原实验的八条前缀、每条前缀自己的名义尾部、任务和每条 384 次
完整链评分；逐步 CEM 使用已封存、已审计的同预算结果。对照方法在
名义尾部上叠加五个各持续两步的二维增量，每轮 12 个候选、4 elite，
起始增量为零、初始标准差 1/3；增量与实际尾部均限制在合法动作域，
每轮首个候选是当前均值，返回所有已评分候选的最优链。随机流以
root 和 prefix 唯一确定。记录全部完整动作与代价、运行时间和指纹。

评价同时报告（1）各根八前缀的评价端 oracle 最优，不能冒充部署
选择；（2）原 ordinary-lookahead 在探针阶段事先选出的两个前缀，
只访问该二者优化结果的可部署比较。每根是统计单位，原样报告
`<0.05` 成功与连续终距；每种方法对每条可选前缀的优化预算一致。

预定开发出口：oracle 八前缀平均终距降低至少 0.02，至少 14/24 根
严格降低，并且两前缀部署平均终距不增加。未满足则不把该参数化
升级为开发候选；满足也只代表支持在原面板继续研究，不是 PC2/PC3
通过。原有描述器负结果和停止规则保持不变。
