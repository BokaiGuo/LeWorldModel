# 有界条件化候选：完整共同池及物理后果开发结果

按 `PC_BOUNDED_PREFIX_FULL_POOL_NOVELTY_DEV_PROTOCOL_20261105_CODEX.md`
对 50 个已暴露任务进行有界条件化闭环。每轮的对照池包括同一
上下文中的普通候选、A 探针和共享响应的四条组合；后者在原
top-k 决定后另外计分，不参与规划器更新。

共 585 个环境迭代中，220 个含相对完整对照池独有的组合，
合计 440 个独有条目，77 个进入原条件化 elite；只有 4 个
上下文中，独有候选的最低模型代价优于完整对照池最低代价。
首次规划的 50 个任务中，47 个曾出现独有组合。上下文和条目
互相关联，不视为 585 个独立任务；独有条目数未做组内去重。
共享对照额外查询 2340 条完整链，必须单独计费。

按 `PC_BOUNDED_PREFIX_NOVELTY_PHYSICAL_DEV_PROTOCOL_20261105_CODEX.md`
预定规则，为首次规划中 47 个有独有组合的任务选择相对同轮
对照池模型代价差最小的独有链，和该池最低分链配对。首先检查
实际最终首链重放：50/50 任务、1194 步动作及完整物理状态
最大差均为 0。随后对这 47 对链执行物理反事实：

| 结果 | 任务数 |
|---|---:|
| 独有链成功 | 17 / 47 |
| 同轮共同池最低分链成功 | 32 / 47 |
| 仅独有链成功 | 2 |
| 仅共同池链成功 | 17 |
| 所选独有链模型分数优于共同池 | 2 |
| 前项中仅独有链物理成功 | 0 |

其余 3 个任务无独有候选，仍保留在 50 任务分母中。94 条
反事实完整计划均无动作越界；有界条件化闭环的 1558 个实际
执行动作也无越界。物理 reset 前首次快照与同任务有界 CEM
逐项一致；有界条件化闭环成功 43/50，但它不能直接与其他
求解器归因比较，因为算法与额外诊断开销均不同。

结论是：这些响应组合确实产生了一些完整池独有链，但该开发
面板中，模型判断优于整个共同池的情况少；事后按最小模型分差
选出的独有链也没有显示相对共同池的物理优势。这不排除其他
描述、生成器、精修或更长时域组合；也不证明最终返回均值依赖
这些链。尚未开展候选进入共同精修后的配对实验，不能据此下
完整搜索或 PC2/PC3 结论。
