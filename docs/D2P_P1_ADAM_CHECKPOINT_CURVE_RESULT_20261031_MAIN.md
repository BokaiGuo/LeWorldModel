模型分数更低不表示真实任务更好，也不能因此选择有利预算。

认证，也不含前缀生成。三种预算点共享一条 20 步运行，记录的
总耗时不是各预算独立运行的耗时；尚无真实物理预算曲线。

同协议比较，并保留提前停止和删失。
