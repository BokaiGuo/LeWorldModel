# 多方向响应与后继多样性：精确动力学开发协议

## 新假设与版本

已封存的 successor 每个名义点将完整雅可比压为一个目标方向；固定预算下
自动组合前缀无跨墙，故提出新的可证伪假设：利用同一次完整响应分解的两个
右奇异方向及正负号，先以模型预测终点选择即时最优首段，再保留与其预测
终点最远的首段，可能产生不同的后继响应并改善自动程序覆盖。此为新版本，
不是重开已停止的六维 block-program 构造，不修改旧方法或旧阈值。

首段以既有单一名义动作为线性化点，中心差分计算 2×10 响应矩阵和一次 SVD；
候选为 zero 与两个右奇异方向正负扰动（最大坐标幅值 0.5，动作裁剪至合法域）。
对五个首段计费预测。响应多样性臂保留即时目标评分最低者和剩余预测终点离其
最远者；同库 greedy 臂保留即时评分最低的两个。若相同按固定索引破平。
每个保留首段计算该后继处响应，生成 zero、旧阻尼响应提议及相对名义动作
反向的提议，共六个十步组合。使用上一版本相同的方差下限 0.05
和最终 zero-prefix 比较，沿用 75% 可负担完整链样本用于共同后缀、
余量用于同一联合精修；所有动作和评估来自模型，禁止解析轨迹。

随机方向臂使用独立根随机种子，从 QR 得到两个动作空间正交方向作为首段，
并在两个保留后继各自生成一个随机方向的正负扰动和 zero；不进行响应或 SVD
计算，将节省的 token 留给搜索。同样以预测终点多样性保留两个。另设充分
利用本协议 480 token 的直接 full-CEM 控制，并保留上一轮四臂结果作为
开发上下文。随机与响应候选结构相同但信息与生成成本不同，是完整方法比较；
不能称为条件候选库消融。五步即时评分与全部响应查询均在预算内。

## 面板、核验和停止

在此前完整暴露的 24 个 Wall 根上，每根运行 `response_diverse`、
`response_greedy`、`random_diverse`、`full_cem` 四臂；完整预测 token
上限均为 480，动作每 5 步计一个 token。种子、后缀策略、动作域、
15 步执行时域和 `<0.05` 成功阈值固定在代码中。记录每次预测请求与
float32 评分输入、预测位置、分数、候选来源、保留、精修、最终选择、
token、响应、SVD 次数及 wall time。封存后逐批用原 exact 后端重算，
核对最终链已评分、合法动作、所有计数与各根臂唯一。

按臂汇报均值、成功数、逐根配对差、候选过墙覆盖、SVD 与总 token；
结构开销和 wall time 单独报告，token 匹配不等于全部计算完全公平。
新臂不包含人工可行轨迹或事后选择。此开发面板不是独立确认，单一
随机种子不能证明强基线上界。若无成功或无所要求的同链机制，不无限
追加旧根、种子或调参；保留负结果、停止本单配置构造。PC2 需另行
对最终选择链进行共同后缀与同预算重规划干预，PC3 另需独立确认。
