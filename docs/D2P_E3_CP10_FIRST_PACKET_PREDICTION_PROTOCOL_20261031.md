# E3 cp10：固定四臂首包预测与真实反馈

对两个已知根、四个已执行臂的首个五步动作（共八条）进行离线
诊断。读取各臂已验收的根 0、根 1 运行报告及其保存检查；固定
根、目标、初始真实 RGB latent、完整两包历史动作和实际执行
首包，使用冻结模型在主机 CUDA 预测第五步。重新编码同一臂的
真实第五步 RGB；保存完整向量、动作哈希、预测目标 MSE、真实
编码目标 MSE 和预测与真实编码 MSE。

逐根列出同一初始状态下四个实际动作的模型与真实编码排序，并
单独列出物体、推杆和原生物理指标。真实物理状态仅供分析，不
输入模型；首包目标距离不是三包优化目标，不能与最终选择分数
等同。已观察轨迹、不同方法成本、两个根均不独立；这是事后
机制与接口诊断，不用于选择算法、改变 gate 或声称性能优势。
