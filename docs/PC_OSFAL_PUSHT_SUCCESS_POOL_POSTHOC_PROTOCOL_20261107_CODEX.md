# PushT 已曝光成功候选池的逐层诊断协议

本协议在既有四任务与共享前缀池结果曝光后制定，属于事后开发分析，不是预注册确认。使用既有任务 0 和 1：它们分别具有 13 条和 1 条第 25 步原生成功链；任务 2、3 的同池终点成功均为零，不能提供成功链排名对照，不用于此特定分析。所有 301 条候选均保留，不按成功筛选。

对同一封存动作重置、重放并逐包核验状态、首次和末帧成功。仅以冻结 RGB 编码器处理真实末帧和目标图，提取所有 12 个 block 的 CLS 与正式输出；每层用相同目标平方距离排序，报告最低代价链成功情况、最优成功链排名和成功/失败链的成对排序比例，同时报告成对比较分母。以任务为单位解释，候选或候选对不是独立任务。第 9 层及正式输出均报告，其他层完整披露，不能按本池结果选择层后当作独立确认。

正式输出代价须与前次完整池真实编码一致（`atol=0.001, rtol=1e-4`）；动作哈希、状态、实际成功和冻结模型指纹必须一致。目标物理状态及成功标签只供评估，不输入模型或用于选链；真实末帧是不可部署的事后上限式诊断。无预测器中间层路径，不将中间层特征与预测 latent 直接比较。记录模型及源文件哈希，结果不得覆盖旧文件；任务和正常环境已有重放证据，不声称该实验是未见任务、在线控制、PC1 描述增量或 gate 通过。
