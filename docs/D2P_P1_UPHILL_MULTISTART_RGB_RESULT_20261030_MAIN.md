第 3 和 5 组发生模型预测与真实 RGB 编码的排序反转；第 4 组
编码排序一致但物体位置排序相反。样本来自两个已知物理根，
逻辑臂共享状态，不能将 2/3 作为独立总体失配率。第 3 组的
真实编码与物理位置指标方向也不同；这些对照把模型失配与
任务度量失配分开，却不能独立排除 normalizer 来源、共享代码
或任务目标绑定等问题。

另外五组 zero 前缀早停成功，不能将其早停帧与 selected 的
十步预测比较为同时间排序。此前观察到其中部分模型分数偏向
selected，仍只是不同停止时刻的性能对照，不是此表的同时间证据。
这是已观察结果后的开发诊断，不是独立确认、共同后缀能力证明
