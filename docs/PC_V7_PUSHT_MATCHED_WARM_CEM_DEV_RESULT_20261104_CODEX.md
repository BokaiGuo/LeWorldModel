# v7 与热启动 CEM：PushT 单根真实 RGB 对照

按[开发协议](PC_V7_PUSHT_MATCHED_WARM_CEM_DEV_PROTOCOL_20261104_CODEX.md)，在已暴露 episode 0 上，v7 与独立 smooth CEM 臂从相同暖身后的真实物理状态、历史 RGB／动作及目标开始，分别进行三轮真实反馈；两臂均未达到官方成功。

| 臂 | 物体位置误差：起点 → 终点 | 角误差：起点 → 终点 | 官方状态距离：起点 → 终点 |
|---|---:|---:|---:|
| v7 | 101.373 → 110.968 | 2.1623 → 2.3008 | 242.135 → 538.478 |
| zero／自身 carry 双起点 CEM | 101.373 → 130.824 | 2.1623 → 1.5105 | 242.135 → 368.337 |

同根末端 v7 的物体位置误差更小，CEM 的角误差与官方状态距离更小；指标方向不一致，不能据此得出整体优劣。初始时刻一致，之后各臂真实状态和图像不同，不能跨臂直接比较模型评分。CEM 每轮 1920 prediction-token；v7 为 1920、1919、1920；这不代表总算力相同，也不表示该基线已充分调优。

[配对审计](../le-wm-main/results/pc_v7_pusht_matched_warm_cem_dev_20261104_codex_pair_audit.json)确认初始帧、动作历史、目标和物理状态一致，且 CEM 后两轮分别使用本臂自身 carry 和 zero 作为近等预算的两个优化起点。[重放审计](../le-wm-main/results/pc_v7_pusht_matched_warm_cem_dev_20261104_codex_audit.json)逐步重放 30 条暖身及派发动作，核对状态、RGB 和终止标记，并重算 297 批、3520 条模型轨迹，位置与评分最大误差均为零；这些仍使用相同冻结模型和后端。控制台继承旧执行器的“两臂”文案，实际新 manifest 只运行一条 CEM 臂。

单根已暴露结果不能认证来源独立、泛化、PC3 或 PC4。后续需要固定多个来源合格的任务、强基线和统计规则，并分别报告预测、编码、分解和实际时间等成本。
