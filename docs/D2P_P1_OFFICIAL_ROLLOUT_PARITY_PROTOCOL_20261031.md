# P1 固定候选：模型原生 rollout 的时间接线对照

对已有 24 前缀 × 4 候选，重建同一真实 cp5 编码、两个历史动作包
以及两个待预测动作包。比较 P1 自定义一步/两步预测与当前加载
checkpoint 的 `rollout` 实现：同一组三帧 latent 与同一四个动作包，
比较五步、十步 latent 和目标 MSE；并复核此前保存的两个预测分数。

为隔离 rollout 的时序和动作索引，原生 rollout 的 `encode` 使用
已真实编码的同一组 context latent；这不是独立图像编码实现。
不读取物理成功选择候选，不重新运行物理、不更改模型或动作。
固定运行全部 96 条，记录模型哈希、设备、调用与输入来源。单次
对照只说明这些输入下实现等价，不证明训练时代码或 normalizer
来源，也不证明预测与真实物理相符或 P1 成立。
