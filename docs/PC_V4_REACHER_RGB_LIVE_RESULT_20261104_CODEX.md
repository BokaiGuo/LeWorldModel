# V4 Reacher 三轮真实 RGB 反馈：单根开发结果

依据[事前协议](PC_V4_REACHER_RGB_LIVE_PROTOCOL_20261104_CODEX.md)，未修改的 v4 在已暴露根 `20263160` 上按固定 15 步终点运行三轮真实 MuJoCo Reacher 反馈。每轮读取自身实际 RGB／动作历史并重编译，分别执行 5 步；整条轨迹不是 v3 轨迹。首轮选中链和候选库与先前保存上下文的 v4 离线诊断一致。

| 执行步数 | 真实关节目标距离 | 该轮选中链模型 latent MSE | 预测 token |
| ---: | ---: | ---: | ---: |
| 0 | 1.003500 | 0.788459 | 1920 |
| 5 | 0.812078 | 0.782008 | 1919 |
| 10 | 0.266470 | 0.745872 | 1920 |
| 15 | 0.491198 | — | — |

三个决策均未弃权。物理距离前两轮下降，最后一轮上升；模型内分数与实际距离是不同量，不可直接对比。已有同根的历史 v3 response 和 smooth CEM 最终物理距离分别为 0.553391 和 0.568320，但这些不是预先充分调优的强基线确认，尤其旧 CEM 没有同等旧尾热启动；单根不能推断平均优势或成功率。

审计与重放：

- [记录审计](../le-wm-main/results/pc_v4_reacher_rgb_live_20261104_codex_audit.json)核对三个决策的输入哈希、15/10/5 时域、RGB 与动作历史、carry 重评分、实际派发、完整链 incumbent、弃权和预测 token。
- [独立参考 rollout](../le-wm-main/results/pc_v4_reacher_rgb_live_20261104_codex_prediction_replay.json)重算 302 批、3642 条预测；最大投影误差 `3.82e-6`，最大分数误差 `4.77e-7`。它使用同一冻结模型与输入，不是独立模型或物理响应验证。
- [同后端物理重放](../le-wm-main/results/pc_v4_reacher_rgb_live_20261104_codex_physical_replay.json)的初始 RGB 一致，四个边界的 qpos 和目标位置最大误差均为零；未检查所有中间状态或 qvel。

运行器复用旧单进程执行器，其控制台固定输出“v3、两臂”；审计器及物理重放器也沿用多臂固定文案。实际 manifest、结果和审计均为 v4 的一个 response 臂、三次决策，不应按旧文案计数。

这完成了 **v4 单根真实 RGB 反馈开发运行及相应重算**，不表示 PC4 通过，也不表示已证明机制或强基线优势。二维投影的任务相关性、模型—物理响应、开发外任务、来源独立性和完整成本仍未认证。执行器的局部模块配置只用于单进程实验，声明依赖哈希不保证整个环境闭包。
