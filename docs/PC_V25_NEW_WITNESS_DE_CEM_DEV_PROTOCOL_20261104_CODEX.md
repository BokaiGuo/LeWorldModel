# 新开发任务：特权前缀下的尾部求解对照

目的：检验在相同完整链预测样本预算下，非局部差分进化是否改善已有随机初始化 CEM 的尾部求解；不是完整规划方法比较。

事前固定八根任务：起点 `(-0.5,y,theta)`，目标 `(0.5,gy)`，`y=±0.145`、`theta=±1.12`、`gy=±0.10` 全组合。检查与已列开发面板不重复；其他来源独立性未知。每根使用既有几何构造器的两条成功见证的前五步，丢弃见证尾部。若不足两条成功见证，记录 unknown 并排除该根的条件求解比较，不替换任务；同时报告全部八根的可行性状态。见证是特权诊断，不能输入正式规划器。

每个前缀每臂固定两次重启，每次 121 条 15 步完整链，即每前缀 242 样本、726 prediction-token。两臂每次共享同一随机初始尾部。CEM 使用既有逐动作实现、批次 12、4 精英；差分进化人口 12，初始人口含相同起点及 11 条均匀随机尾部，DE/rand/1/bin，F=0.8，交叉概率 0.9，越界截断，贪心保留，末批精确计费。所有随机种子按根、前缀、重启确定；不按结果调整。

依次输出每根每臂结果与请求前账本；失败计入根、前缀分母，不重跑或替换。审计动作、预测 token、实际前缀、独立同环境几何评分、逐批确定性提案与最优值。比较前缀终距、`<0.05` 成功、至少一个前缀成功的根、预测成本及含账本墙钟。token 不包含见证构造、其他处理或 GPU；不能据此宣称完整总成本公平、PC2/PC3 通过或独立复现。新实验不可覆盖旧面板或已有输出。
