# PushT 预定随机可达目标：开发诊断结果

按[事前合同](PC_JEPA_REACHABLE_RANDOM_GOAL_DEV_PROTOCOL_20261105_CODEX.md)，四个 root 各用一条预定、未进入模型候选库的随机参考链构造目标；随后冻结模型对另外 64 条预定候选预测，并在预测后编码真实末帧。4×65 条物理执行、4×64 条预测与末帧编码完成。参考链是离线可达性见证，不是预算内自动求解。

| 根 | 候选成功数 / 64 | 目标相对 warmup 末态的物体位移 | 预测评分首选成功 | 真实编码评分首选成功 | 目标 agent 在画布外 | 候选 agent 在画布外 |
|---:|---:|---:|---|---|---|---:|
| 0 | 0 | 136.65 | 否 | 否 | 是 | 28 / 64 |
| 1 | 0 | 1.54 | 否 | 否 | 是 | 25 / 64 |
| 2 | 0 | 0.00 | 否 | 否 | 是 | 27 / 64 |
| 3 | 0 | 0.00 | 否 | 否 | 是 | 25 / 64 |

位移单位为物理环境坐标。agent 是否出界按中心坐标相对 `0–512` 画布判断；画布外不自动等于环境报错或动作非法。动作在 `[-1,1]`，当前后端使用相对动作及 `action_scale=100`，多步动作可以产生远离画布的状态。四个参考目标的 agent 横坐标分别约为 `-216、-185、-269、-329`；其 RGB 目标不提供正常可见的 agent 位置。根 2、3 的目标物体没有位移，因此不能把本面板当作四个接触任务。

**接口更正（2026-11-05）：** `[-1,1]` 是本实验自定的相对输入范围，并非该环境声明的 `action_space`：后者仍为 `[0,512]²`，与 `relative=True` 时实际把动作乘以 100 后加到 agent 当前位置的语义不一致。包含负坐标的动作不符合声明空间；环境 `step` 未执行该空间检查。原先“动作在自定范围内”不能解释成环境接口合法性已经认证。真实数据的相对动作本身也包含负数，不能仅凭负数推断实现多乘了 100。详细证据见[动作尺度审计](PC_JEPA_ACTION_SCALE_AND_VISIBLE_LOCAL_AUDIT_20261105_CODEX.md)。旧记录与结论不作追溯改判。

**候选库全部没有成功动作，故不能估计“成功候选被评分漏选”的概率。** 预测首选终距大或真实评分低也不能直接归因于模型：目标 agent 不可见、参考目标和候选动作跨度较大，且真实评分仍包括整个图像。下一实验应事前约束动作与目标的可见性并报告拒绝率；不能事后剔除本批根再宣称有效。

预测与真实编码评分在各根的非并列动作对同序分别为 `1536/1896`、`1766/1980`、`1670/1961`、`1533/1740`；这些相关动作对不是独立任务，也不能替代成功判据。所有 64 条均被模型直接查询，不是未查询动作预测认证。

## 核验与限制

[独立物理审计](../le-wm-main/experiments/audit_pc_jepa_reachable_random_goal_dev_20261105_codex.py)重新按种子生成动作，并在相同后端逐条重放 260 条动作；历史、所有候选末态及目标帧、目标状态逐元素一致，独立重算成功与评分排序。[审计记录](../le-wm-main/results/pc_jepa_reachable_random_goal_dev_20261105_codex/audit.json)与[原始汇总](../le-wm-main/results/pc_jepa_reachable_random_goal_dev_20261105_codex/report.json)可查。审计不独立重跑神经模型，也不排除共同后端错误。

首次在受限沙箱启动 GPU worker 时因网络命名空间权限失败，未产生神经输出；授权沙箱外运行隔离 worker 后四根完成。记录的 768 prediction tokens 不包括目标和图像编码、物理回放及系统成本。新 seed 不是来源独立证明，训练外、normalizer 外、开发外均为 unknown。此结果不改变 PC0–PC5。
