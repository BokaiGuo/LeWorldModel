# P1 Adam 动作：预测与真实 RGB 同终点复核

在固定 Adam 物理结果已知后，重放实际保存的 24 条动作中
19 条 `probe_completed` 轨迹的两包动作，另对各自物理终点真实 RGB
使用相同冻结模型编码；5 条原生停止轨迹按原合同不补十步终点。
结果是已知根上的事后诊断，不是新物理执行或独立确认。

主机 CUDA 复算 19 条保存赢家分数均在 1e-5 内一致；冻结参数和
buffer 前后哈希一致。输入连接检查规划、物理准备、保存消费、
物理报告、原始动作哈希、十步状态、图像文件和像素哈希。逐行
保存预测及真实 latent，独立数组复算预测误差测试通过。该审计
不证明训练 normalizer 来源或所有依赖完全正确，也不证明理论成立。

按同逻辑槽 selected 与 greedy 的独立优化轨迹逐项对照，8 个逻辑槽中：

- 一槽预测 goal MSE 与真实 RGB goal MSE 排序相反：根 0/on、
  logical pair 2，selected 减 greedy 分别为 +0.04893、-0.04682。
- 两槽真实 RGB goal MSE 与物体位置误差排序相反，分别是 logical
  pair 1 和 2；角度、推杆和原生成功仍需分栏，位置不能代表整个任务。

不同前缀与各自独立后缀改变了完整动作链，这些配对不是相同状态下
的纯动作校准试验；8 槽共享两个已知根，包含重复轨迹，不能作为
独立样本估算总体反转率。不能从这里确认唯一根因或认为所有代码
问题已排除。

关键根 0/on 的两个 selected：预测 goal MSE 为 0.10416/0.09676，
真实 RGB goal MSE 为 0.36751/0.71860，预测与真实 latent 的 MSE
为 0.53346/0.60969；两条均未原生成功。说明这些特定动作链的
低预测代价不能直接视为真实目标接近或成功。此前 zero 成功的
删失记录没有被排除为失败，只是不纳入十步终点误差比较。
