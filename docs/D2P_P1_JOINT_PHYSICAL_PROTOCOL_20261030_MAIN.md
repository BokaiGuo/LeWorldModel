# 联合优化动作已知根物理探索

对已封存 CUDA 重放的全部 16 行，使用原执行器和原生状态恢复合同，
每臂配对 incumbent 与 joint-selected，不按预测或物理结果筛选；
执行最多 15 步，原生停止和域外截断不补齐。保留物体位置、角度、
推杆、原生联合指标和各自停止状态。该实验只有两个已知根，
不证明独立泛化，也不证明真实重配置能力、等预算或 P1 通过。

物理前必须保存并复验 CUDA 动作、标准化、完整上下文、模型和
来源身份，绑定原生 reset、目标、warmup 和执行器源码；每个阶段
独占输出，不覆盖旧数据。物理执行不进行神经推理。该实验是开放
15 步动作链，不是反馈重规划；后续仍需共同后缀能力干预和各前缀
独立优化及公平总预算评测。
