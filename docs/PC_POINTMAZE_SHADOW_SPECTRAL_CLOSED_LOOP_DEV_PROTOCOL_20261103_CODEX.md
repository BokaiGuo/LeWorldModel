# Shadow RGB 谱初始化闭环开发合同

冻结于实现及测试之前；本轮禁止运行物理实验。本合同是开发用途，不是确认性试验。

两条已暴露根 r8343_a0_p2、r8345_a0_p2，baseline 和 spectral 各自重置独立 shadow bridge，重放同一 12 动作前缀并逐帧校验封存 v4 shadow 哈希。每臂随后五次用自身连续 RGB 和固定目标各自规划并执行首动作；不接收模拟器状态、其他臂 RGB 或其他臂动作。前缀初始状态仅供环境重置。两臂同根同轮种子 `2026110400+10*source_index+iteration`、相同动作域、CEM 3×16 加最终 2 个候选，计 50 样本、4 预测批次；允许两臂动作与后续 RGB 不同。

spectral 使用现有可微 RGB 派生上下文任务响应的 Jacobian/SVD 提案，首代四候选经过通常评分；baseline 无结构提案。成功的 spectral 额外每决策一次响应前向、两次反向向量、一次 SVD；不做有限差分。结构成本、预测调用与墙钟时间分别记载，不声称等总预算。完整配对预期 4 reset、68 单步命令、20 决策、1000 评分样本、80 批次，spectral 额外 10 前向、20 反向、10 SVD；目标编码一次，反馈编码 24 次（每臂每根五次加终止一次）。选单臂时减半，但目标编码仍一次。

沿用原执行器已锁定依赖和模型/数据规范、NVIDIA 渲染预检及协作 GPU 锁；附加锁定谱模块。每条 reset/动作之前使用独占创建、文件与目录 fsync 的快照及 fsync 事件，每桥 attempt/returned 独立记录并持久化返回 RGB；失败即停止、不自动重试。attempt 后未见 returned 时动作是否已执行未知。所有决策及 CEM 轨迹、噪声、谱结构和预算须绑定对应臂快照；输出路径必须全新。任何前缀、时钟、输入、预算或模型哈希不匹配都停止。

本轮只运行 CPU 假模型/假 bridge 测试，不启动物理后端、真实 bridge 或 CUDA 实验；未来运行需另行授权。旧上下文诊断是已暴露根的离线开发证据，非新的独立验证。
