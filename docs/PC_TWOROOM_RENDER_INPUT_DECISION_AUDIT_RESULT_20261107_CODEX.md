# TwoRoom 数据帧与重渲染：GPU 决策核验

按[事前协议](PC_TWOROOM_RENDER_INPUT_DECISION_AUDIT_PROTOCOL_20261107_CODEX.md)，在 10 个已暴露开发根上，分别使用数据集帧和根据记录状态重渲染的 RGB，重新运行冻结 LeWM，逐根对同样 656 条候选评分；两种输入各自重新构造和编码 RGB 字典。重渲染的物理状态仅用于评估端合同核验，未输入规划模型。

| 检验 | 结果 |
| --- | --- |
| 原 latent 评分最终选链一致 | 10/10 根 |
| top-30 候选集合一致 | 10/10 根；不表示集合内部排序不变 |
| 字典选择最终链一致 | 10/10 根；含 2 根弃权回退 |
| 两种输入的字典模板偏移集合一致 | 10/10 根 |
| 每候选评分最大绝对差 | 跨所有根与候选最大 0.43714 |
| 数据帧重算对既有封存评分最大绝对差 | 0.000061 |

数据帧重算的字典选链也与上一轮封存结果 10/10 一致；模型加载前后指纹一致。某根的最低两项评分相同，稳定排序依赖候选索引，不能把所有任务都视作有严格的最佳评分间隔。输入像素虽至多相差 1，但评分并非逐位相同；结果只支持**该面板、该固定候选池上的选链稳定性**。

单元测试 4 项通过。环境仍给出 Gymnasium 观测类型／转换警告；本次没有测量独立环境、官方来源等价或物理状态完整性，也没有检验更多任务、闭环与行动后果描述的有效性。此前非线性选择器未达开发出口的决定保持不变，PC0–PC5 不改判。

逐根结果和来源哈希见 `le-wm-main/results/pc_tworoom_render_input_decision_audit_20261107_codex.json`；运行代码为 `le-wm-main/experiments/pc_tworoom_render_input_decision_audit_20261107_codex.py`。`experiment-design` 技能用于固定配对候选与区分数值稳定、动作选择及科学结论。
