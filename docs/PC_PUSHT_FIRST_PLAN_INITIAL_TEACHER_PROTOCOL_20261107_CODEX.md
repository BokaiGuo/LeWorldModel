# PushT 固定首计划：初始图与单步重编码对照

使用前次已封存的 50 任务、两条首计划与相同物理重放结果，不新增候选、不优化或选择动作。对每一任务和动作链分别计算：

1. 原数据初始图出发的自回归预测，并与此前保存的预测表示逐项核对；
2. 相同物理 reset 后立即渲染的初始图出发的自回归预测，动作不变；
3. 使用真实重放得到的逐包 RGB 编码历史与相应动作包，作评估端单步预测（history 最多三个模型时刻）。

前两个条件只改变初始图；第三个使用事后真实图像，是诊断上限而非可免费部署的规划器。五个包分别对应 5、10、15、20、25 真实步。比较同一真实后继编码下的误差、末帧目标分数排序与物理成功；报告整体与每任务配对分母，保留相同链。检查初始物理快照、先前结果和模型指纹、首包自回归与单步预测等价；所有结果写新文件。不得将 teacher forcing 宣称为闭环控制收益或将结果跨轨升级为 gate 通过。
