# PointMaze 因果残差：额外面板开发结果

按事前协议固定轨迹 1892–1899、两个相机及三个五步候选，使用 GPU 执行。该面板部分已暴露，数据来源和训练成员尚未证明独立；不构成独立确认。模型接收完整 proprio，属于 state-assisted，不能作为 RGB-only 证据。

15 步历史动作逐步物理重放最大状态误差 `2.3294e-7`，最大时钟误差 `4.44e-16`；在本面板与所用模拟器中，未发现动作历史和物理时钟明显错位。这不认证完整模型实现或全部预处理。

| 指标，按任务平均 | 原预测 | 因果残差 | persistence |
| --- | ---: | ---: | ---: |
| 三候选后继编码 MSE | 0.176534 | 0.045707 | 0.069261 |
| 选中动作物理 regret | 0.024522 | 0.029259 | 0.030267 |

残差后继 MSE 在 6/8 任务低于 persistence，但物理 regret 相对原预测只有 7/8 不变或更好、0/8 严格改善。仅 1/16 视角改变选择：1897 相机 0 由物理最优的候选 2 改为候选 0，regret 从 0 增至 0.075792。该面板未达到预定开发出口，应停止当前固定单位系数单残差的控制修复；不追溯更改阈值。结果不能证明所有反馈校正无效，也不能证明理论错误。

选择进程只使用历史观测、历史动作、当前 proprio 与目标图像；真实候选后继和物理距离只在选择封存后用于审计。公共与物理数据分进程处理，但不是操作系统级权限沙箱。现有结果不足以声称模型预测—观测失配已修复、可靠闭环改善或任何 gate 通过。
