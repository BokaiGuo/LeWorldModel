# PointMaze DINO 后端预测对照协议

比较已知存在 224 像素位置编码插值差异的两条路径：`hf_shim`（现行兼容 shim）和 `source_snapshot`（本地 DINOv2 源码快照的默认插值）。将同一 HF safetensors 权重严格映射进源码快照；本试验不能认证官方原始权重来源，也不把该路径宣布为官方完整复现。

固定此前产生的 1884–1891 八个已暴露任务、各两个相机位置、三个相同合法动作及目标 RGB 居中规则。模型 predictor、proprio 路径、统计、输入和动作包完全不变，只替换视觉 encoder 后端。两臂均在真实 GPU 上评分，先封存模型代价和选择，再后置读取物理轨迹和真实后继图像；真实后继仅供诊断。对比每视角的预测／真实编码首选一致、物理 regret、视角不一致、预测与真实编码代价；同时确认旧 shim 评分与既有封存结果近似一致。两种输出都只用于 state-assisted，不可跨轨作为 RGB-only。

预定开发出口：所有 16 个视角完成，源码后端平均物理 regret 不高于 shim，预测首选与其真实编码首选的一致数严格高于 shim，且 1887 偏移视角物理 regret 严格低于 shim。若失败，停止将此单一插值差异当成该面板排序错误的充分修复；仍需如实保留后端差异及每项观测。仅在已暴露面板上判定，不能借结果选择阈值或晋级 gate。
