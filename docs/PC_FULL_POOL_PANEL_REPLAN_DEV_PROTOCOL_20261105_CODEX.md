# 固定间隔五任务候选池与重规划留痕协议

预先固定既有 task seed 42 任务索引 0、10、20、30、40（不依据
成功或方法差异筛选），solver seed 42，分别运行原有同结构普通
lookahead 与响应臂。对每任务首次规划记录全部同次查询的动作、
模型预测、目标表示、代价；对所有规划记录实际上下文中的环境 ID、
step index、warm-start 旧尾与最终输出。每次规划 3000 条评分，
不能把额外诊断写盘开销当作算法运行时间。

评估端逐条物理重放已记录的完整池并核对初态，物理状态与成功
不得进入规划器。按任务报告覆盖、模型排序、elite 和最终选择；
逐时刻预测／真实编码诊断可先对固定代表链做，不能据代表链断言
全池的评分性质。旧尾在原生实现中是新优化的 warm start，并非
自动沿用；只有相同时点、合法尾补齐、明确计费及物理反事实才能
推断重规划导致收益或损失。不得将多规划或多 solver seed 视为
独立任务；本面板为开发诊断，不重新判 gate。
