# P1 目标条件化谱初始化：已知根 1 开发合同

旧 structured 初始化只按 Jacobian 的前两个右奇异方向生成动作，
与原方案用目标残差生成阻尼最小二乘动作不同。本实验固定使用
同一已知根 1、同一 checkpoint、目标、真实 RGB 反馈时刻和共同
后缀优化器，只运行新的 structured 臂；历史四臂原报告保留。

在零动作 H3 后继处计算完整 raw-action Jacobian J，identity Q，
残差为目标 latent 减预测 nominal；使用阻尼
`lambda = 0.01 * sigma_max^2` 的 SVD 解。候选固定为零、沿阻尼解
归一化方向的 ±0.25、±0.5、±1 和逐元素裁剪后的阻尼解，共 8 个；
随后沿用两个投影梯度步、模型终点评分和五步真实派发。每个反馈
节点都重新编码真实 RGB。目标是方法开发，不强制选非贪心动作。

比较同根旧 structured 必须报告实际调用、物理指标和停止时间；
两个任务都已观察，不是独立确认。保留原生成功与画布保护，不能
用 latent 改善替代 P1 的真实能力机制；不训练模型、不修改 gate。
