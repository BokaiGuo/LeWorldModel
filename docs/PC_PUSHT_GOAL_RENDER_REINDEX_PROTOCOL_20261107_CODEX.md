# PushT 目标图重绘：shape 索引修正及重新评分

上一版诊断直接设置 body 姿态但未重建 Pymunk shape 索引。实测将两个物体从约 (100,100) 移到 (400,400) 后，重建索引前图像完全不变，重建后变化；因此上版全部重绘比较均无效，保留不覆盖。

本次在评价端设置原数据目标的七维状态，并对 agent 和 block 分别调用 `space.reindex_shapes_for_body`；不推进物理时钟。复用原实验固定 50 目标及候选动作、原始目标编码、模型预测和真实后继编码。分别绘制默认目标标记开启与关闭，检查姿态和图片误差，GPU 同批编码后按原协议平局阈值 0.001 比较每个目标的动作排序与两条链的物理标签。标记开启为默认设置；关闭仅作为可解释性对照，不做按结果自适应选择。所有目标重绘依赖评价端隐藏状态，不能输入 RGB-only 规划器。

记录代码、协议、输入与模型哈希，不覆盖前版或修改历史结论。此开发集诊断不认证闭环、源数据生成协议或 PC0–PC5。比较原目标编码与封存值，超出 0.001 即失败；模型参数运行前后哈希一致。
