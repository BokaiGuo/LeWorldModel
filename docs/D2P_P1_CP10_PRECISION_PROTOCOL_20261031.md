# P1 cp10 推理精度敏感性诊断

固定两根、每根开放与反馈各一条已物理执行的动作及其真实 cp10
上下文和 cp15 图像，不重新规划、不挑选动作。使用相同冻结 checkpoint、
动作归一化和 RGB 预处理，在主机 CUDA 分别执行：

1. 现行 FP32、关闭 TF32 和 autocast；必须复现封存的四条预测向量。
2. encoder、action encoder、predictor 均使用 CUDA BF16 autocast，
   网络权重不变；输入按现行方式构造。输出转 float32 后保存完整向量。

逐动作记录预测与真实目标 MSE、预测与真实 latent MSE、动作身份、
两种预测差异及逐根排序；模型状态、源文件哈希和调用次数前后检查。
真实标签仍使用 FP32 encoder，以保持固定的评价空间；BF16 encoder
仅改变部署输入，不能混淆为不同评价指标。

本诊断是已知根、事后固定动作的探索，不证明 checkpoint 训练精度，
不据结果选择部署精度、不改变 P1 gate，不构成新物理实验、独立
确认或等预算控制收益。如果精度敏感，再单独设计冻结的新对照。
