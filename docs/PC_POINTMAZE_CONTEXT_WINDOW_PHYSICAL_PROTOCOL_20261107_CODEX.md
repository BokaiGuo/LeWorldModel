# PointMaze 窗口比较：封存链物理重放协议

先前 context 1/2 实验已封存三个已曝光根、四个保留规则的动作选择；
本协议不读取物理后果重新选链。将每根八条已封存动作链分别从相同
初态、同一 XML 和 legacy MuJoCo 后端物理重放完整 25 步，检查每步
时钟、动作界限与起点。统一报告位置距离小于 0.5 的首次命中、
首次命中是否在前 10 步、25 步内曾命中及末步距离；记录初态已经
命中的情况。该指标不自动等于完整官方 episode 成功规则。

同时保留继续执行到 25 步的轨迹作为开放环诊断，不把成功后继续
执行称为实际停止策略。以根为配对单位分别报告各规则、两窗口的
曾命中情况；四个规则共享三根，不作为 12 个独立任务。没有强
基线、没有新的因果反馈，不能把结果认定为方法收益或 gate 通过。
