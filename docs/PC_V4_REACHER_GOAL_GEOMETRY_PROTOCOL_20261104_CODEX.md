# Reacher 目标图像及局部距离几何诊断协议

源为 v4 单根的五个已暴露末包反事实和实际 RGB 编码结果；这是事后、有特权状态的评价诊断，不能进入规划器。目标设为原实验保存的目标关节配置，重新 reset 同一后端并核对目标图像和目标 qpos。直接设置关节渲染目标、以及沿目标到五个封存末状态的最短角度插值比例 `0.25/0.5/1.0`，每点 qvel 置零并调用 forward；不将静态设置称为物理控制轨迹。

保存 16 张 RGB 图像、位置和 latent，验证目标图像是否逐像素一致、alpha=1 与封存反事实末帧及关节状态是否一致、角度距离是否符合插值。相同预处理和冻结 encoder 计算 latent 目标 MSE 与像素 MSE，分别报告它们与关节距离在全 16 点的两两排序反转数及每个方向上是否单调。目标自身是锚点，不当作由规划器发现的解。

参考输出仅适用于该五条已曝光方向与状态设定；静态特权目标构造、重复相关点和一次后端不证明目标图像作为一般任务指标有效，也不证明 PC1、PC3 或 PC4。若目标图像不等，报告实际差异和来源，不修改以往结果。
