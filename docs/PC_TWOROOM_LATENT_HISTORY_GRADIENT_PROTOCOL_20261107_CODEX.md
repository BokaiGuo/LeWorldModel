# TwoRoom 带历史 latent 组合：开发数值协议

比较冻结 RGB LeWM 的五个合法动作包整链 rollout，与先计算前缀、
再携带全部前缀预测表示和对应动作包继续 rollout 的结果。已曝光 roots
38、39；每根 8 条随机原始动作链，按固定种子在 `[-0.6,0.6]` 内生成，
经同一个 TwoRoom normalizer 转为五个五步模型包；不读取物理后果。

比较拆分位置 1、2、4，模型历史窗口 1 和 3；后者是实际模型默认设置。
计算整个预测轨迹的最大绝对差、末端 RGB 目标编码平方距离、对全动作
链的梯度最大绝对差、前缀梯度大小。保留中间预测图，不允许对其 detach。
同时报告把历史丢弃、只以最后 latent 起步以及显式 detach 的负对照；
负对照用于识别错误，不当作执行或收益证据。

预设开发数值容差：预测表示最大绝对差 `1e-4`，目标代价最大绝对差
`1e-2`，动作梯度最大绝对差 `1e-3`；同时报告梯度幅值。超过任一阈值
即不认证该条件；不能在看过结果后调整阈值。GPU 运行前后核验权重
指纹，记录代码、模型源码及输入文件指纹。该协议不测试真实控制、
搜索性能、跨模型适用性或正式 gate。
