# 第二已知根：四臂同动作、同时间预测对照

事后探索：固定 root1 既有四臂全部 16 个节点，用每臂自己的实际
RGB 历史、动作归一化和已执行的五步动作预测下一帧编码，并用
冻结模型重新编码同一时刻真实 RGB。检查封存报告、动作、历史、
图像、模型身份和执行节点；保留完整预测和真实向量与误差。
只使用主机 CUDA 和协作锁，不修改动作、任务或结果。

各臂执行动作不同，此设计不是跨臂同动作能力干预；已知根、
事后分析和未知完整成本不能支持独立泛化、P1 或公平优势结论。

## HOST01 结果

执行前保存检查通过全部 16 节点的任务、历史、实际动作、图像和
封存身份；主机 CUDA 重放完成，预测、动作编码、目标 RGB 编码
各 16 次。预测向量相对同时间真实 RGB 编码的 MSE 范围
0.018832–0.173693，16 节点平均 0.089094；11 个节点大于 0.05
仅为描述，不是预先设定的质量门槛。

模型预测的目标距离既有高于也有低于真实编码目标距离的情况。
这表明真实观测刷新后仍存在五步预测误差，但不能把不同状态和
不同动作节点当成配对排序实验，也不能归因其全部物理失败。
