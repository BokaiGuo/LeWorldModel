# V4 Reacher 直接谱方向探针：开发协议

锁定已暴露根 20263160、第三次决策、原 checkpoint、原二维 chart、两个原名义动作及其已记录的 2×10 模型响应矩阵。对每个矩阵的两条右奇异方向，将最大坐标绝对值归一为 1；分别执行名义动作和 ±0.05、±0.5 扰动，共 18 条五步物理轨迹。实际动作统一裁剪至 [-1,1]；记录各坐标裁剪及原 first bank 候选的集合匹配。不得据此选择正式动作或更改 v4。

每条轨迹由相同 seed、已记录暖身和前两包执行重建；对目标、根 RGB、qpos、qvel 和目标状态进行绑定。保存实际动作、末帧、物理状态、冻结模型预测、末帧重新编码和目标编码。各方向计算同尺度模型和实际末帧中心差分，并对小尺度计算模型 JVP；有裁剪时仅称为有限差分而非无约束导数。报告向量范数、绝对误差及稳定时的余弦和相对误差、目标 latent MSE 与物理关节终距的正负比较。物理图像量化限制连续导数解释。

运行前封存协议和实际依赖；结果排他写入，单独重算及复编码。此为单根单时刻后验开发诊断，不能证明 PC1 或方法优势，不能与其他版本拼接。
