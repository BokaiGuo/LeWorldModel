# P3/C3 动态预算：独占 CPU 协议

本协议冻结开发性两根配额对照：预算点 20、30 均须报告；
signal 分别为 `[15,5]`、`[22,8]`，reverse 分别为
`[5,15]`、`[8,22]`。配额直接事前固定，不从近似权重取整推导，
因此不会因取整默默合并为同一策略。两臂每个预算点的候选总数相等，
但仅凭这个事实不能声称记录调用轴、总计算或 wall 相等。

实现也提供整数精确的最大余数通用分配，稳定索引破平；策略相同则
拒绝构造有效对照。固定配额不是从 3:1 比例计算出的精确结果：
预算 30 时，最大余数按默认顺序产生 `[23,7]`，本协议明确使用
既有冻结对照 `[22,8]`，不得混淆两者。

调用分类独立记录 action encoder、predict、predictor sample、
observation encode、planner overhead、physical action；失败的尝试
不退款，返回数独立记录，缺失轴不补零。上限是声明值，真实事件须
未来由执行器接线并在每次实际调用处计量；当前接口不能证明外部
调用没有漏记。不同轴可能嵌套，不可相加称 FLOPs。

未来比较需相同根、目标、反馈时点、候选生成合同、动作执行机会、
预算上限和预先约定的结果指标；逐点报告两臂实际开销、完整 wall、
失败与删失。信号生成和调度开销计入产生它的臂，禁止无效调用补齐。
根清单及任务身份须在正式执行前另行绑定；本模块不生成神经信号、
不执行环境或物理动作，不宣称同轴实际调用相等或科学收益。
`P3_admission=false`、`C3_admission=false`；不修改既有 gate。
