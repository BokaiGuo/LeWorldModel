# P1 cp5 图像预处理：官方评估路径对照

在已观察的固定 24 行 cp5 RGB 上，逐行比较 P1 预处理和仓库
`eval.py` 的 `img_transform`，两者均接收相同 uint8 CHW 图像、
分辨率 224。先比较完整 float32 张量位模式，再分别输入同一冻结
checkpoint，比较实际主机 CUDA 编码结果。保留全部行与差值，
不读取或使用物理成功选择样本。重复根和动作不计为独立样本。

仅检测当前 RGB 路径与当前仓库评估源码的一致性；不认证
checkpoint 训练时的真实预处理、训练数据来源、目标编码、历史
绑定或模型物理预测。两路径一致也不能排除共享依赖中的错误，
更不能作为 P1 通过。禁止 CPU 神经推理和模型训练。
