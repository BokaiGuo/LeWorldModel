# TwoRoom 局部与非局部尾部：等查询事后比较

在已曝光的 40 个开发任务上，复用此前封存的候选、冻结模型分数与物理
轨迹。两臂使用同一 lookahead 保留的两个前缀、各 16 条尾部和同一
incumbent；仅以模型分数选择，真实成功标签只用于事后评价。

| 指标 | 局部扰动 | B 库非局部尾部 |
| --- | ---: | ---: |
| 实际选链曾成功 | 38/40 | 38/40 |
| 实际选链末步成功 | 38/40 | 37/40 |
| 本臂候选池含曾成功链 | 35/40 | 31/40 |

曾成功的配对独胜／独负为 0／0；末步成功为 0／1。非局部臂没有
任何任务选择 B 候选，均保留 incumbent。局部臂可能选择不同动作，
但不能以此宣称非局部候选产生收益。

按本次分析前写入的开发出口（曾成功独胜至少 2、独负不超过 1），
该固定非局部方案未通过。**这是事后重用已经被检查的数据，不是独立
预注册实验**；更不能否定其他非局部生成方式。两臂分别计入 16 条
完整链评分与一次 incumbent 重评分，另有共同上游成本；此前联合批处理
和物理轨迹重用不代表部署时免费，也没有形成完整系统墙钟比较。

这项比较没有新增 GPU 查询或环境执行。已验证相同前缀、候选索引、
动作边界、部分源文件哈希、原局部选择和共同物理结果绑定；两项
选择逻辑测试通过。所有物理结果仍来自同一模拟后端，未认证独立任务、
闭环、描述增量或 PC0–PC5。应保留负结果，不以这组固定候选继续
扩大确认。

实验设计技能用于固定每臂权限、成本和判定条件；不能把其工程执行
当作科学 gate 通过。

## 补充核验

独立审计脚本核对 40 根的结果及来源哈希、共同 incumbent 与实际选链
动作指纹、640 条局部候选轨迹身份以及选链物理轨迹；全部通过。
各根 B 库可访问候选的最低分减 incumbent 分数，最小为 **0.9573**，
没有落在 0.005 范围内的根。因此，已观察的同实现重评分漂移不足以
解释 B 臂始终回退；这不排除更大的跨输入、跨硬件或模型误差。该
核验复用同一物理记录，不是独立执行或模型认证。
