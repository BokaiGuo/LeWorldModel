# PointMaze 固定候选逐 packet 对齐：开发诊断

沿用已封存的八任务、每任务八条 25 环境步动作及其双窗口预测，不用物理结果生成候选。先保存每个窗口从 0 到 5 个 packet 的视觉和 proprio 预测，末点必须匹配已封存预测，目标代价也必须复现。每 packet 为五个环境步。

预测封存后，使用已有物理轨迹在时间 0、5、10、15、20、25 重渲染，不生成新动作；初态图片与原输入、末态图片与既有评价图必须逐像素一致。检查时间戳及重渲染前后 qpos/qvel，明确这不是记录的原始现场视频。

使用同一冻结编码器逐时刻编码实际后继，在严格形状一致下比较预测和真实编码的视觉及 proprio MSE；同时比较初始编码保持不变的 persistence 基线。每个任务先对八条候选平均，再对八个任务平均；逐任务结果全部保留。记录预测当前索引与相邻真实时刻的误差作为时钟错位的探索诊断，但不能把较低的错位误差单独当成动作时间错误的证明。

这一已暴露开发集使用完整 proprio，属于 state-assisted。真实后继仅进入评价，不回流规划器；不改变 gate 或声称 RGB-only 收益。
