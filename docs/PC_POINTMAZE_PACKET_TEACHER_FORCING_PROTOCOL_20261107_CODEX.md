# 已选分段链的逐包预测对齐：事后开发诊断

对已封存的八个曝光根、每根 48 和 160 次 CEM 实际选链，物理轨迹的 0、5、10、15、20、25 环境步重渲染，不重新挑选任务或动作。每一步使用原始计划相同的动作归一化及五步打包，比较：

1. 原计划上下文设置下，从归档初始图开始的完整自回归预测；
2. 从同一物理时刻重渲染图和真实 proprio 重新编码，仅预测下一包；
3. 从相邻两次重渲染观察和其中实际动作历史预测下一包；首包使用单帧。

分别记录视觉与 proprio 编码均方误差，以及预测和真实重编码对同一归档目标的代价。记录初态重渲染与规划输入的像素差，复核原计划终点评分。真实观察、状态及动作历史只用于离线 teacher forcing，绝不反馈原选链或作为实际规划收益。相同选链按两条来源记录，不当成独立样本。重渲染、两帧上下文与历史对齐都可能改变输入语义；结果只指示需要进一步核查的失配，不能单独认定代码 bug 或证明反馈收益。

封存源计划、物理轨迹、渲染 worker、脚本及模型指纹，结果标记 state-assisted、已曝光、事后诊断，不改变 PC gate。
