# PointMaze 动作相关误差事后分解

按[诊断口径](PC_POINTMAZE_ACTION_ERROR_DECOMPOSITION_PROTOCOL_20261107_CODEX.md)
对既有四根、每根两个视角、四个固定动作的封存特征进行分析。
按视角平均后再对四根等权平均：

| 指标 | 均值 |
| --- | ---: |
| 预测—真实特征均方误差 | 0.454541 |
| 四动作共同误差的均方 | 0.448654 |
| 去除共同误差后的均方误差 | 0.005886 |
| 预测所有动作没有差异的基线误差 | 0.003947 |
| 中心化动作后果向量余弦 | 0.1303 |

均方误差分解恒等式按每个根—视角条件验证。中心化动作误差
仅在 **1/4 根**低于零变化基线；四根的平均中心化余弦分别为
0.301、−0.036、0.106、0.150。这说明共同偏移占绝对特征误差的大头，
但动作相关预测在此面板也不可靠；不能把失配全部归结为共同偏移。

用同一组四个真实后继的均值计算事后 oracle 偏移，并用于校正预测
后再选动作，四根平均物理距离遗憾由 0.03993 降至 0.02942。
这是利用未来真实观测的不可部署对照，不证明可实现的校正、真实
闭环收益或统计显著性。
