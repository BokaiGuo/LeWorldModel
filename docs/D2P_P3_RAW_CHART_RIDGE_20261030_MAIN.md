# P3 raw 坐标一致求解：开发组件

新组件 `experiments/spectral_reachability/p3_raw_chart_ridge_20261030_main.py`
直接在 raw 动作坐标上最小化线性残差与 ridge penalty，约束逐项
`[-1, 1]` 及原 L2 半径。返回 float32 raw 动作并在转换后重新计分，
不额外应用 tanh；优化失败、非有限值、违反约束或劣于零动作时拒绝。
SLSQP 的 success 是数值求解状态，不是严格全局最优证书；代码尚未
接入生产 P3 调度、CUDA 模型、物理执行或任何 gate。

对双分支已失败四个决策、两个时域的保存控制和候选（4×2×9=72 条），
用其原任务目标、nominal 和 Jacobian 做事后线性代价诊断；旧实际
raw 和新 raw 均使用相同 `||r-Ju||²/192 + .002||u||²/192`
计分。72/72 新解低于旧 raw 的线性目标超过 `1e-9`，最大差
`0.03166601160163962`。日志 SHA-256 为
`ff67c50f2f76b2d0bc3efcc774e60e42c8a55c564f6beaa4e9d706aa74e61da2`。
这些行包含重复策略和已知根，不是独立样本；该计算只是使用保存
数组的线性代数，没有神经推理，不可说成 CUDA/物理实验结果。

五项单测覆盖内点闭式解、同时存在动作盒和 L2 约束、非法形状
与非有限值拒绝。下一步需要事前固定独立开发合同，将新旧动作
在相同输入、调用及资源账本下进行**主机 CUDA 非线性 rollout**
并真实执行，之后才可能评价坐标修正是否改善控制。线性目标改善
不保证 rollout 或真实任务改善，也不能解除原 P3/P1 gate。
