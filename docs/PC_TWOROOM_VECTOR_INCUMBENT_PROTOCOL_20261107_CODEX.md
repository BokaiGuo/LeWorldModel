# TwoRoom 向量保留加入已评分原链：开发协议

在已曝光 40 根上，使用既有冻结候选、已有四个选择规则和相同模型；把生成前缀时已经评分的 block-CEM、block-random 两个 300 链池的各自最低分链，加入每个规则的最终竞争。原四臂各自先前选中的链与两个原池最优链一起以相同批量重新评分；固定 tie-break 为旧选中链优先，然后 CEM，再 random。仅改变最终竞争候选，不改变原候选生成、探针、保留、精修、预算或物理成功定义。多次模型评分费用需明确记录。

先封存 RGB 输入条件下的选择与动作哈希，不能在此阶段读取物理标签；随后评价端从相同初态独立重放旧链、新链和两个原池赢家，保留每步轨迹。检查旧链重放与原实验曾成功、末步成功和逐步距离一致；不一致则停止解释。模型复评分与历史评分的差异及原池赢家身份完整保留。报告四臂新旧成功变化、成对得失和向量与 lookahead 的对比，同时报告两个原池赢家；按任务而非链计数，统计只是开发描述。

该实验针对漏掉可用 incumbent 的具体实现问题；如果没有提升或出现物理退化，应保留负结果，不将模型分数单调改善当成修复成功。复用所有已曝光任务，因此不构成独立确认、完整成本优势、描述机制或任何 gate 通过；不得使用评价端状态或真实后继做选择。
