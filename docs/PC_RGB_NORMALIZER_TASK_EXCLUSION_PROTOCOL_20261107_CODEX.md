# TwoRoom 任务排除 normalizer 敏感性协议

现有 `model_setup` 对 TwoRoom HDF5 中所有非 NaN 动作拟合标准化器；episode 9000–9039 从同一文件提取。先用 `ep_idx` 和原始有限值规则确认这 40 个任务有多少拟合行，并校验源 normalizer 与既有实验一致。新标准化器对同一文件除全部 40 个任务以外的动作拟合，不得按成功或动作值筛选；固定种子、任务、目标图、冻结模型与原 CEM16 和 effect 规划规则。

逐任务独立进行实际 RGB 反馈，排除组规划器只使用排除组统计、当前及目标图和合法旧尾。比较已封存的全数据拟合正常izer原臂；逐次保存计划、派发、真实轨迹、成功及查询成本，报告参数差异、变化选择数量与成功配对结果。本实验是对 normalizer 敏感性的已曝光任务开发检查，不是重新认证原始模型训练所使用的 normalizer，也不自动证明 checkpoint 训练成员独立、任务开发独立或独立确认。不得将排除后结果改写为官方协议复现。
