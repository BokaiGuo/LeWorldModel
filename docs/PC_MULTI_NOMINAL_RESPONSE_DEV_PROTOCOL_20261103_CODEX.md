# 多名义动作与时域候选生成：开发合同

这是新候选生成协议，不复用旧结果作为确认、不指定任何根或目标方向。对调用方提供的有限时域模型预测接口，固定使用 5、10 步长度及三个与物理 outcome 无关的名义动作：全零、第一动作坐标 +0.25、第一动作坐标 -0.25；每个名义动作都在全部时间步恒定。对全部原始动作坐标做中心差分，epsilon 0.05，奇异值非零的首方向取正负扰动 0.25，动作投影至 [-1,1]。记录名义、长度、Jacobian、奇异值、投影后的动作和实际模型预测响应。不同长度分别用预测响应的最远点贪心规则保留最多四个候选，规则和 tie-break 不依赖任务物理结果。

该生成器只提出候选，不评价或挑选最终程序；完整后缀的非线性模型评价、真实执行与共同后缀干预需要后续接入。模型预测调用和 SVD 次数由传入的计量边界记录；该生成器本身不能声称端到端预算认证。当前 PointMaze 预测接口按五步打包，故长度只能取 5 的倍数；后续不得把 10 步计划只执行 5 步产生的状态当作完整前缀机制见证。
