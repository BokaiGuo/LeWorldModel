# TwoRoom 生成式见证任务：来源与强基线开发协议

固定 40 个 reset seed `1778800..1778839`，每根用独立 `1779900+i` 随机流采样五个 `[-1,1]^2` 常值动作块，每块执行 5 环境步；25 步末状态作为目标。执行中不按任何成功或运动结果重采样，也不删除初态已成功、静止或跨墙失败的根。目标图由环境既有目标渲染生成；同初态重放原动作见证并逐步验证距离与末态。该构造确保本地动力学下存在合法动作见证，但产生的任务分布可能容易，不能替代标准性能集，也不证明非贪心机制。

分别保存仅含 RGB 与 seed 的公开输入、仅供评价使用的状态和见证，以及实际参考轨迹。使用固定 HDF5 拟合的 normalizer 和原 RGB CEM300，在每根最多执行 25 步，每五步重观测，保留合法旧尾，先后记录完整决策和真实轨迹。所有样本按生成顺序纳入；初态成功与否分别报告。不运行已停止的 effect 配置，也不以该基线成绩为行动后果描述贡献。

对本地 HDF5 所有长度至少 26 的 episode，检查与生成任务的初态及第 25 步位置对是否逐值相同；此项仅排除该具体状态对，不证明图像、语义、训练成员、checkpoint 或其他历史任务独立。任务采用新模拟器 reset 与新参考动作，不从该 HDF5 的 episode 读取；HDF5 仍用于 normalizer 拟合。不得据此标记独立确认或改判 PC0–PC5。任务和结果此前对本研究未封存，种子也不能证明训练外。
