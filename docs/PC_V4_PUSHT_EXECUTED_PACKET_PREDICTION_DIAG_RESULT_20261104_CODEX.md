变化以该片段执行前为基准，负值表示该指标下降。六次模型预测的 latent MSE 都低于“下一编码等于当前编码”的持久基线；但物体位置变化的三段预测误差明显较大。CEM 第三段甚至出现目标 latent MSE 预测下降、真实编码上升。另一方面，真实编码目标 MSE 下降并不保证物体更接近目标：例如 response 第三段下降 0.235，但物体位置距离增加 27.596、角度距离增加约 0.198 弧度。这里的相关性不能建立接触导致模型误差的因果关系。

两臂最后一段的单 packet 预测目标 MSE 分别为 1.34285915、1.51458919，与原计划记录中的 1.34285903、1.51458931 相差约 1.2e-7；差异来自独立批次计算的数值精度范围，非动作或终点转换的可见大错。更早决策的原评分对应较长完整链，不能拿来与下一 packet 实测直接比较。

[原始诊断数据](../le-wm-main/results/pc_v4_pusht_executed_packet_diag_20261104_codex.json)绑定运行依赖和输入哈希；动作及边界图像也与原逐步事件核对。物理状态只用于事后评价。结果指出模型预测误差及目标 latent 与物理目标不一致都是需要继续排查的实际风险，但无法单独区分模型误差、公开动作统计与 checkpoint 不一致、时钟或视觉域因素，也不能解释全部搜索失败。原始单根负结果不因此变成代码 bug 或理论否定；PC0–PC5 状态不变。
