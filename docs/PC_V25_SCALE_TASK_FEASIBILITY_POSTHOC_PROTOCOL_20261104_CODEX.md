# v25 幅度面板的事后可行性见证协议

只使用已完成且审计通过的 v25 候选幅度开发面板。对每根任务采用既有墙体特权几何构造的上下两条路径，分别检查 15 步内是否能够表示；可表示时转成与规划器相同的归一化 float32 动作，限制在 `[-1,1]`，并用同一精确动力学和另一几何实现重算。严格使用原有 `<0.05` 终距成功条件。

见证构造恰有上下两种固定路径，不再调整或追加搜索。该诊断在原实验之后进行，且使用特权几何，只能证明被验证的任务在声明动作域及时域下可解；不能计为任一规划臂的成绩，不能注入候选或改变已停止实验。找不到见证时可解性为 unknown，不证明不可解。需记录两个构造的步数、资格、动作、轨迹、碰撞、终距、源文件哈希和结果；不声称该构造符合正式 PC0 的 oracle 预算。
