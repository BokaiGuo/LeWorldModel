# 第二轮重观测后的预测、编码与物理对齐：开发诊断

在已完成完整物理普查的任务 15、25、35 上，对普通 lookahead 和响应两臂，
复用各自真实的第二次规划候选与同次模型预测。对每池选择模型最低分、
实际选中均值，以及存在时的模型评分最低成功链；成功标签仅用于事后
诊断，不输入规划器。任务和代表链均非独立确认样本。

每条代表链先从原始 reset 重放实际前 25 步并逐步核验物理快照；
第二计划依次执行 25 个环境动作，按 0、5、10、15、20、25 步
记录真实编码，与对应模型表示、冻结目标编码及物理成功对比。

距离及每步代价见各 `*.alignment_panel.json`。
