# 前缀配额实验：动作身份与全池覆盖审计

按[事后协议](PC_EXACT_PREFIX_QUOTA_COVERAGE_AUDIT_PROTOCOL_20261107_CODEX.md)
重建 24 个任务的动作和历史评分后，评价端逐根检查完整 B 池。

- 每根 8 个前缀、64 条 B 尾部均逐元素不同。五臂各 192 条 B 查询中，
  没有臂内重复完整动作，也没有重复本根共同名义/A 池的完整动作。
  这是精确动作相等检查，不代表动作之间没有近似重复。
- 24 根中有 **10 根**存在 B 组合优于共同 incumbent；只有 **2 根**
  在 incumbent 未成功时含有新的成功链。两根的成功 B 组合分别为
  3/512 和 8/512，五个历史策略都没有查询到这些成功组合。
- 因此该开发面板的成功率至多有两根可以因选择 B 而产生新增成功；
  五臂均为 11/24 并不能证明它们对所有候选或任务完全等价。
  它也没有推翻预先对固定配额规则的停止决定。

审计逐根验证原候选、共同池及各臂已评分 B 的成本；评价端新增
12,288 次 B 组合评分，不属于任何原规划臂预算。逐项动作身份、完整
B 成本和摘要见
`le-wm-main/results/pc_exact_prefix_quota_coverage_audit_20261107_codex.json`。
身份及全池辅助函数相关测试 **5 项通过**。

PC0–PC5 判定。后验 B 真值未用于重新选择任何历史动作。
