# TwoRoom 失败任务中成功链的预测与真实编码

对已暴露任务行 82490，固定比较此前发现的 **12 条成功精修链**与 parent、lookahead 两条失败选中链。重新评分及物理重放后，12 条成功链的逐步轨迹与上一实验完全一致；模型分数与封存值最大差约 `1.53e-4`。

| 链 | 预测目标代价 | 真实末帧编码目标代价 | 物理末距 |
| --- | ---: | ---: | ---: |
| parent 失败链 | 298.067 | 281.599 | 21.146 |
| lookahead 失败链 | 313.982 | 329.059 | 94.285 |
| 成功链 0/29 | 313.936 | 294.885 | 15.732 |

按真实末帧编码代价，parent 失败链比 **12/12 条曾成功链**都更接近目标；其中 11 条在末帧仍成功，另一条曾成功后离开。故对这个被事后选择的候选组，任务评分失配不只存在于预测后继：即使用真实末帧经同一编码器评分，也会优先选择 parent 失败链。另一方面，lookahead 链的预测分数低于成功链 0/29 以外的 11 条，但真实编码中有 3 条成功链分数低于 lookahead；在这些具体配对上还存在预测与真实编码排序不一致。

这两种现象可以并存。目标是末帧 latent 代价，而成功是 25 步内曾达到距离阈值；单根候选不能证明哪项失配主导整个 benchmark，也不能单凭数值宣布存在实现错误。成功链是事后物理评价选出的，不可提供给部署规划器。本研究未改变评分函数、原选择或 PC gate。

14 条链的分数和表示均方误差见 `le-wm-main/results/pc_tworoom_successful_refinement_alignment_20261107_codex.json`；预测和真实表示另存于同名前缀的 `features` 文件。
