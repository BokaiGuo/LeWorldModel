# D2P：相同物理状态的单像素渲染分叉审计

## 当前结论与范围

完整主机CUDA v3已完成：八根/三任务/17程序共408单元、22576条真实未来、
47192个predict样本、816个完整Jacobian，13项完整性门全部通过。原52单元
逐位对齐，原失败点202652006/full_drive/program16及后续全部完成。模型参数、
buffer、原始权重、输入与封存实验源码均未改变。这里证明该固定观察策略下
全库回放故障已排除，不证明历史P1排序或重配置机制已修复。

完整17前缀能力地图两次在第七根失败，不能记成C2机制负结果。
第二次失败回执准确定位到202652006/full_drive/index16。完整物理积分状态、
模型/场景SHA、关节、过去RGB均一致，终态RGB却不同；192维表示最大差
3.55839729309082e-5。严格逐位检查保留，没有放宽阈值或丢根。

已新增单根完整探针顺序复现器，实测1394条真实未来、2809次观测渲染，17个
原前缀的RGB与192维表示均逐位复现原物理报告。与不插入探针的204条零未来
复查不同，完整顺序在同一index16稳定复现分叉：**只差一个像素绿色通道**，
HWC坐标[184,39,1]、最大像素误差1。九组物理派生数组全部逐位一致：xpos、
xquat、xmat、geom_xpos、geom_xmat、cam_xpos、cam_xmat、light_xpos、light_xdir。

这排除了本例积分状态或这些派生几何不同所致，定位到渲染/量化路径；尚未
据此声称某个具体OpenGL状态就是根因。本例goal-MSE从2.1418321200265207
到2.1418326727544015，变化5.527278807981872e-7；这不是所有历史P1反转的
解释，也不证明重配置成功。原模型、归一化统计与任务目标保持不变。

## 受控干预与独立复核

先检验OpenGL dithering这一单一因素。命令显式`--gl-policy disable-dither`，
保存每次原始render前后实际GL_DITHER状态；仍要求完整原根快照与17原前缀
逐位身份。若图像分布/源身份变化，必须记录失败，不能把近似相同当作通过。
若单根通过，也必须回到原52单元对齐及完整八根/三任务能力地图验证，不能用
一根成功替代全库确认或开启P1。

截至目前五份完整记录已由独立分析器复核输入SHA、归档生成器SHA、全部17程序、
物理未来计数、完整状态/渲染流身份、保存的两张RGB原图及像素差分坐标：

|诊断/干预|真实未来|原前缀逐位复现|同状态图像分叉|
|---|---:|---:|---|
|原顺序复现|1394|17/17|index16同一绿色通道1单位|
|关闭dithering|1394|17/17|仍为同一像素，排除该单因素|

`le-wm-main/results/reacher_d2p_render_replay_analysis5_20261026.json`。

单因素候选`--gl-policy warm-render`已通过该失败根：每次先执行
一次不推进物理状态的渲染，再读取第二次实际渲染。它不查缓存、不修改像素、

物理状态；预热与保留图像差异为零。此结果仅支持该根的候选修复，不证明P1。

复用实现为`reacher_d2p_fixed_warm_render.py`，固定策略名

## 跨渲染策略的非零探针敏感性

对v2/v3共同完成的前六根，按root/task/program独立比较全部306单元：
305个完整单元逐位相同；唯一差异为202652001/shoulder_only/program4，
scale=0.25、coordinate=9、plus端点。该单元所有非probe字段，包括prefix、
两次零未来、两套完整Jacobian、预测向量和计数，均逐位相同；该端点保存的
raw动作、qpos和模型预测也相同，仅RGB SHA与观测表示改变。190个表示分量
改变，最大绝对差2.002716064453125e-5。端点未保存原始图片，不能声称它
也只差一个像素；保存的qpos相同也不替代完整跨策略终态比较。

独立复算该端点影响的物理RGB共同残差增益比例，从0.023910116326425517
变为0.023911256372540365，差1.14004611484822e-6。物理关节探针不变。
这是显式观察策略的敏感性记录，不将差异隐藏成“全部旧探针逐位一致”，也不把
微小变化据为P1修复。后续全库分析统一使用完整v3，不混合v2探针；原52单元
严格对齐合同继续保持。
