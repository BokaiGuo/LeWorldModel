# 相机几何修正后的同动作预测开发实验

前一相机网格以曝光任务 1884–1887 的初态归档帧选出 lookat `(3,3)`，在曝光任务 1888–1891 初态亦逐像素匹配。该设置为后验开发校准，不是官方设置认证。

比较新旧渲染协议时固定这八根的初态、目标物理状态、八条动作链、模型、两个上下文窗口、归一化和末帧多模态代价。当前及目标均使用修正相机渲染，不能只改变当前图；预测在读取物理轨迹之前封存，目标 proprio 属于 state-assisted 合法输入。

随后在真实物理轨迹的 0、5、10、15、20、25 环境步重渲染相同修正相机图像，冻结模型编码真实后继，仅作评价。报告各步视觉、proprio 表示 MSE 与 persistence；最终预测代价对真实编码代价、物理末距的任务内成对排序；选中链物理末距遗憾；与原 `(3,2.5)` 相机的相同指标并列。目标距离及成功是评价标签，不参与规划。逐任务保留全部分母及初态已成功标记。

这是同一已曝光开发面板上仅改变相机的诊断，不是闭环收益、正式测试或 RGB-only 证据。即便视觉预测改善，也需单独验证新环境真实相机、视角变化、候选搜索、完整预算和独立任务，不能把像素匹配当作性能结论。
