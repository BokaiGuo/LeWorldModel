# V5 响应臂：固定随机桥接补充开发诊断

接续已封存的 v5 同库事后诊断，补此前缺失的 random bridge：每个暴露根用种子 `2027112300 + root`，生成一组标准正态的 4×2 knot、逐坐标线性插值为五步并裁剪到 `[-1,1]`。此种子和构造事前固定，不按结果重抽，也不读物理终距选择前缀。

对每根随机前缀应用与同库诊断一致的零尾、119 个 CEM 搜索样本与 `2027111400 + root` 共同随机流、五组固定常量尾和该根最终选中尾。另与 selected 一样在相同裁剪尾的 `.01/.05` 中心差分计算后续响应、任务梯度与障碍分支；保存全部执行动作和结果。与前一审计的 selected 条件成对比较，报告绝对终距、相对零尾变化、同预算重规划、响应差与分支稳定性，不能把随机桥接搜索成本藏进方法预算。

这是已知结果之后新增的随机对照，不是事前确认；随机前缀可能无意义、119 样本不足，不是强搜索上界或唯一随机分布。它不改变其他对照或原始选中链、不证明 PC2/PC3 通过。封存源、协议、动作、轨迹及审计。
