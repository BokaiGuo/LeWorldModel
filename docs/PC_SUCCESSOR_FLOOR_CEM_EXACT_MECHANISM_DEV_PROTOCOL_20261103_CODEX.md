# 新版最终链的同链干预开发协议

本协议在新版本规划成绩揭晓后制定，是暴露根上的事后机制诊断，不是 PC2
确认。固定读取已封存、已经完成 zero-prefix 比较的 24 条 successor 最终链；
无论是否弃权都不替换链。控制为全零五步前缀和同一首次候选库中按五步精确
终距选出的 greedy。每根每个前缀依次拼接同一后缀族：十步零、十步
`(.5,0)`、`(-.5,0)`、`(.5,.5)`、`(.5,-.5)`，以及该根最终链后十步。
记录各自前缀终距、绝对最终终距及相对各自零后缀最终终距的变化。

各前缀另使用新版本 `0.05` 下限 CEM、相同根随机种子
`2026121000 + root`、每前缀 120 次完整链评分独立重规划，记录所有动作
和评分。按旧同链筛查条件报告：前缀非即时进展、最终链后缀相对零后缀的
变化同时优于两个控制、各自重规划终距同时优于两个控制及三者交集。
这些只是有限后缀族和有限优化预算；不把该交集自动称为 PC2 通过。
全部评分须逐条重算，输入和脚本按哈希封存。
