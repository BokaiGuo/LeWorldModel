# TwoRoom 分段动作：50 任务 RGB 开发对照

协议：`PC_TWOROOM_BLOCK_CEM_50DEV_PROTOCOL_20261107_CODEX.md`。冻结 RGB
LeWM，每臂每任务评估 300 条 25 步动作链，选择模型评分最优链并在物理
环境执行；三个候选生成器、三条预定随机流。所有任务均为已曝光开发数据。

这支持继续将动作参数化视为候选生成器或更强基线；不能归因于行动后果
描述、程序合成或闭环反馈，也不能证明相对充分调优的最强 CEM 有优势。
每臂平均生成加 GPU 评分时间分别为 0.1261、0.1217、0.1215 秒；该计时
不包括完整任务成本，不能支持完整系统效率结论。

## 核验

- 六项相关单元测试通过。全部 50 根的候选尺寸、边界、分段保持、
  最低分选择和成功规则通过封存审计；前 10 根的逐步 CEM 和分段随机
  物理轨迹与前次记录一致。
- 固定抽查 4 根、3 臂的全部 3600 条 GPU 分数，利用种子和精英记录
  重建评分时归一化输入，最大误差 `0.0004272461`，各臂最低分选择
  均一致。这是同实现重放，非独立模型或环境认证。
- 初次审计从保存的 float32 物理动作反推归一化动作，在第 50 根逐步
  CEM 上最大分数差 `0.003967285`，选择仍相同。改用实际采样随机流
  重建后误差降至 `0.0004272461`；结果与动作往返舍入敏感性一致，
  但未单独排除 GPU 浮点非确定性。后续应同时封存归一化模型输入，
  不应假设物理动作反变换能逐位重现它。
- Gymnasium 提示 reset 观测类型与声明不一致，以及动作转换类型警告。
  本次规划使用封存的 RGB 输入，物理执行检查动作范围；这些提示不等于
  已完成环境接口认证。
