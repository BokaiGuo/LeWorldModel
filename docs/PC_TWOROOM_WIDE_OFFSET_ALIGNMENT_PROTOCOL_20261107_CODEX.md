# TwoRoom 宽门偏移候选对齐：开发协议

在相同 40 个已曝光 cross-wall 任务上，事前固定 13 个 RGB 门偏移：
`0, -3, +3, -6, +6, -9, +9, -12, +12, -15, +15, -18, +18`
像素；增益均为 1，时域 25 步，复用已修复到点逻辑。偏移规则只取
可见 RGB 提取的门中心，动作有界，不使用隐藏状态、真实接触或物理
后果生成候选。偏移 0 是固定几何基线；不能因为结果修改候选范围。

阶段一在 GPU 上用冻结 LeWM 封存每条完整动作链、每个 packet 的预测
表示、目标表示和评分，并按五个 packet 最低代价选择链；阶段二才
加载物理重置真值，逐链重放完整 25 步，记录物理距离和成功状态，
并用同一冻结编码器计算每五步真实后继表示。仅评价端读取物理信息。

按 root 报告：物理候选成功数、模型选中链成功、固定零偏移成功、
模型与真实编码对成功/失败对的排序（平分计半）、无可区分对任务数、
以及各偏移成功率。只在 root 内算对，再对有对的 root 等权平均；
偏移/链不是独立任务。精确保存逐链轨迹、预测/真实表示、模型哈希、
动作、依赖和时间对齐。结果用于开发诊断，不是独立任务、完整
闭环、门槛认证或行动后果描述增量。
