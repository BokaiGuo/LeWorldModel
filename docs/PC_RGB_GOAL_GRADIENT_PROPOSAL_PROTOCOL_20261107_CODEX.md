# RGB 目标梯度候选：固定起点开发协议

## 假设及范围

先前最大奇异方向最大化末态表示变化，不保证对当前目标有利。检验：
用冻结模型的目标代价对物理动作求梯度，能否在相同候选评分机会下，
比同一名义链的已封存谱方向／随机方向选出更好的真实动作链。
这是普通梯度基线，**不是**行动后果描述或新机制。

使用已曝光 TwoRoom episode 9000、9013、9022、9032 和已封存谱实验的
共同名义链、实际复位 RGB 与目标图。物理状态只用于初始化和评价；
模型、normalizer 和相关工件哈希不一致则停止。名义链逐坐标在
`[-0.7,0.7]`。优化输入为 25×2 物理动作，目标为冻结模型 25 步末帧
latent 代价，梯度经过动作归一化，模型权重不更新。计算梯度使用 math
SDPA、禁用 TF32 的已认证局部后端。

每任务用负梯度按最大绝对坐标归一化，构造父链及 ±0.15、±0.30 四个
候选，共 5 条，合法性逐条检查；按冻结模型最低分选择，平局取最小索引。
在同名义链上按 0.001 中心差分核对梯度方向导数，失败记录并停止物理
结论升级；开发数值判据沿用 `绝对误差 ≤ 0.1 + 0.01 × |自动微分值|`。
计入一次梯度前向／反向、两次差分前向及五候选批量评分，
同步计时；旧谱臂需要完整 Jacobian 和 SVD，随机臂不需要反向，**不是
等计算成本比较**。

先排他封存全体计划，然后评价端从同初态分别执行每个梯度候选 25 步
（truncation 时停止），记录逐步距离、成功和终止；不以真实反馈选择
动作。与既有谱／随机原始轨迹配对报告每任务选中链成功、终距、候选池
成功、模型分数及起点情况。保留初态已成功任务并单独显示，不把链数当
独立任务；不把模型分数变好、池中有解或该小面板结果当闭环性能优势。
本次只用于决定此具体候选是否值得进一步开发，PC0–PC5 不自动改判。
