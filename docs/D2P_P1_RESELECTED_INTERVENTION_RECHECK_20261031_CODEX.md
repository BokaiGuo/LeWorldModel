## 对当前问题的含义

新重选前缀的共同十步后缀与从各自真实 cp5 RGB 规划并物理执行的
结果都已存在，详见 `D2P_P1_UPHILL_H10_COMPLETE_RESULT_20261031_MAIN.md`。
对应的共同四起点 Adam 记录中，selected、zero、greedy 原生成功
分别为 0/8、5/8、0/8；记录共享两个已知根，不能解释成独立成功率。
前缀生成成本未进入完整统一预算。

反馈成功动作链另有共同后缀干预：同一 selected 反馈后缀在 zero
前缀下也原生成功，因此该实例不能证明成功来自 selected 前缀独有的
后续能力。详见 `D2P_P1_PACKET_FEEDBACK_CROSSOVER_RESULT_20261031.md`。
这不排除其他候选、任务或动作族中的能力改变。

root 0 的 selected 前缀虽未改变物体位置和角度，却改善推杆目标和
原生联合 XY 误差；不能由物体未动认定整个任务无即时进展。物体、
角度、推杆和原生成功必须按各自指标报告。已封存合同未事先单独
固定新的全任务非即时进展指标，不能依据结果反向补定。
