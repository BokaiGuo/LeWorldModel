# 自动保留前缀：等预算重启曲线协议

使用已停止的 v25 幅度开发面板八根任务、两臂各自首层 response 保留的四个自动候选，保持原保留顺序与原始动作，不注入特权见证。两种逐步动作 CEM（零初始化、均匀随机初始化）按已定规则各运行 8 次重启、每次 121 完整链样本；只记录预定的 2、4、8 次重启累计结果。每个预算点两种初始化使用相同每前缀样本预算。不同前缀的随机初始化使用其在原保留集合中的顺序生成，配置在执行前固定。

记录每个候选和每个原规划根×臂的最低终距、`<0.05` 成功、各预算点样本、实际 token、失败与原保留索引。不能改变原规划选择或者将诊断中事后最佳前缀当作正式方法输出。使用独立的诊断预算，不能解释为等总成本方法优势。

每次预测尝试、实际动作和返回结果写入账本；审计来源及预算、另一同环境几何实现、优化器逐批回放、固定前缀和原保留顺序。任务已暴露，结果仅用于开发，不能证明独立优势、PC2 或 PC3，也不能因未找到成功尾部而认定不存在。
