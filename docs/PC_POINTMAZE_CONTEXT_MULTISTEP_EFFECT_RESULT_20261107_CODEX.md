# PointMaze 多步动作排序：上下文窗口开发对照

依照 `PC_POINTMAZE_CONTEXT_MULTISTEP_EFFECT_PROTOCOL_20261107_CODEX.md`，
在八个已曝光任务上先对同一组八条固定、合法 25 步动作分别封存
窗口 1/2 模型评分，再从归档 float64 初态用同一物理后端重放。
每个窗口每根计 8 次逻辑候选评分，真实后果不参与模型动作选择。

| 指标 | 窗口 1 | 窗口 2 |
| --- | ---: | ---: |
| 八根等权平均：预测代价／物理末距成对排序一致率 | 0.683 | 0.652 |
| 八根等权平均：选中链末距相对池内最优遗憾 | 0.333 | 0.326 |
| 初始未命中的六根：平均排序一致率 | 0.708 | 0.637 |
| 初始未命中的六根：平均末距遗憾 | 0.333 | 0.325 |

窗口 2 的平均遗憾略低，但平均排序一致率下降，**没有满足事先
要求两项同时改善的开发信号**。两个初始已在 0.5 半径内的根保留
在八根总结果，并在六根分层中单独标记；不能事后把六根替代全体。
两窗口选中链的 25 步内曾命中均为 8/8，但包括初始已命中情况，
且这是继续执行完整链的开放环距离诊断，不是官方完整 episode
成功或闭环收益。候选对和两个窗口共享任务与物理轨迹，不能当作
独立样本。

本次只限制固定随机动作库和该模型／目标评分下的窗口修正作用；
不否定其他候选、模型或后果描述，也不推翻窗口 2 在同源归档动作
上的预测 MSE 改善。动作库构造及排序边界测试 **2/2 通过**。
结果使用完整当前和目标 proprio，属于 **state-assisted**；数据
已曝光，不能作为 RGB-only 或 PC0–PC5 通过证据。
