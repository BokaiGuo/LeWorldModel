# 精确墙障：预测受阻触发侧向脱困开发协议

已有审计显示，精确墙障候选常在障碍前受阻；仅修复名义阶段提前切换
没有增加成功。本实验检验一个不同假设：在模型模拟链的每一步检测到
非零移动请求没有产生位置变化时，暂时朝该请求方向的垂直方向移动，
完成固定距离后回到原 waypoint，能否改善覆盖。

固定已曝光 24 个根、原目标相对几何实验每根全部 384 个偏移、每条
15 步、原始动作边界及 `<0.05` 成功规则。每候选的脱困侧按候选序号
奇偶确定，距离按序号分配 0.3 或 0.6；无需真实墙坐标、物理标签或
其他候选后验信息。每步在预测状态上构造动作并调用一次精确动力学，
因此每臂每根均计 `384×15=5760` 模型步；完整动作见证可重放。
对照为原 384 条已封存的目标相对 waypoint 动作，成本相同计法。
本配置不额外保留对照最优候选，也不把事后真实最优链免费提供给
任一部署臂；同时报告两臂共同 incumbent 的事后上界而非方法成绩。

事前开发出口：脱困臂相对原臂至少 3 根成功独胜、至多 1 根独负，
否则停止扩展本固定规则。报告所有根、平均距离、阻挡和实际触发，
测试并重放动作、边界、时钟与代价。墙障动力学既是模型也是评价
后端，结果不是视觉、独立任务、完整计算成本或行动后果描述证明。
