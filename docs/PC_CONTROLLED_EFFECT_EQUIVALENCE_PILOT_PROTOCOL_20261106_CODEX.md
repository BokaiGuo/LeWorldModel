# PushT 受控动作后果等价：四任务 pilot 协议

运行前固定。使用官方数据训练集面板前四个已暴露任务；模型和动作
normalizer 与已有 PushT 有界开发实验相同，禁止后训练。每任务选用
同一数据集方块初始姿态与目标状态，推杆分别置于方块 x 坐标 ±60、
y 相同的位置，速度置零。两状态是**候选接近配置**，不预称接触，
记录 reset 后实际物理快照、几何和实际动作接触计数。

每种状态在同一物理 reset 下从模拟器原生 renderer 渲染白色背景和
浅灰背景（RGB 245,245,245）。目标图像使用相同目标物理状态和各自
背景重新渲染。背景扰动是外观控制，**不是第二相机或透视变化**；
不能推断相机不变性或训练支持范围。渲染前后核对快照，跨背景复位
后核对物理快照；保存原始图片及内容 hash。

每个状态执行相同世界坐标的三个合法相对控制：零向量、x 正 0.5、
x 负 0.5，各持续 5 环境步，按 checkpoint 的动作打包和数据 normalizer
转换成 1 个 10 维 packet。零控制仅是对照，不声称物体物理静止。
每次探针从独立 reset 开始，执行全 5 步并记录每步实际 state、接触、
success 和末帧；背景只影响 renderer，不影响动作。严格核对两背景
物理轨迹相等，并保留全部任务和失败。

同一初态、相同目标、同一动作对照下记录：冻结 LeWM 预测目标代价、
真实后继图像经同一冻结编码器的目标代价、物理目标状态距离；
分别以各自零控制作差形成有符号后果向量，记录背景差异、状态差异、
正负动作排序及接触。预测与真实编码共享尺度，物理距离单位不同，
只比较符号和排序，不直接相减。每任务为统计单位，不把 12 个条件
作为 12 个独立任务。

这是明确的接口／可操作性 pilot，没有事前确认性功效或 PC1 通过阈值。
不得以背景一致单独宣称有效（常量预测也能满足），不得仅凭状态差异
宣称真实接触效果；动作正负也不是一般物理逆操作。模型预测保持
`model.get_cost` 原实现，若发现动作时钟或预测长度不一致，应中止并
另立版本，不得自行悄悄修正。目标／当前的物理真值仅用于离线诊断。
