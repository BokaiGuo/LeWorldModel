# PushT 已执行片段固定双统计量对照协议

对上一项六个已执行片段的事后误差诊断，增加固定的两套已知动作统计对照：原公开示例均值/标准差，以及既有本地 HDF5 全动作字段的 mean/sample_std。后者来自 `pusht_d2p_archive_action_statistics_v1_20261026.json`，不是 checkpoint 训练统计证明。不得拟合新统计或按结果选部署配置。

同一 checkpoint、输入 RGB、目标 RGB、三段原始历史及实际派发五步命令不变。每臂都从原始动作重建全部历史和未来 packet，使用其各自统计做一次标准化，预测同一个下一真实 RGB 编码。对六段全部报告两统计下的预测—实际 latent MSE、目标 latent MSE 变化及预测差异；对照持久基线，保留全部结果，不挑成功片段。公开统计臂应复现上一诊断的六项评分（允许绝对误差 2e-6）。

本对照不修改旧实验结果、不重新控制、不做额外物理交互、不据此改变方法或 gate。即使其中一套更好，也无法认证训练 normalizer、排除其他模型或输入问题，不能证明接触因果机制。
