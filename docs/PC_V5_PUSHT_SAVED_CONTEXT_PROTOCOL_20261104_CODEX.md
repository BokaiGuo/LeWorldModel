# V5 PushT 保存上下文模型接线协议

复用四个已暴露 PushT 历史 latent 上下文及 v4 保存上下文执行器，签名适配后原样调用 v5 response 核心，使用固定 checkpoint、公开动作统计、15 步与 1920 prediction-token。逐根先核对 5/10/15 步三类固定动作与既有逐 packet 参考路径，然后保存全部候选动作、预测和最终链，并通过独立的显式 packet 路径重算。

输出与历史结果隔离、不覆盖，绑定适配器及 v5/v4 响应和优化依赖。这里只检查模型接口，不采集 RGB 或派发动作；历史训练来源与公开动作统计是否为 checkpoint 原训练约定均未知。不以模型 MSE 声称接触机制、任务成功、PC4 或泛化。
