# P1 真实终帧编码与推杆误差配对

使用已有主机 CUDA 终帧编码与已封存物理状态，对同根、同条件的
完整十步记录做全部两两组合；逐行核对身份、停止状态和物理指标，
并独立复算保存的实际编码目标 MSE。结果包含每对推杆位置差、物体
位置和角度差、latent 差与目标距离排序；未使用这些数据作动作选择。

24 行中 22 行完成十步，2 行分别在第 4、9 步原生停止，没有十步
终帧，显式列为缺失而不补值。22 行产生 51 个组内配对，其中真实
编码目标 MSE 与真实推杆目标误差的排序 39 一致、10 相反、2 平局。
只有两对物体位置和角度都精确相同，且这两对推杆位置也完全相同，
属于重复状态。因此这不是“只改变推杆位置”的控制实验，也不能由
这些计数判定编码器对推杆是否敏感。配对共享两个已知根和轨迹，
不是 51 个独立任务。

为尝试控制变量，曾用默认 PushT reset 重建根 0 的目标图像；其像素
与封存目标 RGB 不相等，故未运行反事实图像编码或声称它是合法
干预。后续需要从认证的场景、渲染配置和目标状态重建精确基线，再
在固定物体姿态下改变推杆位置并验证渲染；模拟器状态只能用于
诊断构造和事后评价，不输入 RGB 规划器。
