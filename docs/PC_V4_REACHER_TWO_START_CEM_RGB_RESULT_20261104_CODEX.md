# Reacher 双起点 CEM：真实 RGB 反馈开发对照

按[事前协议](PC_V4_REACHER_TWO_START_CEM_RGB_PROTOCOL_20261104_CODEX.md)，在已暴露根 20263160 执行双起点 CEM 三轮真实 RGB 反馈。该臂使用自身旧尾和新观测，未读取 v4 轨迹。两个方法同样每轮使用 1920 预测 token、固定终点 15/10/5、每轮执行 5 步。

| 方法 | 初始距离 | 第 5 步 | 第 10 步 | 第 15 步 |
| --- | ---: | ---: | ---: | ---: |
| v4 response，先前封存 | 1.003500 | 0.812078 | 0.266470 | 0.491198 |
| 双起点 smooth CEM | 1.003500 | 1.091327 | 0.992984 | 0.555675 |

第二、三轮 CEM 均先在新图像上下文评分本臂零链和旧尾，各将余下预算平分：分别为每个起点 479 和 959 个完整链样本。两轮旧尾的初始模型评分均优于零链，但最终得分最低的候选都来自零链起点；不能把这个结果解释为“旧尾没有作用”，因为它仍占据预算，且只测一个根。每轮实际按完整链评分选中并派发；中间反馈状态和动作历史已核验。

[记录与预算审计](../le-wm-main/results/pc_v4_reacher_two_start_cem_rgb_20261104_codex_audit.json)核验 3 次选择、分配及动作绑定。[同后端物理重放](../le-wm-main/results/pc_v4_reacher_two_start_cem_rgb_20261104_codex_physical_replay.json)的起始 RGB 一致、四个边界 qpos 和目标最大差为 0；未独立核对 qvel 或所有中间状态。[参考模型路径重算](../le-wm-main/results/pc_v4_reacher_two_start_cem_rgb_20261104_codex_prediction_replay.json)覆盖 297 批、3520 条完整链，最大位置差 4.30e-6、评分差 4.77e-7；重算使用同一 checkpoint 和输入，并非独立模型。

该结果补上了旧尾参与优化的真实反馈基线，但**不能据此宣称 v4 强基线优势**：仅一个开发暴露根；双起点未充分调优；同 token 不代表编码、预测、SVD 和 wall time 等全部资源相等，也未完成独立来源、统计和关键消融。原方案 PC3、PC4 的状态不因该实验改变。
