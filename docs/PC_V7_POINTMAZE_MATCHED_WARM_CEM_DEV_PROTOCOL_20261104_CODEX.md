# v7 PointMaze：同根热启动 CEM 开发对照

在已暴露的 v7 PointMaze 根 0 上，使用同一冻结 checkpoint、RGB 与目标、动作统计、后端、15 步真实暖身、TF32 设置以及固定终点 15／10／5 步时域，另运行一条 smooth CEM 臂；不覆盖 v7 结果。首轮以零链为起点，后两轮在该臂自身真实观测下共同重评分 zero 与本臂 carry，分别以两者初始化四结点 CEM，近等分剩余样本并保留所有评分完整链的最优。每轮预算不超过 1920 prediction-token，记录原始与 float32 请求、预测、代更新、RGB、carry、派发和时钟。

执行器旧接口使用 `response` 作为单臂输出标签；本次方法入口明确将其映射到 `smooth_cem`，manifest 的 method 和依赖记录真实 CEM 方法，标签不表示运行响应程序。原 v7 结果只用于启动前后哈希绑定和事后配对，不得输入基线候选、目标、carry 或策略。

事后检查两臂共同初始 RGB、目标、动作历史及目标位置；审计基线自身 carry、两个起点和预算，再用同一 shadow 后端重放所有 31 帧、用 native 后端重放所有动作、用相同冻结模型显式 packet 路径重算所有预测。逐轮报告真实距离；后续状态不同的模型分数不可跨臂直接比较。实际运行、重放和依赖均排他保存。

这是一个已暴露根的开发对照，不是充分调优的 CEM 上界、来源合格的独立确认或 PC3／PC4 通过；相同 token 不等于总计算成本相同。训练与 normalizer 来源仍为 unknown。
