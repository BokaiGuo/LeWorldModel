# P1 多起点轨迹的第十步可观测性复核

原封存分析采用状态合同：只有 `probe_completed` 才输出固定
十步终点；所有 `native_stopped` 均留空。这一合同没有伪造数据，
但对“第十步已经执行并产生成功事件”的情况过于保守，不能据此
声称这类轨迹没有第十步观测。

对 24 条既有轨迹逐一绑定封存的配对报告、顶层 shard 哈希、
原始逐步事件和任务身份，并检查停止前没有终止事件、十步状态
与该步帧记录中的状态相同。新脚本单独输出第十步是否观测到：

- 19 条 `probe_completed` 的第十步观测与旧终点一致。
- 3 条 `native_stopped` 在第十步停止，第十步状态确实已记录，
  分别是索引 7、19、22，且原生成功。
- 2 条分别在第 8、9 步停止，固定第十步仍为空；未延长轨迹，
  没有填补缺失终点。

新增的三个可比较 selected-minus-zero 逻辑对中，位置终点误差
分别高约 35.50、3.86、3.86；后两条共享相同结果。此为事后
描述，不构成独立样本或公平优势检验；第十步的存在也不意味着
应对提前停止后的规划器继续执行。原先 0/8、5/8、0/8 的成功
记录不变，P1 仍关闭。

实现与结果：

- `le-wm-main/experiments/spectral_reachability/p1_uphill_horizon_observation_20261031.py`
- `le-wm-main/results/p1_uphill_horizon_observation_20261031_RUN01.json`，
  SHA-256 `6b5d986d9a660b4b18a1b6e8cceeecd0d39dc2894c47d87c5772781a3589332e`。
- 两项测试验证第十步终止保留、早停不补值，以及帧状态篡改和
  更早终止事件被拒绝。只读取既有物理数据，没有执行神经推理。

此输出不覆盖历史报告，也不自动修改其下游准入合同。后续若要
使用新增状态计算 RGB 编码或配对统计，需为该新分析重新绑定
实际图像和模型来源，并将终止时序单独报告。

## 共同后缀面板的同一问题

上述状态合同也影响共同后缀：1008 条中，1004 条状态为
`probe_completed`，4 条为 `native_stopped`；后者中两条在第
9 步停止，另两条在第 10 步停止。因此已有第十步观测的记录是
**1006/1008**，而不是仅有 1004 条。旧报告对 root 0 每臂“40 个
可比较终点、1 个提前停止”的描述对 logical pair 2、3 不适用：
这两臂各有 41 个可比较的非零共同后缀，第 0、1 臂仍为 40 个。

追加的第十步记录均为同根重复的 `original_selected_tail`，相对
zero 前缀的共同后缀终点物体位置误差低约 10.61、角度误差低约
0.0282；相对各自零后缀的物体位置响应差也约为 −10.61。它们是
已知根上同一个动作的机制线索，不是两个独立成功，不说明各自
重新规划的能力更强，也不能证明预定非即时进展条件或 P1 通过。
