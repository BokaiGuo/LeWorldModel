# 规划内 RGB 编码缓存：真实反馈开发协议

对既有四根、三个策略，以同一固定种子和初始状态运行缓存版本真实反馈：各策略独立执行并重新渲染，新一轮规划新建缓存会话；目标与动作历史采用原协议。记录每次完整评分、选择、动作和实际物理轨迹，计入编码器调用、同步规划计时、全部模型评分和环境步。

评价端事后比较原版本的每次选择、完整候选分数、实际派发、逐步成功与距离；对不同的结果保留完整轨迹，不以原动作替换缓存控制器输出。若任一分数超出 atol=1e-4、rtol=1e-5，或所选动作、终止、物理距离（1e-6）不一致，则不能声称本面板闭环等价。核验缓存只在单次规划内复用，模型前后指纹不变。此为已曝光小面板的工程回归，不能证明独立性能、非劣效或 PC0–PC5。
