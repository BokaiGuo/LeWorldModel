# 已加载源码绑定：RGB 闭环集成回归

按[协议](PC_SOURCE_BOUND_RGB_REPLAY_PROTOCOL_20261107_CODEX.md)，在本机
GPU、冻结 TwoRoom LeWM 和实际环境上重放已曝光的 episode 9000–9003，
每个任务分别运行 lookahead、effect 和 CEM16。规划接口为 RGB-only，
物理状态仅用于评价端初始化和测量。

12 条轨迹、40 次规划、640 条候选评分、178 个实际执行步均完成。
与既有记录比较，动作及物理距离最大绝对差均为 0，选择和终止状态一致；
这只是同实现回归，不是独立方法比较。新包装器对 checkpoint 逐张量
核验，并在开始和结束时检查已加载的指定目录下绝对路径 `.py` 文件。
本次清单有 5,938 个模块名、5,875 个不同路径，其中 5,814 个模块
位于工作区虚拟环境；产物保存后独立重算全部清单文件哈希，失配为 0。
初始化和结束检查同步计时约 0.540 秒、0.929 秒，不是整任务成本曲线。

首次集成在运行前发现 `torch.classes` 暴露相对伪路径，原检查错误地将其
解析到当前工作区；修正为不纳入相对路径，并增加回归测试。第二次运行
完成轨迹但在验收时检测到四个延迟加载模块，按失败关闭且不写通过产物；
最终运行在快照前显式导入这四个模块并纳入清单，之后清单不变。
源码绑定与原 checkpoint 绑定定向测试共 10 项通过。环境仍有 reset
观测类型和动作转换警告。

该清单不覆盖相对路径模块、非 Python 源码、解释器、尚未加载的模块、
运行中间短暂改变后恢复的文件，也不证明内存代码与文件一致或官方来源。
若有其他延迟导入，当前实现会拒绝验收；它没有自动接入全部研究运行器。
`experiment-design` 用于固定同任务、同算法的回归比较及区分认证和
控制收益。此结果不改变任何 gate，也不能替代行动后果信息的独立增量、
公平成本比较、独立任务和跨模型验证。
